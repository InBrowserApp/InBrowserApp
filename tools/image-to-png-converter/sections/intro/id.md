## Konversikan gambar ke PNG

Buka gambar lokal, periksa pratinjau, lalu unduh gambar yang dipilih sebagai PNG. Gambar yang disimpan mempertahankan dimensi piksel penuh, orientasi yang diterapkan, dan transparansi yang didukung. Kontrol perbesaran, penyesuaian ukuran, dan latar belakang hanya memengaruhi pratinjau; kontrol tersebut tidak mengubah ukuran hasil atau menghilangkan transparansi.

## Format dan pemilihan gambar

Baca JPEG, PNG, GIF, BMP, WebP, gambar diam AVIF, TIFF, ICO, gambar diam dan koleksi HEIC/HEIF, JPEG XL, JP2, serta aliran kode JPEG 2000 (J2K). Isi file diperiksa alih-alih mengandalkan ekstensinya. Dukungan bergantung pada pengodean di dalam file. Untuk gambar vektor SVG, gunakan Konverter SVG ke gambar yang terpisah untuk mengonversinya ke PNG.

Untuk file yang berisi beberapa gambar, pilih halaman TIFF, ukuran ikon, gambar dalam koleksi, atau bingkai animasi sebelum mengunduh. Setiap unduhan berisi satu PNG diam, dengan nomor halaman atau bingkai tercantum dalam nama file. Bingkai GIF, WebP animasi, dan JPEG XL dikompositkan menjadi gambar yang utuh. PNG animasi hanya mengekspor gambar diam bawaannya yang diberi label sebagai poster; bingkai lain tidak dapat diekspor dan animasi tidak dapat dipertahankan.

## Ketepatan dan file yang tidak didukung

Hasil menggunakan kanal 8-bit. Kedalaman bit tinggi dan HDR dikurangi, sehingga konversi ke PNG tidak mengembalikan presisi sumber. Profil warna tertanam dipertahankan jika didukung, tetapi warna mungkin berbeda dari editor dengan pengelolaan warna. Gambar tambahan, peta kedalaman, dan metadata kontainer tidak dipertahankan dalam konversi.

Urutan berwaktu HEIF/AVIF, komposisi JPEG 2000 (JPX/JPF/JPM), dan Motion JPEG 2000 (MJ2) tidak didukung. Gambar yang rusak atau tidak didukung menampilkan kesalahan, bukan menghasilkan unduhan. Gambar yang sangat besar atau rumit dapat melampaui sumber daya browser atau dekoder; tidak ada batas tetap untuk ukuran file atau jumlah gambar.

## Pemrosesan lokal dan unduhan

File tetap di perangkat ini. Batalkan, tutup, atau ganti file untuk melepaskan dekoder dan data unduhan saat ini. Mengubah gambar yang dipilih menghapus data unduhan sebelumnya saat gambar berikutnya disiapkan. File hanya disimpan saat Anda memilih Unduh PNG. Penampil Gambar juga menawarkan unduhan PNG yang sama untuk gambar yang dipilih.
