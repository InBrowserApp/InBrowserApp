## 테스트 이메일 주소 일괄 생성

도메인을 선택하고 개수를 입력한 다음 **생성**을 선택하세요. **예시 도메인 혼합**을 선택하면 여러 도메인을 섞어 생성합니다. 한 번에 생성된 주소는 중복되지 않습니다. 결과를 양식이나 스프레드시트에 복사하거나, 테스트 데이터로 사용할 수 있도록 한 줄에 주소 하나가 담긴 UTF-8 텍스트 파일로 다운로드하세요.

## 어떤 이메일 도메인을 사용할 수 있나요?

Faker.js는 `example.com`, `example.net`, `example.org` 도메인의 주소를 생성합니다. 이 [예약된 예시 도메인](https://www.iana.org/help/example-domains)은 문서와 샘플 데이터에 사용됩니다. `alex.morgan42@example.com`에서 `@` 앞은 로컬 부분이고 `example.com`은 도메인입니다. 테스트에 고정값이 필요하면 하나의 도메인을 사용하고, 필터링이나 가져오기를 테스트하려면 도메인을 섞어 사용하세요.

## 이 주소로 무엇을 테스트할 수 있나요?

이 샘플은 가입 양식 입력, 이메일 주소 형식, 계정 목록 또는 데이터베이스의 중복 제거를 테스트하는 데 사용할 수 있습니다. 생성기는 주소 문자열만 생성하며 받은 편지함은 만들지 않습니다. 메일 배달이나 확인 링크를 테스트하려면 직접 관리하는 받은 편지함이나 개발용 메일 샌드박스를 사용하세요.
