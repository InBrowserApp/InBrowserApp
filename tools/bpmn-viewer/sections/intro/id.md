## Buka diagram BPMN 2.0 secara online

Pilih **Buka file BPMN** atau seret file `.bpmn` atau `.xml` ke penampil. Diagram dibaca langsung di browser. Pilih **Coba contoh** untuk melihat proses persetujuan sederhana sebelum membuka file Anda sendiri.

## Periksa tugas, keputusan, dan alur proses

Seret diagram untuk menggeser tampilan. Gunakan tombol perbesaran untuk membaca label kecil, lalu pilih **Tampilkan seluruh diagram** untuk kembali melihat proses secara utuh. Buka tampilan layar penuh untuk memeriksa diagram besar dengan lajur, aktivitas, gerbang, dan peristiwa.

## Buka file BPMN tanpa tata letak diagram

XML BPMN 2.0 dapat menjelaskan proses tanpa mencatat lokasi bentuk dan penghubung. Penampil menggunakan data BPMN Diagram Interchange yang disimpan bersama model untuk menggambar diagram. Jika tata letaknya tidak ada, buka model di alat pemodelan BPMN dan ekspor ulang dengan menyertakan diagram. Lihat [spesifikasi BPMN 2.0](https://www.omg.org/spec/BPMN/2.0.2/) untuk detail format.

## Unduh diagram sebagai PDF atau SVG

Pilih **Unduh PDF** untuk membagikan seluruh diagram sebagai PDF vektor, atau **Unduh SVG** untuk menyematkannya ke dokumen dan slide. Kedua format memuat seluruh diagram meskipun Anda memperbesar bagian tertentu. Untuk mencetak diagram pada kertas A4 atau US Letter, buka di [Konverter BPMN ke PDF](../bpmn-to-pdf-converter/).
