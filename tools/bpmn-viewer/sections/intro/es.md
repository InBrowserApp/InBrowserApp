## Abrir un diagrama BPMN 2.0 en línea

Selecciona **Abrir archivo BPMN** o arrastra un archivo `.bpmn` o `.xml` al visor. El navegador lee el diagrama en tu dispositivo. Selecciona **Probar un ejemplo** para ver un proceso sencillo de aprobación antes de abrir tu archivo.

## Inspeccionar tareas, decisiones y flujos de proceso

Arrastra el diagrama para desplazarte. Usa los controles de zoom para leer etiquetas pequeñas y selecciona **Ajustar diagrama a la vista** para volver a ver todo el proceso. Abre la vista en pantalla completa para tener más espacio al examinar diagramas grandes con carriles, actividades, compuertas y eventos.

## Abrir un archivo BPMN sin datos de disposición

Un archivo XML de BPMN 2.0 puede describir un proceso sin indicar dónde aparecen sus formas y conexiones. El visor dibuja el diagrama a partir de los datos de BPMN Diagram Interchange guardados con el modelo. Si faltan estos datos, abre el modelo en tu herramienta de modelado BPMN y expórtalo de nuevo con el diagrama incluido. Consulta la [especificación BPMN 2.0](https://www.omg.org/spec/BPMN/2.0.2/) para conocer los detalles del formato.
