## Aprire un diagramma BPMN 2.0 online

Seleziona **Apri file BPMN** o trascina un file `.bpmn` o `.xml` nel visualizzatore. Il browser legge il diagramma sul tuo dispositivo. Seleziona **Prova un esempio** per vedere un semplice processo di approvazione prima di aprire il tuo file.

## Esaminare attività, decisioni e flussi di processo

Trascina il diagramma per spostarti. Usa i pulsanti di zoom per leggere le etichette più piccole e seleziona **Adatta diagramma alla vista** per vedere di nuovo l’intero processo. Passa a schermo intero per esaminare più comodamente i diagrammi grandi con corsie, attività, gateway ed eventi.

## Aprire un file BPMN senza layout

Un file XML BPMN 2.0 può descrivere un processo senza indicare la posizione delle forme e dei collegamenti. Il visualizzatore usa i dati BPMN Diagram Interchange salvati con il modello per disegnare il diagramma. Se manca il layout, apri il modello nello strumento di modellazione BPMN ed esportalo di nuovo includendo il diagramma. Consulta la [specifica BPMN 2.0](https://www.omg.org/spec/BPMN/2.0.2/) per maggiori dettagli sul formato.
