## פתיחת קובצי DICOM

בחרו **פתיחת קובצי DICOM** או גררו קובץ אחד או יותר אל המציג. בחרו את כל התמונות מסדרת CT או MRI כדי לעבור בין החתכים. אם הקבצים כוללים כמה סדרות, השתמשו בבורר **סדרה** כדי לעבור ביניהן. אפשר לפתוח קבצים בסיומת `.dcm` או `.dicom`, וגם קבצים ללא סיומת.

גללו מעל התמונה, העבירו אליה את המיקוד והשתמשו במקשי החצים למעלה ולמטה, או השתמשו במחוון החתכים או בכפתורי הניווט. בחרו **לנסות דוגמה** כדי לעיין בסדרת CT סינתטית לפני שתפתחו קבצים משלכם.

## שינוי רוחב החלון ומרכזו

רוחב החלון קובע את גודל הטווח של ערכי האפור שיוצגו. צמצום החלון מגביר את הניגודיות בתוך הטווח. מרכז החלון, שנקרא גם רמת החלון, מזיז את הטווח לערכים בהירים או כהים יותר. הזינו ערכים תחת **הגדרות חלון**, או גררו לרוחב כדי לשנות את הרוחב ולאורך כדי להזיז את המרכז. בחרו **איפוס** כדי לשחזר את הגדרות התצוגה ההתחלתיות של החתך הנוכחי.

## עיון במטא־נתונים של DICOM

פתחו את **מטא־נתונים** כדי לעיין בתגיות של הקובץ הנוכחי, הכוללות את סוג הדימות, תיאור הסדרה וממדי התמונה אם הם שמורים בקובץ. אפשר לחפש לפי מספר התגית, שם המאפיין או הערך שלו. בקובץ שמכיל כמה פריימים, הטבלה מציגה את המאפיינים המשותפים להם. המטא־נתונים עשויים לכלול מידע מזהה. הקבצים והתגיות מעובדים במכשיר שלכם בלי להעלות אותם.

## תמונות DICOM נתמכות

המציג פותח תמונות DICOM בגוני אפור שנתוני הפיקסלים שלהן נשמרו ללא דחיסה או בדחיסת JPEG Lossless, לרבות קבצים עם כמה פריימים. DICOM הוא פורמט מכל, כך שקידוד נתוני הפיקסלים קובע אם אפשר להציג את התמונה. אם נעשה שימוש בקידוד אחר כמו JPEG 2000, ייצאו את התמונה בפורמט DICOM ללא דחיסה מתוכנת הדימות המקורית. השתמשו במציג לעיון בתמונות ובקבצים ובעמדת עבודה קלינית לצורך אבחון.
