## DICOM 파일 열기

**DICOM 파일 열기**를 선택하거나 하나 이상의 파일을 뷰어에 놓으세요. CT 또는 MRI 시리즈의 영상을 모두 선택하면 슬라이스를 탐색할 수 있습니다. 파일에 여러 시리즈가 포함되어 있으면 **시리즈** 선택 메뉴에서 전환하세요. 파일 확장자는 `.dcm` 또는 `.dicom`이거나 없을 수도 있습니다.

영상 위에서 스크롤하거나 영상에 포커스를 둔 뒤 위아래 화살표 키를 누르세요. 슬라이스 슬라이더나 버튼을 사용해도 됩니다. 파일을 열기 전에 **샘플 사용해 보기**를 선택하여 합성 CT 시리즈를 살펴볼 수 있습니다.

## 윈도우 너비와 레벨 조절하기

윈도우 너비는 표시되는 회색조 값의 범위를 정합니다. 너비를 좁히면 해당 범위의 대비가 높아집니다. 윈도우 중심이라고도 하는 윈도우 레벨은 범위를 더 밝거나 어두운 값 쪽으로 이동합니다. **윈도우 설정**에서 값을 입력하거나 영상 위에서 가로로 드래그해 너비를, 세로로 드래그해 레벨을 조절하세요. **초기화**를 선택하면 현재 슬라이스의 처음 설정으로 돌아갑니다.

## DICOM 메타데이터 확인하기

**메타데이터**를 열면 현재 파일의 태그를 볼 수 있습니다. 파일에 정보가 있으면 촬영 방식, 시리즈 설명, 영상 크기 등이 표시됩니다. 태그 번호, 속성 이름 또는 값으로 검색할 수 있습니다. 다중 프레임 파일의 표에는 파일 전체에 공통된 속성이 표시됩니다. 메타데이터에는 개인 식별 정보가 포함될 수 있습니다. 파일과 태그는 업로드되지 않고 이 기기에서 처리됩니다.

## 지원하는 DICOM 영상

뷰어는 압축되지 않았거나 JPEG Lossless로 인코딩된 픽셀 데이터를 가진 회색조 DICOM 영상을 지원하며, 다중 프레임 파일도 열 수 있습니다. DICOM은 컨테이너 형식이므로 영상 표시 가능 여부는 픽셀 데이터의 인코딩에 따라 달라집니다. JPEG 2000 등 다른 인코딩을 사용한 경우 원본 영상 소프트웨어에서 압축하지 않은 DICOM 파일을 내보내세요. 이 뷰어는 파일과 영상을 확인하는 용도입니다. 진단에는 임상용 워크스테이션을 사용하세요.
