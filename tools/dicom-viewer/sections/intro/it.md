## Come aprire file DICOM

Seleziona **Apri file DICOM** o trascina uno o più file nel visualizzatore. Per scorrere una serie di tomografia computerizzata (TC) o risonanza magnetica (RM), seleziona tutte le sue immagini. Se i file contengono più serie, puoi passare da una all’altra con il selettore **Serie**. I file possono avere estensione `.dcm` o `.dicom`, oppure essere privi di estensione.

Usa la rotellina sull’immagine, raggiungi l’immagine con la tastiera e premi la freccia su o giù, oppure usa il cursore e i pulsanti di navigazione. Seleziona **Prova l’esempio** per esplorare una serie TC sintetica prima di aprire i tuoi file.

## Regolare larghezza e livello della finestra

La larghezza della finestra determina l’intervallo di grigi visibili. Restringendo la finestra, aumenta il contrasto all’interno di quell’intervallo. Il livello della finestra, detto anche centro della finestra, sposta l’intervallo e modifica la luminosità. Inserisci i valori in **Impostazioni della finestra** o trascina sull’immagine in orizzontale per cambiare la larghezza e in verticale per cambiare il livello. Seleziona **Ripristina** per tornare alle impostazioni iniziali della sezione visualizzata.

## Consultare i metadati DICOM

Apri **Metadati** per consultare i tag del file visualizzato, come la modalità di acquisizione, la descrizione della serie e le dimensioni dell’immagine, se presenti. Cerca per numero di tag, nome dell’attributo o valore. Se il file contiene più fotogrammi, la tabella mostra gli attributi comuni a tutto il file. I metadati possono contenere informazioni che permettono di identificare una persona. I file e i relativi tag vengono elaborati su questo dispositivo senza essere caricati online.

## Immagini DICOM supportate

Il visualizzatore apre immagini DICOM in scala di grigi con dati dei pixel non compressi o in formato JPEG senza perdita, compresi i file con più fotogrammi. DICOM è un formato contenitore. La possibilità di visualizzare un’immagine dipende dalla codifica dei pixel. Se l’immagine usa un’altra codifica, come JPEG 2000, esportala come DICOM senza compressione dal software di imaging originale. Il visualizzatore serve a consultare file e immagini. Per la diagnosi, usa una postazione di lavoro clinica.
