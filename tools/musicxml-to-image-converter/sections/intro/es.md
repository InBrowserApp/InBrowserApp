## Convierte MusicXML o MXL a PNG o SVG

Selecciona **Abrir archivo MusicXML** o arrastra al conversor una partitura `.musicxml` o `.xml`, o un archivo `.mxl` comprimido. Selecciona PNG o SVG en **Formato de imagen**. Pulsa **Probar un ejemplo** si quieres probar el proceso con una partitura breve para piano. El conversor genera y exporta las imágenes en el navegador.

## Exporta toda la partitura, una página o unos pocos compases

Elige **Todas las páginas** para guardar la partitura completa en formato A4. Elige **Página actual** y usa las flechas de la **Vista previa de la imagen** para encontrar la página que quieras. Para incluir un ejemplo breve en una diapositiva, elige **Rango de compases**, indica el primero y el último y pulsa **Previsualizar fragmento**. Cuenta los compases en el orden en que aparecen en la partitura, desde el 1 e incluyendo la anacrusa si la hay. El conversor recorta el espacio en blanco alrededor del fragmento.

## Elige entre PNG y SVG

PNG es una imagen de mapa de bits nítida que puedes insertar en un documento, una presentación o un mensaje. SVG mantiene la notación nítida a distintos tamaños y resulta útil en sitios web o editores de dibujo vectorial. Al abrir un SVG, otras aplicaciones pueden sustituir la fuente usada para los títulos o las letras de las canciones. PNG conserva el aspecto que muestra el navegador.

## Descarga las imágenes

Selecciona **Descargar imagen** si solo quieres una imagen. Si la exportación ocupa varias páginas, selecciona **Descargar ZIP** y descomprime el archivo para obtener una imagen numerada por página. Para imprimir toda la partitura en un solo documento, usa el [Conversor de MusicXML a PDF](/es/tools/musicxml-to-pdf-converter/).
