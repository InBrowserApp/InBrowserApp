## 從 MP4 或 WebM 影片擷取音訊

將影片的配樂、旁白或其他語言的音軌另存成音訊檔。開啟 MP4 或 WebM 影片，選擇要保留的音軌，試聽後即可下載。所有處理都在瀏覽器中完成，影片和擷取的音訊都會留在你的裝置上。

### 如何從影片擷取音軌

1. 按一下 **選擇 MP4 或 WebM**，或將裝置上的影片拖曳到工具中。
2. 選擇 **音軌**。每個選項都會顯示編解碼器，以及檔案中已有的語言標記或音軌名稱，方便在有多條音軌的影片中找到講評或其他語言的音軌。
3. 使用 **試聽音軌** 確認選得正確，再下載音訊檔。如需分開儲存其他音軌，切換音軌後再下載即可。

### 可以下載哪些音訊格式？

| 來源 | 音訊編解碼器   | 下載格式    |
| ---- | -------------- | ----------- |
| MP4  | AAC            | M4A         |
| WebM | Opus 或 Vorbis | 純音訊 WebM |

工具會將已編碼的音訊複製到新的容器中，這個過程稱為重新封裝。下載的檔案保留原始音質，只包含選取的音軌。

### 常見問題

#### 可以將 MP4 的音訊擷取為 M4A 並保留原始音質嗎？

可以。如果 MP4 含有 AAC 音軌，工具會將原始 AAC 音訊封裝為 M4A，無需重新編碼。

#### 為什麼無法試聽音軌？

能否播放取決於瀏覽器是否支援擷取後的音訊格式。即使無法試聽，支援匯出的音軌仍可下載。如果工具顯示編解碼器不受支援，可以試試影片中的其他音軌。
