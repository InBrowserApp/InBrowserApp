File `.torrent` adalah file kecil yang berisi metadata BitTorrent. Isinya mencakup nama, jalur folder, dan ukuran file yang akan diunduh oleh klien torrent. Buka file `.torrent` di sini untuk melihat isinya sebelum membukanya di klien BitTorrent.

## Cara membuka file .torrent

Pilih file `.torrent` atau seret ke penampil. Daftar file menampilkan jalur dan ukuran yang tercatat dalam metadata. Anda dapat memfilter daftar tersebut berdasarkan nama file atau jalur folder. Ringkasannya memuat ukuran total, ukuran dan jumlah potongan, serta informasi pembuatan atau komentar jika tersedia.

## Arti info hash dan pelacak

Info hash adalah pengenal torrent yang juga tercantum dalam tautan magnet BitTorrent. Bandingkan nilai ini dengan hash dari sumber tepercaya untuk memeriksa apakah keduanya menunjuk ke torrent yang sama. Pelacak (_tracker_) membantu peer saling menemukan, sedangkan _web seed_ adalah server yang dapat menyediakan data file. Penampil mencantumkan alamat yang tercatat dalam file torrent.

## Torrent yang didukung dan privasi

Penampil membaca metadata BitTorrent v1 dan hibrida v1/v2. File dibaca secara lokal di browser Anda tanpa diunggah dan tanpa menghubungi pelacak, peer, atau web seed. Nama dan ukuran file diambil dari metadata. Ketersediaan dan isi file yang sebenarnya perlu diperiksa secara terpisah.
