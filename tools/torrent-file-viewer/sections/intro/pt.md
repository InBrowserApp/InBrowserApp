Um arquivo `.torrent` é um pequeno arquivo de metadados BitTorrent. Ele descreve os arquivos que um cliente de torrent baixaria, incluindo nomes, caminhos de pastas e tamanhos. Abra-o aqui para ver o conteúdo do torrent antes de abri-lo em um cliente BitTorrent.

## Como abrir um arquivo .torrent

Escolha ou arraste um arquivo `.torrent`. A lista mostra os caminhos e tamanhos informados nos metadados. Você pode filtrá-la por nome de arquivo ou caminho de pasta. A visão geral mostra o tamanho total, o tamanho e a quantidade de peças, além dos dados de criação e comentários disponíveis.

## O que significam o hash de informação e os trackers

O hash de informação identifica o torrent e é o valor presente em um link magnet BitTorrent. Compare-o com um hash de uma fonte conhecida para verificar se ambos identificam o mesmo torrent. Os trackers ajudam os peers a se encontrar, enquanto os web seeds são servidores que podem fornecer dados dos arquivos. O visualizador lista os endereços registrados no arquivo torrent.

## Torrents compatíveis e privacidade

O visualizador lê metadados BitTorrent v1 e híbridos v1/v2. O arquivo é lido localmente no navegador, sem envio e sem conexão com trackers, peers ou web seeds. Nomes e tamanhos de arquivos vêm dos metadados. A disponibilidade e o conteúdo dos arquivos não podem ser determinados apenas pelos metadados.
