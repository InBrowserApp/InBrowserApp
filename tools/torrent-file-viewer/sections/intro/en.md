A `.torrent` file is a small BitTorrent metadata file. It describes the files a torrent client would download, including their names, folder paths, and sizes. Open it here to see what the torrent contains before opening it in a BitTorrent client.

## How to open a .torrent file

Choose or drag in a `.torrent` file. The file list shows the advertised paths and sizes. You can filter it by file name or folder path. The overview shows the total size, piece size, piece count, and any available creation details or comment.

## What the info hash and trackers mean

The info hash identifies the torrent and is the value carried by a BitTorrent magnet link. Compare it with a hash from a known source to check whether the two identify the same torrent. Trackers help peers find one another, while web seeds are servers that can supply file data. The viewer lists the addresses recorded in the torrent file.

## Supported torrents and privacy

The viewer reads BitTorrent v1 and hybrid v1/v2 metadata. It reads the file locally in your browser without uploading it or contacting trackers, peers, or web seeds. File names and sizes come from the metadata. Availability and file contents are separate from what the metadata can show.
