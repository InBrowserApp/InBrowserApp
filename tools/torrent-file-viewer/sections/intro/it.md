Un file `.torrent` è un piccolo file di metadati BitTorrent. Descrive i file che un client torrent scaricherebbe, con nomi, percorsi delle cartelle e dimensioni. Aprilo qui per scoprire cosa contiene il torrent prima di aprirlo in un client BitTorrent.

## Come aprire un file .torrent

Scegli o trascina un file `.torrent` nella pagina. L'elenco mostra i percorsi e le dimensioni indicati nel torrent. Puoi filtrarlo per nome del file o per percorso della cartella. Il riepilogo mostra la dimensione totale, la dimensione e il numero dei pezzi, oltre a eventuali informazioni sulla creazione e commenti.

## Cosa indicano l'info hash e i tracker

L'info hash identifica il torrent ed è il valore contenuto nel link magnet BitTorrent. Confrontalo con l'hash di una fonte nota per verificare se identificano lo stesso torrent. I tracker aiutano i peer a trovarsi, mentre i web seed sono server che possono fornire i dati dei file. Il visualizzatore elenca gli indirizzi registrati nel file torrent.

## Torrent supportati e privacy

Il visualizzatore legge i metadati BitTorrent v1 e quelli dei torrent ibridi v1/v2. Il browser legge il file localmente, senza caricarlo su un server né contattare tracker, peer o web seed. I nomi e le dimensioni dei file vengono dai metadati. Per verificare la disponibilità e il contenuto dei file occorrono altre fonti.
