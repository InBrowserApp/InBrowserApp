ไฟล์ `.torrent` คือไฟล์ขนาดเล็กที่เก็บเมตาดาตาของ BitTorrent เช่น ชื่อไฟล์ ตำแหน่งโฟลเดอร์ และขนาดของไฟล์ที่โปรแกรม BitTorrent จะดาวน์โหลด เปิดไฟล์ที่นี่เพื่อดูรายการไฟล์ก่อนนำไปเปิดในโปรแกรม BitTorrent

## วิธีเปิดไฟล์ .torrent

เลือกไฟล์ `.torrent` หรือลากมาวางบนหน้าเว็บ รายการจะแสดงพาธและขนาดที่ระบุไว้สำหรับแต่ละไฟล์ คุณกรองรายการตามชื่อไฟล์หรือพาธของโฟลเดอร์ได้ ส่วนสรุปจะแสดงขนาดรวม ขนาดและจำนวนชิ้นข้อมูล รวมถึงข้อมูลการสร้างทอร์เรนต์และหมายเหตุหากมีระบุไว้

## Info Hash และแทร็กเกอร์คืออะไร

Info Hash คือค่าแฮชที่ใช้ระบุทอร์เรนต์และอยู่ในลิงก์ Magnet ของ BitTorrent คุณเปรียบเทียบค่านี้กับค่าแฮชจากแหล่งที่รู้จักได้เพื่อตรวจว่าทั้งสองค่าระบุทอร์เรนต์เดียวกัน แทร็กเกอร์ช่วยให้เพียร์ค้นหากันเจอ ส่วนเว็บซีด (web seed) คือเซิร์ฟเวอร์ที่ให้ข้อมูลไฟล์ได้ เครื่องมือนี้จะแสดงที่อยู่ที่ระบุไว้ในไฟล์ทอร์เรนต์

## รูปแบบที่รองรับและความเป็นส่วนตัว

เครื่องมือนี้อ่านเมตาดาตาของ BitTorrent v1 และแบบผสม v1/v2 เบราว์เซอร์อ่านไฟล์บนอุปกรณ์ของคุณโดยไม่อัปโหลดหรือเชื่อมต่อกับแทร็กเกอร์ เพียร์ หรือเว็บซีด ชื่อและขนาดไฟล์มาจากเมตาดาตา หากต้องการดูเนื้อหาจริงหรือตรวจว่ายังดาวน์โหลดได้หรือไม่ ต้องตรวจสอบเพิ่มเติม
