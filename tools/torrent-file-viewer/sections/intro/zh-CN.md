`.torrent` 文件是一种小型 BitTorrent 元数据文件，记录了种子客户端将要下载的文件及其名称、文件夹路径和大小。在 BitTorrent 客户端中打开种子之前，可以先在这里查看种子包含的内容。

## 如何打开 .torrent 文件

选择或拖入 `.torrent` 文件。文件列表会显示元数据中记录的路径和大小，并支持按文件名或文件夹路径筛选。概览会显示总大小、分片大小、分片数量，以及可用的创建信息和备注。

## 信息哈希和 Tracker 的含义

信息哈希用于标识种子，也是 BitTorrent 磁力链接中携带的值。可以将它与可信来源提供的哈希值比较，确认两者是否指向同一个种子。Tracker 帮助节点相互发现；Web 种子则是可以提供文件数据的服务器。查看器会列出种子文件中记录的地址。

## 支持的种子和隐私

查看器支持读取 BitTorrent v1 和 v1/v2 混合种子的元数据。文件在浏览器中本地读取，不会上传，也不会连接 Tracker、节点或 Web 种子。文件名和大小来自元数据；文件是否可用以及实际内容无法仅凭元数据确定。
