Un fichier `.torrent` est un petit fichier de métadonnées BitTorrent. Il décrit les fichiers qu’un client BitTorrent téléchargerait, avec leurs noms, leurs dossiers et leurs tailles. Ouvrez-le ici pour savoir ce que contient le torrent avant de l’ajouter à votre client BitTorrent.

## Comment ouvrir un fichier .torrent

Sélectionnez ou déposez un fichier `.torrent`. La liste affiche les chemins et les tailles indiqués dans le torrent. Vous pouvez la filtrer par nom de fichier ou chemin de dossier. Le récapitulatif donne la taille totale, la taille et le nombre de morceaux, ainsi que les informations de création et le commentaire, s’ils sont disponibles.

## À quoi servent l’info hash et les trackers ?

L’info hash est l’empreinte qui identifie le torrent dans un lien magnet. Comparez-le à l’empreinte fournie par une source connue pour vérifier qu’il s’agit du même torrent. Les trackers aident les pairs à se trouver. Les sources web sont des serveurs qui peuvent fournir les données des fichiers. La visionneuse affiche les adresses inscrites dans le fichier torrent.

## Torrents pris en charge et confidentialité

La visionneuse lit les métadonnées BitTorrent v1 et hybrides v1/v2. Elle lit le fichier localement dans votre navigateur, sans l’envoyer à un serveur ni contacter de trackers, de pairs ou de sources web. Les noms et tailles affichés proviennent des métadonnées. Pour connaître la disponibilité ou le contenu des fichiers, il faut consulter le réseau BitTorrent ou les fichiers eux-mêmes.
