## Konversikan notasi ABC ke MIDI

Tempel **Notasi ABC**, atau pilih **Buka file ABC** untuk membuka file `.abc` atau `.txt`. Tombol **Coba contoh** memuat dua lagu pendek. Periksa not di **Pratinjau partitur**, lalu pilih **Unduh MIDI** untuk menyimpan file `.mid` standar yang dapat dibuka di DAW, sequencer, atau pemutar MIDI.

## Dengarkan lagu sebelum mengunduh

Pilih **Dengarkan** untuk memutar lagu yang tampil di **Pratinjau partitur** dengan instrumen General MIDI bawaan. Gunakan tombol panah di pratinjau untuk mendengar lagu lain. Saat pertama kali memutar lagu, suara instrumen mungkin perlu waktu untuk dimuat. Penanda tempo, tanda ulang, dan jalur suara ABC yang didukung diterapkan dalam sekuens MIDI.

## Ekspor lagu dari koleksi

Baris `X:` menandai awal setiap lagu dan `T:` berisi judulnya. Gunakan **Lagu yang disertakan** untuk memilih satu atau beberapa lagu. Satu lagu diunduh langsung sebagai file MIDI. Untuk beberapa lagu, pilih **Unduh ZIP**. Anda akan mendapatkan satu file MIDI bernomor untuk setiap lagu dalam urutan aslinya, termasuk jika ada judul yang sama.

## Gunakan MIDI untuk pemutaran dan penyuntingan

MIDI menyimpan peristiwa not, pengaturan waktu, dan instruksi pemutaran lain. Impor file ke perangkat lunak musik untuk mengubah suara instrumen atau menyunting permainannya. Untuk mencetak partitur, gunakan [Konverter Notasi ABC ke PDF](/id/tools/abc-notation-to-pdf-converter/).
