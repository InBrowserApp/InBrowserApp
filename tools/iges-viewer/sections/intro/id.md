## Buka file IGS atau IGES secara online

Pilih **Buka file** atau seret model CAD `.igs` atau `.iges` ke penampil. Kedua ekstensi tersebut mengacu pada format pertukaran IGES. Pilih **Coba contoh** untuk melihat komponen bertingkat. Penampil membaca file di perangkat Anda.

## Periksa permukaan model dalam 3D

Seret untuk memutar, gulir atau gunakan dua jari untuk memperbesar atau memperkecil, lalu seret dengan tombol kanan mouse atau dua jari untuk menggeser tampilan. Pilih **Tampilkan seluruh model** agar model terlihat utuh, **Rangka kawat** untuk melihat segitiga yang ditampilkan, atau **Buka layar penuh** agar lebih leluasa. Penampil mengubah permukaan IGES yang didukung menjadi mesh segitiga untuk ditampilkan dan menggunakan warna yang dibaca saat impor. Jika file IGES hanya berisi kurva, ekspor permukaannya dari aplikasi CAD. [Pengimpor IGES OpenCascade](https://github.com/kovacsv/occt-import-js)

## Ukur jarak dan ganti satuan

**Dimensi keseluruhan** menunjukkan bentang model di sepanjang sumbu X, Y, dan Z. **Satuan pengukuran** memungkinkan Anda memilih milimeter, meter, atau inci. Pilih **Ukur**, lalu pilih dua titik pada permukaan yang ditampilkan untuk mengetahui jarak garis lurusnya. Pengukuran pada permukaan melengkung berupa perkiraan karena didasarkan pada segitiga yang ditampilkan. Periksa dimensi penting di model CAD asli.

## Simpan PNG atau buka file CAD terkait

Atur sudut pandang dan tingkat perbesaran, lalu pilih **Simpan PNG** untuk menangkap tampilan saat ini sebagai bahan tinjauan gambar atau catatan produksi. Buka file STEP atau STP untuk komponen dan rakitan CAD di [Penampil STEP](../step-viewer/).
