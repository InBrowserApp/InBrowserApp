## Как найти метаданные NFT по адресу контракта и ID токена

Вставьте адрес контракта в основной сети Ethereum в поле **Адрес контракта** и укажите **ID токена**. Затем нажмите **Показать метаданные**. ID токена можно записать десятичным числом, например `1`, или шестнадцатеричным, например `0x1`. Нажмите **Попробовать на примере**, чтобы увидеть результат поиска. Браузер отправляет запрос Ethereum RPC только на чтение, поэтому для просмотра публичного токена кошелёк подключать не нужно.

## Где посмотреть URI токена, изображение, свойства и JSON

Инструмент читает `tokenURI` для ERC-721 или `uri` для ERC-1155. Поле **URI токена** содержит строку, которую вернул контракт. Инструмент загружает метаданные по этому адресу и отображает изображение, имя и свойства, если эти поля доступны. В разделе **Исходный JSON** можно посмотреть или скопировать ответ в исходном виде. Поддерживаются IPFS, HTTP, Arweave и встроенные данные JSON в data URI.

## Как подставляется ID токена в ERC-1155

Контракт ERC-1155 может вернуть общий шаблон для нескольких токенов. Инструмент заменяет `{id}` на ID токена в виде 64 строчных шестнадцатеричных символов с ведущими нулями, без префикса `0x`. После подстановки в поле **URI после подстановки** отображается адрес, по которому были запрошены данные токена. Такая же подстановка используется в полях предпросмотра, например в ссылке на изображение.

## Почему виден URI токена, а изображение недоступно?

Контракт может вернуть URI, даже если веб-сервер или шлюз IPFS временно недоступен. Если метаданные загрузить не удалось, URI остаётся доступным для копирования. Если JSON доступен, проверьте его поле `image` и попробуйте открыть источник напрямую. Серверы HTTP могут ограничивать междоменные запросы, из-за чего часть данных недоступна из браузера.

Описание полей, часто используемых приложениями NFT, см. в [стандарте ERC-721](https://eips.ethereum.org/EIPS/eip-721), [спецификации метаданных ERC-1155](https://eips.ethereum.org/EIPS/eip-1155#metadata) и [руководстве OpenSea по метаданным](https://docs.opensea.io/docs/metadata-standards).
