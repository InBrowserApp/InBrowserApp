## 컨트랙트 주소와 토큰 ID로 NFT 메타데이터 조회하기

이더리움 메인넷의 **컨트랙트 주소**를 붙여넣고 **토큰 ID**를 입력한 다음 **메타데이터 보기**를 누르세요. 토큰 ID는 `1` 같은 10진수나 `0x1` 같은 16진수로 입력할 수 있습니다. **예제 사용하기**를 누르면 조회 과정 전체를 확인할 수 있습니다. 이 도구는 브라우저에서 읽기 전용 이더리움 RPC 요청을 보내므로 지갑을 연결하지 않고도 공개 토큰을 조회할 수 있습니다.

## 토큰 URI, 이미지, 특성, JSON 확인하기

이 도구는 ERC-721의 `tokenURI` 또는 ERC-1155의 `uri`를 읽습니다. **토큰 URI**는 컨트랙트가 반환한 문자열입니다. 이 URI가 가리키는 메타데이터를 읽고, 해당 필드가 있으면 이미지, 이름, 특성을 표시합니다. **원본 JSON**에서 응답을 그대로 확인하거나 복사할 수 있습니다. IPFS, HTTP, Arweave, 그리고 JSON을 포함한 인라인 데이터 URI를 지원합니다.

## ERC-1155 토큰 ID가 치환되는 방식

ERC-1155 컨트랙트는 여러 토큰이 공유하는 템플릿을 반환할 수 있습니다. 이 도구는 `{id}`를 앞에 0을 채운 소문자 16진수 64자리 토큰 ID로 바꾸고 `0x` 접두사는 생략합니다. 템플릿이 바뀌면 **해석된 URI**에 해당 토큰을 가져오는 데 사용한 주소가 표시됩니다. 이미지 링크 같은 미리보기 필드에도 같은 치환 규칙이 적용됩니다.

## 토큰 URI는 표시되지만 이미지가 보이지 않으면 어떻게 하나요?

웹 호스트나 IPFS 게이트웨이를 일시적으로 사용할 수 없더라도 컨트랙트는 URI를 반환할 수 있습니다. 메타데이터를 불러오지 못한 경우에도 URI를 복사할 수 있습니다. JSON을 볼 수 있다면 `image` 필드를 확인하고 이미지 소스를 브라우저에서 직접 열어 보세요. HTTP 호스트가 교차 출처 요청을 제한하면 브라우저에서 읽을 수 있는 내용이 달라질 수 있습니다.

NFT 앱에서 자주 사용하는 필드에 대해서는 [ERC-721 표준](https://eips.ethereum.org/EIPS/eip-721), [ERC-1155 메타데이터 사양](https://eips.ethereum.org/EIPS/eip-1155#metadata), [OpenSea 메타데이터 가이드](https://docs.opensea.io/docs/metadata-standards)를 참고하세요.
