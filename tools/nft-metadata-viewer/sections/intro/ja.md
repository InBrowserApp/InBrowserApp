## コントラクトアドレスとトークン ID から NFT メタデータを調べる

Ethereum メインネットの **コントラクトアドレス** を貼り付け、**トークン ID** を入力し、**メタデータを表示** を押します。トークン ID は `1` のような 10 進数でも、`0x1` のような 16 進数でも指定できます。**サンプルを試す** を押すと、実際の検索結果を確認できます。このツールはブラウザから Ethereum に読み取り専用の RPC リクエストを送るため、ウォレットを接続せずに公開トークンを調べられます。

## トークン URI、画像、特性、JSON を確認する

このツールは ERC-721 の `tokenURI` または ERC-1155 の `uri` を読み取ります。**トークン URI** はコントラクトから返された文字列です。そこから取得したメタデータに画像、名前、特性が含まれていれば、それらを表示します。**元の JSON** では、変更を加えていないレスポンスを表示したりコピーしたりできます。IPFS、HTTP、Arweave、JSON をインラインで含むデータ URI に対応しています。

## ERC-1155 のトークン ID の置換方法

ERC-1155 コントラクトは複数のトークンで共用するテンプレートを返すことがあります。このツールは、先頭をゼロで埋めた小文字の 16 進数 64 桁のトークン ID で `{id}` を置き換えます。`0x` 接頭辞は付きません。テンプレートを置き換えた場合、実際に取得に使ったアドレスが **解決後の URI** に表示されます。画像リンクなどのプレビュー項目にも同じ置換規則が適用されます。

## トークン URI は表示されるのに画像が表示されない場合

ウェブホストや IPFS ゲートウェイが一時的に利用できない場合でも、コントラクトは URI を返すことがあります。メタデータを読み込めなくても、URI はコピーできます。JSON を取得できた場合は、`image` を確認し、画像の取得元を直接開いてみてください。HTTP ホストでクロスオリジンリクエストが制限され、ブラウザから読み取れる内容が限られる場合もあります。

NFT アプリでよく使われる項目については、[ERC-721 規格](https://eips.ethereum.org/EIPS/eip-721)、[ERC-1155 メタデータ仕様](https://eips.ethereum.org/EIPS/eip-1155#metadata)、[OpenSea メタデータガイド](https://docs.opensea.io/docs/metadata-standards)を参照してください。
