## 透過合約位址和代幣 ID 查詢 NFT 中繼資料

貼上以太坊主網的 **合約位址**，輸入 **代幣 ID**，再按下 **檢視中繼資料**。代幣 ID 可以是 `1` 這樣的十進位數，也可以是 `0x1` 這樣的十六進位數。按下 **試用範例** 即可查看完整的查詢流程。工具會在瀏覽器中向以太坊發出唯讀 RPC 請求，無須連接錢包就能查詢公開的代幣。

## 查看代幣 URI、圖片、特徵和 JSON

工具會讀取 ERC-721 的 `tokenURI` 或 ERC-1155 的 `uri`。**代幣 URI** 是合約傳回的字串。工具會讀取它指向的中繼資料，並在有相關欄位時顯示圖片、名稱和特徵。使用 **原始 JSON** 可檢視或複製未經修改的回應。支援 IPFS、HTTP、Arweave 和內嵌 JSON 的資料 URI。

## ERC-1155 如何替換代幣 ID

ERC-1155 合約可以傳回多個代幣共用的範本。工具會將 `{id}` 替換為 64 位小寫十六進位代幣 ID，在左側補零並省略 `0x` 前綴。替換範本後，**解析後的 URI** 會顯示用來取得該代幣中繼資料的實際位址。圖片連結等預覽欄位也會套用相同的替換規則。

## 為什麼有代幣 URI 卻沒有圖片？

即使網站主機或 IPFS 閘道暫時無法存取，合約仍可能傳回 URI。如果無法載入中繼資料，工具會保留 URI 供你複製。若有取得 JSON，請檢查其中的 `image` 欄位並直接開啟圖片來源。HTTP 主機也可能限制跨來源請求，影響瀏覽器可以讀取的內容。

NFT 應用程式常用欄位的定義請參閱 [ERC-721 標準](https://eips.ethereum.org/EIPS/eip-721)、[ERC-1155 中繼資料規格](https://eips.ethereum.org/EIPS/eip-1155#metadata)和 [OpenSea 中繼資料指南](https://docs.opensea.io/docs/metadata-standards)。
