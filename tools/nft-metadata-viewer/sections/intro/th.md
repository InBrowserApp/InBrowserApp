## ค้นหาข้อมูลเมตา NFT ด้วยที่อยู่สัญญาและ ID ของโทเคน

วาง **ที่อยู่สัญญา** บนเครือข่ายหลัก Ethereum แล้วป้อน **ID ของโทเคน** จากนั้นเลือก **ดูข้อมูลเมตา** ID ของโทเคนเป็นเลขฐานสิบ เช่น `1` หรือเลขฐานสิบหก เช่น `0x1` ก็ได้ เลือก **ลองใช้ตัวอย่าง** เพื่อดูขั้นตอนการค้นหาตั้งแต่ต้นจนจบ โปรแกรมส่งคำขอ Ethereum RPC แบบอ่านอย่างเดียวจากเบราว์เซอร์ คุณจึงค้นหาโทเคนสาธารณะได้โดยไม่ต้องเชื่อมต่อกระเป๋าเงิน

## ดู URI ของโทเคน รูปภาพ ลักษณะ และ JSON

โปรแกรมอ่าน `tokenURI` สำหรับ ERC-721 หรือ `uri` สำหรับ ERC-1155 **URI ของโทเคน** คือข้อความที่สัญญาส่งกลับมา โปรแกรมอ่านข้อมูลเมตาจาก URI นั้นและแสดงรูปภาพ ชื่อ และลักษณะเมื่อมีข้อมูล ใช้ **JSON ดิบ** เพื่อตรวจสอบหรือคัดลอกผลตอบกลับต้นฉบับ โปรแกรมรองรับ IPFS, HTTP, Arweave และ URI ข้อมูลที่ฝัง JSON โดยตรง

## การแทนค่า ID ของโทเคน ERC-1155

สัญญา ERC-1155 อาจส่งเทมเพลตที่ใช้ร่วมกันสำหรับหลายโทเคน โปรแกรมแทน `{id}` ด้วย ID ของโทเคนในรูปเลขฐานสิบหก ใช้ตัวอักษรพิมพ์เล็ก เติมศูนย์ด้านซ้ายให้ครบ 64 หลัก และไม่ใส่คำนำหน้า `0x` หลังแทนค่าแล้ว **URI หลังแทนค่า** จะแสดงที่อยู่ที่ใช้เรียกข้อมูลของโทเคนนั้น โปรแกรมใช้วิธีเดียวกันกับฟิลด์ตัวอย่าง เช่น ลิงก์รูปภาพ

## หากเห็น URI ของโทเคนแต่ไม่เห็นรูปภาพ

สัญญาอาจส่ง URI กลับมาแม้ว่าเว็บโฮสต์หรือเกตเวย์ IPFS จะใช้งานไม่ได้ชั่วคราว หากโหลดข้อมูลเมตาไม่ได้ โปรแกรมจะยังแสดง URI ให้คัดลอก หากมี JSON ให้ตรวจสอบฟิลด์ `image` แล้วลองเปิดแหล่งที่มาโดยตรง โฮสต์ HTTP อาจจำกัดคำขอข้ามต้นทาง ซึ่งส่งผลต่อข้อมูลที่เบราว์เซอร์อ่านได้
