## המרת JSON לגיליון Excel

הדביקו מערך JSON או פתחו קובץ <bdi dir="ltr">`.json`</bdi> מהמכשיר, בדקו את התצוגה המקדימה ובחרו **הורדת XLSX**. הממיר יוצר גיליון עבודה אחד עם שורת כותרת. כל אובייקט הופך לשורה, וכל שדה שמופיע במערך מקבל עמודה. כך אפשר לסדר רשומות API, רשימות מוצרים ונתונים שיוצאו ממערכות אחרות. אם הרשומות בתגובת ה-API נמצאות בתוך שדה כמו <bdi dir="ltr">`data`</bdi>, הדביקו את המערך שבתוך השדה.

## הרחבת שדות JSON מקוננים לעמודות

האפשרות **הרחבת שדות מקוננים** מופעלת כברירת מחדל. משתי הרשומות שלהלן מתקבלות העמודות <bdi dir="ltr">`name`</bdi>, <bdi dir="ltr">`contact.city`</bdi> ו-<bdi dir="ltr">`tags`</bdi>.

<div dir="ltr">

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

</div>

כאשר ההרחבה כבויה, <bdi dir="ltr">`contact`</bdi> נשמר בעמודה אחת כטקסט JSON כגון <bdi dir="ltr">`{"city":"Oslo"}`</bdi>. בשני המצבים כל מערך נשאר בתא אחד, כך ש-<bdi dir="ltr">`tags`</bdi> לא יוצר שורות נוספות. שדות חסרים ושדות שערכם <bdi dir="ltr">`null`</bdi> מופיעים כתאים ריקים.

## כיצד Excel שומר ערכי JSON

בדרך כלל מספרים וערכים בוליאניים נשמרים כמספרים וכערכים לוגיים של Excel. מספרים שחורגים מהדיוק או מהטווח של Excel נשמרים כטקסט, כדי לשמור על כל הספרות. מחרוזות JSON נשמרות כטקסט, וכך מזהים כגון <bdi dir="ltr">`"00123"`</bdi>, תאריכים שנכתבו כמחרוזות וטקסט שמתחיל ב-<bdi dir="ltr">`=`</bdi> שומרים על התווים המקוריים שלהם.

## תצוגה מקדימה והורדה בדפדפן

התצוגה המקדימה מציגה את תחילת הגיליון. קובץ ה-XLSX כולל את כל הרשומות והעמודות. ההמרה מתבצעת בדפדפן וה-JSON נשאר במכשיר שלכם. לייצוא כטקסט פשוט, השתמשו ב[ממיר JSON ל-CSV](../json-to-csv-converter/).
