## 将 JSON 转换为 Excel 表格

粘贴 JSON 数组或打开本地 `.json` 文件，确认预览后点击 **下载 XLSX**。导出的工作簿包含一张带表头的工作表。数组里的每个对象对应一行，所有对象中出现过的字段都会生成对应的列。你可以用它整理 API 响应、商品清单和系统导出的记录。如果 API 把记录放在 `data` 等字段里，复制该字段里的数组即可。

## 将嵌套 JSON 字段展开为多列

**展开嵌套字段** 默认开启。以下两条记录会生成 `name`、`contact.city` 和 `tags` 三列。

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

关闭展开后，`contact` 会以 `{"city":"Oslo"}` 这样的 JSON 文本保存在一列中。无论是否展开，数组都保存在一个单元格内，因此 `tags` 不会增加行数。缺失的字段和 `null` 值都会显示为空白单元格。

## Excel 如何保存 JSON 中的值

数字和布尔值通常会保留为 Excel 数值和逻辑值。超出 Excel 精度或表示范围的数字按文本保存，以保留原有数字。JSON 字符串会保留为文本，因此 `"00123"` 这类编号、以字符串表示的日期、以 `=` 开头的文本都能保留原有字符。

## 在浏览器中预览和下载

预览只显示工作表开头的一部分，下载的 XLSX 包含全部记录和列。转换在浏览器中完成，JSON 数据留在你的设备上。如果需要纯文本表格，可使用 [JSON 转 CSV](../json-to-csv-converter/)。
