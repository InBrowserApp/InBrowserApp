## JSON を Excel の表に変換

JSON 配列を貼り付けるか、端末の `.json` ファイルを開き、表のプレビューを確認して **XLSX をダウンロード** を選択します。見出し行を含むワークシートが 1 枚作成されます。各オブジェクトは 1 行になり、配列内のいずれかのオブジェクトにあるフィールドが列になります。API のレコード、商品一覧、エクスポートしたデータに便利です。API の応答でレコードが `data` などのフィールドに入っている場合は、そのフィールド内の配列を貼り付けてください。

## ネストされた JSON フィールドを列に展開

**ネストされたフィールドを展開** は初期状態でオンです。たとえば、次の 2 件のレコードからは `name`、`contact.city`、`tags` の列が作られます。

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

展開をオフにすると、`contact` は `{"city":"Oslo"}` のような JSON テキストとして 1 つの列に保持されます。配列はどちらの場合も 1 つのセルに保持されるため、`tags` によって行が増えることはありません。存在しないフィールドや `null` のフィールドは空白セルになります。

## JSON の値を Excel に保持する方法

数値と真偽値は通常、Excel の数値と論理値になります。Excel の精度や範囲を超える数値は、桁を保持するためにテキストとして保存されます。JSON の文字列はテキストのままなので、`"00123"` のような ID、文字列として記載された日付、`=` で始まるテキストも元の文字が保持されます。

## 端末内でプレビューしてダウンロード

プレビューにはシートの先頭部分が表示されます。ダウンロードした XLSX にはすべてのレコードと列が含まれます。変換はブラウザー内で実行され、JSON は端末内に留まります。プレーンテキストで出力するには、[JSON CSV 変換](../json-to-csv-converter/)を使ってください。
