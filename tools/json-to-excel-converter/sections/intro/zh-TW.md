## 將 JSON 轉換成 Excel 試算表

貼上 JSON 陣列或開啟本機的 `.json` 檔案，確認試算表預覽後選擇**下載 XLSX**。轉換器會建立一張含標題列的工作表。每個物件會成為一列，陣列中任何物件出現的欄位都會成為欄。這適用於 API 記錄、產品清單及匯出資料。如果 API 回應將記錄包在 `data` 等欄位中，請貼上該欄位內的陣列。

## 將巢狀 JSON 欄位展開成欄

**展開巢狀欄位**預設為開啟。例如，下列兩筆記錄會產生 `name`、`contact.city` 和 `tags` 等欄。

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

關閉展開時，`contact` 會以 `{"city":"Oslo"}` 等 JSON 文字保留在單一欄中。兩種模式下陣列都保留在單一儲存格中，因此 `tags` 不會產生額外的列。缺少的欄位或值為 `null` 的欄位會顯示為空白儲存格。

## Excel 如何保留 JSON 的值

數字和布林值通常會轉成 Excel 數值和邏輯值。超出 Excel 精度或範圍的數字會保留為文字，以保留其數字位數。JSON 字串會維持文字格式，因此 `"00123"` 等 ID、以字串表示的日期和以 `=` 開頭的文字都會保留原有字元。

## 在本機預覽與下載

預覽會顯示工作表的前段；下載的 XLSX 包含所有記錄和欄。轉換在瀏覽器中執行，JSON 會留在您的裝置上。若要匯出純文字，請使用 [JSON 轉 CSV 轉換器](../json-to-csv-converter/)。
