## JSON을 Excel 스프레드시트로 변환

JSON 배열을 붙여 넣거나 기기의 `.json` 파일을 열고, 스프레드시트 미리보기를 확인한 다음 **XLSX 다운로드**를 선택하세요. 머리글 행이 있는 워크시트 하나가 만들어집니다. 각 객체는 한 행이 되고 배열 어디에든 있는 필드는 열이 됩니다. API 레코드, 제품 목록, 내보낸 데이터에 유용합니다. API 응답에서 레코드가 `data` 같은 필드 안에 들어 있다면 해당 필드의 배열을 붙여 넣으세요.

## 중첩 JSON 필드를 열로 펼치기

**중첩 필드 펼치기**는 기본으로 켜져 있습니다. 예를 들어 아래 두 레코드는 `name`, `contact.city`, `tags` 열을 만듭니다.

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

펼치기를 끄면 `contact`는 `{"city":"Oslo"}` 같은 JSON 텍스트로 한 열에 유지됩니다. 배열은 어느 모드에서나 한 셀에 유지되므로 `tags`가 추가 행을 만들지 않습니다. 누락된 필드나 `null`인 필드는 빈 셀로 표시됩니다.

## JSON 값이 Excel에 저장되는 방식

숫자와 불리언은 보통 Excel의 숫자와 논리값이 됩니다. Excel의 정밀도나 범위를 벗어난 숫자는 자릿수를 보존하기 위해 텍스트로 저장됩니다. JSON 문자열은 텍스트로 유지되므로 `"00123"` 같은 ID, 문자열로 작성된 날짜, `=`로 시작하는 텍스트의 원래 문자가 보존됩니다.

## 기기에서 미리 보고 다운로드

미리보기에는 시트의 앞부분이 표시됩니다. 다운로드한 XLSX에는 모든 레코드와 열이 포함됩니다. 변환은 브라우저에서 실행되며 JSON은 기기에 남습니다. 일반 텍스트로 내보내려면 [JSON CSV 변환기](../json-to-csv-converter/)를 사용하세요.
