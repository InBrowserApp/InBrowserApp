## Как преобразовать JSON в таблицу Excel

Вставьте массив JSON или откройте локальный файл `.json`, проверьте таблицу в предпросмотре и нажмите **Скачать XLSX**. Конвертер создаёт один лист со строкой заголовков. Каждый объект становится строкой, а все поля, встречающиеся в массиве, становятся столбцами. Так удобно обрабатывать записи API, списки товаров и выгрузки данных. Если в ответе API записи находятся внутри поля, например `data`, вставьте массив из этого поля.

## Разворачивание вложенных полей JSON в столбцы

Параметр **Развернуть вложенные поля** включён по умолчанию. Из двух записей ниже получатся столбцы `name`, `contact.city` и `tags`.

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

Если выключить параметр, `contact` останется в одном столбце в виде текста JSON, например `{"city":"Oslo"}`. При любой настройке каждый массив остаётся в одной ячейке, поэтому `tags` не создаёт дополнительных строк. Отсутствующие поля и поля со значением `null` отображаются как пустые ячейки.

## Как Excel сохраняет значения JSON

Числа и логические значения обычно сохраняются в Excel с соответствующим типом данных. Если число выходит за пределы точности или диапазона Excel, оно сохраняется как текст, чтобы не потерять цифры. Строки JSON остаются текстом, поэтому идентификаторы вроде `"00123"`, даты, записанные строками, и текст, начинающийся с `=`, сохраняют исходные символы.

## Предпросмотр и скачивание в браузере

В предпросмотре видна начальная часть листа. В скачанном файле XLSX будут все записи и столбцы. Преобразование выполняется в браузере, и данные JSON остаются на вашем устройстве. Для экспорта в текстовый формат воспользуйтесь [конвертером JSON в CSV](../json-to-csv-converter/).
