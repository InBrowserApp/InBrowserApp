## JSON को Excel स्प्रेडशीट में बदलें

JSON ऐरे पेस्ट करें या अपने डिवाइस से `.json` फ़ाइल खोलें। स्प्रेडशीट का पूर्वावलोकन देखने के बाद **XLSX डाउनलोड करें** चुनें। कन्वर्टर एक वर्कशीट बनाता है, जिसकी पहली पंक्ति में कॉलम के नाम होते हैं। हर ऑब्जेक्ट एक पंक्ति बनता है और ऐरे में जहाँ भी कोई फ़ील्ड मिलता है, उसका एक कॉलम बनता है। यह API रिकॉर्ड, उत्पादों की सूची और एक्सपोर्ट किए गए डेटा के लिए काम आता है। अगर API के जवाब में रिकॉर्ड `data` जैसे फ़ील्ड के अंदर हैं, तो उसी फ़ील्ड के अंदर वाला ऐरे पेस्ट करें।

## नेस्टेड JSON फ़ील्ड को अलग कॉलम में बाँटें

**नेस्टेड फ़ील्ड अलग करें** विकल्प पहले से चालू है। नीचे दिए गए दो रिकॉर्ड से `name`, `contact.city` और `tags` कॉलम बनते हैं।

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

विकल्प बंद करने पर `contact` एक ही कॉलम में JSON टेक्स्ट के तौर पर रहता है, जैसे `{"city":"Oslo"}`। दोनों सेटिंग में ऐरे एक ही सेल में रहते हैं, इसलिए `tags` से नई पंक्तियाँ नहीं बनतीं। जो फ़ील्ड रिकॉर्ड में मौजूद नहीं हैं या जिनका मान `null` है, उनके सेल खाली दिखते हैं।

## Excel में JSON के मान कैसे सहेजे जाते हैं

संख्याएँ और बूलियन मान आम तौर पर Excel में संख्या और तार्किक मान बनते हैं। Excel की सटीकता या मानों की सीमा से बाहर की संख्याएँ टेक्स्ट के तौर पर सहेजी जाती हैं, ताकि उनके अंक सुरक्षित रहें। JSON स्ट्रिंग टेक्स्ट ही रहती हैं। इसलिए `"00123"` जैसी आईडी, स्ट्रिंग के रूप में लिखी तारीखें और `=` से शुरू होने वाला टेक्स्ट अपने मूल रूप में रहता है।

## ब्राउज़र में पूर्वावलोकन देखें और डाउनलोड करें

पूर्वावलोकन में वर्कशीट का शुरुआती हिस्सा दिखता है। डाउनलोड की गई XLSX फ़ाइल में सभी रिकॉर्ड और कॉलम शामिल होते हैं। कन्वर्ज़न ब्राउज़र में होता है और आपका JSON आपके डिवाइस पर ही रहता है। सामान्य टेक्स्ट में एक्सपोर्ट करने के लिए [JSON → CSV परिवर्तक](../json-to-csv-converter/) का इस्तेमाल करें।
