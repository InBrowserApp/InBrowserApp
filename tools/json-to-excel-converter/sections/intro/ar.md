## تحويل JSON إلى جدول بيانات Excel

الصق مصفوفة JSON أو افتح ملف <bdi dir="ltr">`.json`</bdi> محليًا، وراجع معاينة الجدول، ثم اختر **تنزيل XLSX**. ينشئ المحوّل ورقة عمل واحدة بصف عناوين. يتحوّل كل كائن إلى صف، ويحصل كل حقل يظهر في المصفوفة على عمود. يفيد ذلك في تنظيم سجلات API وقوائم المنتجات والبيانات المصدّرة. إذا كانت سجلات استجابة API داخل حقل مثل <bdi dir="ltr">`data`</bdi>، فالصق المصفوفة الموجودة داخل ذلك الحقل.

## توسيع حقول JSON المتداخلة إلى أعمدة

خيار **توسيع الحقول المتداخلة** مفعّل افتراضيًا. ينتج عن السجلين أدناه ثلاثة أعمدة هي <bdi dir="ltr">`name`</bdi> و<bdi dir="ltr">`contact.city`</bdi> و<bdi dir="ltr">`tags`</bdi>.

<div dir="ltr">

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

</div>

عند إيقاف التوسيع، يبقى <bdi dir="ltr">`contact`</bdi> في عمود واحد على هيئة نص JSON مثل <bdi dir="ltr">`{"city":"Oslo"}`</bdi>. تبقى كل مصفوفة في خلية واحدة في الحالتين، لذلك لا ينشئ <bdi dir="ltr">`tags`</bdi> صفوفًا إضافية. تظهر الحقول المفقودة والحقول التي قيمتها <bdi dir="ltr">`null`</bdi> كخلايا فارغة.

## كيف يحفظ Excel قيم JSON

يحفظ Excel الأرقام والقيم المنطقية بأنواعها في المعتاد. تُحفظ الأرقام التي تتجاوز دقة Excel أو نطاقه كنص للحفاظ على جميع أرقامها. وتبقى سلاسل JSON نصوصًا، فتحتفظ المعرّفات مثل <bdi dir="ltr">`"00123"`</bdi>، والتواريخ المكتوبة كنص، والنصوص التي تبدأ بعلامة <bdi dir="ltr">`=`</bdi> بأحرفها الأصلية.

## المعاينة والتنزيل داخل المتصفح

تعرض المعاينة الجزء الأول من ورقة العمل، ويشمل ملف XLSX جميع السجلات والأعمدة. يجري التحويل في متصفحك وتبقى بيانات JSON على جهازك. للتصدير كنص عادي، استخدم [محوّل JSON إلى CSV](../json-to-csv-converter/).
