## แปลง JSON เป็นตาราง Excel

วางอาร์เรย์ JSON หรือเปิดไฟล์ `.json` จากเครื่อง ตรวจสอบตัวอย่างตาราง แล้วเลือก **ดาวน์โหลด XLSX** เครื่องมือจะสร้างเวิร์กชีตหนึ่งแผ่นพร้อมแถวหัวตาราง ออบเจ็กต์แต่ละรายการจะกลายเป็นหนึ่งแถว และทุกฟิลด์ที่พบในอาร์เรย์จะกลายเป็นคอลัมน์ เหมาะกับข้อมูลจาก API รายการสินค้า และข้อมูลที่ส่งออกจากระบบอื่น หากผลตอบกลับของ API เก็บรายการไว้ในฟิลด์ เช่น `data` ให้วางอาร์เรย์ภายในฟิลด์นั้น

## แยกฟิลด์ JSON ที่ซ้อนกันเป็นคอลัมน์

ตัวเลือก **แยกฟิลด์ที่ซ้อนกัน** เปิดไว้โดยค่าเริ่มต้น สองรายการในตัวอย่างนี้จะสร้างคอลัมน์ `name`, `contact.city` และ `tags`

```json
[
  {
    "name": "Maya",
    "contact": { "city": "Oslo" },
    "tags": ["retail", "online"]
  },
  { "name": "Leo", "contact": { "city": "Lisbon" } }
]
```

เมื่อปิดตัวเลือกนี้ `contact` จะอยู่ในคอลัมน์เดียวในรูปข้อความ JSON เช่น `{"city":"Oslo"}` อาร์เรย์จะอยู่ในเซลล์เดียวทั้งสองแบบ ดังนั้น `tags` จึงไม่ทำให้จำนวนแถวเพิ่มขึ้น ฟิลด์ที่ไม่มีในรายการหรือมีค่าเป็น `null` จะแสดงเป็นเซลล์ว่าง

## Excel เก็บค่าใดจาก JSON

โดยปกติ ตัวเลขและค่าบูลีนจะกลายเป็นตัวเลขและค่าตรรกะของ Excel ตัวเลขที่เกินความแม่นยำหรือช่วงค่าที่ Excel รองรับจะเก็บเป็นข้อความเพื่อรักษาตัวเลขทุกหลัก สตริง JSON จะยังเป็นข้อความ รหัสอย่าง `"00123"` วันที่ที่เขียนเป็นสตริง และข้อความที่ขึ้นต้นด้วย `=` จึงคงอักขระเดิมไว้ครบ
