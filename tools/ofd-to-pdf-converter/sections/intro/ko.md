## OFD 페이지를 PDF로 변환하기

로컬 OFD 파일을 열거나 끌어다 놓고 변환이 완료되면 PDF 미리보기를 확인한 뒤 결과를 다운로드하세요. 여러 문서가 포함된 패키지에서는 모든 문서를 원래 순서대로 포함하고 각 문서의 페이지도 원래 순서를 유지합니다. 페이지 크기와 세로 또는 가로 방향이 유지됩니다. 페이지 탐색, 맞춤, 확대·축소, 집중 미리보기 모드로 변환된 페이지를 확인하세요.

## 표시 결과와 호환성

PDF는 흰색 배경에 150 DPI로 렌더링된 이미지 페이지로 구성됩니다. 텍스트는 선택하거나 검색할 수 없으며 OCR은 추가되지 않습니다. 링크, 대화형 필드, 원래 벡터 객체, 문서에 포함된 동작은 유지되지 않습니다. 누락되었거나 사용할 수 없는 글꼴은 대체될 수 있습니다. 이 경우 다운로드 전에 문자, 금액, 정렬을 확인하라는 안내가 표시됩니다.

이 변환기는 디지털 서명이나 내장된 인장 데이터를 검증하거나 보존하지 않습니다. 이러한 데이터가 포함된 파일은 인장이 빠진 문서로 내보내는 대신 변환을 거부합니다. 일반 이미지나 도형으로 된 도장은 해당 그래픽이 지원되면 포함할 수 있지만, 보이는 모습만으로 진위가 입증되지는 않습니다. 페이지, 이미지, 템플릿이 누락되었거나 지원하지 않는 것으로 알려진 그래픽이 있으면 변환이 중단되며 불완전한 PDF는 다운로드할 수 없습니다. 복잡한 OFD 기능에는 전용 OFD 애플리케이션이 필요할 수 있습니다.

## 로컬 처리

파일은 이 브라우저 안에만 유지됩니다. 변환기는 원격 문서 리소스를 가져오거나 문서에 포함된 동작을 실행하지 않습니다. 파일을 바꾸거나 닫으면 이전 변환이 취소되고 다운로드용 결과가 제거됩니다. 취소하면 사용 중인 렌더링 리소스가 해제됩니다. 고정된 파일 크기나 페이지 수 제한은 없지만, 사용 가능한 브라우저 메모리와 캔버스 할당 한도는 적용됩니다.

OFD 파일을 원래 형식으로 확인하려면 [OFD 뷰어](../ofd-viewer/)를 여세요.
