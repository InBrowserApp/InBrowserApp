## Konversikan halaman OFD ke PDF

Buka atau letakkan file OFD lokal, tunggu konversi selesai, periksa pratinjau PDF, lalu unduh hasilnya. Setiap dokumen dalam paket yang berisi beberapa dokumen disertakan sesuai urutan aslinya, dengan halaman setiap dokumen juga mengikuti urutan aslinya. Ukuran halaman serta orientasi potret atau lanskap dipertahankan. Gunakan navigasi halaman, penyesuaian tampilan, pembesaran, dan mode fokus untuk memeriksa halaman hasil konversi.

## Tampilan dan kompatibilitas

PDF berisi halaman gambar yang dirender pada 150 DPI dengan latar belakang putih. Teks tidak dapat dipilih atau dicari, dan OCR tidak ditambahkan. Tautan, bidang interaktif, objek vektor asli, dan tindakan dokumen tidak dipertahankan. Font yang hilang atau tidak dapat digunakan mungkin diganti; pemberitahuan yang terlihat meminta Anda memeriksa karakter, jumlah nominal, dan perataan sebelum mengunduh.

Konverter ini tidak memverifikasi atau mempertahankan tanda tangan digital maupun data cap yang disematkan. File yang berisi fitur tersebut ditolak agar dokumen tidak diekspor tanpa cap. Gambar atau ilustrasi cap biasa dapat disertakan jika grafiknya didukung; tampilannya tidak membuktikan keaslian. Halaman, gambar, atau templat yang hilang serta grafik yang diketahui tidak didukung menghentikan konversi, dan PDF yang tidak lengkap tidak tersedia untuk diunduh. Fitur OFD yang kompleks mungkin memerlukan aplikasi OFD khusus.

## Pemrosesan lokal

File tetap di browser ini. Konverter tidak mengambil sumber daya dokumen dari server jarak jauh atau menjalankan tindakan dokumen. Mengganti atau menutup file membatalkan konversi sebelumnya dan menghapus hasil yang disiapkan untuk diunduh. Membatalkan konversi membebaskan sumber daya perenderan yang aktif. Tidak ada batas tetap untuk ukuran file atau jumlah halaman; memori browser yang tersedia dan batas alokasi kanvas tetap berlaku.

Untuk memeriksa file OFD dalam format aslinya, buka [Penampil OFD](../ofd-viewer/).
