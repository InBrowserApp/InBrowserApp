## 產生用於測試的郵遞區號

選擇國家或地區、輸入數量，然後選取 **產生**。你可以複製整批結果，或下載每行一個郵遞區號的 UTF-8 文字檔。使用結果填寫測試表單、建立範例資料，或檢查結帳和註冊表單如何顯示當地郵遞區號。

## 比較郵遞區號格式

郵遞區號可能包含字母、空格、連字號或前導零。美國 ZIP 郵遞區號的範例是 `02108`，ZIP+4 則加上連字號和四位數，例如 `02108-1234`。英國郵遞區號的範例是 `SW1 2AB`，加拿大為 `K1A 0B1`，日本為 `100-0001`，巴西 CEP 為 `01001-000`。選擇的國家或地區決定產生的格式，與頁面語言無關。

將結果匯入試算表或資料庫時，請將郵遞區號儲存為文字。若將 `02108` 當作數字匯入，前導零會被移除，導致值改變。

## 可以用產生的區號寄件嗎？

Faker.js 依所選格式產生範例區號。區號可能已分配給真實投遞區域，也可能沒有。寄件時，請向相關郵政服務查詢實際地址對應的區號。
