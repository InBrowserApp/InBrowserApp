## יצירת מיקודים לבדיקה

בחרו מדינה או אזור, הזינו את הכמות ובחרו **יצירה**. אפשר להעתיק את הרשימה או להוריד קובץ טקסט בקידוד UTF-8 ובו מיקוד אחד בכל שורה. השתמשו בתוצאות כדי למלא טופסי בדיקה, להזין נתונים לדוגמה או לבדוק איך מוצגים מיקודים מקומיים בטופסי תשלום והרשמה.

## השוואת פורמטים של מיקודים

מיקודים יכולים לכלול אותיות, רווחים, מקפים או אפסים בתחילת הקוד. קוד ZIP בארצות הברית יכול להיראות כמו `02108`, ופורמט ZIP+4 מוסיף מקף וארבע ספרות, למשל `02108-1234`. מיקוד בריטי יכול להיראות כמו `SW1 2AB`, מיקוד קנדי כמו `K1A 0B1`, מיקוד יפני כמו `100-0001` ומיקוד CEP ברזילאי כמו `01001-000`. המדינה או האזור שבחרתם קובעים את פורמט המיקוד ללא קשר לשפת הדף.

כשמייבאים את התוצאות לגיליון אלקטרוני או למסד נתונים, כדאי לשמור את המיקודים כטקסט. אם מייבאים את `02108` כמספר, האפס בתחילת הקוד נעלם והערך משתנה.

## האם אפשר להשתמש בתוצאות למשלוח דואר?

הספרייה Faker.js יוצרת מיקודים לדוגמה בפורמט שנבחר. חלק מהמיקודים עשויים להתאים לאזורי חלוקה אמיתיים. למשלוח דואר, בדקו את המיקוד של הכתובת בפועל באתר של שירות הדואר המתאים.
