## Postleitzahlen für Tests generieren

Wähle ein Land oder eine Region, gib die Anzahl ein und wähle **Generieren**. Du kannst die Liste kopieren oder als UTF-8-Textdatei mit einer Postleitzahl pro Zeile herunterladen. Verwende die Ergebnisse, um Testformulare auszufüllen, Beispieldaten anzulegen oder die Anzeige lokaler Postleitzahlen in Bezahl- und Registrierungsformularen zu prüfen.

## Postleitzahlenformate vergleichen

Postleitzahlen können Buchstaben, Leerzeichen, Bindestriche oder führende Nullen enthalten. Ein US-ZIP-Code kann `02108` lauten; ZIP+4 ergänzt einen Bindestrich und vier Ziffern, etwa `02108-1234`. Eine britische Postleitzahl kann `SW1 2AB` lauten, eine kanadische `K1A 0B1`, eine japanische `100-0001` und eine brasilianische CEP `01001-000`. Das ausgewählte Land oder die Region bestimmt das generierte Format unabhängig von der Seitensprache.

Speichere Postleitzahlen beim Import in eine Tabelle oder Datenbank als Text. Wird `02108` als Zahl importiert, fällt die führende Null weg und der Wert ändert sich.

## Kann ich die Ergebnisse für den Postversand verwenden?

Faker.js erstellt Beispielcodes im ausgewählten Format. Ein Code kann einem tatsächlichen Zustellgebiet zugeordnet sein, muss es aber nicht. Schlage für den Postversand die Postleitzahl der tatsächlichen Adresse beim zuständigen Postdienst nach.
