## Generera postnummer för testning

Välj land eller region, ange hur många postnummer du vill ha och välj **Generera**. Kopiera listan eller ladda ner en UTF-8-kodad textfil med ett postnummer per rad. Använd resultaten för att fylla i testformulär, lägga in exempeldata eller kontrollera hur formulär för kassa och registrering visar lokala postnummer.

## Jämför olika postnummerformat

Postnummer kan innehålla bokstäver, mellanslag, bindestreck eller inledande nollor. En amerikansk ZIP-kod kan se ut som `02108`. ZIP+4 lägger till ett bindestreck och fyra siffror, som i `02108-1234`. Ett brittiskt postnummer kan se ut som `SW1 2AB`, ett kanadensiskt som `K1A 0B1`, ett japanskt som `100-0001` och ett brasilianskt CEP som `01001-000`. Landet eller regionen du väljer styr formatet oberoende av sidans språk.

Spara postnumren som text när du importerar resultaten till ett kalkylblad eller en databas. Om du importerar `02108` som ett tal försvinner den inledande nollan och värdet ändras.

## Kan jag använda resultaten för att skicka post?

Faker.js skapar exempelkoder i det valda formatet. En genererad kod kan råka stämma överens med ett verkligt utdelningsområde. När du ska skicka post kan du slå upp postnumret för den faktiska adressen hos den aktuella posttjänsten.
