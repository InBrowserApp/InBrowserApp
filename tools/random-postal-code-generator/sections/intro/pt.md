## Gerar códigos postais para testes

Escolha um país ou região, introduza a quantidade e selecione **Gerar**. Pode copiar o lote ou descarregar um ficheiro de texto UTF-8 com um código postal por linha. Use os resultados para preencher formulários de teste, criar dados de exemplo ou verificar como os formulários de pagamento e registo apresentam códigos postais locais.

## Comparar formatos de códigos postais

Os códigos postais podem incluir letras, espaços, hífenes ou zeros iniciais. Um código ZIP dos EUA pode ser `02108`, e o ZIP+4 acrescenta um hífen e quatro dígitos, como em `02108-1234`. Um código postal do Reino Unido pode ser `SW1 2AB`, um do Canadá `K1A 0B1`, um do Japão `100-0001` e um CEP brasileiro `01001-000`. O país ou região selecionado determina o formato gerado, independentemente do idioma da página.

Ao importar os resultados para uma folha de cálculo ou base de dados, guarde os códigos postais como texto. Importar `02108` como número remove o zero inicial e altera o valor.

## Posso usar os resultados para enviar correio?

O Faker.js cria códigos de exemplo no formato selecionado. Um código pode ou não estar atribuído a uma área de distribuição real. Para enviar correio, consulte o código da morada real junto do serviço postal relevante.
