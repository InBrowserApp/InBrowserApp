## สร้างรหัสไปรษณีย์สำหรับการทดสอบ

เลือกประเทศหรือภูมิภาค ระบุจำนวน แล้วเลือก **สร้าง** คุณสามารถคัดลอกทั้งรายการหรือดาวน์โหลดเป็นไฟล์ข้อความ UTF-8 ที่มีรหัสไปรษณีย์หนึ่งรหัสต่อบรรทัด นำผลลัพธ์ไปใช้กรอกแบบฟอร์มทดสอบ เตรียมข้อมูลตัวอย่าง หรือตรวจสอบว่าแบบฟอร์มชำระเงินและสมัครสมาชิกแสดงรหัสไปรษณีย์ของแต่ละประเทศอย่างไร

## เปรียบเทียบรูปแบบรหัสไปรษณีย์

รหัสไปรษณีย์อาจมีตัวอักษร ช่องว่าง ขีดกลาง หรือเลขศูนย์นำหน้า รหัส ZIP ของสหรัฐอเมริกาอาจมีรูปแบบอย่าง `02108` ส่วน ZIP+4 จะเพิ่มขีดกลางและตัวเลขอีกสี่หลัก เช่น `02108-1234` ตัวอย่างรหัสไปรษณีย์ของสหราชอาณาจักรคือ `SW1 2AB` ของแคนาดาคือ `K1A 0B1` ของญี่ปุ่นคือ `100-0001` และรหัส CEP ของบราซิลอาจเป็น `01001-000` รูปแบบรหัสขึ้นอยู่กับประเทศหรือภูมิภาคที่เลือก โดยไม่ขึ้นกับภาษาของหน้าเว็บ

เมื่อนำผลลัพธ์เข้าสเปรดชีตหรือฐานข้อมูล ให้เก็บรหัสไปรษณีย์เป็นข้อความ หากนำเข้า `02108` เป็นตัวเลข เลขศูนย์นำหน้าจะหายไปและค่าจะเปลี่ยนไป

## ใช้ผลลัพธ์ส่งไปรษณีย์ได้ไหม

Faker.js สร้างรหัสตัวอย่างตามรูปแบบที่เลือก รหัสที่ได้อาจตรงกับรหัสของพื้นที่จัดส่งจริงหรือไม่ก็ได้ เมื่อต้องการส่งไปรษณีย์ ให้ค้นหารหัสของที่อยู่จริงกับผู้ให้บริการไปรษณีย์ที่เกี่ยวข้อง
