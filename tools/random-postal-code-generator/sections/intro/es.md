## Generar códigos postales para pruebas

Elige un país o región, introduce la cantidad y selecciona **Generar**. Puedes copiar el lote o descargar un archivo de texto UTF-8 con un código postal por línea. Usa los resultados para rellenar formularios de prueba, crear datos de ejemplo o comprobar cómo muestran los códigos postales locales los formularios de pago y registro.

## Comparar formatos de códigos postales

Los códigos postales pueden incluir letras, espacios, guiones o ceros iniciales. Un código ZIP de EE. UU. puede ser `02108`, y ZIP+4 añade un guion y cuatro dígitos, como en `02108-1234`. Un código postal del Reino Unido puede ser `SW1 2AB`; uno de Canadá, `K1A 0B1`; uno de Japón, `100-0001`; y un CEP brasileño, `01001-000`. El país o región elegido determina el formato generado independientemente del idioma de la página.

Al importar los resultados a una hoja de cálculo o base de datos, guarda los códigos postales como texto. Si importas `02108` como número, se elimina el cero inicial y cambia el valor.

## ¿Puedo usar los resultados para enviar correo?

Faker.js crea códigos de ejemplo con el formato seleccionado. Un código puede estar asignado o no a una zona real de reparto. Para enviar correo, consulta el código de la dirección real con el servicio postal correspondiente.
