## Buka file STEP dan STP secara online

Pilih **Buka file STEP** atau seret file `.step` atau `.stp` ke penampil untuk memeriksa komponen atau rakitan CAD dalam 3D. Pilih **Coba contoh** untuk melihat braket pemasangan sebelum membuka file Anda sendiri. STEP (ISO 10303) adalah format pertukaran data CAD. Kedua ekstensi tersebut mengacu pada format yang sama. Model diproses langsung di perangkat Anda tanpa perlu diunggah.

Seret untuk memutar model, lalu gulir atau gunakan gerakan mencubit dan merentangkan dua jari untuk memperbesar atau memperkecil. Untuk menggeser tampilan, seret dengan tombol kanan mouse atau gunakan dua jari. Pilih tampilan isometrik, depan, atas, atau kanan. Gunakan **Tampilkan seluruh model** untuk mengembalikan seluruh model ke area tampilan, atau buka layar penuh agar lebih leluasa.

## Periksa dimensi keseluruhan dan ukur jarak

**Dimensi keseluruhan** menunjukkan ukuran terluar model di sepanjang sumbu X, Y, dan Z. Nilai ini tetap sama saat Anda memutar tampilan. Beralihlah antara milimeter dan inci untuk membandingkan hasil dengan gambar teknik atau spesifikasi. Sebagai contoh, 60 mm setara dengan sekitar 2,36 inci.

Pilih **Ukur**, lalu pilih dua titik pada permukaan model yang terlihat untuk mengetahui jarak lurus antartitik. Gunakan pilihan tampilan atau perbesar model agar titik lebih mudah dipilih. Pengukuran didasarkan pada permukaan model yang ditampilkan sehingga hasilnya berupa perkiraan, terutama pada bagian yang melengkung. Konfirmasikan dimensi yang memengaruhi toleransi atau kecocokan komponen pada model CAD asli.

## Simpan tampilan 3D sebagai PNG

Atur sudut pandang dan tingkat perbesaran sesuai kebutuhan, lalu pilih **Simpan PNG**. File yang diunduh menampilkan model sebagaimana terlihat di penampil, termasuk pengukuran yang sudah selesai beserta nilainya. Gunakan gambar tersebut untuk menunjukkan detail desain dalam tinjauan, penawaran harga, atau catatan perakitan.

- [Penampil DXF](../dxf-viewer/)

Gunakan [Konverter STEP ke STL](../step-to-stl-converter/) untuk menyiapkan STL biner dengan koordinat dalam milimeter bagi aplikasi slicer.

Buka file CAD `.igs` atau `.iges` di [Penampil IGES](../iges-viewer/) untuk memeriksa permukaan, mengukur jarak, dan menyimpan PNG.
