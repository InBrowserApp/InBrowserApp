## Konversikan file WPS Writer ke PDF

Buka atau letakkan dokumen WPS Writer (`.wps`) atau templat (`.wpt`) yang kompatibel di sini. Pratinjau PDF di browser Anda dan unduh setelah siap. File tetap berada di perangkat Anda.

## Tata letak halaman dan kompatibilitas

Isi utama dokumen yang didukung ditata ulang ke halaman A4 dan dirender sebagai gambar dengan resolusi 150 DPI. File terenkripsi, format WPS lama yang berpemilik, file Microsoft Works, dan file dengan jenis konten rumit tertentu tidak didukung.

Untuk membaca file, gunakan [Penampil WPS](../wps-viewer/). Untuk file `.doc` dan `.docx`, gunakan [Konverter Microsoft Word ke PDF](../microsoft-word-to-pdf-converter/).
