## Converti un file WPS Writer in PDF

Apri o trascina un documento WPS Writer compatibile (`.wps`) o un modello (`.wpt`). Visualizza il PDF in anteprima nel browser e scaricalo quando è pronto. Il file resta sul tuo dispositivo.

## Impaginazione e compatibilità

Il corpo del documento viene reimpaginato su pagine A4 e reso come immagini a 150 DPI. La conversione non supporta file crittografati, formati proprietari WPS meno recenti, file Microsoft Works e file con alcuni tipi di contenuti complessi.

Per leggere un file, usa il [Visualizzatore WPS](../wps-viewer/). Per i file `.doc` e `.docx`, usa il [Convertitore da Microsoft Word a PDF](../microsoft-word-to-pdf-converter/).
