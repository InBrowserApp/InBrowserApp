## Modifier un fichier OPML en ligne

OPML (Outline Processor Markup Language) est un format XML qui représente des arborescences. Les lecteurs RSS l’utilisent pour enregistrer les listes d’abonnements avec leurs dossiers. Ouvrez un fichier .opml, collez son XML ou partez d’une arborescence vide. Sélectionnez un dossier ou un flux pour le renommer, modifier son adresse ou le déplacer. Utilisez les réglages de retrait pour modifier la hiérarchie des dossiers.

## Exporter les abonnements RSS et Atom vers un autre lecteur

Exportez la liste de vos abonnements depuis votre lecteur RSS et ouvrez-la ici. Ajustez les noms des dossiers, ajoutez des flux ou réorganisez les éléments. Cliquez sur Télécharger le fichier OPML pour enregistrer la liste modifiée dans un fichier .opml, puis importez ce fichier dans le lecteur de votre choix. Copier le XML vous donne la même arborescence sous forme de texte, à coller dans un éditeur ou à conserver en sauvegarde.

## Ce que l’éditeur OPML conserve

Un document OPML contient une arborescence et les adresses des abonnements. Lorsque vous modifiez les champs courants, l’éditeur préserve la version du fichier, les métadonnées d’en-tête, les niveaux de dossiers et les autres attributs. Il lit et écrit le document dans votre navigateur. Les adresses des flux restent dans le document et votre lecteur RSS pourra les ouvrir après l’importation.
