## Como editar um arquivo OPML online

OPML (Outline Processor Markup Language) é um formato XML para estruturas hierárquicas. Leitores de RSS o usam para salvar listas de assinaturas com suas pastas. Abra um arquivo .opml, cole o XML ou comece com uma estrutura vazia. Selecione uma pasta ou um feed para renomear, atualizar o endereço ou mudar sua posição. Use os controles de recuo para alterar a hierarquia de pastas.

## Como exportar assinaturas RSS e Atom para outro leitor

Exporte a lista de assinaturas do seu leitor de RSS e abra-a aqui. Ajuste os nomes das pastas, adicione feeds ou organize os itens na ordem que quiser. Use Baixar OPML para salvar a lista editada como arquivo .opml e importe esse arquivo no leitor que quiser usar. Copiar XML fornece a mesma estrutura em texto para colar em um editor ou guardar como backup.

## O que o editor de OPML preserva

O OPML armazena uma estrutura e os endereços das assinaturas. Ao editar os campos mais comuns, o editor preserva a versão do arquivo, os metadados do cabeçalho, a estrutura hierárquica e os demais atributos. A leitura e a gravação do documento acontecem no seu navegador. Os endereços dos feeds permanecem no documento e podem ser abertos pelo seu leitor de RSS após a importação.
