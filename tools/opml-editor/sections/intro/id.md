## Cara mengedit file OPML secara online

OPML (Outline Processor Markup Language) adalah format XML untuk kerangka bertingkat. Pembaca RSS menggunakannya untuk menyimpan daftar langganan beserta foldernya. Buka file .opml, tempel XML, atau mulai dengan kerangka kosong. Pilih folder atau feed untuk mengganti nama, memperbarui alamat, atau memindahkannya. Untuk mengubah hierarki folder, jadikan suatu item sebagai subitem atau naikkan satu tingkat.

## Ekspor langganan RSS dan Atom ke pembaca lain

Ekspor daftar langganan dari pembaca RSS, lalu buka filenya di sini. Rapikan nama folder, tambahkan feed, atau atur urutan item sesuai kebutuhan. Pilih Unduh OPML untuk menyimpan daftar hasil edit sebagai file .opml, lalu impor file tersebut ke pembaca pilihan Anda. Pilih Salin XML untuk menyalin kerangka yang sama sebagai teks untuk diedit atau dicadangkan.

## Data yang dipertahankan Editor OPML

OPML menyimpan kerangka dan alamat feed yang dilanggan. Saat Anda mengedit kolom umum, editor mempertahankan versi file, metadata header, struktur bertingkat, dan atribut lainnya. Editor membaca dan menulis dokumen di browser. Alamat feed tetap tersimpan dalam dokumen, dan pembaca RSS dapat membukanya setelah Anda mengimpor file.
