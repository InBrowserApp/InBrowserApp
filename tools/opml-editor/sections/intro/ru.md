## Как редактировать файл OPML онлайн

OPML (Outline Processor Markup Language) — это формат XML для иерархических списков. Программы для чтения RSS используют его, чтобы сохранять списки подписок вместе с папками. Откройте файл .opml, вставьте XML или начните с пустого списка. Выберите папку или ленту, чтобы изменить название, адрес или положение в списке. Чтобы изменить вложенность папок, переместите элемент на уровень глубже или выше.

## Как перенести подписки RSS и Atom в другую программу

Экспортируйте список подписок из программы для чтения RSS и откройте его здесь. Переименуйте папки, добавьте ленты или измените порядок элементов. Нажмите «Скачать OPML», чтобы сохранить изменённый список в файл .opml, а затем импортируйте его в нужную программу. Кнопка «Копировать XML» копирует тот же список в виде текста для редактора или резервной копии.

## Что сохраняет редактор OPML

OPML хранит структуру списка и адреса подписок. При изменении основных полей редактор сохраняет версию файла, метаданные заголовка, вложенность и другие атрибуты. Он читает и записывает документ в вашем браузере. Адреса лент остаются в документе, и после импорта их может открыть ваша программа для чтения RSS.
