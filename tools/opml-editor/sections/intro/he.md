## איך עורכים קובץ OPML באינטרנט

OPML ‏(Outline Processor Markup Language) הוא פורמט XML למתווים היררכיים. קוראי RSS משתמשים בו כדי לשמור רשימות מינויים עם התיקיות שלהן. פתחו קובץ .opml, הדביקו את ה־XML או התחילו במתווה ריק. בחרו תיקייה או ערוץ כדי לשנות את השם, לעדכן את הכתובת או להעביר את הפריט למיקום אחר. הגדילו או הקטינו את הכניסה של פריטים כדי לשנות את מבנה התיקיות.

## ייצוא מינויים ל־RSS ול־Atom לקורא אחר

ייצאו את רשימת המינויים מקורא ה־RSS ופתחו אותה כאן. שנו שמות של תיקיות, הוסיפו ערוצים או סדרו את הפריטים כרצונכם. בחרו ״הורדת OPML״ כדי לשמור את הרשימה המעודכנת כקובץ .opml, ואז ייבאו אותו לקורא שבחרתם. ״העתקת XML״ מעתיקה את אותו מתווה כטקסט, לשימוש בעורך או לגיבוי.

## מה נשמר בעריכה של קובץ OPML

קובץ OPML מכיל מתווה וכתובות של מינויים. כשעורכים את השדות הנפוצים, העורך שומר את גרסת הקובץ, את המטא־נתונים בכותרת, את המבנה ההיררכי ואת המאפיינים האחרים. הוא קורא וכותב את המסמך בדפדפן שלכם. כתובות הערוצים נשארות חלק מהמסמך, וקורא ה־RSS יכול לפתוח אותן אחרי הייבוא.
