## OPML ファイルをオンラインで編集

OPML（Outline Processor Markup Language）は、入れ子になったアウトラインを表す XML 形式です。RSS リーダーは購読リストとフォルダーの保存に使用します。.opml ファイルを開くか、XML を貼り付けるか、空のアウトラインから始めます。フォルダーやフィードを選択して、名前やアドレスを変更したり、位置を移動したりできます。インデントとその解除でフォルダーの階層を変更できます。

## RSS と Atom の購読リストを別のリーダー向けにエクスポート

RSS リーダーから購読リストをエクスポートし、ここで開きます。フォルダー名の整理やフィードの追加を行い、項目を好きな順序に並べ替えます。「OPML をダウンロード」で編集したリストを .opml ファイルとして保存し、使いたいリーダーにインポートします。「XML をコピー」では、同じアウトラインをテキストとしてコピーして編集やバックアップに利用できます。

## OPML エディターで保持される情報

OPML にはアウトラインと購読先のアドレスが保存されます。一般的な項目を編集しても、ファイルのバージョン、ヘッダーのメタデータ、入れ子構造、その他の属性は保持されます。文書の読み書きはブラウザー内で行われます。フィードのアドレスは文書に残り、インポート後に RSS リーダーで開くことができます。
