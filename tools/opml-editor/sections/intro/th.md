## วิธีแก้ไขไฟล์ OPML ออนไลน์

OPML (Outline Processor Markup Language) เป็นรูปแบบ XML สำหรับโครงร่างหลายระดับ โปรแกรมอ่าน RSS ใช้บันทึกรายการฟีดที่ติดตามพร้อมโฟลเดอร์ เปิดไฟล์ .opml วาง XML หรือเริ่มจากโครงร่างว่าง แล้วเลือกโฟลเดอร์หรือฟีดเพื่อเปลี่ยนชื่อ แก้ไขที่อยู่ หรือย้ายตำแหน่ง ปรับลำดับชั้นของโฟลเดอร์ด้วยการจัดเป็นรายการย่อยหรือเลื่อนรายการขึ้นหนึ่งระดับ

## ส่งออกรายการฟีด RSS และ Atom ไปยังโปรแกรมอ่านอื่น

ส่งออกรายการฟีดที่ติดตามจากโปรแกรมอ่าน RSS แล้วเปิดไฟล์ที่นี่ คุณสามารถจัดชื่อโฟลเดอร์ให้เป็นระเบียบ เพิ่มฟีด หรือจัดลำดับรายการใหม่ เลือกดาวน์โหลด OPML เพื่อบันทึกรายการที่แก้ไขเป็นไฟล์ .opml แล้วนำไฟล์นั้นเข้าโปรแกรมอ่านที่ต้องการ เลือกคัดลอก XML เพื่อคัดลอกโครงร่างเดียวกันเป็นข้อความสำหรับแก้ไขหรือสำรองข้อมูล

## เครื่องมือแก้ไข OPML เก็บข้อมูลส่วนใดไว้บ้าง

OPML เก็บโครงร่างและที่อยู่ของฟีดที่ติดตาม เมื่อแก้ไขช่องข้อมูลทั่วไป เครื่องมือจะเก็บเวอร์ชันไฟล์ ข้อมูลเมตาในส่วนหัว โครงสร้างหลายระดับ และแอตทริบิวต์อื่น ๆ ไว้ การอ่านและเขียนเอกสารเกิดขึ้นในเบราว์เซอร์ ที่อยู่ฟีดยังคงอยู่ในเอกสาร และโปรแกรมอ่าน RSS จะเปิดที่อยู่เหล่านั้นได้หลังนำเข้า
