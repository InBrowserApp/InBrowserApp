## Edit an OPML file online

OPML (Outline Processor Markup Language) is an XML format for nested outlines. RSS readers use it to save subscription lists with their folders. Open an .opml file, paste the XML, or start with an empty outline. Select a folder or feed to rename it, update its address, or move it to a new position. Use indent and outdent to change the folder hierarchy.

## Export RSS and Atom subscriptions for another reader

Export the subscription list from your RSS reader and open it here. Clean up folder names, add feeds, or move entries into the order you want. Use Download OPML to save the edited list as a .opml file, then import that file into the reader you want to use. Copy XML gives you the same outline as text for an editor or backup.

## What the OPML editor preserves

OPML stores an outline and subscription addresses. The editor preserves the file’s version, header metadata, nested structure, and other attributes when you edit common fields. It reads and writes the document in your browser. Feed addresses stay part of the document and can be opened by your RSS reader after import.
