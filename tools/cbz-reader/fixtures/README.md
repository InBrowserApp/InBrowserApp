# CBZ fixtures

All artwork is original geometric artwork generated by `generate.py` using Pillow and the system DejaVu Sans font. No third-party comic pages or personal documents are included.

- `representative.cbz`: nested natural-order paths, damaged first page, portrait PNG, wide JPEG, WebP, GIF, BMP, AVIF, 4200×6000 PNG, TIFF and SVG failure slots, small RGBA PNG, and ignored metadata/hidden files. Eleven page slots; the first readable image is page 2.
- `avif-compatible.cbz`: AVIF with a `mif1` main brand and `avif` compatible brand.
- `protected.cbz`: AES-encrypted page generated with zip.js and the fixture-only password `fixture-only`.
- `long.cbz`: 1,201 naturally numbered PNG pages for navigation and thumbnail pagination.
- `empty.cbz`: metadata only.
- `unsupported.cbz`: SVG and TIFF entries retained as unreadable pages.
- `disguised-svg.cbz`: SVG markup under a PNG name, including a remote reference; it must never render or fetch that reference.
- `corrupt.cbz`: truncated ZIP header.

Password protection and CRC failures are produced directly in the archive tests with zip.js so those behaviors are verified against real archives.
