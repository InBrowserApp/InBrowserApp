## Как преобразовать MAC-адрес в IPv6-адрес

Введите 48-битный MAC-адрес с двоеточиями, дефисами, точками или без разделителей. Укажите нужный сетевой префикс IPv6 `/64`. Префикс можно записать в сокращённой или полной форме, при этом все биты узла должны быть нулевыми. IPv6-адрес обновляется по мере ввода, и его можно сразу скопировать. Кнопка **Попробовать пример** заполняет оба поля примерами.

## Как модифицированная схема EUI-64 формирует адрес

В подсети `/64` первые 64 бита задаёт сетевой префикс, последние 64 бита задаёт идентификатор интерфейса. Модифицированная схема EUI-64 вставляет `ff:fe` между двумя половинами MAC-адреса и инвертирует бит универсальной или локальной адресации (U/L) в первом байте. Например, из `00:11:22:33:44:55` получается идентификатор интерфейса `211:22ff:fe33:4455`. С префиксом `2001:db8:1:2::/64` получается адрес `2001:db8:1:2:211:22ff:fe33:4455`.

## Распространённые префиксы IPv6

- **Локальный для канала (link-local).** Используйте `fe80::/64` для связи в пределах одного канала. Кнопка **Подставить префикс link-local** заполняет поле префикса, сохраняя введённый MAC-адрес. Чтобы добавить имя интерфейса, например `%eth0`, воспользуйтесь [конвертером локальных адресов канала IPv6](/ru/tools/mac-address-to-ipv6-link-local-address-converter/).
- **Уникальный локальный (ULA).** Кнопка **Подставить пример ULA** вводит `fd12:3456:789a:1::/64`, пример префикса из диапазона `fd00::/8` для внутренних сетей. Чтобы создать уникальный префикс для своей сети, воспользуйтесь [генератором ULA IPv6](/ru/tools/ipv6-ula-generator/).
- **Глобальный одноадресный.** Введите подсеть `/64` из диапазона, выделенного вам интернет-провайдером, облачным провайдером или администратором сети.
- **Для документации.** Префикс `2001:db8:1:2::/64` входит в диапазон `2001:db8::/32`, зарезервированный для документации и примеров.

## Совпадёт ли результат с IPv6-адресом моего устройства?

Конвертер формирует адрес для вашего префикса по модифицированной схеме EUI-64. Устройство может использовать другой идентификатор интерфейса, например стабильный или временный идентификатор, созданный для защиты конфиденциальности. Если у вас уже есть IPv6-адрес с идентификатором интерфейса, полученным из MAC-адреса, восстановить MAC-адрес поможет [конвертер IPv6-адресов в MAC-адреса](/ru/tools/ipv6-address-to-mac-address-converter/).
