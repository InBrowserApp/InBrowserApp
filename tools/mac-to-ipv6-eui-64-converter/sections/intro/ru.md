## Как формируется IPv6-адрес

Модифицированная схема EUI-64 вставляет `ff:fe` между двумя половинами MAC-адреса и инвертирует бит универсальной или локальной адресации (U/L) в первом байте. Например, из `00:11:22:33:44:55` получается идентификатор интерфейса `211:22ff:fe33:4455`. С префиксом `2001:db8:1:2::/64` получается адрес `2001:db8:1:2:211:22ff:fe33:4455`.

Для локального адреса канала введите `fe80::/64`. Чтобы добавить имя интерфейса, воспользуйтесь [конвертером локальных адресов канала](/ru/tools/mac-address-to-ipv6-link-local-address-converter/). Чтобы получить одноадресный адрес для своей сети, укажите назначенный ей префикс /64. В примере используется префикс, выделенный для документации.
