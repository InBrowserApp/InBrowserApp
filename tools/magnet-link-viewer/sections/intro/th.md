ลิงก์ Magnet ใช้ Info Hash เพื่อระบุทอร์เรนต์ของ BitTorrent ลิงก์อาจมีชื่อที่แสดง ที่อยู่แทร็กเกอร์ เว็บซีด หรือแหล่งเมตาดาตาด้วย หากต้องการดูชื่อและขนาดของไฟล์จริง โปรแกรมต้องดึงเมตาดาตาของทอร์เรนต์ก่อน

## วิธีตรวจสอบลิงก์ Magnet

วางลิงก์ที่ขึ้นต้นด้วย `magnet:?` แล้วเลือก “ค้นหาเมตาดาตา” เครื่องมือจะแสดง Info Hash รวมถึงชื่อและที่อยู่แทร็กเกอร์ที่ระบุในลิงก์ เมื่อ WebTorrent ได้รับเมตาดาตาแล้ว คุณจะเห็นชื่อทอร์เรนต์ พาธและขนาดของแต่ละไฟล์ ขนาดรวม และข้อมูลเกี่ยวกับชิ้นข้อมูล คุณกรองรายชื่อไฟล์และคัดลอก Info Hash ได้

## ทำไมบางลิงก์ Magnet จึงค้นหาไม่สำเร็จ

เมื่อทำงานในเบราว์เซอร์ WebTorrent ต้องเชื่อมต่อกับเพียร์ที่รองรับ WebRTC ซึ่งมักค้นหาผ่านแทร็กเกอร์ WebSocket ลิงก์ Magnet บางรายการระบุแหล่งเมตาดาตา HTTPS ที่เบราว์เซอร์อ่านได้ แม้ลิงก์จะเปิดในโปรแกรม BitTorrent บนคอมพิวเตอร์ได้ การค้นหาบนเว็บก็อาจหมดเวลา หากคุณมีไฟล์ `.torrent` ให้เปิดด้วยโปรแกรมดูไฟล์ Torrent เพื่ออ่านเมตาดาตาได้ทันที

## ระหว่างค้นหา เครื่องมือเชื่อมต่อกับอะไรบ้าง

การค้นหาทำงานในเบราว์เซอร์ของคุณ WebTorrent อาจเชื่อมต่อกับแทร็กเกอร์ เพียร์ หรือแหล่งเมตาดาตาของทอร์เรนต์ที่คุณเลือก ปลายทางเหล่านั้นอาจเห็นที่อยู่ IP ของคุณและทอร์เรนต์ที่คุณกำลังค้นหา เครื่องมือขอเฉพาะเมตาดาตาและจะไม่ดาวน์โหลดไฟล์ในรายการ ลิงก์ Magnet ต้องมี Info Hash ของ BitTorrent v1 (`btih`) และอาจมีตัวระบุของ v2 เพิ่มมาด้วยได้
