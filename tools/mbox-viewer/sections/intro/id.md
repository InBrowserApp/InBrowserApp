## Cara membuka dan membaca file MBOX

Satu file MBOX menyimpan sejumlah pesan email dalam satu arsip kotak surat. Seret dan lepas file ke area di atas atau pilih dari perangkat Anda, lalu pilih pesan dari daftar. Untuk menemukan percakapan, cari berdasarkan subjek, pengirim, atau penerima. Anda bisa membaca pesan HTML atau teks biasa, melihat pengirim dan waktu pengiriman, serta mengunduh lampiran dari pesan yang dipilih.

## Menemukan file kotak surat dari Gmail, Thunderbird, atau Apple Mail

Untuk Gmail, ekspor email dengan Google Takeout, lalu ekstrak arsip yang diunduh. Cari file .mbox di folder Takeout/Mail. File kotak surat Thunderbird mungkin tidak memiliki ekstensi. Untuk hasil ekspor Apple Mail, buka folder .mbox dan pilih file bernama mbox. Jika unduhan berformat ZIP atau TGZ, ekstrak dahulu sebelum membuka file kotak surat.

## Baca email di browser tanpa mengunggah file

Browser mengindeks kotak surat di perangkat Anda dan membaca pesan satu per satu saat Anda memilihnya. Email dan lampiran tetap di perangkat Anda. Tampilan HTML memblokir konten eksternal seperti gambar pelacak. Pengindeksan kotak surat yang sangat besar dapat memakan waktu lebih lama, tergantung perangkat dan browser Anda.
