## Come aprire e leggere un file MBOX

Un file MBOX raccoglie più messaggi di posta elettronica in un unico archivio. Trascina il file nell’area qui sopra o selezionalo sul tuo dispositivo, poi scegli un messaggio dall’elenco. Cerca per oggetto, mittente o destinatario per trovare una conversazione. Puoi leggere i messaggi in HTML e in testo semplice, vedere chi li ha inviati e quando e scaricare gli allegati del messaggio selezionato.

## Dove trovare il file MBOX nelle esportazioni di Gmail, Thunderbird o Apple Mail

Per Gmail, esporta la posta con Google Takeout ed estrai l’archivio scaricato. Cerca un file .mbox in Takeout/Mail. In Thunderbird, il file della casella di posta può essere privo di estensione. Se hai esportato una casella da Apple Mail, apri la cartella .mbox e seleziona il file chiamato mbox. Se hai scaricato uno ZIP o un TGZ, estrailo prima di aprire il file della casella di posta.

## Leggi le email nel browser in tutta riservatezza

Il browser indicizza la casella di posta sul tuo dispositivo e legge i singoli messaggi man mano che li selezioni. Email e allegati rimangono sul tuo dispositivo. L’anteprima HTML blocca contenuti esterni come le immagini di tracciamento. L’indicizzazione di caselle di posta molto grandi può richiedere più tempo a seconda del dispositivo e del browser.
