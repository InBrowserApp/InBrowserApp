## SHA-512/224 (FIPS 180-4)란?

SHA-512/224 (FIPS 180-4)는 224비트(28바이트) 다이제스트를 출력하는 SHA-2 암호화 해시 함수로, 일반적으로 56자리 16진수 문자열로 표시됩니다. SHA-512를 기반으로 하되 다른 초깃값을 사용하고 출력을 잘라내므로, SHA-512의 내부 구조를 유지하면서 더 짧은 다이제스트를 제공합니다.

**주요 특징:**

- **결정적**: 같은 입력은 항상 같은 해시를 생성합니다
- **빠른 계산**: 주어진 입력의 해시를 빠르게 계산합니다
- **눈사태 효과**: 입력의 작은 변화가 출력을 크게 바꿉니다
- **비가역적**: 해시를 역으로 계산해 원본 입력을 찾는 것은 계산상 사실상 불가능합니다
- **충돌 저항성**: 같은 해시를 생성하는 서로 다른 두 입력을 찾기가 매우 어렵습니다

**주요 용도:**

- 디지털 서명과 인증서
- 무결성 검사와 체크섬
- HMAC 구성
- 파일 검증과 데이터 파이프라인
- 224비트 해시가 필요한 프로토콜
