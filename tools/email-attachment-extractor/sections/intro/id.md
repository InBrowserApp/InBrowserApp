## Ekstrak lampiran email tersimpan

Buka email EML, EMLX, atau MSG untuk melihat file tersematnya. Unduh satu lampiran atau pilih beberapa file dan buat ZIP. Semuanya tetap di browser Anda; tidak ada unggahan dan tidak ada konten jarak jauh yang dimuat.

## Pilih file yang Anda perlukan

Lampiran biasa, sumber daya dalam pesan, dan email terlampir memiliki label berbeda. Sumber daya dalam pesan awalnya tidak dipilih, tetapi Anda dapat menyertakannya. Lampiran kosong tetap menjadi file kosong yang valid. Nama unduhan disesuaikan untuk menghindari nama yang tidak aman dan benturan nama, sementara nama asli tetap terlihat.

Email RFC 822 terlampir diunduh sebagai file EML. Pesan Outlook terlampir disimpan sebagai file MSG mandiri. Lampiran diunduh sebagai file; isinya tidak dipratinjau atau dijalankan oleh alat ini.

## Email yang didukung dan batasan

Gunakan email lengkap yang tidak terenkripsi dengan lampiran tersemat. Sumber daya Apple Mail yang terpisah, file yang ditautkan secara eksternal, pesan tidak lengkap, dan lampiran yang tidak dapat dibaca tidak dapat diekstrak. Isi email yang tidak dapat dibaca tidak menghalangi ekstraksi selama lampirannya dapat dibaca. Identitas pengirim, pengiriman, dan tanda tangan digital tidak diverifikasi.

Memori browser dan format yang didukung menentukan apa yang dapat diproses; tidak ada batas tetap untuk ukuran file atau jumlah lampiran. Untuk membaca pesan, gunakan [Penampil Email](/tools/email-viewer/). Untuk menyimpan isi pesan, gunakan [Konverter Email ke HTML / Teks](/tools/email-content-export/).
