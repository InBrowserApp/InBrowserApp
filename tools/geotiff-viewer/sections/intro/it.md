## Come aprire un GeoTIFF

Scegli un file .tif o .tiff oppure trascinalo nel visualizzatore. Se non hai un file a disposizione, seleziona **Prova un esempio**. L’esempio è un piccolo raster di elevazione generato per la dimostrazione. L’anteprima e i dettagli del raster vengono elaborati sul tuo dispositivo. Il file non viene caricato su un server.

## Visualizzare un raster o una singola banda

In **Visualizzazione**, scegli l’immagine a colori, se disponibile, o seleziona una singola banda. Il visualizzatore distribuisce i valori della banda sull’intera scala di grigi per evidenziare i dettagli. I pixel che corrispondono al valore NoData del file appaiono trasparenti. Per i raster di grandi dimensioni, l’anteprima si basa su un campionamento. Ingrandisci l’immagine per esaminarla e seleziona **Inquadra il raster** per tornare alla vista completa.

## Leggere i metadati di un GeoTIFF

Un GeoTIFF contiene un raster e informazioni sulla posizione dei suoi pixel sulla Terra. Controlla le dimensioni in pixel e il numero di bande per identificare il set di dati. Il sistema di riferimento delle coordinate e l’estensione provengono dai metadati del file. L’estensione è espressa nel sistema di coordinate di origine, che può usare gradi o unità di proiezione come i metri. Anche un normale TIFF si può aprire come immagine. I metadati spaziali assenti sono indicati come non disponibili.
