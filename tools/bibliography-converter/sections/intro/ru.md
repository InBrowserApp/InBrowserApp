## Когда выбирать BibTeX, RIS или CSL JSON?

Выберите формат, который поддерживает импорт в нужном вам приложении.

- **BibTeX (`.bib`)** часто используют в проектах LaTeX в Overleaf или локальном редакторе.
- **RIS (`.ris`)** удобен для переноса библиографических записей из базы данных или другого менеджера библиографии в Zotero или EndNote.
- **CSL JSON (`.json`)** содержит структурированные библиографические данные для обработчиков цитирований и других инструментов, поддерживающих данные Citation Style Language.

## Как преобразовать и проверить библиографические записи?

Вставьте записи или нажмите **Открыть файл**. В поле **Исходный формат** оставьте **Определить автоматически**. Если определить формат автоматически не удаётся, укажите его вручную. Выберите **Формат результата**, нажмите **Преобразовать и проверить**, затем скопируйте результат или скачайте файл. Преобразование выполняется в браузере.

Например, откройте RIS-файл, экспортированный из Zotero, выберите BibTeX и скачайте файл `.bib` для проекта в Overleaf. Если у вас есть только оформленный список литературы, скопированный из Word, сначала экспортируйте записи из менеджера библиографии, в котором создали этот список. Чтобы импортировать полученный файл в Zotero, воспользуйтесь [инструкцией по импорту Zotero](https://www.zotero.org/support/kb/importing_standardized_formats).

## Что такое возможный дубликат?

Отчёт группирует записи с одинаковым DOI, в том числе записанным в виде ссылки `doi.org`. При отсутствии DOI записи могут совпасть по названию, году публикации, фамилии и инициалу имени первого автора. Номера записей соответствуют их порядку в исходных данных. Нажмите **Загрузить пример**, чтобы увидеть, как отображаются в отчёте две записи об одной и той же статье. Проверьте каждую группу, прежде чем объединять её записи в менеджере библиографии. Скачанный файл содержит все записи.

## Какие поля сохраняются при преобразовании?

Основные поля, такие как название, авторы, год публикации и DOI, обычно переносятся между форматами. При преобразовании некоторые пользовательские поля могут быть пропущены, а в новом файле BibTeX могут измениться ключи цитирования, чтобы избежать конфликтов. Сохраните исходный файл экспорта, если вам нужны эти сведения. Для поиска дубликатов с сохранением исходных полей выберите один и тот же формат для исходных данных и результата.
