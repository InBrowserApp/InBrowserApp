## การตรวจจับประเภทไฟล์ทำงานอย่างไร

เครื่องมือนี้อ่านไฟล์ในอุปกรณ์ไม่เกิน 64 KiB แรก และตรวจสอบลายเซ็นไบนารีด้วย
[file-type](https://github.com/sindresorhus/file-type) ผลลัพธ์ประกอบด้วยประเภท MIME
ที่ตรวจพบ นามสกุลที่คาดไว้ และตัวอย่าง 256 ไบต์แรกในรูปเลขฐานสิบหกและ ASCII
ไม่มีการอัปโหลดข้อมูล

## เหตุใดนามสกุลจึงอาจไม่ตรงกัน

การเปลี่ยนชื่อไฟล์เปลี่ยนเฉพาะชื่อ ไม่ได้เปลี่ยนเนื้อหา ไฟล์ PNG ที่ชื่อ photo.jpg
ยังคงมีลายเซ็น PNG เครื่องมือยอมรับนามสกุลที่ใช้แทนกันได้ เช่น .jpg และ .jpeg
MIME ที่เบราว์เซอร์รายงานจะแสดงแยกต่างหาก เพราะมักอิงจากชื่อไฟล์
แทนที่จะตรวจสอบไบต์

## ข้อจำกัดในการตรวจจับ

ลายเซ็นเป็นเพียงเบาะแส ไม่ใช่หลักฐานยืนยันว่าไฟล์ถูกต้องหรือปลอดภัย รูปแบบข้อความ
เช่น TXT, CSV และ SVG อาจตรวจไม่พบ ตัวอย่างสั้น ๆ อาจระบุได้ว่าเป็น ZIP
หรือคอนเทนเนอร์อื่น โดยยังยืนยันชนิดย่อยไม่ได้ เช่น เอกสาร Office
ตัวอย่างเลขฐานสิบหกแสดงเนื้อหาไฟล์ดิบ ไม่ใช่เช็กซัมทางการเข้ารหัสลับ
