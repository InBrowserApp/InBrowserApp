## 檔案類型偵測的運作方式

此工具最多讀取本機檔案的前 64 KiB，並使用 [file-type](https://github.com/sindresorhus/file-type) 檢查二進位檔案特徵。結果包含偵測到的 MIME 類型、預期副檔名，以及前 256 個位元組的十六進位與 ASCII 預覽。不會上傳任何內容。

## 副檔名為何可能不符

重新命名只會改變檔名，不會改變內容。名為 photo.jpg 的 PNG 仍具有 PNG 檔案特徵。.jpg 與 .jpeg 等常見別名均視為相符。瀏覽器回報的 MIME 會另外顯示，因為它通常根據檔名判斷，而非檢查位元組。

## 偵測限制

檔案特徵僅供參考，無法證明檔案有效或安全。TXT、CSV 和 SVG 等文字格式可能無法識別。短樣本可能只能識別 ZIP 或其他容器格式，而無法確認 Office 文件等子類型。十六進位預覽顯示的是檔案原始內容，並非密碼學校驗碼。
