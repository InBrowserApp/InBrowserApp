## 文件类型识别的工作原理

此工具最多读取本地文件的前 64 KiB，并使用
[file-type](https://github.com/sindresorhus/file-type) 检查二进制签名。结果包括
检测到的 MIME 类型、预期扩展名，以及前 256 字节的十六进制和 ASCII 预览。
文件不会上传。

## 为什么扩展名可能不匹配

重命名文件只会改变名称，不会改变内容。名为 photo.jpg 的 PNG 仍有 PNG 签名。
工具接受 .jpg 和 .jpeg 等常见别名。浏览器报告的 MIME 单独显示，因为它通常
根据文件名判断，而非检查文件字节。

## 识别限制

签名仅供参考，不能证明文件有效或安全。TXT、CSV 和 SVG 等文本格式可能无法识别。
有限的样本可能只能识别出 ZIP 或其他容器格式，无法确认 Office 文档等具体子类型。
十六进制预览展示的是文件原始内容，不是加密校验和。
