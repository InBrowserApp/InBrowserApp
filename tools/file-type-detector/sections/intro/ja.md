## ファイル形式を判定する仕組み

このツールはローカルファイルの先頭から最大 64 KiB を読み取り、
[file-type](https://github.com/sindresorhus/file-type) でバイナリーシグネチャを
調べます。検出された MIME タイプ、該当する拡張子、先頭 256 バイトの16進数と
ASCII によるプレビューを表示します。ファイルはアップロードされません。

## 拡張子が一致しない理由

ファイル名を変更しても、内容は変わりません。photo.jpg という名前の PNG にも
PNG のシグネチャが残ります。.jpg と .jpeg など、一般的な別表記の拡張子も
一致として扱います。ブラウザーが報告する MIME は、バイト列を調べずに
ファイル名から判断されることが多いため、別の項目として表示します。

## 判定の限界

シグネチャは判断の手がかりであり、ファイルの有効性や安全性を保証しません。
TXT、CSV、SVG などのテキスト形式は認識できない場合があります。短い読み取り
範囲では ZIP などのコンテナーを検出できても、Office 文書などの詳細な形式を
確認できない場合があります。16進数プレビューはファイルの生の内容であり、
暗号学的チェックサムではありません。
