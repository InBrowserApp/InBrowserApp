## 파일 형식 감지 방식

이 도구는 로컬 파일의 처음 64 KiB까지 읽고
[file-type](https://github.com/sindresorhus/file-type)으로 바이너리 시그니처를 검사합니다.
결과에는 감지된 MIME 유형, 예상 확장자, 처음 256바이트의 16진수 및 ASCII
미리보기가 포함됩니다. 아무것도 업로드하지 않습니다.

## 확장자가 일치하지 않을 수 있는 이유

파일 이름을 바꾸어도 내용은 바뀌지 않습니다. photo.jpg라는 이름의 PNG는 여전히
PNG 시그니처를 갖습니다. .jpg와 .jpeg 같은 일반적인 별칭 확장자도 허용됩니다.
브라우저가 보고하는 MIME은 바이트를 검사하기보다 파일 이름을 따르는 경우가 많으므로
별도로 표시합니다.

## 감지의 한계

시그니처는 단서일 뿐, 파일의 유효성이나 안전성을 입증하지 않습니다. TXT, CSV, SVG 같은
텍스트 형식은 인식되지 않을 수 있습니다. 짧은 샘플로 ZIP이나 다른 컨테이너를 식별해도
Office 문서와 같은 하위 형식까지 확인하지는 못할 수 있습니다.
16진수 미리보기는 원시 파일 내용이며 암호학적 체크섬이 아닙니다.
