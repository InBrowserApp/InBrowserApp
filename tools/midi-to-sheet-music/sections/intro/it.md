## Convertire MIDI in spartito e PDF

Seleziona **Apri file MIDI** o trascina un file `.mid` o `.midi` nello strumento. Puoi anche selezionare **Prova un esempio** per iniziare con una breve melodia per pianoforte. Lo strumento trasforma le note MIDI in uno spartito e mostra il risultato pagina per pagina. Controlla il ritmo nell’**Anteprima dello spartito**, poi seleziona **Scarica PDF** per salvare tutte le pagine e stamparle o condividerle. La conversione avviene nel browser.

## Regolare la scrittura del ritmo

In un’esecuzione registrata, alcune note possono cadere prima o dopo il battito. La **Griglia di quantizzazione** allinea l’inizio e la fine di ogni nota a una suddivisione ritmica. Parti dalle semicrome (1/16). Prova le crome (1/8) per semplificare il ritmo o le biscrome (1/32) per mantenere distinte le note più brevi. L’anteprima si aggiorna quando cambi la griglia. Confrontala con l’esecuzione originale se una pausa o una legatura di valore non è come te l’aspettavi.

## Scegliere PDF o MusicXML

Usa il PDF per stampare lo spartito su carta A4 o leggerlo su un tablet. Seleziona **Scarica MusicXML** per rivedere la notazione, aggiungere diteggiature o modificare l’impaginazione in un programma di notazione come MuseScore Studio, Dorico o Sibelius. Per la carta in formato Lettera USA, apri il file nel [Convertitore da MusicXML a PDF](/it/tools/musicxml-to-pdf-converter/).

## Cosa conserva lo spartito

Lo strumento legge file MIDI standard in formato 0 o 1 con risoluzione in impulsi per semiminima (PPQ). Raggruppa le note simultanee e conserva le indicazioni di metro, le armature di chiave e i cambi di tempo. Il MIDI registra la posizione temporale e l’altezza delle note eseguite. Puoi ritoccare i gruppi irregolari, le battute in anacrusi e la grafia enarmonica nel file MusicXML.
