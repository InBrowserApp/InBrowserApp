## ตรวจสอบไฟล์ Parquet ในเบราว์เซอร์

เปิดหรือวางไฟล์ `.parquet` เพื่อเรียกดูข้อมูลและตรวจสอบชนิดทางกายภาพ คำอธิบายชนิดเชิงตรรกะ และการซ้ำของแต่ละฟิลด์ กลุ่มที่ซ้อนกันจะยังแสดงอยู่ในสคีมา สรุปจะแสดงจำนวนแถว คอลัมน์ กลุ่มแถว การบีบอัด และผู้สร้างไฟล์หากมีข้อมูล คุณสามารถลองตัวอย่างที่ให้มาได้โดยไม่ต้องเลือกไฟล์

## เรียกดูข้อมูลและส่งออก CSV หรือ JSON

ข้อมูลจะโหลดทีละหน้า ใช้ตัวควบคุมหน้าเพื่อเลื่อนดูไฟล์ และเลือกเซลล์เพื่ออ่านค่าแบบเต็ม สลับไปที่ **สคีมา** เพื่อตรวจสอบฟิลด์ ใช้ **ส่งออกข้อมูล** เพื่อดาวน์โหลดหน้าปัจจุบันหรือทุกแถวเป็น CSV แบบ UTF-8 หรืออาร์เรย์ JSON การส่งออกทั้งไฟล์จะเตรียมเป็นชุดและสามารถยกเลิกได้

CSV มีชื่อคอลัมน์และใช้เครื่องหมายอัญประกาศครอบค่าที่มีจุลภาค อัญประกาศ และการขึ้นบรรทัดใหม่ ค่า null จะกลายเป็นฟิลด์ CSV ว่างและยังเป็น `null` ใน JSON ค่าที่ซ้อนกันใช้ JSON ส่วนค่าฐานสองใช้ข้อความเลขฐานสิบหก JSON จะเขียนจำนวนเต็ม 64 บิตเป็นสตริงเพื่อคงค่าไว้ วันที่และเวลาประทับใช้ข้อความ ISO ที่มีความละเอียดระดับมิลลิวินาที ค่าทศนิยมเป็นไปตามความแม่นยำเชิงตัวเลขของตัวอ่าน ดังนั้นโปรแกรมดูนี้จึงไม่ใช่เครื่องมือแปลงแบบไม่สูญเสียข้อมูลสำหรับค่าทศนิยมหรือเวลาประทับที่มีความละเอียดสูง

## ประมวลผลในเครื่อง

ไฟล์ของคุณจะอ่านในเครื่องโดยเวิร์กเกอร์เบื้องหลังและไม่มีการอัปโหลด โปรแกรมดูจะอ่านส่วนท้ายไฟล์ก่อน จากนั้นอ่านเฉพาะช่วงแถวที่จำเป็นสำหรับการเรียกดู การถอดรหัสกลุ่มแถวของ Parquet อาจยังต้องใช้หน่วยความจำจำนวนมาก ขนาดการส่งออกจึงจำกัดตามหน่วยความจำที่มีอยู่ในเบราว์เซอร์ hyparquet และแพ็กเกจการบีบอัดรองรับข้อมูลที่ไม่บีบอัดและโคเดก Snappy, Gzip, Brotli, Zstandard และ LZ4 ไม่รองรับไฟล์ Parquet ที่เข้ารหัส
