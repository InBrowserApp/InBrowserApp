## 브라우저에서 Parquet 파일 확인

`.parquet` 파일을 열거나 끌어 놓아 데이터를 탐색하고 각 필드의 물리 유형, 논리 주석, 반복 유형을 확인하세요. 중첩 그룹도 스키마에 표시됩니다. 요약에는 행 수, 열 수, 행 그룹, 압축 방식과 확인 가능한 파일 생성 도구가 표시됩니다. 파일을 선택하지 않고도 포함된 샘플을 체험할 수 있습니다.

## 데이터 탐색 및 CSV 또는 JSON 내보내기

데이터는 한 번에 한 페이지씩 불러옵니다. 페이지 컨트롤로 파일을 탐색하고 셀을 선택하여 전체 값을 확인하세요. **스키마**로 전환하면 필드를 확인할 수 있습니다. **데이터 내보내기**에서 현재 페이지 또는 모든 행을 UTF-8 CSV나 JSON 배열로 다운로드하세요. 전체 파일 내보내기는 일괄 처리되며 취소할 수 있습니다.

CSV에는 열 이름이 포함되며 쉼표, 따옴표, 줄바꿈이 있는 값은 따옴표로 감쌉니다. null은 CSV에서 빈 필드가 되며 JSON에서는 `null`로 유지됩니다. 중첩 값은 JSON, 바이너리 값은 16진수 텍스트를 사용합니다. 64비트 정수를 보존하기 위해 JSON에는 문자열로 기록됩니다. 날짜와 타임스탬프는 밀리초 정밀도의 ISO 텍스트를 사용합니다. 소수는 리더의 수치 정밀도를 따르므로 이 뷰어는 고정밀 소수나 타임스탬프 데이터를 무손실 변환하는 도구가 아닙니다.

## 로컬 처리

파일은 백그라운드 워커에서 로컬로 읽으며 업로드하지 않습니다. 뷰어는 먼저 푸터를 읽은 다음 탐색에 필요한 행 범위만 읽습니다. Parquet 행 그룹을 디코딩할 때는 여전히 많은 메모리가 필요할 수 있으며, 내보내기 크기는 브라우저의 사용 가능한 메모리에 따라 제한됩니다. hyparquet와 압축기 패키지는 비압축, Snappy, Gzip, Brotli, Zstandard, LZ4 코덱을 지원합니다. 암호화된 Parquet 파일은 지원하지 않습니다.
