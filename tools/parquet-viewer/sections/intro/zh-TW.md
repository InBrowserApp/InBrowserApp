## 在瀏覽器中檢查 Parquet 檔案

開啟或拖放 `.parquet` 檔案，即可瀏覽資料，並檢查每個欄位的實體型別、邏輯註記與重複性。結構中也會顯示巢狀群組。摘要會顯示資料列數、欄位數、資料列群組數、壓縮方式，以及檔案中記錄的建立程式。你也可以直接試用內附的範例，不必選擇檔案。

## 瀏覽資料並匯出 CSV 或 JSON

資料會逐頁載入。使用分頁控制項瀏覽檔案，選取儲存格即可閱讀完整內容。切換至**結構**以檢查欄位。使用**匯出資料**，將目前頁面或所有資料列下載為 UTF-8 CSV 或 JSON 陣列。整份檔案的匯出作業會分批準備，並可隨時取消。

CSV 包含欄位名稱，並以引號處理逗號、引號與換行。null 在 CSV 中會轉為空白欄位，在 JSON 中則保留為 `null`。巢狀值使用 JSON；二進位值使用十六進位文字。為保留 64 位元整數，JSON 會將其寫為字串。日期與時間戳記使用 ISO 文字，精度為毫秒。十進位數值採用讀取程式的數值精度，因此此檢視器不適合用來無損轉換高精度十進位數值或時間戳記資料。

## 本機處理

檔案會在本機的背景工作執行緒中讀取，絕不會上傳。檢視器會先讀取檔案尾端的中繼資料，再讀取瀏覽所需的資料列範圍。Parquet 資料列群組的解碼仍可能需要大量記憶體；匯出大小受限於瀏覽器的可用記憶體。hyparquet 及其壓縮套件支援未壓縮、Snappy、Gzip、Brotli、Zstandard 和 LZ4 格式。不支援加密的 Parquet 檔案。
