## 在浏览器中查看 Parquet 文件

打开或拖放 `.parquet` 文件，即可浏览数据，查看每个字段的物理类型、逻辑注解和重复类型。嵌套组会保留在字段结构中。摘要显示行数、列数、行组数、压缩格式，以及可用的文件创建程序信息。无需选择文件，也可试用内置示例。

## 浏览数据并导出 CSV 或 JSON

数据按页加载。使用分页控件浏览文件，选择单元格可查看完整值。切换到**字段结构**查看字段。使用**导出数据**将当前页或所有行下载为 UTF-8 CSV 或 JSON 数组。整个文件的导出会分批准备，并可随时取消。

CSV 包含列名，并对逗号、引号和换行进行引号转义。null 值导出为空 CSV 字段，在 JSON 中则保留为 `null`。嵌套值使用 JSON，二进制值使用十六进制文本。为保留 64 位整数，JSON 会将其写为字符串。日期和时间戳使用 ISO 文本，精度为毫秒。小数采用读取器的数值精度，因此此查看器不适用于高精度小数或时间戳数据的无损转换。

## 本地处理

文件在后台工作线程中本地读取，绝不会上传。查看器先读取文件尾部元数据，再按需读取浏览所需的行范围。Parquet 行组解码仍可能需要较多内存，导出大小受浏览器可用内存限制。hyparquet 及其压缩器包支持未压缩、Snappy、Gzip、Brotli、Zstandard 和 LZ4 格式。不支持加密的 Parquet 文件。
