## Просмотр файлов Parquet в браузере

Откройте или перетащите файл `.parquet`, чтобы просмотреть данные и проверить физический тип, логическую аннотацию и повторяемость каждого поля. Вложенные группы отображаются в схеме. В сводке указаны количество строк, столбцов и групп строк, способы сжатия и, при наличии, сведения о создателе файла. Встроенный пример можно попробовать, не выбирая файл.

## Просмотр данных и экспорт в CSV или JSON

Данные загружаются постранично. Перемещайтесь по файлу с помощью элементов управления страницами и выбирайте ячейку, чтобы прочитать её полное значение. Перейдите на вкладку **Схема**, чтобы проверить поля. В разделе **Экспорт данных** можно скачать текущую страницу или все строки в формате CSV с кодировкой UTF-8 либо в виде массива JSON. Экспорт всего файла подготавливается порциями; его можно отменить.

CSV включает имена столбцов; значения с запятыми, кавычками и переносами строк заключаются в кавычки. null преобразуется в пустые поля CSV и сохраняется как `null` в JSON. Вложенные значения записываются в JSON, двоичные — шестнадцатеричным текстом. Для сохранения 64-битных целых чисел JSON записывает их строками. Даты и временные метки записываются текстом в формате ISO с точностью до миллисекунды. Точность десятичных чисел зависит от механизма чтения, поэтому этот инструмент просмотра не предназначен для преобразования десятичных чисел или временных меток высокой точности без потерь.

## Локальная обработка

Файл читается локально в фоновом рабочем потоке и никогда не загружается на сервер. Инструмент сначала читает завершающие метаданные файла, а затем — только диапазоны строк, необходимые для просмотра. При этом декодирование групп строк Parquet всё же может требовать значительного объёма памяти; размер экспорта ограничен доступной браузеру памятью. hyparquet и пакет декомпрессоров поддерживают файлы без сжатия и кодеки Snappy, Gzip, Brotli, Zstandard и LZ4. Зашифрованные файлы Parquet не поддерживаются.
