## Lire un document Typst en local

Ouvrez un fichier `.typ` pour lire ses pages après rendu. Parcourez les pages, recherchez du texte, réglez le zoom, ajustez la page ou sa largeur et utilisez la lecture concentrée pour gagner de l’espace. Vous pouvez remplacer ou fermer le document pendant son rendu. Les fichiers restent dans votre navigateur.

## Compatibilité et polices

La visionneuse utilise Typst 0.14.2 et les polices fournies Libertinus Serif, New Computer Modern et DejaVu Sans Mono. D’autres versions du langage et choix de polices peuvent modifier le résultat. Les polices indisponibles peuvent être remplacées ; certains caractères, dont les textes CJK et les emoji, peuvent manquer. Comparez les équations et symboles importants avec l’original.

## Fichiers autonomes

Seul le fichier source UTF-8 sélectionné est disponible. Les paquets importés, les images séparées, les données et les autres fichiers source ne peuvent pas être chargés. Aucune ressource du document ni aucune police n’est récupérée automatiquement. Pour un projet qui nécessite ces éléments, utilisez son environnement de création d’origine ou obtenez une copie PDF. Les erreurs du code source indiquent une ligne et une colonne lorsque le moteur les fournit. Les documents volumineux dépendent de la mémoire disponible dans votre navigateur.
