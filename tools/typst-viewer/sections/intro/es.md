## Lee un documento Typst de forma local

Abre un archivo `.typ` para leer sus páginas renderizadas. Navega entre páginas, busca texto, ajusta el zoom, encaja la página o su ancho y usa la lectura sin distracciones para disponer de más espacio. Puedes reemplazar o cerrar el documento mientras se renderiza. Los archivos permanecen en tu navegador. Descargar PDF guarda el documento compilado. El zoom de la vista previa no cambia el PDF descargado.

## Compatibilidad y fuentes

El visor usa Typst 0.14.2 y las fuentes incluidas Libertinus Serif, New Computer Modern y DejaVu Sans Mono. Otras versiones del lenguaje y otras fuentes pueden cambiar el resultado. Las fuentes no disponibles pueden sustituirse; pueden faltar algunos caracteres, como texto CJK y emojis. Comprueba las ecuaciones y los símbolos importantes con el original.

## Archivos autocontenidos

Solo está disponible el archivo fuente UTF-8 seleccionado. No se pueden cargar paquetes importados, imágenes independientes, datos ni otros archivos fuente. No se descargan automáticamente recursos del documento ni fuentes. Para un proyecto que necesite estos elementos, usa el entorno original de creación u obtén una copia en PDF. Los errores del código fuente incluyen una línea y una columna cuando el motor las proporciona. Los documentos grandes dependen de la memoria disponible en tu navegador.
