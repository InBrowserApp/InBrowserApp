## Read a Typst document locally

Open a `.typ` file to read its rendered pages. Move between pages, find text, adjust zoom, fit the page or its width, and use focus reading for more space. You can replace or close the document while it is rendering. Files stay in your browser.

## Compatibility and fonts

The viewer uses Typst 0.14.2 and the bundled Libertinus Serif, New Computer Modern, and DejaVu Sans Mono fonts. Other language versions and font choices can change the result. Unavailable fonts may be substituted; some characters, including CJK text and emoji, may be missing. Check important equations and symbols against the original.

## Self-contained files

Only the selected UTF-8 source file is available. Imported packages, separate images, data, and other source files cannot be loaded. No document resources or fonts are fetched automatically. For a project that needs these inputs, use its original authoring environment or obtain a PDF copy. Source errors include a line and column when the engine provides them. Large documents depend on your browser's available memory.
