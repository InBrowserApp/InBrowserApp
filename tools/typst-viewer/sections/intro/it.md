## Leggi un documento Typst in locale

Apri un file `.typ` per leggerne le pagine dopo il rendering. Passa da una pagina all’altra, cerca testo, regola lo zoom, adatta la pagina o la sua larghezza e usa la lettura senza distrazioni per avere più spazio. Puoi sostituire o chiudere il documento durante il rendering. I file restano nel browser. Scarica PDF salva il documento compilato. Lo zoom dell’anteprima non modifica il PDF scaricato.

## Compatibilità e font

Il visualizzatore usa Typst 0.14.2 e i font inclusi Libertinus Serif, New Computer Modern e DejaVu Sans Mono. Altre versioni del linguaggio o scelte di font possono cambiare il risultato. I font non disponibili possono essere sostituiti; alcuni caratteri, inclusi testo CJK ed emoji, potrebbero mancare. Confronta le equazioni e i simboli importanti con l’originale.

## File autonomi

È disponibile solo il file sorgente UTF-8 selezionato. Non è possibile caricare pacchetti importati, immagini separate, dati e altri file sorgente. Le risorse del documento e i font non vengono recuperati automaticamente. Per un progetto che richiede questi elementi, usa l’ambiente di creazione originale oppure procurati una copia PDF. Gli errori del sorgente includono riga e colonna quando il motore le fornisce. I documenti di grandi dimensioni dipendono dalla memoria disponibile nel browser.
