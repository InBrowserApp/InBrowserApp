## CBZ 또는 CBR을 EPUB으로 변환하는 방법

`.cbz` 또는 `.cbr` 만화 파일을 선택하거나 변환기에 끌어다 놓으세요. 만화 페이지 이미지가 담긴 ZIP 또는 RAR 압축 파일도 변환할 수 있습니다. 표지와 페이지 수를 확인한 뒤 **EPUB 다운로드**를 선택하세요. 예를 들어 `volume-01.cbz`는 `volume-01.epub`으로 변환됩니다. 변환은 기기에서 진행됩니다.

## 만화 페이지의 원래 레이아웃 유지

고정 레이아웃 EPUB 3 형식을 사용해 이미지 한 장을 한 페이지에 담습니다. 폴더와 파일 이름에 들어 있는 숫자 순서를 고려해 페이지를 정렬하며, 첫 이미지가 표지가 됩니다. 세로 페이지와 가로로 넓은 펼침면 모두 원래 비율을 유지합니다. 호환되는 이미지 파일은 그대로 사용하고, WebP, BMP, AVIF 이미지는 PNG로 저장합니다.

## EPUB 만화 읽기

고정 레이아웃 책을 지원하는 EPUB 리더에서 파일을 여세요. EPUB 목차의 링크를 통해 각 페이지로 이동할 수 있습니다. 말풍선 속 대사처럼 그림에 포함된 글자는 페이지 이미지의 일부로 유지됩니다.
