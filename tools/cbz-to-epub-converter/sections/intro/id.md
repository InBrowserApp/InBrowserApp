## Cara mengubah CBZ atau CBR ke EPUB

Pilih komik `.cbz` atau `.cbr` atau seret dan lepas file ke konverter. Arsip ZIP atau RAR yang berisi gambar halaman komik juga bisa digunakan. Periksa sampul dan jumlah halaman, lalu pilih **Unduh EPUB**. Misalnya, `volume-01.cbz` menjadi `volume-01.epub`. Konversi berlangsung di perangkat Anda.

## Mempertahankan tata letak asli halaman komik

Konverter membuat EPUB 3 dengan tata letak tetap agar setiap gambar menempati satu halaman. Halaman mengikuti urutan alami berdasarkan folder dan nama file, dan gambar pertama menjadi sampul. Proporsi halaman tegak dan bentangan lebar tetap terjaga. File gambar yang kompatibel bisa dipertahankan dalam format aslinya. Gambar WebP, BMP, dan AVIF disimpan sebagai PNG.

## Membaca komik EPUB

Buka file di aplikasi pembaca EPUB yang mendukung buku dengan tata letak tetap. Daftar isi EPUB memuat tautan ke setiap halaman. Dialog manga dan tulisan lain pada ilustrasi tetap menjadi bagian dari gambar halaman.
