## Comment convertir un EPUB en Word

Choisissez un fichier `.epub` ou faites-le glisser sur le convertisseur. Vérifiez les chapitres dans l’aperçu, puis cliquez sur **Télécharger le DOCX**. Par exemple, `field-guide.epub` devient `field-guide.docx`. La conversion se fait sur votre appareil.

## Modifier le texte du livre dans un document DOCX

Ouvrez le fichier `.docx` dans Microsoft Word ou un éditeur compatible pour modifier ou réutiliser le texte. Le convertisseur conserve l’ordre des chapitres, les titres, les listes, les tableaux, les liens et les illustrations prises en charge. Le document reprend le titre et le nom de l’auteur lorsqu’ils figurent dans l’EPUB.

## Quels fichiers EPUB choisir

Utilisez un EPUB non chiffré à mise en page adaptable, qui permet de régler la taille du texte. Le document Word a une mise en page modifiable, ce qui peut changer la pagination et les retours à la ligne. Ouvrez le résultat dans la [Visionneuse Microsoft Word](/fr/tools/microsoft-word-viewer/) pour vérifier le document converti.
