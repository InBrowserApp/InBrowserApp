## Så konverterar du EPUB till Word

Välj en `.epub`-fil eller dra den till konverteraren. Förhandsvisa kapitlen och välj sedan **Ladda ner DOCX**. Till exempel blir `field-guide.epub` till `field-guide.docx`. Konverteringen sker på din enhet.

## Redigera e-bokens text i ett DOCX-dokument

Öppna `.docx`-filen i Microsoft Word eller ett kompatibelt program för att redigera eller återanvända texten. Konverteraren bevarar kapitelordningen, rubriker, listor, tabeller, länkar och illustrationer som stöds. Dokumentet använder uppgifterna om titel och författare från EPUB-filen när de finns.

## Vilka EPUB-böcker kan du konvertera?

Använd en okrypterad EPUB-bok med flödande text, där du kan ändra textstorleken. Word-dokumentet går att redigera, och sidindelning och radbrytningar kan ändras vid konverteringen. Öppna resultatet i [visaren för Microsoft Word](/sv/tools/microsoft-word-viewer/) för att granska dokumentet.
