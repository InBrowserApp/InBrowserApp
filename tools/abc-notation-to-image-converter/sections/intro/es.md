## Convierte notación ABC a PNG o SVG

Pega la **Notación ABC** o pulsa **Abrir archivo ABC** para abrir un archivo `.abc` o `.txt`. Pulsa **Probar un ejemplo** para ver una colección de dos melodías. El conversor dibuja en tu navegador la partitura de cada melodía seleccionada y recorta los márgenes en blanco. Usa las flechas de la **Vista previa de la imagen** para recorrer los resultados.

## Exporta una melodía o toda la colección

Cada campo `X:` empieza una melodía y el campo `T:` indica su título. Al principio se incluyen todas las melodías. Usa **Melodías para incluir** para elegir solo algunas. Pulsa **Borrar selección** si quieres elegir solo una o dos melodías. Pulsa **Seleccionar todo** para volver a incluir la colección completa. Elige **Descargar imagen** para guardar un solo resultado o **Descargar ZIP** para guardar las imágenes numeradas en el orden del texto original.

## Elige un formato de imagen

En **Formato de imagen**, elige PNG para diapositivas, materiales de clase o para compartir una imagen en un mensaje. SVG mantiene la notación nítida a distintos tamaños y resulta útil en sitios web y en editores de dibujo vectorial. En un SVG, los títulos y las letras se muestran con las fuentes disponibles en la aplicación que lo abre. Si una melodía muy extensa supera el tamaño máximo de PNG que admite tu navegador, elige SVG.

## Comparte imágenes o imprime una partitura paginada

La imagen recortada se ajusta a la melodía e incluye el título y las letras que aparecen en la vista previa. Así puedes colocar la partitura junto a instrucciones u otras piezas. Para distribuir las melodías seleccionadas en páginas de tamaño estándar y prepararlas para imprimir, usa el [Conversor de notación ABC a PDF](/es/tools/abc-notation-to-pdf-converter/).
