## Ouvrir un fichier OSM PBF

Ouvrez ou déposez un extrait OpenStreetMap au format `.osm.pbf` ou `.pbf`. Le navigateur analyse le fichier et affiche le nombre de nœuds, de chemins et de relations. Sélectionnez un élément sur la carte ou dans la liste pour consulter ses attributs, par exemple `name`, `highway` ou `amenity`. Choisissez **Essayer un exemple** pour voir comment les points et les chemins s’affichent avant d’ouvrir votre fichier. Votre fichier reste sur votre appareil.

## Ce que montre l’aperçu cartographique

Le comptage porte sur tous les enregistrements de l’extrait. La carte affiche jusqu’à 200 nœuds et 400 chemins dotés d’attributs. Pour afficher un chemin, il faut connaître les coordonnées des nœuds qu’il référence. Certains chemins peuvent donc manquer si l’extrait est incomplet. Les relations sont prises en compte dans les totaux. L’aperçu repose sur un fond de carte simple utilisable hors ligne. Vous pouvez ainsi repérer des éléments et consulter leurs attributs sans demander de tuiles à un service en ligne.

## Qu’est-ce qu’un extrait OpenStreetMap PBF ?

OpenStreetMap utilise le [Protocolbuffer Binary Format](https://wiki.openstreetmap.org/wiki/PBF_Format) pour stocker les données cartographiques sous une forme compacte. Un extrait régional contient les données OpenStreetMap brutes d’une zone, par exemple une ville ou un pays. L’extension `.pbf` peut aussi désigner une tuile vectorielle pour une carte web, qui utilise un schéma différent. Choisissez un extrait régional pour accélérer l’analyse, surtout sur mobile. Si vous partagez des données OpenStreetMap ou une carte qui en est issue, conservez la [mention de source OpenStreetMap](https://www.openstreetmap.org/copyright).
