## Come aprire un file OSM PBF

Apri o trascina un estratto di OpenStreetMap in formato `.osm.pbf` o `.pbf`. Il browser analizza il file e mostra il numero di nodi, percorsi e relazioni. Seleziona un elemento sulla mappa o nell’elenco per consultare tag come `name`, `highway` o `amenity`. Usa **Prova un esempio** per vedere come appaiono punti e percorsi prima di aprire il tuo file. Il file resta sul tuo dispositivo.

## Cosa mostra l’anteprima della mappa

Il conteggio include tutti i record dell’estratto. La mappa mostra fino a 200 nodi e 400 percorsi con tag. Per visualizzare un percorso occorrono le coordinate dei nodi a cui fa riferimento. Se l’estratto è incompleto, alcuni percorsi possono quindi mancare. Le relazioni sono incluse nei totali. L’anteprima usa una mappa di base offline essenziale. Puoi identificare gli elementi e controllare i tag senza richiedere tasselli a un servizio online.

## Cos’è un estratto OpenStreetMap PBF?

OpenStreetMap usa il [Protocolbuffer Binary Format](https://wiki.openstreetmap.org/wiki/PBF_Format) per conservare i dati cartografici in forma compatta. Un estratto regionale contiene i dati grezzi di OpenStreetMap relativi a un’area, ad esempio una città o un paese. L’estensione `.pbf` può anche indicare un tassello vettoriale per mappe web, che usa uno schema diverso. Scegli un estratto regionale per velocizzare l’analisi, soprattutto su dispositivi mobili. Se condividi dati OpenStreetMap o una mappa che li utilizza, mantieni l’[attribuzione a OpenStreetMap](https://www.openstreetmap.org/copyright).
