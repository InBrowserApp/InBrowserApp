## Cómo abrir un archivo OSM PBF

Abre o suelta un extracto de OpenStreetMap en formato `.osm.pbf` o `.pbf`. El navegador analiza el archivo y muestra cuántos nodos, vías y relaciones contiene. Selecciona un elemento en el mapa o en la lista para consultar etiquetas como `name`, `highway` o `amenity`. Usa **Probar un ejemplo** para ver cómo se muestran los puntos y las vías antes de abrir tu archivo. El archivo se queda en tu dispositivo.

## Qué muestra la vista previa del mapa

El recuento incluye todos los registros del extracto. El mapa muestra hasta 200 nodos y 400 vías con etiquetas. Para mostrar una vía se necesitan las coordenadas de los nodos a los que hace referencia. Por eso, un extracto incompleto puede dejar algunas vías fuera del mapa. Las relaciones se incluyen en los totales. La vista previa usa un mapa base sencillo sin conexión. Así puedes identificar elementos y consultar etiquetas sin solicitar teselas a un servicio en línea.

## ¿Qué es un extracto PBF de OpenStreetMap?

OpenStreetMap usa el [Protocolbuffer Binary Format](https://wiki.openstreetmap.org/wiki/PBF_Format) para guardar los datos cartográficos en un formato compacto. Un extracto regional contiene datos sin procesar de OpenStreetMap para una zona, como una ciudad o un país. La extensión `.pbf` también puede identificar una tesela vectorial para mapas web, que utiliza un esquema diferente. Elige un extracto regional para acelerar el análisis, especialmente en el móvil. Si compartes datos de OpenStreetMap o un mapa basado en ellos, conserva la [atribución a OpenStreetMap](https://www.openstreetmap.org/copyright).
