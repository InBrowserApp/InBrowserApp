## 导出邮件内容

打开 EML、EMLX 或 MSG 文件，选择 HTML 或纯文本。预览并下载独立的 HTML 文档，或复制并下载 UTF-8 文本。两种输出均包含可读取的已保存邮件头、原始日期文本和附件列表。邮件仅在浏览器中处理。

## HTML 和文本输出

HTML 使用简洁的阅读布局，包含可选择的文本和受支持的嵌入位图图片。优先使用可读取的 HTML 正文；如无 HTML 正文，则使用已保存的纯文本。文件可离线打开。安全的外部链接仅在你点击时打开；内部引用仍在文档内跳转。原有样式、脚本、表单、嵌入式应用、SVG 和 MathML 会被省略。不会获取远程图片和其他外部资源；输出中会注明省略情况。

文本导出优先使用已保存的纯文本正文。如果没有纯文本正文，则从 HTML 中提取可读取的文本和安全的链接地址，保留有助于阅读的段落、列表、引用和表格分隔。文本不包含图片或格式。两种输出均列出附件的名称、类型、大小和用途，但不包含附件文件或附加邮件的内容。

## 支持的邮件及限制

请使用完整且未加密的邮件。无法导出不完整的邮件、嵌入图片缺失或无法读取的邮件、日历或联系人 MSG 项目，以及仅有压缩 RTF 正文的 Outlook 邮件。不会加载 Apple Mail 的外部分离资源。日期缺失或格式错误，以及 Outlook 使用 UTC 时间戳的情况，均会明确标注，不推测发件人的时区。不验证发件人身份、数字签名和投递情况。

可处理的文件取决于浏览器内存和格式支持，没有固定的文件大小或页数限制。如需直接查看已保存的邮件及其不同格式的正文，请使用[邮件查看器](../email-viewer/)。如需生成可打印的副本，请使用[邮件转 PDF 转换器](../email-to-pdf-converter/)。
