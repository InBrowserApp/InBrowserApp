## 匯出郵件內容

開啟 EML、EMLX 或 MSG 檔案，並選擇 HTML 或純文字。您可以預覽及下載獨立的 HTML 文件，或複製及下載 UTF-8 文字。兩種輸出都包含可讀取的儲存郵件標頭、原始日期文字與附件清單。您的郵件會留在瀏覽器中。

## HTML 與文字輸出

HTML 採用簡易閱讀版面，保留可選取的文字與支援的內嵌點陣圖片。它會優先使用可讀取的 HTML 本文，否則使用儲存的純文字。檔案可離線開啟。安全的外部連結只有在點選時才會開啟；內部參照會保留在文件中。原始樣式、指令碼、表單、嵌入式應用程式、SVG 與 MathML 會省略。不會擷取遠端圖片或其他外部資源；省略的內容會在輸出中註明。

文字匯出會優先使用儲存的純文字版本。若沒有此版本，便會從 HTML 擷取可讀取的文字與安全連結位址，保留有助於閱讀的段落、清單、引用與表格分隔。純文字不包含圖片或格式。兩種輸出都會列出附件名稱、類型、大小與用途，但不會納入附加的檔案或巢狀郵件。

## 支援的郵件與限制

請使用完整且未加密的郵件。無法匯出不完整的郵件、內嵌圖片遺失或無法讀取的郵件、行事曆或聯絡人 MSG 項目，以及僅有壓縮 RTF 本文的 Outlook 郵件。不會載入未隨郵件儲存的 Apple Mail 資源。日期遺失或格式有誤，以及 Outlook 改用 UTC 時間的情況，都會明確標示，不會猜測寄件者的時區。寄件者身分、數位簽章及遞送情況未經驗證。

瀏覽器記憶體與格式支援程度決定了可以處理哪些檔案，檔案大小或頁數沒有固定限制。若要檢視儲存的郵件及其不同本文版本，可使用[電子郵件檢視器](../email-viewer/)。若需要可供列印的副本，可使用[電子郵件轉 PDF 轉換器](../email-to-pdf-converter/)。
