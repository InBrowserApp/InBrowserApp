## Export email content

Open an EML, EMLX or MSG file and choose HTML or plain text. Preview and download a standalone HTML document, or copy and download UTF-8 text. Both outputs include readable saved headers, the original date text and an attachment list. Your email stays in your browser.

## HTML and text outputs

HTML uses a simple reading layout with selectable text and supported embedded raster images. It prefers the readable HTML body, falling back to saved plain text. The file opens offline. Safe external links open only when selected; internal references stay in the document. Original styles, scripts, forms, embedded applications, SVG and MathML are omitted. Remote images and other external resources are not fetched; omissions are noted in the output.

Text export prefers the saved plain-text alternative. If none exists, readable text and safe link addresses are extracted from HTML, keeping useful paragraph, list, quote and table boundaries. It contains no images or formatting. Attachment names, types, sizes and roles are listed, but attached files and nested emails are not incorporated into either output.

## Supported messages and limits

Use a complete, unencrypted email. Incomplete messages, missing or unreadable embedded images, calendar/contact MSG items and Outlook bodies available only as compressed RTF cannot be exported. Detached Apple Mail resources are not loaded. Missing or malformed dates and Outlook UTC fallbacks are labelled without guessing the sender's timezone. Sender identity, digital signatures and delivery are not verified.

Browser memory and format support determine what can be processed, with no fixed file-size or page-count quota. To inspect the saved message and its alternatives without exporting, use the [Email Viewer](../email-viewer/). For a printable copy, use the [Email to PDF Converter](../email-to-pdf-converter/).
