## ส่งออกเนื้อหาอีเมล

เปิดไฟล์ EML, EMLX หรือ MSG แล้วเลือก HTML หรือข้อความธรรมดา ดูตัวอย่างและดาวน์โหลดเอกสาร HTML แบบแยกเดี่ยว หรือคัดลอกและดาวน์โหลดข้อความ UTF-8 ผลลัพธ์ทั้งสองรูปแบบมีส่วนหัวที่บันทึกไว้ซึ่งอ่านได้ ข้อความวันที่เดิม และรายการไฟล์แนบ อีเมลของคุณอยู่ในเบราว์เซอร์ของคุณ

## ผลลัพธ์ HTML และข้อความ

HTML ใช้เค้าโครงสำหรับอ่านแบบเรียบง่ายพร้อมข้อความที่เลือกได้และภาพแรสเตอร์ที่ฝังไว้ซึ่งรองรับ โดยจะใช้เนื้อหา HTML ที่อ่านได้ก่อน และใช้ข้อความธรรมดาที่บันทึกไว้แทนหากไม่มี ไฟล์เปิดแบบออฟไลน์ได้ ลิงก์ภายนอกที่ปลอดภัยจะเปิดเมื่อเลือกเท่านั้น ส่วนการอ้างอิงภายในยังอยู่ในเอกสาร สไตล์เดิม สคริปต์ แบบฟอร์ม แอปที่ฝังไว้ SVG และ MathML จะถูกละไว้ ไม่มีการดึงภาพจากภายนอกหรือทรัพยากรภายนอกอื่น ๆ และจะมีหมายเหตุในผลลัพธ์ระบุสิ่งที่ละไว้

การส่งออกข้อความจะใช้เนื้อหาทางเลือกแบบข้อความธรรมดาที่บันทึกไว้ก่อน หากไม่มี จะดึงข้อความที่อ่านได้และที่อยู่ลิงก์ที่ปลอดภัยจาก HTML โดยคงการแบ่งย่อหน้า รายการ ข้อความอ้างอิง และตารางที่ช่วยให้อ่านเข้าใจ ไม่มีรูปภาพหรือการจัดรูปแบบ มีรายการชื่อ ชนิด ขนาด และบทบาทของไฟล์แนบ แต่ไฟล์และอีเมลที่แนบมาจะไม่รวมอยู่ในผลลัพธ์ทั้งสองรูปแบบ
