## Cara mengubah CBR ke CBZ

Pilih komik `.cbr` atau seret dan lepas file ke konverter. Arsip `.rar` yang berisi gambar halaman komik juga bisa digunakan. Periksa nama file halaman pertama dan terakhir, lalu pilih **Unduh CBZ**. Misalnya, `volume-01.cbr` menjadi `volume-01.cbz`. Konversi berlangsung di perangkat Anda.

## Mempertahankan halaman asli dan metadata komik

CBR menyimpan gambar komik di dalam arsip RAR. CBZ menggunakan ZIP, format yang bisa dibuka oleh banyak pembaca dan aplikasi pengelola komik. Konverter menyalin file halaman asli ke dalam ZIP, sehingga resolusi dan kualitas gambar tetap terjaga. Folder dan nama file mengikuti urutan baca alami, sehingga `chapter2/page2.jpg` muncul sebelum `chapter2/page10.jpg`. File `ComicInfo.xml` yang sudah ada juga ikut disalin.

## Membuka file CBZ hasil konversi

Setelah mengunduh, buka hasilnya di [Pembaca Komik CBZ](/id/tools/cbz-reader/) atau impor file ke koleksi komik Anda. Jika ingin mencetak komik, gunakan [Konverter CBZ ke PDF](/id/tools/cbz-to-pdf-converter/). Jika arsip RAR dilindungi kata sandi atau terbagi menjadi beberapa bagian, ekstrak dulu isinya lalu gunakan satu arsip tanpa kata sandi.
