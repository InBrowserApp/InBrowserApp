## Come convertire CBR in CBZ

Scegli un fumetto `.cbr` o trascinalo nel convertitore. Puoi usare anche un archivio `.rar` che contiene le immagini delle pagine. Controlla i nomi dei file della prima e dell’ultima pagina, quindi seleziona **Scarica CBZ**. Ad esempio, `volume-01.cbr` diventa `volume-01.cbz`. La conversione avviene sul tuo dispositivo.

## Conserva le pagine originali e i metadati del fumetto

Un file CBR contiene le immagini del fumetto in un archivio RAR. Un file CBZ usa ZIP, un formato supportato da molti lettori e applicazioni per le raccolte di fumetti. Il convertitore copia i file delle pagine nello ZIP senza ricodificarli, così la risoluzione e la qualità rimangono invariate. Mantiene l’ordine naturale delle cartelle e dei nomi dei file, perciò `chapter2/page2.jpg` viene prima di `chapter2/page10.jpg`. Conserva anche eventuali file `ComicInfo.xml`.

## Apri il nuovo file CBZ

Dopo aver scaricato il file, aprilo nel [Lettore di fumetti CBZ](/it/tools/cbz-reader/) o importalo nella tua raccolta di fumetti. Se ti serve una versione stampabile, usa il [Convertitore da CBZ a PDF](/it/tools/cbz-to-pdf-converter/). Se il RAR è protetto da password o diviso in più parti, estrailo prima e usa un unico archivio senza protezione.
