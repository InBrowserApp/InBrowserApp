## 什麼是舊版 Motorola 系統金鑰？

軟體系統金鑰是一種 `.KEY` 檔案，供相容的 Motorola 寫頻軟體使用，以啟用受保護中繼式系統設定的編輯功能。本產生器可依據系統 ID 重現源自 BatLabs 的舊版格式。系統金鑰與無線電通訊加密金鑰不同，本身並不授予無線電網路的存取權。

## 如何使用本產生器

1. 輸入由 1–4 位十六進位數字（`0–9`、`A–F`）組成的系統 ID，不含 `0x` 前綴。可使用小寫字母，較短的 ID 會在開頭補零：`ab` 會變成 `00AB`。
2. 檢查正規化 ID、檔案名稱及十六進位預覽。
3. 下載二進位 `.KEY` 檔案，並在相容的舊版寫頻軟體中載入。檔案大小為 27 位元組；系統 ID `1234` 會產生 `SYS01234.KEY`。

## 相容性限制

本工具遵循已公開的舊版格式；相容性取決於寫頻軟體。不支援 ASTRO 25 Portable CPS（包括 XTS5000）、APX CPS 或 Advanced System Keys（ASK）。即使位元組格式符合參考格式，也不代表已驗證與特定無線電或 CPS 版本的相容性。

## 隱私權

產生、驗證及檔案預覽皆在您的瀏覽器本機端執行。您的系統 ID 與產生的金鑰不會傳送至伺服器。
