## Что такое системный ключ Motorola старого формата?

Программный системный ключ — это файл `.KEY`, который совместимое программное обеспечение Motorola для программирования радиостанций использует для редактирования защищённых настроек транкинговой системы. Этот генератор воспроизводит старый формат на основе BatLabs для заданного ID системы. Системный ключ отличается от ключа шифрования радиотрафика и сам по себе не предоставляет доступ к радиосети.

## Как пользоваться генератором

1. Введите ID системы, используя 1–4 шестнадцатеричные цифры (`0–9`, `A–F`), без префикса `0x`. Допускаются строчные буквы, а короткие ID дополняются нулями слева: `ab` превращается в `00AB`.
2. Проверьте нормализованный ID, имя файла и шестнадцатеричный предпросмотр.
3. Скачайте двоичный файл `.KEY` и загрузите его в совместимое ПО для программирования старых радиостанций. Размер файла — 27 байт; для ID системы `1234` создаётся файл `SYS01234.KEY`.

## Ограничения совместимости

Этот инструмент использует опубликованный старый формат; совместимость зависит от ПО для программирования. Он не поддерживает ASTRO 25 Portable CPS (включая XTS5000), APX CPS и Advanced System Keys (ASK). Соответствие байтов эталонному формату не подтверждает совместимость с конкретной радиостанцией или версией CPS.

## Конфиденциальность

Создание, проверка и предпросмотр файлов выполняются локально в браузере. ID системы и созданный ключ не отправляются на сервер.
