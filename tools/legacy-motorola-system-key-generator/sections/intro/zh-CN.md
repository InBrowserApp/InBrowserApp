## 旧版 Motorola 系统密钥是什么？

软件系统密钥是一种 `.KEY` 文件，供兼容的 Motorola 编程软件使用，用于启用对受保护的集群系统设置的编辑功能。此生成器根据系统 ID，生成源自 BatLabs 的旧版格式密钥。系统密钥不同于无线电通信加密密钥，其本身并不授予无线电网络的访问权限。

## 如何使用此生成器

1. 输入由 1–4 位十六进制数字（`0–9`、`A–F`）组成的系统 ID，不要包含 `0x` 前缀。支持小写字母，较短的 ID 会在前面补零：`ab` 会变为 `00AB`。
2. 检查规范化 ID、文件名和十六进制预览。
3. 下载二进制 `.KEY` 文件，并将其加载到兼容的旧版编程软件中。文件大小为 27 字节；系统 ID `1234` 会生成 `SYS01234.KEY`。

## 兼容性限制

此工具遵循已公开的旧版格式；兼容性取决于编程软件。它不支持 ASTRO 25 Portable CPS（包括 XTS5000）、APX CPS 或 Advanced System Keys（ASK）。符合参考实现的字节格式并不能确认与特定无线电设备或 CPS 版本的兼容性。

## 隐私

生成、验证和文件预览均在您的浏览器中本地运行。您的系统 ID 和生成的密钥不会发送到服务器。
