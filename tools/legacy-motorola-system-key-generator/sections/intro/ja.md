## 旧形式の Motorola システムキーとは？

ソフトウェアシステムキーは、対応する Motorola プログラミングソフトウェアで、保護されたトランキングシステム設定の編集を可能にする `.KEY` ファイルです。この生成ツールは BatLabs に基づく旧形式を再現し、システム ID に対応したキーを生成します。システムキーは無線通信の暗号化キーとは異なり、それだけで無線ネットワークへのアクセスが許可されるわけではありません。

## この生成ツールの使い方

1. 1–4 桁の16進数（`0–9`、`A–F`）で、接頭辞 `0x` を付けずにシステム ID を入力します。小文字も使用でき、短い ID には先頭にゼロが追加されます。たとえば、`ab` は `00AB` になります。
2. 正規化済み ID、ファイル名、16進数プレビューを確認します。
3. バイナリ形式の `.KEY` ファイルをダウンロードし、対応する旧型のプログラミングソフトウェアに読み込みます。ファイルサイズは 27 バイトです。システム ID が `1234` の場合、`SYS01234.KEY` が生成されます。

## 互換性の制限

このツールは公開された旧形式に従っており、互換性は使用するプログラミングソフトウェアによって異なります。ASTRO 25 Portable CPS（XTS5000 を含む）、APX CPS、Advanced System Keys（ASK）には対応していません。参照実装のバイト形式と一致していても、特定の無線機や CPS バージョンとの互換性が確認されたことにはなりません。

## プライバシー

生成、検証、ファイルのプレビューは、ブラウザー内でローカルに実行されます。システム ID と生成されたキーがサーバーに送信されることはありません。
