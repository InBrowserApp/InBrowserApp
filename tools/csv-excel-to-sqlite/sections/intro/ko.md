## 스프레드시트를 SQLite 데이터베이스로 변환하기

CSV 또는 Excel 파일(.xlsx, .xls)을 한 개 이상 추가하세요. CSV 파일 하나와 데이터가 있는 Excel 워크시트 하나는 각각 별도의 테이블이 되며, 모든 테이블은 하나의 데이터베이스에 저장됩니다. 미리보기에서 열을 확인하고 테이블 이름을 바꾼 뒤 **SQLite 데이터베이스 만들기**를 선택하세요. 변환은 브라우저에서 이루어지며 파일은 기기에 그대로 남습니다.

## 스프레드시트 데이터가 테이블로 변환되는 방식

기본적으로 첫 행의 값이 열 이름이 됩니다. 첫 행에도 데이터가 들어 있다면 해당 테이블에서 **첫 행을 열 이름으로 사용**을 끄세요. 첫 행은 데이터로 가져오고, 열 이름은 `column_1`과 같은 형식으로 자동 생성됩니다. 테이블 이름이나 열 이름이 중복되면 뒤에 숫자가 붙으므로 이름이 같은 파일을 추가해도 테이블이 따로 유지됩니다.

변환기는 숫자 열을 자동으로 감지하면서 `00123` 같은 텍스트 식별자의 앞자리 0을 그대로 보존합니다. 빈 셀은 SQL의 `NULL` 값으로 저장됩니다. Excel의 날짜는 ISO 형식의 날짜 또는 타임스탬프 텍스트로 저장되며, 수식이 있는 셀은 통합 문서에 저장된 계산 결과를 사용합니다. 결과를 갱신해야 한다면 Excel에서 수식을 다시 계산하고 통합 문서를 저장하세요.

## SQL로 변환 결과 조회하기

**SQLite 뷰어에서 열기**를 선택하면 테이블을 살펴보고 쿼리를 실행할 수 있습니다. `.sqlite` 데이터베이스를 다운로드해 SQLite 명령줄 도구, Python 또는 다른 SQLite 앱에서 열 수도 있습니다. 예를 들어 `orders.csv`와 `customers` 워크시트가 있는 Excel 통합 문서를 변환한 뒤 다음 쿼리로 고객별 주문 수를 확인할 수 있습니다.

```sql
SELECT customers.name, COUNT(*) AS order_count
FROM orders
JOIN customers ON customers.id = orders.customer_id
GROUP BY customers.id, customers.name;
```

이 예제를 수정할 때는 미리보기에 표시된 테이블 이름과 열 이름을 사용하세요.
