## แปลงสเปรดชีตเป็นฐานข้อมูล SQLite

เพิ่มไฟล์ CSV หรือ Excel (.xlsx หรือ .xls) ได้ตั้งแต่หนึ่งไฟล์ขึ้นไป ไฟล์ CSV แต่ละไฟล์และเวิร์กชีต Excel แต่ละแผ่นที่มีข้อมูลจะแปลงเป็นตารางแยกกันในฐานข้อมูลเดียว ดูตัวอย่างเพื่อตรวจคอลัมน์และเปลี่ยนชื่อตารางก่อนเลือก **สร้างฐานข้อมูล SQLite** การแปลงทำในเบราว์เซอร์และไฟล์จะอยู่ในอุปกรณ์ของคุณ

## วิธีแปลงข้อมูลจากสเปรดชีตเป็นตาราง

ระบบใช้แถวแรกเป็นชื่อคอลัมน์ตามค่าเริ่มต้น หากแถวแรกเป็นข้อมูล ให้ปิดตัวเลือก **ใช้แถวแรกเป็นชื่อคอลัมน์** สำหรับตารางนั้น ระบบจะนำเข้าแถวดังกล่าวเป็นข้อมูลและสร้างชื่อคอลัมน์ เช่น `column_1` หากชื่อตารางหรือคอลัมน์ซ้ำกัน ระบบจะเติมตัวเลขท้ายชื่อ จึงยังเก็บทั้งสองตารางไว้ได้เมื่อเพิ่มไฟล์ชื่อเดียวกัน

ตัวแปลงจะตรวจหาคอลัมน์ตัวเลขและเก็บเลขศูนย์นำหน้าในรหัสที่เป็นข้อความ เช่น `00123` เซลล์ว่างจะกลายเป็นค่า `NULL` ใน SQL วันที่ใน Excel จะเก็บเป็นข้อความในรูปแบบวันที่หรือวันและเวลาตามมาตรฐาน ISO ส่วนเซลล์ที่มีสูตรจะใช้ผลลัพธ์ที่บันทึกอยู่ในสมุดงาน หากต้องคำนวณผลลัพธ์ใหม่ ให้คำนวณและบันทึกสมุดงานใน Excel ก่อนนำเข้า

## ค้นข้อมูลในผลลัพธ์ด้วย SQL

เลือก **เปิดในโปรแกรมดู SQLite** เพื่อสำรวจตารางและรันคำสั่ง SQL หรือดาวน์โหลดฐานข้อมูล `.sqlite` ไปใช้กับเครื่องมือบรรทัดคำสั่ง SQLite, Python หรือแอป SQLite อื่นๆ ตัวอย่างเช่น แปลง `orders.csv` และสมุดงาน Excel ที่มีเวิร์กชีตชื่อ `customers` แล้วใช้คำสั่งนี้เพื่อนับจำนวนคำสั่งซื้อของลูกค้าแต่ละราย

```sql
SELECT customers.name, COUNT(*) AS order_count
FROM orders
JOIN customers ON customers.id = orders.customer_id
GROUP BY customers.id, customers.name;
```

เมื่อปรับตัวอย่างนี้ให้เข้ากับข้อมูลของคุณ ให้ใช้ชื่อตารางและชื่อคอลัมน์ที่แสดงในตัวอย่างตาราง
