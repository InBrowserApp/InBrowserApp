## המרת גיליונות אלקטרוניים למסד נתונים של SQLite

אפשר להוסיף קובץ אחד או יותר בפורמט CSV או Excel (עם הסיומת .xlsx או .xls). כל קובץ CSV וכל גיליון Excel שמכיל נתונים הופכים לטבלה נפרדת באותו מסד נתונים. בתצוגה המקדימה אפשר לבדוק את העמודות ולשנות את שמות הטבלאות לפני שבוחרים **יצירת מסד נתונים של SQLite**. ההמרה מתבצעת בדפדפן והקבצים נשארים במכשיר.

## איך נתוני הגיליון הופכים לטבלאות?

כברירת מחדל, השורה הראשונה משמשת לשמות העמודות. כדי לייבא את השורה הזו כשורת נתונים, יש לבטל את האפשרות **שימוש בשורה הראשונה לשמות העמודות** בטבלה הרצויה. לכל עמודה יינתן שם כמו `column_1`. סיומות מספריות מתווספות לשמות כפולים של טבלאות או עמודות, כך שאפשר להוסיף עוד קובץ באותו שם ולשמור את שתי הטבלאות.

הממיר מזהה עמודות מספריות ושומר על אפסים מובילים במזהים טקסטואליים כמו `00123`. תאים ריקים הופכים לערכי SQL מסוג `NULL`. תאריכי Excel נשמרים כטקסט בפורמט ISO של תאריך או חותמת זמן. בתאים שמכילים נוסחה מיובאת התוצאה השמורה בחוברת העבודה. אם צריך לחשב מחדש את תוצאות הנוסחאות, מומלץ לעשות זאת ב־Excel ולשמור את חוברת העבודה לפני ההמרה.

## שאילתות SQL על הנתונים שהומרו

באמצעות **פתיחה במציג SQLite** אפשר לעיין בטבלאות ולהריץ שאילתות. אפשר גם להוריד את מסד הנתונים בסיומת `.sqlite` ולהשתמש בו בשורת הפקודה של SQLite, ב־Python או ביישום אחר שתומך ב־SQLite. לדוגמה, אפשר להמיר את הקובץ `orders.csv` וחוברת Excel עם גיליון בשם `customers`, ואז להריץ שאילתה שסופרת הזמנות לפי לקוח.

```sql
SELECT customers.name, COUNT(*) AS order_count
FROM orders
JOIN customers ON customers.id = orders.customer_id
GROUP BY customers.id, customers.name;
```

כדי להתאים את הדוגמה לנתונים שלך, יש להשתמש בשמות הטבלאות והעמודות שמופיעים בתצוגה המקדימה.
