## Преобразование электронных таблиц в базу данных SQLite

Добавьте один или несколько файлов CSV или Excel (.xlsx или .xls). Каждый файл CSV и каждый лист Excel с данными станут отдельными таблицами в одной базе данных. Перед нажатием **Создать базу данных SQLite** проверьте столбцы в предпросмотре и при необходимости переименуйте таблицы. Преобразование выполняется в браузере, а файлы остаются на вашем устройстве.

## Как данные становятся таблицами

По умолчанию первая строка используется для имён столбцов. Отключите для таблицы параметр **Использовать первую строку как имена столбцов**, чтобы импортировать эту строку как данные и создать имена вида `column_1`. К повторяющимся именам таблиц или столбцов добавляются числовые суффиксы, поэтому при добавлении ещё одного файла с тем же именем сохраняются обе таблицы.

Конвертер распознаёт числовые столбцы и сохраняет начальные нули в текстовых идентификаторах, например `00123`. Пустые ячейки преобразуются в значения SQL `NULL`. Даты Excel сохраняются как текст в формате даты или отметки времени ISO, а для ячеек с формулами используются результаты, сохранённые в книге. Если отображаемые результаты нужно пересчитать, сначала сохраните книгу в Excel.

## Запросы к результату с помощью SQL

Нажмите **Открыть в «Просмотр SQLite»**, чтобы просмотреть таблицы и выполнить запрос, или скачайте базу данных `.sqlite` для работы с ней в командной строке SQLite, Python или другом приложении SQLite. Например, преобразуйте файл `orders.csv` и книгу Excel с листом `customers`, а затем выполните запрос для подсчёта заказов каждого клиента:

```sql
SELECT customers.name, COUNT(*) AS order_count
FROM orders
JOIN customers ON customers.id = orders.customer_id
GROUP BY customers.id, customers.name;
```

При адаптации примера используйте имена таблиц и столбцов из предпросмотра своих данных.
