## Editar los metadatos y cambiar la portada de un EPUB

Con este editor de metadatos EPUB puedes corregir el título o el autor de un libro, añadir una descripción que falte o cambiar la portada que aparece en tu biblioteca digital. Puedes editar el título, los autores, el código de idioma, la editorial, los temas y la descripción de libros en EPUB 2 y EPUB 3. Las aplicaciones de lectura utilizan estos datos para identificar, mostrar y organizar tus libros.

## Cómo editar un EPUB

1. Abre un EPUB o suéltalo en el editor. Los datos y la portada del libro aparecen automáticamente si están disponibles.
2. Actualiza los campos que necesites. Escribe cada autor o tema en una línea distinta. Para el idioma del libro, introduce un código como `en` para inglés o `pt-BR` para portugués de Brasil.
3. Para añadir o cambiar la portada, elige una imagen JPG o PNG. Comprueba la vista previa antes de descargar el libro. La imagen conserva sus proporciones.
4. Selecciona **Descargar EPUB editado** para guardar una copia nueva. Abre el archivo descargado en tu aplicación de lectura para ver los cambios.

## ¿Qué cambia en el EPUB descargado?

El editor actualiza los metadatos del paquete EPUB y la imagen de portada. Se conservan los capítulos, el índice y el orden de lectura. Si la portada original es JPG o PNG, las páginas que usan esa misma imagen también muestran la nueva. Si la portada tiene otro formato, tu biblioteca digital mostrará la imagen nueva y, si el EPUB tiene una página de portada independiente, esta conservará su ilustración original.

## Privacidad y compatibilidad de archivos

Tu navegador procesa el EPUB y la imagen de portada de forma local. Los archivos originales se quedan en tu dispositivo y el libro editado se descarga como un EPUB independiente. El editor es compatible con archivos EPUB 2 y EPUB 3 sin DRM.
