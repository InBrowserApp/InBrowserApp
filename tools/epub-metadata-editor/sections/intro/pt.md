## Edite os metadados e troque a capa de um EPUB

Use este editor de metadados de EPUB para corrigir o título ou o autor de um livro, acrescentar uma descrição que esteja faltando ou trocar a capa que aparece na sua biblioteca digital. Você pode editar o título, os autores, o código do idioma, a editora, os assuntos e a descrição de livros EPUB 2 e EPUB 3. Os aplicativos de leitura usam esses dados para identificar, exibir e organizar seus livros digitais.

## Como editar um EPUB

1. Abra um EPUB ou solte o arquivo no editor. Os dados e a capa do livro aparecem automaticamente quando estão disponíveis.
2. Atualize os campos que quiser. Digite cada autor ou assunto em sua própria linha. Para informar o idioma do livro, use um código como `en` para inglês ou `pt-BR` para português do Brasil.
3. Para adicionar ou trocar a capa, escolha uma imagem JPG ou PNG. Confira a prévia antes de baixar o livro. A imagem mantém suas proporções.
4. Selecione **Baixar EPUB editado** para salvar uma nova cópia. Abra o arquivo baixado no seu aplicativo de leitura para ver as alterações.

## O que muda no EPUB baixado?

O editor atualiza os metadados do pacote EPUB e a imagem da capa. Os capítulos, o sumário e a ordem de leitura são preservados. Se a capa atual for JPG ou PNG, as páginas que usam essa mesma imagem também passam a mostrar a nova capa. Para os demais formatos, a nova imagem aparece na sua biblioteca digital. Se o EPUB tiver uma página de capa separada, ela mantém a arte original.

## Privacidade e compatibilidade de arquivos

O navegador processa o EPUB e a imagem da capa localmente. Os arquivos originais ficam no seu dispositivo, e o livro editado é baixado como um EPUB separado. O editor funciona com arquivos EPUB 2 e EPUB 3 sem DRM.
