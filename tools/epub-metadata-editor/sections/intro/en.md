## Edit EPUB metadata and change the book cover

Use this EPUB metadata editor to correct a book title or author, add a missing description, or replace the cover shown in your ebook library. You can edit the title, authors, language code, publisher, subjects, and description in EPUB 2 and EPUB 3 books. These details help reading apps identify, display, and organize your ebooks.

## How to edit an EPUB

1. Open an EPUB or drop it into the editor. The current book details and cover appear automatically when available.
2. Update the fields you need. Put each author or subject on its own line. For the book language, enter a code such as `en` for English or `pt-BR` for Brazilian Portuguese.
3. To add or replace the book cover, choose a JPG or PNG. Check the preview before downloading. The image keeps its proportions.
4. Select **Download edited EPUB** to save a new copy. Open the downloaded file in your reading app to see the changes.

## What changes in the downloaded EPUB?

The editor updates the book’s package metadata and cover image. Chapters, the table of contents, and the reading order are preserved. If the existing cover is a JPG or PNG, pages that display the same image pick up the replacement too. With other cover formats, the new image becomes the cover used by ebook libraries, while any separate cover page keeps its original artwork.

## Privacy and file compatibility

Your EPUB and cover image are processed locally in your browser. The original files stay on your device, and the edited book downloads as a separate EPUB. The editor works with EPUB 2 and EPUB 3 files that are free of DRM.
