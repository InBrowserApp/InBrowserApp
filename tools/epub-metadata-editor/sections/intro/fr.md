## Modifier les métadonnées et la couverture d’un EPUB

Cet éditeur de métadonnées EPUB vous permet de corriger le titre ou l’auteur d’un livre, d’ajouter une description manquante ou de remplacer la couverture affichée dans votre bibliothèque numérique. Pour les livres EPUB 2 et EPUB 3, vous pouvez modifier le titre, les auteurs, le code de langue, l’éditeur, les sujets et la description. Les applications de lecture utilisent ces informations pour identifier, afficher et organiser vos livres numériques.

## Comment modifier un EPUB

1. Ouvrez un EPUB ou déposez-le dans l’éditeur. Les informations actuelles et la couverture du livre s’affichent automatiquement si elles sont disponibles.
2. Modifiez les champs souhaités. Saisissez un auteur ou un sujet par ligne. Indiquez la langue du livre avec un code tel que `en` pour l’anglais ou `pt-BR` pour le portugais du Brésil.
3. Pour ajouter ou remplacer une couverture, choisissez une image JPG ou PNG. Vérifiez l’aperçu avant de télécharger le livre. L’image conserve ses proportions.
4. Sélectionnez **Télécharger l’EPUB modifié** pour enregistrer une nouvelle copie. Ouvrez le fichier téléchargé dans votre application de lecture pour voir les modifications.

## Qu’est-ce qui change dans l’EPUB téléchargé ?

L’éditeur met à jour les métadonnées du paquet EPUB et l’image de couverture. Les chapitres, la table des matières et l’ordre de lecture sont conservés. Si l’ancienne couverture est au format JPG ou PNG, les pages qui utilisent cette image affichent aussi la nouvelle. Pour les autres formats, la nouvelle image s’affiche dans votre bibliothèque numérique. Une éventuelle page de couverture distincte conserve son illustration d’origine.

## Confidentialité et compatibilité des fichiers

Votre navigateur traite l’EPUB et l’image de couverture en local. Les fichiers d’origine restent sur votre appareil et le livre modifié se télécharge dans un fichier EPUB distinct. L’éditeur prend en charge les fichiers EPUB 2 et EPUB 3 sans DRM.
