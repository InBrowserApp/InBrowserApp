## glTF モデルを単一の GLB に変換する

**ファイルを開く** を選び、`.gltf` モデルとその `.bin` バッファー、テクスチャを一緒に選択します。テクスチャがサブフォルダーにある場合は **フォルダーを開く** を使用すると、モデル内のパスに従ってファイルを読み取れます。データがすでに埋め込まれた glTF ファイルにも対応しています。**サンプルを試す** でアニメーション付きのピラミッドをまとめ、**GLB をダウンロード** を選択します。ファイルはブラウザー内で処理されます。

## 不足しているバッファーやテクスチャを追加する

`.gltf` の JSON ファイルは `model.bin` や `textures/albedo.png` などのアセットを参照することがあります。変換ツールは不足しているパスを表示します。**ファイルを追加** を選ぶと、モデルを開いたまま不足ファイルを指定できます。元のファイル名は保持してください。異なるフォルダーに同じ名前のファイルがある場合は、モデルと参照ファイルを含むフォルダーを選び、それぞれのパスを読み取れるようにしてください。

## GLB を共有して確認する

GLB にはモデルが参照する形状、対応するテクスチャ、その他の標準データが埋め込まれます。メッシュ、マテリアル、アニメーションクリップも引き継がれます。まとめる際に元のテクスチャのエンコードとメッシュの圧縮方式が保持されるため、利用先がそれらに対応している必要があります。PNG と JPEG のテクスチャは幅広い glTF ソフトで利用できます。ダウンロードしたファイルを単独で [GLB / glTF ビューアー](../gltf-viewer/)で開き、寸法、マテリアル、アニメーションを確認できます。[glTF 2.0 ファイル形式](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)
