## 如何使用瀏覽器序列終端機

使用資料傳輸線連接 Arduino、ESP32、Raspberry Pi Pico 或 USB 序列埠轉接器。設定裝置使用的鮑率，例如 9600 或 115200，然後選取**連線**，並在瀏覽器中選擇其連接埠。此序列監視器使用 8 個資料位元、無同位檢查、1 個停止位元，且不使用流量控制（8N1）。

## 傳送文字和十六進位位元組

文字以 UTF-8 傳送。如果裝置使用換行字元來送出指令，請選擇 LF、CR 或 CR + LF。若要傳送二進位指令，請選取**十六進位**並輸入完整的位元組，例如 `41 54 0D 0A`。十六進位模式會依輸入內容傳送位元組，不會自動附加換行字元。

## 讀取及儲存序列記錄

記錄會顯示接收（RX）和傳送（TX）的資料及其時間戳記。文字顯示為亂碼時，可切換至十六進位模式檢視個別位元組。資料持續接收時，可暫停捲動以查看較早的記錄，或將保留的記錄下載為文字檔。序列資料會留在此分頁中，直到你選擇儲存為止。

## 為什麼無法連接裝置？

請使用支援 Web Serial 的最新瀏覽器，並確認作業系統能辨識序列埠。試用另一條傳輸線，並關閉已在使用該連接埠的其他序列監視器。如果裝置已連線但輸出的文字無法閱讀，請檢查鮑率，並嘗試以十六進位模式查看位元組。
