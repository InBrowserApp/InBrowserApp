## Kompilasi file Typst menjadi PDF

Pilih atau letakkan file .typ berisi teks UTF-8. Dokumen dikompilasi di browser Anda menggunakan font bawaan. Lihat pratinjau halaman, lalu pilih Unduh PDF untuk menyimpan salinan dengan nama file sumber dan ekstensi .pdf. Mengganti atau menutup dokumen akan membatalkan proses yang belum selesai serta melepaskan pratinjau dan unduhannya.

## Tinjau hasilnya

Konverter ini menggunakan Typst 0.14.2 dengan Libertinus Serif, New Computer Modern, dan DejaVu Sans Mono. Versi bahasa dan pilihan font lain dapat mengubah hasil. Font yang tidak tersedia mungkin diganti, dan beberapa karakter, termasuk teks CJK dan emoji, mungkin tidak muncul. Periksa persamaan dan simbol penting dalam pratinjau. Kesalahan dan peringatan sumber menyertakan baris dan kolom jika tersedia; pesan terperinci dari mesin ditampilkan dalam bahasa Inggris. Jika kompilasi gagal, PDF lama tidak akan tetap tersedia untuk diunduh.

## Mandiri dan lokal

Hanya file sumber yang dipilih yang tersedia. Paket yang diimpor, gambar terpisah, data, dan file sumber lain tidak dapat dimuat. Gunakan dokumen mandiri atau kompilasi proyek dengan banyak file di lingkungan penulisan aslinya. Sumber Anda tidak diunggah, tidak diperlukan akun, dan tidak ada batas tetap untuk ukuran file atau jumlah halaman. Dokumen besar tetap dapat melampaui sumber daya browser. Penampil Typst juga menyediakan unduhan PDF saat Anda sedang membaca dokumen.
