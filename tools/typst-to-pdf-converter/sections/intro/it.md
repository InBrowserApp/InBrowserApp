## Compila un file Typst in PDF

Seleziona o trascina un file .typ in UTF-8. Il documento viene compilato nel browser usando i font inclusi. Visualizza l’anteprima delle pagine, poi scegli Scarica PDF per salvare una copia con il nome del file sorgente e l’estensione .pdf. Sostituendo o chiudendo il documento, le operazioni in corso vengono annullate e l’anteprima e il file da scaricare vengono rilasciati.

## Controlla il risultato

Il convertitore usa Typst 0.14.2 con Libertinus Serif, New Computer Modern e DejaVu Sans Mono. Altre versioni del linguaggio o scelte di font possono cambiare il risultato. I font mancanti possono essere sostituiti e alcuni caratteri, inclusi testo CJK ed emoji, potrebbero essere assenti. Controlla le equazioni e i simboli importanti nell’anteprima. Gli errori e gli avvisi del sorgente includono riga e colonna quando disponibili; i messaggi dettagliati del motore sono mostrati in inglese. Se la compilazione non riesce, nessun PDF precedente rimane disponibile per il download.

## Documenti autonomi e locali

È disponibile solo il file sorgente selezionato. Non è possibile caricare pacchetti importati, immagini separate, dati e altri file sorgente. Usa un documento autonomo oppure compila un progetto con più file nel suo ambiente di creazione originale. Il sorgente non viene caricato, non serve un account e non ci sono limiti fissi alla dimensione dei file o al numero di pagine. I documenti di grandi dimensioni possono comunque superare le risorse del browser. Anche il Visualizzatore Typst consente di scaricare il PDF mentre leggi un documento.
