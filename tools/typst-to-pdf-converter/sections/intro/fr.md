## Compiler un fichier Typst en PDF

Sélectionnez ou déposez un fichier .typ encodé en UTF-8. Le document est compilé dans votre navigateur avec les polices fournies. Prévisualisez les pages, puis choisissez Télécharger le PDF pour enregistrer une copie portant le nom du fichier source et l’extension .pdf. Remplacer ou fermer le document annule le travail en cours et supprime l’aperçu et le fichier proposé au téléchargement.

## Vérifier le résultat

Le convertisseur utilise Typst 0.14.2 avec Libertinus Serif, New Computer Modern et DejaVu Sans Mono. D’autres versions du langage et choix de polices peuvent modifier le résultat. Les polices manquantes peuvent être remplacées et certains caractères, dont les textes CJK et les emoji, peuvent être absents. Vérifiez les équations et symboles importants dans l’aperçu. Les erreurs et avertissements du code source indiquent une ligne et une colonne lorsque ces informations sont disponibles ; les messages détaillés du moteur sont affichés en anglais. En cas d’échec de la compilation, aucun ancien PDF ne reste disponible au téléchargement.

## Autonome et local

Seul le fichier source sélectionné est disponible. Les paquets importés, les images séparées, les données et les autres fichiers source ne peuvent pas être chargés. Utilisez un document autonome ou compilez un projet composé de plusieurs fichiers dans son environnement de création d’origine. Votre code source n’est pas envoyé, aucun compte n’est nécessaire et aucune limite fixe n’est imposée à la taille des fichiers ou au nombre de pages. Les documents volumineux peuvent néanmoins dépasser les ressources du navigateur. La visionneuse Typst propose également le téléchargement PDF lorsque vous consultez déjà un document.
