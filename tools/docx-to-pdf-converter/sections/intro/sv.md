## Konvertera Word-dokument till PDF

Öppna eller släpp en lokal DOCX-, DOCM-, DOTX- eller DOTM-fil. Vänta på konverteringen, granska PDF-förhandsvisningen och ladda ner resultatet. Bläddra mellan sidor, justera zoom eller använd fokuserad förhandsvisning för att kontrollera stycken, tabeller, sidhuvuden, sidfötter, bilder och ekvationer. Resultatet använder dokumentets sidstorlekar och stående eller liggande orientering.

## Utseende och kompatibilitet

PDF-filen innehåller bildsidor som renderas med 150 DPI och vit bakgrund. Det går inte att markera eller söka i texten, och ingen OCR läggs till. Webbläsaren utformar dokumentets layout med det innehåll som stöds och de teckensnitt som finns tillgängliga; sidantal, radbrytningar, teckensnittens utseende och komplex grafik kan skilja sig från Word. Jämför förhandsvisningen med originalet innan du förlitar dig på exporten.

Dokumentets slutliga version visas: infogad text visas och borttagen text döljs. Granskningskommentarer utelämnas. Fält för sidnummer och datum kan uppdateras när layouten skapas, så kontrollera deras värden. Makron körs aldrig. Hyperlänkar, formulärens interaktiva beteende och digitala signaturer bevaras eller verifieras inte. Lösenordsskyddade filer, saknade dokumentresurser och upptäckt innehåll som inte stöds stoppar konverteringen utan att någon ofullständig PDF-fil kan laddas ner. Komplexa dokument kan behöva exporteras från det ursprungliga Office-programmet.

## Lokal bearbetning

Filerna stannar i den här webbläsaren. Konverteraren hämtar inte dokumentresurser eller teckensnitt från nätet. Om du byter fil, avbryter konverteringen eller stänger filen tas det föregående resultatet bort och bearbetningsresurserna frigörs. Det finns ingen fast gräns för filstorlek eller sidantal; resursgränserna för arkiv, bilder, ritytor och webbläsarens minne gäller fortfarande.

Öppna [DOCX-visare](../docx-viewer/) för att granska originalfilen. Använd [Konverterare från DOCX till Markdown](../docx-to-markdown-converter/) för att få redigerbar text och struktur.
