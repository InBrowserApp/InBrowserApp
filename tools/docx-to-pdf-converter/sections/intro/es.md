## Convierte documentos de Word a PDF

Abre o suelta un archivo DOCX, DOCM, DOTX o DOTM local. Espera a que termine la conversión, revisa la vista previa del PDF y descarga el resultado. Navega por las páginas, ajusta el zoom o usa el modo de enfoque para comprobar párrafos, tablas, encabezados, pies de página, imágenes y ecuaciones. El resultado usa los tamaños de página y la orientación vertical u horizontal del documento.

## Aspecto y compatibilidad

El PDF contiene páginas de imágenes representadas a 150 DPI, con fondo blanco. El texto no se puede seleccionar ni buscar, y no se añade OCR. El navegador compone el documento con el contenido compatible y las fuentes disponibles; el número de páginas, los saltos de línea, el aspecto de las fuentes y los gráficos complejos pueden diferir de Word. Compara la vista previa con el original antes de confiar en la exportación.

Se usa la vista final del documento: se muestra el texto insertado y se oculta el texto eliminado. Se omiten los comentarios de revisión. Los campos de página y fecha pueden actualizarse durante la maquetación, así que comprueba sus valores. Las macros nunca se ejecutan. No se conservan ni se verifican los hipervínculos, el comportamiento interactivo de los formularios ni las firmas digitales. Los archivos protegidos con contraseña, los recursos del documento ausentes y el contenido no compatible detectado detienen la conversión sin ofrecer un PDF parcial para descargar. Los documentos complejos pueden requerir la exportación desde su aplicación de Office original.

## Procesamiento local

Los archivos permanecen en este navegador. El conversor no obtiene recursos del documento ni fuentes de forma remota. Al reemplazar o cerrar el archivo, o cancelar la conversión, se elimina el resultado anterior y se liberan sus recursos de procesamiento. No hay una cuota fija de tamaño de archivo ni de número de páginas; siguen aplicándose los límites de recursos para archivos comprimidos, imágenes, lienzos y memoria del navegador.

Para revisar el archivo original, abre el [Visor de DOCX](../docx-viewer/). Para obtener texto y estructura editables, usa el [Conversor de DOCX a Markdown](../docx-to-markdown-converter/).
