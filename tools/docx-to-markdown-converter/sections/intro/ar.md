## تحويل مستند Word إلى Markdown

اختر ملف .docx أو .docm أو .dotx أو .dotm محليًا أو أفلته هنا. اقرأ نص Markdown الناتج أو انسخه أو نزّل ملف .md بترميز UTF-8 يحمل اسم الملف الأصلي. يؤدي استبدال المستند أو إغلاقه إلى إلغاء التحويل غير المكتمل ومسح المخرجات السابقة. يتيح عارض DOCX أيضًا تصدير المستند المفتوح إلى Markdown.

## الاحتفاظ بالنص والبنية المفيدين

تحتفظ العناوين والفقرات والتنسيقات الأساسية لإبراز النص والقوائم والجداول والروابط ببنية مفيدة. تُضاف محارف إفلات إلى رموز Markdown في نص المستند. تحتفظ الحواشي السفلية والختامية والتعليقات بإحالاتها حيثما تتوفر، مع وضع محتواها في أقسام منفصلة. تُجمع الرؤوس والتذييلات أيضًا بشكل منفصل. قد تعرض تطبيقات Markdown المختلفة الحواشي السفلية والمراسي وفواصل الأسطر في الجداول بطرق مختلفة.

لا يعيد Markdown إنتاج تخطيط صفحات Word أو خطوطه أو ترتيب القراءة الدقيق. تُستبدل الصور والمخططات والمعادلات والأشكال غير المدعومة بعلامات تشير إلى استبعادها؛ ويُحتفظ بالنص المتاح داخل الأشكال. تُبسَّط الخلايا المدمجة والجداول المتداخلة، ويُضاف إلى الجداول التي لا تحتوي على صف رؤوس صف رؤوس فارغ بصيغة Markdown. تُزال علامات التغييرات المتعقبة مع الاحتفاظ بالنص النهائي المتاح. تستخدم الحقول نصها المحفوظ. قارن المحتوى المهم بالأصل.

## المعالجة المحلية والتوافق

يبقى ملفك في المتصفح ولا ترفعه هذه الأداة أو تحفظه. لا تُشغَّل وحدات الماكرو ولا تُحمَّل الموارد الخارجية. الملفات المحمية بكلمة مرور وملفات .doc القديمة والمستندات التي لا تحتوي إلا على صور دون نص قابل للاستخراج غير مدعومة. لا يوجد حد ثابت لحجم الملف أو عدد الصفحات، لكن المستندات المعقدة قد تتجاوز موارد المتصفح. تصدّر هذه الأداة النص؛ ولا تعدّل المستند الأصلي أو تحوّل الصور الممسوحة ضوئيًا إلى نص.
