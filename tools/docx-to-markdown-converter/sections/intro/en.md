## Convert a Word document to Markdown

Select or drop a local .docx, .docm, .dotx, or .dotm file. Read the generated Markdown, copy it, or download a UTF-8 .md file with the original filename. Replacing or closing the document cancels unfinished conversion and clears the previous output. The DOCX Viewer also offers Markdown export for an open document.

## Keep useful text and structure

Headings, paragraphs, basic emphasis, lists, tables, and links retain useful structure. Markdown punctuation in document text is escaped. Footnotes, endnotes, and comments keep references where available, with their content in separate sections. Headers and footers are also collected separately. Different Markdown applications may render footnotes, anchors, and table line breaks differently.

Markdown does not reproduce Word page layout, fonts, or exact reading order. Images, charts, equations, and unsupported shapes use omission markers; text available inside shapes is kept. Merged cells and nested tables are simplified, and tables without a header receive an empty Markdown header. Tracked-change markup is removed, keeping available final text. Fields use their saved text. Review important content against the original.

## Local processing and compatibility

Your file stays in the browser and is not uploaded or saved by this tool. Macros do not run, and external resources are not loaded. Password-protected files, legacy .doc files, and image-only documents without extractable text are unsupported. There is no fixed file-size or page-count quota, though complex documents can exceed browser resources. This tool exports text; it does not edit the original document or convert scanned images to text.
