## Converti un documento Word in Markdown

Seleziona o trascina un file .docx, .docm, .dotx o .dotm locale. Leggi il Markdown generato, copialo o scarica un file .md in UTF-8 con il nome del file originale. Sostituire o chiudere il documento annulla la conversione non completata e cancella il risultato precedente. Anche il visualizzatore DOCX offre l’esportazione in Markdown per un documento aperto.

## Conserva testo e struttura utili

Titoli, paragrafi, formattazioni di enfasi di base, elenchi, tabelle e collegamenti mantengono una struttura utile. I caratteri di punteggiatura Markdown nel testo del documento vengono protetti con caratteri di escape. Le note a piè di pagina, le note di chiusura e i commenti mantengono i riferimenti quando disponibili, con il contenuto in sezioni separate. Anche le intestazioni e i piè di pagina vengono raccolti separatamente. Applicazioni Markdown diverse possono visualizzare in modo diverso le note a piè di pagina, le ancore e le interruzioni di riga nelle tabelle.

Markdown non riproduce il layout delle pagine di Word, i caratteri o l’ordine di lettura esatto. Immagini, grafici, equazioni e forme non supportate vengono sostituiti da indicatori di omissione; il testo disponibile all’interno delle forme viene conservato. Le celle unite e le tabelle annidate vengono semplificate e le tabelle senza intestazione ricevono un’intestazione Markdown vuota. I contrassegni delle revisioni vengono rimossi, mantenendo il testo finale disponibile. I campi usano il testo salvato. Confronta i contenuti importanti con l’originale.

## Elaborazione locale e compatibilità

Il file resta nel browser e non viene caricato su un server né salvato da questo strumento. Le macro non vengono eseguite e le risorse esterne non vengono caricate. I file protetti da password, i vecchi file .doc e i documenti composti solo da immagini senza testo estraibile non sono supportati. Non esiste un limite fisso per la dimensione dei file o il numero di pagine, ma i documenti complessi possono superare le risorse del browser. Questo strumento esporta testo; non modifica il documento originale né converte immagini scansionate in testo.
