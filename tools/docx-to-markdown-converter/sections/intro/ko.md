## Word 문서를 Markdown으로 변환하기

기기에 있는 .docx, .docm, .dotx 또는 .dotm 파일을 선택하거나 끌어다 놓으세요. 생성된 Markdown을 읽거나 복사하거나 원래 파일 이름을 사용하는 UTF-8 .md 파일로 다운로드할 수 있습니다. 문서를 바꾸거나 닫으면 완료되지 않은 변환이 취소되고 이전 결과가 지워집니다. DOCX 뷰어에서도 열려 있는 문서를 Markdown으로 내보낼 수 있습니다.

## 유용한 텍스트와 구조 유지하기

제목, 문단, 기본 강조 서식, 목록, 표, 링크는 유용한 구조를 유지합니다. 문서 텍스트의 Markdown 문장 부호는 이스케이프 처리됩니다. 각주, 미주, 메모는 참조가 있으면 유지하며, 내용은 별도 섹션에 표시됩니다. 머리글과 바닥글도 따로 모아 표시됩니다. Markdown 애플리케이션에 따라 각주, 앵커, 표 안의 줄 바꿈이 다르게 표시될 수 있습니다.

Markdown은 Word의 페이지 레이아웃, 글꼴, 정확한 읽기 순서를 재현하지 않습니다. 이미지, 차트, 수식, 지원하지 않는 도형은 생략 표시로 대체되며, 도형 안에 있는 텍스트는 가져올 수 있는 경우 유지됩니다. 병합된 셀과 중첩된 표는 단순화되고, 머리글이 없는 표에는 빈 Markdown 머리글 행이 추가됩니다. 변경 내용 추적 표시는 제거되고 사용 가능한 최종 텍스트는 유지됩니다. 필드에는 저장된 텍스트가 사용됩니다. 중요한 내용은 원본과 비교해 확인하세요.

## 기기 내 처리 및 호환성

파일은 브라우저 안에만 머무르며 이 도구가 업로드하거나 저장하지 않습니다. 매크로를 실행하지 않으며 외부 리소스를 불러오지 않습니다. 암호로 보호된 파일, 이전 형식의 .doc 파일, 추출할 수 있는 텍스트 없이 이미지로만 이루어진 문서는 지원하지 않습니다. 파일 크기나 페이지 수에 고정된 제한은 없지만, 복잡한 문서는 브라우저 리소스를 초과할 수 있습니다. 이 도구는 텍스트를 내보내며, 원본 문서를 편집하거나 스캔한 이미지를 텍스트로 변환하지 않습니다.
