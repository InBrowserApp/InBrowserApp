## Convierte un documento de Word a Markdown

Selecciona o suelta un archivo .docx, .docm, .dotx o .dotm local. Lee el Markdown generado, cópialo o descarga un archivo .md en UTF-8 con el nombre original. Al reemplazar o cerrar el documento, se cancela cualquier conversión en curso y se borra el resultado anterior. El Visor de DOCX también permite exportar a Markdown un documento abierto.

## Conserva el texto y la estructura útiles

Los títulos, párrafos, formatos básicos de énfasis, listas, tablas y enlaces conservan una estructura útil. Los signos de puntuación de Markdown que aparecen en el texto del documento se escapan. Las notas al pie, notas al final y comentarios conservan sus referencias cuando están disponibles, con su contenido en secciones separadas. Los encabezados y pies de página también se recopilan por separado. Las distintas aplicaciones de Markdown pueden mostrar las notas al pie, anclajes y saltos de línea en tablas de forma diferente.

Markdown no reproduce el diseño de página, las fuentes ni el orden exacto de lectura de Word. Las imágenes, gráficos, ecuaciones y formas no compatibles usan marcadores de omisión; se conserva el texto disponible dentro de las formas. Las celdas combinadas y las tablas anidadas se simplifican, y las tablas sin encabezado reciben uno vacío en Markdown. Se eliminan las marcas de control de cambios y se conserva el texto final disponible. Los campos usan su texto guardado. Compara el contenido importante con el original.

## Procesamiento local y compatibilidad

Tu archivo permanece en el navegador y esta herramienta no lo sube ni lo guarda. No se ejecutan macros ni se cargan recursos externos. No se admiten archivos protegidos con contraseña, archivos .doc antiguos ni documentos que solo contengan imágenes sin texto extraíble. No hay un límite fijo de tamaño de archivo ni de número de páginas, aunque los documentos complejos pueden superar los recursos del navegador. Esta herramienta exporta texto; no edita el documento original ni convierte imágenes escaneadas en texto.
