## Konversi dokumen Word ke Markdown

Pilih atau letakkan file .docx, .docm, .dotx, atau .dotm lokal. Baca Markdown yang dihasilkan, salin, atau unduh file .md berformat UTF-8 dengan nama file asli. Mengganti atau menutup dokumen membatalkan konversi yang belum selesai dan menghapus hasil sebelumnya. Penampil DOCX juga menyediakan ekspor Markdown untuk dokumen yang sedang dibuka.

## Pertahankan teks dan struktur yang berguna

Judul, paragraf, penekanan dasar, daftar, tabel, dan tautan mempertahankan struktur yang berguna. Tanda baca Markdown dalam teks dokumen diberi karakter pelolos. Catatan kaki, catatan akhir, dan komentar mempertahankan referensi jika tersedia, dengan kontennya di bagian terpisah. Header dan footer juga dikumpulkan secara terpisah. Aplikasi Markdown yang berbeda dapat menampilkan catatan kaki, jangkar, dan pemisah baris dalam tabel dengan cara yang berbeda.

Markdown tidak mereproduksi tata letak halaman Word, font, atau urutan baca secara persis. Gambar, bagan, persamaan, dan bentuk yang tidak didukung diganti dengan penanda bahwa konten tidak disertakan; teks yang tersedia di dalam bentuk tetap dipertahankan. Sel gabungan dan tabel bersarang disederhanakan, dan tabel tanpa baris header diberi baris header Markdown kosong. Penanda pelacakan perubahan dihapus, dengan tetap mempertahankan teks akhir yang tersedia. Bidang menggunakan teks yang tersimpan. Bandingkan konten penting dengan dokumen asli.

## Pemrosesan lokal dan kompatibilitas

File Anda tetap berada di browser dan tidak diunggah atau disimpan oleh alat ini. Makro tidak dijalankan dan sumber daya eksternal tidak dimuat. File yang dilindungi kata sandi, file .doc lama, dan dokumen yang hanya berisi gambar tanpa teks yang dapat diekstrak tidak didukung. Tidak ada batas tetap untuk ukuran file atau jumlah halaman, meskipun dokumen kompleks dapat melebihi sumber daya browser. Alat ini mengekspor teks; alat ini tidak mengedit dokumen asli atau mengubah gambar hasil pindai menjadi teks.
