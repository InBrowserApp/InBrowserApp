## แปลงเอกสาร Word เป็น Markdown

เลือกหรือวางไฟล์ .docx, .docm, .dotx หรือ .dotm จากเครื่อง อ่าน Markdown ที่สร้างขึ้น คัดลอก หรือดาวน์โหลดไฟล์ .md แบบ UTF-8 ที่ใช้ชื่อไฟล์เดิม การเปลี่ยนหรือปิดเอกสารจะยกเลิกการแปลงที่ยังไม่เสร็จและล้างผลลัพธ์ก่อนหน้า โปรแกรมดู DOCX ยังรองรับการส่งออกเอกสารที่เปิดอยู่เป็น Markdown ด้วย

## เก็บข้อความและโครงสร้างที่มีประโยชน์

หัวเรื่อง ย่อหน้า การเน้นข้อความพื้นฐาน รายการ ตาราง และลิงก์จะคงโครงสร้างที่มีประโยชน์ไว้ เครื่องหมายวรรคตอนของ Markdown ในข้อความเอกสารจะถูกใส่อักขระหลีก เชิงอรรถ อ้างอิงท้ายเรื่อง และความคิดเห็นจะเก็บการอ้างอิงไว้เมื่อมี โดยแยกเนื้อหาไว้ในแต่ละส่วน หัวกระดาษและท้ายกระดาษจะถูกรวบรวมแยกไว้เช่นกัน แอป Markdown แต่ละแอปอาจแสดงเชิงอรรถ จุดยึด และการขึ้นบรรทัดใหม่ในตารางแตกต่างกัน

Markdown ไม่สามารถจำลองเค้าโครงหน้า แบบอักษร หรือลำดับการอ่านที่ตรงกับ Word ทุกประการได้ รูปภาพ แผนภูมิ สมการ และรูปร่างที่ไม่รองรับจะใช้เครื่องหมายระบุว่าเนื้อหาถูกละไว้ โดยยังเก็บข้อความที่มีอยู่ภายในรูปร่าง เซลล์ที่ผสานและตารางซ้อนกันจะถูกลดความซับซ้อน ส่วนตารางที่ไม่มีแถวหัวตารางจะได้รับแถวหัวตาราง Markdown ว่าง เครื่องหมายติดตามการเปลี่ยนแปลงจะถูกนำออก โดยเก็บข้อความฉบับสุดท้ายที่มีอยู่ เขตข้อมูลใช้ข้อความที่บันทึกไว้ ตรวจสอบเนื้อหาสำคัญเทียบกับต้นฉบับ

## การประมวลผลในเครื่องและความเข้ากันได้

ไฟล์ของคุณอยู่ในเบราว์เซอร์ โดยเครื่องมือนี้จะไม่อัปโหลดหรือบันทึกไฟล์ ไม่มีการเรียกใช้แมโครหรือโหลดทรัพยากรจากภายนอก ไม่รองรับไฟล์ที่ป้องกันด้วยรหัสผ่าน ไฟล์ .doc รุ่นเก่า และเอกสารที่มีแต่รูปภาพโดยไม่มีข้อความที่ดึงออกมาได้ ไม่มีขีดจำกัดตายตัวสำหรับขนาดไฟล์หรือจำนวนหน้า แต่เอกสารที่ซับซ้อนอาจใช้ทรัพยากรเกินกว่าที่เบราว์เซอร์มีให้ เครื่องมือนี้ส่งออกข้อความ โดยไม่แก้ไขเอกสารต้นฉบับหรือแปลงรูปภาพที่สแกนเป็นข้อความ
