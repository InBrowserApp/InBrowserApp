## 将 Word 文档转换为 Markdown

选择或拖放本地 .docx、.docm、.dotx 或 .dotm 文件。查看生成的 Markdown，复制文本，或下载沿用原文件名的 UTF-8 .md 文件。更换或关闭文档会取消尚未完成的转换，并清除之前的输出。DOCX 查看器也支持将已打开的文档导出为 Markdown。

## 保留实用的文本和结构

标题、段落、基本强调格式、列表、表格和链接会保留实用的结构。文档文本中的 Markdown 标点符号会进行转义。脚注、尾注和批注会在可用时保留引用，其内容分别列于独立章节。页眉和页脚也会单独汇总。不同的 Markdown 应用对脚注、锚点和表格内换行的显示方式可能有所不同。

Markdown 无法重现 Word 的页面布局、字体或精确的阅读顺序。图片、图表、公式和不受支持的形状会以省略标记表示；形状中可提取的文本会保留。合并单元格和嵌套表格会被简化，没有表头的表格会添加空的 Markdown 表头。修订标记会被移除，并保留可提取的最终文本。域使用其已保存的文本。请对照原文核查重要内容。

## 本地处理与兼容性

文件始终留在浏览器中，本工具不会上传或保存文件。宏不会运行，外部资源也不会加载。不支持受密码保护的文件、旧版 .doc 文件，以及没有可提取文本的纯图片文档。文件大小和页数没有固定限制，但复杂文档可能超出浏览器的资源容量。本工具用于导出文本，不会编辑原始文档，也不会将扫描图片转为文字。
