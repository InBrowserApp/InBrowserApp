## 將 Word 文件轉換為 Markdown

選擇或拖放本機的 .docx、.docm、.dotx 或 .dotm 檔案。閱讀產生的 Markdown、複製內容，或下載使用原始檔名的 UTF-8 .md 檔案。更換或關閉文件會取消尚未完成的轉換，並清除先前的輸出。DOCX 檢視器也提供已開啟文件的 Markdown 匯出功能。

## 保留實用的文字與結構

標題、段落、基本強調格式、清單、表格與連結會保留實用的結構。文件文字中的 Markdown 標點符號會進行跳脫處理。註腳、章節附註與註解會盡可能保留參照，並將內容置於各自的區段。頁首與頁尾也會分別彙整。不同的 Markdown 應用程式可能會以不同方式呈現註腳、錨點與表格中的換行。

Markdown 不會重現 Word 的頁面版面配置、字型或精確的閱讀順序。圖片、圖表、方程式與不支援的圖形會以省略標記代替；圖形內可取得的文字會保留。合併儲存格與巢狀表格會簡化，沒有標題列的表格會加入空白的 Markdown 標題列。追蹤修訂標記會移除，並保留可取得的最終文字。欄位使用已儲存的文字。請將重要內容與原始文件核對。

## 本機處理與相容性

您的檔案會留在瀏覽器中，本工具不會上傳或儲存檔案。不會執行巨集，也不會載入外部資源。不支援受密碼保護的檔案、舊版 .doc 檔案，以及僅包含圖片且沒有可擷取文字的文件。檔案大小與頁數沒有固定上限，但複雜文件仍可能超過瀏覽器可用的資源。本工具會匯出文字，不會編輯原始文件，也不會將掃描圖片轉換為文字。
