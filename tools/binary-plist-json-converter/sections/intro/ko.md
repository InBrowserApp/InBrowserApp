## 바이너리 Plist 파일을 JSON으로 변환하기

**바이너리 Plist 열기**를 선택하거나 Apple 바이너리 `.plist` 파일을 끌어다 놓으세요. 보기 좋게 정리된 JSON을 확인하고 복사하거나 `.json` 파일로 다운로드할 수 있습니다. 바이너리 속성 목록은 `bplist00`으로 시작하며 Apple 앱 번들, 환경설정, 아카이브 데이터에 사용됩니다. 예제를 사용하면 속성 목록의 값이 JSON에 어떻게 표시되는지 확인할 수 있습니다.

## JSON을 Apple 바이너리 속성 목록으로 변환하기

**JSON을 Plist로**를 선택하고 JSON을 붙여넣거나 `.json` 파일을 연 뒤 **바이너리 Plist로 변환**을 선택하세요. 생성된 `.plist` 파일을 다운로드할 수 있습니다. 문자열, 불리언, 숫자, 배열, 객체는 각각 대응하는 속성 목록 타입으로 변환됩니다. `null`은 다른 값으로 바꾸거나 해당 키를 제거하세요. 파일과 붙여넣은 텍스트는 브라우저에서 처리됩니다.

## 날짜, 바이트 데이터, 큰 정수 보존하기

JSON에는 날짜, 바이트 데이터, 키 기반 아카이브의 UID를 위한 기본 타입이 없습니다. 변환기는 `$plist` 태그로 타입을 명시해 양방향 변환에서도 값의 의미를 보존합니다.

| Plist 값                        | JSON 예제                                              |
| ------------------------------- | ------------------------------------------------------ |
| UTC 날짜                        | `{"$plist":"date","value":"2025-01-01T00:00:00.000Z"}` |
| Base64로 인코딩된 바이트 데이터 | `{"$plist":"data","value":"AQID"}`                     |
| 10진수 문자열로 표현한 큰 정수  | `{"$plist":"integer","value":"9007199254740993"}`      |
| 키 기반 아카이브의 UID          | `{"$plist":"uid","value":42}`                          |
| 값이 큰 실수                    | `{"$plist":"real","value":"1e+100"}`                   |

Plist로 되돌릴 때 태그를 유지하세요. JSON의 안전한 정수 범위를 벗어나는 값은 정수 태그를 사용하고 10진수 값을 따옴표로 감싸세요. 태그와 구조가 같은 딕셔너리는 키를 보존하기 위해 `dictionary` 태그로 감쌉니다. 변환 시 데이터 구조와 지원되는 값은 보존됩니다. Plist 객체 순서, `1.0`처럼 정수와 값이 같은 실수의 숫자 타입, 원본 바이너리 데이터는 바뀔 수 있습니다.
