## המרת קובץ Plist בינארי ל־JSON

בחרו **פתיחת Plist בינארי** או גררו קובץ `.plist` בינארי של Apple. עיינו בפלט ה־JSON המסודר, העתיקו אותו או הורידו אותו כקובץ `.json`. רשימות מאפיינים בינאריות מתחילות בחתימה `bplist00` ומשמשות בחבילות אפליקציות של Apple, בקובצי העדפות ובנתונים בארכיון. הדוגמה מראה כיצד הערכים ברשימת מאפיינים מופיעים ב־JSON.

## המרת JSON לרשימת מאפיינים בינארית של Apple

בחרו **המרת JSON ל־Plist**, הדביקו JSON או פתחו קובץ `.json`, ואז בחרו **המרה ל־Plist בינארי**. הורידו את קובץ ה־`.plist` שנוצר. מחרוזות, ערכים בוליאניים, מספרים, מערכים ואובייקטים מומרים לסוגים המקבילים ברשימת המאפיינים. החליפו את `null` בערך אחר או השמיטו את המפתח שלו. הקבצים והטקסט שהדבקתם מעובדים בדפדפן.

## שימור תאריכים, בתים ומספרים שלמים גדולים

ב־JSON אין סוגים מובנים לתאריכים, לנתוני בתים או למזהי UID של ארכיונים מבוססי מפתחות. הממיר משתמש בתגי `$plist` מפורשים כדי לשמר את המשמעות של ערכים אלה בהמרה לשני הכיוונים.

| ערך Plist                       | דוגמת JSON                                             |
| ------------------------------- | ------------------------------------------------------ |
| תאריך לפי UTC                   | `{"$plist":"date","value":"2025-01-01T00:00:00.000Z"}` |
| בתים בקידוד Base64              | `{"$plist":"data","value":"AQID"}`                     |
| מספר שלם גדול כמחרוזת עשרונית   | `{"$plist":"integer","value":"9007199254740993"}`      |
| מזהה UID של ארכיון מבוסס מפתחות | `{"$plist":"uid","value":42}`                          |
| מספר ממשי גדול                  | `{"$plist":"real","value":"1e+100"}`                   |

השאירו את התגים בהמרה חזרה ל־Plist. למספרים שלמים מחוץ לטווח הבטוח של JSON, כתבו את המספר העשרוני במירכאות עם תג המספר השלם. מילון שמבנהו זהה למבנה של תג נעטף בתג `dictionary` כדי לשמור על המפתחות שלו. ההמרה שומרת על המבנה ועל הערכים הנתמכים. סדר האובייקטים ב־Plist, הטיפוס המספרי של מספרים ממשיים שערכם שלם, כמו `1.0`, והבתים הבינאריים המקוריים עשויים להשתנות.
