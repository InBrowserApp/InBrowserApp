## Как преобразовать бинарный Plist в JSON

Выберите **Открыть бинарный Plist** или перетащите бинарный файл Apple `.plist`. Проверьте отформатированный JSON, скопируйте его или скачайте как файл `.json`. Бинарные списки свойств начинаются с сигнатуры `bplist00` и встречаются в пакетах приложений Apple, настройках и архивных данных. Пример показывает, как значения списка свойств выглядят в JSON.

## Как преобразовать JSON в бинарный список свойств Apple

Выберите **JSON в Plist**, вставьте JSON или откройте файл `.json`, затем выберите **Преобразовать в бинарный Plist**. Скачайте полученный файл `.plist`. Строки, логические значения, числа, массивы и объекты преобразуются в соответствующие типы списка свойств. Замените `null` другим значением или уберите его ключ. Файлы и вставленный текст обрабатываются в браузере.

## Как сохранить даты, байты и большие целые числа

В JSON нет собственных типов для дат, байтовых данных и UID в архивах с ключами. Конвертер использует метки `$plist`, чтобы сохранить смысл этих значений при преобразовании в обе стороны.

| Значение Plist                               | Пример JSON                                            |
| -------------------------------------------- | ------------------------------------------------------ |
| Дата в UTC                                   | `{"$plist":"date","value":"2025-01-01T00:00:00.000Z"}` |
| Байты в Base64                               | `{"$plist":"data","value":"AQID"}`                     |
| Большое целое число в виде десятичной строки | `{"$plist":"integer","value":"9007199254740993"}`      |
| UID в архиве с ключами                       | `{"$plist":"uid","value":42}`                          |

Сохраняйте метки при обратном преобразовании в Plist. Для числа за пределами безопасного диапазона целых чисел JSON используйте метку целого числа и укажите десятичное значение в кавычках. Если структура словаря совпадает со структурой метки, он оборачивается в метку `dictionary`, чтобы сохранить ключи. Преобразование сохраняет структуру и поддерживаемые значения. Порядок объектов Plist, число байтов для хранения чисел и исходные двоичные данные могут измениться.
