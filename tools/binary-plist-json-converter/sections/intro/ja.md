## バイナリ Plist ファイルを JSON に変換する

**バイナリ Plist を開く**を選ぶか、Apple のバイナリ `.plist` ファイルをドラッグ＆ドロップします。整形済みの JSON を確認し、コピーするか `.json` ファイルとしてダウンロードできます。バイナリ形式のプロパティリストは `bplist00` で始まり、Apple のアプリバンドル、環境設定、アーカイブデータなどに含まれています。サンプルを試すと、プロパティリストの値が JSON でどのように表されるか確認できます。

## JSON を Apple のバイナリ形式のプロパティリストに変換する

**JSON から Plist** を選び、JSON を貼り付けるか `.json` ファイルを開いて、**バイナリ Plist に変換**を選びます。変換した `.plist` ファイルをダウンロードしてください。文字列、真偽値、数値、配列、オブジェクトはそれぞれ対応するプロパティリストの型に変換されます。`null` は別の値に置き換えるか、対応するキーを省略してください。ファイルと貼り付けたテキストはブラウザー内で処理されます。

## 日付、バイトデータ、大きな整数を保持する

JSON には日付、バイトデータ、キー付きアーカイブの UID に対応する組み込みの型がありません。このツールでは、どちらの方向に変換しても値の意味が失われないよう、`$plist` タグで型を明示します。

| Plist の値                          | JSON の例                                              |
| ----------------------------------- | ------------------------------------------------------ |
| UTC の日付                          | `{"$plist":"date","value":"2025-01-01T00:00:00.000Z"}` |
| Base64 で表現したバイトデータ       | `{"$plist":"data","value":"AQID"}`                     |
| 10 進数の文字列で表現した大きな整数 | `{"$plist":"integer","value":"9007199254740993"}`      |
| キー付きアーカイブの UID            | `{"$plist":"uid","value":42}`                          |
| 大きな実数                          | `{"$plist":"real","value":"1e+100"}`                   |

Plist に戻すときはタグを残してください。JSON で安全に表現できる整数の範囲を超える値には、整数タグを使い、10 進数の値を引用符で囲みます。型タグと同じ構造の辞書には `dictionary` タグを付けてキーを保持します。変換ではデータ構造と対応する値を保持します。Plist オブジェクトの順序や`1.0` など整数と同じ値を持つ実数の数値型、元のバイナリデータは変わる場合があります。

[Apple のプロパティリストの構造と型](https://developer.apple.com/library/archive/documentation/CoreFoundation/Conceptual/CFPropertyLists/CFPropertyLists.html)
