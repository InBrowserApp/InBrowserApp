## تحويل ملف Plist ثنائي إلى JSON

اختر **فتح ملف Plist ثنائي** أو أفلت ملف `.plist` ثنائيًا من Apple. راجع ناتج JSON المنسّق، ثم انسخه أو نزّله على هيئة ملف `.json`. تبدأ قوائم الخصائص الثنائية بالتوقيع `bplist00`، وتُستخدم في حزم تطبيقات Apple وملفات التفضيلات والبيانات المؤرشفة. يوضّح المثال كيف تظهر قيم قائمة الخصائص في JSON.

## تحويل JSON إلى قائمة خصائص ثنائية من Apple

اختر **تحويل JSON إلى Plist**، ثم ألصق JSON أو افتح ملف `.json` واختر **تحويل إلى Plist ثنائي**. نزّل ملف `.plist` الناتج. تتحوّل النصوص والقيم المنطقية والأعداد والمصفوفات والكائنات إلى أنواعها المقابلة في قائمة الخصائص. استبدل `null` بقيمة أو احذف مفتاحها. تُعالَج الملفات والنصوص الملصقة في متصفحك.

## الحفاظ على التواريخ والبايتات والأعداد الصحيحة الكبيرة

لا يوفّر JSON أنواعًا أصلية للتواريخ أو بيانات البايت أو معرّفات UID في الأرشيفات ذات المفاتيح. يستخدم المحوّل وسوم `$plist` صريحةً للحفاظ على معنى هذه القيم عند التحويل في الاتجاهين.

| قيمة Plist                          | مثال JSON                                              |
| ----------------------------------- | ------------------------------------------------------ |
| تاريخ بالتوقيت العالمي المنسّق (UTC) | `{"$plist":"date","value":"2025-01-01T00:00:00.000Z"}` |
| بايتات بترميز Base64                | `{"$plist":"data","value":"AQID"}`                     |
| عدد صحيح كبير على هيئة نص عشري      | `{"$plist":"integer","value":"9007199254740993"}`      |
| معرّف UID في أرشيف ذي مفاتيح         | `{"$plist":"uid","value":42}`                          |

احتفظ بالوسوم عند التحويل مجددًا إلى Plist. للقيم التي تقع خارج نطاق الأعداد الصحيحة الآمن في JSON، استخدم قيمةً عشرية بين علامتي اقتباس مع وسم العدد الصحيح. إذا اتخذ قاموس صيغة أحد الوسوم، يُغلَّف بوسم `dictionary` للحفاظ على مفاتيحه. يحافظ التحويل على البنية والقيم المدعومة. قد يتغيّر ترتيب كائنات Plist أو عدد البايتات المخصّصة لتخزين الأعداد أو البايتات الثنائية الأصلية.
