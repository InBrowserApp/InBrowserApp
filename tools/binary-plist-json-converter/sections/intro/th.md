## แปลงไฟล์ Plist ไบนารีเป็น JSON

เลือก **เปิด Plist ไบนารี** หรือลากไฟล์ `.plist` ไบนารีของ Apple มาวาง ตรวจดู JSON ที่จัดรูปแบบแล้ว จากนั้นคัดลอกหรือดาวน์โหลดเป็นไฟล์ `.json` รายการคุณสมบัติแบบไบนารีขึ้นต้นด้วย `bplist00` และพบได้ในชุดไฟล์แอปของ Apple ค่ากำหนด และข้อมูลที่จัดเก็บถาวร ลองใช้ตัวอย่างเพื่อดูว่าค่าในรายการคุณสมบัติแสดงใน JSON อย่างไร

## แปลง JSON เป็นรายการคุณสมบัติแบบไบนารีของ Apple

เลือก **JSON เป็น Plist** วาง JSON หรือเปิดไฟล์ `.json` แล้วเลือก **แปลงเป็น Plist ไบนารี** จากนั้นดาวน์โหลดไฟล์ `.plist` ที่ได้ สตริง ค่าบูลีน ตัวเลข อาร์เรย์ และออบเจ็กต์จะถูกแปลงเป็นชนิดข้อมูลที่ตรงกันในรายการคุณสมบัติ เปลี่ยน `null` เป็นค่าอื่นหรือลบคีย์ที่เกี่ยวข้อง เบราว์เซอร์จะประมวลผลไฟล์และข้อความที่วางบนอุปกรณ์ของคุณ

## เก็บวันที่ ข้อมูลไบต์ และจำนวนเต็มขนาดใหญ่ไว้

JSON ไม่มีชนิดข้อมูลในตัวสำหรับวันที่ ข้อมูลไบต์ หรือ UID ในข้อมูลที่จัดเก็บแบบใช้คีย์ โปรแกรมใช้แท็ก `$plist` ระบุชนิดข้อมูลเพื่อรักษาความหมายของค่าเมื่อแปลงทั้งสองทิศทาง

| ค่า Plist                          | ตัวอย่าง JSON                                            |
| --------------------------------- | ------------------------------------------------------ |
| วันที่ในเขตเวลา UTC                  | `{"$plist":"date","value":"2025-01-01T00:00:00.000Z"}` |
| ข้อมูลไบต์ที่เข้ารหัส Base64             | `{"$plist":"data","value":"AQID"}`                     |
| จำนวนเต็มขนาดใหญ่ในรูปข้อความเลขฐานสิบ | `{"$plist":"integer","value":"9007199254740993"}`      |
| UID ในข้อมูลที่จัดเก็บแบบใช้คีย์           | `{"$plist":"uid","value":42}`                          |

เก็บแท็กไว้เมื่อแปลงกลับเป็น Plist ถ้าจำนวนเต็มอยู่นอกช่วงที่ JSON เก็บได้อย่างแม่นยำ ให้ใช้แท็กจำนวนเต็มและใส่ค่าเลขฐานสิบไว้ในเครื่องหมายอัญประกาศ หากดิกชันนารีมีโครงสร้างเหมือนแท็ก โปรแกรมจะครอบด้วยแท็ก `dictionary` เพื่อเก็บคีย์เดิม การแปลงจะรักษาโครงสร้างและค่าที่รองรับ ส่วนลำดับออบเจ็กต์ใน Plist จำนวนบิตที่ใช้เก็บตัวเลข และข้อมูลไบนารีเดิมอาจเปลี่ยนได้
