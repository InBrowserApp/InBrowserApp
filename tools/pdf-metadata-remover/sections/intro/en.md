## How to remove metadata from a PDF

1. Choose a PDF from your device or drop it into the file area.
2. Select **Remove metadata** to clear the document properties and document-level XMP metadata.
3. Download the new PDF. The original file stays on your device.

The tool runs in your browser and works without uploading your document.

## Which PDF metadata is removed?

A PDF can store details such as its title, author, subject, keywords, creation and modification dates, and the software that created it. These details can appear in a PDF reader’s **Document Properties**. The tool removes standard and custom document properties, the document’s XMP metadata packet, and the PDF file identifiers. It writes a fresh PDF so the removed entries do not remain in earlier revisions of the downloaded file.

Use it before posting a PDF publicly, sending a draft to a client, or sharing a document whose properties still show an old author name or an internal project title.

## Does metadata removal change the PDF pages?

The page text, images, links, bookmarks, form fields, and comments stay in the PDF. Names written on a page, comment authors, attachments, and metadata inside embedded images can still contain personal details. Use a PDF redaction tool to remove sensitive page content. Rewriting a PDF can invalidate digital signatures, so keep the original signed file.

## How can I check the downloaded PDF?

Open the new copy in a PDF reader and look under **Document Properties**. The original title, author, and other cleared fields should be gone. Some readers show the filename when the title field is empty. If you edit or export the PDF again, the editing app may add new metadata.
