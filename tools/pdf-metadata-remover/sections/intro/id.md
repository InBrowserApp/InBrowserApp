## Cara menghapus metadata dari PDF

1. Pilih PDF dari perangkat Anda atau seret dan lepas ke area pemilihan file.
2. Pilih **Hapus metadata** untuk menghapus properti dokumen dan metadata XMP pada tingkat dokumen.
3. Unduh PDF baru. File asli tetap ada di perangkat Anda.

Alat ini berjalan di browser Anda tanpa mengunggah dokumen.

## Metadata PDF apa saja yang dihapus?

PDF dapat menyimpan judul, nama penulis, subjek, kata kunci, tanggal pembuatan dan perubahan, serta nama perangkat lunak yang membuatnya. Informasi ini dapat muncul di menu **Properti Dokumen** pada penampil PDF. Alat ini menghapus properti dokumen standar dan kustom, paket metadata XMP dokumen, serta pengenal file PDF. Alat ini membuat PDF baru agar data yang dihapus tidak tertinggal dalam revisi lama di file unduhan.

Gunakan alat ini sebelum memublikasikan PDF, mengirim draf ke klien, atau membagikan dokumen yang propertinya masih mencantumkan nama penulis lama atau judul proyek internal.

## Apakah penghapusan metadata mengubah halaman PDF?

Teks halaman, gambar, tautan, markah buku, kolom formulir, dan komentar tetap ada di PDF. Nama yang tertulis di halaman, nama pemberi komentar, lampiran, dan metadata gambar yang disematkan masih bisa memuat informasi pribadi. Gunakan alat PDF khusus untuk menghapus konten sensitif secara permanen dari halaman. Penulisan ulang PDF dapat membuat tanda tangan digital tidak valid, jadi simpan file asli yang sudah ditandatangani.

## Bagaimana cara memeriksa PDF yang diunduh?

Buka salinan baru di penampil PDF dan lihat **Properti Dokumen**. Judul, nama penulis, dan properti lain yang dihapus seharusnya sudah hilang. Sebagian penampil menampilkan nama file jika kolom judul kosong. Jika PDF diedit atau diekspor kembali, aplikasi penyunting bisa menambahkan metadata baru.
