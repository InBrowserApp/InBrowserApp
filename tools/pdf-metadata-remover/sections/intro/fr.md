## Comment supprimer les métadonnées d’un PDF ?

1. Choisissez un PDF sur votre appareil ou déposez-le dans la zone prévue.
2. Sélectionnez **Supprimer les métadonnées** pour effacer les propriétés du document et ses métadonnées XMP.
3. Téléchargez le nouveau PDF. Le fichier d’origine reste sur votre appareil.

Le traitement se fait dans votre navigateur, sans envoi du document.

## Quelles métadonnées du PDF sont supprimées ?

Un PDF peut contenir un titre, un nom d’auteur, un sujet, des mots-clés, des dates de création et de modification ou encore le nom du logiciel qui l’a créé. Ces informations peuvent s’afficher dans les **Propriétés du document** de votre lecteur PDF. L’outil efface les propriétés standard et personnalisées, le bloc de métadonnées XMP du document ainsi que les identifiants du fichier PDF. Il réécrit le fichier pour que les données effacées ne subsistent pas dans les anciennes révisions du PDF téléchargé.

Vous pouvez utiliser cet outil avant de publier un PDF, d’envoyer un brouillon à un client ou de partager un document dont les propriétés affichent encore le nom d’un ancien auteur ou un titre de projet interne.

## La suppression des métadonnées modifie-t-elle les pages du PDF ?

Le texte des pages, les images, les liens, les signets, les champs de formulaire et les commentaires restent dans le PDF. Des informations personnelles peuvent encore figurer sur les pages, dans les noms des auteurs des commentaires, dans les pièces jointes ou dans les métadonnées des images incorporées. Pour retirer du contenu sensible des pages, utilisez un outil de caviardage PDF. La réécriture d’un PDF peut invalider ses signatures numériques. Conservez le fichier signé d’origine.

## Comment vérifier le PDF téléchargé ?

Ouvrez la nouvelle copie dans un lecteur PDF et consultez les **Propriétés du document**. Le titre, l’auteur et les autres champs effacés ne devraient plus contenir leurs valeurs d’origine. Certains lecteurs affichent le nom du fichier lorsque le champ du titre est vide. Si vous modifiez ou exportez de nouveau le PDF, le logiciel utilisé peut ajouter de nouvelles métadonnées.
