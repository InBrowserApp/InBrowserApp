## Putar file MIDI di browser

Pilih **Buka file MIDI** atau seret dan lepas file `.mid` atau `.midi`. Pilih **Coba contoh** untuk memuat karya pendek dengan dua trek. Tekan **Putar** untuk mendengarkan file dengan instrumen General MIDI bawaan. Pada pemutaran pertama, suara instrumen mungkin perlu waktu untuk dimuat. Pemutar mendukung MIDI standar format 0 atau 1 dengan pengaturan tick per ketukan. Pemutaran berlangsung di browser Anda.

## Lompat ke bagian tertentu, ubah kecepatan, dan ulangi

Seret penggeser **Posisi pemutaran** untuk melompat ke bagian tertentu. Gunakan tombol panah pada keyboard untuk bergeser sedikit demi sedikit. Kurangi **Kecepatan pemutaran** saat berlatih sebuah frasa. Tinggi nada tetap sama. Aktifkan **Ulangi pemutaran** untuk memutar seluruh file berulang kali, atau pilih **Kembali ke awal** untuk mengulang dari awal.

## Dengarkan trek satu per satu

Pilih **Bisukan** di samping trek untuk mendengarkan trek lain tanpa suaranya. Pilih **Aktifkan suara** untuk mendengarkan trek tersebut kembali. Ini juga berlaku untuk trek terpisah yang menggunakan kanal MIDI yang sama. Pilihan trek dan kecepatan pemutaran berlaku selama sesi ini. Untuk menyimpan rekaman yang bisa dibagikan atau diputar di pemutar audio biasa, gunakan [Konverter MIDI ke WAV](/id/tools/midi-to-wav-converter/).
