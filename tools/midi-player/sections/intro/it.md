## Riprodurre un file MIDI nel browser

Seleziona **Apri file MIDI** o trascina un file `.mid` o `.midi`. **Prova un esempio** carica un breve brano con due tracce. Premi **Riproduci** per ascoltare il file con gli strumenti General MIDI integrati. La prima riproduzione può richiedere qualche istante mentre vengono caricati i suoni. Il lettore accetta file MIDI standard in formato 0 o 1 con risoluzione in impulsi per semiminima (PPQ). La riproduzione avviene nel browser.

## Spostarsi, variare la velocità e riprodurre in loop

Trascina il cursore di **Posizione di riproduzione** per raggiungere un passaggio o usa i tasti freccia per spostarti a piccoli passi. Riduci la **Velocità di riproduzione** per esercitarti su una frase musicale. Le note mantengono la stessa altezza. Attiva **Riproduci in loop** per ripetere l’intero file oppure seleziona **Torna all’inizio** per ricominciare.

## Ascoltare le singole tracce

Usa **Silenzia** accanto a una traccia per ascoltare solo le altre, poi seleziona **Riattiva audio** per tornare a sentirla. Funziona anche con tracce separate che usano lo stesso canale MIDI. La selezione delle tracce e la velocità valgono per la sessione in corso. Per salvare un file audio da condividere o riprodurre in un normale lettore audio, usa il [Convertitore da MIDI a WAV](/it/tools/midi-to-wav-converter/).
