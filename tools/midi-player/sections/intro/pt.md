## Como reproduzir um arquivo MIDI no navegador

Selecione **Abrir arquivo MIDI** ou solte um arquivo `.mid` ou `.midi`. **Experimentar um exemplo** carrega uma peça curta com duas faixas. Pressione **Reproduzir** para ouvir o arquivo com os instrumentos General MIDI integrados. A primeira reprodução pode levar alguns instantes enquanto os sons são carregados. O reprodutor aceita arquivos MIDI padrão no formato 0 ou 1 com resolução em pulsos por semínima (PPQ). A reprodução acontece no navegador.

## Como navegar, mudar a velocidade e repetir em loop

Arraste o controle de **Posição da reprodução** para pular para um trecho ou use as teclas de seta para avançar ou voltar em pequenos passos. Diminua a **Velocidade de reprodução** para praticar uma frase musical. As notas mantêm a mesma altura. Ative **Repetir em loop** para repetir o arquivo inteiro ou selecione **Voltar ao início** para recomeçar.

## Como ouvir faixas separadamente

Use **Silenciar** ao lado de uma faixa para ouvir apenas as outras. Depois, selecione **Reativar som** para voltar a ouvi-la. Isso também funciona para faixas separadas que usam o mesmo canal MIDI. A seleção de faixas e a velocidade de reprodução valem para esta sessão. Para salvar um áudio que você possa compartilhar ou ouvir em um reprodutor comum, use o [Conversor de MIDI para WAV](/pt/tools/midi-to-wav-converter/).
