## Generera en lista med exempel på telefonnummer

Välj land eller region och nummerformat, ange antal och klicka på **Generera**. Kopiera resultaten till ett formulär eller ladda ner en UTF-8-kodad textfil med ett nummer per rad. Använd numren för att testa inmatningsmasker i formulär, fylla en lista med exempelkontakter eller kontrollera hur din app lagrar och visar telefonnummer.

## Nationellt och internationellt format

**Nationellt** använder ett format från Faker.js för det valda landet. Ett amerikanskt nummer kan till exempel se ut som `(202) 555-0100` och ett brittiskt nummer som `07700 900123`. **Internationellt (E.164)** skriver ut plustecknet, landskoden och resten av siffrorna utan mellanslag, som i `+12025550100` eller `+447700900123`.

## Behåll plustecknet och inledande nollor

Lagra telefonnummer som text i kalkylblad och databaser. Om ett kalkylblad importerar `07700 900123` eller `+447700900123` som ett tal kan den inledande nollan eller plustecknet försvinna. Använd exempelnumren för att testa formatet. När du testar samtal eller sms kan du använda ett testnummer som du själv har tillgång till.
