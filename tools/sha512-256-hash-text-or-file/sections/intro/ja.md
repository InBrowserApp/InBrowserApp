## SHA-512/256（FIPS 180-4）とは

SHA-512/256（FIPS 180-4）はSHA-2暗号学的ハッシュ関数で、256ビット（32バイト）のダイジェストを出力します。通常は64文字の16進数文字列で表します。初期値を変更したSHA-512を基に出力を切り詰め、SHA-512の内部構造を保ちながら短いダイジェストを生成します。

**主な特徴：**

- **決定的**：同じ入力から常に同じハッシュが得られます
- **高速**：入力をすばやく計算できます
- **アバランチ効果**：入力のわずかな変化で出力が大きく変わります
- **不可逆**：ハッシュから元の入力を復元することは計算上きわめて困難です
- **衝突耐性**：同じハッシュになる異なる入力を見つけるのは非常に困難です

**主な用途：**

- デジタル署名と証明書
- 整合性検査とチェックサム
- HMACの構成
- ファイル検証とデータ処理パイプライン
- 256ビットハッシュを必要とするプロトコル
