## IPFS-Datei per CID oder Link herunterladen

Fügen Sie eine CID, eine `ipfs://`-URI oder die URL eines IPFS-Gateways ein und wählen Sie **Inhalt öffnen**. Verweist die Adresse auf eine Datei, wählen Sie **Datei herunterladen**, um sie zu speichern. Mit einem Pfad hinter der CID kann ein Link direkt eine Datei oder einen Unterordner öffnen.

## Ganzen IPFS-Ordner als ZIP herunterladen

Öffnen Sie einen Ordner, um seine Einträge zu durchsuchen. Wählen Sie anschließend **ZIP herunterladen**, um den Ordner samt Unterordnern zu speichern. Die Pfade bleiben im ZIP-Archiv erhalten. Falls einige Pfade nicht abgerufen werden können, listet das Tool sie auf. Sie können den ZIP-Download erneut versuchen oder **Verfügbare Dateien herunterladen** wählen, um den abgerufenen Teil zu speichern.

## Wie der Browser IPFS-Inhalte abruft

Der Browser fragt die benötigten Blöcke bei öffentlichen IPFS-Gateways ab und prüft sie anhand ihrer CIDs, bevor er sie verwendet. Eine CID kennzeichnet einen Inhalt. Der Abruf setzt außerdem voraus, dass die Gateways die Peers erreichen, die diese Blöcke bereitstellen. Ist ein Ordner zu groß, um ihn auf Ihrem Gerät zu packen, öffnen Sie einen Unterordner oder laden Sie die Dateien einzeln herunter. [IPFS-Dokumentation zum Abruf von Inhalten](https://docs.ipfs.tech/quickstart/retrieve/)
