## Scarica un file IPFS tramite CID o link

Incolla un CID, un URI `ipfs://` o un URL di un gateway IPFS e seleziona **Apri contenuto**. Se l’indirizzo punta a un file, scegli **Scarica file** per salvarlo. Un link con un percorso dopo il CID può aprire un file specifico o una sottocartella.

## Scarica un’intera cartella IPFS come ZIP

Apri una cartella per esplorarne gli elementi, quindi scegli **Scarica ZIP** per salvare la cartella e le sue sottocartelle. Lo ZIP ne conserva i percorsi. Se alcuni percorsi non vengono scaricati, lo strumento li elenca. Puoi riprovare a creare lo ZIP oppure usare **Scarica i file disponibili** per salvare la parte recuperata.

## Come il browser recupera i contenuti IPFS

Il browser richiede i blocchi necessari ai gateway IPFS pubblici e li verifica rispetto ai rispettivi CID prima di usarli. Un CID identifica un contenuto. Il recupero dipende anche dalla capacità dei gateway di raggiungere i peer che forniscono quei blocchi. Se una cartella è troppo grande perché il dispositivo possa impacchettarla, apri una sottocartella o scarica singoli file. [Documentazione IPFS sul recupero dei contenuti](https://docs.ipfs.tech/quickstart/retrieve/)
