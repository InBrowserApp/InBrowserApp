## CID 또는 링크로 IPFS 파일 다운로드하기

CID, `ipfs://` URI 또는 IPFS 게이트웨이 URL을 붙여넣고 **콘텐츠 열기**를 누르세요. 주소가 파일을 가리키면 **파일 다운로드**를 눌러 저장하세요. CID 뒤에 경로가 붙은 링크로 특정 파일이나 하위 폴더를 바로 열 수 있습니다.

## IPFS 폴더 전체를 ZIP으로 다운로드하기

폴더를 열면 안에 있는 항목을 둘러볼 수 있습니다. **ZIP 다운로드**를 누르면 해당 폴더와 하위 폴더를 원래 경로 그대로 저장합니다. 일부 경로에서 다운로드에 실패하면 도구에서 해당 경로를 목록으로 표시합니다. ZIP 다운로드를 다시 시도하거나 **가져온 파일 다운로드**를 눌러 이미 가져온 부분을 저장할 수 있습니다.

## 브라우저에서 IPFS 콘텐츠를 가져오는 방식

브라우저는 공개 IPFS 게이트웨이에 필요한 블록을 요청하고, 사용하기 전에 각 블록을 해당 CID와 대조합니다. CID는 콘텐츠를 식별하며, 콘텐츠를 가져올 수 있는지는 게이트웨이가 해당 블록을 제공하는 피어에 연결할 수 있는지에도 달려 있습니다. 기기에서 ZIP으로 묶기에 폴더가 너무 크다면 하위 폴더를 열거나 파일을 개별적으로 다운로드하세요. [IPFS 콘텐츠 가져오기 문서](https://docs.ipfs.tech/quickstart/retrieve/)
