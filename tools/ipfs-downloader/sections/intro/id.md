## Unduh file IPFS dengan CID atau tautan

Tempel CID, URI `ipfs://`, atau URL gateway IPFS, lalu pilih **Buka konten**. Jika alamat menunjuk ke file, pilih **Unduh file** untuk menyimpannya. Tautan dengan jalur setelah CID dapat langsung membuka file atau subfolder tertentu.

## Unduh seluruh folder IPFS sebagai ZIP

Buka folder untuk melihat isinya, lalu pilih **Unduh ZIP** untuk menyimpan folder itu beserta subfoldernya. ZIP mempertahankan jalur aslinya. Jika unduhan gagal untuk beberapa jalur, alat ini akan menampilkan daftarnya. Anda bisa mencoba lagi atau memilih **Unduh file yang tersedia** untuk menyimpan bagian yang sudah diambil.

## Cara browser mengambil konten IPFS

Browser meminta blok yang diperlukan dari gateway IPFS publik dan memeriksa CID setiap blok sebelum menggunakannya. CID mengidentifikasi konten. Pengambilan data juga bergantung pada kemampuan gateway menjangkau node yang menyediakan blok tersebut. Jika folder terlalu besar untuk dikemas sebagai ZIP di perangkat Anda, buka subfolder atau unduh file satu per satu. [Dokumentasi pengambilan konten IPFS](https://docs.ipfs.tech/quickstart/retrieve/)
