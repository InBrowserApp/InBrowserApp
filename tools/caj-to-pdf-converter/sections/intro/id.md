## Konversi makalah ke PDF

Pilih atau letakkan dokumen CAJ, KDH, atau NH. Konversi berjalan di browser Anda. Periksa pratinjau halaman, lalu pilih Unduh PDF untuk menyimpan salinan dengan nama file asli dan ekstensi .pdf. Teks dan penanda yang tersedia dipertahankan. Mengganti atau menutup dokumen akan membatalkan proses yang belum selesai.

## Periksa kompatibilitas

File CAJ yang berisi objek halaman PDF dan file KDH yang berisi konten PDF didukung. Dukungan untuk varian HN-A/NH dan C8 berbasis gambar masih eksperimental: bandingkan persamaan, tabel, dan diagram penting dengan aslinya. Teks asli HN-B/C8 yang membutuhkan font terpisah, file yang dilindungi, varian TEB, dokumen rusak, dan file rujukan CAA tidak didukung. Hasil konversi yang tidak lengkap tidak tersedia untuk diunduh.

Halaman pindaian tetap berupa gambar; OCR tidak dilakukan. Beberapa karakter mungkin menggunakan glif pengganti, dan beberapa penanda mungkin disesuaikan atau tidak tersedia. Tinjau catatan konversi sebelum membagikan PDF.

## Simpan dokumen Anda secara lokal

Makalah Anda tidak diunggah dan tidak diperlukan akun. Tidak ada batas tetap untuk ukuran file atau jumlah halaman, meskipun dokumen besar dapat melampaui sumber daya browser. Menutup dokumen akan melepaskan pratinjau dan unduhannya. Penampil CAJ juga menyediakan unduhan PDF saat Anda sedang membaca makalah.
