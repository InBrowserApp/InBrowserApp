## Converti un documento in PDF

Seleziona o trascina un documento CAJ, KDH o NH. La conversione avviene nel browser. Controlla l’anteprima delle pagine, poi scegli Scarica PDF per salvare una copia con il nome del file originale e l’estensione .pdf. Il testo e i segnalibri disponibili vengono mantenuti. Sostituire o chiudere il documento annulla le operazioni non ancora completate.

## Verifica la compatibilità

Sono supportati i file CAJ contenenti oggetti pagina PDF e i file KDH contenenti dati PDF. Il supporto delle varianti HN-A/NH e C8 basate su immagini è sperimentale: confronta equazioni, tabelle e diagrammi importanti con l’originale. Non sono supportati il testo nativo HN-B/C8 che richiede caratteri separati, i file protetti, le varianti TEB, i documenti danneggiati e i file di riferimento CAA. Le conversioni incomplete non sono disponibili per il download.

Le pagine scansionate rimangono immagini; non viene eseguito l’OCR. Alcuni caratteri potrebbero usare glifi sostitutivi e alcuni segnalibri potrebbero essere adattati o non disponibili. Controlla le note sulla conversione prima di condividere il PDF.

## Mantieni il documento in locale

Il documento non viene caricato su un server e non è necessario un account. Non ci sono limiti fissi alla dimensione del file o al numero di pagine, anche se i documenti di grandi dimensioni possono superare le risorse del browser. Chiudere il documento libera l’anteprima e il file da scaricare. Anche il Visualizzatore CAJ permette di scaricare il PDF mentre stai già leggendo un documento.
