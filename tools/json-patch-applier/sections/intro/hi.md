## JSON Patch कैसे लागू करें

पहले एडिटर में मूल JSON दस्तावेज़ और दूसरे में RFC 6902 JSON Patch ऐरे पेस्ट करें। अपडेट किया गया JSON देखने और कॉपी करने के लिए **पैच लागू करें** चुनें। पैच बनाने के लिए [JSON अंतर और पथ](../json-diff-path/) में मूल और संशोधित दस्तावेज़ों की तुलना करें और **JSON Patch** आउटपुट कॉपी करें। पैच उसी मूल दस्तावेज़ पर लागू करें।

## JSON Patch का उदाहरण

मूल दस्तावेज़ में एक स्थिति और एक टैग है।

```json
{
  "status": "draft",
  "tags": ["api"]
}
```

यह पैच मूल स्थिति की जाँच करता है, उसे अपडेट करता है और आखिर में एक टैग जोड़ता है।

```json
[
  { "op": "test", "path": "/status", "value": "draft" },
  { "op": "replace", "path": "/status", "value": "published" },
  { "op": "add", "path": "/tags/-", "value": "release" }
]
```

नतीजा `{"status":"published","tags":["api","release"]}` है।

## समर्थित ऑपरेशन और JSON Pointer का सिंटैक्स

- `add` किसी ऑब्जेक्ट में नई प्रॉपर्टी जोड़ता है या मौजूदा प्रॉपर्टी बदलता है, ऐरे में आइटम डालता है या रूट पर पूरा दस्तावेज़ बदलता है।
- `remove` किसी मौजूदा मान को हटाता है। `replace` मौजूदा मान की जगह नया मान रखता है।
- `move` मौजूदा मान को `from` पाथ से उठाकर `path` पर डालता है। `copy` वहाँ उसकी अलग कॉपी डालता है।
- `test` जाँचता है कि `path` पर मौजूद मान दिए गए `value` के बराबर है या नहीं। इससे दस्तावेज़ में कोई बदलाव नहीं होता।

पाथ के लिए RFC 6901 JSON Pointer का इस्तेमाल होता है। ऐरे के इंडेक्स शून्य से शुरू होते हैं, इसलिए `/tags/0` पहले टैग का पाथ है और किसी जोड़ने वाले ऑपरेशन में `/tags/-` ऐरे के आखिर में मान जोड़ता है। ऑब्जेक्ट की कुंजी में स्लैश के लिए `~1` और टिल्ड के लिए `~0` इस्तेमाल करें। उदाहरण के लिए, `/a~1b` कुंजी `a/b` का पाथ है। खाली पाथ `""` पूरे दस्तावेज़ को दर्शाता है और `/` ऐसी प्रॉपर्टी को जिसकी कुंजी खाली है।

## JSON Patch ऑपरेशन क्यों विफल होता है

ऑपरेशन ऐरे के क्रम में चलते हैं। हर ऑपरेशन पहले वाले ऑपरेशन के नतीजे पर काम करता है। अगर लक्ष्य मौजूद नहीं है, इंडेक्स ऐरे की सीमा के बाहर है या `test` में मान अपेक्षित मान से मेल नहीं खाता, तो टूल पहली विफलता दिखाता है और वहीं रुक जाता है। JSON का पूर्वावलोकन तभी दिखाई देता है जब पूरा पैच सफल हो जाता है। खाली पैच ऐरे `[]` मूल दस्तावेज़ लौटाती है।

पैच आपके ब्राउज़र में ही लागू होता है। मूल JSON और पैच आपके ब्राउज़र में रहते हैं।
