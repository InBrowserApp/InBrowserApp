## Как применить JSON Patch

Вставьте исходный JSON-документ в первый редактор, а массив JSON Patch по RFC 6902 — во второй. Нажмите **Применить патч**, чтобы просмотреть и скопировать обновлённый JSON. Чтобы создать патч, сравните исходный и изменённый документы в инструменте [Сравнение JSON по путям](../json-diff-path/) и скопируйте результат на вкладке **JSON Patch**. Примените патч к тому же исходному документу.

## Пример JSON Patch

Исходный документ содержит статус и одну метку.

```json
{
  "status": "draft",
  "tags": ["api"]
}
```

Патч проверяет исходный статус, обновляет его и добавляет метку.

```json
[
  { "op": "test", "path": "/status", "value": "draft" },
  { "op": "replace", "path": "/status", "value": "published" },
  { "op": "add", "path": "/tags/-", "value": "release" }
]
```

Результат — `{"status":"published","tags":["api","release"]}`.

## Поддерживаемые операции и синтаксис JSON Pointer

- `add` создаёт или перезаписывает свойство объекта, вставляет элемент в массив или заменяет документ в корне.
- `remove` удаляет существующее значение. `replace` заменяет существующее значение новым.
- `move` извлекает существующее значение по пути `from` и вставляет его по пути `path`. Операция `copy` вставляет независимую копию.
- `test` проверяет, совпадает ли значение по пути `path` с указанным `value`, без изменения документа.

Пути записываются в формате JSON Pointer по RFC 6901. Индексация массивов начинается с нуля. Путь `/tags/0` указывает на первую метку, а `/tags/-` при вставке добавляет значение в конец массива. В ключах объектов используйте `~1` вместо косой черты и `~0` вместо тильды. Например, путь `/a~1b` указывает на ключ `a/b`. Пустой путь `""` указывает на весь документ, а `/` — на свойство с пустым ключом.

## Почему возникает ошибка при применении JSON Patch

Операции выполняются в порядке массива. Каждая операция работает с результатом предыдущих. Если целевой путь отсутствует, индекс выходит за границы массива или проверяемое значение в `test` отличается от ожидаемого, инструмент выделяет первую ошибку и останавливается. Предпросмотр JSON появляется только при успешном применении всего патча. Патч с пустым массивом `[]` возвращает исходный документ.

Патч применяется локально. Исходный JSON и патч остаются в вашем браузере.
