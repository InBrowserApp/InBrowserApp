# Owned legacy fixture

`field-notes.ppt` is original test content created by `generate.py` with python-pptx and Pillow, then saved as genuine PowerPoint 97–2003 binary format using LibreOffice. It contains three saved slides with text, a filled shape, an original PNG illustration, a table, and rotated text. The script makes the source reproducible; LibreOffice is used only to prepare the test fixture, never by the browser viewer.

The public upstream `tests/fixtures/legacy/file-example-250kb.ppt` and genuine WPS Linux DPS/DPT files are inspected locally and are not redistributed here. Their provenance and observed fidelity belong in the PR validation record.
