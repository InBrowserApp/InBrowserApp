## Baca presentasi format lama secara lokal

Buka file PowerPoint 97–2003 `.ppt` atau file WPS Presentation `.dps` atau `.dpt` yang kompatibel. Telusuri slide tersimpan, buka ikhtisar gambar mini, lompat ke slide, cari teks yang dipulihkan, atau gunakan penyesuaian slide, zoom, dan mode baca fokus. File tetap di perangkat Anda; penampil ini tidak mengunggahnya atau memuat sumber daya dokumen eksternal.

## Kompatibilitas dan pratinjau sebagian

Format biner ini dapat berisi fitur yang tidak dapat ditampilkan sepenuhnya oleh browser. Teks, bentuk umum, gambar, dan slide templat tersimpan mungkin dapat dipulihkan. Format teks, tata letak master, bentuk yang dikelompokkan, teks yang diputar, tabel, persamaan, dan bagan tersemat mungkin disederhanakan atau hilang. Setiap presentasi yang dibuka ditandai sebagai pratinjau sebagian. Bandingkan konten penting dengan aplikasi asalnya sebelum mengandalkan tampilannya.

Font yang tersedia di perangkat Anda digunakan. Font yang tidak tersedia akan diganti, yang dapat mengubah jarak dan pergantian baris. Animasi, transisi, pemutaran audio/video, makro, dan otomatisasi tayangan slide tidak dijalankan. Alat ini hanya untuk membaca dan tidak membuat presentasi baru dari templat.

## File yang tidak dapat dibuka

File yang dilindungi kata sandi, format PowerPoint yang lebih lama dari PowerPoint 97, serta varian WPS lain yang tidak terkait atau tidak kompatibel tidak didukung. Mengganti nama ekstensi tidak mengubah format aslinya. Gunakan Penampil PPTX untuk presentasi PowerPoint modern. File yang rusak serta keterbatasan memori browser atau kanvas akan menimbulkan kesalahan; tutup atau ganti file untuk melanjutkan.

Untuk membuat PDF yang dapat diunduh, gunakan [Konverter PPT / DPS ke PDF](../ppt-to-pdf-converter/). Periksa halaman hasil konversi sebelum mengunduh.
