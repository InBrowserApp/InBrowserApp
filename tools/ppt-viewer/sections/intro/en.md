## Read legacy presentations locally

Open a PowerPoint 97–2003 `.ppt` file or a compatible WPS Presentation `.dps` or `.dpt` file. Browse its saved slides, open the thumbnail overview, jump to a slide, search recovered text, or use fit-slide, zoom, and focus reading. Files stay on your device; this viewer does not upload them or load external document resources.

## Compatibility and partial previews

These binary formats can contain features that a browser cannot reproduce fully. Text, common shapes, pictures, and saved template slides may be recovered. Text formatting, master layouts, grouped shapes, rotated text, tables, equations, and embedded charts can be simplified or missing. Every opened presentation is marked as a partial preview. Compare important content with the original application before relying on its appearance.

Fonts available on your device are used. Missing fonts are substituted, which can change spacing and line breaks. Animations, transitions, audio/video playback, macros, and slideshow automation do not run. This tool is read-only and does not create a new presentation from a template.

## Files that cannot be opened

Password-protected files, PowerPoint formats older than PowerPoint 97, and unrelated or incompatible WPS variants are not supported. A renamed extension does not change the underlying format. Use the PPTX Viewer for modern PowerPoint presentations. Damaged files and browser memory or canvas limitations produce an error; close or replace the file to continue.
