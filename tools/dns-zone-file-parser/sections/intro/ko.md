## DNS 영역 파일을 읽는 방법

BIND 형식으로 내보낸 DNS 파일을 열거나 텍스트를 붙여넣으세요. 예제를 불러오면 SOA 레코드, IPv4 및 IPv6 주소 레코드, 메일 레코드, TXT 문자열을 확인할 수 있습니다. 각 행에는 레코드 이름, 클래스, 유형, TTL(캐시 유지 시간, 초 단위), 레코드 데이터가 표시됩니다. 이름, MX 같은 유형 또는 값의 일부로 필터링한 다음 표시된 레코드를 JSON으로 복사해 인벤토리 작성이나 마이그레이션에 활용하세요.

## 기준 도메인, TTL, 레코드 데이터 처리 방식

$ORIGIN이 example.com.이면 상대 이름 ‘www’는 www.example.com.이 됩니다. 이름에 @를 쓰면 현재 기준 도메인을 가리키며, 들여쓴 레코드는 앞선 레코드의 이름을 이어받습니다. 파일에 $ORIGIN이 없으면 초기 기준 도메인에 영역의 도메인을 입력하세요. 기본 $TTL이 1h이면 3,600초로 표시되며, 레코드에 별도의 TTL이 있으면 그 값을 사용합니다. 데이터의 따옴표, 이스케이프, 상대 대상은 원문 그대로 유지되므로 “hello; world”는 하나의 TXT 값으로 남고 MX 데이터의 ‘mail’도 ‘mail’로 표시됩니다.

## 분석 결과에서 확인할 수 있는 내용

파서는 주석, 따옴표로 묶은 텍스트, 여러 줄에 걸친 레코드를 처리합니다. 파싱 알림에서 문제가 있는 줄 번호를 안내하며 읽을 수 있는 레코드는 그대로 표시합니다. 영역 파일에 $INCLUDE나 $GENERATE가 있다면 먼저 해당 지시문을 펼친 레코드를 붙여넣으세요. 도구는 입력 내용을 브라우저 내부에서 읽습니다. DNS 서버에 접속하거나 특정 업체가 영역 파일을 불러올 수 있는지 검사하는 기능은 제공하지 않습니다.
