## איך קוראים דוח DMARC מצטבר

פתחו את הקובץ המצורף לדוח המצטבר שנשלח לכתובת המוגדרת ב־`rua` ברשומת ה־DMARC שלכם. המציג תומך ב־XML, ב־GZIP ובקובץ ZIP שמכיל דוח XML אחד. אפשר גם להדביק את ה־XML או לטעון דוגמה. הסיכום מציג את הגוף ששלח את הדוח, את התקופה לפי UTC ואת המדיניות שהדומיין פרסם. הקבצים והטקסט שהדבקתם מעובדים בדפדפן שלכם.

## איך מפרשים את ספירת ההודעות

כל רשומת מקור מקבצת הודעות שחולקות כתובת IP של המקור ותוצאת בדיקה זהה. רשומה יכולה לייצג כמה הודעות, ואותה כתובת IP יכולה להופיע בכמה רשומות. הסכומים מחושבים לפי מספר ההודעות בכל שורה. הודעה עוברת DMARC כשהיא עוברת אימות SPF או DKIM והדומיין של אותה שיטת אימות מתאים לדומיין הגלוי בכותרת From. המציג סופר הודעה ככישלון כששתי בדיקות ההתאמה נכשלות. כשחסרים נתוני התאמה, התוצאה מוצגת כלא ידועה.

## למה ההתאמה, האימות והפעולה שננקטה יכולים להיות שונים

פתחו את ״תוצאות אימות גולמיות״ כדי לראות את הדומיינים, התוצאות ובוררי DKIM שמופיעים בדוח. אימות SPF או DKIM יכול לעבור עבור דומיין אחר, ובדיקת ההתאמה ל־DMARC עדיין יכולה להיכשל. הפעולה שננקטה מתארת איך שרת הדואר המקבל טיפל בקבוצת ההודעות. כשהשרת מחיל חריגה מהמדיניות, הפעולה יכולה להיות שונה מהמדיניות שפורסמה. סננו לפי כתובת IP של המקור או הדומיין בכותרת From כדי לבדוק שולח בלי לשנות את הסכומים הכוללים.

## באילו פורמטי XML של DMARC המציג תומך

המציג קורא דוחות מצטברים לפי RFC 9990, כולל מרחב השמות של DMARC המוגדר בו, וגם דוחות ותיקים לפי RFC 7489. תקן RFC 9990 מתאר את פורמט ה־XML המשמש לסיכום תוצאות האימות והפעולות שננקטו בדוחות מצטברים. אם מערכת הדוא״ל ארזה כמה דוחות בקובץ דחוס אחד, חלצו את הדוח שתרצו לבדוק ופתחו אותו בנפרד.
