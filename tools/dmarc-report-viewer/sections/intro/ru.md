## Как прочитать агрегированный отчёт DMARC

Откройте вложение из агрегированного отчёта, полученного на адрес `rua` из вашей записи DMARC. Инструмент принимает XML, GZIP и ZIP с одним отчётом XML. Можно также вставить XML или загрузить пример. В сводке указано, кто отправил отчёт, за какой период в UTC он составлен и какая политика опубликована для домена. Файлы и вставленный текст обрабатываются в браузере.

## Как читать число писем

Каждая запись объединяет письма с одним IP-адресом источника и одинаковым результатом проверки. В записи может быть несколько писем, а один IP-адрес может встречаться в нескольких записях. Итоги рассчитываются по числу писем в каждой строке. Письмо проходит DMARC, если SPF или DKIM проходит проверку и соответствующий домен выровнен с доменом в видимом поле From. Письмо учитывается как не прошедшее проверку, только если оба результата выравнивания отрицательные. При неполных данных о выравнивании результат считается неизвестным.

## Чем отличаются выравнивание, аутентификация и действие получателя

Разверните «Исходные результаты аутентификации», чтобы посмотреть домены, результаты проверок и селекторы DKIM из отчёта. SPF или DKIM может пройти проверку для другого домена, а выравнивание по DMARC при этом не пройдёт. Действие получателя показывает, как принимающий сервер обработал группу писем. Если он применил исключение, это действие может отличаться от опубликованной политики. Отфильтруйте записи по IP-адресу источника или домену From, чтобы изучить отдельного отправителя. Общие итоги при этом сохраняются.

## Какие форматы XML для DMARC поддерживаются

Инструмент читает агрегированные отчёты по RFC 9990, включая его пространство имён DMARC, и отчёты старого формата по RFC 7489. RFC 9990 описывает формат XML, используемый в агрегированных отчётах для сводки результатов аутентификации и действий получателя. Если почтовая система упаковала несколько отчётов в один архив, извлеките нужный отчёт и откройте его отдельно.
