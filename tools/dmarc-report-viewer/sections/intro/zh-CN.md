## 如何读取 DMARC 汇总报告

打开发送到 DMARC 记录中 `rua` 地址的汇总报告附件。查看器支持 XML、GZIP，以及包含一份 XML 报告的 ZIP 文件。也可以粘贴 XML 或加载示例。报告摘要显示报告发送方、UTC 时间段和域名的已发布策略。文件和粘贴的文本均在浏览器中处理。

## 如何理解邮件数量

每条来源记录汇总来源 IP 和评估结果相同的邮件。一条记录可能代表多封邮件，同一个 IP 也可能出现在多条记录中。总数按每行的邮件数量计算。当 SPF 或 DKIM 中至少一项通过认证且与可见的 From 域名对齐时，邮件通过 DMARC。只有两项对齐结果均失败时，查看器才会将邮件计为失败。对齐数据不完整时显示为未知。

## 为什么对齐、认证和处理结果不同

展开“原始认证结果”，可查看报告中的域名、结果和 DKIM 选择器。SPF 或 DKIM 可能对另一个域名认证通过，但其 DMARC 对齐结果仍为失败。实际处理结果描述收件方如何处理一组邮件；当收件方覆盖策略时，该结果可能与已发布策略不同。按来源 IP 或 From 域名筛选可查看某个发送方，不会改变总体数量。

## 支持哪些 DMARC XML 格式

查看器支持符合 RFC 9990 的汇总报告，包括使用其 DMARC 命名空间的报告，也支持基于 RFC 7489 的旧版报告。RFC 9990 描述了用于在汇总报告中概述认证和处理结果的 XML 格式。如果邮件系统将多份报告打包到一个压缩包中，请解压所需报告并单独打开。
