## DMARC 집계 보고서를 읽는 방법

DMARC 레코드의 `rua` 주소로 받은 집계 보고서의 첨부 파일을 여세요. XML, GZIP 또는 XML 보고서 하나가 들어 있는 ZIP을 열 수 있습니다. XML을 붙여넣거나 예제를 불러와도 됩니다. 요약에는 보고서를 보낸 기관, UTC 기준 보고 기간, 도메인에 게시된 정책이 표시됩니다. 파일과 붙여넣은 텍스트는 브라우저에서 처리됩니다.

## 메일 수를 해석하는 방법

발신 레코드 하나는 발신 IP와 평가 결과가 같은 메일을 묶어 보여줍니다. 한 레코드에 메일이 여러 건 포함될 수 있고, 같은 IP가 여러 레코드에 나올 수도 있습니다. 합계는 각 행의 메일 수를 더해 계산합니다. SPF 또는 DKIM 인증을 통과한 도메인이 수신자에게 표시되는 From 도메인과 일치하면 DMARC를 통과합니다. 두 도메인 일치 결과가 모두 실패일 때만 실패로 집계합니다. 일치 여부를 판단할 데이터가 부족하면 알 수 없음으로 표시합니다.

## 도메인 일치, 인증, 처리 방식이 서로 다른 이유

보고된 인증 결과를 펼치면 보고서에 기록된 도메인, 인증 결과, DKIM 선택자를 볼 수 있습니다. 다른 도메인에 대한 SPF 또는 DKIM 인증은 통과하더라도 DMARC의 도메인 일치 검사는 실패할 수 있습니다. 적용된 처리 방식은 수신 서버가 해당 메일 묶음을 어떻게 처리했는지 보여줍니다. 수신 서버가 예외를 적용하면 게시된 정책과 다를 수 있습니다. 발신 IP나 From 도메인으로 필터링하면 전체 합계를 유지하면서 특정 발신자를 살펴볼 수 있습니다.

## 지원하는 DMARC XML 형식

이 뷰어는 DMARC 네임스페이스를 포함한 RFC 9990 집계 보고서와 RFC 7489 기반의 이전 보고서를 읽습니다. RFC 9990은 집계 보고서에서 인증과 처리 방식을 요약하는 데 사용하는 XML 형식을 정의합니다. 메일 시스템에서 보고서 여러 개를 하나의 압축 파일에 넣었다면, 확인할 보고서만 압축을 풀어 개별적으로 여세요.
