## 如何讀取 DMARC 彙總報告

開啟傳送至 DMARC 記錄中 `rua` 位址的彙總報告附件。檢視器支援 XML、GZIP，以及包含一份 XML 報告的 ZIP 檔案。也可以貼上 XML 或載入範例。報告摘要會顯示報告寄件者、UTC 期間和網域的已發布政策。檔案及貼上的文字都在瀏覽器中處理。

## 如何理解郵件數量

每筆來源記錄彙整來源 IP 和評估結果相同的郵件。一筆記錄可能代表多封郵件，同一個 IP 也可能出現在多筆記錄中。總數依每列的郵件數計算。只要 SPF 或 DKIM 至少一項驗證通過，且與可見的 From 網域對齊，郵件就會通過 DMARC。只有兩項對齊結果都失敗時，檢視器才會將郵件計為失敗。對齊資料不完整時會顯示為未知。

## 為什麼對齊、驗證和處理結果不同

展開「原始驗證結果」，即可查看報告中的網域、結果和 DKIM 選擇器。SPF 或 DKIM 可能對另一個網域驗證通過，但其 DMARC 對齊結果仍然失敗。實際處理結果說明收件方如何處理一組郵件；當收件方覆寫政策時，該結果可能與已發布政策不同。依來源 IP 或 From 網域篩選可查看特定寄件者，不會改變整體總數。

## 支援哪些 DMARC XML 格式

檢視器支援符合 RFC 9990 的彙總報告，包括使用其 DMARC 命名空間的報告，也支援基於 RFC 7489 的舊版報告。RFC 9990 說明用於彙總報告中概述驗證及處理結果的 XML 格式。如果郵件系統將多份報告打包在同一個壓縮檔中，請解壓縮所需報告並個別開啟。
