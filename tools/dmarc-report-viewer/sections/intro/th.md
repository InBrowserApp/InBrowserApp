## วิธีอ่านรายงานสรุปรวม DMARC

เปิดไฟล์แนบจากรายงานสรุปรวมที่ส่งไปยังที่อยู่ `rua` ในระเบียน DMARC ของคุณ โปรแกรมเปิดไฟล์ XML, GZIP และ ZIP ที่มีรายงาน XML หนึ่งฉบับได้ คุณยังวาง XML หรือโหลดตัวอย่างได้ด้วย ส่วนสรุปจะแสดงผู้ส่งรายงาน ช่วงเวลาตาม UTC และนโยบายที่โดเมนประกาศ ไฟล์และข้อความที่วางจะประมวลผลในเบราว์เซอร์ของคุณ

## วิธีอ่านจำนวนอีเมล

ระเบียนแต่ละรายการรวมอีเมลที่มี IP ต้นทางและผลการประเมินเดียวกัน หนึ่งระเบียนอาจมีอีเมลหลายฉบับ และ IP เดียวกันอาจอยู่ในหลายระเบียน ยอดรวมคำนวณจากจำนวนอีเมลในแต่ละแถว อีเมลจะผ่าน DMARC เมื่อ SPF หรือ DKIM ตรวจสอบผ่านและโดเมนที่ผ่านตรงกับโดเมนในช่อง From ที่ผู้รับเห็น โปรแกรมนับเป็นไม่ผ่านเมื่อผลการจับคู่โดเมนทั้งสองรายการเป็นไม่ผ่าน หากข้อมูลการจับคู่ไม่ครบ จะแสดงว่าไม่ทราบผล

## เหตุใดผลการจับคู่โดเมน ผลการตรวจสอบสิทธิ์ และวิธีจัดการจึงต่างกัน

ขยายส่วนผลการตรวจสอบสิทธิ์ดั้งเดิมเพื่อดูโดเมน ผลการตรวจสอบ และตัวเลือกคีย์ DKIM ที่ระบุในรายงาน SPF หรือ DKIM อาจตรวจสอบผ่านสำหรับโดเมนอื่น แต่การจับคู่โดเมนของ DMARC ยังไม่ผ่าน วิธีจัดการที่ใช้จริงบอกว่าเซิร์ฟเวอร์ผู้รับจัดการอีเมลกลุ่มนั้นอย่างไร วิธีนี้อาจต่างจากนโยบายที่ประกาศเมื่อผู้รับใช้ข้อยกเว้น กรองตาม IP ต้นทางหรือโดเมนใน From เพื่อดูผู้ส่งรายใดรายหนึ่งโดยที่ยอดรวมทั้งหมดยังคงเดิม

## รองรับไฟล์ DMARC XML แบบใดบ้าง

โปรแกรมอ่านรายงานสรุปรวมตาม RFC 9990 ซึ่งรวมถึงเนมสเปซ DMARC ของมาตรฐานนี้ และรายงานรุ่นเดิมตาม RFC 7489 โดย RFC 9990 กำหนดรูปแบบ XML สำหรับสรุปผลการตรวจสอบสิทธิ์และวิธีจัดการอีเมลในรายงานสรุปรวม หากระบบอีเมลบีบอัดรายงานหลายฉบับไว้ในไฟล์เดียว ให้แตกไฟล์รายงานที่ต้องการแล้วเปิดแยกกัน
