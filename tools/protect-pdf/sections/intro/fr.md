## Comment protéger un PDF par mot de passe

1. Choisissez ou déposez un PDF qui s’ouvre sans mot de passe.
2. Saisissez le mot de passe que les destinataires devront utiliser pour ouvrir le PDF, puis saisissez-le à nouveau pour le confirmer. L’icône en forme d’œil permet de vérifier votre saisie.
3. Sélectionnez **Protéger le PDF**, puis **Télécharger le PDF protégé**. Ouvrez la copie téléchargée dans votre visionneuse de PDF pour vérifier qu’elle vous demande le mot de passe.

L’outil crée un fichier distinct. Par exemple, si vous protégez `invoice.pdf`, vous obtenez `invoice-protected.pdf`. Si vous prévoyez d’apposer une signature numérique, définissez le mot de passe avant de signer la copie protégée.

## À quoi sert le mot de passe d’ouverture d’un PDF ?

Le mot de passe d’ouverture contrôle l’accès au contenu du PDF chiffré. L’outil chiffre la copie téléchargeable avec AES-256. Une fois le document ouvert avec le mot de passe, les destinataires peuvent le modifier, l’imprimer et en copier le contenu. L’outil lève les restrictions d’utilisation déjà définies dans le PDF lorsqu’il crée la copie protégée.

Un mot de passe d’ouverture peut servir à partager une fiche de paie, un relevé bancaire, un contrat ou un formulaire rempli. Choisissez un mot de passe robuste et unique, et communiquez-le séparément du PDF, par exemple via une messagerie sécurisée. Conservez le fichier d’origine pour pouvoir y accéder si vous perdez le mot de passe.

## Le PDF est-il envoyé quelque part ?

Le fichier et le mot de passe restent dans votre navigateur. Le chiffrement s’effectue sur votre appareil et la copie protégée est enregistrée via les téléchargements de votre navigateur. Vous pouvez utiliser l’outil sans compte.
