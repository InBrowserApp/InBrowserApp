## Come proteggere un PDF con password

1. Scegli o trascina qui un PDF che si apre senza password.
2. Inserisci la password che i destinatari dovranno usare per aprire il PDF e ripetila per confermarla. Usa l’icona a forma di occhio per controllare cosa hai digitato.
3. Seleziona **Proteggi PDF**, poi **Scarica il PDF protetto**. Apri la copia scaricata in un visualizzatore PDF per verificare che ti chieda la password.

Lo strumento crea un file separato. Ad esempio, se proteggi `invoice.pdf`, otterrai `invoice-protected.pdf`. Il PDF originale resta intatto.

## A cosa serve la password di apertura di un PDF

La password di apertura controlla chi può visualizzare il PDF cifrato. Lo strumento cifra la copia da scaricare con AES-256. Dopo aver aperto il file con la password, i destinatari possono stamparlo o copiarne il contenuto. Le restrizioni alla stampa e alla modifica sono un’impostazione separata dei PDF.

La password di apertura può essere utile per condividere una busta paga, un estratto conto, un contratto o un modulo compilato. Scegli una password robusta e univoca e condividila separatamente dal PDF, ad esempio con un messaggio sicuro. Conserva il file originale per poter accedere al documento anche se perdi la password.

## Il PDF viene caricato online?

Il file e la password restano nel browser. Il PDF viene cifrato sul tuo dispositivo e puoi salvare la copia protetta dal menu dei download del browser. Puoi usare lo strumento senza un account.
