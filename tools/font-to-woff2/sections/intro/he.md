## איך להמיר גופני TTF או OTF ל-WOFF2

בחרו קובץ אחד או יותר של גופן TrueType (`.ttf`) או OpenType (`.otf`), או גררו את הקבצים לאזור ההמרה. ההמרה מתחילה מיד עם הוספת הקבצים. כשהגופן מוכן, השוו את גודל הקובץ המקורי לגודל קובץ ה-WOFF2 ובחרו **הורדת WOFF2**. לדוגמה, `Inter-Regular.ttf` הופך ל-`Inter-Regular.woff2`. כל עיבוד הגופנים מתבצע בדפדפן, והקבצים נשארים במכשיר שלכם.

## למה להשתמש ב-WOFF2 לגופני אינטרנט?

פורמט WOFF2 ‏(Web Open Font Format 2) אורז את נתוני הגופן בדחיסת Brotli. כשאתר מגיש גופן בפורמט WOFF2 במקום בקובץ ה-TTF או ה-OTF המקורי, לרוב נדרש להעביר פחות נתונים. מידת החיסכון משתנה מגופן לגופן. המרת הפורמט שומרת על כל הגליפים ועל צירי הגופן המשתנה, כך שקובץ גופן משתנה אחד עדיין יכול לכסות טווח של משקלים. אם האתר משתמש רק בקבוצה מסוימת של תווים, אפשר להקטין עוד את הקובץ בעזרת [מחולל תת־קבוצות גופנים](../font-subset-generator/).

## איך להשתמש בקובץ WOFF2 ב-CSS

שמרו את הקובץ שהורדתם בתיקיית הגופנים של האתר והפנו אליו באמצעות `@font-face`. התאימו את הנתיב, המשקל והסגנון לקובץ הגופן. הדוגמה הזו טוענת גופן במשקל רגיל מהתיקייה `/fonts/` ומציגה את הטקסט בגופן חלופי בזמן הטעינה.

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/Inter-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "Inter", sans-serif;
}
```

כשמשתמשים בגופן משתנה, הגדירו את טווח המשקלים שהגופן תומך בו בפועל, למשל `font-weight: 100 900;`. בדקו את רישיון הגופן לפני שמאחסנים אותו באתר, ובדקו את השפות והמשקלים שבהם משתמשים בדפי האתר. ראו [תיעוד `@font-face` ב-MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40font-face).
