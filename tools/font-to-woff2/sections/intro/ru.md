## Как конвертировать TTF или OTF в WOFF2

Выберите один или несколько файлов шрифтов TrueType (`.ttf`) или OpenType (`.otf`) либо перетащите их в конвертер. Преобразование начнётся сразу после добавления файлов. Когда шрифт будет готов, сравните размеры исходного файла и WOFF2 и нажмите **Скачать WOFF2**. Например, `Inter-Regular.ttf` превратится в `Inter-Regular.woff2`. Вся обработка шрифтов происходит в браузере, поэтому файлы остаются на вашем устройстве.

## Зачем использовать WOFF2 для веб-шрифтов?

WOFF2 (Web Open Font Format 2) упаковывает данные шрифта с помощью сжатия Brotli. По сравнению с передачей исходного TTF или OTF формат WOFF2 обычно позволяет передать меньше данных. Экономия зависит от шрифта. Преобразование формата сохраняет полный набор глифов и оси вариативного шрифта, поэтому один файл вариативного шрифта по-прежнему может охватывать диапазон начертаний по насыщенности. Если сайт использует только определённый набор символов, воспользуйтесь [генератором подмножества шрифта](../font-subset-generator/), чтобы дополнительно уменьшить файл.

## Как использовать файл WOFF2 в CSS

Поместите скачанный файл в папку шрифтов вашего сайта и подключите его с помощью `@font-face`. Укажите путь, насыщенность и стиль в соответствии с используемым файлом. В этом примере обычное начертание загружается из `/fonts/`, а во время загрузки текст отображается резервным шрифтом.

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/Inter-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "Inter", sans-serif;
}
```

Для вариативного шрифта укажите диапазон насыщенности, который он действительно поддерживает, например `font-weight: 100 900;`. Прежде чем размещать шрифт на сайте, проверьте его лицензию и протестируйте языки и начертания по насыщенности, используемые на страницах. См. [справку MDN по @font-face](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40font-face).
