## วิธีแปลง TTF หรือ OTF เป็น WOFF2

เลือกไฟล์ฟอนต์ TrueType (`.ttf`) หรือ OpenType (`.otf`) หนึ่งไฟล์ขึ้นไป หรือลากไฟล์มาวางในตัวแปลง ระบบจะเริ่มแปลงทันทีที่เพิ่มไฟล์ เมื่อแปลงเสร็จแล้ว ให้เปรียบเทียบขนาดไฟล์ต้นฉบับกับไฟล์ WOFF2 แล้วเลือก **ดาวน์โหลด WOFF2** ตัวอย่างเช่น `Inter-Regular.ttf` จะกลายเป็น `Inter-Regular.woff2` การประมวลผลทั้งหมดเกิดขึ้นในเบราว์เซอร์ ไฟล์จึงอยู่บนอุปกรณ์ของคุณ

## ทำไมจึงควรใช้ WOFF2 สำหรับฟอนต์เว็บ?

WOFF2 (Web Open Font Format 2) บีบอัดข้อมูลฟอนต์ด้วย Brotli การส่งไฟล์ WOFF2 จากเว็บไซต์มักใช้ข้อมูลน้อยกว่าการส่งไฟล์ TTF หรือ OTF ต้นฉบับ ขนาดที่ลดลงขึ้นอยู่กับฟอนต์ การแปลงรูปแบบจะเก็บรูปอักษรทั้งหมดและแกนของฟอนต์แปรผันไว้ ฟอนต์แปรผันเพียงไฟล์เดียวจึงยังรองรับน้ำหนักตัวอักษรได้หลายระดับ หากเว็บไซต์ใช้เฉพาะอักขระบางชุด ให้ใช้[เครื่องมือสร้างชุดย่อยฟอนต์](../font-subset-generator/)เพื่อลดขนาดไฟล์ลงอีก

## วิธีใช้ไฟล์ WOFF2 ใน CSS

เก็บไฟล์ที่ดาวน์โหลดไว้ในโฟลเดอร์ฟอนต์ของเว็บไซต์ แล้วอ้างอิงไฟล์ด้วย `@font-face` ระบุพาธ น้ำหนัก และสไตล์ให้ตรงกับไฟล์ที่ใช้ ตัวอย่างนี้โหลดฟอนต์น้ำหนักปกติจาก `/fonts/` และแสดงข้อความด้วยฟอนต์สำรองระหว่างโหลด

```css
@font-face {
  font-family: "Inter";
  src: url("/fonts/Inter-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "Inter", sans-serif;
}
```

สำหรับฟอนต์แปรผัน ให้ระบุช่วงน้ำหนักที่ฟอนต์รองรับจริง เช่น `font-weight: 100 900;` ตรวจสอบสัญญาอนุญาตก่อนโฮสต์ฟอนต์บนเว็บไซต์ และทดสอบภาษาและน้ำหนักตัวอักษรที่ใช้ในแต่ละหน้า ดู [เอกสารอ้างอิง @font-face ของ MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40font-face)
