## 애니메이션 WebP를 GIF로 변환

애니메이션 WebP는 여러 프레임을 하나의 `.webp` 파일에 담습니다. 채팅 앱이나 문서 사이트 등에서 애니메이션을 GIF로 공유해야 할 때 변환하세요. 손실 압축과 무손실 압축을 사용한 애니메이션 WebP를 모두 지원하며, 변환은 사용자의 기기에서 처리됩니다.

### 애니메이션 WebP를 GIF로 변환하는 방법

1. **파일 선택**을 누르거나 애니메이션 WebP를 도구에 끌어다 놓으세요.
2. **GIF 만들기**를 눌러 원본 크기 그대로 프레임을 변환하세요.
3. **재생**으로 GIF를 확인한 뒤 **GIF 다운로드**를 눌러 저장하세요.

### 프레임 표시 시간과 반복 설정은 어떻게 되나요?

프레임별 표시 시간은 GIF가 사용하는 10밀리초 단위로 반올림하며, 재생할 때 최소 표시 시간은 20밀리초입니다. 예를 들어 100밀리초 프레임 다음에 250밀리초 프레임이 이어지면 두 시간 모두 그대로 유지됩니다. WebP에 지정된 총 재생 횟수도 유지됩니다. 원본이 무한 반복이면 GIF도 계속 반복됩니다.

### GIF는 투명도와 색상을 어떻게 처리하나요?

GIF는 인덱스 색상을 사용하며, 프레임마다 팔레트 항목이 최대 256개이고 그중 하나를 투명색으로 쓸 수 있습니다. WebP는 부분 투명도를 저장할 수 있어 GIF로 바꾸면 반투명한 그림자나 부드러운 윤곽이 다르게 보일 수 있습니다. 색이 풍부한 프레임에서는 그라데이션에 띠가 나타날 수도 있습니다. 사용할 배경을 고려해 미리보기에서 확인하세요.

#### GIF가 WebP보다 커지는 이유는 무엇인가요?
