## Practice with a steady beat

Choose a tempo and press **Start**. You can type the BPM, move the slider, or use the minus and plus buttons to change it by one beat per minute. At 120 BPM you hear two main clicks per second. Start at a speed where you can play evenly, then raise the tempo as the passage gets easier. Turn off **Sound** to follow the visual beat while keeping the room quiet.

## Find a tempo by tapping

Press **Tap tempo** twice or more at a steady pace. The first tap starts measuring. Further taps update the tempo from your recent intervals. Tap once per main beat. If you pause and start again, the tool measures a new tempo. To estimate the BPM from a song or recording, use the [BPM Detector](/tools/bpm-detector/).

## Set beats per bar and subdivision

Set **Beats per bar** to 4 for a four-beat count or 3 for a waltz. **Accent first beat** makes the start of each bar easier to hear. Use **Subdivision** to add quieter clicks between the main beats. Choose 2 per beat to practice eighth notes in 4/4, or 3 per beat to practice triplets. For a 6/8 feel, try 2 main beats per bar and 3 clicks per beat.
