## Read a saved HTML document

Open an HTML, HTM, or XHTML file to read a saved article, exported report, or standalone document. Follow internal links, navigate headings from the outline, adjust zoom, or enter focused reading. Text stays selectable, and wide tables and code blocks scroll within the document.

## Included content and missing resources

Self-contained documents work best. Embedded styles and common embedded images are retained. Images, styles, and fonts stored on a website or in a sibling folder are not loaded. Reading notes explain when resources are missing. Save a self-contained HTML copy from the original application when possible.

HTML is displayed as a continuous document; complex website layouts may differ. SVG drawings, embedded apps, media, and content that requires scripts are not displayed. XHTML must be well formed. UTF-8, UTF-16, and browser-supported legacy encodings are recognized from byte markers or encoding declarations.

## Local, read-only viewing

Files stay on your device. Scripts, forms, redirects, and embedded frames are disabled. Selecting an external link opens it separately. The viewer does not load website addresses, restore login sessions, or run web applications. Close or replace the document to release the current preview. MHTML archives require an MHTML viewer.
