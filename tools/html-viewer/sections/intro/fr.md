## Lire un document HTML enregistré

Ouvrez un fichier HTML, HTM ou XHTML pour lire un article enregistré, un rapport exporté ou un document autonome. Suivez les liens internes, accédez aux titres depuis le plan, ajustez le zoom ou activez la lecture concentrée. Le texte reste sélectionnable, et les tableaux larges et les blocs de code défilent à l’intérieur du document.

## Contenu inclus et ressources manquantes

Les documents autonomes offrent les meilleurs résultats. Les styles intégrés et les images intégrées aux formats courants sont conservés. Les images, styles et polices stockés sur un site web ou dans un dossier placé à côté du fichier ne sont pas chargés. Les notes de lecture signalent les ressources manquantes. Si possible, enregistrez une copie HTML autonome depuis l’application d’origine.

Le HTML s’affiche sous forme de document continu ; les mises en page complexes de sites web peuvent différer. Les dessins SVG, les applications intégrées, les médias et les contenus nécessitant des scripts ne sont pas affichés. Le XHTML doit être bien formé. Les encodages UTF-8, UTF-16 et les encodages anciens pris en charge par le navigateur sont reconnus à partir des marqueurs d’octets ou des déclarations d’encodage.

## Consultation locale en lecture seule

Les fichiers restent sur votre appareil. Les scripts, formulaires, redirections et cadres intégrés sont désactivés. Sélectionner un lien externe l’ouvre séparément. La visionneuse ne charge pas d’adresses de sites web, ne restaure pas les sessions de connexion et n’exécute pas d’applications web. Fermez ou remplacez le document pour libérer l’aperçu actuel. Les archives MHTML nécessitent une visionneuse MHTML.
