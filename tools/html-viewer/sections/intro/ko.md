## 저장한 HTML 문서 읽기

HTML, HTM 또는 XHTML 파일을 열어 저장한 기사, 내보낸 보고서, 독립형 문서를 읽으세요. 내부 링크를 따라가거나 문서 개요에서 제목으로 이동하고, 확대/축소를 조절하거나 집중 읽기를 사용할 수 있습니다. 텍스트를 선택할 수 있으며, 너비가 넓은 표와 코드 블록은 문서 안에서 스크롤됩니다.

## 포함된 콘텐츠와 누락된 리소스

필요한 리소스가 파일 안에 모두 포함된 문서가 가장 잘 표시됩니다. 문서에 포함된 스타일과 일반적인 이미지가 유지됩니다. 웹사이트나 문서와 같은 위치의 폴더에 저장된 이미지, 스타일, 글꼴은 불러오지 않습니다. 누락된 리소스가 있으면 읽기 안내에 표시됩니다. 가능하면 원래 앱에서 필요한 리소스를 모두 포함한 HTML 사본을 저장하세요.

HTML은 하나의 연속된 문서로 표시되므로 복잡한 웹사이트 레이아웃은 다르게 보일 수 있습니다. SVG 그림, 삽입된 앱, 미디어, 스크립트가 필요한 콘텐츠는 표시되지 않습니다. XHTML은 올바른 문법으로 작성되어야 합니다. 바이트 표식이나 인코딩 선언을 통해 UTF-8, UTF-16 및 브라우저가 지원하는 이전 문자 인코딩을 인식합니다.

## 로컬에서 읽기 전용으로 보기

파일은 기기에만 보관됩니다. 스크립트, 양식, 리디렉션, 삽입된 프레임은 비활성화됩니다. 외부 링크를 선택하면 별도로 열립니다. 이 뷰어는 웹사이트 주소를 불러오거나 로그인 세션을 복원하거나 웹 앱을 실행하지 않습니다. 문서를 닫거나 바꾸면 현재 미리보기가 해제됩니다. MHTML 아카이브는 MHTML 뷰어가 필요합니다.
