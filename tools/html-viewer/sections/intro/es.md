## Lee un documento HTML guardado

Abre un archivo HTML, HTM o XHTML para leer un artículo guardado, un informe exportado o un documento independiente. Sigue enlaces internos, navega por los encabezados desde el esquema, ajusta el zoom o activa la lectura sin distracciones. El texto se puede seleccionar y las tablas anchas y los bloques de código se pueden desplazar dentro del documento.

## Contenido incluido y recursos ausentes

Los documentos autónomos funcionan mejor. Se conservan los estilos incrustados y las imágenes incrustadas en formatos comunes. No se cargan las imágenes, los estilos ni las fuentes guardados en un sitio web o en una carpeta que acompañe al archivo. Las notas de lectura indican cuándo faltan recursos. Siempre que sea posible, guarda una copia HTML autónoma desde la aplicación original.

El HTML se muestra como un documento continuo; los diseños web complejos pueden verse diferentes. No se muestran dibujos SVG, aplicaciones incrustadas, contenido multimedia ni contenido que requiera scripts. El XHTML debe estar bien formado. UTF-8, UTF-16 y las codificaciones antiguas compatibles con el navegador se reconocen mediante marcas de bytes o declaraciones de codificación.

## Visualización local de solo lectura

Los archivos permanecen en tu dispositivo. Los scripts, formularios, redirecciones y marcos incrustados están desactivados. Al seleccionar un enlace externo, se abre por separado. El visor no carga direcciones web, restaura sesiones de inicio de sesión ni ejecuta aplicaciones web. Cierra o reemplaza el documento para liberar la vista previa actual. Los archivos MHTML requieren un visor de MHTML.
