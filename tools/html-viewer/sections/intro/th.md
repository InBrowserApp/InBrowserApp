## อ่านเอกสาร HTML ที่บันทึกไว้

เปิดไฟล์ HTML, HTM หรือ XHTML เพื่ออ่านบทความที่บันทึกไว้ รายงานที่ส่งออก หรือเอกสารแบบไฟล์เดียว ใช้ลิงก์ภายใน ไปยังหัวข้อจากเค้าโครง ปรับการซูม หรือเข้าสู่โหมดอ่านแบบมีสมาธิ ข้อความยังคงเลือกได้ และตารางหรือบล็อกโค้ดที่กว้างสามารถเลื่อนดูภายในเอกสารได้

## เนื้อหาที่รวมไว้และทรัพยากรที่ขาดหาย

เอกสารที่รวมทุกอย่างไว้ในไฟล์เดียวทำงานได้ดีที่สุด สไตล์ที่ฝังไว้และรูปภาพแบบฝังในรูปแบบทั่วไปจะยังคงแสดงอยู่ ระบบไม่โหลดรูปภาพ สไตล์ และแบบอักษรที่อยู่บนเว็บไซต์หรือในโฟลเดอร์ข้างไฟล์ หมายเหตุการอ่านจะแจ้งเมื่อมีทรัพยากรขาดหาย หากทำได้ ให้บันทึกสำเนา HTML ที่รวมทุกอย่างไว้ในไฟล์เดียวจากแอปพลิเคชันต้นฉบับ

HTML จะแสดงเป็นเอกสารต่อเนื่อง รูปแบบเว็บไซต์ที่ซับซ้อนอาจแสดงต่างไป ภาพวาด SVG แอปที่ฝังไว้ สื่อ และเนื้อหาที่ต้องใช้สคริปต์จะไม่แสดง XHTML ต้องมีโครงสร้างที่ถูกต้อง ระบบตรวจหาการเข้ารหัส UTF-8, UTF-16 และการเข้ารหัสรุ่นเก่าที่เบราว์เซอร์รองรับจากเครื่องหมายไบต์หรือการประกาศการเข้ารหัส

## ดูไฟล์ในเครื่องแบบอ่านอย่างเดียว

ไฟล์อยู่บนอุปกรณ์ของคุณ สคริปต์ แบบฟอร์ม การเปลี่ยนเส้นทาง และเฟรมที่ฝังไว้ถูกปิดใช้งาน การเลือกลิงก์ภายนอกจะเปิดลิงก์นั้นแยกต่างหาก โปรแกรมดูนี้ไม่โหลดที่อยู่เว็บไซต์ ไม่กู้คืนเซสชันการเข้าสู่ระบบ และไม่เรียกใช้เว็บแอปพลิเคชัน ปิดหรือเปลี่ยนเอกสารเพื่อปล่อยทรัพยากรของตัวอย่างปัจจุบัน ไฟล์ MHTML ต้องใช้โปรแกรมดู MHTML
