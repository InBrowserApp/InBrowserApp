## Baca dokumen HTML tersimpan

Buka file HTML, HTM, atau XHTML untuk membaca artikel tersimpan, laporan yang diekspor, atau dokumen mandiri. Ikuti tautan internal, buka judul bagian dari kerangka dokumen, atur zoom, atau gunakan mode baca fokus. Teks tetap dapat dipilih, dan tabel serta blok kode yang lebar dapat digulir di dalam dokumen.

## Konten yang disertakan dan sumber daya yang hilang

Dokumen mandiri memberikan hasil terbaik. Gaya tersemat dan gambar tersemat yang umum tetap dipertahankan. Gambar, gaya, dan font yang disimpan di situs web atau folder di lokasi yang sama tidak dimuat. Catatan pembacaan menjelaskan jika ada sumber daya yang hilang. Jika memungkinkan, simpan salinan HTML mandiri dari aplikasi asalnya.

HTML ditampilkan sebagai dokumen berkesinambungan; tata letak situs web yang kompleks mungkin berbeda. Gambar SVG, aplikasi tersemat, media, dan konten yang memerlukan skrip tidak ditampilkan. XHTML harus memiliki struktur yang valid. UTF-8, UTF-16, dan pengodean lama yang didukung browser dikenali dari penanda byte atau deklarasi pengodean.

## Tampilan lokal hanya baca

File tetap di perangkat Anda. Skrip, formulir, pengalihan, dan bingkai tersemat dinonaktifkan. Memilih tautan eksternal akan membukanya secara terpisah. Penampil ini tidak memuat alamat situs web, memulihkan sesi login, atau menjalankan aplikasi web. Tutup atau ganti dokumen untuk menghapus pratinjau saat ini dari memori. Arsip MHTML memerlukan penampil MHTML.
