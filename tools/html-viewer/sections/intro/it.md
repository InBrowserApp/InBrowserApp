## Leggi un documento HTML salvato

Apri un file HTML, HTM o XHTML per leggere un articolo salvato, un report esportato o un documento autonomo. Segui i link interni, passa ai titoli dall’indice, regola lo zoom o attiva la lettura senza distrazioni. Il testo resta selezionabile e le tabelle larghe e i blocchi di codice scorrono all’interno del documento.

## Contenuti inclusi e risorse mancanti

I documenti autonomi offrono i risultati migliori. Gli stili incorporati e le immagini incorporate nei formati comuni vengono mantenuti. Immagini, stili e caratteri memorizzati su un sito web o in una cartella accanto al file non vengono caricati. Le note di lettura segnalano le risorse mancanti. Quando possibile, salva una copia HTML autonoma dall’applicazione originale.

Il contenuto HTML viene visualizzato come un documento continuo; i layout complessi dei siti web possono apparire diversi. Disegni SVG, app incorporate, contenuti multimediali e contenuti che richiedono script non vengono visualizzati. Il codice XHTML deve essere ben formato. UTF-8, UTF-16 e le codifiche precedenti supportate dal browser vengono riconosciuti dai marcatori di byte o dalle dichiarazioni di codifica.

## Visualizzazione locale in sola lettura

I file restano sul tuo dispositivo. Script, moduli, reindirizzamenti e frame incorporati sono disabilitati. Selezionando un link esterno, questo si apre separatamente. Il visualizzatore non carica indirizzi di siti web, non ripristina sessioni di accesso e non esegue applicazioni web. Chiudi o sostituisci il documento per rilasciare l’anteprima corrente. Gli archivi MHTML richiedono un visualizzatore MHTML.
