## Как спланировать подсети IPv4 с помощью VLSM

Введите исходный блок в формате CIDR, например 192.168.10.0/24. Добавьте по строке для каждой подсети и укажите, сколько адресов нужно для узлов с учётом шлюза и возможного расширения. После расчёта вы увидите выделенные подсети, их маски, диапазоны доступных адресов и широковещательные адреса, а также блоки CIDR, которые остались свободными.

Маски подсетей переменной длины (VLSM) позволяют разделить сеть на подсети разного размера. Калькулятор выбирает наименьший блок, подходящий для каждого числа узлов, и размещает блоки от больших к малым с учётом границ CIDR. В обычной подсети резервируются сетевой и широковещательный адреса. Например, блок /26 вмещает 50 узлов, поскольку в нём доступно 62 адреса для узлов.

Выбирайте /31 только для соединения IPv4 «точка-точка», в котором доступны оба адреса. Для одного адреса, например адреса интерфейса loopback маршрутизатора, подходит /32. Для этих двух вариантов широковещательный адрес отсутствует. Расчёт выполняется в браузере, и имена подсетей остаются в нём.
