## สร้างพรีฟิกซ์ IPv6 ULA ขนาด /48

คัดลอกพรีฟิกซ์ `fd` ที่สร้างขึ้นไปใช้ในเครือข่ายที่บ้าน ห้องทดลอง หรือ VPN บันทึกพรีฟิกซ์ `/48` ที่เลือกไว้กับการตั้งค่าเครือข่ายเพื่อใช้ค่าเดิมเมื่อเพิ่มซับเน็ต กด **สร้างพรีฟิกซ์ใหม่** เมื่อต้องการจัดสรรพรีฟิกซ์ใหม่

## คำนวณซับเน็ต /64

ใส่ **ID ซับเน็ต** เป็นเลขฐานสิบหกตั้งแต่ `0000` ถึง `ffff` ตัวอย่างเช่น ID `00a0` ภายใน `fd12:3456:789a::/48` จะได้ `fd12:3456:789a:a0::/64` พรีฟิกซ์ `/48` หนึ่งค่ามีซับเน็ต `/64` ให้ใช้ 65,536 ซับเน็ต จึงแบ่งพรีฟิกซ์ให้ LAN, Wi-Fi สำหรับผู้มาเยือน และ VPN แยกกันได้

## พรีฟิกซ์ fd มาจากไหน

RFC 4193 กำหนดช่วง Unique Local Address ไว้ที่ `fc00::/7` ครึ่งหนึ่งของช่วงนี้ใช้สำหรับจัดสรรภายใน คือ `fd00::/8` ซึ่งขึ้นต้นด้วย `fd` เครื่องมือจะนำ Global ID แบบสุ่มขนาด 40 บิตจาก Web Crypto API ของเบราว์เซอร์มาต่อเป็นพรีฟิกซ์ `/48`

## ควรใช้ Unique Local Address เมื่อไร

ใช้ ULA เมื่อต้องการให้ที่อยู่ IPv6 ภายในเครือข่ายหรือระหว่างไซต์ที่เชื่อมต่อผ่าน VPN คงเดิม อุปกรณ์หนึ่งเครื่องใช้ที่อยู่ IPv6 แบบสากลสำหรับรับส่งข้อมูลผ่านอินเทอร์เน็ตสาธารณะ พร้อมใช้ ULA สำหรับบริการภายในได้
