## 產生 IPv6 ULA /48 前綴

複製產生的 `fd` 前綴，供家庭網路、實驗環境或 VPN 使用。把選定的 `/48` 記錄在網路設定中，新增子網路時就能沿用。需要重新分配時，選擇 **產生新前綴**。

## 計算 /64 子網路

輸入 `0000` 到 `ffff` 之間的十六進位 **子網路 ID**。例如，在 `fd12:3456:789a::/48` 中輸入 `00a0`，會得到 `fd12:3456:789a:a0::/64`。一個 `/48` 最多可分成 65,536 個 `/64` 子網路，可為區域網路、訪客 Wi-Fi 或 VPN 各自分配前綴。

## fd 前綴的由來

RFC 4193 將唯一本地位址定義在 `fc00::/7` 範圍內。其中用於本地指派的 `fd00::/8` 以 `fd` 開頭。工具透過瀏覽器的 Web Crypto API 產生 40 位元的隨機 Global ID，再與前綴組合成 `/48`。

## 何時使用唯一本地位址

ULA 適合用來在單一網路內或透過 VPN 互連的多個站點之間，提供穩定的 IPv6 位址。裝置可以同時使用全球單播 IPv6 位址存取網際網路，並以 ULA 存取內部服務。
