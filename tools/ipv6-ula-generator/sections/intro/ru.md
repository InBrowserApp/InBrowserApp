## Как сгенерировать префикс IPv6 ULA /48

Скопируйте сгенерированный префикс `fd` для домашней сети, лаборатории или VPN. Сохраните выбранный `/48` вместе с настройками сети, чтобы использовать его при добавлении подсетей. Для нового выделения адресов выберите **Сгенерировать новый префикс**.

## Как рассчитать подсеть /64

Введите шестнадцатеричный **ID подсети** от `0000` до `ffff`. Например, ID `00a0` внутри `fd12:3456:789a::/48` даёт `fd12:3456:789a:a0::/64`. Один префикс `/48` даёт 65 536 возможных подсетей `/64`. Так можно назначить отдельные префиксы для локальной сети, гостевого Wi-Fi и VPN.

## Откуда берётся префикс fd

RFC 4193 выделяет диапазон `fc00::/7` для уникальных локальных адресов. Его половина для локального назначения, `fd00::/8`, начинается с `fd`. Генератор дополняет её случайным 40-битным глобальным ID из Web Crypto API браузера и получает префикс `/48`.

## Когда использовать уникальный локальный адрес

ULA подходит для постоянной IPv6-адресации внутри сети или между площадками, соединёнными по VPN. Устройство может одновременно использовать глобальный IPv6-адрес для доступа в интернет и ULA для внутренних сервисов.
