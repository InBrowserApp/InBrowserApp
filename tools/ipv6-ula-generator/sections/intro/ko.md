## IPv6 ULA /48 프리픽스 생성하기

생성된 `fd` 프리픽스를 복사해 가정 네트워크, 실험실 네트워크 또는 VPN에 사용하세요. 선택한 `/48`을 네트워크 설정과 함께 저장해 두면 서브넷을 추가할 때 재사용할 수 있습니다. 새로 할당하려면 **새 프리픽스 생성**을 선택하세요.

## /64 서브넷 계산하기

`0000`부터 `ffff`까지의 16진수 **서브넷 ID**를 입력하세요. 예를 들어 `fd12:3456:789a::/48`에서 ID `00a0`을 선택하면 `fd12:3456:789a:a0::/64`가 나옵니다. `/48` 하나에 `/64` 서브넷을 65,536개 만들 수 있으므로 LAN, 게스트 Wi-Fi, VPN 등에 별도 프리픽스를 할당할 수 있습니다.

## fd 프리픽스가 만들어지는 방식

RFC 4193은 `fc00::/7`을 고유 로컬 주소 공간으로 정의합니다. 그중 로컬에서 할당하는 절반인 `fd00::/8`은 `fd`로 시작합니다. 생성기는 브라우저의 Web Crypto API에서 가져온 40비트 난수를 글로벌 ID로 붙여 `/48`을 만듭니다.

## 고유 로컬 주소를 사용하는 경우

네트워크 내부나 VPN으로 연결된 사이트 간에 안정적인 IPv6 주소가 필요할 때 ULA를 사용하세요. 하나의 기기에서 내부 서비스에는 ULA를, 공용 인터넷 트래픽에는 전역 IPv6 주소를 함께 사용할 수 있습니다.
