## 生成 IPv6 ULA /48 前缀

复制生成的 `fd` 前缀，用于家庭网络、实验环境或 VPN。将选定的 `/48` 与网络配置一起保存，以便后续添加子网时继续使用。需要新的分配时，点击 **生成新前缀**。

## 计算 /64 子网

输入 `0000` 到 `ffff` 之间的十六进制 **子网 ID**。例如，在 `fd12:3456:789a::/48` 中输入 `00a0`，即可得到 `fd12:3456:789a:a0::/64`。一个 `/48` 可以划分出 65,536 个 `/64` 子网，可分别给局域网、访客 Wi-Fi 和 VPN 等网络分配前缀。

## fd 前缀从哪里来

RFC 4193 将 `fc00::/7` 定义为唯一本地地址空间。其中，用于本地分配的一半是 `fd00::/8`，以 `fd` 开头。工具通过浏览器的 Web Crypto API 生成随机的 40 位全局 ID，再与前缀组合成 `/48`。

## 什么时候用唯一本地地址

需要在单个网络内部或通过 VPN 互联的多个站点间使用稳定的 IPv6 地址时，可以使用 ULA。同一台设备可以同时用全局 IPv6 地址访问公网，并用 ULA 连接内部服务。
