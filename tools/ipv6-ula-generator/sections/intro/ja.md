## IPv6 ULA の /48 プレフィックスを生成する

生成された `fd` プレフィックスをコピーして、自宅のネットワーク、検証環境、VPN に使えます。選んだ `/48` をネットワーク設定と一緒に保存しておくと、サブネットを追加するときに再利用できます。新しい割り当てが必要な場合は、**新しいプレフィックスを生成**を選びます。

## /64 サブネットを計算する

`0000` から `ffff` までの 16 進数を **サブネット ID** に入力します。たとえば、`fd12:3456:789a::/48` で ID に `00a0` を指定すると、`fd12:3456:789a:a0::/64` になります。1 つの `/48` から 65,536 個の `/64` を作れるため、LAN、ゲスト Wi-Fi、VPN などに個別のプレフィックスを割り当てられます。

## fd プレフィックスの仕組み

RFC 4193 では、ユニークローカルアドレスに `fc00::/7` が割り当てられています。そのうちローカル割り当て用の半分は `fd00::/8` で、先頭は `fd` です。このツールでは、ブラウザーの Web Crypto API で生成した 40 ビットのランダムなグローバル ID を加えて `/48` を作ります。

## ユニークローカルアドレスの使いどころ

ULA は、同じネットワーク内や VPN でつないだ拠点間で、安定した IPv6 アドレスが必要なときに使えます。端末にグローバル IPv6 アドレスも設定すれば、インターネットとの通信にはグローバルアドレスを、内部サービスには ULA を使えます。
