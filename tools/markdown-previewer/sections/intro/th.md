## เครื่องมือนี้ทำอะไร

โปรแกรมดูตัวอย่าง Markdown เปิดเอกสาร `.md`, `.markdown`, `.mdown` และ `.txt` บนอุปกรณ์ในเบราว์เซอร์ของคุณ โหมดอ่านซ่อนตัวแก้ไขต้นฉบับ ส่วนโหมดมีสมาธิให้เอกสารใช้พื้นที่หน้าจอ ปรับขนาดข้อความ ความกว้างในการอ่าน และธีมสะอาดหรือสเลตได้โดยไม่เสียตำแหน่งที่อ่านอยู่ โครงร่างที่ยุบได้ช่วยนำทางไปยังหัวข้อ Markdown และตารางกับบล็อกโค้ดที่กว้างสามารถเลื่อนแยกกันได้

## ควรใช้เมื่อใด

ใช้สำหรับ README บันทึกการออกรุ่น คู่มือปฏิบัติงาน และเอกสาร Markdown อื่น ๆ รองรับ Markdown มาตรฐาน รวมถึงตาราง รายการงาน ข้อความขีดฆ่า และบล็อกโค้ดแบบ fenced ตามรูปแบบ GitHub โค้ดไม่มีการเน้นสีไวยากรณ์ และไม่แสดงผลคณิตศาสตร์ แผนภาพ เชิงอรรถ และส่วนขยายรูปแบบอื่น ๆ HTML แบบ inline จะถูกกรองให้ปลอดภัย สคริปต์ สไตล์ แบบฟอร์ม และเนื้อหาที่ฝังไม่สามารถทำงานได้ ระบบไม่ดึงรูปภาพและแบบอักษรจากภายนอก รูปภาพที่ใช้เส้นทางสัมพัทธ์ต้องอาศัยไฟล์ที่ไม่ได้ให้มาด้วย จึงแสดงข้อความแทนรูปภาพหากมี รูปภาพแรสเตอร์ที่ฝังอยู่ใช้งานได้ แต่รูปภาพ SVG และลิงก์ไปยังเอกสารอื่นบนอุปกรณ์จะไม่ถูกโหลด

## เคล็ดลับเวิร์กโฟลว์

เปิดหรือวางไฟล์เพื่อเริ่มอ่าน จากนั้นเลือกแก้ไขเพื่อตรวจสอบหรือเปลี่ยนแปลงต้นฉบับ เนื้อหาไฟล์บนอุปกรณ์และการแก้ไขจะอยู่ในหน่วยความจำและถูกทิ้งเมื่อคุณปิดหรือโหลดหน้าใหม่ ไฟล์ต้นฉบับจะไม่ถูกเปลี่ยนแปลง ร่างที่กำลังแก้ไขแยกต่างหากจะบันทึกในเบราว์เซอร์นี้และกลับมาเมื่อคุณปิดไฟล์บนอุปกรณ์ ใช้ล้างข้อความขณะไม่มีไฟล์เปิดอยู่เพื่อลบร่างที่บันทึกไว้ คัดลอก HTML ดาวน์โหลด HTML และพิมพ์จะคงเนื้อหาที่แสดงผลและธีมที่เลือกไว้ การส่งออกใช้ข้อจำกัดด้านความปลอดภัยของทรัพยากรเดียวกับตัวอย่าง โดยไม่รวมขนาดข้อความและความกว้างที่ใช้ในการอ่าน
