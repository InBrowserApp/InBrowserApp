## 이 도구가 하는 일

Markdown Previewer는 브라우저에서 `.md`, `.markdown`, `.mdown`, `.txt` 문서를 로컬로 엽니다. 읽기 모드에서는 소스 편집기가 숨겨지고, 집중 모드에서는 문서가 화면을 채웁니다. 읽던 위치를 유지하면서 글자 크기, 읽기 너비, 깔끔한 테마 또는 슬레이트 테마를 조절하세요. 접을 수 있는 목차로 Markdown 제목 사이를 이동할 수 있으며, 넓은 표와 코드 블록은 각각 따로 스크롤됩니다.

## 언제 사용하면 좋은가

README, 릴리스 노트, 운영 지침서 등 Markdown 문서를 읽을 때 사용하세요. 표준 Markdown과 GitHub 스타일의 표, 작업 목록, 취소선, 펜스 코드 블록을 지원합니다. 코드에는 구문 강조가 적용되지 않으며 수식, 다이어그램, 각주 및 기타 Markdown 확장 문법은 렌더링되지 않습니다. 인라인 HTML은 안전하게 정리되며 스크립트, 스타일, 양식, 삽입 콘텐츠는 실행되지 않습니다. 원격 이미지와 글꼴은 가져오지 않습니다. 상대 경로 이미지는 제공되지 않은 파일이 필요하므로 대체 텍스트가 있으면 대신 표시합니다. 문서에 포함된 래스터 이미지는 표시되지만 SVG 이미지와 다른 로컬 문서로 연결되는 링크는 불러오지 않습니다.

## 작업 흐름 팁

파일을 열거나 끌어다 놓아 읽기를 시작한 다음, 편집을 선택해 소스를 확인하거나 수정하세요. 로컬 파일의 내용과 수정 사항은 메모리에만 남으며 페이지를 닫거나 새로고침하면 사라집니다. 원본 파일은 변경되지 않습니다. 별도의 편집 초안은 이 브라우저에 저장되며 로컬 파일을 닫으면 다시 표시됩니다. 열린 파일이 없을 때 텍스트 지우기를 선택하면 저장된 초안이 삭제됩니다. HTML 복사, HTML 다운로드, 인쇄는 렌더링된 내용과 선택한 테마를 유지합니다. 내보내기에는 미리보기와 동일한 안전한 리소스 제한이 적용되며, 읽기 화면의 글자 크기와 너비는 포함되지 않습니다.
