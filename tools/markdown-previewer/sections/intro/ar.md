## ما الذي تفعله هذه الأداة

يفتح معاين Markdown مستندات `.md` و`.markdown` و`.mdown` و`.txt` محلياً في متصفحك. يخفي وضع القراءة محرر المصدر، بينما يخصص وضع التركيز الشاشة للمستند. عدّل حجم النص وعرض القراءة والسمة النظيفة أو الداكنة دون فقدان موضعك. يتيح المخطط القابل للطي التنقل بين عناوين Markdown، ويمكن تمرير الجداول العريضة وكتل التعليمات البرمجية بشكل مستقل.

## متى تستخدمها

استخدمها لملفات README وملاحظات الإصدارات وكتيبات التشغيل ومستندات Markdown الأخرى. تدعم Markdown القياسي والجداول وقوائم المهام والنص المشطوب وكتل التعليمات البرمجية المسيّجة بأسلوب GitHub. لا تُلوّن التعليمات البرمجية حسب بناء الجملة؛ ولا تُعرض الصيغ الرياضية والمخططات والحواشي السفلية وامتدادات صيَغ Markdown الأخرى. تتم تنقية HTML المضمّن، ولا يمكن تشغيل النصوص البرمجية والأنماط والنماذج والعناصر المضمّنة. لا تُجلب الصور والخطوط البعيدة. تحتاج الصور ذات المسارات النسبية إلى ملفات لم تُقدّم؛ ويبقى النص البديل ظاهراً عند توفره. تعمل الصور النقطية المضمّنة، لكن صور SVG وروابط المستندات المحلية الأخرى لا تُحمّل.

## نصائح لسير العمل

افتح ملفاً أو أفلته لبدء القراءة، ثم اختر تحرير لفحص مصدره أو تغييره. تبقى محتويات الملف المحلي والتعديلات في الذاكرة وتُحذف عند إغلاق الصفحة أو إعادة تحميلها؛ ولا يتغير ملفك الأصلي مطلقاً. تُحفظ مسودة التحرير المنفصلة في هذا المتصفح وتُستعاد عند إغلاق الملف المحلي. استخدم مسح النص دون فتح أي ملف لحذف تلك المسودة المحفوظة. تحافظ خيارات نسخ HTML وتنزيل HTML والطباعة على المحتوى المعروض والسمة المحددة. تخضع الملفات المُصدّرة لقيود الموارد الآمنة نفسها المستخدمة في المعاينة؛ ولا تشمل حجم النص أو العرض المحددين للقراءة.
