## Qué Hace Esta Herramienta

Vista previa de Markdown abre documentos `.md`, `.markdown`, `.mdown` y `.txt` localmente en tu navegador. El modo de lectura oculta el editor del código fuente, mientras que el modo sin distracciones dedica la pantalla al documento. Ajusta el tamaño del texto, el ancho de lectura y el tema limpio o pizarra sin perder tu posición. El esquema plegable permite navegar por los encabezados Markdown, y las tablas anchas y los bloques de código se desplazan de forma independiente.

## Cuándo Usarla

Úsala para README, notas de versión, runbooks y otros documentos Markdown. Admite Markdown estándar y tablas, listas de tareas, texto tachado y bloques de código delimitados al estilo de GitHub. El código no tiene resaltado de sintaxis; no se renderizan fórmulas matemáticas, diagramas, notas al pie ni otras extensiones de variantes de Markdown. El HTML en línea se sanea, y los scripts, estilos, formularios y elementos incrustados no pueden ejecutarse. No se descargan imágenes ni fuentes remotas. Las imágenes con rutas relativas necesitan archivos que no se han proporcionado; el texto alternativo permanece visible cuando está disponible. Las imágenes de mapa de bits incrustadas funcionan, pero no se cargan las imágenes SVG ni los enlaces a otros documentos locales.

## Consejos De Flujo De Trabajo

Abre o arrastra un archivo para empezar a leer y luego elige Editar para inspeccionar o modificar su código fuente. El contenido de los archivos locales y sus modificaciones permanecen en memoria y se descartan al cerrar o recargar la página; el archivo original nunca se modifica. El borrador de edición independiente se guarda en este navegador y se restaura al cerrar un archivo local. Usa Borrar texto sin ningún archivo abierto para eliminar ese borrador guardado. Copiar HTML, Descargar HTML e Imprimir conservan el contenido renderizado y el tema seleccionado. Las exportaciones usan las mismas restricciones de seguridad para los recursos que la vista previa; no incluyen el tamaño del texto ni el ancho del área de lectura.
