## このツールでできること

Markdown プレビューアーは `.md`、`.markdown`、`.mdown`、`.txt` 文書をブラウザー内でローカルに開きます。読書モードではソースエディターを隠し、集中モードでは文書を画面いっぱいに表示します。読んでいる位置を保ったまま、文字サイズ、表示幅、クリーンまたはスレートのテーマを調整できます。折りたたみ可能なアウトラインから Markdown の見出しに移動でき、幅の広い表やコードブロックは個別にスクロールできます。

## 使う場面

README、リリースノート、運用手順書などの Markdown 文書に使えます。標準の Markdown と、GitHub 形式の表、タスクリスト、取り消し線、フェンス付きコードブロックに対応しています。コードに構文ハイライトはなく、数式、図、脚注、その他の方言拡張はレンダリングされません。インライン HTML はサニタイズされ、スクリプト、スタイル、フォーム、埋め込みは実行できません。リモートの画像やフォントは取得しません。相対パスの画像には未提供のファイルが必要なため、代替テキストがあれば表示します。埋め込みのラスター画像は表示できますが、SVG 画像や他のローカル文書へのリンクは読み込まれません。

## ワークフローのヒント

ファイルを開くかドロップして読み始め、ソースを確認・変更したいときは「編集」を選びます。ローカルファイルの内容と編集内容はメモリ内に保持され、ページを閉じるか再読み込みすると破棄されます。元のファイルは変更されません。編集用の下書きは別途このブラウザーに保存され、ローカルファイルを閉じると復元されます。保存済みの下書きを削除するには、ファイルを開いていない状態で「テキストを消去」を使います。「HTML をコピー」「HTML をダウンロード」「印刷」では、レンダリングされた内容と選択中のテーマが保持されます。書き出しにもプレビューと同じ安全なリソース制限が適用され、閲覧時の文字サイズや表示幅は反映されません。
