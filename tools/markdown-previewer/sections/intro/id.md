## Yang Dilakukan Alat Ini

Pratinjau Markdown membuka dokumen `.md`, `.markdown`, `.mdown`, dan `.txt` secara lokal di browser Anda. Mode baca menyembunyikan editor sumber, sedangkan mode fokus memberikan ruang layar untuk dokumen. Sesuaikan ukuran teks, lebar baca, serta tema bersih atau slate tanpa kehilangan posisi baca. Kerangka yang dapat dilipat menavigasi judul Markdown, sementara tabel lebar dan blok kode dapat digulir secara terpisah.

## Kapan Menggunakannya

Gunakan untuk README, catatan rilis, runbook, dan dokumen Markdown lainnya. Markdown standar serta tabel bergaya GitHub, daftar tugas, teks coret, dan blok kode berpagar didukung. Kode tidak memiliki penyorotan sintaks; rumus matematika, diagram, catatan kaki, dan ekstensi dialek lainnya tidak dirender. HTML inline disanitasi, dan skrip, gaya, formulir, serta sematan tidak dapat berjalan. Gambar dan font jarak jauh tidak diambil. Gambar relatif memerlukan file yang belum disediakan; teks alternatif tetap terlihat jika tersedia. Gambar raster yang disematkan berfungsi, tetapi gambar SVG dan tautan ke dokumen lokal lain tidak dimuat.

## Tips Alur Kerja

Buka atau letakkan file untuk mulai membaca, lalu pilih Edit untuk memeriksa atau mengubah sumbernya. Konten file lokal dan perubahan tetap berada di memori dan dibuang saat Anda menutup atau memuat ulang halaman; file asli Anda tidak pernah diubah. Draf penyuntingan yang terpisah disimpan di browser ini dan dipulihkan saat Anda menutup file lokal. Gunakan Hapus teks saat tidak ada file yang terbuka untuk menghapus draf tersimpan tersebut. Salin HTML, Unduh HTML, dan Cetak mempertahankan konten yang dirender dan tema yang dipilih. Ekspor menggunakan pembatasan sumber daya aman yang sama dengan pratinjau; ukuran teks dan lebar area baca tidak disertakan.
