## 這個工具能做什麼

Markdown 預覽器可在瀏覽器中開啟本機的 `.md`、`.markdown`、`.mdown` 與 `.txt` 文件。閱讀模式會隱藏原始內容編輯器，專注模式則讓文件占滿畫面。你可以調整文字大小、閱讀寬度，以及簡潔或深色主題，同時保留閱讀位置。可收合的目錄能導覽 Markdown 標題，寬表格與程式碼區塊則可各自捲動。

## 什麼時候適合用它

適合閱讀 README、版本更新說明、操作手冊及其他 Markdown 文件。支援標準 Markdown，以及 GitHub 風格的表格、工作清單、刪除線與圍欄程式碼區塊。程式碼沒有語法醒目提示；數學公式、圖表、註腳及其他方言擴充語法不會渲染。內嵌 HTML 會經過淨化，指令碼、樣式、表單與內嵌內容皆無法執行。遠端圖片與字型不會載入。相對路徑的圖片需要尚未提供的檔案；如果有替代文字，仍會顯示該文字。內嵌點陣圖片可正常顯示，但 SVG 圖片與指向其他本機文件的連結不會載入。

## 工作流程建議

開啟或拖放檔案即可開始閱讀，再選擇「編輯」以檢查或修改原始內容。本機檔案內容與編輯會保留在記憶體中，並在你關閉或重新載入頁面時捨棄；原始檔案絕不會變更。獨立的編輯草稿會儲存於此瀏覽器，並在你關閉本機檔案時恢復。未開啟檔案時，使用「清空文字」即可移除已儲存的草稿。「複製 HTML」、「下載 HTML」與「列印」會保留渲染後的內容及選取的主題。匯出採用與預覽相同的安全資源限制，不包含預覽器的文字大小與寬度設定。
