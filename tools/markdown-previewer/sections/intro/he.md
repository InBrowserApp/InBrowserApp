## מה הכלי הזה עושה

Markdown Previewer פותח מסמכי `.md`, `.markdown`, `.mdown` ו-`.txt` באופן מקומי בדפדפן שלך. מצב קריאה מסתיר את עורך המקור, ומצב מיקוד מפנה את המסך למסמך. התאם את גודל הטקסט, את רוחב הקריאה ואת ערכת הנושא הנקייה או הכהה בלי לאבד את המקום שלך. המתאר שניתן לכווץ מאפשר לנווט בין כותרות Markdown, ואפשר לגלול טבלאות רחבות ובלוקי קוד בנפרד.

## מתי להשתמש בו

השתמש בו עבור קובצי README, הערות גרסה, מדריכי תפעול ומסמכי Markdown אחרים. הכלי תומך ב-Markdown רגיל ובטבלאות, רשימות משימות, קו חוצה ובלוקי קוד מגודרים בסגנון GitHub. לקוד אין הדגשת תחביר; נוסחאות מתמטיות, תרשימים, הערות שוליים והרחבות אחרות של הניב אינם מרונדרים. HTML מוטמע עובר סינון, וסקריפטים, סגנונות, טפסים והטמעות אינם יכולים לפעול. תמונות וגופנים מרוחקים אינם נטענים. תמונות עם נתיבים יחסיים זקוקות לקבצים שלא סופקו; טקסט חלופי נשאר גלוי כשהוא זמין. תמונות רסטר מוטמעות פועלות, אך תמונות SVG וקישורים למסמכים מקומיים אחרים אינם נטענים.

## עצות לתהליך העבודה

פתח או גרור קובץ כדי להתחיל לקרוא, ואז בחר עריכה כדי לבדוק או לשנות את המקור שלו. תוכן הקובץ המקומי והעריכות בו נשארים בזיכרון ונמחקים כשסוגרים את הדף או טוענים אותו מחדש; הקובץ המקורי שלך לעולם אינו משתנה. טיוטת העריכה הנפרדת נשמרת בדפדפן הזה ומשוחזרת כשסוגרים קובץ מקומי. השתמש בניקוי הטקסט כשאין קובץ פתוח כדי להסיר את הטיוטה השמורה. העתקת HTML, הורדת HTML והדפסה משמרות את התוכן המרונדר ואת ערכת הנושא שנבחרה. על הייצוא חלות אותן מגבלות בטיחות על משאבים כמו בתצוגה המקדימה; גודל הטקסט ורוחב אזור הקריאה אינם נכללים בו.
