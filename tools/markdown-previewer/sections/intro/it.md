## Cosa Fa Questo Strumento

Markdown Previewer apre documenti `.md`, `.markdown`, `.mdown` e `.txt` localmente nel browser. La modalità Leggi nasconde l’editor del sorgente, mentre la modalità concentrazione dedica lo schermo al documento. Regola la dimensione del testo, la larghezza di lettura e il tema pulito o ardesia senza perdere il punto. La struttura comprimibile permette di navigare tra i titoli Markdown, mentre tabelle larghe e blocchi di codice scorrono in modo indipendente.

## Quando Usarlo

Usalo per README, note di rilascio, runbook e altri documenti Markdown. Sono supportati Markdown standard e tabelle, elenchi di attività, testo barrato e blocchi di codice delimitati in stile GitHub. Il codice non ha evidenziazione della sintassi; formule matematiche, diagrammi, note a piè di pagina e altre estensioni dei dialetti Markdown non vengono renderizzati. L’HTML inline viene sanificato e script, stili, moduli e contenuti incorporati non possono essere eseguiti. Le immagini e i caratteri remoti non vengono recuperati. Le immagini relative richiedono file non forniti; il testo alternativo rimane visibile quando disponibile. Le immagini raster incorporate funzionano, mentre le immagini SVG e i link ad altri documenti locali non vengono caricati.

## Suggerimenti Di Flusso

Apri o trascina un file per iniziare a leggere, poi scegli Modifica per esaminare o cambiare il sorgente. Il contenuto dei file locali e le modifiche restano in memoria e vengono scartati quando chiudi o ricarichi la pagina; il file originale non viene mai modificato. La bozza di modifica separata viene salvata in questo browser e ripristinata quando chiudi un file locale. Usa Cancella testo senza file aperti per rimuovere la bozza salvata. Copia HTML, Scarica HTML e Stampa conservano il contenuto renderizzato e il tema selezionato. Le esportazioni usano le stesse restrizioni di sicurezza sulle risorse dell’anteprima; la dimensione del testo e la larghezza di lettura non vengono incluse.
