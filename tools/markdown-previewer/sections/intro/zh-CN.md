## 这个工具能做什么

Markdown 预览器会在浏览器中本地打开 `.md`、`.markdown`、`.mdown` 和 `.txt` 文档。阅读模式会隐藏源码编辑器，专注模式则让文档占据屏幕。调整文字大小、阅读宽度以及简洁或深色主题时，不会丢失阅读位置。可折叠目录方便你跳转到 Markdown 标题，宽表格和代码块可以独立滚动。

## 什么时候适合用它

它适合阅读 README、更新日志、操作手册和其他 Markdown 文档。支持标准 Markdown 以及 GitHub 风格的表格、任务列表、删除线和围栏代码块。代码不显示语法高亮；不渲染数学公式、图表、脚注及其他方言扩展。内联 HTML 会经过净化处理，脚本、样式、表单和嵌入内容无法运行。不会获取远程图片和字体。相对路径图片所需的文件未提供；如果有替代文本，仍会显示该文本。支持嵌入的位图图片，但不会加载 SVG 图片和指向其他本地文档的链接。

## 工作流建议

打开或拖放文件即可开始阅读，然后选择“编辑”来查看或修改源文本。本地文件内容和修改仅保留在内存中，关闭或重新加载页面时会丢弃；原始文件始终不会改变。单独的编辑草稿会保存在此浏览器中，并在关闭本地文件时恢复显示。未打开文件时，使用“清空文本”即可删除已保存的草稿。“复制 HTML”“下载 HTML”和“打印”会保留渲染内容和所选主题。导出内容采用与预览相同的安全资源限制，不包含阅读时设置的文字大小和宽度。
