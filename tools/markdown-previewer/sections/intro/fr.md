## Ce Que Fait Cet Outil

Markdown Previewer ouvre les documents `.md`, `.markdown`, `.mdown` et `.txt` localement dans ton navigateur. Le mode lecture masque l’éditeur source, tandis que le mode concentration laisse tout l’écran au document. Ajuste la taille du texte, la largeur de lecture et le thème clair ou ardoise sans perdre ta position. Le plan repliable permet de naviguer entre les titres Markdown, et les tableaux larges et les blocs de code défilent indépendamment.

## Quand L’utiliser

Utilise-le pour les README, les notes de version, les procédures d’exploitation et d’autres documents Markdown. Le Markdown standard ainsi que les tableaux, listes de tâches, textes barrés et blocs de code clôturés de style GitHub sont pris en charge. Le code n’a pas de coloration syntaxique ; les formules mathématiques, diagrammes, notes de bas de page et autres extensions de dialecte ne sont pas rendus. Le HTML en ligne est nettoyé, et les scripts, styles, formulaires et contenus intégrés ne peuvent pas s’exécuter. Les images et polices distantes ne sont pas chargées. Les images relatives nécessitent des fichiers qui n’ont pas été fournis ; leur texte alternatif reste visible lorsqu’il est disponible. Les images matricielles intégrées fonctionnent, mais les images SVG et les liens vers d’autres documents locaux ne sont pas chargés.

## Conseils De Flux De Travail

Ouvre ou dépose un fichier pour commencer à lire, puis choisis Modifier pour examiner ou changer sa source. Le contenu du fichier local et les modifications restent en mémoire et sont abandonnés lorsque tu fermes ou recharges la page ; ton fichier d’origine n’est jamais modifié. Le brouillon d’édition distinct est enregistré dans ce navigateur et restauré lorsque tu fermes un fichier local. Utilise Effacer le texte sans fichier ouvert pour supprimer ce brouillon enregistré. Copier le HTML, Télécharger le HTML et Imprimer conservent le contenu rendu et le thème sélectionné. Les exports appliquent les mêmes restrictions de ressources que l’aperçu pour rester sûrs ; la taille du texte et la largeur de lecture ne sont pas incluses.
