## APK를 열고 매니페스트 읽기

Android `.apk` 파일을 끌어다 놓거나 **APK 또는 매니페스트 열기**를 선택하세요. 뷰어는 대부분의 APK에서 쓰는 컴파일된 바이너리 XML을 포함하여 APK에 들어 있는 `AndroidManifest.xml`을 읽습니다. 이전에 추출한 바이너리 또는 텍스트 매니페스트도 열 수 있습니다. 샘플 APK로 개요와 디코딩한 XML을 살펴보세요. 파일은 브라우저에서 처리됩니다.

## 패키지, 버전, SDK 항목 이해하기

**패키지 이름**은 Android 앱을 식별합니다. 버전 이름은 사용자에게 표시되는 출시 버전의 이름이고, 버전 코드는 Android가 업데이트 순서를 판단하는 데 사용하는 숫자입니다. 최소 SDK는 매니페스트에 선언된 가장 낮은 Android API 수준이며, 타겟 SDK는 앱이 대상으로 하는 API 수준입니다. 매니페스트에 없는 항목은 ‘지정되지 않음’으로 표시됩니다.

## 권한을 확인하고 AndroidManifest.xml 내보내기

개요에는 패키지가 선언한 권한 이름이 표시됩니다. 기기에서 실제로 부여되는 권한은 Android가 OS 버전, 앱 설정 및 사용자의 선택에 따라 결정합니다. **매니페스트 XML**을 열면 구성요소, 인텐트 필터, 조건부 권한 선언을 확인할 수 있습니다. **XML 복사** 또는 **XML 다운로드**를 사용해 디코딩한 XML을 저장하세요. 컴파일된 리소스에 대한 참조는 `@0x7f010001`과 같은 ID로 표시될 수 있습니다.
