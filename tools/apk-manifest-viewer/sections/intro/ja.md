## APK を開いてマニフェストを読む

Android の `.apk` ファイルをドラッグ＆ドロップするか、**APK またはマニフェストを開く**を選びます。ビューアーは APK 内の `AndroidManifest.xml` を読み込みます。ほとんどの APK で使われているコンパイル済みのバイナリ XML にも対応しています。すでに抽出したバイナリ形式またはテキスト形式のマニフェストも開けます。サンプル APK で概要とデコードした XML を確認できます。ファイルはブラウザー内で処理されます。

## パッケージ名、バージョン、SDK の項目を確認する

**パッケージ名**は Android アプリを識別する名前です。バージョン名はユーザーに表示されるリリースのラベルで、バージョンコードは Android が更新順序を判断するための数値です。最小 SDK はマニフェストで宣言された最も古い Android API レベルで、ターゲット SDK はアプリが対象とする API レベルです。マニフェストに記載のない項目は「指定なし」と表示されます。

## 権限を確認して AndroidManifest.xml を書き出す

概要には、パッケージが宣言している権限名が表示されます。端末上で実際に付与される権限は、OS バージョン、アプリの設定、ユーザーの選択に基づいて Android が決定します。**マニフェスト XML** を開くと、コンポーネント、インテント フィルタ、条件付きの権限宣言を確認できます。**XML をコピー**または**XML をダウンロード**で、デコードした XML を保存できます。コンパイル済みのリソースへの参照は、`@0x7f010001` のような ID で表示される場合があります。
