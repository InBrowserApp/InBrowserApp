## เปิด APK และอ่านไฟล์ Manifest

ลากไฟล์ `.apk` ของ Android มาวาง หรือเลือก **เปิด APK หรือไฟล์ Manifest** โปรแกรมจะเปิด `AndroidManifest.xml` ที่อยู่ในแพ็กเกจ รวมถึง XML แบบไบนารีที่คอมไพล์แล้วซึ่งพบใน APK ส่วนใหญ่ คุณยังเปิดไฟล์ Manifest แบบไบนารีหรือข้อความที่แยกออกมาแล้วได้ ลองเปิด APK ตัวอย่างเพื่อดูภาพรวมและ XML ที่ถอดรหัสแล้ว ระบบประมวลผลไฟล์ในเบราว์เซอร์ของคุณ

## ทำความเข้าใจช่องข้อมูลแพ็กเกจ เวอร์ชัน และ SDK

**ชื่อแพ็กเกจ** ใช้ระบุแอป Android ชื่อเวอร์ชันคือชื่อรุ่นที่แสดงให้ผู้ใช้เห็น ส่วนรหัสเวอร์ชันคือตัวเลขที่ Android ใช้จัดลำดับการอัปเดต SDK ขั้นต่ำคือระดับ Android API ต่ำสุดที่ประกาศใน Manifest ส่วน SDK เป้าหมายคือระดับ API เป้าหมายของแอป ช่องที่ไม่มีใน Manifest จะแสดงว่า “ไม่ได้ระบุ”

## ตรวจสอบสิทธิ์และส่งออก AndroidManifest.xml

ภาพรวมจะแสดงชื่อสิทธิ์ที่แพ็กเกจประกาศ Android จะกำหนดสิทธิ์ที่ให้จริงบนอุปกรณ์โดยพิจารณาเวอร์ชันระบบปฏิบัติการ การตั้งค่าแอป และตัวเลือกของผู้ใช้ เปิด **XML ของ Manifest** เพื่อดูคอมโพเนนต์ ตัวกรอง Intent และการประกาศสิทธิ์แบบมีเงื่อนไข เลือก **คัดลอก XML** หรือ **ดาวน์โหลด XML** เพื่อเก็บ XML ที่ถอดรหัสแล้ว การอ้างอิงถึงทรัพยากรที่คอมไพล์แล้วอาจแสดงเป็นรหัส เช่น `@0x7f010001`
