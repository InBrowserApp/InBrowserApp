## Как открыть APK и прочитать его манифест

Перетащите файл `.apk` для Android или выберите **Открыть APK или манифест**. Инструмент открывает `AndroidManifest.xml` из пакета, в том числе скомпилированный бинарный XML, который встречается в большинстве APK. Также можно открыть ранее извлечённый манифест в бинарном или текстовом формате. Откройте пример APK, чтобы посмотреть сводку и декодированный XML. Файлы остаются в вашем браузере.

## Что означают поля пакета, версии и SDK?

**Имя пакета** идентифицирует приложение Android. Имя версии видят пользователи, а код версии — это число, по которому Android определяет порядок обновлений. Минимальный уровень SDK — самый ранний уровень API Android, указанный в манифесте. Целевой уровень SDK показывает, на какой уровень API рассчитано приложение. Для полей, пропущенных в манифесте, отображается «Не указано».

## Как проверить разрешения и экспортировать AndroidManifest.xml

В обзоре перечислены разрешения, объявленные в пакете. Android определяет, какие разрешения выдать на устройстве, с учётом версии операционной системы, настроек приложения и выбора пользователя. Откройте **XML манифеста**, чтобы изучить компоненты, фильтры намерений и условные объявления разрешений. Нажмите **Копировать XML** или **Скачать XML**, чтобы сохранить декодированный файл. Ссылки на скомпилированные ресурсы могут отображаться как идентификаторы, например `@0x7f010001`.
