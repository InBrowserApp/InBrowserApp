## 如何打开 CHM 文件

选择**打开 CHM 文件**，或将 `.chm` 文件拖入查看器。如果文档有起始页，查看器会打开该页面。使用**目录**浏览章节，或通过**筛选主题标题**查找特定条目。点击前进和后退箭头，可以重新查看跟随链接访问过的主题。在小屏幕上，选择**目录**可在主题列表和页面之间切换。

选择**试用示例**，可以浏览 PuTTY 手册，了解编译后的帮助文件是如何组织的。

## 什么是 CHM 文件？

CHM 是 Compiled HTML Help（编译的 HTML 帮助文件）的缩写。微软为 Windows 帮助系统推出了这一格式。CHM 文件将 HTML 主题和图片、样式表等资源打包到一个压缩文件中，通常还包含用于组织主题的目录。一些旧版软件手册、API 参考文档和电子书仍在使用这种格式。

## 没有 Windows 也能阅读 CHM 文件吗？

可以。查看器可在 Windows、macOS、Linux 和移动设备的浏览器中打开文件。你可以阅读页面、打开同一 CHM 文件内的链接，还可以选择和复制文本。如果文件没有目录，查看器会列出可用的主题。

## 查看器如何处理我的文件？

CHM 文件在你的设备上打开和处理。嵌入的图片和样式可以显示，但脚本、外部链接和远程资源会被禁用。如果某个主题无法访问，仍可从目录中选择其他主题。
