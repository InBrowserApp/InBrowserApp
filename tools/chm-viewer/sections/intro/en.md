## How to open a CHM file

Choose **Open CHM file** or drag a `.chm` file into the viewer. The viewer opens the document’s start page when available. Use **Contents** to browse chapters and **Filter topic titles** to find a particular entry. The back and forward arrows let you revisit topics after following links. On a small screen, select **Contents** to switch between the topic list and the page.

Select **Try a sample** to explore the PuTTY manual and see how a compiled help file is organized.

## What is a CHM file?

CHM stands for Compiled HTML Help. Microsoft introduced the format for Windows help systems. A CHM file packages HTML topics and resources such as images and stylesheets into a single compressed file. It often includes a table of contents to organize the topics. Older software manuals, API references, and some ebooks still use this format.

## Can I read CHM files without Windows?

Yes. The viewer opens the file in your browser on Windows, macOS, Linux, and mobile devices. You can read the pages, follow links within the same CHM, and select and copy text. If the file lacks a table of contents, the viewer lists the available topics.

## How does the viewer handle my file?

Your CHM file is opened and processed on your device. Embedded images and styles can display, while scripts, external links, and remote resources are disabled. If a particular topic is unavailable, you can still select another one from the contents.
