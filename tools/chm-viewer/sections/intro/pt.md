## Como abrir um arquivo CHM

Selecione **Abrir arquivo CHM** ou arraste um arquivo `.chm` para o visualizador. A página inicial do documento será aberta, se estiver disponível. Use o **Sumário** para navegar pelos capítulos e **Filtrar títulos dos tópicos** para encontrar um item específico. Após seguir links, use as setas de voltar e avançar para revisitar os tópicos. Em uma tela pequena, selecione **Sumário** para alternar entre a lista de tópicos e a página.

Selecione **Experimentar um exemplo** para explorar o manual do PuTTY e ver como um arquivo de ajuda compilado é organizado.

## O que é um arquivo CHM?

CHM significa Compiled HTML Help. A Microsoft introduziu esse formato para os sistemas de ajuda do Windows. Um arquivo CHM reúne tópicos HTML e recursos como imagens e folhas de estilo em um único arquivo compactado. Ele geralmente inclui um sumário para organizar os tópicos. Manuais de software mais antigos, referências de API e alguns livros digitais ainda usam esse formato.

## Posso ler arquivos CHM sem Windows?

Sim. O visualizador abre o arquivo no navegador em dispositivos Windows, macOS, Linux e móveis. Você pode ler as páginas, seguir links dentro do mesmo CHM e selecionar e copiar texto. Se o arquivo não tiver um sumário, o visualizador listará os tópicos disponíveis.

## Como o visualizador trata meu arquivo?

Seu arquivo CHM é aberto e processado no dispositivo. Imagens e estilos incorporados podem ser exibidos, enquanto scripts, links externos e recursos remotos ficam desativados. Se um tópico não estiver disponível, você ainda poderá selecionar outro no sumário.
