## CHM ファイルを開くには

**CHM ファイルを開く**を選択するか、`.chm` ファイルをビューアーにドラッグします。開始ページがある場合は、ビューアーがそのページを開きます。**目次**で章を参照し、**トピックのタイトルを絞り込む**で目的の項目を探せます。リンクをたどった後は、戻る矢印と進む矢印で閲覧したトピックに移動できます。小さな画面では、**目次**を選択してトピック一覧とページを切り替えます。

**サンプルを試す**を選択すると、PuTTY のマニュアルを開き、コンパイル済みヘルプファイルの構成を確認できます。

## CHM ファイルとは？

CHM は Compiled HTML Help の略です。Microsoft が Windows のヘルプシステム向けに導入した形式です。CHM ファイルには、HTML トピックや画像、スタイルシートなどのリソースが単一の圧縮ファイルにまとめられています。多くの場合、トピックを整理するための目次が含まれています。古いソフトウェアのマニュアルや API リファレンス、一部の電子書籍では現在もこの形式が使われています。

## Windows がなくても CHM ファイルを読めますか？

はい。Windows、macOS、Linux、モバイルデバイスのブラウザーでファイルを開けます。ページを読んだり、同じ CHM 内のリンクをたどったり、テキストを選択してコピーしたりできます。ファイルに目次がない場合は、利用可能なトピックの一覧を表示します。

## ファイルはどのように処理されますか？

CHM ファイルはデバイス上で開かれ、処理されます。埋め込まれた画像やスタイルは表示できますが、スクリプト、外部リンク、リモートリソースは無効になります。特定のトピックが利用できない場合でも、目次から別のトピックを選択できます。
