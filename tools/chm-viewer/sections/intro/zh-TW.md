## 如何開啟 CHM 檔案？

選擇 **開啟 CHM 檔案**，或將 `.chm` 檔案拖曳至檢視器。若文件有起始頁，檢視器會先開啟該頁面。使用**目錄**瀏覽章節，並透過**篩選主題標題**尋找特定項目。跟隨連結後，可以使用上一頁和下一頁箭頭重新瀏覽先前開啟的主題。在小螢幕上，選擇**目錄**即可切換主題清單與頁面。

選擇**試用範例**，即可瀏覽 PuTTY 手冊，了解編譯後的說明檔如何組織內容。

## 什麼是 CHM 檔案？

CHM 是 Compiled HTML Help（編譯後的 HTML 說明）的縮寫。Microsoft 為 Windows 說明系統推出了這種格式。CHM 檔案會將 HTML 主題及圖片、樣式表等資源打包成單一壓縮檔案，通常還包含用來組織主題的目錄。部分舊版軟體手冊、API 參考文件和電子書仍使用此格式。

## 不使用 Windows 也能閱讀 CHM 檔案嗎？

可以。檢視器能在 Windows、macOS、Linux 和行動裝置的瀏覽器中開啟檔案。您可以閱讀頁面、跟隨同一個 CHM 檔案內的連結，以及選取並複製文字。若檔案沒有目錄，檢視器會列出可用的主題。

## 檢視器如何處理我的檔案？

CHM 檔案會在您的裝置上開啟和處理。內嵌的圖片和樣式可以顯示，但指令碼、外部連結及遠端資源會停用。若某個主題無法使用，您仍可從目錄中選擇其他主題。
