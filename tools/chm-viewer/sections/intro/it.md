## Come aprire un file CHM

Seleziona **Apri file CHM** oppure trascina un file `.chm` nel visualizzatore. Se disponibile, si aprirà la pagina iniziale del documento. Usa l'**Indice** per esplorare i capitoli e **Filtra i titoli degli argomenti** per trovare una voce specifica. Dopo aver seguito i collegamenti, puoi usare le frecce indietro e avanti per tornare agli argomenti visitati. Su uno schermo piccolo, seleziona **Indice** per passare dall'elenco degli argomenti alla pagina e viceversa.

Seleziona **Prova un esempio** per esplorare il manuale di PuTTY e vedere come è organizzato un file della guida compilato.

## Che cos'è un file CHM?

CHM significa Compiled HTML Help. Microsoft ha introdotto questo formato per i sistemi della guida di Windows. Un file CHM raccoglie argomenti HTML e risorse come immagini e fogli di stile in un unico file compresso. Spesso include un indice per organizzare gli argomenti. Manuali software meno recenti, riferimenti API e alcuni ebook usano ancora questo formato.

## Posso leggere file CHM senza Windows?

Sì. Il visualizzatore apre il file nel browser su Windows, macOS, Linux e dispositivi mobili. Puoi leggere le pagine, seguire i collegamenti all'interno dello stesso CHM e selezionare e copiare il testo. Se il file non contiene un indice, il visualizzatore elenca gli argomenti disponibili.

## Come viene gestito il mio file?

Il file CHM viene aperto ed elaborato sul tuo dispositivo. Le immagini e gli stili incorporati possono essere visualizzati, mentre script, collegamenti esterni e risorse remote sono disabilitati. Se un argomento non è disponibile, puoi comunque sceglierne un altro dall'indice.
