## CHM 파일을 열려면 어떻게 하나요?

**CHM 파일 열기**를 선택하거나 `.chm` 파일을 뷰어로 끌어다 놓으세요. 문서의 시작 페이지가 있으면 뷰어에서 해당 페이지를 엽니다. **목차**에서 장을 살펴보고 **항목 제목 필터링**으로 원하는 항목을 찾을 수 있습니다. 링크를 따라 이동한 뒤에는 뒤로 및 앞으로 화살표를 사용해 방문한 항목을 다시 볼 수 있습니다. 작은 화면에서는 **목차**를 선택해 항목 목록과 페이지 사이를 전환하세요.

**샘플 사용해 보기**를 선택하면 PuTTY 설명서를 살펴보며 컴파일된 도움말 파일의 구성을 확인할 수 있습니다.

## CHM 파일이란 무엇인가요?

CHM은 Compiled HTML Help의 약자입니다. Microsoft가 Windows 도움말 시스템을 위해 도입한 형식입니다. CHM 파일은 HTML 항목과 이미지, 스타일시트 등의 리소스를 하나의 압축 파일로 묶습니다. 항목을 정리한 목차가 포함된 경우가 많습니다. 오래된 소프트웨어 설명서와 API 참조 문서, 일부 전자책에서 여전히 이 형식을 사용합니다.

## Windows 없이 CHM 파일을 읽을 수 있나요?

네. Windows, macOS, Linux 및 모바일 기기의 브라우저에서 파일을 열 수 있습니다. 페이지를 읽고 같은 CHM 파일 안의 링크를 따라가며 텍스트를 선택해 복사할 수 있습니다. 파일에 목차가 없으면 뷰어가 사용 가능한 항목을 나열합니다.

## 뷰어는 파일을 어떻게 처리하나요?

CHM 파일은 사용자 기기에서 열고 처리합니다. 파일에 포함된 이미지와 스타일은 표시될 수 있으며 스크립트, 외부 링크, 원격 리소스는 차단됩니다. 특정 항목을 사용할 수 없더라도 목차에서 다른 항목을 선택할 수 있습니다.
