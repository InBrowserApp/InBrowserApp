## Как открыть файл CHM?

Выберите **Открыть файл CHM** или перетащите файл `.chm` в окно просмотра. Если в документе есть начальная страница, она откроется первой. Откройте **Оглавление**, чтобы просмотреть главы, и используйте **Фильтр названий разделов**, чтобы найти нужный пункт. Стрелки назад и вперёд позволяют возвращаться к разделам после перехода по ссылкам. На небольшом экране выберите **Оглавление**, чтобы переключаться между списком разделов и страницей.

Выберите **Попробовать пример**, чтобы изучить руководство PuTTY и посмотреть, как устроен скомпилированный справочный файл.

## Что такое файл CHM?

CHM означает Compiled HTML Help. Microsoft представила этот формат для справочных систем Windows. Файл CHM объединяет разделы HTML и ресурсы, например изображения и таблицы стилей, в один сжатый файл. Часто он содержит оглавление для навигации по разделам. Этот формат до сих пор используется в старых руководствах к программам, справочниках API и некоторых электронных книгах.

## Можно ли читать файлы CHM без Windows?

Да. Средство просмотра открывает файл в браузере на Windows, macOS, Linux и мобильных устройствах. Вы можете читать страницы, переходить по ссылкам внутри того же файла CHM, выделять и копировать текст. Если в файле нет оглавления, средство просмотра покажет список доступных разделов.

## Как обрабатывается мой файл?

Файл CHM открывается и обрабатывается на вашем устройстве. Встроенные изображения и стили могут отображаться, а скрипты, внешние ссылки и удалённые ресурсы отключены. Если какой-либо раздел недоступен, вы всё равно можете выбрать другой в оглавлении.
