## Cómo abrir un archivo CHM

Elige **Abrir archivo CHM** o arrastra un archivo `.chm` al visor. Si está disponible, el visor abre la página inicial del documento. Usa **Contenido** para explorar los capítulos y **Filtrar títulos de temas** para encontrar una entrada concreta. Las flechas de retroceso y avance te permiten volver a los temas después de seguir enlaces. En una pantalla pequeña, selecciona **Contenido** para alternar entre la lista de temas y la página.

Selecciona **Probar un ejemplo** para explorar el manual de PuTTY y ver cómo se organiza un archivo de ayuda compilado.

## ¿Qué es un archivo CHM?

CHM significa Compiled HTML Help. Microsoft introdujo este formato para los sistemas de ayuda de Windows. Un archivo CHM agrupa temas HTML y recursos como imágenes y hojas de estilo en un único archivo comprimido. A menudo incluye un índice de contenido para organizar los temas. Algunos manuales de software antiguos, referencias de API y libros electrónicos todavía usan este formato.

## ¿Puedo leer archivos CHM sin Windows?

Sí. El visor abre el archivo en tu navegador en Windows, macOS, Linux y dispositivos móviles. Puedes leer las páginas, seguir enlaces dentro del mismo CHM y seleccionar y copiar texto. Si el archivo no tiene índice de contenido, el visor muestra una lista de los temas disponibles.

## ¿Cómo trata el visor mi archivo?

Tu archivo CHM se abre y procesa en tu dispositivo. Se pueden mostrar las imágenes y los estilos integrados, mientras que los scripts, los enlaces externos y los recursos remotos están deshabilitados. Si un tema no está disponible, puedes seleccionar otro en el contenido.
