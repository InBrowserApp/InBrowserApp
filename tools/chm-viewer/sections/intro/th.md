## วิธีเปิดไฟล์ CHM

เลือก **เปิดไฟล์ CHM** หรือลากไฟล์ `.chm` มาวางในโปรแกรมดู หากเอกสารมีหน้าเริ่มต้น โปรแกรมจะเปิดหน้านั้น ใช้ **สารบัญ** เพื่อเรียกดูบทต่าง ๆ และใช้ **กรองชื่อหัวข้อ** เพื่อหารายการที่ต้องการ หลังจากตามลิงก์แล้ว คุณสามารถใช้ลูกศรย้อนกลับและเดินหน้าเพื่อกลับไปยังหัวข้อที่เคยเปิด บนหน้าจอขนาดเล็ก ให้เลือก **สารบัญ** เพื่อสลับระหว่างรายการหัวข้อกับหน้าเนื้อหา

เลือก **ลองใช้ตัวอย่าง** เพื่อสำรวจคู่มือ PuTTY และดูวิธีจัดระเบียบไฟล์วิธีใช้ที่คอมไพล์แล้ว

## ไฟล์ CHM คืออะไร?

CHM ย่อมาจาก Compiled HTML Help เป็นรูปแบบที่ Microsoft สร้างขึ้นสำหรับระบบวิธีใช้ของ Windows ไฟล์ CHM รวมหัวข้อ HTML และทรัพยากร เช่น รูปภาพและสไตล์ชีต ไว้ในไฟล์บีบอัดเดียว โดยมักมีสารบัญสำหรับจัดระเบียบหัวข้อ คู่มือซอฟต์แวร์รุ่นเก่า เอกสารอ้างอิง API และหนังสืออิเล็กทรอนิกส์บางเล่มยังคงใช้รูปแบบนี้

## อ่านไฟล์ CHM โดยไม่ใช้ Windows ได้ไหม?

ได้ โปรแกรมดูเปิดไฟล์ในเบราว์เซอร์บน Windows, macOS, Linux และอุปกรณ์พกพา คุณสามารถอ่านหน้าเนื้อหา ตามลิงก์ภายในไฟล์ CHM เดียวกัน รวมถึงเลือกและคัดลอกข้อความได้ หากไฟล์ไม่มีสารบัญ โปรแกรมจะแสดงรายการหัวข้อที่มีอยู่

## โปรแกรมดูจัดการไฟล์ของฉันอย่างไร?

ไฟล์ CHM จะเปิดและประมวลผลบนอุปกรณ์ของคุณ รูปภาพและรูปแบบที่ฝังอยู่สามารถแสดงได้ แต่สคริปต์ ลิงก์ภายนอก และทรัพยากรจากระยะไกลจะถูกปิดใช้งาน หากหัวข้อใดไม่พร้อมใช้งาน คุณยังสามารถเลือกหัวข้ออื่นจากสารบัญได้
