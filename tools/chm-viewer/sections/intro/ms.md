## Cara membuka fail CHM

Pilih **Buka fail CHM** atau seret fail `.chm` ke dalam pemapar. Pemapar akan membuka halaman mula dokumen jika tersedia. Gunakan **Kandungan** untuk menyemak imbas bab dan **Tapis tajuk topik** untuk mencari entri tertentu. Anak panah kembali dan maju membolehkan anda melawat semula topik selepas mengikuti pautan. Pada skrin kecil, pilih **Kandungan** untuk bertukar antara senarai topik dan halaman.

Pilih **Cuba sampel** untuk meneroka manual PuTTY dan melihat cara fail bantuan terkompil disusun.

## Apakah fail CHM?

CHM bermaksud Compiled HTML Help. Microsoft memperkenalkan format ini untuk sistem bantuan Windows. Fail CHM menggabungkan topik HTML dan sumber seperti imej serta helaian gaya ke dalam satu fail termampat. Ia sering mengandungi senarai kandungan untuk menyusun topik. Manual perisian lama, rujukan API dan sesetengah e-buku masih menggunakan format ini.

## Bolehkah saya membaca fail CHM tanpa Windows?

Ya. Pemapar membuka fail dalam pelayar anda pada Windows, macOS, Linux dan peranti mudah alih. Anda boleh membaca halaman, mengikuti pautan dalam CHM yang sama, serta memilih dan menyalin teks. Jika fail tiada senarai kandungan, pemapar akan menyenaraikan topik yang tersedia.

## Bagaimanakah pemapar mengendalikan fail saya?

Fail CHM anda dibuka dan diproses pada peranti anda. Imej dan gaya terbenam boleh dipaparkan, manakala skrip, pautan luaran dan sumber jauh dilumpuhkan. Jika sesuatu topik tidak tersedia, anda masih boleh memilih topik lain daripada kandungan.
