## Previsualiza un documento LaTeX local

Abre un archivo `.tex` o `.latex` para leer una vista previa limitada y autocontenida. El contenido compatible incluye títulos, encabezados, párrafos, listas habituales, tablas sencillas, fórmulas matemáticas en línea y en bloque, y algunas macros definidas localmente. El código fuente original está disponible para su consulta de solo lectura.

## Comprende las funciones compatibles

Esta es una vista previa de lectura, no una compilación completa de TeX. No se cargan paquetes, clases de documento personalizadas, archivos incluidos, figuras externas, diagramas TikZ ni bases de datos bibliográficas. Las referencias sencillas y un `thebibliography` integrado pueden mostrarse, pero las funciones que dependen de paquetes y las composiciones avanzadas pueden no hacerlo. Los saltos de página, las fuentes, el espaciado y la numeración de ecuaciones pueden diferir de un PDF compilado.

Las notas de la vista previa identifican los comandos no compatibles detectados y los posibles problemas de estructura, con las líneas del código fuente cuando están disponibles. Estas comprobaciones no constituyen una validación completa de TeX. Revisa el código fuente si el contenido parece incompleto. Las tablas anchas y las fórmulas se desplazan horizontalmente dentro del documento.

## Lee con privacidad y comodidad

Los archivos se procesan en tu dispositivo sin subirlos, sin solicitudes automáticas de recursos del documento y sin guardar su contenido. Usa el esquema, el zoom y el modo de lectura sin distracciones para documentos largos. Se admite texto UTF-8 y UTF-16 con BOM. No hay límites fijos de tamaño de archivo ni de cantidad de encabezados; las limitaciones reales de recursos del navegador y del motor pueden impedir la vista previa.
