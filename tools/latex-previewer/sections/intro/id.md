## Pratinjau dokumen LaTeX lokal

Buka file `.tex` atau `.latex` untuk membaca pratinjau terbatas dari satu file lengkap. Konten yang didukung mencakup judul, judul bagian, paragraf, daftar umum, tabel sederhana, matematika dalam baris dan blok, serta beberapa makro yang didefinisikan secara lokal. Sumber asli tersedia untuk diperiksa dalam mode hanya baca.

## Pahami fitur yang didukung

Ini adalah pratinjau untuk membaca, bukan kompilasi TeX lengkap. Paket, kelas dokumen khusus, file yang disertakan, gambar eksternal, diagram TikZ, dan basis data bibliografi tidak dimuat. Referensi sederhana dan `thebibliography` dalam file yang sama dapat ditampilkan, tetapi fitur yang bergantung pada paket dan tata letak lanjutan mungkin tidak. Pemisahan halaman, font, spasi, dan penomoran persamaan dapat berbeda dari PDF hasil kompilasi.

Catatan pratinjau menunjukkan perintah yang terdeteksi tidak didukung dan kemungkinan masalah struktur, beserta baris sumber jika tersedia. Pemeriksaan ini bukan validasi TeX yang menyeluruh. Periksa sumbernya jika konten tampak tidak lengkap. Tabel dan rumus yang lebar dapat digulir secara horizontal di dalam dokumen.

## Baca dengan nyaman dan privat

File diproses di perangkat Anda tanpa unggahan, permintaan sumber daya dokumen secara otomatis, atau penyimpanan isi dokumen. Gunakan kerangka dokumen, perbesaran, dan mode baca fokus untuk dokumen panjang. Teks UTF-8 dan UTF-16 dengan penanda BOM didukung. Tidak ada batas ukuran file atau jumlah judul bagian yang tetap; keterbatasan sumber daya browser dan mesin pratinjau dapat menghalangi pratinjau.
