## Ouvrir un fichier ICS sans l’importer

Cliquez sur **Ouvrir un fichier** pour consulter un export de calendrier ou une invitation au format iCalendar. Vous pouvez aussi choisir **Coller le texte ICS**, puis **Afficher les événements**, pour consulter les données du texte source. Recherchez dans l’agenda par titre, lieu ou description, puis ouvrez un événement pour voir ses détails. L’exemple contient un événement avec des horaires et un événement sur la journée entière.

## Comprendre les horaires et les événements récurrents

Les horaires s’affichent tels qu’ils figurent dans le calendrier, avec le fuseau horaire d’origine lorsqu’il est indiqué. Le libellé **Heure locale** signale qu’aucun fuseau n’est indiqué dans le fichier. Les dates des événements sur la journée entière ne changent pas avec le fuseau horaire du navigateur. Si un tel événement se termine à minuit, la visionneuse affiche son dernier jour effectif.

L’agenda affiche les événements enregistrés dans le fichier. Les événements récurrents sont signalés par un libellé et les occurrences modifiées peuvent s’afficher séparément. Pour consulter les prochaines occurrences, ouvrez le fichier dans votre application de calendrier.

## Qu’est-ce qu’un fichier iCalendar ?

Un fichier ICS peut contenir une invitation ou plusieurs événements exportés depuis Google Agenda, Outlook ou Calendrier d’Apple. La consultation du fichier ici laisse votre calendrier intact. Le fichier est lu dans votre navigateur.
