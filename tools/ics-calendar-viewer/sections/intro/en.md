## Open an ICS file without importing it

Choose **Open file** to inspect an iCalendar export or invitation. You can also use **Paste ICS text** and **View events** to inspect source text. Search the agenda by event title, location, or description. Open an event to read its details. Try the example to see both a timed event and an all-day event.

## Read event times and repeated events

Times are shown as written in the calendar, with the source time zone when present. A time labeled **Local time** has no time zone in the file. All-day dates are read as calendar dates, so they do not shift with the browser’s time zone. An all-day event ending at midnight shows the last day it occupies.

The agenda displays the event records stored in the file. Repeating events carry a recurrence label, and edited occurrences can appear as separate records. The viewer does not generate future occurrences.

## What is an iCalendar file?

An ICS file can contain one calendar invitation or many events exported from Google Calendar, Outlook, or Apple Calendar. Viewing it here leaves your calendar untouched. The file is read in your browser.
