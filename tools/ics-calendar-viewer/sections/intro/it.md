## Aprire un file ICS senza importarlo

Seleziona **Apri file** per consultare un calendario esportato o un invito in formato iCalendar. Puoi anche selezionare **Incolla testo ICS** e poi **Mostra eventi**. Cerca nell’agenda per titolo, luogo o descrizione. Apri un evento per leggerne i dettagli. Prova l’esempio per vedere un evento con orario e uno che dura tutto il giorno.

## Leggere gli orari e gli eventi ricorrenti

Gli orari sono mostrati come appaiono nel calendario, con il fuso orario originale quando è indicato. L’etichetta **Ora locale** indica che il file non specifica il fuso orario. Le date degli eventi che durano tutto il giorno non cambiano in base al fuso orario del browser. Se un evento di questo tipo finisce a mezzanotte, viene mostrato l’ultimo giorno effettivo.

L’agenda mostra gli eventi registrati nel file. Gli eventi ricorrenti sono contrassegnati da un’etichetta e le occorrenze modificate possono apparire separatamente. Per vedere le occorrenze future, apri il file nella tua app di calendario.

## Cos’è un file iCalendar?

Un file ICS può contenere un invito o più eventi esportati da Google Calendar, Outlook o Calendario Apple. Visualizzarli qui lascia il tuo calendario intatto. Il file viene letto nel browser.
