## Buka file ICS tanpa mengimpornya

Pilih **Buka file** untuk melihat hasil ekspor iCalendar atau undangan. Anda juga dapat memilih **Tempel teks ICS**, lalu **Lihat acara** untuk membaca isi teks sumber. Cari acara berdasarkan judul, lokasi, atau deskripsi. Buka acara untuk membaca detailnya. Contoh yang tersedia berisi acara dengan jam tertentu dan acara sepanjang hari.

## Baca waktu acara dan kenali acara berulang

Waktu ditampilkan sebagaimana tercantum di kalender, termasuk zona waktu asal jika tersedia. Label **Waktu setempat** berarti file tidak mencantumkan zona waktu untuk acara tersebut. Tanggal acara sepanjang hari dibaca sebagai tanggal kalender sehingga tidak bergeser mengikuti zona waktu browser. Jika acara sepanjang hari berakhir pada tengah malam, penampil menampilkan tanggal terakhir saat acara masih berlangsung.

Daftar menampilkan entri acara yang disimpan dalam file. Acara berulang diberi label, dan kejadian tertentu yang telah diubah dapat muncul sebagai entri tersendiri. Penampil tidak membuat entri untuk kejadian mendatang.

## Apa itu file iCalendar?

File ICS dapat berisi satu undangan kalender atau banyak acara yang diekspor dari Google Calendar, Outlook, atau Apple Calendar. Membuka file di sini tidak mengubah kalender Anda. Browser Anda membaca file tersebut secara lokal.
