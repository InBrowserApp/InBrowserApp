## Как зачернить данные в PDF онлайн

1. Выберите PDF или перетащите его в инструмент. Файл откроется прямо в браузере на вашем устройстве.
2. Нарисуйте прямоугольник поверх каждого имени, адреса, суммы по договору, подписи или других данных, которые нужно убрать. Увеличьте масштаб для точной разметки и выберите «Перемещать», чтобы осмотреть увеличенную страницу.
3. Перелистывайте страницы, чтобы проверить весь документ. Нажмите «Отменить», чтобы убрать последний прямоугольник на текущей странице.
4. Нажмите **Скачать PDF с зачернением**, чтобы сохранить отдельную копию. Откройте её и проверьте, что каждый прямоугольник полностью закрывает нужные данные.

## Как работает безвозвратное удаление данных из PDF

Инструмент преобразует страницы в изображения, закрашивает отмеченные области и создаёт из этих изображений новый PDF. Пиксели внутри прямоугольников заменяются сплошным чёрным цветом. Исходные текстовые и графические объекты, скрытые текстовые слои, вложения и метаданные в новый файл не попадают. Закрашенные данные нельзя восстановить через поиск, выделение текста, извлечение объектов из PDF или удаление наложенного слоя.

Прямоугольниками можно закрывать обычный текст, фрагменты сканов со слоем распознанного текста (OCR), подписи и рисунки. Если конфиденциальные данные встречаются несколько раз, отметьте каждое видимое вхождение.

## Что содержит экспортированный PDF

В копии сохраняются порядок страниц и их внешний вид за пределами отмеченных областей. Все страницы становятся изображениями, поэтому поиск и выделение текста, активные ссылки и интерактивные формы недоступны. Размер файла может измениться. Исходный файл остаётся без изменений. Инструмент обрабатывает PDF на вашем устройстве, без загрузки на сервер.
