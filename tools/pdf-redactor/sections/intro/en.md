## How to redact a PDF online

1. Choose a PDF or drag it into the tool. Your file opens locally in your browser.
2. Drag a rectangle over each name, address, contract amount, signature, or other detail to remove. Zoom in for a closer view and use Pan to move around a zoomed page.
3. Use the page controls to check the rest of the document. Use Undo to remove the most recent box on the current page.
4. Select **Download redacted PDF** to save a separate copy. Open it and check that each box covers the entire sensitive detail.

## How permanent PDF redaction works

The tool paints each box onto the rendered page and builds a new PDF from the resulting page images. The pixels inside the box are replaced with solid black, and the original text and image objects, hidden text layers, attachments, and metadata are left out of the export. The covered content cannot be found by searching, selecting text, extracting PDF objects, or removing an overlay.

You can redact typed text, scanned documents with an OCR layer, signatures, and figures using the same rectangle tool. If sensitive information appears more than once, mark each visible occurrence.

## What the exported PDF contains

The exported copy preserves the appearance and order of the pages outside your selections. All exported pages are images, so searchable or selectable text, clickable links, and interactive forms are removed. File size can change. The source file is left intact, and the tool processes the PDF on your device without uploading it.
