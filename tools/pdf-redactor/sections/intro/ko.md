## 온라인에서 PDF의 민감 정보를 가리는 방법

1. PDF를 선택하거나 도구로 끌어다 놓으세요. 파일이 브라우저에서 직접 열립니다.
2. 삭제할 이름, 주소, 계약 금액, 서명 등의 정보 위로 드래그해 사각형을 그리세요. 자세히 보려면 확대하고, 확대된 페이지를 둘러보려면 이동 도구를 사용하세요.
3. 페이지 이동 버튼으로 문서의 나머지 부분을 확인하세요. 실행 취소를 누르면 현재 페이지에 마지막으로 그린 상자가 제거됩니다.
4. **가린 PDF 다운로드**를 선택해 별도의 사본을 저장하세요. 저장한 파일을 열어 상자가 민감한 정보를 빠짐없이 덮고 있는지 확인하세요.

## PDF의 민감 정보가 영구 삭제되는 원리

이 도구는 렌더링된 각 페이지에 상자를 그린 다음, 그 결과인 페이지 이미지로 새 PDF를 만듭니다. 상자 안의 픽셀은 검은색으로 바뀌며 원본 텍스트와 이미지 객체, 숨겨진 텍스트 레이어, 첨부 파일, 메타데이터는 내보낸 파일에 포함되지 않습니다. 가린 내용은 검색하거나 텍스트를 선택하거나 PDF 객체를 추출하거나 덮개를 제거해도 찾아낼 수 없습니다.

같은 사각형 도구로 입력된 텍스트, OCR 레이어가 있는 스캔 문서, 서명, 도형을 가릴 수 있습니다. 민감한 정보가 여러 번 등장하면 눈에 보이는 모든 위치에 표시하세요.

## 내보낸 PDF에 포함되는 내용

내보낸 사본은 선택한 영역 밖의 페이지 모양과 페이지 순서를 유지합니다. 내보낸 모든 페이지는 이미지이므로 텍스트 검색과 선택, 링크 클릭, 대화형 양식 기능이 제거됩니다. 파일 크기는 달라질 수 있습니다. 원본 파일은 그대로 유지되며 PDF는 업로드되지 않고 기기에서 처리됩니다.
