## Como censurar um PDF online

1. Escolha um PDF ou arraste o arquivo para a ferramenta. O PDF é aberto localmente no navegador.
2. Desenhe um retângulo sobre cada nome, endereço, valor de contrato, assinatura ou outro detalhe que deseja remover. Amplie para ver os detalhes e use **Deslocar** para se mover pela página ampliada.
3. Use os controles de navegação para conferir o restante do documento. Use **Desfazer** para remover o retângulo mais recente da página atual.
4. Selecione **Baixar PDF censurado** para salvar uma cópia separada. Abra a cópia e verifique se cada retângulo cobre toda a informação confidencial.

## Como funciona a censura permanente de um PDF

A ferramenta pinta os retângulos diretamente nas imagens renderizadas das páginas e cria um PDF a partir dessas imagens. Os pixels de cada área marcada são substituídos por preto sólido. Os objetos de texto e de imagem do original, as camadas de texto ocultas, os anexos e os metadados ficam fora da exportação. Pesquisar ou selecionar texto, extrair objetos do PDF ou remover uma sobreposição não permite recuperar o conteúdo coberto.

Use a ferramenta de retângulo para censurar texto digitado, documentos digitalizados com uma camada de OCR, assinaturas e figuras. Se uma informação confidencial aparecer mais de uma vez, marque cada ocorrência visível.

## O que o PDF exportado contém

A cópia exportada preserva a ordem das páginas e a aparência delas fora das áreas selecionadas. As páginas são imagens, por isso o PDF perde o texto pesquisável ou selecionável, os links clicáveis e os formulários interativos. O tamanho do arquivo pode mudar. O arquivo original permanece intacto e todo o processamento ocorre no seu dispositivo, sem envio do PDF a um servidor.
