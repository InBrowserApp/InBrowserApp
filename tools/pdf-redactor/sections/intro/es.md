## Cómo censurar un PDF en línea

1. Elige un PDF o arrástralo a la herramienta. El archivo se abre localmente en tu navegador.
2. Dibuja un rectángulo sobre cada nombre, dirección, importe de contrato, firma u otro dato que quieras eliminar. Acerca la vista para marcar con más precisión y usa «Desplazar» para recorrer la página ampliada.
3. Cambia de página para revisar el resto del documento. Usa «Deshacer» para quitar el último recuadro de la página actual.
4. Selecciona **Descargar PDF censurado** para guardar una copia. Ábrela y comprueba que cada recuadro cubra por completo la información confidencial.

## Cómo se eliminan datos de un PDF de forma permanente

La herramienta convierte cada página en una imagen, pinta los recuadros sobre ella y genera un PDF nuevo con las imágenes resultantes. Los píxeles de cada zona marcada se sustituyen por negro sólido. El nuevo archivo prescinde de los objetos de texto e imagen originales, las capas de texto ocultas, los archivos adjuntos y los metadatos. El contenido cubierto no se puede recuperar mediante búsquedas, selección de texto, extracción de objetos del PDF ni eliminación de una capa superpuesta.

Puedes usar la misma herramienta de rectángulo para censurar texto, documentos escaneados con una capa de OCR, firmas y figuras. Si un dato confidencial aparece varias veces, marca todos los lugares donde se vea.

## Qué contiene el PDF exportado

La copia conserva el orden de las páginas y su aspecto fuera de las zonas marcadas. Todas las páginas se exportan como imágenes, por lo que se pierde la posibilidad de buscar o seleccionar texto, abrir enlaces y usar formularios interactivos. El tamaño del archivo puede cambiar. El archivo original queda intacto y el PDF se procesa en tu dispositivo sin subirlo a un servidor.
