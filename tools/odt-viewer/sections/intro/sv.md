## Läs OpenDocument-textfiler lokalt

Öppna ett ODT-dokument eller en OTT-mall för att läsa formaterad text, rubriker, listor, tabeller och inbäddade bilder som stöds. Filerna stannar på din enhet. Mallar öppnas som skrivskyddade dokument utan att någon fil skapas eller redigeras.

## Navigera och läs bekvämt

Använd dokumentöversikten för att hoppa till rubriker, ändra zoom eller aktivera fokuserat läsläge. Markera och kopiera text direkt. Interna bokmärken och fotnotshänvisningar går att använda när deras mål finns tillgängliga. Du kan stänga eller byta dokument när som helst.

## Förstå läslayouten

Dokument visas i en sammanhängande läslayout i stället för som exakta utskrivna sidor. Uttryckliga sidbrytningar visas som avdelare, och fotnoter visas intill sina hänvisningar. Tillgängliga standardsidhuvuden och standardsidfötter samt första sidans sidhuvud och sidfot visas i ett separat avsnitt som kan fällas ut. De upprepas inte på varje sida. Ursprungliga sidstorlekar, sidindelning, komplex placering och saknade teckensnitt kan påverka utseendet.

Spårade ändringar visas som om de accepterats: infogad text finns kvar och borttagen text döljs. Detta ändrar inte filen. Kommentarer, komplexa teckningar, inbäddade objekt och viss formatering kan utelämnas. Saknade eller länkade bilder markeras med ett kompatibilitetsmeddelande. Fjärrinnehåll, externa länkar och makron körs eller läses inte in. Lösenordsskyddade dokument måste först sparas som en okrypterad kopia i ett kontorsprogram. ODS-kalkylblad och ODP-presentationer ingår inte i den här visarens stöd.
