## 기기에서 OpenDocument 텍스트 파일 읽기

ODT 문서나 OTT 서식을 열어 서식이 적용된 텍스트, 제목, 목록, 표, 지원하는 삽입 이미지를 읽으세요. 파일은 기기를 벗어나지 않습니다. 서식은 읽기 전용 문서로 열리며, 파일을 새로 만들거나 편집하지 않습니다.

## 편안하게 탐색하고 읽기

문서 개요에서 제목으로 이동하고, 배율을 조절하거나 집중 읽기 모드를 사용하세요. 텍스트를 직접 선택해 복사할 수 있습니다. 대상이 있으면 내부 책갈피와 각주 참조를 이용할 수 있습니다. 언제든 문서를 닫거나 다른 문서로 바꿀 수 있습니다.

## 읽기 화면 알아보기

문서는 인쇄 페이지를 그대로 재현하지 않고 연속해서 이어지는 읽기 화면으로 표시됩니다. 명시적인 페이지 나누기는 구분선으로, 각주는 참조 옆에 표시됩니다. 기본 머리글·바닥글과 첫 페이지 머리글·바닥글이 있으면 별도의 펼칠 수 있는 영역에 표시되며, 페이지마다 반복되지 않습니다. 원본 페이지 크기, 페이지 구분, 복잡한 위치 지정, 사용할 수 없는 글꼴로 인해 모양이 달라질 수 있습니다.

추적된 변경 내용은 모두 적용된 상태로 표시됩니다. 삽입된 텍스트는 남고 삭제된 텍스트는 숨겨집니다. 파일 자체는 변경되지 않습니다. 주석, 복잡한 도형, 삽입된 개체, 일부 서식은 생략될 수 있습니다. 이미지가 누락되었거나 외부에 연결되어 있으면 호환성 안내가 표시됩니다. 원격 콘텐츠, 외부 링크, 매크로는 실행되거나 로드되지 않습니다. 암호로 보호된 문서는 먼저 오피스 앱에서 암호화되지 않은 사본으로 저장해야 합니다. ODS 스프레드시트와 ODP 프레젠테이션은 이 뷰어의 지원 범위에 포함되지 않습니다.

인쇄 가능한 사본을 만들려면 [ODT → PDF 변환기](../odt-to-pdf-converter/)를 사용하세요.
