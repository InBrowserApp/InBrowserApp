## แปลงเอกสาร AsciiDoc บนอุปกรณ์

เปิดไฟล์ `.adoc` หรือ `.asciidoc` บนอุปกรณ์ ตรวจสอบเอกสารที่แสดง และดาวน์โหลดไฟล์ HTML แบบแยกเดี่ยวที่เข้ารหัส UTF-8 ไฟล์เปิดแบบออฟไลน์ได้และยังเลือกข้อความได้ หากต้องการตรวจสอบคำเตือนในซอร์สหรือไฟล์ที่รวมเข้ามาซึ่งไม่พร้อมใช้งานก่อนแปลง ให้ใช้[โปรแกรมดู AsciiDoc](../asciidoc-viewer/)

## ผลลัพธ์และความเข้ากันได้

หัวข้อ รายการ ตาราง บล็อกโค้ด หมายเหตุ ข้อความอ้างอิง เชิงอรรถ ลิงก์ และภาพแรสเตอร์ที่ฝังไว้ซึ่งรองรับจะถูกเก็บไว้ด้วยธีมการอ่านแบบตายตัว บุ๊กมาร์กภายในและเชิงอรรถยังอยู่ในเอกสาร ส่วนลิงก์ภายนอกจะเปิดเมื่อเลือกเท่านั้น โค้ดและตารางที่กว้างเลื่อนในแนวนอนได้ การซูมตัวอย่างไม่เปลี่ยนไฟล์ที่ดาวน์โหลด แบบอักษรและระยะห่างอาจต่างจากเครื่องมือ AsciiDoc อื่น

ใช้ซอร์สที่รวมทุกอย่างไว้ในไฟล์เดียวในรูปแบบ UTF-8 หรือ UTF-16 ที่มีเครื่องหมาย BOM ไม่มีการโหลดไฟล์ที่รวมเข้ามาหรือทรัพยากรรูปภาพและสไตล์ภายนอก ไฟล์ที่รวมเข้ามาซึ่งไม่พร้อมใช้งาน คำเตือนจากตัวแยกวิเคราะห์ แอตทริบิวต์ที่ยังแก้ค่าไม่ได้ และทรัพยากรที่ขาดหายหรืออ่านไม่ได้จะทำให้การส่งออกหยุดลงโดยไม่มีไฟล์บางส่วนให้ดาวน์โหลด รูปภาพที่ฝังไว้ รวมถึงภาพพื้นหลัง CSS ต้องถอดรหัสได้สำเร็จ ไม่รองรับมาโครที่กำหนดเอง แผนภาพ ส่วนขยาย และแบบอักษรที่ฝังไว้ สคริปต์ แบบฟอร์ม แอปที่ฝังไว้ SVG และ MathML จะถูกละไว้ ไวยากรณ์ซอร์สที่ไม่รองรับอาจยังแสดงเป็นข้อความธรรมดา

## ความเป็นส่วนตัวและทรัพยากรของเบราว์เซอร์

ไฟล์อยู่ในเบราว์เซอร์นี้ ไม่มีการดึงทรัพยากรที่ขาดหายจากคอมพิวเตอร์ของคุณหรือเว็บไซต์ และไม่มีการอัปโหลดเนื้อหาไฟล์ HTML ที่สร้างขึ้นบล็อกสคริปต์และการโหลดทรัพยากรภายนอกโดยอัตโนมัติ การเปิดลิงก์ภายนอกเป็นอีกการกระทำหนึ่งที่อาจติดต่อเว็บไซต์นั้น คุณสามารถยกเลิก ปิด หรือเปลี่ยนเอกสารซอร์สได้ ไม่มีโควตาขนาดไฟล์หรือจำนวนหน้าตายตัว เอกสารขนาดใหญ่ขึ้นอยู่กับหน่วยความจำที่เบราว์เซอร์มีให้ใช้ และระบบจะแจ้งความล้มเหลวจากทรัพยากรเมื่อตรวจพบได้
