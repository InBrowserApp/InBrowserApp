## 在本機轉換 AsciiDoc

開啟本機的 `.adoc` 或 `.asciidoc` 檔案，檢查繪製後的文件，並下載獨立的 UTF-8 HTML 檔案。檔案可離線開啟，且文字仍可選取。若要在轉換前檢查原始文件的警告或無法取得的引入檔案，請使用 [AsciiDoc 檢視器](../asciidoc-viewer/)。

## 輸出與相容性

標題、清單、表格、程式碼區塊、提示、引文、註腳、連結與支援的內嵌點陣圖片，會以固定的閱讀主題保留。內部書籤與註腳會保留在文件中；外部連結只有在點選時才會開啟。較寬的程式碼與表格可水平捲動。預覽縮放不會改變下載的檔案。字型與間距可能與其他 AsciiDoc 工具不同。

請使用內容完整獨立的 UTF-8 或帶有 BOM 標記的 UTF-16 原始文件。不會載入引入檔案或外部圖片／樣式資源。無法取得的引入檔案、剖析警告、無法解析的屬性，以及缺少或無法讀取的資源，都會使匯出停止，且不會提供部分完成的檔案供下載。內嵌圖片（包括 CSS 背景圖片）必須能成功解碼。不支援自訂巨集、圖表、擴充功能與內嵌字型。指令碼、表單、嵌入式應用程式、SVG 與 MathML 會省略。不支援的原始語法可能會以一般文字保留。

## 隱私與瀏覽器資源

檔案會留在此瀏覽器中。絕不會從您的電腦或網站擷取缺少的資源，也絕不會上傳檔案內容。產生的 HTML 會封鎖指令碼與自動載入外部資源的行為。開啟外部連結是另一項操作，可能會連線至該網站。您可以取消轉換、關閉或更換原始文件。檔案大小與頁數沒有固定上限；大型文件取決於瀏覽器可用的記憶體，若能偵測到資源不足，系統就會顯示錯誤。
