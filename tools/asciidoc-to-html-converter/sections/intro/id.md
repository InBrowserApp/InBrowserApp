## Konversikan AsciiDoc secara lokal

Buka file `.adoc` atau `.asciidoc` lokal, periksa dokumen yang dirender, lalu unduh file HTML UTF-8 mandiri. File dapat dibuka secara offline dan teksnya tetap dapat dipilih. Untuk meninjau peringatan sumber atau file yang disertakan tetapi tidak tersedia sebelum konversi, gunakan [Penampil AsciiDoc](../asciidoc-viewer/).

## Hasil dan kompatibilitas

Judul bagian, daftar, tabel, blok kode, catatan, kutipan, catatan kaki, tautan, dan gambar raster tersemat yang didukung dipertahankan dengan tema baca tetap. Penanda internal dan catatan kaki tetap berada di dalam dokumen; tautan eksternal hanya terbuka saat dipilih. Kode dan tabel yang lebar dapat digulir secara horizontal. Perbesaran pratinjau tidak mengubah file yang diunduh. Font dan spasi mungkin berbeda dari alat AsciiDoc lainnya.

Gunakan sumber lengkap dalam satu file berformat UTF-8 atau UTF-16 dengan penanda BOM. File yang disertakan serta sumber daya gambar atau gaya eksternal tidak dimuat. File yang disertakan tetapi tidak tersedia, peringatan pengurai, atribut yang belum terselesaikan, dan sumber daya yang hilang atau tidak dapat dibaca menghentikan ekspor tanpa unduhan parsial. Gambar tersemat, termasuk gambar latar CSS, harus berhasil didekodekan. Makro khusus, diagram, ekstensi, dan font tersemat tidak didukung. Skrip, formulir, aplikasi tersemat, SVG, dan MathML dihilangkan. Sintaks sumber yang tidak didukung mungkin tetap ditampilkan sebagai teks biasa.

## Privasi dan sumber daya browser

File tetap berada di browser ini. Aset yang hilang tidak pernah diambil dari komputer Anda atau situs web, dan isi file tidak pernah diunggah. HTML yang dihasilkan memblokir skrip dan pemuatan sumber daya eksternal secara otomatis. Membuka tautan eksternal merupakan tindakan terpisah yang mungkin menghubungi situs tersebut. Anda dapat membatalkan, menutup, atau mengganti dokumen sumber. Tidak ada batas tetap untuk ukuran file atau jumlah halaman; dokumen besar bergantung pada memori browser yang tersedia, dan kegagalan sumber daya dilaporkan jika dapat dideteksi.
