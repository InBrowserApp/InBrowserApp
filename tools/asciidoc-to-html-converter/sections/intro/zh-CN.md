## 在本地转换 AsciiDoc

打开本地 `.adoc` 或 `.asciidoc` 文件，检查渲染后的文档，并下载独立的 UTF-8 HTML 文件。该文件可离线打开，文本仍可选择。如需在转换前检查源文件警告或不可用的引用文件，请使用 [AsciiDoc 查看器](../asciidoc-viewer/)。

## 输出与兼容性

标题、列表、表格、代码块、提示块、引用、脚注、链接和受支持的嵌入位图图片会以固定阅读主题保留。内部书签和脚注在文档内跳转，外部链接仅在你点击时打开。较宽的代码和表格可横向滚动。预览缩放不会改变下载的文件。字体和间距可能与其他 AsciiDoc 工具不同。

请使用 UTF-8 或带 BOM 标记的 UTF-16 编码的自包含源文件。不会加载引用文件和外部图片或样式资源。不可用的引用文件、解析警告、未解析的属性，以及缺失或无法读取的资源都会阻止导出，也不会提供不完整的文件供下载。嵌入图片（包括 CSS 背景图片）必须能够成功解码。不支持自定义宏、图表、扩展和嵌入字体。脚本、表单、嵌入式应用、SVG 和 MathML 会被省略。不受支持的源语法可能会保留为普通文本。

## 隐私与浏览器资源

文件仅在此浏览器中处理。缺失的资源不会从你的计算机或网站获取，文件内容也不会上传。生成的 HTML 会阻止脚本执行和外部资源自动加载。打开外部链接是单独的操作，可能会连接到相应网站。你可以取消转换、关闭或更换源文档。不设置固定的文件大小或页数上限；大型文档的处理取决于可用的浏览器内存，检测到资源不足时会提示错误。
