# AsciiDoc HTML export fixtures

`field-manual.adoc` extends the repository's original AsciiDoc viewer manual.
It exercises headings, nested lists, tables, code and callouts, admonitions,
quotations, description lists, footnotes, internal/external links, task states,
non-Latin text and the final document marker.

The embedded 160 × 80 PNG is the original programmatically generated four-color
image from the Markdown PDF fixture. Its colors are RGB (35,111,192),
(238,162,38), (37,148,107) and (183,67,99). No third-party document or image is
bundled here.

Independent compatibility checks reuse the pinned Git manual described in the
AsciiDoc viewer compatibility notes; it is downloaded only for local validation.
