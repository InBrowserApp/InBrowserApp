## Zufällige UPC-A-Codes generieren

Geben Sie eine Anzahl von `1` bis `1000` ein und wählen Sie **Generieren**. Jede Zeile enthält einen 12-stelligen UPC-A-Code. Wählen Sie **Alle kopieren**, um die Codes in ein Testformular oder eine Tabelle einzufügen, oder **TXT herunterladen**, um sie als Text zu speichern.

## Prüfziffer und führende Nullen verstehen

Ein UPC-A-Barcode stellt eine 12-stellige Produktkennung namens `GTIN-12` dar. Die letzte Ziffer ist die Prüfziffer, die aus den ersten 11 Ziffern berechnet wird. In `084044127435` gehört die führende `0` zum Code und die letzte Ziffer `5` ist die Prüfziffer. Sie ergänzt die gewichtete Summe aller 12 Ziffern zu einem Vielfachen von zehn.

## Codes für Handelstests verwenden

Verwenden Sie diese Beispielcodes, um Produktformulare, Inventarimporte oder die UPC-Validierung zu testen. Speichern Sie sie als Text, damit führende Nullen erhalten bleiben. Um ein Testbarcode-Bild zu drucken, fügen Sie einen generierten Code in den [Barcode-Generator](/de/tools/barcode-generator/) ein und wählen Sie `UPC`. Verwenden Sie für ein tatsächliches Produktangebot oder eine Verpackung die dem Produkt zugewiesene GTIN.
