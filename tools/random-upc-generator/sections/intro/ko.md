## 무작위 UPC-A 코드 생성하기

수량을 `1`부터 `1000`까지 설정한 다음 **생성**을 선택하세요. 각 줄에는 12자리 UPC-A 코드가 하나씩 표시됩니다. **모두 복사**를 선택해 코드를 한꺼번에 테스트 양식이나 스프레드시트에 붙여 넣거나 **TXT 다운로드**를 선택해 텍스트로 저장하세요.

## 체크디지트와 앞의 0 확인하기

UPC-A 바코드는 `GTIN-12`라고 하는 12자리 상품 식별코드를 나타냅니다. 마지막 자리는 앞의 11자리로 계산한 체크디지트입니다. `084044127435`에서 맨 앞의 `0`은 코드의 일부이며 마지막 `5`가 체크디지트입니다. 체크디지트를 포함한 12자리 숫자의 가중 합은 10의 배수가 됩니다.

## 소매 테스트에 코드 사용하기

이 예제 코드를 사용해 상품 양식, 재고 가져오기 또는 UPC 검증을 테스트하세요. 앞의 0이 유지되도록 코드를 텍스트로 저장하세요. 테스트용 바코드 이미지를 인쇄하려면 생성된 코드를 [바코드 생성기](/tools/barcode-generator/)에 붙여 넣고 `UPC`를 선택하세요. 실제 상품 등록이나 포장에는 해당 상품에 부여된 GTIN을 사용하세요.
