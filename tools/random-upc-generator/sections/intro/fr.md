## Générer des codes UPC-A aléatoires

Indiquez une quantité entre `1` et `1000`, puis sélectionnez **Générer**. Chaque ligne contient un code UPC-A à 12 chiffres. Sélectionnez **Tout copier** pour coller le lot dans un formulaire de test ou un tableur, ou **Télécharger en TXT** pour enregistrer les codes en texte.

## Comprendre la clé de contrôle et les zéros initiaux

Un code-barres UPC-A représente un identifiant de produit à 12 chiffres appelé `GTIN-12`. Le dernier chiffre est la clé de contrôle calculée à partir des 11 premiers. Dans `084044127435`, le `0` initial fait partie du code et le `5` final est sa clé de contrôle. Celle-ci rend la somme pondérée des 12 chiffres multiple de dix.

## Utiliser les codes pour les tests de vente

Utilisez ces codes d’exemple pour tester des formulaires de produits, des importations de stocks ou la validation UPC. Enregistrez-les en texte pour conserver les zéros initiaux. Pour imprimer une image de code-barres de test, collez un code généré dans le [Générateur de Codes-barres](/fr/tools/barcode-generator/) et choisissez `UPC`. Pour une fiche produit publiée ou un emballage, utilisez le GTIN attribué au produit.
