## Konversi file 3MF ke STL

Pilih **Buka file** atau seret file `.3mf` ke konverter. Model dibaca langsung di perangkat Anda dan disimpan sebagai STL biner. Pilih **Coba contoh** untuk membuka model cetak dengan dua braket berwarna, lalu pilih **Unduh STL** untuk menyimpan hasilnya.

## Pertahankan ukuran dan posisi cetak

Konverter menghasilkan koordinat mesh dalam milimeter. Komponen yang disusun di meja cetak tetap berada pada posisi relatif semula, termasuk komponen yang diulang. Jika bentang suatu komponen dalam 3MF adalah satu inci, bentangnya menjadi 25,4 satuan koordinat dalam STL. Pilih milimeter jika aplikasi meminta satuan saat mengimpor STL.

## Periksa isi file STL

STL memuat segitiga permukaan. Simpan file 3MF asli jika Anda memerlukan warna, material, atau pengaturan slicer. Buka hasilnya di [Penampil STL](../stl-viewer/) atau periksa file sumber di [Penampil 3MF](../3mf-viewer/). Gunakan [Konverter STL ke 3MF](../stl-to-3mf-converter/) jika langkah berikutnya memerlukan paket model 3MF. [Tentang format 3MF](https://3mf.io/resources/faq/)
