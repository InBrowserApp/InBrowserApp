## Convertire un file 3MF in STL

Seleziona **Apri file** o trascina un `.3mf` nel convertitore. Lo strumento legge il modello sul tuo dispositivo e crea un file STL binario. Seleziona **Prova un esempio** per usare un modello con due staffe di montaggio colorate, quindi scegli **Scarica STL** per salvare il risultato.

## Conservare le dimensioni e la disposizione delle parti

Il convertitore esporta le coordinate della mesh in millimetri. Le parti sul piano di stampa mantengono le posizioni relative, anche quando sono presenti più copie. Una parte che misura un pollice nel 3MF misura 25,4 unità di coordinate nello STL. Seleziona i millimetri se il programma chiede un’unità di misura durante l’importazione dello STL.

## Controllare il contenuto del file STL

Lo STL contiene i triangoli delle superfici. Conserva il 3MF originale per i colori, i materiali e le impostazioni dello slicer. Apri il risultato nel [Visualizzatore STL](../stl-viewer/) oppure esamina l’originale con il [Visualizzatore 3MF](../3mf-viewer/). Usa il [Convertitore da STL a 3MF](../stl-to-3mf-converter/) se il prossimo passaggio richiede un file 3MF. [Informazioni sul formato 3MF](https://3mf.io/resources/faq/)
