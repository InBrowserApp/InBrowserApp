## Convertir un archivo BPMN 2.0 a PDF

1. Arrastra un archivo `.bpmn` o `.xml` al conversor o selecciona **Abrir archivo BPMN**. Si quieres ver primero el resultado, selecciona **Probar un ejemplo** para cargar un proceso de aprobación.
2. Revisa la vista previa y selecciona **Tamaño original del diagrama**, **A4** o **Carta (EE. UU.)** en **Tamaño de página del PDF**.
3. Selecciona **Descargar PDF**. El PDF conserva el nombre del archivo de origen y contiene el proceso completo, aunque hayas ampliado una parte en la vista previa.

## Elegir un tamaño de PDF para compartir o imprimir

El tamaño original resulta útil para compartir un proceso grande que se va a consultar en pantalla. Selecciona A4 o Carta (EE. UU.) para ajustarlo a una hoja con márgenes. El conversor elige la orientación vertical u horizontal según la forma del diagrama. Si un proceso denso debe caber en una hoja, comprueba que las etiquetas más pequeñas sean legibles antes de imprimir.

Las formas y conexiones se guardan como vectores y se mantienen nítidas al ampliar. Selecciona **Descargar SVG** si quieres insertar el diagrama en una página web o abrirlo en un editor vectorial. Conserva el archivo BPMN si vas a modificar el proceso en tu herramienta de modelado.

Las etiquetas se guardan como contornos vectoriales. Usa el archivo de origen para copiar o editar su texto.

## Abrir XML de BPMN con datos de disposición

El conversor usa los datos de BPMN Diagram Interchange para ubicar las actividades, los carriles, los eventos y las conexiones. Si el XML solo describe el proceso, ábrelo en tu herramienta de modelado y vuelve a exportarlo con los datos de disposición. Los archivos XML de otros formatos, como un archivo nativo de draw.io, deben exportarse primero como BPMN 2.0 con datos de disposición.

Tu navegador lee y convierte el archivo de forma local. Para examinar el proceso y desplazarte por el diagrama, usa el [Visor BPMN](../bpmn-viewer/).
