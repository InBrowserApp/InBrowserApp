## Converter um arquivo BPMN 2.0 para PDF

1. Arraste um arquivo `.bpmn` ou `.xml` para o conversor ou selecione **Abrir arquivo BPMN**. Para ver o resultado primeiro, selecione **Experimentar um exemplo** para carregar um processo de aprovação.
2. Confira a prévia e escolha **Tamanho original do diagrama**, **A4** ou **Carta (EUA)** em **Tamanho da página do PDF**.
3. Selecione **Baixar PDF**. O PDF mantém o nome do arquivo de origem e inclui o processo inteiro, mesmo que você tenha ampliado uma parte da prévia.

## Escolher um tamanho de PDF para compartilhar ou imprimir

O tamanho original é útil para compartilhar um processo grande que será visto na tela. Escolha A4 ou Carta (EUA) para ajustá-lo a uma folha com margens. O conversor escolhe a orientação retrato ou paisagem de acordo com o formato do diagrama. Se um processo complexo precisar caber em uma folha, confira a legibilidade dos rótulos menores antes de imprimir.

O PDF mantém as formas e conexões como vetores para que continuem nítidas com ampliação. Use **Baixar SVG** para inserir o diagrama em uma página da web ou editá-lo em um editor vetorial. Guarde o arquivo BPMN se precisar alterar o processo na sua ferramenta de modelagem.

Os rótulos são salvos como contornos vetoriais. Use o arquivo de origem para copiar ou editar o texto dos rótulos.

## Abrir XML de BPMN com o layout do diagrama

O conversor usa os dados de BPMN Diagram Interchange para localizar atividades, raias, eventos e conexões. Se o XML só descrever o processo, abra o arquivo na sua ferramenta de modelagem e exporte novamente com o layout do diagrama. Arquivos XML de outros formatos, como um arquivo nativo do draw.io, precisam ser exportados como BPMN 2.0 com dados de layout primeiro.

O navegador lê e converte o arquivo localmente. Para examinar o processo e navegar pelo diagrama, use o [Visualizador de BPMN](../bpmn-viewer/).
