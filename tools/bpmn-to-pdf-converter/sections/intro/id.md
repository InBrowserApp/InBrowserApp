## Konversi file BPMN 2.0 ke PDF

1. Seret file `.bpmn` atau `.xml` ke konverter atau pilih **Buka file BPMN**. Untuk melihat hasilnya terlebih dahulu, pilih **Coba contoh** untuk membuka alur persetujuan.
2. Periksa pratinjau diagram, lalu pilih **Ukuran asli diagram**, **A4**, atau **US Letter** pada **Ukuran halaman PDF**.
3. Pilih **Unduh PDF**. Nama PDF mengikuti nama file sumber dan isinya mencakup seluruh proses meskipun Anda hanya memperbesar satu bagian di pratinjau.

## Pilih ukuran PDF untuk berbagi atau mencetak

Ukuran asli diagram cocok untuk membagikan peta proses yang besar agar dibaca di layar. Pilih A4 atau US Letter untuk memuat diagram dalam selembar kertas dengan margin. Konverter memilih orientasi potret atau lanskap sesuai bentuk diagram. Periksa label kecil sebelum mencetak proses yang padat di satu lembar.

PDF menyimpan bentuk dan koneksi sebagai vektor agar tetap tajam ketika diperbesar. Gunakan **Unduh SVG** untuk menyematkan diagram di halaman web atau mengeditnya di editor vektor. Simpan file BPMN jika ingin mengubah proses di alat pemodelan.

Label disimpan sebagai garis bentuk vektor. Gunakan berkas sumber untuk menyalin atau menyunting teks label.

## Buka XML BPMN yang menyertakan tata letak diagram

Konverter menggunakan data BPMN Diagram Interchange untuk menemukan posisi aktivitas, lajur, peristiwa, dan koneksi. Jika XML hanya mendeskripsikan prosesnya, buka di alat pemodelan dan ekspor ulang dengan tata letak diagram. XML dari format lain, seperti file asli draw.io, perlu diekspor menjadi BPMN 2.0 dengan data tata letak terlebih dahulu.

File dibaca dan dikonversi secara lokal di browser. Untuk memeriksa dan menjelajahi diagram proses, gunakan [Penampil BPMN](../bpmn-viewer/).
