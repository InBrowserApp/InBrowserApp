## Convertire un file BPMN 2.0 in PDF

1. Trascina un file `.bpmn` o `.xml` nel convertitore oppure seleziona **Apri file BPMN**. Per vedere prima il risultato, scegli **Prova un esempio** per caricare un processo di approvazione.
2. Controlla l’anteprima e scegli **Dimensioni originali del diagramma**, **A4** o **Lettera USA** in **Formato pagina PDF**.
3. Seleziona **Scarica PDF**. Il PDF conserva il nome del file di origine e contiene tutto il processo, anche se hai ingrandito una parte dell’anteprima.

## Scegliere un formato PDF per la condivisione o la stampa

Le dimensioni originali sono utili per condividere a schermo un processo di grandi dimensioni. Scegli A4 o Lettera USA per adattarlo a un foglio con margini. Il convertitore imposta l’orientamento verticale o orizzontale in base alla forma del diagramma. Se un processo complesso deve stare su un solo foglio, verifica la leggibilità delle etichette più piccole prima di stampare.

Il PDF mantiene forme e collegamenti in formato vettoriale, così restano nitidi quando li ingrandisci. Scegli **Scarica SVG** per inserire il diagramma in una pagina web o modificarlo in un editor vettoriale. Conserva il file BPMN se vuoi cambiare il processo nello strumento di modellazione.

Le etichette vengono salvate come contorni vettoriali. Usa il file sorgente per copiare o modificare il testo delle etichette.

## Aprire un file XML BPMN con i dati di layout

Il convertitore usa i dati BPMN Diagram Interchange per individuare la posizione di attività, corsie, eventi e collegamenti. Se l’XML descrive solo il processo, aprilo nello strumento di modellazione ed esportalo di nuovo con il layout del diagramma. Un file XML in un altro formato, come un file nativo di draw.io, va prima esportato come BPMN 2.0 con i dati di layout.

Il browser legge e converte il file in locale. Per esaminare un processo e navigare nel diagramma, usa il [Visualizzatore BPMN](../bpmn-viewer/).
