## Buka dan baca partitur MusicXML

Pilih **Buka file MusicXML** atau seret partitur ke penampil. Halaman ini menampilkan not, tanda istirahat, tanda kunci, dan tanda lain dari file pada paranada. Pilih **Coba contoh** untuk mengenal penampil sebelum membuka partitur Anda sendiri. MusicXML adalah format yang umum digunakan untuk bertukar partitur antarprogram notasi seperti MuseScore Studio, Dorico, dan Sibelius.

## Perbesar tampilan atau gunakan mode fokus

Gunakan kontrol perbesaran untuk membaca bagian yang padat atau melihat lebih banyak birama sekaligus. Pilih angka persentase untuk mengatur ulang perbesaran. Mode fokus memberikan ruang lebih luas untuk membaca di ponsel atau melihat partitur dengan beberapa paranada. Gulir partitur di dalam penampil agar bilah alat tetap mudah dijangkau.

## File MusicXML, XML, dan MXL

Partitur MusicXML dapat menggunakan ekstensi .musicxml atau .xml. File .mxl adalah paket MusicXML terkompresi yang bisa langsung dibuka. Jika partitur gagal dibuka, ekspor ulang dari program notasi Anda dalam format MusicXML partwise, yang menyusun data berdasarkan bagian instrumen atau vokal. Program notasi bisa menata partitur yang sama dengan cara berbeda, sehingga pemenggalan baris dan jarak antarnot dapat bervariasi. Penampil membaca dan menggambar partitur langsung di browser Anda.
