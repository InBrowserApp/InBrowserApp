## Open and read MusicXML sheet music

Choose **Open MusicXML file** or drag a score into the viewer. The page draws the notes, rests, clefs, and other markings from the file on a staff. Use **Try an example** to explore the viewer before opening your own score. MusicXML is a common interchange format for notation programs such as MuseScore Studio, Dorico, and Sibelius.

## Zoom in or use focus mode

Use the zoom controls to read a dense passage or see more measures at a glance. Select the zoom percentage to reset it. Focus mode gives the score more space, which helps on a phone or when reading a score with several staves. The score can scroll inside the viewer, so the toolbar remains within reach.

## MusicXML, XML, and MXL files

A MusicXML score may use the .musicxml or .xml extension. An .mxl file is a compressed MusicXML package and can be opened directly. If a score fails to open, export it again from your notation program in partwise MusicXML format. Notation programs can lay the same score out differently, so line breaks and spacing may vary. The viewer reads and renders the file in your browser.
