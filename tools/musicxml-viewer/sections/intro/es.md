## Cómo abrir y leer partituras MusicXML

Selecciona **Abrir archivo MusicXML** o arrastra una partitura al visor. La página representa en el pentagrama las notas, los silencios, las claves y otras indicaciones del archivo. Selecciona **Probar un ejemplo** para explorar el visor antes de abrir tu propia partitura. MusicXML es un formato de intercambio habitual en editores de partituras como MuseScore Studio, Dorico y Sibelius.

## Cómo usar el zoom y el modo de lectura

Usa los controles de zoom para leer un pasaje con muchas notas o ver más compases de un vistazo. Selecciona el porcentaje para restablecer el zoom. El modo de lectura deja más espacio para la partitura, algo útil en un móvil o al leer una obra con varios pentagramas. Puedes desplazarte por la partitura dentro del visor con la barra de herramientas siempre a mano.

## Archivos MusicXML, XML y MXL

Las partituras MusicXML pueden tener la extensión .musicxml o .xml. Los archivos .mxl son paquetes MusicXML comprimidos que puedes abrir directamente. Si no puedes abrir una partitura, vuelve a exportarla desde tu editor de partituras en formato MusicXML con estructura por partes (partwise). Cada programa puede distribuir la misma partitura de forma distinta, así que los saltos de sistema y el espaciado pueden variar. El visor lee y muestra el archivo en tu navegador.
