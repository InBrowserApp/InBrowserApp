## Aprire e leggere uno spartito MusicXML

Seleziona **Apri file MusicXML** o trascina uno spartito nel visualizzatore. La pagina mostra sul pentagramma le note, le pause, le chiavi e le altre indicazioni del file. Seleziona **Prova un esempio** per esplorare il visualizzatore prima di aprire il tuo spartito. MusicXML è un formato di scambio comune tra i programmi di notazione, come MuseScore Studio, Dorico e Sibelius.

## Usare lo zoom o la lettura senza distrazioni

Usa i controlli dello zoom per leggere un passaggio fitto o vedere più battute a colpo d’occhio. Seleziona la percentuale per ripristinare lo zoom. La lettura senza distrazioni dà più spazio allo spartito, per esempio su un telefono o per una partitura con più pentagrammi. Puoi scorrere lo spartito nel visualizzatore tenendo sempre a portata di mano la barra degli strumenti.

## File MusicXML, XML e MXL

Uno spartito MusicXML può avere l’estensione .musicxml o .xml. Un file .mxl è un archivio MusicXML compresso che puoi aprire direttamente. Se uno spartito non si apre, esportalo di nuovo dal tuo programma di notazione come MusicXML organizzato per parti (partwise). Programmi diversi possono impaginare lo stesso spartito in modi diversi, perciò le interruzioni di sistema e la spaziatura possono variare. Il visualizzatore legge e mostra il file nel browser.

## Scaricare lo spartito

Usa **Scarica** per salvare lo spartito su pagine in formato A4. Scegli il PDF per la stampa, il PNG per condividere un’immagine nitida o l’SVG per ridimensionarla senza perdere dettagli. Se lo spartito occupa più di una pagina, il download in PNG o SVG contiene un file per pagina in un archivio ZIP. Le pagine esportate mantengono la stessa impaginazione su smartphone e computer.
