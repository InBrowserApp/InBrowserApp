## 스캔한 PDF를 압축하는 방법

스캔한 양식, 영수증, 보고서를 이메일로 보내거나 제출 사이트에 올리기 전에 파일 크기를 줄여 보세요. 스캔한 문서에서 용량을 가장 많이 차지하는 것은 대개 이미지입니다. PDF 압축 도구는 문서에 포함된 이미지 중 지원되는 이미지를 압축합니다.

1. PDF를 선택하거나 도구에 끌어다 놓습니다.
2. **균형**을 고른 뒤 **PDF 압축**을 선택합니다.
3. **원본 크기**, **다운로드 크기**, **감소율**을 비교합니다. 첨부 파일 크기에 제한이 있다면 다운로드 크기가 한도 이내인지 확인하세요.
4. 파일을 다운로드한 뒤 열어서 작은 글씨, 도장, 손글씨를 확인하세요. 압축 수준을 바꿔 원본을 다시 압축할 수 있습니다.

## 압축 수준 선택하기

- **고화질**은 작은 글씨와 도표의 세부 내용을 더 잘 보존합니다. 인쇄할 스캔본에도 적합합니다.
- **균형**은 양식, 청구서, 보고서 같은 일반적인 스캔본에 먼저 적용해 볼 만한 설정입니다.
- **최소 용량**은 이미지 해상도와 화질을 더 낮춥니다. 업로드 한도가 작아 이 설정을 사용했다면 다운로드한 PDF에서 중요한 부분이 잘 보이는지 확인하세요.

## 압축한 PDF에서도 텍스트를 검색할 수 있나요?

원본에 텍스트가 들어 있는 부분은 계속 검색할 수 있습니다. 도구는 지원되는 내장 이미지를 교체하면서 선택 가능한 텍스트와 광학 문자 인식(OCR) 레이어를 비롯한 기존 페이지 콘텐츠를 유지합니다. 이미지만 들어 있는 스캔본에서 글자를 선택하거나 검색하려면 OCR이 필요합니다.

## PDF 용량이 그대로인 이유는 무엇인가요?

대부분이 텍스트나 벡터 그래픽인 PDF, 이미 최적화된 스캔본, 지원하지 않는 방식으로 인코딩된 이미지가 많은 PDF는 용량이 거의 줄지 않거나 그대로일 수 있습니다. 투명도가 있거나 특수 색상 프로필을 사용하는 이미지 등은 그대로 유지합니다. 압축 결과가 원본과 크기가 같거나 더 크면 다운로드에는 원본 파일을 사용합니다. 디지털 서명이 있는 파일도 원본 그대로 유지합니다. 비밀번호로 보호된 PDF는 잠금을 해제한 뒤 압축하세요.

## 편집한 PDF를 기기에서 압축하기

브라우저는 사용자의 기기에서 PDF를 읽고 압축합니다. 문서를 서버에 업로드하지 않으며, 다운로드한 사본은 원본과 별개입니다. [PDF 병합](/ko/tools/pdf-merger/), [PDF 분할](/ko/tools/pdf-splitter/), [PDF 페이지 순서 변경 및 회전](/ko/tools/pdf-page-organizer/)이 필요하다면 먼저 해당 작업을 끝내세요. 내보낸 PDF를 이 도구에서 열고 공유하기 전에 다운로드 크기를 확인하세요.
