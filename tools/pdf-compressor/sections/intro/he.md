## איך לדחוס קובץ PDF סרוק

אפשר להקטין טפסים, קבלות ודוחות סרוקים לפני שליחה בדוא״ל או העלאה לפורטל. הכלי דוחס תמונות מוטמעות שהפורמט שלהן נתמך. התמונות הן לעיתים קרובות החלק שתופס הכי הרבה מקום בקובץ שמגיע מסורק.

1. בחרו קובץ PDF או גררו אותו אל הכלי.
2. בחרו **מאוזנת** כרמת הדחיסה הראשונה ואז בחרו **דחיסת קובץ PDF**.
3. השוו בין **גודל מקורי**, **גודל להורדה** ו**הקטנה בגודל**. אם יש מגבלת גודל לקבצים מצורפים, ודאו שהגודל להורדה עומד בה.
4. הורידו את הקובץ ופתחו אותו כדי לבדוק אותיות קטנות, חותמות וכתב יד. אפשר לבחור רמת דחיסה אחרת ולדחוס שוב את הקובץ המקורי.

## בחירת רמת דחיסה

- ברמה **איכות גבוהה יותר** נשמרים יותר פרטים באותיות קטנות, בתרשימים ובסריקות המיועדות להדפסה.
- **מאוזנת** היא נקודת פתיחה טובה לסריקות נפוצות כמו טפסים, חשבוניות ודוחות.
- ברמה **הקובץ הקטן ביותר** הרזולוציה ואיכות התמונות יורדות עוד יותר. אם בחרתם בה כדי לעמוד במגבלת העלאה, בדקו שפרטים חשובים נשארו קריאים בקובץ שהורדתם.

## האם עדיין יהיה אפשר לחפש טקסט ב-PDF?

כן, בתנאי שהקובץ המקורי כבר כולל טקסט. הכלי מחליף תמונות מוטמעות נתמכות תוך שמירה על תוכן העמודים, לרבות טקסט שניתן לבחירה ושכבת טקסט שנוצרה בזיהוי תווים אופטי (OCR). סריקה שמורכבת רק מתמונות עדיין זקוקה ל-OCR כדי שיהיה אפשר לבחור מילים או לחפש אותן.

## למה גודל קובץ ה-PDF נשאר זהה?

ייתכן שקובצי PDF שמכילים בעיקר טקסט או גרפיקה וקטורית, סריקות שכבר עברו אופטימיזציה וקבצים עם תמונות בקידוד שאינו נתמך כמעט שלא יקטנו. חלק מהתמונות, כגון תמונות עם שקיפות או עם פרופיל צבע מיוחד, נשמרות כפי שהן. אם התוצאה זהה בגודלה למקור או גדולה ממנו, הקובץ המקורי זמין להורדה. גם קבצים עם חתימה דיגיטלית נשארים ללא שינוי. לפני הדחיסה הסירו את הגנת הסיסמה מקובצי PDF מוגנים.

## דחיסת קובצי PDF במכשיר לאחר עריכה

הדפדפן קורא ודוחס את הקובץ במכשיר שלכם. המסמך נשאר במכשיר והעותק שהורדתם נפרד מקובץ המקור. אם אתם צריכים [למזג קובצי PDF](/he/tools/pdf-merger/), [לפצל קובץ PDF](/he/tools/pdf-splitter/) או [לשנות את סדר העמודים ולסובב אותם](/he/tools/pdf-page-organizer/), סיימו תחילה את העריכה. לאחר מכן פתחו כאן את קובץ ה-PDF שייצאתם ובדקו את הגודל להורדה לפני שתשתפו אותו.
