## Aprire un disegno DXF online

Seleziona **Apri file DXF** o trascina un file `.dxf` in formato ASCII nel visualizzatore. Il browser legge il disegno sul tuo dispositivo. Seleziona **Prova un esempio** per aprire il disegno di una staffa con profilo, fori, linee d’asse e annotazioni.

## Ingrandire il disegno e gestire i layer

Trascina per spostare la vista e usa la rotellina o il gesto di pizzicamento per lo zoom. Seleziona **Inquadra disegno** per tornare alla vista d’insieme. Apri **Layer** per mostrare o nascondere i singoli layer del file. Ad esempio, nascondi le linee d’asse per controllare i contorni dei fori, poi mostrale di nuovo per verificarne l’allineamento.

## File DXF supportati

Il visualizzatore mostra i comuni elementi 2D dello spazio modello, tra cui linee, polilinee, archi, cerchi, blocchi e i tipi di testo supportati. Se il programma CAD offre l’opzione DXF binario, scegli DXF ASCII per l’esportazione. Se il disegno si trova solo in un foglio di layout, copia la geometria pertinente nello spazio modello prima di esportare. L’aspetto del testo dipende dai caratteri disponibili. Per conservarlo con precisione, converti le annotazioni in contorni nel programma CAD.

Il formato DXF memorizza le informazioni del disegno sotto forma di entità e tabelle associate. Per i dettagli, consulta la [guida di riferimento DXF di Autodesk](https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-DXF/files/index.htm).

## Esaminare il modello CAD originale

Se hai il file STEP o STP originale, usa il [Visualizzatore STEP](../step-viewer/) per esaminare in 3D una parte solida o un assieme.
