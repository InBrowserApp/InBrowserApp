## Abrir um desenho DXF online

Clique em **Abrir arquivo DXF** ou solte um arquivo `.dxf` em formato ASCII no visualizador. O navegador lê o desenho no seu dispositivo. Clique em **Experimentar um exemplo** para abrir o desenho de um suporte com perfil, furos, linhas de centro e anotações.

## Ajustar o zoom e alternar a visibilidade das camadas

Arraste para deslocar a vista e use a roda do mouse ou o gesto de pinça para dar zoom. Use **Enquadrar desenho** para voltar a ver o desenho inteiro. Abra **Camadas** para mostrar ou ocultar cada camada do arquivo. Por exemplo, oculte as linhas de centro ao conferir o contorno dos furos e volte a exibi-las para verificar o alinhamento.

## Arquivos DXF compatíveis

O visualizador mostra elementos 2D comuns do espaço do modelo, como linhas, polilinhas, arcos, círculos, blocos e os tipos de texto compatíveis. Se seu programa CAD oferecer a opção DXF binário, escolha DXF ASCII ao exportar. Se o desenho estiver apenas em uma folha de layout, copie a geometria relevante para o espaço do modelo antes de exportar. A aparência do texto depende das fontes disponíveis. Para preservá-la com exatidão, converta as anotações em contornos no programa CAD.

O formato DXF guarda as informações do desenho na forma de entidades e tabelas relacionadas. Consulte a [referência de DXF da Autodesk](https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-DXF/files/index.htm) para saber mais.

## Inspecionar o modelo CAD original

Se você tiver o arquivo STEP ou STP original, use o [Visualizador de STEP](../step-viewer/) para inspecionar uma peça sólida ou montagem em 3D.

Use o [Conversor de DXF para SVG](../dxf-to-svg-converter/) para exportar as camadas selecionadas do espaço do modelo como SVG para um documento, uma página da web ou um editor vetorial.
