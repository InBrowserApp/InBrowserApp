## Buka gambar DXF secara online

Pilih **Buka file DXF** atau seret file `.dxf` ASCII ke penampil. Browser membaca gambar langsung di perangkat Anda. Pilih **Coba contoh** untuk membuka gambar braket dengan profil, lubang bor, garis sumbu, dan label.

## Ubah skala tampilan gambar dan atur lapisan

Seret untuk menggeser, gulir atau gunakan dua jari untuk memperbesar atau memperkecil. Pilih **Tampilkan seluruh gambar** agar seluruh gambar kembali terlihat. Buka **Lapisan** untuk menampilkan atau menyembunyikan setiap lapisan pada file. Misalnya, sembunyikan garis sumbu saat memeriksa garis tepi lubang, lalu tampilkan kembali untuk melihat kelurusannya.

## Periksa file DXF yang dapat dibuka

Penampil menggambar objek 2D yang umum di ruang model (Model Space), seperti garis, garis bersambung (polyline), busur, lingkaran, blok, dan teks yang didukung. Jika aplikasi CAD menyediakan opsi DXF biner, pilih ekspor DXF ASCII. Jika gambar hanya tersimpan di lembar tata letak (Layout), salin geometri yang diperlukan ke ruang model sebelum mengekspor. Tampilan teks bergantung pada font yang tersedia. Jika tampilan label harus sama persis, ubah teks menjadi garis kontur di aplikasi CAD.

DXF menyimpan informasi gambar sebagai entitas dan tabel terkait. Lihat [referensi DXF dari Autodesk](https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-DXF/files/index.htm) untuk informasi lebih lanjut.

## Periksa model CAD asli

Jika Anda memiliki file STEP atau STP asli, gunakan [Penampil STEP](../step-viewer/) untuk memeriksa komponen solid atau rakitan dalam 3D.

Gunakan [Konverter DXF ke SVG](../dxf-to-svg-converter/) untuk mengekspor lapisan ruang model yang dipilih menjadi SVG bagi dokumen, halaman web, atau editor vektor.
