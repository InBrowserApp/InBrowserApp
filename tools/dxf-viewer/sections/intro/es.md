## Abrir un dibujo DXF en línea

Pulsa **Abrir archivo DXF** o suelta un archivo `.dxf` en formato ASCII en el visor. El navegador lee el dibujo en tu dispositivo. Pulsa **Probar un ejemplo** para abrir el dibujo de un soporte con su perfil, orificios, líneas de centro y etiquetas.

## Ajustar el zoom y cambiar la visibilidad de las capas

Arrastra para desplazar la vista y utiliza la rueda del ratón o el gesto de pinza para acercar o alejar. Pulsa **Encuadrar dibujo** para volver a ver el dibujo completo. Abre **Capas** para mostrar u ocultar capas del archivo de forma individual. Por ejemplo, oculta las líneas de centro mientras revisas los contornos de los orificios y vuelve a mostrarlas para comprobar su alineación.

## Archivos DXF compatibles

El visor muestra los elementos 2D habituales del espacio modelo, como líneas, polilíneas, arcos, círculos, bloques y los tipos de texto compatibles. Si tu programa CAD permite guardar DXF binarios, elige DXF ASCII para exportar. Si el dibujo solo está en una presentación, copia la geometría pertinente al espacio modelo antes de exportarlo. El aspecto del texto depende de las fuentes disponibles. Si necesitas conservarlo con exactitud, convierte las etiquetas en contornos en el programa CAD.

DXF almacena la información del dibujo en entidades y tablas relacionadas. Consulta la [referencia de DXF de Autodesk](https://help.autodesk.com/cloudhelp/2017/ENU/AutoCAD-DXF/files/index.htm) para conocer los detalles.

## Inspeccionar el modelo CAD original

Si tienes el archivo STEP o STP original, usa el [Visor de STEP](../step-viewer/) para inspeccionar una pieza sólida o un ensamblaje en 3D.

Usa el [Conversor de DXF a SVG](../dxf-to-svg-converter/) para exportar las capas seleccionadas del espacio modelo como SVG para un documento, una página web o un editor vectorial.
