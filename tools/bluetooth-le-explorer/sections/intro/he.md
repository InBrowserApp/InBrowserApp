## איך מתחברים להתקן Bluetooth עם צריכת אנרגיה נמוכה

הפעילו את Bluetooth והעבירו את ההתקן למצב שמאפשר חיבור. בחרו **חיבור התקן** ובחרו את ההתקן ההיקפי בדפדפן. הסייר מבקש גישה לשירותי GATT נפוצים כגון Battery Service, Device Information, Heart Rate ו-Environmental Sensing. לשירות GATT מותאם אישית, הזינו את מזהה ה-UUID שלו לפני פתיחת חלון הבחירה. השתמשו במזהה UUID של 16 סיביות כגון `180F`, או במזהה מלא של 128 סיביות מתיעוד ההתקן.

## איך קוראים מאפייני GATT

הרחיבו שירות כדי לראות את המאפיינים שלו ואת הפעולות הנתמכות. בחרו **קריאה** כדי לבקש את הערך הנוכחי. תצוגה הקסדצימלית מציגה את הבתים בדיוק כפי שהתקבלו, ואילו UTF-8 שימושי למאפיינים המכילים טקסט. ייתכן שיהיה צורך לפרש רמת סוללה, מדידה או ערך בינארי אחר לפי המפרט של אותו מאפיין.

## איך מתעדים התראות Bluetooth

בחרו **הרשמה לעדכונים** במאפיין שתומך בהתראות או באינדיקציות. העדכונים מופיעים עם הזמן ומזהה ה-UUID של המאפיין. אפשר להוריד את 100 ההתראות האחרונות כקובץ JSON לבדיקה מאוחרת, או לבחור **ביטול הרשמה** כדי לעצור את זרם העדכונים. הדף שומר את היומן באופן מקומי.

## למה לא רואים את ההתקן או את השירותים שלו?

התמיכה ב-Web Bluetooth תלויה בדפדפן ובמערכת ההפעלה. השתמשו בדפדפן נתמך דרך HTTPS, השאירו את ההתקן בקרבת מקום ונתקו אותו מיישומים אחרים אם הוא מאפשר חיבור אחד בלבד. הדפדפן מאפשר גישה לשירותי GATT מורשים בהתקני Bluetooth LE היקפיים. התקני Bluetooth Classic, כגון אוזניות שחושפות רק פרופילי שמע, דורשים ממשק אחר.
