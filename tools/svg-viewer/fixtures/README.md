# SVG viewer examples

`coastal-notes.svg`, its gzip-equivalent `coastal-notes.svgz`, and
`active-content.svg` are original test illustrations made for this repository.
The first covers a negative-origin viewBox, styled text, paths, a gradient,
mask, Gaussian blur, transparency, and an embedded PNG. The active example
contains deliberately blocked scripts, SMIL, linked resources, CSS imports,
remote fonts, foreign HTML, and a nested SVG image.

The following W3C SVG 2 specification examples are unmodified upstream files,
retrieved on 2026-10-09. They are independent format-producer fixtures, not
generated by the viewer:
