## View SVG and SVGZ illustrations

Open a local SVG or gzip-compressed SVGZ file to inspect a vector illustration without converting it. Zoom, drag to pan, or use the arrow keys while the illustration is focused. Fit and reset return the drawing to the available space. A transparency grid and light or dark backgrounds help reveal pale or transparent artwork.

## Dimensions and compatibility

The details panel shows declared dimensions and the viewBox when available. Relative or missing dimensions use the viewBox, or a 300 × 150 viewport when no viewBox exists. Actual size is available for absolute dimensions. The declared viewport is preserved; artwork beyond it is not included automatically.

Paths, shapes, text, gradients, local masks and filters, and embedded static PNG, JPEG, and WebP images are supported where your browser can display them. Scripts, SVG animation, embedded HTML, linked resources, custom fonts, nested SVG images, animated raster images, and unsupported styles are omitted. Installed fonts may change text appearance. Files with document type declarations are not supported.

## Local and read-only

Files stay on your device. The viewer does not upload or automatically store them, and it does not fetch resources referenced by a document. Closing or replacing a file releases its preview. There is no fixed file-size or drawing-element limit; available browser memory and rendering capabilities determine what can open. Use the SVG converter when you need an exported image.
