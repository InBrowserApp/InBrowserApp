## Visa SVG- och SVGZ-illustrationer

Öppna en lokal SVG-fil eller gzip-komprimerad SVGZ-fil för att granska en vektorillustration utan att konvertera den. Zooma, dra för att panorera eller använd piltangenterna när illustrationen har fokus. Anpassa och återställ återför ritningen till det tillgängliga utrymmet. Ett transparensrutnät samt ljusa eller mörka bakgrunder gör det lättare att se ljus eller genomskinlig grafik.

## Mått och kompatibilitet

Detaljpanelen visar angivna mått och viewBox när de finns. Vid relativa eller saknade mått används viewBox, eller en visningsyta på 300 × 150 om viewBox saknas. Faktisk storlek är tillgänglig för absoluta mått. Den angivna visningsytan bevaras; grafik utanför den tas inte med automatiskt.

Banor, former, text, toningar, lokala masker och filter samt inbäddade statiska PNG-, JPEG- och WebP-bilder stöds där webbläsaren kan visa dem. Skript, SVG-animation, inbäddad HTML, länkade resurser, anpassade teckensnitt, nästlade SVG-bilder, animerade rasterbilder och stilar som inte stöds utelämnas. Installerade teckensnitt kan ändra textens utseende. Filer med dokumenttypsdeklarationer stöds inte.

## Lokalt och skrivskyddat

Filerna stannar på din enhet. Visaren laddar inte upp eller lagrar dem automatiskt och hämtar inte resurser som ett dokument refererar till. När du stänger eller byter fil frigörs dess förhandsvisning. Det finns ingen fast gräns för filstorlek eller antal ritelement; webbläsarens tillgängliga minne och renderingsförmåga avgör vad som kan öppnas. Använd SVG-konverteraren när du behöver exportera en bild.
