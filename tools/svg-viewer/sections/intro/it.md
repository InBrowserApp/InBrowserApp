## Visualizza illustrazioni SVG e SVGZ

Apri un file SVG locale o un file SVGZ compresso con gzip per esaminare un’illustrazione vettoriale senza convertirla. Regola lo zoom, trascina per spostarti o usa i tasti freccia quando l’illustrazione è selezionata. I comandi di adattamento e ripristino riportano il disegno nello spazio disponibile. Una griglia di trasparenza e sfondi chiari o scuri aiutano a distinguere le parti chiare o trasparenti dell’illustrazione.

## Dimensioni e compatibilità

Il pannello dei dettagli mostra le dimensioni dichiarate e il viewBox, quando disponibile. In caso di dimensioni relative o mancanti, viene usato il viewBox oppure, se assente, un’area di visualizzazione di 300 × 150. Le dimensioni reali sono disponibili per le dimensioni assolute. L’area di visualizzazione dichiarata viene preservata; le parti dell’illustrazione esterne a essa non vengono incluse automaticamente.

Tracciati, forme, testo, sfumature, maschere e filtri locali e immagini statiche PNG, JPEG e WebP incorporate sono supportati se il browser può visualizzarli. Script, animazioni SVG, HTML incorporato, risorse collegate, font personalizzati, immagini SVG annidate, immagini raster animate e stili non supportati vengono omessi. I font installati possono modificare l’aspetto del testo. I file con dichiarazioni del tipo di documento non sono supportati.

## In locale e in sola lettura

I file restano sul tuo dispositivo. Il visualizzatore non li carica né li salva automaticamente e non recupera le risorse a cui fa riferimento un documento. La chiusura o la sostituzione di un file libera le risorse dell’anteprima. Non esiste un limite fisso alla dimensione del file o al numero di elementi del disegno; la memoria disponibile nel browser e le sue capacità di rendering determinano quali file possono essere aperti. Usa il convertitore SVG quando ti serve un’immagine esportata.
