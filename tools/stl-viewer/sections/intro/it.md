## Aprire un file STL online

Trascina un file `.stl` nel visualizzatore o selezionalo dal tuo dispositivo. Puoi aprire file STL ASCII e binari nel browser. Il modello resta sul tuo dispositivo. Seleziona **Prova un esempio** per esplorare una piccola staffa di montaggio.

## Esaminare il modello 3D prima della stampa

Trascina per ruotare, usa la rotellina o il gesto di pizzicamento per lo zoom e trascina con il tasto destro o con due dita per spostare la vista. Scegli **Adatta alla vista** per inquadrare di nuovo l’intero modello. Attiva **Wireframe** per vedere i triangoli che compongono la superficie e capire quanto è fine, ad esempio, la mesh in una zona curva.

Le dimensioni d’ingombro indicano l’estensione del modello lungo gli assi X, Y e Z. STL memorizza le coordinate senza unità di misura. Una lunghezza di 40 può corrispondere a 40 mm o a 40 pollici, secondo le impostazioni di esportazione. Verifica l’unità quando importi il modello nel tuo slicer.

## Aprire altri formati 3D

STL descrive la superficie di una parte mediante triangoli. Per aprire un file Wavefront con la relativa libreria di materiali, usa il [Visualizzatore OBJ](../obj-viewer/). Per un file di interscambio CAD che contiene un assieme o un modello solido, usa il [Visualizzatore STEP](../step-viewer/).
