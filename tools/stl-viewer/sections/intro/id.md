## Buka file STL secara online

Seret file `.stl` ke penampil atau pilih file dari perangkat Anda. Browser dapat membuka STL ASCII maupun biner. Model tetap di perangkat Anda. Pilih **Coba contoh** untuk melihat model braket pemasangan kecil terlebih dahulu.

## Periksa model 3D sebelum mencetak

Seret untuk memutar, gulir atau cubit layar untuk memperbesar atau memperkecil, dan seret dengan tombol kanan mouse atau dua jari untuk menggeser tampilan. Gunakan **Tampilkan seluruh model** untuk mengembalikan seluruh model ke area tampilan. Aktifkan **Rangka kawat** untuk melihat segitiga yang membentuk permukaan dan memeriksa tingkat detail bagian yang melengkung setelah ekspor.

Dimensi menunjukkan bentang model dari ujung ke ujung pada sumbu X, Y, dan Z. STL menyimpan koordinat tanpa satuan. Nilai 40 dapat berarti 40 mm atau 40 inci, bergantung pada pengaturan ekspor. Pastikan satuannya saat mengimpor model ke aplikasi slicer untuk pencetakan 3D.
