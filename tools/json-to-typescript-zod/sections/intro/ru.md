## Как конвертер определяет типы полей

Конвертер анализирует все элементы массива. В этом примере поле `active` есть только в первой записи, поэтому оно становится необязательным. Поле `name` есть в обеих записях: в одной это строка, в другой — `null`. Поэтому поле остаётся обязательным и получает тип `string | null`.

```json
[
  { "id": 1, "name": "Ada", "active": true },
  { "id": 2, "name": null }
]
```

```ts
export type ApiResponse = Array<{
  id: number
  name: string | null
  active?: boolean
}>
```

Если в массиве нет ни одного элемента, тип его элементов будет `unknown`. Чтобы точнее описать ответы API, добавьте в пример записи с разной структурой.

## Когда использовать TypeScript или Zod

Используйте **TypeScript** для проверок в редакторе кода и при компиляции. С помощью **Zod** можно проверять входящие данные во время выполнения программы через `apiResponseSchema.safeParse(data)`. Сгенерированный файл Zod также экспортирует тип TypeScript. Если того требует контракт API, добавьте правила для допустимых значений или форматов строк.
