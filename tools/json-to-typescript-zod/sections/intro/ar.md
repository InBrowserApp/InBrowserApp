## كيف تُستنتج الحقول

يفحص المحوّل كل عنصر في المصفوفة. في هذا المثال، يظهر الحقل `active` في السجل الأول فقط، لذا يصبح اختياريًا. أما الحقل `name` فيظهر في كلا السجلين، بقيمة نصية في أحدهما وبقيمة `null` في الآخر، لذا يكون الحقل مطلوبًا ونوعه `string | null`.

```json
[
  { "id": 1, "name": "Ada", "active": true },
  { "id": 2, "name": null }
]
```

```ts
export type ApiResponse = Array<{
  id: number
  name: string | null
  active?: boolean
}>
```

إذا كانت المصفوفة فارغة في المثال، فسيكون نوع عناصرها `unknown`. أدرج سجلات تبيّن البُنى المختلفة التي تعيدها واجهة API لتحصل على نتيجة أكثر تمثيلًا لها.

## متى تستخدم TypeScript أو Zod

استخدم **TypeScript** للتحقق في محرر الشيفرة وأثناء الترجمة البرمجية. واستخدم **Zod** للتحقق من البيانات الواردة وقت التشغيل باستدعاء `apiResponseSchema.safeParse(data)`. يصدّر ملف Zod الناتج نوع TypeScript أيضًا. أضف قواعد خاصة بواجهة API، مثل القيم المسموح بها أو تنسيقات السلاسل النصية، إذا تطلّبتها مواصفات الواجهة.
