## फ़ील्ड का अनुमान कैसे लगाया जाता है

कन्वर्टर ऐरे के हर आइटम को देखता है। इस उदाहरण में `active` सिर्फ़ पहले रिकॉर्ड में मौजूद है, इसलिए यह फ़ील्ड वैकल्पिक है। `name` दोनों रिकॉर्ड में मौजूद है। एक में स्ट्रिंग है और दूसरे में `null`। इसलिए यह फ़ील्ड ज़रूरी है और इसका टाइप `string | null` है।

```json
[
  { "id": 1, "name": "Ada", "active": true },
  { "id": 2, "name": null }
]
```

```ts
export type ApiResponse = Array<{
  id: number
  name: string | null
  active?: boolean
}>
```

अगर उदाहरण में ऐरे खाली है, तो उसके एलिमेंट का टाइप `unknown` होगा। बेहतर नतीजे के लिए ऐसे रिकॉर्ड शामिल करें जो आपके API से मिलने वाले अलग-अलग ढाँचों के उदाहरण हों।

## TypeScript या Zod का इस्तेमाल कब करें

एडिटर में और कंपाइल करते समय जाँच के लिए **TypeScript** का इस्तेमाल करें। रनटाइम पर आने वाले डेटा की जाँच के लिए **Zod** के साथ `apiResponseSchema.safeParse(data)` इस्तेमाल करें। बनी हुई Zod फ़ाइल TypeScript टाइप को भी एक्सपोर्ट करती है। अगर आपके API कॉन्ट्रैक्ट में ज़रूरी हो, तो मान्य वैल्यू या स्ट्रिंग फ़ॉर्मेट जैसे नियम भी जोड़ें।
