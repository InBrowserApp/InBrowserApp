## วิธีอนุมานชนิดของฟิลด์

ตัวแปลงจะตรวจดูทุกรายการในอาร์เรย์ ในตัวอย่างนี้มีเพียงรายการแรกที่มี `active` ฟิลด์นี้จึงไม่บังคับ ทั้งสองรายการมี `name` รายการหนึ่งมีค่าเป็นสตริงและอีกรายการมีค่าเป็น `null` ฟิลด์นี้จึงเป็นฟิลด์บังคับและมีชนิดเป็น `string | null`

```json
[
  { "id": 1, "name": "Ada", "active": true },
  { "id": 2, "name": null }
]
```

```ts
export type ApiResponse = Array<{
  id: number
  name: string | null
  active?: boolean
}>
```

หากอาร์เรย์ไม่มีรายการตัวอย่าง ชนิดของสมาชิกจะเป็น `unknown` ใส่ตัวอย่างที่มีโครงสร้างหลากหลายตามที่ API ส่งกลับเพื่อให้ผลลัพธ์สะท้อนข้อมูลจริงมากขึ้น

## ควรใช้ TypeScript หรือ Zod เมื่อใด

ใช้ **TypeScript** เพื่อตรวจสอบชนิดข้อมูลในโปรแกรมแก้ไขโค้ดและขณะคอมไพล์ ใช้ **Zod** เพื่อตรวจสอบข้อมูลที่เข้ามาขณะรันโปรแกรมด้วย `apiResponseSchema.safeParse(data)` ไฟล์ Zod ที่สร้างขึ้นจะส่งออกชนิดข้อมูล TypeScript ด้วย เพิ่มกฎเฉพาะของ API เช่น ค่าที่อนุญาตหรือรูปแบบสตริง ตามข้อกำหนดของ API
