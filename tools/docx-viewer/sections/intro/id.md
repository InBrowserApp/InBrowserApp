## Baca dokumen Word di browser Anda

Buka file .docx lokal atau letakkan di penampil. Berpindah antarhalaman, atur zoom atau sesuaikan halaman dengan lebar yang tersedia, pilih teks untuk disalin, dan cari dalam dokumen. Tabel, gambar, header, dan footer ditampilkan jika didukung.

## Privasi dan kompatibilitas

Dokumen diproses secara lokal serta tidak diunggah atau disimpan oleh alat ini. Font diambil dari dokumen atau perangkat Anda; tidak ada font daring yang diminta. Penggantian font dan fitur yang tidak didukung dapat mengubah pemenggalan baris dan pembagian halaman dibandingkan dengan Word desktop.

Ukuran hasil ekstraksi arsip dan halaman yang dirender dibatasi untuk membatasi penggunaan memori browser. Dokumen terenkripsi, file .doc lama, templat, dan file dengan makro tidak didukung. Penampil ini tidak mengedit, mengekspor, atau mencetak dokumen, menjalankan makro, maupun memuat sumber daya dokumen eksternal.
