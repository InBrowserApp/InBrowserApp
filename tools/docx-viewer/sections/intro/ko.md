## 브라우저에서 Word 문서 읽기

기기에 있는 .docx, .docm, .dotx 또는 .dotm 파일을 열거나 뷰어에 끌어다 놓으세요. 문서와 서식 파일은 저장된 내용을 읽기 전용으로 엽니다. 페이지 사이를 이동하고, 확대 및 축소하거나 페이지를 사용 가능한 너비에 맞추고, 텍스트를 선택하여 복사하고, 문서에서 검색할 수 있습니다. 지원되는 표, 이미지, 머리글, 바닥글이 표시됩니다. Markdown 내보내기로 텍스트 사본을 준비한 다음 Markdown 다운로드로 저장하세요.

## 개인정보 보호 및 호환성

문서는 기기에서 처리되며 이 도구가 업로드하거나 저장하지 않습니다. 문서에 포함된 글꼴이나 기기의 글꼴을 사용하며, 온라인 글꼴을 요청하지 않습니다. 글꼴 대체 및 지원되지 않는 기능으로 인해 데스크톱 Word와 줄 바꿈이나 페이지 구분이 달라질 수 있습니다.

매크로 사용 문서와 서식 파일을 볼 수 있지만 매크로는 실행되지 않습니다. 매크로, 양식 자동화 또는 외부 데이터에 의존하는 내용은 업데이트되지 않습니다. 서식 파일은 새 문서를 만들지 않고 엽니다.

브라우저 메모리 사용량을 제한하기 위해 압축 해제 크기와 렌더링되는 페이지 크기가 제한됩니다. 암호화된 문서와 이전 형식인 .doc 파일은 지원하지 않습니다. 이 뷰어는 문서를 편집하거나 인쇄하지 않으며 외부 문서 리소스를 불러오지 않습니다.

Markdown 내보내기는 텍스트와 기본 구조를 유지하며 머리글, 바닥글, 각주, 미주, 메모를 별도 섹션에 표시합니다. 페이지 레이아웃이나 글꼴은 유지하지 않습니다. 이미지, 차트, 수식, 지원하지 않는 도형은 생략 표시로 대체되며, 복잡한 표와 추적된 변경 내용은 단순화됩니다. 중요한 내용은 원본과 비교해 확인하세요.

지원되는 문서를 이미지 기반 PDF로 다운로드하려면 [DOCX → PDF 변환기](../docx-to-pdf-converter/)를 사용하고 다운로드하기 전에 출력 모양을 확인하세요.
