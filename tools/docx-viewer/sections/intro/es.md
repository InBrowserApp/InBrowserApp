## Lee un documento de Word en tu navegador

Abre un archivo .docx, .docm, .dotx o .dotm local o suéltalo en el visor. Los documentos y las plantillas se abren con el contenido guardado, en modo de solo lectura. Navega por las páginas, amplía o ajusta la página al ancho disponible, selecciona texto para copiarlo y busca en el documento. Se muestran tablas, imágenes, encabezados y pies de página cuando son compatibles. Usa «Exportar Markdown» para preparar una copia de texto y después «Descargar Markdown» para guardarla.

## Privacidad y compatibilidad

Los documentos se procesan localmente y esta herramienta no los sube ni los guarda. Las fuentes se toman del documento o de tu dispositivo; no se solicitan fuentes en línea. La sustitución de fuentes y las funciones no compatibles pueden cambiar los saltos de línea y la paginación con respecto a Word de escritorio.

Se pueden ver documentos y plantillas habilitados para macros, pero sus macros nunca se ejecutan. El contenido que depende de macros, automatización de formularios o datos externos no se actualiza. Las plantillas se abren sin crear un documento nuevo.

Se limita el tamaño de los datos descomprimidos y de las páginas renderizadas para mantener acotado el uso de memoria del navegador. No se admiten documentos cifrados ni archivos .doc antiguos. El visor no edita ni imprime documentos ni carga recursos externos del documento.

La exportación a Markdown conserva el texto y la estructura básica, con los encabezados, pies de página, notas y comentarios en secciones separadas. No conserva el diseño de página ni las fuentes. Las imágenes, gráficos, ecuaciones y formas no compatibles usan marcadores de omisión; las tablas complejas y los cambios registrados se simplifican. Compara el contenido importante con el original.

Para descargar un documento compatible como PDF basado en imágenes, usa el [Conversor de DOCX a PDF](../docx-to-pdf-converter/) y comprueba el aspecto del resultado antes de descargarlo.
