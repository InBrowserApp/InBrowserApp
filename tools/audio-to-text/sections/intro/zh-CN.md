## 如何将录音转成文字

将会议录音、采访、讲座、播客或语音备忘录拖入工具。可以使用自动语言检测；如果知道录音中的语言，也可以手动选择。选择 转写模型，然后点击**开始转写**。文字稿生成后，点击时间戳即可回听对应片段。复制或下载前，你可以修改人名、标点和识别错误的词语。

工具可以读取浏览器能够解码的音频格式，包括常见的 MP3、WAV、M4A、FLAC、OGG 和 WebM。不同浏览器支持的编码格式可能不同。如果文件无法打开，请尝试从录音工具导出为 WAV 或 MP3。

## 如何选择转写模型？

清晰的录音或初次转写可以使用 **Whisper Base**。**Whisper Small** 有助于识别口音和对话。**Whisper Large V3 Turbo** 适合有噪声或听不清的录音，但下载文件更大，占用的内存也更多。Whisper 模型支持将多种语言转写为原语言文字。**SenseVoiceSmall** 支持普通话、粤语、英语、日语和韩语。 **Qwen3-ASR 0.6B** 支持纯文本转写，也可对齐时间戳以供回放和制作字幕；对齐时会额外下载一个模型。纯文本文字稿可导出为 TXT。

当浏览器和显卡支持时，Whisper 使用 WebGPU 加速。首次运行会下载所选模型；浏览器可以复用其缓存中保留的模型文件。下载大小和处理时间取决于模型和设备。录音在设备上解码和转写，模型下载不包含你的音频。SenseVoiceSmall 通过 WebAssembly 在设备的 CPU 上本地运行。如果 WebGPU 不可用，Whisper 会通过 WebAssembly 回退到 CPU 运行。

## 导出带时间戳的文字稿或字幕

- **TXT** 为每个段落标注开始时间。例如，`[00:02:15.320] Let's review the agenda.` 对应录音开始两分多钟后的一行文字，适合用于会议笔记、采访引文或可搜索的文本。
- **SRT**（SubRip） 为每条编号字幕标注开始和结束时间，是视频编辑软件常用的格式。
- **VTT**（WebVTT） 也为每条字幕标注开始和结束时间，适用于支持字幕轨道的 HTML 视频播放器。

工具 会估计每个段落的开始和结束位置。分享前请回听重要引文，并检查字幕时间。背景噪声和多人同时说话可能影响结果。文字稿按时间分段。
