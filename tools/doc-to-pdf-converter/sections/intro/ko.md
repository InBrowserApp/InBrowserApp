## 이전 버전의 문서를 PDF로 변환

로컬의 Word 97–2003 DOC 또는 호환되는 WPS / WPT 문서를 여세요. 지원되는 본문 텍스트, 표, 포함된 래스터 이미지를 여백이 18 mm인 A4 세로 페이지에 재배치합니다. 복구된 명시적 페이지 나누기는 유지됩니다. 페이지 이동, 확대/축소 또는 집중 모드로 생성된 PDF를 확인한 다음 다운로드하세요.

## 모양과 호환성

PDF는 흰색 배경의 150 DPI 이미지 페이지로 구성됩니다. 텍스트를 선택하거나 검색할 수 없으며 OCR은 추가되지 않습니다. 내용이 재배치된 사본이므로 원래 페이지 크기, 단 구성, 위치, 글꼴, 간격 및 페이지 수는 정확하게 재현되지 않습니다. 필드는 다시 계산하지 않고 저장된 텍스트를 사용합니다. 변경 내용이 적용된 최종본 보기에서는 삽입된 텍스트는 남고 삭제된 텍스트는 제거됩니다.

자동 번호 매기기, 머리글, 바닥글, 각주, 미주, 메모, 텍스트 상자, 포함된 개체, 누락된 이미지 또는 지원하지 않는 내용이 감지되면 변환이 중단되며 일부만 변환된 파일은 다운로드할 수 없습니다. 직접 입력한 목록 번호는 일반 텍스트로 유지됩니다. 복잡한 문서는 원래 Office 애플리케이션에서 내보내야 합니다. 이전 WPS 전용 형식, Microsoft Works, OLE 안에 HTML이 담긴 문서 및 암호로 보호된 문서는 지원하지 않습니다. 서식 파일은 저장된 내용을 내보냅니다. 매크로는 절대 실행하지 않으며, 대화형 링크와 디지털 서명은 보존하거나 검증하지 않습니다.

## 로컬 처리

문서는 이 브라우저 안에만 유지됩니다. 원격 문서 리소스와 글꼴을 가져오지 않습니다. 변환을 취소하거나 문서를 바꾸거나 닫으면 변환 결과가 삭제되고 처리 리소스가 해제됩니다. 파일 크기나 페이지 수에는 정해진 제한이 없지만, 실제 브라우저 메모리와 이미지 리소스 한도는 적용됩니다.

원본 파일을 읽으려면 [DOC 및 WPS 뷰어](../doc-viewer/)를 사용하세요. 최신 Word 파일에는 [DOCX → PDF 변환기](../docx-to-pdf-converter/)를 사용하세요.
