## Convierte documentos antiguos a PDF

Abre un documento DOC de Word 97–2003 o WPS / WPT compatible que tengas en tu dispositivo. El texto principal, las tablas y las imágenes de mapa de bits incrustadas compatibles se redistribuyen en páginas A4 en orientación vertical con márgenes de 18 mm. Los saltos de página explícitos se conservan cuando se pueden recuperar. Revisa el PDF generado con la navegación por páginas, el zoom o el modo de vista previa centrada y luego descárgalo.

## Aspecto y compatibilidad

El PDF contiene páginas de imágenes a 150 DPI con fondo blanco. El texto no se puede seleccionar ni buscar, y no se añade OCR. Esta es una copia con el contenido redistribuido: los tamaños de página, las columnas, la posición de los elementos, las fuentes, el espaciado y el número de páginas del original no se reproducen exactamente. Se usa el texto guardado de los campos sin recalcularlo. La vista final de las revisiones conserva el texto insertado y elimina el texto borrado.

Si se detectan numeración automática, encabezados, pies de página, notas al pie, notas al final, comentarios, cuadros de texto, objetos incrustados, imágenes ausentes o contenido no compatible, la conversión se detiene sin ofrecer una descarga parcial. Los números de listas escritos manualmente permanecen como texto normal. Los documentos complejos deben exportarse desde su aplicación de Office original. No se admiten formatos WPS propietarios antiguos, Microsoft Works, HTML-in-OLE ni documentos protegidos con contraseña. Las plantillas exportan su contenido guardado. Las macros nunca se ejecutan; los enlaces interactivos y las firmas digitales no se conservan ni se verifican.

## Procesamiento local

Los documentos permanecen en este navegador. No se descargan recursos remotos de los documentos ni fuentes remotas. Al cancelar, reemplazar o cerrar un documento, se descarta su resultado y se liberan los recursos de procesamiento. No hay un límite fijo de tamaño de archivo ni de número de páginas; siguen aplicándose los límites reales de memoria y de procesamiento de imágenes del navegador.

Para leer el archivo original, usa el [Visor de DOC y WPS](../doc-viewer/). Para archivos de Word modernos, usa el [Conversor de DOCX a PDF](../docx-to-pdf-converter/).
