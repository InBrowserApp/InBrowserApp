## Kompatibilitas dan font

File biner HWP 5 dan paket HWPX didukung dengan kompatibilitas terbatas. Teks Korea dan campuran bahasa, tabel biasa, serta gambar tertanam dapat ditampilkan. Ini adalah pratinjau visual: pemilihan teks dan pencarian dokumen tidak tersedia.

Penampil menggunakan font yang tersedia di perangkat Anda dan tidak mengunduh font dokumen. Penggantian font dapat mengubah karakter, pemisah baris, perataan formulir, dan pembagian halaman. Tabel bersarang, persamaan, header dan footer, kotak teks, serta objek tertanam mungkin berbeda dari Hangul atau tidak ditampilkan. Konten tertaut eksternal tidak dimuat. Periksa detail penting dan formulir resmi di Hangul; pratinjau ini tidak memverifikasi tanda tangan atau keaslian.
