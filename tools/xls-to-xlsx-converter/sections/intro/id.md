## Konversi buku kerja Excel lama di browser Anda

Buka atau letakkan file XLS lokal. Pilih lembar kerja, periksa data selnya, lalu unduh buku kerja XLSX. Anda dapat menelusuri pratinjau atau memasukkan alamat sel kiri atas untuk berpindah ke area lain. Jendela pratinjau tidak membatasi ekspor: semua lembar kerja dan sel yang diimpor disertakan.

Nama dan urutan lembar kerja, lembar kosong, status tersembunyi lembar, teks, angka, boolean, kesalahan lembar bentang, format angka yang didukung, sel gabungan, tinggi baris, lebar kolom, serta baris dan kolom tersembunyi dipertahankan sejauh didukung oleh pengurai file sumber. Pengenal teks mempertahankan nol di awal. Tanggal mempertahankan nomor seri Excel dan sistem tanggal buku kerja.

## Rumus dan kompatibilitas

Ekspresi rumus yang didukung beserta hasil tersimpannya dipertahankan. Browser tidak menghitung ulang rumus atau memperbarui data eksternal. Rumus tanpa hasil tersimpan ditampilkan dengan pemberitahuan dalam pratinjau; ekspresinya tetap ada dalam file hasil agar dapat dihitung oleh aplikasi lembar bentang. Ekspresi rumus yang tidak didukung atau referensi eksternal mungkin tidak dipertahankan dengan benar selama konversi.

Ini adalah konversi data, bukan reproduksi akurat dari setiap fitur buku kerja. Bagan, gambar, makro, fitur pivot, dan gaya lanjutan tidak dipertahankan. Pratinjau tidak mereproduksi tata letak sel gabungan atau pemformatan. Periksa buku kerja yang diunduh di aplikasi lembar bentang Anda, terutama jika rumus atau tata letak penting. Lembar makro, lembar bagan, file terenkripsi, file rusak, dan file yang hanya diubah namanya menjadi .xls tidak didukung.

## Pemrosesan lokal

Buku kerja Anda diproses di browser ini tanpa mengunggah isinya. Makro tidak dijalankan dan sumber daya tertaut tidak diambil. Mengganti atau menutup buku kerja membuang hasilnya; membatalkan menghentikan konversi. Tidak ada batas tetap untuk ukuran file atau jumlah lembar kerja, meskipun pemrosesan buku kerja besar tetap bergantung pada memori browser yang tersedia.

Untuk menelusuri format lembar bentang lainnya, buka [Penampil Lembar Bentang](../xlsx-viewer/).
