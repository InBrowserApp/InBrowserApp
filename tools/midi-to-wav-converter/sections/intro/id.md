## Konversikan MIDI ke WAV di browser

Pilih file .mid atau .midi, lalu pilih **Konversikan ke WAV**. Dengarkan hasilnya dan unduh file WAV stereo 44,1 kHz, 16 bit. Gunakan WAV untuk membagikan trek pengiring, mengimpor audio ke editor video, atau mengirim versi yang bisa diputar tanpa memasang instrumen MIDI.

## Cara suara instrumen dipilih

File MIDI menyimpan instruksi seperti not, tempo, dan pergantian instrumen. SoundFont menyediakan sampel instrumen untuk mengubah instruksi tersebut menjadi audio. SoundFont GeneralUser GS bawaan mencakup instrumen dan drum standar General MIDI. Untuk mencoba suara piano, set drum, atau bank instrumen lain, pilih file .sf2 atau .sf3 milik Anda sebelum mengonversi. WAV akan menggunakan suara dari SoundFont yang Anda pilih.

## Dengarkan pratinjau dan unduh WAV

Dengarkan hasil pencampuran audio sebelum mengunduhnya. Perenderan menambahkan sedikit waktu di bagian akhir agar suara not dan efek dapat meluruh setelah peristiwa MIDI terakhir. Alat ini merender file MIDI dengan pengaturan waktu berbasis ketukan (format 0 atau 1) yang berdurasi kurang dari 10 menit dan memproses MIDI serta SoundFont secara lokal. Bank suara bawaan diunduh saat pertama kali Anda menggunakannya.
