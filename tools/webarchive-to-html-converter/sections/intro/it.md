## Convertire un WebArchive di Safari in HTML

In Safari sul Mac, scegli File → Salva come e seleziona Archivio web come formato per creare un file `.webarchive`. Trascina il file qui o scegli **Apri WebArchive**. Controlla l’anteprima e seleziona **Scarica HTML** per salvare un file `.html` da aprire in un altro browser, condividere o conservare per consultarlo offline. Prova l’archivio di esempio per vedere come funziona prima di aprire un tuo file.

## Cosa contiene il file HTML?

Un WebArchive di Safari contiene la pagina principale e copie di alcune risorse. Il convertitore incorpora direttamente nell’HTML le immagini, i fogli di stile e i caratteri salvati che supporta. Il testo resta selezionabile e il file risultante usa la codifica UTF-8. Anche se mancano alcune risorse, puoi scaricare la pagina convertita. L’aspetto può cambiare quando il file salvato dipende da script, frame o risorse che non sono state incluse nell’archivio.

## I file vengono caricati online?

Il browser legge l’archivio e prepara il file da scaricare sul tuo dispositivo. L’anteprima e la pagina esportata usano una copia statica della pagina principale con script e moduli disattivati. Le risorse mancanti non vengono recuperate dal sito originale.
