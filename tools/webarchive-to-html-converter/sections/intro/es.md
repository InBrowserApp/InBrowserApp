## Convertir un WebArchive de Safari a HTML

En Safari para Mac, elige Archivo → Guardar como y selecciona Archivo web como formato para crear un archivo `.webarchive`. Arrastra el archivo hasta aquí o elige **Abrir WebArchive**. Comprueba la vista previa y selecciona **Descargar HTML** para guardar un archivo `.html` que puedes abrir en otro navegador, compartir o consultar sin conexión. Prueba el archivo de ejemplo para ver cómo funciona antes de abrir el tuyo.

## ¿Qué incluye el archivo HTML?

Un WebArchive de Safari guarda la página principal y copias de algunos recursos. El conversor incrusta directamente en el HTML las imágenes, hojas de estilo y fuentes guardadas que sean compatibles. Puedes seguir seleccionando el texto y el archivo resultante usa UTF-8. Si faltan recursos, puedes descargar igualmente la página convertida. El aspecto puede variar si el archivo guardado depende de scripts, marcos o recursos que no se incluyeron al guardarlo.

## ¿Se sube algún archivo?

Tu navegador lee el archivo y genera la descarga en tu dispositivo. La vista previa y la página exportada usan una copia estática de la página principal con los scripts y los formularios desactivados. Los recursos que faltan no se solicitan al sitio web original.

[Guardar parte de una página web o una página web completa en Safari](https://support.apple.com/guide/safari/save-part-or-all-of-a-webpage-ibrw1089/mac)
