## Safari WebArchive를 HTML로 변환하기

Mac의 Safari에서 파일 메뉴의 별도 저장을 선택한 뒤 형식으로 웹 아카이브를 지정하면 `.webarchive` 파일을 만들 수 있습니다. 파일을 여기에 끌어다 놓거나 **WebArchive 열기**를 선택하세요. 미리보기를 확인하고 **HTML 다운로드**를 선택하면 일반 `.html` 파일로 저장됩니다. 다른 브라우저에서 열거나 공유할 수 있고 오프라인에서도 보관할 수 있습니다. 내 파일을 열기 전에 샘플 아카이브를 사용해 보세요.

## HTML 파일에는 무엇이 포함되나요?

Safari 웹 아카이브에는 기본 페이지와 일부 리소스의 사본이 저장됩니다. 변환기는 저장된 이미지, 스타일시트, 글꼴 중 지원되는 항목을 HTML에 직접 포함합니다. 변환 후에도 텍스트를 선택할 수 있으며 UTF-8 인코딩이 사용됩니다. 일부 리소스가 없어도 변환된 페이지를 다운로드할 수 있습니다. 페이지가 스크립트, 프레임 또는 저장되지 않은 리소스에 의존하면 원래와 다르게 보일 수 있습니다.

## 파일을 업로드하나요?

브라우저가 기기에서 아카이브를 읽고 다운로드 파일을 만듭니다. 미리보기와 내보낸 파일은 기본 페이지의 정적 사본을 사용하며 스크립트와 양식은 비활성화됩니다. 저장되지 않은 리소스는 원본 웹사이트에서 불러오지 않습니다.

[Safari에서 웹 페이지의 일부 또는 전체 저장하기](https://support.apple.com/guide/safari/save-part-or-all-of-a-webpage-ibrw1089/mac)
