## Как преобразовать веб-архив Safari в HTML

В Safari на Mac выберите «Файл» → «Сохранить как», затем выберите формат «Веб-архив», чтобы создать файл `.webarchive`. Перетащите его сюда или выберите **Открыть WebArchive**. Проверьте предпросмотр и нажмите **Скачать HTML**, чтобы получить обычный файл `.html`. Его можно открыть в другом браузере, отправить или сохранить для просмотра без интернета. Откройте архив-пример, чтобы проверить, как работает инструмент, прежде чем открывать свой файл.

## Что входит в HTML-файл?

Веб-архив Safari содержит основную страницу и копии некоторых ресурсов. Конвертер встраивает в HTML сохранённые изображения, таблицы стилей и шрифты поддерживаемых форматов. Текст по-прежнему можно выделять, а файл использует кодировку UTF-8. Если часть ресурсов отсутствует, преобразованную страницу всё равно можно скачать. Внешний вид может измениться, если для страницы нужны скрипты, фреймы или ресурсы, которых нет в архиве.

## Отправляются ли файлы на сервер?

Браузер читает архив и создаёт файл на вашем устройстве. Для предпросмотра и скачивания используется статическая копия основной страницы с отключёнными скриптами и формами. Отсутствующие ресурсы с исходного сайта не загружаются.
