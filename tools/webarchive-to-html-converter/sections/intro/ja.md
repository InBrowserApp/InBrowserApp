## Safari の WebArchive を HTML に変換する

Mac の Safari で「ファイル」→「別名で保存」を選び、フォーマットに「ウェブアーカイブ」を指定すると、`.webarchive` ファイルを作成できます。ファイルをここにドラッグ＆ドロップするか、**WebArchive を開く**を選びます。プレビューを確認し、**HTML をダウンロード**を選ぶと、別のブラウザーで開いたり、共有したり、オフラインで保存したりできる通常の `.html` ファイルが手に入ります。自分のファイルを開く前に、サンプルでも試せます。

## HTML ファイルには何が含まれますか？

Safari のウェブアーカイブには、メインページと一部のリソースのコピーが保存されます。変換ツールは、保存済みで対応している形式の画像、スタイルシート、フォントを HTML に直接埋め込みます。変換後もテキストを選択でき、文字コードは UTF-8 です。一部のリソースがなくても、変換後のページはダウンロードできます。スクリプト、フレーム、保存されなかったリソースに依存するページは、見た目が変わる場合があります。

## ファイルはアップロードされますか？

ブラウザーは端末内でアーカイブを読み込み、ダウンロードするファイルを作成します。プレビューと書き出し結果にはメインページの静的なコピーを使い、スクリプトとフォームは無効になります。保存されていないリソースは元のウェブサイトから取得しません。

[Safari でウェブページの一部または全体を保存する](https://support.apple.com/guide/safari/save-part-or-all-of-a-webpage-ibrw1089/mac)
