## Convert a Safari WebArchive to HTML

In Safari on Mac, choose File → Save As and select Web Archive to create a `.webarchive` file. Drop that file here or choose **Open WebArchive**. Check the preview and select **Download HTML** to save an ordinary `.html` file you can open in another browser, share, or keep offline. Try the sample archive to see the process before opening your own file.

## What is included in the HTML file?

A Safari WebArchive stores the main page and copies of some resources. The converter embeds supported saved images, style sheets, and fonts directly into the HTML. Text remains selectable and the output uses UTF-8. If some resources are missing, you can still download the converted page. Appearance can differ when the saved archive depends on scripts, frames, or resources it did not capture.

## Are any files uploaded?

Your browser reads the archive and creates the download on your device. The preview and exported page use a static copy of the main page with scripts and forms disabled. Missing resources are not fetched from the original website.
