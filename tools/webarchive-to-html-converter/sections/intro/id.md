## Mengubah WebArchive dari Safari menjadi HTML

Di Safari di Mac, pilih File → Simpan Sebagai, lalu pilih format Arsip Web untuk membuat file `.webarchive`. Seret dan lepaskan file itu di sini atau pilih **Buka WebArchive**. Periksa pratinjau dan pilih **Unduh HTML** untuk menyimpan file `.html` biasa yang dapat dibuka di browser lain, dibagikan, atau disimpan untuk dibuka secara offline. Coba arsip contoh untuk melihat prosesnya sebelum membuka file Anda sendiri.

## Apa yang disertakan dalam file HTML?

WebArchive dari Safari menyimpan halaman utama dan salinan beberapa sumber dayanya. Konverter menyematkan gambar, lembar gaya, dan font tersimpan yang didukung langsung ke file HTML. Teks tetap dapat diseleksi dan hasilnya memakai pengodean UTF-8. Jika ada sumber daya yang hilang, Anda tetap dapat mengunduh halaman hasil konversi. Halaman dapat terlihat berbeda jika bergantung pada skrip, bingkai, atau sumber daya yang tidak tersimpan di arsip.

## Apakah file diunggah?

Browser membaca arsip dan membuat file unduhan di perangkat Anda. Pratinjau dan file hasil konversi memakai salinan statis halaman utama dengan skrip dan formulir yang dinonaktifkan. Browser tidak mengambil sumber daya yang hilang dari situs asli.
