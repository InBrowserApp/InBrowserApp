## Baca dokumen OFD secara lokal

Buka atau letakkan file `.ofd` untuk melihat halamannya di browser ini. Gunakan ikhtisar halaman, kontrol sebelumnya dan berikutnya, atau masukkan nomor halaman. Sesuaikan lebar, sesuaikan halaman, pembesaran, dan rotasi membantu Anda membaca berbagai ukuran dan orientasi halaman. Fokus membaca memberi lebih banyak ruang untuk dokumen. Ganti atau tutup file untuk melepas dokumen saat ini.

File diproses di perangkat Anda. Penampil ini tidak mengunggah dokumen, mengambil sumber daya dokumen dari server jarak jauh, menjalankan tindakan dokumen, atau menyimpan riwayat bacaan. Ini adalah pratinjau visual; pemilihan teks, pencarian dokumen, pengeditan, pencetakan, dan ekspor tidak tersedia.

## Kompatibilitas dan detail penting

File OFD dapat berisi teks dengan posisi tertentu, tabel, gambar yang disematkan, dan anotasi. Tampilannya bergantung pada fitur dokumen, font yang disematkan, dan format gambar yang didukung browser Anda. Font pengganti dapat mengubah karakter atau perataan. Grafik kompleks, beberapa efek warna, serta gambar JBIG2 atau gambar lain yang tidak didukung mungkin tidak muncul atau berbeda dari tampilannya di aplikasi pembaca OFD khusus. Masalah tampilan yang diketahui dilaporkan di area baca; pratinjau bukan pemeriksaan menyeluruh atas kesesuaian format.

Tanda tangan digital tidak diverifikasi. Tampilan cap yang disimpan di dalam tanda tangan digital tidak ditampilkan; gambar atau ilustrasi cap biasa mungkin terlihat. Cap yang terlihat tidak membuktikan keaslian. Jika suatu paket berisi beberapa dokumen, penampil ini hanya menampilkan dokumen pertama dan menjelaskan bahwa paket tersebut ditampilkan secara tidak lengkap di sini. Periksa jumlah nominal penting, konten yang hilang, dan informasi tanda tangan dengan aplikasi pembaca OFD yang sesuai.

Tidak ada batas tetap untuk ukuran file atau jumlah halaman. Memori browser yang tersedia dan kerumitan halaman tetap dapat menyebabkan dokumen gagal dibuka. Pada tingkat pembesaran yang sangat tinggi, halaman dapat melebihi batas alokasi kanvas browser; kurangi pembesaran atau gunakan Sesuaikan halaman.
