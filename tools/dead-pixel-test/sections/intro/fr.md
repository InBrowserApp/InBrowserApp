## Comment repérer les pixels morts sur votre écran

Nettoyez d’abord votre écran pour éviter de confondre poussières et traces de doigts avec un défaut. Choisissez **Lancer le test en plein écran**, puis examinez le centre, les bords et les coins sur chacun des cinq aplats de couleur. Cliquez ou touchez la couleur pour passer à la suivante. Les flèches permettent d’aller dans les deux sens. Utilisez **Masquer les commandes** pour examiner la zone qu’elles couvrent, puis touchez l’écran pour les faire réapparaître. Choisissez **Quitter le plein écran** ou appuyez sur Échap pour terminer.

## À quoi ressemble un pixel mort ou bloqué ?

Sur fond blanc, cherchez de minuscules points sombres. Sur fond noir, cherchez les pixels qui restent allumés. Le rouge, le vert et le bleu aident à isoler un sous-pixel qui reste éteint ou allumé sur une couleur. Vérifiez que le point reste exactement au même endroit quand vous changez de couleur. La poussière et les reflets peuvent ressembler à des défauts, surtout quand vous regardez l’écran de biais.

## Tester un ordinateur portable, un téléphone ou un moniteur externe

Ouvrez le test sur l’écran à examiner. Si vous avez plusieurs moniteurs, quittez le plein écran et déplacez le navigateur sur le suivant avant de relancer le test. Sur un téléphone, changez l’orientation si cela facilite l’examen. Ce test permet de repérer les défauts de pixels à l’œil nu. Pour une demande de prise en charge sous garantie, comparez vos observations aux critères du fabricant de l’écran.
