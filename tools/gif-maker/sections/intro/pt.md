## Crie um GIF animado a partir de imagens

Transforme uma sequência de imagens PNG, JPG (JPEG), WebP ou AVIF em um único GIF animado. Cada imagem vira um quadro. Junte capturas de tela para mostrar como uma interface funciona, anime uma série de ilustrações ou crie uma apresentação curta de fotos para compartilhar em um só arquivo.

## Como transformar imagens em um GIF

1. **Adicionar imagens.** Selecione ou solte pelo menos dois arquivos de imagem. Você pode misturar os formatos compatíveis na mesma animação.
2. **Organize os quadros.** Arraste os quadros ou use as setas para cima e para baixo. A lista mostra a ordem de reprodução.
3. **Ajuste a duração.** Altere a duração ao lado de cada quadro. Para começar com um ritmo uniforme, digite uma duração e selecione **Aplicar a todos**. Depois, ajuste os quadros que precisam ficar mais ou menos tempo na tela.
4. **Crie, confira e baixe o GIF.** Defina o número de reproduções e selecione **Criar GIF**. Use **Reproduzir** para conferir a animação e depois selecione **Baixar GIF**. Você pode editar os quadros que já adicionou e criar outra versão.

## Escolha a duração dos quadros e o número de reproduções

A duração indica quanto tempo cada quadro fica visível, em milissegundos. O valor padrão de 200 ms exibe cinco quadros por segundo em intervalos regulares. Use durações menores para movimentos rápidos e maiores quando for preciso dar tempo para ler um texto. Ajuste a duração em incrementos de 10 ms, a partir de 20 ms.

O número de reproduções indica quantas vezes a animação inteira será exibida. Digite **0** para repetir indefinidamente, **1** para reproduzir uma vez ou um número como **3** para reproduzir a sequência completa três vezes.

Para um tutorial de três etapas, experimente **200 ms**, **200 ms** e **600 ms**. Cada reprodução dura um segundo, com uma pausa maior na captura final. Defina **3** reproduções para obter uma animação de três segundos.

## Combine imagens de tamanhos diferentes e mantenha os fundos transparentes

O GIF usa uma única área de imagem com base no quadro mais largo e no mais alto. As imagens ficam centralizadas e o espaço ao redor das menores permanece transparente. Se o lado mais longo passar de 1280 pixels, a ferramenta reduz as dimensões proporcionalmente. Para manter o mesmo enquadramento durante toda a animação, ajuste as imagens para as mesmas dimensões no [Redimensionador de imagens](../image-resizer/).

Em um GIF, cada pixel é totalmente transparente ou totalmente opaco. Bordas suaves e sombras semitransparentes podem ficar diferentes na animação exportada. Confira esses detalhes na prévia.

## Perguntas frequentes

### Como reduzir o tamanho do arquivo GIF?

Use imagens de origem menores ou remova quadros que pouco contribuem para o movimento. Você pode conferir as dimensões e o tamanho do arquivo exportado na prévia. Se seu projeto web aceitar WebP animado, experimente o [Conversor de GIF para WebP animado](../gif-to-animated-webp-converter/).

### Onde minhas imagens são processadas?

Seu navegador lê as imagens e cria o GIF no seu dispositivo. O GIF é baixado como um único arquivo que você pode salvar e compartilhar.
