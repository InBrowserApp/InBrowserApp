## 将演示文稿转换为 Markdown

打开本地 .pptx、.pptm、.potx、.potm、.ppsx 或 .ppsm 文件，或将其拖放到转换器中。预览 Markdown 文本，复制文本，或下载沿用原文件名的 UTF-8 .md 文件。更换或关闭文件会取消尚未完成的转换，并清除之前的输出。PPTX 查看器也提供“导出 Markdown”操作。

## 将幻灯片和备注保留在一起

幻灯片按文件中的顺序排列。每张幻灯片都有带编号的标题，并包含可提取的幻灯片标题；隐藏幻灯片也会包含在内并加以标记。段落、基本强调格式、嵌套列表、表格和支持的链接会保留实用的结构。可提取的演讲者备注会列在对应幻灯片之后。文本中的 Markdown 标点符号和 HTML 会进行转义，以保持为普通文本。

导出内容遵循文件保存的内容顺序，这可能与按对象位置设定的阅读顺序不同。导出不会重现字体、页面布局、动画或切换效果。图片、图表、公式、媒体和嵌入对象会以省略标记表示；形状中可提取的文本会保留。模板装饰和审阅批注不会导出。合并单元格和复杂格式会被简化。没有表头行的表格会添加空的 Markdown 表头。不同 Markdown 应用对内联 HTML 和换行的支持有所不同，因此请对照原始演示文稿检查输出。

## 本地处理与兼容性

文件始终留在此浏览器中，本工具不会上传或保存文件。宏、脚本、媒体和外部资源不会运行或加载。域使用其已保存的文本，而非刷新后的值。不支持加密演示文稿、旧版 .ppt 文件，以及没有可提取文本的演示文稿。文件大小和幻灯片数量没有固定限制，但复杂演示文稿可能超出浏览器的资源容量。本工具用于导出文本，不会编辑演示文稿，也不会将图片转为文字。
