## 프레젠테이션을 Markdown으로 변환하기

기기에 있는 .pptx, .pptm, .potx, .potm, .ppsx 또는 .ppsm 파일을 열거나 변환기에 끌어다 놓으세요. Markdown 텍스트를 미리 보고 복사하거나 원본 파일 이름을 사용하는 UTF-8 인코딩의 .md 파일로 다운로드할 수 있습니다. 파일을 바꾸거나 닫으면 완료되지 않은 작업이 취소되고 이전 결과가 지워집니다. PPTX 뷰어에서도 Markdown 내보내기 기능을 제공합니다.

## 슬라이드와 노트를 함께 유지하기

슬라이드는 파일 순서를 유지합니다. 각 슬라이드에는 번호가 붙은 제목이 있으며, 슬라이드 제목이 있으면 함께 표시됩니다. 숨겨진 슬라이드도 포함되고 숨김 표시가 붙습니다. 문단, 기본 강조 서식, 중첩 목록, 표, 지원되는 링크는 유용한 구조를 유지합니다. 발표자 노트가 있으면 해당 슬라이드 뒤에 표시됩니다. 문자로 쓰인 Markdown 기호와 HTML은 텍스트로 유지되도록 이스케이프 처리됩니다.

내보내기는 저장된 내용 순서를 따르므로 배치된 개체의 의도된 읽기 순서와 다를 수 있습니다. 글꼴, 페이지 레이아웃, 애니메이션, 전환 효과는 재현하지 않습니다. 이미지, 차트, 수식, 미디어, 삽입된 개체는 생략 표시로 대체되며, 도형 안에 있는 텍스트는 유지됩니다. 서식 파일의 장식 요소와 검토 메모는 내보내지 않습니다. 병합된 셀과 복잡한 서식은 단순화됩니다. 머리글 행이 없는 표에는 빈 Markdown 머리글이 추가됩니다. Markdown 애플리케이션마다 인라인 HTML과 줄 바꿈 지원이 다르므로 결과를 원본 프레젠테이션과 비교하세요.

## 로컬 처리 및 호환성

파일은 이 브라우저 안에만 머무르며 도구가 업로드하거나 저장하지 않습니다. 매크로, 스크립트, 미디어, 외부 리소스는 실행하거나 불러오지 않습니다. 필드는 갱신된 값 대신 저장된 텍스트를 사용합니다. 암호화된 프레젠테이션, 이전 형식인 .ppt 파일, 추출할 수 있는 텍스트가 없는 프레젠테이션은 지원하지 않습니다. 파일 크기나 슬라이드 수에 고정된 제한은 없지만 복잡한 프레젠테이션은 브라우저의 리소스를 초과할 수 있습니다. 이 도구는 텍스트를 내보내며, 프레젠테이션을 편집하거나 이미지에서 텍스트를 인식하지 않습니다.
