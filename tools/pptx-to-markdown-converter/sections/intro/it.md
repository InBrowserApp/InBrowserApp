## Converti una presentazione in Markdown

Apri un file .pptx, .pptm, .potx, .potm, .ppsx o .ppsm locale o trascinalo nel convertitore. Visualizza il testo Markdown in anteprima, copialo o scarica un file .md in UTF-8 con il nome dell’originale. Sostituire o chiudere il file annulla le operazioni non ancora completate e cancella il risultato precedente. Anche il Visualizzatore PPTX offre l’azione «Esporta Markdown».

## Mantieni insieme diapositive e note

Le diapositive mantengono l’ordine del file. Ogni diapositiva ha un’intestazione numerata con il titolo, se disponibile; le diapositive nascoste vengono incluse e contrassegnate. Paragrafi, enfasi di base, elenchi annidati, tabelle e collegamenti supportati conservano una struttura utile. Le note del relatore disponibili seguono la rispettiva diapositiva. I segni di punteggiatura Markdown e l’HTML presenti nel testo vengono sottoposti a escape affinché rimangano testo.

L’esportazione segue l’ordine dei contenuti salvato, che può differire dall’ordine di lettura previsto per gli oggetti posizionati. Non riproduce caratteri, layout delle pagine, animazioni o transizioni. Immagini, grafici, equazioni, contenuti multimediali e oggetti incorporati vengono sostituiti da indicatori di omissione; il testo disponibile nelle forme viene conservato. Le decorazioni dei modelli e i commenti di revisione non vengono esportati. Le celle unite e la formattazione complessa vengono semplificate. Una tabella senza riga di intestazione riceve un’intestazione Markdown vuota. Il supporto per HTML inline e interruzioni di riga varia tra le applicazioni Markdown, quindi confronta il risultato con la presentazione originale.

## Elaborazione locale e compatibilità

Il file resta in questo browser e non viene caricato su server né salvato dallo strumento. Macro, script, contenuti multimediali e risorse esterne non vengono eseguiti o caricati. I campi usano il testo salvato anziché valori aggiornati. Le presentazioni crittografate, i vecchi file .ppt e le presentazioni senza testo estraibile non sono supportati. Non ci sono limiti fissi per la dimensione del file o il numero di diapositive, ma una presentazione complessa può superare le risorse del browser. Questo strumento esporta testo; non modifica la presentazione e non trascrive testo dalle immagini.
