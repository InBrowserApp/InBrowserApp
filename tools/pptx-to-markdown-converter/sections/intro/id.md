## Konversi presentasi ke Markdown

Buka file .pptx, .pptm, .potx, .potm, .ppsx, atau .ppsm lokal atau letakkan di konverter. Pratinjau teks Markdown, salin, atau unduh file .md berformat UTF-8 dengan nama file asli. Mengganti atau menutup file akan membatalkan proses yang belum selesai dan menghapus hasil sebelumnya. Penampil PPTX juga menyediakan tindakan Ekspor Markdown.

## Simpan slide dan catatan bersama

Slide tetap mengikuti urutan dalam file. Setiap slide memiliki judul bagian bernomor yang menyertakan judul slide jika tersedia; slide tersembunyi disertakan dan ditandai. Paragraf, penekanan dasar, daftar bersarang, tabel, dan tautan yang didukung mempertahankan struktur yang berguna. Catatan pembicara yang tersedia mengikuti slide masing-masing. Tanda baca Markdown literal dan HTML diberi karakter escape agar tetap menjadi teks.

Ekspor mengikuti urutan konten yang tersimpan, yang mungkin berbeda dari urutan baca yang dimaksudkan untuk objek yang ditempatkan pada posisi tertentu. Ekspor tidak mereproduksi font, tata letak halaman, animasi, atau transisi. Gambar, bagan, persamaan, media, dan objek yang disematkan diganti dengan penanda bahwa konten tidak disertakan; teks yang tersedia di dalam bentuk tetap dipertahankan. Dekorasi templat dan komentar peninjauan tidak diekspor. Sel gabungan dan pemformatan kompleks disederhanakan. Tabel tanpa baris header diberi header Markdown kosong. Dukungan aplikasi Markdown untuk HTML sebaris dan pergantian baris berbeda-beda, jadi bandingkan hasilnya dengan presentasi asli.

## Pemrosesan lokal dan kompatibilitas

File Anda tetap berada di browser ini dan tidak diunggah atau disimpan oleh alat ini. Makro, skrip, media, dan sumber daya eksternal tidak dijalankan atau dimuat. Bidang menggunakan teks yang tersimpan, bukan nilai yang diperbarui. Presentasi terenkripsi, file .ppt lama, dan presentasi tanpa teks yang dapat diekstrak tidak didukung. Tidak ada batas tetap untuk ukuran file atau jumlah slide, tetapi presentasi yang kompleks dapat melebihi sumber daya browser. Alat ini mengekspor teks; tidak mengedit presentasi atau mentranskripsikan teks dari gambar.
