## Convert a presentation to Markdown

Open a local .pptx, .pptm, .potx, .potm, .ppsx, or .ppsm file or drop it into the converter. Preview the Markdown text, copy it, or download a UTF-8 .md file named after the original. Replacing or closing the file cancels unfinished work and clears the previous output. The PPTX Viewer also provides an Export Markdown action.

## Keep slides and notes together

Slides remain in file order. Each slide has a numbered heading with its available title; hidden slides are included and marked. Paragraphs, basic emphasis, nested lists, tables, and supported links retain useful structure. Available speaker notes follow their own slide. Literal Markdown punctuation and HTML are escaped so they remain text.

The export follows the saved content order, which may differ from the intended reading order of positioned objects. It does not reproduce fonts, page layout, animations, or transitions. Pictures, charts, equations, media, and embedded objects have omission markers; available shape text is kept. Template decorations and review comments are not exported. Merged cells and complex formatting are simplified. A table without a header row receives an empty Markdown header. Markdown applications vary in their support for inline HTML and line breaks, so compare the output with the original presentation.

## Local processing and compatibility

Your file stays in this browser and is not uploaded or saved by the tool. Macros, scripts, media, and external resources are not run or loaded. Fields use their saved text rather than refreshed values. Encrypted presentations, legacy .ppt files, and presentations without extractable text are not supported. There are no fixed file-size or slide-count quotas, but a complex presentation may exceed the browser's resources. This tool exports text; it does not edit the presentation or transcribe text from images.
