## แปลงงานนำเสนอเป็น Markdown

เปิดไฟล์ .pptx, .pptm, .potx, .potm, .ppsx หรือ .ppsm จากเครื่องหรือวางไฟล์ลงในโปรแกรมแปลง ดูตัวอย่างข้อความ Markdown คัดลอก หรือดาวน์โหลดไฟล์ .md ที่เข้ารหัสแบบ UTF-8 โดยใช้ชื่อไฟล์เดิม การเปลี่ยนหรือปิดไฟล์จะยกเลิกงานที่ยังไม่เสร็จและล้างผลลัพธ์ก่อนหน้า โปรแกรมดู PPTX ก็มีตัวเลือกส่งออก Markdown เช่นกัน

## เก็บสไลด์และบันทึกย่อไว้ด้วยกัน

สไลด์ยังคงเรียงตามลำดับในไฟล์ แต่ละสไลด์จะมีหัวข้อพร้อมหมายเลขและชื่อสไลด์หากมี โดยรวมสไลด์ที่ซ่อนไว้และทำเครื่องหมายกำกับ ย่อหน้า การเน้นข้อความพื้นฐาน รายการซ้อนกัน ตาราง และลิงก์ที่รองรับจะคงโครงสร้างที่เป็นประโยชน์ไว้ บันทึกย่อของผู้บรรยายที่มีอยู่จะอยู่ต่อจากสไลด์ของตนเอง เครื่องหมายวรรคตอนของ Markdown และ HTML ที่อยู่ในข้อความจะถูกใส่อักขระหลีกเพื่อให้ยังคงเป็นข้อความ

การส่งออกจะเรียงตามลำดับเนื้อหาที่บันทึกไว้ ซึ่งอาจต่างจากลำดับการอ่านที่ตั้งใจไว้ตามตำแหน่งของวัตถุ โดยไม่สร้างแบบอักษร เค้าโครงหน้า ภาพเคลื่อนไหว หรือเอฟเฟกต์เปลี่ยนสไลด์ขึ้นใหม่ รูปภาพ แผนภูมิ สมการ สื่อ และวัตถุที่ฝังไว้จะมีเครื่องหมายระบุว่าเนื้อหาถูกละไว้ โดยเก็บข้อความในรูปร่างที่ดึงออกมาได้ ไม่ส่งออกองค์ประกอบตกแต่งของแม่แบบและความคิดเห็นจากการตรวจทาน เซลล์ผสานและการจัดรูปแบบที่ซับซ้อนจะถูกลดความซับซ้อน ตารางที่ไม่มีแถวส่วนหัวจะได้รับส่วนหัว Markdown ที่ว่างเปล่า แอปพลิเคชัน Markdown รองรับ HTML แบบอินไลน์และการขึ้นบรรทัดใหม่แตกต่างกัน จึงควรเปรียบเทียบผลลัพธ์กับงานนำเสนอต้นฉบับ

## การประมวลผลในเครื่องและความเข้ากันได้

ไฟล์ของคุณจะอยู่ในเบราว์เซอร์นี้ โดยเครื่องมือจะไม่อัปโหลดหรือบันทึกไฟล์ ไม่มีการเรียกใช้หรือโหลดแมโคร สคริปต์ สื่อ และทรัพยากรจากภายนอก เขตข้อมูลใช้ข้อความที่บันทึกไว้แทนค่าที่อัปเดตใหม่ ไม่รองรับงานนำเสนอที่เข้ารหัส ไฟล์ .ppt รุ่นเก่า และงานนำเสนอที่ไม่มีข้อความให้ดึงออกมาได้ ไม่มีขีดจำกัดตายตัวสำหรับขนาดไฟล์หรือจำนวนสไลด์ แต่งานนำเสนอที่ซับซ้อนอาจใช้ทรัพยากรเกินกว่าที่เบราว์เซอร์มีให้ เครื่องมือนี้ส่งออกข้อความ โดยไม่แก้ไขงานนำเสนอหรือถอดข้อความจากรูปภาพ
