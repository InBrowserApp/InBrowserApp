## 將簡報轉換為 Markdown

開啟本機 .pptx、.pptm、.potx、.potm、.ppsx 或 .ppsm 檔案，或將檔案拖放到轉換器中。預覽 Markdown 文字、複製內容，或下載以原始檔名命名的 UTF-8 .md 檔案。更換或關閉檔案會取消尚未完成的處理，並清除先前的輸出。PPTX 檢視器也提供「匯出 Markdown」功能。

## 將投影片與備忘稿放在一起

投影片會維持檔案中的順序。每張投影片都有包含編號及可用標題的標題行；隱藏投影片也會納入並標示。段落、基本強調格式、巢狀清單、表格與支援的連結會保留實用的結構。可取得的演講者備忘稿會接在各自對應的投影片之後。文字中的 Markdown 標點符號與 HTML 會進行跳脫處理，以保留為純文字。

匯出會遵循儲存的內容順序，這可能與物件版面配置所預期的閱讀順序不同。不會重現字型、頁面版面配置、動畫或轉場效果。圖片、圖表、方程式、媒體與內嵌物件會以省略標記代替；圖形內可取得的文字會保留。不會匯出範本裝飾元素與審閱註解。合併儲存格與複雜格式會簡化。沒有標題列的表格會加入空白的 Markdown 標題列。Markdown 應用程式對行內 HTML 與換行的支援程度各異，因此請將輸出與原始簡報核對。

## 本機處理與相容性

您的檔案會留在此瀏覽器中，本工具不會上傳或儲存檔案。不會執行或載入巨集、指令碼、媒體與外部資源。欄位使用已儲存的文字，而非重新整理後的值。不支援加密簡報、舊版 .ppt 檔案，以及沒有可擷取文字的簡報。檔案大小與投影片數量沒有固定上限，但複雜簡報仍可能超過瀏覽器可用的資源。本工具會匯出文字，不會編輯簡報，也不會辨識圖片中的文字。
