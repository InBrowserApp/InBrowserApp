## Ouvrir un fichier 3MF en ligne

Cliquez sur **Ouvrir des fichiers** ou déposez un fichier `.3mf` dans la visionneuse. Le format 3MF (3D Manufacturing Format) regroupe dans un même fichier une ou plusieurs pièces imprimables ainsi que les positions et les matériaux qu’il définit. La visionneuse lit le fichier sur votre appareil. Cliquez sur **Essayer un exemple** pour ouvrir deux supports de fixation colorés.

## Examiner les pièces, leur placement et leurs dimensions

Glissez pour faire pivoter le modèle et zoomez à la molette ou en pinçant. Cliquez sur **Cadrer le modèle** pour voir toutes les pièces ensemble. Activez le mode **Filaire** pour examiner les triangles de la surface. Les dimensions hors tout couvrent l’ensemble des pièces à leur emplacement d’impression. La visionneuse convertit les unités du fichier en millimètres. Une pièce de 1 pouce s’affiche ainsi avec une dimension de 25,4 mm.

## Vérifier le contenu du fichier 3MF

L’aperçu montre la géométrie et les couleurs du modèle prises en charge. Retrouvez les paramètres d’impression, les supports et les trajectoires d’impression dans le logiciel de tranchage qui a créé le projet. Ce logiciel permet de vérifier comment les pièces seront imprimées. Les [spécifications 3MF](https://3mf.io/spec/) décrivent la structure du fichier et les extensions du format.

## Ouvrir d’autres modèles 3D

Utilisez la [Visionneuse STL](../stl-viewer/) pour ouvrir un maillage triangulaire exporté pour l’impression. Pour un modèle GLB ou glTF avec des textures ou des animations, utilisez la [Visionneuse GLB / glTF](../gltf-viewer/).
