## Open a 3MF file online

Choose **Open files** or drop a `.3mf` file onto the viewer. The 3D Manufacturing Format packages one or more printable parts in a single file, along with the positions and materials it defines. The viewer reads the package locally. Choose **Try an example** to open a pair of colored mounting brackets.

## Inspect parts, placement and size

Drag to rotate and scroll or pinch to zoom. Use **Fit to view** to see all parts together. Choose **Wireframe** to inspect the surface triangles. The overall dimensions cover all parts in their build positions. The viewer converts the units stored in the package to millimeters, so a part that spans 1 inch appears as 25.4 mm.

## Check what the package includes

The preview shows the model geometry and supported model colors. Slicer-specific print settings, supports and toolpaths belong in the slicer that created the project. Use that slicer to check how the parts will actually be printed. The [3MF specifications](https://3mf.io/spec/) describe the package structure and format extensions.

## View other 3D models

Use the [STL Viewer](../stl-viewer/) to open a triangular mesh exported for printing. For a GLB or glTF model with textures or animation, use the [GLB / glTF Viewer](../gltf-viewer/).

Use the [3MF to STL Converter](../3mf-to-stl-converter/) to download the placed mesh geometry as a binary STL.
