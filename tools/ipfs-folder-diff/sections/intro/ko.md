## 두 IPFS 디렉터리의 CID 비교하기

기존 폴더 주소를 **변경 전 폴더**에, 업데이트된 폴더 주소를 **변경 후 폴더**에 붙여넣고 **폴더 비교**를 누르세요. 두 입력란 모두 CID, `ipfs://` 주소, HTTP 게이트웨이 링크를 지원합니다. 하위 폴더를 비교하려면 주소에 경로를 포함하세요. 결과 항목을 열어 CID를 확인하거나, 목록을 경로로 필터링하거나, JSON으로 다운로드해 비교 결과를 저장할 수 있습니다.

## 추가, 삭제, 변경된 경로는 어떻게 구분하나요?

변경 후 폴더에만 있으면 추가된 경로로, 변경 전 폴더에만 있으면 삭제된 경로로 표시됩니다. 하위 폴더 전체가 추가되거나 삭제되면 해당 폴더의 경로 하나만 표시됩니다. 두 버전에 같은 하위 폴더가 있지만 CID가 다르면 그 안의 경로를 비교합니다. 항목의 CID가 다르면 변경된 것으로 표시됩니다. 파일의 내용이 같아 보이더라도 가져올 때 사용한 청크 분할 또는 인코딩 설정이 다르면 CID가 달라질 수 있습니다.

## 모든 파일을 다운로드하지 않고 IPFS 스냅샷 비교하기

브라우저는 공개 게이트웨이에서 IPFS 블록을 가져와 검증하고, 이미 CID가 일치하는 가지는 건너뜁니다. 이렇게 하면 변하지 않는 폴더 주소를 사용해 웹사이트, 공개된 데이터 세트 또는 백업의 여러 버전을 비교할 수 있습니다. 링크의 변경 사항은 전체 파일을 다운로드하지 않고 참조를 대조해 확인할 수 있습니다. 폴더의 항목을 가져올 수 없으면 결과에 비교하지 못한 경로가 표시됩니다.

자세한 내용은 [콘텐츠 주소 지정 및 데이터 세트 버전](https://docs.ipfs.tech/how-to/content-addressing-data-sets/) 문서를 참고하세요.
