## 比較兩個 IPFS 目錄的 CID

將原始資料夾的位址貼到 **舊版資料夾**，將更新後的位址貼到 **新版資料夾**，再按下 **比較資料夾**。兩個欄位都支援 CID、`ipfs://` 位址或 HTTP 閘道連結。若要比較兩個子資料夾，請在位址中加入路徑。展開結果項目可查看對應的 CID，也可以依路徑篩選清單，或下載 JSON 儲存比較結果。

## 如何判斷路徑是新增、移除還是變更？

僅出現在新版資料夾中的路徑會標為新增，僅出現在舊版中的路徑會標為移除。整個子資料夾新增或移除時，只顯示該子資料夾的路徑。若兩個版本都有同一個子資料夾但 CID 不同，工具會繼續比較其中的路徑。項目的 CID 不同時會標為變更。即使資料看起來一樣，匯入檔案時採用不同的區塊切割或編碼設定，也可能產生不同的 CID。

## 比較 IPFS 快照，無須逐一下載檔案

瀏覽器透過公開閘道取得 IPFS 區塊、驗證其內容，並略過 CID 已相符的分支。這樣就能以不可變的資料夾位址，比較網站、已發布資料集或備份的不同版本。只要比較參照即可檢查連結變更，無須下載完整檔案。若有資料夾項目無法取得，結果會列出未能比較的路徑。
