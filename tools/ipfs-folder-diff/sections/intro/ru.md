## Как сравнить две папки IPFS по CID

Вставьте адрес исходной папки в поле **Исходная папка**, а адрес новой версии — в поле **Обновлённая папка**. Затем нажмите **Сравнить папки**. В каждом поле можно указать CID, адрес `ipfs://` или HTTP-ссылку на шлюз. Чтобы сравнить две подпапки, укажите пути к ним. Откройте результат, чтобы посмотреть его CID, отфильтруйте список по пути или скачайте JSON, чтобы сохранить сравнение.

## Какие пути считаются добавленными, удалёнными или изменёнными?

Если путь есть только в одной папке, он считается добавленным или удалённым. Целиком добавленная или удалённая подпапка отображается как один путь. Если подпапка есть в обеих версиях, но её CID различаются, инструмент сравнивает пути внутри неё. В списке изменённых отображаются файлы и символические ссылки с изменившимся CID, а также пути, по которым изменился тип элемента. При разных настройках разбиения на блоки или кодирования файлы могут получить разные CID, даже если их видимое содержимое совпадает.

## Сравнение версий IPFS без скачивания всех файлов

Браузер получает блоки IPFS через общедоступные шлюзы, проверяет их по CID и пропускает ветви с совпадающими CID. Так можно сравнивать версии сайта, опубликованного набора данных или резервной копии по неизменяемым адресам папок. Изменившиеся ссылки можно сравнить без скачивания файлов целиком. Если элемент папки недоступен, результат покажет пути, которые сравнить не удалось.

Подробнее об [адресации по содержимому и версиях наборов данных](https://docs.ipfs.tech/how-to/content-addressing-data-sets/).
