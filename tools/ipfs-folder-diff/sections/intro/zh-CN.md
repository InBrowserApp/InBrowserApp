## 对比两个 IPFS 目录的 CID

将原文件夹的地址粘贴到 **旧版文件夹**，将更新后的地址粘贴到 **新版文件夹**，然后点击 **对比文件夹**。两个输入框都支持 CID、`ipfs://` 地址和 HTTP 网关链接。要对比两个子文件夹，请在地址中加上路径。展开结果项可查看对应的 CID，也可以按路径筛选列表，或下载 JSON 保存对比结果。

## 怎样判定路径新增、删除或变更？

仅在新版文件夹中出现的路径标为新增，仅在旧版中出现的路径标为删除。整个子文件夹新增或删除时，只显示该子文件夹的路径。如果两个版本都有同一个子文件夹，但 CID 不同，工具会继续对比其中的路径。变更列表包括 CID 不同的文件或符号链接，以及条目类型发生变化的路径。即使可见内容相同，文件在导入时使用不同的分块或编码设置也可能得到不同的 CID。

## 无需逐个下载文件即可对比 IPFS 快照

浏览器从公共网关获取 IPFS 数据块、校验其内容，并跳过 CID 已经一致的分支。这样，你可以用不可变的文件夹地址对比网站、已发布的数据集或备份的不同版本。检查链接变化只需要比较引用，无需下载完整文件。如果文件夹中的某个条目无法获取，结果会列出无法对比的路径。
