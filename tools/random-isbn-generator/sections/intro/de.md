## Zufällige ISBN-10 oder ISBN-13 generieren

Wählen Sie `ISBN-13` für aktuelle Formulare zur Buchkatalogisierung und zum Buchverkauf oder `ISBN-10` für ältere Datensätze. Legen Sie eine Anzahl von `1` bis `1000` fest, wählen Sie, ob Bindestriche eingefügt werden sollen, und wählen Sie **Generieren**. Kopieren Sie die Liste oder laden Sie eine TXT-Datei mit einer ISBN pro Zeile herunter.

## Format und Prüfziffer verstehen

Eine Internationale Standardbuchnummer (ISBN) kennzeichnet die Ausgabe und das Format eines Buches. Die generierten `ISBN-13` verwenden das Präfix `978` und enden mit einer numerischen Prüfziffer. Eine `ISBN-10` kann auf `X` enden, das bei der Berechnung der Prüfsumme für zehn steht. Zwei Beispiele sind `978-0-306-40615-7` und `0-8044-2957-X`. Bindestriche erleichtern das Lesen der Gruppen und ändern die Prüfziffer nicht.

## Ergebnisse als Testdaten verwenden

Verwenden Sie diese Beispielkennungen, um Katalogformulare, Importe und die ISBN-Validierung zu testen. Um einen Prüfsummenfehler zu testen, ersetzen Sie nur das letzte Zeichen durch eine andere Ziffer und versuchen Sie den Import erneut. Speichern Sie ISBN in einer Tabellenkalkulation oder Datenbank als Text, damit eine führende Null oder ein abschließendes `X` erhalten bleibt. Die ISBN eines veröffentlichten Buches finden Sie auf dem Umschlag der Ausgabe oder im Verlagsdatensatz.
