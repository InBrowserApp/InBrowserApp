## How to transform EPSG coordinates

Search for the source and target coordinate reference systems by code or name. Enter the coordinate pair in the units shown, then copy the result. Common choices include WGS 84 (EPSG:4326), Web Mercator (EPSG:3857) and WGS 84 / UTM zones.

## Axis order, units and accuracy

Use longitude and latitude in degrees for geographic systems, and easting and northing for projected systems. The tool provides a built-in set of common EPSG systems and applies the transformations in your browser. For local grids or survey-grade work, use the correct datum transformation and area of use.
