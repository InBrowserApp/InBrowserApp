## Leggi un manuale AsciiDoc

Apri un file locale .adoc o .asciidoc per leggere un manuale, una specifica o un articolo tecnico. Esplora i titoli dalla struttura del documento, segui i riferimenti interni, regola lo zoom e la larghezza di lettura oppure attiva la modalità senza distrazioni. Il testo resta selezionabile. Le tabelle e i blocchi di codice larghi scorrono all’interno del documento.

## Documenti autonomi e contenuti mancanti

Il visualizzatore supporta titoli, sezioni annidate, formattazione comune, elenchi, tabelle, codice, richiami e riquadri di avvertenza. Sono supportati i documenti UTF-8 e UTF-16 con indicatore dell’ordine dei byte. Le immagini raster incorporate possono essere visualizzate; i file immagine separati e le risorse remote non vengono caricati.

I file inclusi, gli attributi del progetto di documentazione, le estensioni personalizzate, i diagrammi e le estensioni per l’evidenziazione della sintassi non vengono caricati. I contenuti inclusi devono essere già inseriti nel file selezionato. Le note di lettura segnalano i file inclusi e le risorse mancanti rilevati, oltre agli avvisi di analisi. Le macro sconosciute o il sorgente dei diagrammi potrebbero restare come testo. Chiedi all’autore un documento autonomo quando l’anteprima è incompleta.

## Visualizzazione locale in sola lettura

I file restano sul tuo dispositivo. L’apertura di un documento non recupera risorse remote, non legge altri file locali e non esegue script. I collegamenti esterni si aprono separatamente solo quando vengono selezionati. Chiudi o sostituisci il file per liberare l’anteprima corrente. Questo visualizzatore non modifica, non esporta e non genera siti di documentazione. L’estensione .asc non è accettata perché viene usata anche per tipi di file non correlati.
