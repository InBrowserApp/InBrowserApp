## Lee un manual AsciiDoc

Abre un archivo local .adoc o .asciidoc para leer un manual, una especificación o un artículo técnico. Navega por los encabezados desde el esquema, sigue referencias internas, ajusta el zoom y el ancho de lectura o activa el modo sin distracciones. El texto se puede seleccionar. Las tablas anchas y los bloques de código se desplazan dentro del documento.

## Documentos autocontenidos y contenido ausente

El visor admite títulos, secciones anidadas, formato habitual, listas, tablas, código, llamadas explicativas y avisos. Se admiten documentos UTF-8 y UTF-16 con marca de orden de bytes. Se pueden mostrar imágenes de mapa de bits incrustadas; no se cargan archivos de imagen separados ni recursos remotos.

No se cargan archivos incluidos, atributos de proyectos de documentación, extensiones personalizadas, diagramas ni extensiones de resaltado de sintaxis. El contenido incluido debe estar ya incorporado en el archivo seleccionado. Las notas de lectura señalan los archivos incluidos y recursos ausentes detectados, así como las advertencias del analizador. Las macros desconocidas o el código de los diagramas pueden mostrarse como texto. Pide al autor un documento autocontenido si la vista previa está incompleta.

## Visualización local de solo lectura

Los archivos permanecen en tu dispositivo. Abrir un documento no descarga recursos remotos, lee otros archivos locales ni ejecuta scripts. Los enlaces externos se abren por separado solo al seleccionarlos. Cierra o reemplaza el archivo para liberar la vista previa actual. Este visor no edita, exporta ni genera sitios de documentación. No se admite la extensión .asc porque también se usa para otros tipos de archivo.
