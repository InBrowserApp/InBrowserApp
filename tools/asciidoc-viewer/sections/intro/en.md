## Read an AsciiDoc manual

Open a local .adoc or .asciidoc file to read a manual, specification, or technical article. Navigate headings from the outline, follow internal references, adjust zoom and reading width, or enter focused reading. Text stays selectable. Wide tables and code blocks scroll within the document.

## Self-contained documents and missing content

The viewer supports titles, nested sections, ordinary formatting, lists, tables, code, callouts, and admonitions. UTF-8 and byte-marked UTF-16 documents are supported. Embedded raster images can be displayed; separate image files and remote resources are not loaded.

Included files, documentation-project attributes, custom extensions, diagrams, and syntax-highlighting extensions are not loaded. Included content must already be expanded into the selected file. Reading notes flag detected missing includes, resources, and parser warnings. Unknown macros or diagram source may remain as text. Ask the author for a self-contained document when the preview is incomplete.

## Local, read-only viewing

Files stay on your device. Opening a document does not fetch remote resources, read other local files, or run scripts. External links open separately only when selected. Close or replace the file to release the current preview. This viewer does not edit, export, or build documentation sites. The .asc extension is not accepted because it is also used for unrelated file types.
