## Baca manual AsciiDoc

Buka file .adoc atau .asciidoc lokal untuk membaca manual, spesifikasi, atau artikel teknis. Telusuri judul bagian melalui kerangka dokumen, ikuti referensi internal, sesuaikan perbesaran dan lebar baca, atau gunakan mode baca fokus. Teks tetap dapat dipilih. Tabel lebar dan blok kode dapat digulir di dalam dokumen.

## Dokumen lengkap dalam satu file dan konten yang hilang

Penampil ini mendukung judul, bagian bertingkat, pemformatan umum, daftar, tabel, kode, penanda keterangan, dan catatan peringatan. Dokumen UTF-8 dan UTF-16 dengan penanda byte didukung. Gambar raster yang tertanam dapat ditampilkan; file gambar terpisah dan sumber daya jarak jauh tidak dimuat.

File yang disertakan, atribut proyek dokumentasi, ekstensi khusus, diagram, dan ekstensi penyorotan sintaks tidak dimuat. Konten dari file yang disertakan harus sudah digabungkan ke dalam file yang dipilih. Catatan pembacaan menandai file yang disertakan atau sumber daya yang terdeteksi hilang, serta peringatan pengurai. Makro yang tidak dikenal atau sumber diagram mungkin tetap ditampilkan sebagai teks. Mintalah penulis menyediakan dokumen lengkap dalam satu file jika pratinjau tidak lengkap.

## Penayangan lokal, hanya baca

File tetap di perangkat Anda. Membuka dokumen tidak mengambil sumber daya jarak jauh, membaca file lokal lain, atau menjalankan skrip. Tautan eksternal terbuka secara terpisah hanya saat dipilih. Tutup atau ganti file untuk melepaskan pratinjau saat ini. Penampil ini tidak mengedit, mengekspor, atau membangun situs dokumentasi. Ekstensi .asc tidak diterima karena juga digunakan untuk jenis file lain yang tidak terkait.
