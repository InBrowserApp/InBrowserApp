# PDF ページ整理ツール

PDF ページ整理ツールは、ドキュメントをサーバーにアップロードせずに、PDF のページを並べ替え、回転、削除できるツールです。選択したページ順から新しい PDF を作成し、元のファイルは変更しません。

## 使う場面

スキャンした文書の順序を直したいとき、誤って入った空白ページを削除したいとき、添付資料を正しい順序に移動したいとき、横向きに取り込まれたページを回転したいときに使います。

## ページを整理する方法

1. PDF を選択するか、ファイル領域にドロップします。各ページが番号付きのプレビューとして表示されます。
2. ページのハンドルをドラッグするか、移動ボタンを使って順序を変更します。ハンドルにフォーカスして、上または下矢印キーを押すこともできます。ページを時計回りに90°ずつ回転したり、不要なページを削除したりできます。
3. **元に戻す**で直前の変更を取り消すか、**ページをリセット**で元の順序、回転、削除したページを復元します。
4. **PDF を生成**を選択し、続いて**PDF をダウンロード**を選択します。プレビューの番号は出力時の順序を示し、元のページのラベルは元の文書のページを示します。

## プライバシーと制限

ファイルはお使いの端末で処理され、サーバーにアップロードされることはありません。パスワードで保護または暗号化された PDF は、先にロックを解除してください。書き出すには、少なくとも1ページは残す必要があります。大きな文書ではプレビューの表示や保存に時間がかかることがありますが、プレビューの読み込み中もページを整理できます。プレビューを表示できない場合も、ページの操作や書き出しは可能です。ページを閉じるか再読み込みすると、このセッションのデータは消去されます。
