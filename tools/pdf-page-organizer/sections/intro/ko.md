# PDF 페이지 정리 도구

PDF 페이지 정리 도구는 문서를 서버에 업로드하지 않고도 PDF에서 페이지 순서를 바꾸고, 회전하고, 제거할 수 있게 해 줍니다. 선택한 페이지 순서로 새 PDF를 만들며 원본 파일은 변경하지 않습니다.

## 사용 시점

스캔한 문서를 바로잡거나, 실수로 들어간 빈 페이지를 제거하거나, 첨부 자료를 올바른 순서로 옮기거나, 옆으로 돌아간 페이지를 회전해야 할 때 사용하세요.

## 페이지 정리 방법

1. PDF를 선택하거나 파일 영역에 끌어다 놓으세요. 각 페이지가 번호가 매겨진 미리보기로 표시됩니다.
2. 페이지 핸들을 드래그하거나 이동 버튼으로 순서를 바꾸세요. 핸들에 포커스를 맞춘 뒤 위쪽 또는 아래쪽 화살표 키를 눌러도 됩니다. 페이지를 시계 방향으로 90°씩 회전하거나 필요 없는 페이지를 제거하세요.
3. **실행 취소**로 최근 변경을 되돌리거나 **페이지 초기화**로 원래 순서와 회전 상태를 복원하고 제거한 페이지를 되살리세요.
4. **PDF 생성**을 선택한 뒤 **PDF 다운로드**를 선택하세요. 미리보기의 번호는 출력 순서를 나타내며, 원본 페이지 레이블은 원본 문서의 페이지를 가리킵니다.

## 개인정보 보호 및 제한 사항

파일은 기기에서 처리되며 서버에 업로드되지 않습니다. 비밀번호로 보호되었거나 암호화된 PDF는 먼저 잠금을 해제해야 합니다. 내보내려면 페이지를 하나 이상 남겨 두세요. 큰 문서는 미리보기를 불러오거나 저장하는 데 시간이 더 걸릴 수 있으며, 미리보기를 불러오는 동안에도 페이지를 정리할 수 있습니다. 미리보기를 사용할 수 없어도 페이지 조작 기능과 내보내기는 계속 사용할 수 있습니다. 페이지를 닫거나 새로고침하면 이 세션이 지워집니다.
