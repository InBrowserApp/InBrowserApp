El Organizador de páginas PDF te permite reordenar, girar y eliminar páginas de un PDF sin subir el documento a un servidor. Crea un nuevo PDF a partir del orden de páginas que elijas y deja intacto el archivo original.

## Cuándo usarlo

Úsalo cuando necesites corregir documentos escaneados, eliminar páginas en blanco accidentales, mover anexos al orden correcto o girar páginas capturadas de lado.

## Cómo organizar páginas

1. Elige un PDF o suéltalo en el área de archivos. Cada página aparece como una vista previa numerada.
2. Arrastra una página por su control para cambiar el orden o usa los botones de mover. También puedes situar el foco en un control y pulsar la flecha hacia arriba o hacia abajo. Gira las páginas en sentido horario en pasos de 90° o elimina las páginas que no necesites.
3. Usa **Deshacer** para revertir un cambio reciente o **Restablecer páginas** para restaurar el orden y las rotaciones originales y recuperar las páginas eliminadas.
4. Selecciona **Generar PDF** y luego **Descargar PDF**. Los números de las vistas previas muestran el orden de salida; las etiquetas de página de origen se refieren al documento original.

## Privacidad y límites

Tu archivo se procesa en tu dispositivo y nunca se sube a un servidor. Primero debes desbloquear los PDF protegidos con contraseña o cifrados. Conserva al menos una página para exportar. Los documentos grandes pueden tardar más en mostrar las vistas previas o guardarse; puedes seguir organizando las páginas mientras se cargan las vistas previas. Si una vista previa no está disponible, los controles de página y la exportación siguen disponibles. Al cerrar o recargar la página se borra esta sesión.
