## 在本地转换保存的网页存档

打开本地 `.mhtml` 或 `.mht` 存档，查看转换后的主页面，并下载独立的 UTF-8 HTML 文件。内含资源保存在文件中，因此可离线打开。如需阅读恢复的内容或不完整的存档，请使用 [MHTML 查看器](../mhtml-viewer/)。

## 输出与兼容性

受支持的 content-location 和 content-ID 引用会在存档内部解析。文本、基本格式、表格、链接、内含的位图图片和受支持的样式会保留在可阅读的静态文档中。文本仍可选择。内部书签在文档内跳转，外部链接仅在你点击时打开。预览缩放不会改变下载的文件。字体和复杂布局可能与原先保存的页面不同。

脚本、表单、重定向、嵌入式应用、SVG 和 MathML 会被省略。不会恢复网站会话和交互功能。存档不完整、文本编码不受支持、包含其他页面或缺少资源时，转换会停止，不会提供不完整的文件供下载。嵌入图片（包括 CSS 背景图片）必须能够成功解码。如果转换失败，请单独保存主文档的完整存档。电子邮件和纯 HTML 文件需要使用相应的工具。

## 隐私与浏览器资源

文件仅在此浏览器中处理。缺失的资源不会从你的计算机或在线网站获取，文件内容也不会上传。生成的 HTML 在离线打开时会阻止脚本执行和外部资源加载。打开外部链接是单独的操作，可能会连接到相应网站。你可以取消转换、关闭或更换存档。不设置固定的文件大小或页数上限；大型存档的处理取决于可用的浏览器内存，检测到资源不足时会提示错误。
