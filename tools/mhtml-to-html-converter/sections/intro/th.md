## แปลงไฟล์เก็บถาวรเว็บที่บันทึกไว้บนอุปกรณ์

เปิดไฟล์เก็บถาวร `.mhtml` หรือ `.mht` บนอุปกรณ์ ตรวจดูหน้าเว็บหลักที่แปลงแล้ว และดาวน์โหลดไฟล์ HTML แบบแยกเดี่ยวที่เข้ารหัส UTF-8 ทรัพยากรที่รวมอยู่จะถูกเก็บไว้ภายในไฟล์เพื่อให้เปิดแบบออฟไลน์ได้ หากต้องการอ่านไฟล์เก็บถาวรที่กู้คืนได้หรือไม่ครบถ้วน ให้ใช้[โปรแกรมดู MHTML](../mhtml-viewer/)

## ผลลัพธ์และความเข้ากันได้

จุดอ้างอิง content-location และ content-ID ที่รองรับจะถูกเชื่อมโยงภายในไฟล์เก็บถาวร ข้อความ การจัดรูปแบบพื้นฐาน ตาราง ลิงก์ รูปภาพราสเตอร์ที่รวมอยู่ในไฟล์ และสไตล์ที่รองรับจะถูกเก็บไว้ในเอกสารแบบคงที่ที่อ่านได้ ข้อความยังคงเลือกได้ บุ๊กมาร์กภายในยังอยู่ในเอกสาร และลิงก์ภายนอกจะเปิดเมื่อเลือกเท่านั้น การซูมตัวอย่างไม่เปลี่ยนแปลงไฟล์ที่ดาวน์โหลด แบบอักษรและเค้าโครงที่ซับซ้อนอาจต่างจากหน้าเว็บต้นฉบับที่บันทึกไว้

สคริปต์ แบบฟอร์ม การเปลี่ยนเส้นทาง แอปที่ฝังไว้ SVG และ MathML จะถูกละไว้ เซสชันเว็บไซต์และคุณสมบัติแบบโต้ตอบจะไม่ถูกกู้คืน ไฟล์เก็บถาวรที่ไม่ครบถ้วน การเข้ารหัสข้อความที่ไม่รองรับ หน้าเว็บเพิ่มเติม และทรัพยากรที่ขาดหายจะทำให้การแปลงหยุดลงโดยไม่มีไฟล์ที่ไม่ครบถ้วนให้ดาวน์โหลด รูปภาพที่ฝังไว้ รวมถึงภาพพื้นหลัง CSS ต้องถอดรหัสได้สำเร็จ หากแปลงไม่สำเร็จ ให้บันทึกสำเนาเฉพาะเอกสารหลักให้ครบถ้วนเป็นไฟล์แยก ข้อความอีเมลและไฟล์ HTML ธรรมดาต้องใช้เครื่องมือที่ตรงกับประเภทไฟล์

## ความเป็นส่วนตัวและทรัพยากรของเบราว์เซอร์

ไฟล์จะอยู่ในเบราว์เซอร์นี้ ทรัพยากรที่ขาดหายจะไม่ถูกดึงจากคอมพิวเตอร์ของคุณหรือเว็บไซต์ออนไลน์ และเนื้อหาไฟล์จะไม่ถูกอัปโหลด HTML ที่สร้างขึ้นจะปิดกั้นสคริปต์และการโหลดทรัพยากรภายนอกเมื่อเปิดแบบออฟไลน์ การเปิดลิงก์ภายนอกเป็นการกระทำแยกต่างหากที่อาจติดต่อเว็บไซต์นั้น คุณสามารถยกเลิก ปิด หรือเปลี่ยนไฟล์เก็บถาวรได้ ไม่มีการจำกัดขนาดไฟล์หรือจำนวนหน้าตายตัว ไฟล์เก็บถาวรขนาดใหญ่ขึ้นอยู่กับหน่วยความจำที่เบราว์เซอร์มี และระบบจะแจ้งความล้มเหลวด้านทรัพยากรเมื่อตรวจพบได้
