## Konversikan arsip web yang disimpan secara lokal

Buka arsip `.mhtml` atau `.mht` lokal, periksa halaman utama hasil konversi, lalu unduh file HTML UTF-8 mandiri. Sumber daya yang disertakan disimpan di dalam file agar dapat dibuka secara offline. Untuk membaca arsip yang dipulihkan atau tidak lengkap, gunakan [Penampil MHTML](../mhtml-viewer/).

## Hasil dan kompatibilitas

Referensi content-location dan content-ID yang didukung diselesaikan di dalam arsip. Teks, pemformatan dasar, tabel, tautan, gambar raster yang disertakan, dan gaya yang didukung dipertahankan dalam dokumen statis yang mudah dibaca. Teks tetap dapat dipilih. Penanda internal tetap berada di dalam dokumen, dan tautan eksternal hanya terbuka saat dipilih. Perbesaran pratinjau tidak mengubah file yang diunduh. Font dan tata letak yang kompleks mungkin berbeda dari halaman asli yang disimpan.

Skrip, formulir, pengalihan, aplikasi tersemat, SVG, dan MathML dihilangkan. Sesi situs web dan fitur interaktif tidak dipulihkan. Arsip yang tidak lengkap, pengodean teks yang tidak didukung, halaman tambahan, dan sumber daya yang hilang menghentikan konversi tanpa unduhan parsial. Gambar tersemat, termasuk gambar latar CSS, harus berhasil didekodekan. Simpan hasil penyimpanan lengkap dokumen utama secara terpisah jika konversi gagal. Pesan email dan file HTML biasa memerlukan alat yang sesuai.

## Privasi dan sumber daya browser

File tetap berada di browser ini. Aset yang hilang tidak pernah diambil dari komputer Anda atau situs web langsung, dan isi file tidak pernah diunggah. HTML yang dihasilkan memblokir skrip dan pemuatan sumber daya eksternal saat dibuka secara offline. Membuka tautan eksternal merupakan tindakan terpisah yang mungkin menghubungi situs tersebut. Anda dapat membatalkan, menutup, atau mengganti arsip. Tidak ada batas tetap untuk ukuran file atau jumlah halaman; arsip besar bergantung pada memori browser yang tersedia, dan kegagalan sumber daya dilaporkan jika dapat dideteksi.
