## 在本機轉換儲存的網頁封存檔

開啟本機的 `.mhtml` 或 `.mht` 封存檔，檢查轉換後的主要頁面，並下載獨立的 UTF-8 HTML 檔案。封存的資源會保留在檔案內，讓檔案可離線開啟。若要閱讀已復原或不完整的封存檔，請使用 [MHTML 檢視器](../mhtml-viewer/)。

## 輸出與相容性

工具會在封存檔內解析支援的 content-location 與 content-ID 參照。文字、基本格式、表格、連結、封存的點陣圖片與支援的樣式，會保留在可閱讀的靜態文件中。文字仍可選取。內部書籤會保留在文件中，外部連結則只有在點選時才會開啟。預覽縮放不會改變下載的檔案。字型與複雜版面可能與原始儲存的頁面不同。

指令碼、表單、重新導向、內嵌應用程式、SVG 與 MathML 會省略。不會還原網站工作階段與互動功能。封存檔不完整、文字編碼不受支援、包含其他頁面或缺少資源時，轉換會停止，且不會提供部分完成的檔案供下載。內嵌圖片（包括 CSS 背景圖片）必須能成功解碼。如果轉換失敗，請單獨完整儲存主要文件。電子郵件與純 HTML 檔案需使用對應的工具。

## 隱私與瀏覽器資源

檔案會留在此瀏覽器中。絕不會從您的電腦或原始網站擷取缺少的資源，也絕不會上傳檔案內容。產生的 HTML 在離線開啟時會封鎖指令碼與外部資源載入。開啟外部連結是另一項操作，可能會連線至該網站。您可以取消轉換、關閉或更換封存檔。檔案大小與頁數沒有固定上限；大型封存檔取決於瀏覽器可用的記憶體，若能偵測到資源不足，系統就會顯示錯誤。
