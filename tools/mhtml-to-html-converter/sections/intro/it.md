## Converti un archivio web salvato in locale

Apri un archivio locale `.mhtml` o `.mht`, esamina la pagina principale convertita e scarica un file HTML UTF-8 autonomo. Le risorse incluse restano all’interno del file, che può quindi aprirsi offline. Per leggere archivi recuperati o incompleti, usa il [Visualizzatore MHTML](../mhtml-viewer/).

## Risultato e compatibilità

I riferimenti content-location e content-ID supportati vengono risolti all’interno dell’archivio. Testo, formattazione di base, tabelle, link, immagini raster incluse e stili supportati vengono conservati in un documento statico leggibile. Il testo rimane selezionabile. I segnalibri interni restano nel documento e i link esterni si aprono solo quando li selezioni. Lo zoom dell’anteprima non modifica il file scaricato. I caratteri e i layout complessi possono differire dalla pagina originale salvata.

Script, moduli, reindirizzamenti, app incorporate, SVG e MathML vengono omessi. Le sessioni dei siti web e le funzioni interattive non vengono ripristinate. Archivi incompleti, codifiche del testo non supportate, pagine aggiuntive e risorse mancanti interrompono la conversione senza consentire un download parziale. Le immagini incorporate, comprese le immagini di sfondo CSS, devono essere decodificate correttamente. Se la conversione non riesce, salva un’acquisizione completa del solo documento principale. I messaggi email e i file HTML semplici richiedono i rispettivi strumenti.

## Privacy e risorse del browser

I file restano in questo browser. Le risorse mancanti non vengono mai recuperate dal tuo computer o dal sito web online e il contenuto dei file non viene mai caricato su un server. Quando viene aperto offline, l’HTML generato blocca gli script e il caricamento di risorse esterne. Seguire un link esterno è un’azione separata che può contattare quel sito. Puoi annullare la conversione, chiudere o sostituire l’archivio. Non ci sono limiti fissi per le dimensioni dei file o il numero di pagine; gli archivi di grandi dimensioni dipendono dalla memoria disponibile nel browser e gli errori dovuti alle risorse vengono segnalati quando rilevabili.
