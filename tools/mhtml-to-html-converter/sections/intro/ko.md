## 저장된 웹 아카이브를 로컬에서 변환하기

기기에 저장된 `.mhtml` 또는 `.mht` 아카이브를 열고 변환된 기본 페이지를 확인한 다음 독립적인 UTF-8 HTML 파일을 다운로드하세요. 포함된 리소스를 파일 안에 유지하므로 오프라인에서 열 수 있습니다. 복구된 아카이브나 불완전한 아카이브를 읽으려면 [MHTML 뷰어](../mhtml-viewer/)를 사용하세요.

## 출력 및 호환성

지원되는 content-location 및 content-ID 참조는 아카이브 안에서 처리됩니다. 텍스트, 기본 서식, 표, 링크, 포함된 래스터 이미지 및 지원되는 스타일을 읽기 쉬운 정적 문서에 유지합니다. 텍스트는 계속 선택할 수 있습니다. 내부 책갈피는 문서 안에서 이동하며, 외부 링크는 선택한 경우에만 열립니다. 미리보기의 확대/축소는 다운로드한 파일에 영향을 주지 않습니다. 글꼴과 복잡한 레이아웃은 원래 저장된 페이지와 다를 수 있습니다.

스크립트, 양식, 리디렉션, 삽입된 앱, SVG 및 MathML은 제외됩니다. 웹사이트 세션과 대화형 기능은 복원되지 않습니다. 불완전한 아카이브, 지원하지 않는 텍스트 인코딩, 추가 페이지 또는 누락된 리소스가 있으면 변환이 중단되며 부분적으로 생성된 파일은 다운로드할 수 없습니다. CSS 배경 이미지를 비롯한 포함된 이미지는 정상적으로 디코딩되어야 합니다. 변환에 실패하면 기본 문서만 따로 완전한 사본으로 저장하세요. 이메일 메시지와 일반 HTML 파일은 해당 도구를 사용해야 합니다.

## 개인정보 보호 및 브라우저 리소스

파일은 이 브라우저 안에만 유지됩니다. 누락된 리소스를 컴퓨터나 실제 웹사이트에서 가져오지 않으며, 파일 내용을 업로드하지 않습니다. 생성된 HTML은 오프라인에서 열 때 스크립트 실행과 외부 리소스 로딩을 차단합니다. 외부 링크를 여는 것은 별도의 동작이며 해당 사이트에 접속할 수 있습니다. 변환을 취소하거나 아카이브를 닫거나 바꿀 수 있습니다. 고정된 파일 크기 또는 페이지 수 제한은 없습니다. 큰 아카이브는 사용 가능한 브라우저 메모리에 따라 처리되며, 감지할 수 있는 리소스 오류는 안내합니다.
