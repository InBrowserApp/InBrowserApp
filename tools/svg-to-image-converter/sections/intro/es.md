## Qué hace esta herramienta

Este convertidor de SVG a imagen transforma un archivo SVG local en una imagen
PNG, JPEG o WebP directamente en su navegador. Puede conservar el tamaño
original, establecer dimensiones de salida personalizadas, controlar el relleno
de fondo y ajustar la calidad de exportación cuando el formato lo permita.

## Para qué sirve

Úselo cuando necesite convertir rápidamente un SVG en una imagen rasterizada
para entregar un diseño, trabajar con un CMS, crear una vista previa para redes
sociales o preparar un recurso de una aplicación. Resulta útil para convertir
gráficos vectoriales en mapas de bits con resultados predecibles sin abrir otro
editor gráfico.

## Cómo funciona

Suba un archivo SVG, elija el formato de salida y ajuste el ancho, el alto, el
fondo y la calidad. El convertidor renderiza el SVG en su navegador y prepara un
archivo de imagen descargable sin enviar nada a un servidor.

## Consejos para obtener mejores exportaciones

- Mantenga activada la relación de aspecto para cambiar el tamaño sin deformar
  la imagen.
- Elija un color de fondo al exportar como JPEG, ya que este formato no admite
  transparencia.
- Utilice PNG para obtener una imagen nítida sin pérdida de calidad, o WebP y
  JPEG cuando sea más importante reducir el tamaño del archivo.
