## Cosa fa questo strumento

Questo convertitore da SVG a immagine trasforma un file SVG locale in un'immagine
PNG, JPEG o WebP direttamente nel browser. Puoi mantenere le dimensioni originali,
impostare dimensioni di output personalizzate, gestire il riempimento dello
sfondo e regolare la qualità di esportazione quando il formato lo consente.

## Perché è utile

Usalo quando devi convertire rapidamente un SVG in un'immagine raster per la
consegna di un progetto grafico, un flusso di lavoro in un CMS, un'anteprima social
o una risorsa per un'app. È utile per trasformare la grafica vettoriale in un
output bitmap prevedibile senza aprire un editor grafico separato.

## Come funziona

Carica un file SVG, scegli il formato di output e regola larghezza, altezza,
sfondo e qualità. Il convertitore renderizza l'SVG nel browser e prepara un file
immagine da scaricare senza inviare nulla a un server.

## Suggerimenti per esportazioni migliori

- Mantieni attiva l'opzione per conservare le proporzioni se vuoi ridimensionare
  senza distorsioni.
- Scegli un colore di sfondo per l'output JPEG, perché JPEG non supporta la
  trasparenza.
- Usa PNG per un output nitido e senza perdita di qualità oppure WebP e JPEG
  quando è più importante ridurre la dimensione del file.
