## Separare i canali sinistro e destro di un audio stereo

Apri una registrazione stereo per estrarre i canali sinistro e destro in due file mono. Puoi farlo se hai registrato due microfoni sui due canali dello stesso file, se vuoi controllare se c’è rumore su un lato o se ti serve modificare i canali separatamente in un editor audio.

## Come separare i canali di un file stereo

1. Scegli un file audio stereo o trascinalo nello strumento. I canali vengono separati automaticamente.
2. Usa il lettore di ogni canale per ascoltare l’audio registrato su quel lato.
3. Scegli un formato di download per entrambi i canali, quindi salva il canale che ti serve oppure entrambi. Se scegli WAV, da `interview.wav` ottieni `interview-left.wav` e `interview-right.wav`.

Ogni file contiene un solo canale per l’intera durata della registrazione. I due file restano sincronizzati se li posizioni allo stesso punto di partenza in un editor audio. In riproduzione, il suono di ogni canale mono si sente al centro. L’etichetta sopra il lettore indica il canale di origine.

## Quale formato scegliere per scaricare l’audio?

- **WAV** è il formato predefinito ed è adatto alla modifica. Per le registrazioni PCM supportate mantiene la frequenza di campionamento e la precisione originali.
- **FLAC** comprime i campioni senza perdita e riduce le dimensioni del file. Scegli WAV quando l’encoder FLAC non riesce a mantenere la frequenza di campionamento o la precisione della registrazione, ad esempio con un file WAV in virgola mobile.
- **MP3** produce file più piccoli da condividere. L’esportazione in MP3 applica la compressione con perdita anche se la registrazione è già in MP3. Se la frequenza di campionamento originale non è supportata dal formato MP3, viene usata quella compatibile più vicina. Scegli WAV o FLAC per evitare una seconda compressione con perdita.

Puoi aprire file stereo in formati comuni come WAV, MP3, M4A, FLAC e OGG. La compatibilità dipende dal browser e dal codec del file. Se un file non si apre, prova a esportarlo in WAV stereo e ad aprire quella copia. Il browser legge la registrazione e prepara i file da scaricare sul tuo dispositivo.

## Che cosa puoi separare in un file stereo?

Un file stereo contiene due canali. La separazione salva ciascun canale in un file distinto. Il mixaggio in mono riunisce entrambi in un unico file. Se voci e strumenti sono già mixati sullo stesso canale, rimangono insieme nel file esportato. Una registrazione mono contiene un solo canale. Per una registrazione surround, esporta prima in stereo la coppia di canali desiderata usando un editor audio.
