## 저장된 내용과 호환성

더 최신의 마이너 버전을 포함하여 노트북 형식 4를 지원합니다. Markdown, 코드, 원시 셀, 실행 횟수, 저장된 스트림 텍스트, 오류, HTML 표, 내장된 래스터 이미지 및 정적 SVG 이미지를 표시합니다. 셀 첨부 파일은 해당 셀 안에서만 참조됩니다. 지원되지 않는 셀이나 출력 유형에는 안내가 표시되며, 사용 가능한 텍스트는 유지됩니다.

뷰어는 저장된 내용만 표시합니다. 출력이 없다고 해서 실행에 실패한 것은 아니며, 저장된 결과가 오래된 것일 수 있습니다. 대화형 위젯, JavaScript, SVG 애니메이션, 오디오 및 비디오는 실행하거나 재생하지 않습니다. 사용할 수 있는 정적 표현을 우선 표시합니다. LaTeX 수식은 소스 텍스트로 남으며, 노트북 스타일이 다를 수 있습니다. 이전 메이저 형식은 원래 애플리케이션에서 형식 4로 저장해야 합니다.
