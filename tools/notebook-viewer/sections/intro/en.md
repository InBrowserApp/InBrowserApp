## Read a notebook without running it

Open a local .ipynb notebook to read its explanations, code, and saved results in their original order. Navigate by cell or Markdown heading, adjust zoom, or enter focused reading. Code and output sections collapse independently. Text stays selectable, and wide code and tables scroll within their own area.

## Saved content and compatibility

Notebook format 4 is supported, including newer minor versions. Markdown, code, raw cells, execution counts, saved stream text, errors, HTML tables, embedded raster images, and static SVG images are displayed. Cell attachments are resolved only within their own cell. Unsupported cell or output types receive a notice and retain available text.

The viewer displays only what was saved. Missing output does not indicate a failed run, and saved results may be out of date. Interactive widgets, JavaScript, SVG animations, audio, and video are not run. An available static representation is preferred. LaTeX equations remain as source text, and notebook styles may differ. Older major formats must be saved as format 4 in the original application.

## Local, read-only viewing

Files stay on your device. Opening a notebook does not execute code, start a kernel, install packages, or fetch external resources. Remote images and missing attachments are reported. External links open separately only when selected. Close or replace the notebook to release the preview. This viewer does not edit, export, or automatically store notebook content.
