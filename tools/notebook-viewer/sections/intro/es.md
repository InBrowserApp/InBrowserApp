## Lee un cuaderno sin ejecutarlo

Abre un cuaderno .ipynb local para leer sus explicaciones, código y resultados guardados en su orden original. Navega por celda o encabezado Markdown, ajusta el zoom o activa el modo sin distracciones. Las secciones de código y salida se pueden contraer por separado. El texto se puede seleccionar, y el código y las tablas anchos se desplazan dentro de su propia área.

## Contenido guardado y compatibilidad

Se admite el formato de cuaderno 4, incluidas sus versiones menores más recientes. Se muestran celdas Markdown, de código y de texto sin procesar, contadores de ejecución, texto guardado de flujos de salida, errores, tablas HTML, imágenes de mapa de bits incrustadas e imágenes SVG estáticas. Los adjuntos de cada celda solo se resuelven dentro de esa misma celda. Los tipos de celda o salida no compatibles reciben un aviso y conservan el texto disponible.

El visor solo muestra lo que se guardó. La ausencia de salida no indica que una ejecución haya fallado, y los resultados guardados pueden estar desactualizados. No se ejecutan widgets interactivos ni JavaScript, ni se reproducen animaciones SVG, audio o vídeo. Se prefiere una representación estática cuando está disponible. Las ecuaciones LaTeX se muestran como texto fuente y los estilos del cuaderno pueden variar. Las versiones principales anteriores deben guardarse en formato 4 desde la aplicación original.

## Visualización local de solo lectura

Los archivos permanecen en tu dispositivo. Abrir un cuaderno no ejecuta código, inicia un kernel, instala paquetes ni descarga recursos externos. Se informa de las imágenes remotas y los adjuntos ausentes. Los enlaces externos se abren por separado solo al seleccionarlos. Cierra o reemplaza el cuaderno para liberar la vista previa. Este visor no edita, exporta ni almacena automáticamente el contenido del cuaderno.
