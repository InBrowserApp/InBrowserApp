## อ่านโน้ตบุ๊กโดยไม่รัน

เปิดโน้ตบุ๊ก .ipynb บนอุปกรณ์เพื่ออ่านคำอธิบาย โค้ด และผลลัพธ์ที่บันทึกไว้ตามลำดับเดิม นำทางตามเซลล์หรือหัวข้อ Markdown ปรับการซูม หรือเข้าสู่โหมดอ่านแบบมีสมาธิ ส่วนโค้ดและเอาต์พุตยุบแยกจากกันได้ ข้อความยังคงเลือกได้ และโค้ดกับตารางที่กว้างเลื่อนได้ภายในพื้นที่ของตัวเอง

## เนื้อหาที่บันทึกไว้และความเข้ากันได้

รองรับรูปแบบโน้ตบุ๊กเวอร์ชัน 4 รวมถึงเวอร์ชันย่อยที่ใหม่กว่า แสดง Markdown โค้ด เซลล์ข้อความดิบ จำนวนครั้งการรัน ข้อความสตรีมที่บันทึกไว้ ข้อผิดพลาด ตาราง HTML ภาพแรสเตอร์ที่ฝังไว้ และภาพ SVG แบบคงที่ได้ ไฟล์แนบของเซลล์จะถูกอ้างอิงได้ภายในเซลล์ของตัวเองเท่านั้น เซลล์หรือเอาต์พุตประเภทที่ไม่รองรับจะแสดงข้อความแจ้งและคงข้อความที่มีอยู่ไว้

ตัวอ่านแสดงเฉพาะสิ่งที่บันทึกไว้ การไม่มีเอาต์พุตไม่ได้หมายความว่าการรันล้มเหลว และผลลัพธ์ที่บันทึกไว้อาจล้าสมัย ไม่มีการรันวิดเจ็ตแบบโต้ตอบ JavaScript ภาพเคลื่อนไหว SVG เสียง หรือวิดีโอ โดยจะแสดงรูปแบบคงที่ที่มีอยู่เป็นหลัก สมการ LaTeX ยังคงเป็นข้อความต้นฉบับ และรูปแบบของโน้ตบุ๊กอาจต่างออกไป รูปแบบเวอร์ชันหลักที่เก่ากว่าต้องบันทึกเป็นเวอร์ชัน 4 ในแอปเดิม

## ดูบนอุปกรณ์แบบอ่านอย่างเดียว

ไฟล์อยู่บนอุปกรณ์ของคุณ การเปิดโน้ตบุ๊กจะไม่รันโค้ด เริ่มเคอร์เนล ติดตั้งแพ็กเกจ หรือดึงทรัพยากรภายนอก ระบบจะแจ้งเมื่อมีรูปภาพระยะไกลและไฟล์แนบที่ขาดหาย ลิงก์ภายนอกจะเปิดแยกต่างหากเมื่อเลือกเท่านั้น ปิดหรือเปลี่ยนโน้ตบุ๊กเพื่อคืนทรัพยากรของตัวอย่าง ตัวอ่านนี้ไม่แก้ไข ส่งออก หรือจัดเก็บเนื้อหาโน้ตบุ๊กโดยอัตโนมัติ
