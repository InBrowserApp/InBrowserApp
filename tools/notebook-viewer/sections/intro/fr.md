## Lire un notebook sans l’exécuter

Ouvrez un notebook local .ipynb pour lire ses explications, son code et ses résultats enregistrés dans leur ordre d’origine. Naviguez par cellule ou titre Markdown, réglez le zoom ou activez la lecture concentrée. Les sections de code et de sortie se replient indépendamment. Le texte reste sélectionnable, et les blocs de code et tableaux larges défilent dans leur propre zone.

## Contenu enregistré et compatibilité

Le format de notebook 4 est pris en charge, y compris ses versions mineures plus récentes. Les cellules Markdown, de code et de texte brut, les compteurs d’exécution, le texte des flux enregistrés, les erreurs, les tableaux HTML, les images matricielles intégrées et les images SVG statiques sont affichés. Les pièces jointes d’une cellule ne sont accessibles que depuis cette cellule. Les types de cellules ou de sorties non pris en charge font l’objet d’un avertissement et conservent le texte disponible.

La visionneuse affiche uniquement ce qui a été enregistré. Une sortie manquante n’indique pas un échec d’exécution, et les résultats enregistrés peuvent être obsolètes. Les widgets interactifs, JavaScript, les animations SVG, l’audio et la vidéo ne sont pas exécutés ni lus. Une représentation statique est privilégiée lorsqu’elle est disponible. Les équations LaTeX restent sous forme de texte source, et les styles du notebook peuvent différer. Les anciennes versions majeures du format doivent être enregistrées au format 4 dans l’application d’origine.

## Consultation locale en lecture seule

Les fichiers restent sur votre appareil. L’ouverture d’un notebook n’exécute aucun code, ne lance aucun noyau, n’installe aucun package et ne récupère aucune ressource externe. Les images distantes et les pièces jointes manquantes sont signalées. Les liens externes s’ouvrent séparément, uniquement lorsque vous les sélectionnez. Fermez ou remplacez le notebook pour libérer l’aperçu. Cette visionneuse ne permet pas de modifier, d’exporter ou de stocker automatiquement le contenu des notebooks.
