## How to convert WKT and GeoJSON

Choose WKT → GeoJSON or GeoJSON → WKT, then paste a geometry or open a text file. The tool accepts points, lines, polygons, multi-part geometries and geometry collections. Copy or download the result for a database query, GIS editor or web map.

## Coordinate systems and feature properties

WKT means Well-Known Text. Geometry WKT stores coordinates and shape types. Converting GeoJSON features to WKT drops their property fields. The tool keeps coordinate values and order. Use WGS 84 longitude and latitude if the output is intended to be standard GeoJSON.
