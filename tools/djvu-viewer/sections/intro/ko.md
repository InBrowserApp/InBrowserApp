## DjVu 파일을 온라인에서 여는 방법

**DjVu 열기**를 선택하거나 기기에서 `.djvu` 또는 `.djv` 파일을 끌어다 놓으세요. 뷰어가 브라우저에서 첫 페이지를 엽니다. 앱이나 브라우저 확장 프로그램을 설치할 필요가 없습니다. 한 페이지짜리 스캔 파일과 모든 페이지가 하나의 파일에 담긴 여러 페이지의 책이나 문서를 지원합니다.

## 읽기와 확대/축소 방법

페이지 번호 옆의 화살표로 페이지를 넘기세요. 특정 페이지로 이동하려면 페이지 번호를 입력하고 Enter를 누르세요. 읽기 영역에 키보드 포커스가 있으면 Page Up과 Page Down으로 페이지를 넘기고 Home과 End로 문서의 처음이나 끝으로 이동할 수 있습니다.

**페이지에 맞추기**는 스캔한 페이지 전체를 보여 줍니다. **너비에 맞추기**는 사용 가능한 공간의 너비를 활용하므로 휴대전화에서 작은 글씨를 읽을 때 유용합니다. 더 확대하여 도표나 주석을 살펴볼 수도 있습니다. **집중해서 읽기**는 문서에 더 넓은 공간을 제공합니다. Escape를 누르면 도구 페이지로 돌아갑니다.

## DjVu 파일이란?

DjVu는 책, 저널, 보관 문서 등의 고해상도 스캔을 압축하도록 설계된 문서 형식입니다. 뷰어는 스캔한 페이지를 이미지로 표시하여 원래 레이아웃을 유지합니다. 다운로드한 DjVu가 색인과 별도의 페이지 파일로 구성되어 있다면 모든 페이지가 하나의 파일에 담긴 사본을 찾아보세요. 한 페이지가 표시되지 않아도 다른 페이지를 열어 볼 수 있습니다.

## 파일은 어디에서 처리되나요?

브라우저가 기기에서 문서를 읽고 렌더링합니다. 파일을 열고 읽는 데 계정이나 업로드가 필요하지 않습니다.
