## Cara membuka file DjVu secara online

Pilih **Buka DjVu** atau seret dan lepas file `.djvu` atau `.djv` dari perangkat Anda. Halaman pertama langsung terbuka di browser, tanpa perlu memasang aplikasi atau ekstensi. Penampil mendukung pindaian satu halaman serta buku dan dokumen dengan banyak halaman dalam satu file.

## Cara membaca dan memperbesar halaman

Gunakan tombol panah di samping nomor halaman untuk berpindah halaman. Untuk melompat ke halaman tertentu, masukkan nomornya lalu tekan Enter. Saat fokus keyboard berada di area baca, gunakan Page Up dan Page Down untuk berpindah halaman, atau Home dan End untuk menuju halaman pertama dan terakhir.

**Sesuaikan halaman** menampilkan seluruh halaman pindaian. **Sesuaikan lebar** memanfaatkan lebar area baca, sehingga tulisan kecil lebih mudah dibaca di ponsel. Perbesar lagi untuk melihat detail diagram atau catatan. **Mode fokus membaca** memberi ruang lebih luas untuk dokumen. Tekan Escape untuk kembali ke halaman alat.

## Apa itu file DjVu?

DjVu adalah format dokumen yang dirancang untuk memampatkan pindaian beresolusi tinggi, seperti buku, jurnal, dan dokumen arsip. Penampil menyajikan halaman pindaian sebagai gambar dengan tata letak aslinya. Jika unduhan DjVu berisi file indeks dan file halaman yang terpisah, cari salinan yang memuat semua halaman dalam satu file. Jika satu halaman gagal ditampilkan, Anda masih bisa mencoba membuka halaman lain.

## Di mana file diproses?

Browser membaca dan menampilkan dokumen langsung di perangkat Anda. Anda dapat membuka dan membaca file tanpa akun dan tanpa mengunggahnya.
