## Baca presentasi di browser Anda

Buka file .pptx, .pptm, .potx, .potm, .ppsx, atau .ppsm lokal atau letakkan di penampil. Presentasi, peragaan slide, dan templat dibuka sebagai slide hanya baca sesuai kondisi tersimpan. Berpindah antarslide, atur zoom, pilih teks untuk disalin, dan cari dalam presentasi. Teks, bentuk, tabel, dan gambar ditampilkan jika didukung.

## Privasi dan kompatibilitas

Presentasi diproses secara lokal serta tidak diunggah atau disimpan oleh alat ini. Font berasal dari presentasi atau perangkat Anda; tidak ada font daring yang diminta. Penggantian font dan fitur yang tidak didukung dapat memengaruhi tata letak. Animasi, transisi, pemutaran media yang disematkan, dan mode penyaji tidak disertakan.

File dengan makro dapat dilihat, tetapi makronya tidak pernah dijalankan. Konten yang bergantung pada otomatisasi atau data eksternal tidak diperbarui. Templat dibuka tanpa membuat presentasi baru, dan peragaan slide tidak mulai diputar atau masuk ke layar penuh secara otomatis.

Ukuran hasil ekstraksi arsip dan slide yang dirender dibatasi. Presentasi terenkripsi dan file .ppt lama tidak didukung. Penampil ini tidak mengedit, mengekspor, atau mencetak presentasi maupun memuat sumber daya dokumen eksternal.
