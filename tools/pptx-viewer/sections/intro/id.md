## Baca presentasi di browser Anda

Buka file .pptx lokal atau letakkan di penampil. Berpindah antarslide, atur zoom, pilih teks untuk disalin, dan cari dalam presentasi. Teks, bentuk, tabel, dan gambar ditampilkan jika didukung.

## Privasi dan kompatibilitas

Presentasi diproses secara lokal serta tidak diunggah atau disimpan oleh alat ini. Font berasal dari presentasi atau perangkat Anda; tidak ada font daring yang diminta. Penggantian font dan fitur yang tidak didukung dapat memengaruhi tata letak. Animasi, transisi, pemutaran media yang disematkan, dan mode penyaji tidak disertakan.

File dibatasi hingga 50 MB dan 1.000 slide. Ukuran hasil ekstraksi arsip dan slide yang dirender juga dibatasi. Presentasi terenkripsi, file .ppt lama, templat, dan file dengan makro tidak didukung. Penampil ini tidak mengedit, mengekspor, atau mencetak presentasi, menjalankan makro, maupun memuat sumber daya dokumen eksternal.
