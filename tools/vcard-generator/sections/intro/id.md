## Buat dan simpan vCard

Masukkan nama depan atau nama belakang, lalu tambahkan nomor telepon, alamat email, atau detail lain yang ingin Anda bagikan. Pratinjau kartu kontak diperbarui saat Anda mengetik. Pilih **Unduh VCF** untuk menyimpan kartu atau **Salin vCard** untuk menempelkan teks sumber ke aplikasi lain. Semua data diproses di browser Anda.

Contohnya, masukkan `Taylor Morgan` dan `taylor@example.com` untuk membuat kartu yang menyimpan nama dan alamat email dalam satu file. Buka **Detail kontak lainnya** untuk menambahkan perusahaan, jabatan, situs web, alamat, atau catatan.

## Buka file kontak VCF

vCard adalah format file untuk bertukar informasi kontak. Ekstensi `.vcf` menandai jenis file yang dapat diimpor ke aplikasi kontak. Alat ini membuat file vCard 3.0 berformat UTF-8 untuk satu kontak. Gunakan menu impor di aplikasi kontak atau buka file di perangkat yang mendukung vCard. Google Contacts dan Apple Contacts sama-sama mendukung impor vCard.

## Bagikan satu kartu atau seluruh daftar kontak

Kirim file VCF sebagai lampiran agar penerima dapat menyimpan detail kontak Anda. Periksa pratinjau terlebih dahulu dan sisakan hanya detail yang ingin Anda bagikan. Jika daftar kontak Anda sudah berbentuk spreadsheet, gunakan pengonversi vCard ↔ CSV untuk membuat satu file VCF berisi beberapa kartu.
