## Crear y guardar una vCard

Escribe un nombre o apellido y añade el teléfono, el correo electrónico o cualquier otro dato que quieras compartir. La vista previa se actualiza mientras escribes. Selecciona **Descargar VCF** para guardar la tarjeta o **Copiar vCard** para pegar el texto de origen en otra aplicación. Los datos se procesan en tu navegador.

Por ejemplo, escribe `Taylor Morgan` y `taylor@example.com` para reunir el nombre y el correo en una sola tarjeta. Abre **Más datos de contacto** para incluir la empresa, el cargo, el sitio web, la dirección o notas.

## Abrir un archivo de contacto VCF

vCard es un formato de archivo para intercambiar datos de contacto. La extensión `.vcf` indica a las aplicaciones de contactos qué formato deben importar. Este generador crea un archivo vCard 3.0 con codificación UTF-8 para un solo contacto. Usa la opción de importación de tu agenda de contactos o abre el archivo en un dispositivo compatible con vCard. Contactos de Google y Contactos de Apple permiten importar estas tarjetas.

## Compartir una tarjeta o una lista de contactos

Adjunta el archivo VCF cuando quieras que alguien pueda guardar tus datos. Revisa la vista previa y conserva solo los campos que quieras compartir. Si ya tienes una hoja de cálculo con tus contactos, un convertidor de vCard y CSV puede reunir todas las tarjetas en un único archivo VCF.
