## Creare e salvare una vCard

Inserisci il nome o il cognome, poi aggiungi il numero di telefono, l’indirizzo email o gli altri recapiti che vuoi condividere. L’anteprima si aggiorna mentre scrivi. Seleziona **Scarica VCF** per salvare la scheda o **Copia vCard** per incollarne il testo in un’altra applicazione. I dati vengono elaborati nel browser.

Per esempio, inserisci `Taylor Morgan` e `taylor@example.com` per riunire il nome e l’indirizzo email in una sola scheda. Apri **Altri dati di contatto** per aggiungere azienda, qualifica, sito web, indirizzo o note.

## Aprire un file di contatto VCF

vCard è un formato di file per lo scambio di dati di contatto. L’estensione `.vcf` indica alle app dei contatti quale formato importare. Il generatore crea un file vCard 3.0 con codifica UTF-8 per un singolo contatto. Usa la funzione di importazione della tua rubrica o apri il file su un dispositivo compatibile. Contatti Google e Contatti Apple consentono di importare vCard.

## Condividere una scheda o un elenco di contatti

Allega il file VCF al tuo messaggio per permettere a chi lo riceve di salvare i tuoi recapiti. Controlla l’anteprima e tieni solo i campi che vuoi condividere. Se hai già un foglio di calcolo con i contatti, un convertitore tra vCard e CSV può creare un solo file VCF con più schede.
