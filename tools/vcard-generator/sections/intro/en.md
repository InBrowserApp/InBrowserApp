## Create and save a vCard

Enter a first or last name, then add the phone number, email address, or any other details you want to share. The contact preview updates as you type. Choose **Download VCF** to save the card or **Copy vCard** to paste its source text into another application. The form processes everything in your browser.

For example, enter `Taylor Morgan` and `taylor@example.com` to create a contact card that carries both the name and email address in one file. Open **More contact details** to include a company, job title, website, address, or notes.

## Open a VCF contact file

A vCard is a file format for exchanging contact information. The `.vcf` extension tells contact apps what kind of file to import. This generator creates a UTF-8 vCard 3.0 file for a single contact. Use the import option in your address book, or open the file on a device that supports vCards. Google Contacts and Apple Contacts both offer vCard import.

## Share a card or a whole contact list

Send the VCF file as an attachment when you want someone to save your contact details. Check the preview first and keep only the fields you want to share. If you already have a spreadsheet of contacts, a vCard and CSV converter can create a single VCF file containing multiple cards.
