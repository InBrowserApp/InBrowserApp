## Eine vCard erstellen und speichern

Geben Sie einen Vor- oder Nachnamen ein und ergänzen Sie Telefonnummer, E-Mail-Adresse oder weitere Angaben, die Sie teilen möchten. Die Kontaktvorschau aktualisiert sich bei der Eingabe. Mit **VCF herunterladen** speichern Sie die Karte. Mit **vCard kopieren** übernehmen Sie den Quelltext in eine andere Anwendung. Sämtliche Eingaben werden direkt im Browser verarbeitet.

Geben Sie beispielsweise `Taylor Morgan` und `taylor@example.com` ein. So enthält Ihre Kontaktkarte Name und E-Mail-Adresse in einer einzigen Datei. Unter **Weitere Kontaktdaten** können Sie Unternehmen, Position, Website, Adresse oder Notizen hinzufügen.

## Eine VCF-Kontaktdatei öffnen

Das vCard-Format dient zum Austausch von Kontaktdaten. An der Endung `.vcf` erkennen Kontakt-Apps das Dateiformat beim Import. Der Generator erstellt eine UTF-8-Datei im Format vCard 3.0 mit genau einem Kontakt. Verwenden Sie die Importfunktion Ihres Adressbuchs oder öffnen Sie die Datei auf einem Gerät, das vCards unterstützt. Google Kontakte und Apple Kontakte können vCards importieren.

## Eine Kontaktkarte oder eine ganze Kontaktliste teilen

Hängen Sie die VCF-Datei an eine Nachricht an, damit andere Ihre Kontaktdaten speichern können. Prüfen Sie vorher die Vorschau und übernehmen Sie nur die Angaben, die Sie weitergeben möchten. Wenn Ihre Kontakte bereits in einer Tabelle stehen, kann der vCard-CSV-Konverter mehrere Karten in einer einzigen VCF-Datei speichern.
