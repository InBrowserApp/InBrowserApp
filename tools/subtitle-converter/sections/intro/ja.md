## 字幕コンバーターについて

既存の字幕ファイルを 19 種類のテキスト字幕形式間で変換したり、プレーンテキストの書き起こしとして出力したりできます。ウェブ動画向けに SRT を VTT に変換する、ASS や SSA のセリフを SRT に変換する、動画プラットフォーム向けに字幕を準備する、変換した複数のエピソードを 1 つの ZIP にまとめる、といった用途に使えます。変換はブラウザー内で実行され、字幕ファイルや貼り付けた内容はアップロードされません。

このツールは字幕のテキストとタイミングを扱います。ファイルを選択するか字幕を貼り付け、出力形式を選び、プレビューで結果を確認してからダウンロードできます。貼り付けた入力を編集して再変換しても、端末内の元のファイルは変わりません。

## 字幕を変換する方法

1. **ファイルを選択**で 1 つ以上の字幕ファイルを開くか、入力パネルにファイルをドラッグするか、エディターに字幕テキストを貼り付けます。**サンプルを試す**では、字幕が 2 つ入った短い SRT サンプルを読み込めます。
2. 通常は**入力形式**を**自動検出**のままにします。検出ではファイル名だけでなく内容も確認します。形式を特定しにくいファイルは、元の形式を手動で選択してください。
3. **出力形式**を選びます。一般的なウェブサイトの字幕トラックには WebVTT を、プレーヤーやエディターで SRT ファイルが必要な場合は SubRip を選択します。
4. 別の文字コード、フレームレート、時間オフセットが必要な場合は、**変換設定**を開きます。これらの設定は変換前に変更してください。
5. **字幕を変換**を選択します。結果には、入力形式と出力形式、出力ファイル名、変換した字幕の数が表示されます。
6. **プレビュー**と**ファイル内容**を切り替えて確認し、変換したテキストをコピーするか、ファイルをダウンロードします。表には最大 100 個の字幕が表示されます。ファイル内容とダウンロードには、すべての結果が含まれます。

**クリア**を選択すると、現在の入力と結果がページから削除されます。新たにファイルを選択すると、それまでの選択が置き換わります。字幕の履歴は保存されないため、残しておきたい結果はダウンロードしてください。

## 対応形式と出力の精度

以下の形式は、読みやすい書き起こしの出力専用である TXT を除き、すべて読み込みと書き出しに対応しています。時刻の保存方法は形式によって異なります。精度が低い形式を選ぶと、その形式が対応する単位にタイムスタンプが丸められます。

| 形式                                   | 拡張子    | 書き出す時刻の単位・精度 |
| -------------------------------------- | --------- | ------------------------ |
| SubRip                                 | `.srt`    | ミリ秒                   |
| WebVTT                                 | `.vtt`    | ミリ秒                   |
| Advanced SubStation Alpha              | `.ass`    | 100 分の 1 秒            |
| SubStation Alpha                       | `.ssa`    | 100 分の 1 秒            |
| YouTube SubViewer                      | `.sbv`    | ミリ秒                   |
| MicroDVD                               | `.sub`    | 映像のフレーム           |
| SubViewer 2.0                          | `.sub`    | 100 分の 1 秒            |
| SAMI                                   | `.smi`    | ミリ秒                   |
| LRC lyrics                             | `.lrc`    | 開始時刻は 100 分の 1 秒 |
| Timed Text                             | `.ttml`   | ミリ秒                   |
| Distribution Format Exchange Profile   | `.dfxp`   | ミリ秒                   |
| YouTube SRV3                           | `.srv3`   | ミリ秒                   |
| YouTube transcript XML                 | `.xml`    | ミリ秒精度の秒数         |
| MPL2                                   | `.mpl`    | 10 分の 1 秒             |
| Spruce Subtitle, text format           | `.stl`    | 映像のフレーム           |
| QuickTime Text                         | `.qt.txt` | ミリ秒                   |
| JSON                                   | `.json`   | ミリ秒の数値             |
| CSV                                    | `.csv`    | ミリ秒の数値             |
| TSV                                    | `.tsv`    | ミリ秒の数値             |
| プレーンテキストの書き起こし、出力専用 | `.txt`    | タイムスタンプなし       |

TTML の入力では、互換性のある iTT ファイルも読み込めます。DFXP は TTML 系の形式です。TTML の書き出しでは、プラットフォーム固有のプロファイル、レイアウト、スタイルのルールをすべて再現するわけではありません。

ここで対応している `.sub` 拡張子は、テキスト形式の MicroDVD または SubViewer を指します。バイナリー形式の VobSub は別の形式です。同様に、対応する `.stl` 形式はテキスト形式の Spruce STL であり、バイナリー形式の EBU STL ではありません。これらの拡張子で形式を特定できない場合は、形式の正式名称を確認して選択してください。

## SRT、VTT、ASS、プレーンテキストの選び方

**SRT** は、動画プレーヤー、エディター、アップロードフォームで SubRip 字幕が求められる場合に適しています。**VTT** は HTML 動画のテキストトラックに使われる形式で、ウェブ固有のキュー設定も記録できます。これらの形式を相互変換すると、字幕テキストとミリ秒単位のタイミングを保持しながら、ファイルの構文を組み直します。

番号付きの SRT キューでは、ミリ秒の前にコンマを使います。

```text
1
00:00:01,250 --> 00:00:03,500
Hello, world!
```

同じ字幕を WebVTT にすると、ファイルヘッダーが付き、タイムスタンプには小数点を使います。

```text
WEBVTT

00:00:01.250 --> 00:00:03.500
Hello, world!
```

**ASS と SSA** は、次に使うアプリケーションでこれらの形式が必要な場合に役立ちます。対応する太字、斜体、下線の書式は、それらを表現できる形式間で引き継げます。フォント、画面上の配置、描画コマンド、カラオケアニメーションなどの高度な表示機能は簡略化され、読めるセリフを含まないグラフィック用の ASS イベントはスキップされます。このコンバーターは、作り込まれたアニメーションやレイアウトの再現よりも、読みやすい字幕の変換を重視しています。

**TXT** は、タイムスタンプやスタイルを除いた読みやすいセリフを抽出します。プレビューにはタイミングの表の代わりに、出力するテキストが表示されます。TXT 出力は字幕のタイミングを新たに作成したり、音声を書き起こしたり、話されている言語を翻訳したりする機能ではありません。

## ファイルの文字コードと文字化けへの対処

自動でファイルを読み取る場合は UTF-8 を使い、バイトオーダーマークで UTF-16 と判別できる場合は UTF-16 を使います。古いファイルで文字化けする場合や読み取れない場合は、元の文字コードを選択してください。明示的に指定できる UTF-8 と UTF-16 に加え、Windows-1252、Windows-1251、GB18030、Big5、Shift_JIS、EUC-KR などを選べます。

たとえば、GB18030 で保存されたことがわかっている中国語の字幕には GB18030 を、古いアプリケーションで作成された日本語のファイルには Shift_JIS を試してください。文字コードは、既存のバイト列の読み取り方を変えるもので、内容を翻訳するものではありません。別の文字コードを選択したら、もう一度変換してください。ダウンロードする字幕ファイルは、入力の文字コードに関係なく UTF-8 になります。

## タイミングとフレームレートの調整

### すべての字幕を早める・遅らせる

時間オフセットの単位はミリ秒です。`1500` を指定するとすべての字幕が 1.5 秒遅れ、`-500` を指定すると 0.5 秒早く表示されます。`00:00:01.250` から始まる字幕の場合、それぞれ `00:00:02.750` と `00:00:00.750` に変わります。

オフセットは開始時刻と終了時刻を両方移動し、タイムラインの先頭に達するまでは表示時間を保ちます。全体が 0 秒より前に移動した字幕は削除され、一部が 0 秒より前になる字幕は 0 秒から開始します。オフセットで補正できるのは一定のずれです。動画の再生中にずれの大きさが変わっていく字幕トラックは補正できません。

### フレーム単位のタイムスタンプにフレームレートを指定する

MicroDVD と Spruce STL は映像のフレームを使うため、フレームを経過時間に換算する方法はフレームレートによって決まります。TTML にもフレーム単位のタイミングが含まれることがあります。入力の解釈に必要な場合は、元の動画のフレームレート（`23.976`、`24`、`25`、`29.97` など）を指定してください。

入力形式にフレームレートが埋め込まれている場合は、その値が優先されます。フレーム単位で出力する場合は、選択した設定が書き出し時のフレームレートになります。この設定を変えても、通常の SRT や VTT の時刻形式のタイムスタンプは伸縮しません。フレーム単位のタイムスタンプの解釈方法や書き出し方法が変わります。

### 丸め処理と終了時刻の省略について

SRT と VTT はミリ秒の精度を保ちます。ASS、SSA、SubViewer、LRC は 100 分の 1 秒、MPL2 は 10 分の 1 秒、フレーム単位の出力はフレーム単位に丸めます。非常に短い字幕でも、丸めた後の表示時間が正の値になるようにします。プレビューには、丸める前の入力タイムスタンプではなく、出力形式のタイミングが反映されます。

LRC では、終了時刻を指定せずに開始時刻だけを指定できます。終了時刻がない場合は、次の異なる開始時刻を使い、最後の字幕は 2 秒間とします。LRC 出力では元の空白期間や重複する終了時刻を保持できず、複数行の字幕は 1 行の歌詞になります。QuickTime Text はタイムラインマーカーを使います。SAMI と QuickTime では、重なっている字幕をタイミングの境界ごとに結合したテキストとして組み直す場合があるため、結果の字幕区間数が変わることがあります。

## 一括変換と ZIP ダウンロード

複数のファイルを選択またはドロップすると、同じ出力形式と設定でまとめて変換できます。ファイル名のメニューから結果を選んで確認してください。変換できないファイルには個別のエラーが表示され、成功した結果はそれぞれダウンロードできます。

2 つ以上のファイルの変換に成功すると、**すべて ZIP でダウンロード**でそれらの出力をまとめられます。ZIP に含まれるのは変換に成功したファイルだけです。表示されたエラーを確認し、必要に応じて入力形式や文字コードを調整して、残りのファイルをもう一度変換してください。

出力ファイル名は、元のファイル名の拡張子を選択した形式のものに置き換えます。たとえば、`episode01.srt` は `episode01.vtt` になります。同じ名前になる結果が複数ある場合は、` (2)` などの接尾辞を付けて ZIP 内で区別します。このツールで ZIP を使えるのはダウンロード時です。入力には字幕ファイル自体を選択してください。

## JSON、CSV、TSV でのデータ交換

JSON は字幕オブジェクトの配列を使います。各オブジェクトにはミリ秒単位の `start` と `end`、文字列の `text` を指定します。

```json
[
  { "start": 1250, "end": 3500, "text": "Hello, world!" },
  { "start": 4000, "end": 6000, "text": "Another caption." }
]
```

読み込みでは、`segments` 配列を含む Whisper 形式の JSON にも対応しています。この形式のセグメントの `start` と `end` は秒単位です。これは入力専用の別の規約で、通常の JSON 出力はミリ秒単位のままです。

CSV と TSV は、列名に `start`、`end`、`text` を使います。入力の時刻には、ミリ秒の数値または時刻形式のタイムスタンプを指定できます。CSV はコンマ、引用符、改行を含むフィールドを引用符で囲み、TSV は列の区切りにタブを使います。どちらの出力も時刻をミリ秒の数値で書き出します。字幕をスプレッドシートや別の字幕処理のワークフローに移す場合に使ってください。

## よくある質問

### プレビューとダウンロードしたテキストの見た目が違うのはなぜですか？

プレビューの表には、読みやすい字幕テキストと出力形式のタイミングが表示されます。ファイル内容には、ヘッダー、番号、区切り文字、対応する書式の構文を含む、実際のファイルの内容が表示されます。表の表示が最初の 100 個の字幕まででも、ダウンロードには書き出された内容がすべて含まれます。

### スタイルや配置が変わったのはなぜですか？

スタイルの表現方法は形式によって異なります。対応する基本的な書式は、出力形式で表現できる場合に保持されますが、高度なスタイル、ウェブのキュー配置、アニメーション、プラットフォームのメタデータは完全には再現されません。ファイル内容の表示で出力を確認し、実際に使うプレーヤーやエディターで試してください。

### 動画や画像形式のトラックから字幕を抽出できますか？

既存のテキスト字幕ファイルを用意してください。動画に埋め込まれた字幕トラックは、先に動画から抽出する必要があります。画像形式の PGS/SUP や VobSub/IDX のトラックをテキストにするには OCR が必要です。バイナリー形式の EBU STL には、その形式を読み込める字幕エディターが必要です。

### 形式の仕様はどこで確認できますか？

ファイルの構文やプラットフォームの要件については、[WebVTT の仕様](https://www.w3.org/TR/webvtt1/)、[TTML の仕様](https://www.w3.org/TR/ttml2/)、[YouTube が対応する字幕形式](https://support.google.com/youtube/answer/2734698)をご覧ください。
