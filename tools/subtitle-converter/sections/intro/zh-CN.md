## 关于字幕转换器

将现有字幕文件在 19 种带时间信息的文本格式之间转换，或导出纯文本记录。常见用途包括将 SRT 转为网页视频使用的 VTT、将 ASS 或 SSA 对白转为 SRT、为视频平台准备字幕，以及将多集转换结果打包为一个 ZIP。转换在浏览器中进行，不会上传字幕文件或粘贴的内容。

此工具处理字幕文本及其时间信息。选择文件或粘贴字幕，选定输出格式，再通过预览检查结果后下载。你可以修改粘贴的内容并重新转换，而不会改动设备上的原始文件。

## 如何转换字幕

1. 点击**选择文件**打开一个或多个字幕文件，将文件拖到输入面板，或将字幕文本粘贴到编辑器中。**试用示例**会载入一段含两条字幕的简短 SRT 示例。
2. 通常将**输入格式**保留为**自动识别**即可。识别会检查内容，而不只是依赖文件名。如果文件格式难以判断，请手动选择源格式。
3. 选择**输出格式**。常见的网站字幕轨可选 WebVTT；如果播放器或编辑器要求 SRT 文件，则选择 SubRip。
4. 如需更改文件编码、帧率或时间偏移，请打开**转换设置**，并在转换前完成设置。
5. 点击**转换字幕**。结果会显示源格式、输出格式、输出文件名及已转换的字幕条数。
6. 在**预览**与**文件内容**之间切换，然后复制转换后的文本或下载文件。表格最多显示 100 条字幕；文件内容与下载文件均包含完整结果。

**清空**会从页面移除当前输入和结果。选择一组新文件会替换之前的选择。转换器不会保留字幕历史记录，请下载需要保存的结果。

## 支持的格式与输出精度

下表中除 TXT 仅用于导出便于阅读的文本记录外，所有格式均支持读取和写入。不同格式存储时间的方式不同；选择精度较低的格式时，时间戳会舍入到该格式支持的单位。

| 格式                                 | 扩展名    | 写入的时间精度           |
| ------------------------------------ | --------- | ------------------------ |
| SubRip                               | `.srt`    | 毫秒                     |
| WebVTT                               | `.vtt`    | 毫秒                     |
| Advanced SubStation Alpha            | `.ass`    | 百分之一秒               |
| SubStation Alpha                     | `.ssa`    | 百分之一秒               |
| YouTube SubViewer                    | `.sbv`    | 毫秒                     |
| MicroDVD                             | `.sub`    | 视频帧                   |
| SubViewer 2.0                        | `.sub`    | 百分之一秒               |
| SAMI                                 | `.smi`    | 毫秒                     |
| LRC lyrics                           | `.lrc`    | 开始时间精确到百分之一秒 |
| Timed Text                           | `.ttml`   | 毫秒                     |
| Distribution Format Exchange Profile | `.dfxp`   | 毫秒                     |
| YouTube SRV3                         | `.srv3`   | 毫秒                     |
| YouTube transcript XML               | `.xml`    | 以秒为单位，精确到毫秒   |
| MPL2                                 | `.mpl`    | 十分之一秒               |
| Spruce Subtitle, text format         | `.stl`    | 视频帧                   |
| QuickTime Text                       | `.qt.txt` | 毫秒                     |
| JSON                                 | `.json`   | 毫秒数值                 |
| CSV                                  | `.csv`    | 毫秒数值                 |
| TSV                                  | `.tsv`    | 毫秒数值                 |
| 纯文本记录，仅供导出                 | `.txt`    | 无时间戳                 |

TTML 输入也接受兼容的 iTT 文件。DFXP 属于 TTML 格式家族。导出 TTML 时不会重建所有平台专属的配置、布局或样式规则。

这里的 `.sub` 扩展名可能代表文本格式的 MicroDVD 或 SubViewer。二进制 VobSub 是另一种格式。同样，支持的 `.stl` 格式是文本形式的 Spruce STL，而非二进制 EBU STL。如果这些扩展名存在歧义，请根据格式全名选择。

## 如何选择 SRT、VTT、ASS 与纯文本

当视频播放器、编辑器或上传表单要求 SubRip 字幕时，**SRT** 是合适的选择。**VTT** 是 HTML 视频文本轨使用的格式，还能包含网页专用的字幕设置。二者互转时会保留字幕文本和毫秒级时间信息，同时重新生成文件语法。

带编号的 SRT 字幕在毫秒前使用逗号：

```text
1
00:00:01,250 --> 00:00:03,500
Hello, world!
```

同一条字幕采用 WebVTT 格式时，会包含文件头，时间戳使用小数点：

```text
WEBVTT

00:00:01.250 --> 00:00:03.500
Hello, world!
```

如果接下来使用的应用要求 **ASS 或 SSA**，这两种格式可用于交换字幕。对于能够表达粗体、斜体和下划线的格式，转换时可以保留这些受支持的格式设置。字体、屏幕定位、绘图命令、卡拉 OK 动画及其他高级呈现功能会被简化；不含可读对白的 ASS 图形事件会被跳过。转换器侧重于生成可读字幕，不会完整复现原先制作的动画或布局。

**TXT** 提取可读对白，不含时间戳或样式。其预览显示导出的文本，而非时间表格。TXT 导出不会生成字幕时间、转录语音或翻译对白语言。

## 文件编码与文本可读性

自动解码文件时使用 UTF-8；如果字节顺序标记表明文件采用 UTF-16，则使用 UTF-16。对于较旧的文件，如果出现乱码或无法解码，请选择文件的原始编码。除明确指定 UTF-8 和 UTF-16 的选项外，还可选择 Windows-1252、Windows-1251、GB18030、Big5、Shift_JIS 和 EUC-KR 等编码。

例如，已知中文字幕以 GB18030 保存时，可以尝试选择 GB18030；来自旧版应用的日文文件则可以尝试 Shift_JIS。编码影响现有字节的读取方式，不会翻译文本含义。选择其他编码后，请重新转换。无论输入采用哪种编码，下载的字幕文件都使用 UTF-8。

## 调整时间与帧率

### 让所有字幕提前或延后

时间偏移以毫秒为单位。设为 `1500` 会让每条字幕延后 1.5 秒；设为 `-500` 会让字幕提前半秒。对于开始时间为 `00:00:01.250` 的字幕，这两种设置会分别将其改为 `00:00:02.750` 和 `00:00:00.750`。

偏移会同时移动开始和结束时间，在未触及时间轴起点时保持字幕时长不变。完全移到零时刻之前的字幕会被移除；部分跨过零时刻的字幕会改为从零开始。偏移可校正固定的时间差，无法修正随视频播放进程不断变化的字幕时间偏差。

### 为基于帧的时间戳设置帧率

MicroDVD 和 Spruce STL 使用视频帧，因此帧率决定了如何将帧数换算为经过的时间。TTML 也可能包含基于帧的时间信息。需要据此解析输入时，请使用源视频的帧率，例如 `23.976`、`24`、`25` 或 `29.97`。

如果输入格式提供了内嵌帧率，则优先使用该帧率。对于基于帧的输出，所选设置决定写入时使用的帧率。更改此设置不会按比例缩放普通 SRT 或 VTT 的时钟时间戳；它会改变基于帧的时间戳的解析或写入方式。

### 了解舍入与缺失的结束时间

SRT 和 VTT 保留毫秒精度。ASS、SSA、SubViewer 和 LRC 舍入到百分之一秒；MPL2 舍入到十分之一秒；基于帧的输出则舍入到视频帧。极短的字幕在舍入后仍会保留大于零的时长。预览反映导出格式的时间信息，而不是显示未经舍入的输入时间戳。

LRC 可以只提供开始时间而没有结束时间。缺失的结束时间取下一个不同的开始时间，最后一条字幕则持续两秒。LRC 导出无法保留原始字幕之间的间隔和重叠的结束时间，多行字幕会合并为单行歌词。QuickTime Text 使用时间轴标记；SAMI 和 QuickTime 可在每个时间分界点将重叠字幕重建为合并后的文本，因此结果中的字幕片段数可能发生变化。

## 批量转换与 ZIP 下载

选择或拖入多个文件，即可使用相同的输出格式和设置进行转换。从文件名菜单中选择一项结果即可查看。无法转换的文件会分别保留各自的错误信息，成功转换的结果仍可单独下载。

至少有两个文件成功转换时，**全部下载为 ZIP** 会将这些输出文件打包。压缩包只包含成功转换的结果。检查显示的错误，根据需要调整输入格式或编码，再次转换其余文件。

输出文件名保留源文件的基本名称，并使用所选扩展名：例如，`episode01.srt` 会变为 `episode01.vtt`。如果多个结果名称相同，会添加 ` (2)` 等后缀，让它们在 ZIP 中拥有不同的名称。这里的 ZIP 仅用于下载；输入时请选择字幕文件本身。

## JSON、CSV 与 TSV 数据交换

JSON 使用字幕对象数组，每个对象包含以毫秒为单位的 `start` 和 `end` 值，以及 `text` 字符串：

```json
[
  { "start": 1250, "end": 3500, "text": "Hello, world!" },
  { "start": 4000, "end": 6000, "text": "Another caption." }
]
```

读取时也接受 Whisper 风格的 JSON，其中包含 `segments` 数组，各片段的 `start` 和 `end` 值以秒为单位。这是一种独立的输入约定；常规 JSON 导出仍使用毫秒。

CSV 和 TSV 使用 `start`、`end` 和 `text` 作为列名。输入时间可以是毫秒数值或时钟时间戳。CSV 会用引号包裹包含逗号、引号或换行的字段；TSV 在列之间使用制表符。二者导出时都写入毫秒数值。需要将字幕导入电子表格或其他字幕处理流程时，可以使用这些格式。

## 常见问题

### 为什么预览与下载的文本看起来不同？

预览表格显示可读的字幕文本及目标格式的时间信息。文件内容显示实际序列化后的文件，包括文件头、编号、分隔符和受支持的格式语法。即使表格只显示前 100 条字幕，下载文件仍包含完整的序列化内容。

### 为什么样式或定位发生了变化？

不同格式使用的样式模型不同。能够表达的基本格式会予以保留；高级样式、网页字幕定位、动画及平台元数据不会完整复现。请在文件内容视图中检查导出结果，并在实际使用的播放器或编辑器中测试。

### 能从视频或图片字幕轨中提取字幕吗？

请使用现有的文本字幕文件。如果字幕轨内嵌在视频中，请先将其提取出来。基于图像的 PGS/SUP 和 VobSub/IDX 字幕轨需要通过 OCR 转为文本；二进制 EBU STL 则需要能读取该格式的字幕编辑器。

### 在哪里可以查看格式规范？

有关文件语法与平台要求，请参阅 [WebVTT 规范](https://www.w3.org/TR/webvtt1/)、[TTML 规范](https://www.w3.org/TR/ttml2/) 和 [YouTube 支持的字幕格式](https://support.google.com/youtube/answer/2734698)。
