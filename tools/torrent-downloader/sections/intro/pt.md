O Baixador de torrents abre links magnet BitTorrent e arquivos .torrent no navegador. Escolha um arquivo do torrent, inicie o download e acompanhe o progresso. A ferramenta se conecta pelo WebTorrent e salva o arquivo usando o navegador.

## Como baixar um arquivo de um torrent

Cole um link magnet e selecione “Abrir torrent” ou escolha um arquivo .torrent local. Quando a lista de arquivos aparecer, use o filtro para encontrar um arquivo pelo nome ou caminho da pasta. Selecione “Baixar” ao lado do arquivo desejado. Você pode baixar um arquivo por vez e cancelar uma transferência em andamento. Mantenha a aba aberta até terminar de salvar.

## Quais torrents funcionam no navegador?

O baixador oferece suporte a torrents BitTorrent v1 e híbridos com hash de informação v1. No navegador, o WebTorrent pode se conectar a peers compatíveis com WebRTC encontrados por meio de um tracker WebSocket. Também pode ler dados de web seeds HTTP compatíveis quando o servidor permite requisições do navegador. Um link magnet pode conter uma fonte separada de metadados. Conseguir abrir a lista de arquivos não garante que haja uma fonte disponível para os dados dos arquivos.

## Onde os arquivos são salvos e o que os peers podem ver

A ferramenta é executada no navegador. Se ele oferecer uma janela “Salvar como”, você poderá escolher o destino antes do início da transferência. Caso contrário, depois que os dados chegarem, o arquivo será entregue ao gerenciador de downloads do navegador. Trackers, peers e web seeds podem ver sua conexão e qual torrent você solicitou. Enquanto o torrent estiver ativo, o WebTorrent poderá compartilhar peças com os peers conectados. Fechar o torrent encerra a sessão.
