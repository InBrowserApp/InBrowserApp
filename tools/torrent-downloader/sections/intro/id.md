Pengunduh Torrent membuka tautan magnet BitTorrent dan file .torrent langsung di browser. Pilih salah satu file dalam torrent untuk mulai mengunduh dan memantau kemajuannya. Alat ini menggunakan WebTorrent untuk mengambil data dan menyimpan file melalui browser.

## Cara mengunduh file dari torrent

Tempel tautan magnet dan pilih “Buka torrent”, atau pilih file .torrent dari perangkat Anda. Setelah daftar muncul, gunakan filter untuk mencari file berdasarkan nama atau jalur folder. Pilih “Unduh” di samping file yang diinginkan. Anda dapat mengunduh satu file dalam satu waktu dan membatalkan transfer yang sedang berjalan. Biarkan tab tetap terbuka sampai file tersimpan.

## Torrent apa saja yang bisa digunakan di browser?

Alat ini mendukung BitTorrent v1 dan torrent hibrida yang memuat info hash v1. WebTorrent di browser dapat terhubung ke peer yang mendukung WebRTC melalui pelacak WebSocket. Alat ini juga dapat mengambil data dari web seed HTTP yang kompatibel jika server mengizinkan permintaan dari browser. Tautan magnet terkadang memuat sumber metadata terpisah. Daftar file mungkin bisa ditampilkan meski sumber data filenya belum tersedia.

## Di mana file disimpan dan apa yang dapat dilihat peer?

Alat ini berjalan di browser Anda. Jika browser menyediakan dialog “Simpan Sebagai”, Anda dapat memilih lokasi penyimpanan sebelum transfer dimulai. Jika pilihan itu tidak tersedia, file akan diteruskan ke pengelola unduhan browser setelah semua data diterima. Pelacak, peer, dan web seed dapat melihat informasi koneksi Anda dan torrent yang Anda minta. Selama torrent masih aktif, WebTorrent dapat membagikan potongan file kepada peer yang terhubung. Tutup torrent untuk mengakhiri sesi.
