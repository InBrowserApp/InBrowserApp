Con questo strumento puoi aprire link magnet BitTorrent e file .torrent direttamente nel browser. Scegli un file del torrent, avvia il download e segui l'avanzamento. Lo strumento si connette tramite WebTorrent e usa il browser per salvare il file.

## Come scaricare un file da un torrent

Incolla un link magnet e seleziona «Apri torrent», oppure scegli un file .torrent dal tuo dispositivo. Quando compare l'elenco, usa il filtro per trovare il file per nome o percorso della cartella. Seleziona «Scarica» accanto al file desiderato. Puoi scaricare un file alla volta e annullare un trasferimento in corso. Tieni aperta la scheda fino alla fine del salvataggio.

## Quali torrent funzionano nel browser?

Lo strumento supporta i torrent BitTorrent v1 e quelli ibridi con un info hash v1. Nel browser, WebTorrent può connettersi a peer che supportano WebRTC, trovati tramite un tracker WebSocket. Può anche ricevere dati da web seed HTTP compatibili, se il server accetta le richieste del browser. Un link magnet può contenere una fonte separata per i metadati. Anche quando l'elenco dei file si apre, può mancare una fonte da cui scaricare il file.

## Dove finiscono i file e cosa possono vedere i peer

Lo strumento funziona nel browser. Se il browser offre la finestra «Salva con nome», puoi scegliere la destinazione prima che inizi il trasferimento. Altrimenti, una volta ricevuti tutti i dati, il file viene passato al gestore dei download del browser. Tracker, peer e web seed possono vedere i dati della tua connessione e quale torrent hai richiesto. Mentre il torrent è aperto, WebTorrent può condividere pezzi con i peer connessi. Chiudi il torrent per terminare la sessione.
