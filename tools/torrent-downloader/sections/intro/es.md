Con el Descargador de torrents puedes abrir enlaces magnet de BitTorrent y archivos `.torrent` en tu navegador. Elige un archivo del torrent, inicia la descarga y consulta su progreso. La herramienta se conecta mediante WebTorrent y guarda el archivo a través del navegador.

## Cómo descargar un archivo de un torrent

Pega un enlace magnet y pulsa «Abrir torrent», o selecciona un archivo `.torrent` de tu dispositivo. Cuando aparezca la lista, usa el filtro para buscar un archivo por nombre o ruta de carpeta. Pulsa «Descargar» junto al archivo. Puedes descargar un archivo a la vez y cancelar una transferencia en curso. Mantén abierta la pestaña hasta que se guarde el archivo.

## Qué torrents funcionan en el navegador

El descargador admite BitTorrent v1 y torrents híbridos con un hash v1. WebTorrent puede conectarse desde el navegador a pares compatibles con WebRTC que se encuentren mediante un rastreador WebSocket. También puede leer datos de semillas web HTTP compatibles si el servidor admite solicitudes del navegador. Un enlace magnet puede incluir una fuente de metadatos independiente. Aunque puedas abrir la lista, puede que no haya una fuente disponible para descargar el archivo.

## Dónde se guardan los archivos y qué pueden ver los pares

La herramienta se ejecuta en tu navegador. Si el navegador ofrece la opción «Guardar como», puedes elegir el destino antes de iniciar la transferencia. En los demás casos, el archivo se envía al gestor de descargas del navegador cuando se han recibido todos sus datos. Los rastreadores, los pares y las semillas web pueden ver tu conexión y qué torrent has solicitado. Mientras el torrent esté abierto, WebTorrent puede compartir piezas con los pares conectados. Cierra el torrent para terminar la sesión.
