BT 种子下载器可在浏览器中打开 BitTorrent 磁力链接和 .torrent 文件。选择种子中的文件，开始下载并查看进度。工具通过 WebTorrent 连接，并使用浏览器保存文件。

## 如何下载种子中的文件

粘贴磁力链接并选择“打开种子”，或选择本地 .torrent 文件。文件列表出现后，可以按文件名或文件夹路径筛选，再选择目标文件旁的“下载”。每次可下载一个文件，也可以取消正在进行的传输。请保持标签页打开，直到保存完成。

## 哪些种子可以在浏览器中使用？

下载器支持 BitTorrent v1 种子，以及带有 v1 信息哈希的混合种子。浏览器中的 WebTorrent 可以通过 WebSocket Tracker 发现并连接支持 WebRTC 的节点。如果服务器允许浏览器请求，也可以从兼容的 HTTP Web 种子读取数据。磁力链接还可能包含独立的元数据来源。能够打开文件列表，并不代表一定有可用的文件数据来源。

## 文件保存位置及节点可见的信息

工具在浏览器中运行。如果浏览器提供“另存为”对话框，你可以在传输开始前选择保存位置。否则，文件数据接收完成后会交给浏览器的下载管理器。Tracker、节点和 Web 种子可以看到你的连接以及你请求的种子。种子处于活动状态时，WebTorrent 可能会向已连接的节点分享文件分片。关闭种子会结束会话。
