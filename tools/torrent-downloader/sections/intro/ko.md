토렌트 다운로더에서는 BitTorrent 마그넷 링크와 .torrent 파일을 브라우저에서 열 수 있습니다. 토렌트에 포함된 파일을 선택해 다운로드하고 진행 상황을 확인하세요. WebTorrent로 파일 데이터를 받고 브라우저를 통해 저장합니다.

## 토렌트에서 파일을 다운로드하는 방법

마그넷 링크를 붙여넣고 ‘토렌트 열기’를 선택하거나 기기에 있는 .torrent 파일을 선택하세요. 파일 목록이 표시되면 필터에서 파일 이름이나 폴더 경로로 원하는 파일을 찾을 수 있습니다. 해당 파일 옆의 ‘다운로드’를 선택하세요. 한 번에 파일 하나를 다운로드할 수 있으며, 진행 중인 전송은 취소할 수 있습니다. 저장이 끝날 때까지 이 탭을 열어 두세요.

## 브라우저에서 어떤 토렌트를 사용할 수 있나요?

BitTorrent v1과 v1 정보 해시가 포함된 하이브리드 토렌트를 지원합니다. 브라우저의 WebTorrent는 WebSocket 트래커를 통해 WebRTC를 지원하는 피어를 찾아 연결할 수 있습니다. 호환되는 HTTP 웹 시드가 브라우저의 요청을 허용하는 경우, 그 서버에서도 파일 데이터를 받을 수 있습니다. 마그넷 링크에는 별도의 메타데이터 소스가 포함되기도 합니다. 파일 목록을 열 수 있더라도 실제 다운로드에는 파일 데이터를 제공하는 소스가 필요합니다.

## 파일 저장 위치와 다른 피어에게 보이는 정보

이 도구는 브라우저에서 실행됩니다. 브라우저가 ‘다른 이름으로 저장’ 대화상자를 지원하면 전송을 시작하기 전에 저장 위치를 선택할 수 있습니다. 다른 경우에는 파일 데이터를 모두 받은 후 브라우저의 다운로드 관리자로 파일을 전달합니다. 트래커, 피어, 웹 시드는 내 접속 정보와 요청한 토렌트를 확인할 수 있습니다. 토렌트가 열려 있는 동안 WebTorrent가 연결된 피어와 파일 조각을 공유할 수 있습니다. 토렌트를 닫으면 세션이 종료됩니다.
