Открывайте магнит-ссылки BitTorrent и файлы `.torrent` прямо в браузере. Выберите нужный файл из торрента, запустите загрузку и следите за её ходом. Инструмент получает данные через WebTorrent и сохраняет файл с помощью браузера.

## Как скачать файл из торрента

Вставьте магнит-ссылку и нажмите «Открыть торрент» или выберите файл `.torrent` на устройстве. Когда появится список файлов, найдите нужный по имени или пути к папке. Нажмите «Скачать» рядом с ним. Можно скачивать по одному файлу за раз и отменять текущую загрузку. Не закрывайте вкладку до завершения сохранения.

## Какие торренты работают в браузере?

Поддерживаются торренты BitTorrent v1 и гибридные торренты с инфо-хешем v1. В браузере WebTorrent подключается к пирам с поддержкой WebRTC, найденным через WebSocket-трекер. Данные также можно получать с совместимых HTTP-веб-сидов, если сервер разрешает запросы из браузера. В магнит-ссылке может быть указан отдельный источник метаданных. Даже если список файлов открылся, источник данных для скачивания может быть недоступен.

## Куда сохраняются файлы и что видят пиры

Инструмент работает в браузере. Если браузер поддерживает диалог «Сохранить как», папку назначения можно выбрать до начала загрузки. В остальных случаях после получения всех данных файл передаётся менеджеру загрузок браузера. Трекеры, пиры и веб-сиды могут видеть ваше подключение и запрошенный торрент. Пока торрент открыт, WebTorrent может передавать части файлов подключённым пирам. Закройте торрент, чтобы завершить сеанс.
