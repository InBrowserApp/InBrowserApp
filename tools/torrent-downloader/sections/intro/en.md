Torrent Downloader opens BitTorrent magnet links and .torrent files in your browser. Choose a file from the torrent, start the download, and follow its progress. The tool connects through WebTorrent and saves the file using your browser.

## How to download a torrent file

Paste a magnet link and choose Open torrent, or select a local .torrent file. After the file list appears, use the filter to find a file by its name or folder path. Select Download next to that file. You can download one file at a time and cancel an active transfer. Keep the tab open until saving finishes.

## Which torrents work in a browser?

The downloader supports BitTorrent v1 and hybrid torrents with a v1 info hash. Browser WebTorrent can connect to WebRTC-capable peers found through a WebSocket tracker. It can also read data from compatible HTTP web seeds when the server permits browser requests. A magnet link may contain a separate metadata source. Being able to open the file list does not guarantee that a source for the file data is available.

## Where the files go and what peers can see

The tool runs in your browser. If your browser offers a Save As picker, you can choose a destination before the transfer starts. Otherwise, the downloaded file is handed to the browser's download manager after its data arrives. Trackers, peers, and web seeds can see your connection and which torrent you requested. While the torrent is active, WebTorrent may share pieces with connected peers. Closing the torrent ends the session.
