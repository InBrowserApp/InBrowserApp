Le téléchargeur de torrents ouvre les liens magnet BitTorrent et les fichiers .torrent dans votre navigateur. Choisissez un fichier dans le torrent, lancez le téléchargement et suivez sa progression. L’outil utilise WebTorrent pour établir la connexion et votre navigateur pour enregistrer le fichier.

## Comment télécharger les fichiers d’un torrent

Collez un lien magnet et cliquez sur « Ouvrir le torrent », ou sélectionnez un fichier .torrent sur votre appareil. Une fois la liste affichée, utilisez le filtre pour retrouver un fichier par son nom ou le chemin de son dossier. Cliquez sur « Télécharger » à côté du fichier. Vous pouvez télécharger un fichier à la fois et annuler un transfert en cours. Gardez l’onglet ouvert jusqu’à la fin de l’enregistrement.

## Quels torrents fonctionnent dans un navigateur ?

Le téléchargeur prend en charge les torrents BitTorrent v1 et hybrides dotés d’un info hash v1. Dans le navigateur, WebTorrent peut se connecter à des pairs compatibles avec WebRTC, repérés grâce à un tracker WebSocket. Il peut aussi récupérer des données auprès de sources web compatibles via HTTP si leurs serveurs autorisent les requêtes du navigateur. Un lien magnet peut indiquer une source distincte pour les métadonnées. Même si la liste des fichiers s’affiche, les données à télécharger peuvent être indisponibles.

## Où vont les fichiers et que voient les autres pairs ?

L’outil fonctionne dans votre navigateur. Si celui-ci propose une boîte de dialogue « Enregistrer sous », vous pouvez choisir l’emplacement du fichier avant le début du transfert. Sinon, une fois toutes les données reçues, le fichier est transmis au gestionnaire de téléchargements du navigateur. Les trackers, les pairs et les sources web peuvent voir votre connexion et le torrent que vous avez demandé. Tant que le torrent est ouvert, WebTorrent peut partager des morceaux avec les pairs connectés. Fermez le torrent pour terminer la session.
