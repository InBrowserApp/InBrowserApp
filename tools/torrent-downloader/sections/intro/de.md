Der Torrent-Downloader öffnet BitTorrent-Magnet-Links und .torrent-Dateien direkt im Browser. Wähle eine Datei aus dem Torrent, starte den Download und verfolge seinen Fortschritt. Das Tool stellt die Verbindung über WebTorrent her und nutzt deinen Browser zum Speichern.

## So lädst du eine Datei aus einem Torrent herunter

Füge einen Magnet-Link ein und wähle „Torrent öffnen“ oder wähle eine lokale .torrent-Datei aus. Sobald die Dateiliste erscheint, kannst du sie nach Dateinamen oder Ordnerpfaden filtern. Wähle neben der gewünschten Datei „Herunterladen“. Du kannst jeweils eine Datei herunterladen und eine laufende Übertragung abbrechen. Lass den Tab offen, bis die Datei gespeichert ist.

## Welche Torrents funktionieren im Browser?

Der Downloader unterstützt BitTorrent v1 und hybride Torrents mit einem v1-Info-Hash. Im Browser kann WebTorrent über einen WebSocket-Tracker Peers finden und sich mit ihnen verbinden, wenn sie WebRTC unterstützen. Es kann auch Daten von kompatiblen HTTP-Webseeds abrufen, sofern der Server Anfragen des Browsers zulässt. Ein Magnet-Link kann eine separate Metadatenquelle enthalten. Auch wenn sich die Dateiliste öffnen lässt, steht möglicherweise keine Quelle für die Dateidaten zur Verfügung.

## Wo die Dateien landen und was Peers sehen können

Das Tool läuft in deinem Browser. Wenn dein Browser einen Dialog „Speichern unter“ anbietet, kannst du vor Beginn der Übertragung einen Speicherort auswählen. Ansonsten wird die Datei nach der Übertragung an die Download-Verwaltung des Browsers übergeben. Tracker, Peers und Webseeds können deine Verbindung und den angefragten Torrent sehen. Solange der Torrent geöffnet ist, kann WebTorrent Datenteile mit verbundenen Peers teilen. Wenn du den Torrent schließt, endet die Sitzung.
