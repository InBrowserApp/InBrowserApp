## Filecoin Onchain Cloud 스토리지 비용 추정하기

데이터 크기, **보존 기간(일)**, **복제본 수**를 입력하세요. 계산기는 Filecoin Warm Storage Service를 이용해 복제본마다 새 데이터 세트를 저장하는 데 드는 비용을 추정합니다. 월별 저장 및 증명 비용, 선택한 기간의 지출액, 데이터 세트 생성과 피스 추가에 드는 비용을 보여줍니다. 금액은 USDFC 단위로 표시됩니다. Filecoin의 요금은 30일을 한 달로 계산합니다.

## 스토리지 비용을 계산하는 방식

활성 데이터 세트마다 크기에 따른 저장 비용과 데이터 보유 증명(PDP)에 대한 정액 비용이 발생합니다. 예를 들어 저장 비용이 TiB당 2.50 USDFC이고 증명 비용이 복제본당 0.12 USDFC라면, 1 TiB의 복제본 두 개를 저장하는 데 30일마다 약 5.24 USDFC가 듭니다. 예상 비용은 입력한 데이터 크기를 기준으로 계산합니다. Filecoin은 실제 데이터가 있는 리프 노드를 기준으로 정확한 청구 크기를 계산하므로 피스당 최대 31바이트가 추가될 수 있습니다.

## 업로드 비용과 환급 가능한 예치금 계획하기

**업로드 세부 정보**를 열어 복제본마다 포함할 피스 수와 업로드 배치 수를 입력하세요. 기본적으로 복제본당 배치 하나를 기준으로 추정합니다. 피스 수를 비워 두면 Synapse SDK 업로드 한도인 63.5 GiB를 기준으로 필요한 최소 피스 수를 추정합니다. 실제 수를 알고 있다면 직접 입력하세요. 복제본마다 데이터 세트 생성 비용이 발생하며, 피스를 추가할 때 배치별 기본 비용과 피스별 비용을 지불합니다. 서비스는 이용 기간 중 운영 비용에 대비해 예치금을 보관합니다. 예치금은 예상 지출액과 별도로 표시되며 정산이 끝나면 사용하지 않은 금액이 반환됩니다. 예상 비용에는 새 업로드와 지정한 저장 기간이 포함됩니다. 데이터 가져오기와 이후 작업에는 별도의 비용이 발생합니다. [Synapse SDK 크기 제한](https://docs.filecoin.cloud/developer-guides/synapse/#size-constraints)을 참고하세요.

## Filecoin 요율의 출처

이 페이지는 결과 옆에 날짜와 함께 표시된 기준 요율로 계산합니다. **메인넷 요율 새로고침**을 누르면 공개 Filecoin RPC를 통해 Warm Storage 요금 컨트랙트를 읽습니다. 브라우저는 반환된 요율을 사용하고 출처인 블록을 표시합니다. 요율을 가져올 수 없는 경우에도 기준 요율로 계산할 수 있습니다.

정확한 청구 크기, 계정별 필요 자금, 전체 요금표는 [Filecoin 스토리지 비용 가이드](https://docs.filecoin.cloud/developer-guides/storage/storage-costs/)를 참고하세요.
