## Как оценить стоимость хранения в Filecoin Onchain Cloud

Введите объём данных, **Срок хранения (дни)** и число в поле **Копии**. Калькулятор оценивает расходы на хранение нового набора данных для каждой копии в Filecoin Warm Storage Service. Он показывает месячную стоимость хранения и предоставления доказательств, расходы за выбранный срок и сборы за создание наборов данных и добавление фрагментов. Суммы указаны в USDFC. Для расчёта тарифов Filecoin месяц равен 30 дням.

## Как рассчитывается стоимость хранения

Для каждого активного набора данных оплачиваются хранение по объёму и фиксированный сбор за доказательство наличия данных (Proof of Data Possession, PDP). Например, при тарифе хранения 2,50 USDFC за TiB и сборе за доказательство 0,12 USDFC за копию хранение одного TiB в двух копиях обойдётся примерно в 5,24 USDFC за 30 дней. Для оценки используется введённый объём данных. Filecoin рассчитывает точный оплачиваемый объём по листовым узлам, содержащим данные. Это может добавить до 31 байта на фрагмент.

## Как учесть сборы за загрузку и возвратный резерв

Откройте **Параметры загрузки** и укажите число фрагментов и пакетов загрузки на копию. По умолчанию один пакет содержит один фрагмент. Для каждой копии взимается плата за создание набора данных. Стоимость добавления фрагментов складывается из базового сбора за пакет и отдельного сбора за каждый фрагмент. Сервис удерживает резерв на жизненный цикл для оплаты операций. Резерв показывается отдельно от расчётных расходов, а неиспользованные средства высвобождаются после расчётов. Оценка охватывает новую загрузку и выбранный срок хранения. Извлечение данных и последующие операции оплачиваются отдельно.

## Откуда берутся тарифы Filecoin

Для расчёта используются справочные тарифы на указанную рядом с результатом дату. Нажмите **Обновить тарифы основной сети**, чтобы прочитать контракт ценообразования Warm Storage через публичный Filecoin RPC. Браузер использует полученные тарифы и показывает блок, из которого они взяты. Если запрос недоступен, оценку можно рассчитать по справочным тарифам.

Точный оплачиваемый объём, требования к пополнению конкретного счёта и полный перечень сборов описаны в [руководстве Filecoin по стоимости хранения](https://docs.filecoin.cloud/developer-guides/storage/storage-costs/).
