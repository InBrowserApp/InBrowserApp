## How to edit a CSV file online

Open or drop a CSV or TSV file, paste delimited text, or try the example. To edit a value, click or tap its cell. Press Enter to save, Escape to cancel, or Shift+Enter to insert a line break. When the first row contains field names, leave First row is a header selected so it stays at the top while you sort and filter. You can edit a field name in the column menu.

## Sort rows, filter values, and reorder columns

Use a column menu to sort in ascending or descending order, or clear the sort to restore the original row order. The filter finds matching text across the whole table or in one selected column. Drag a column grip to change the order, or use the move commands in the column menu. Filters affect what you see and keep every row in the table.

## Save the edited table as CSV or TSV

Download saves every row in the current sort and column order. To export only the rows that match your filter, use the download options. The editor keeps the detected delimiter and line-ending style, along with a byte-order mark if present. Cell values are kept as text, so leading zeros and long IDs survive edits and export.

## Supported files and privacy

The editor supports comma, tab, semicolon, and pipe delimiters, quoted fields, and multiline cells. Open UTF-8 files or UTF-16 files with a byte-order mark. Files are read and edited on your device without uploading them. Download a copy before leaving the page to keep your changes.
