## Cómo editar un archivo CSV en línea

Abre o arrastra un archivo CSV o TSV, pega texto delimitado o prueba el ejemplo. Haz clic o toca una celda para editar su valor. Pulsa Intro para guardar, Esc para cancelar o Mayús + Intro para insertar un salto de línea. Si la primera fila contiene los nombres de los campos, deja activada la opción Usar la primera fila como encabezado para mantenerla arriba al ordenar y filtrar. Puedes cambiar el nombre de cada campo en el menú de su columna.

## Ordenar filas, filtrar valores y reordenar columnas

En el menú de una columna, elige el orden ascendente o descendente, o restaura el orden original. El filtro busca texto en toda la tabla o solo en la columna que selecciones. Para cambiar la posición de una columna, arrástrala desde el tirador o usa las opciones de su menú. El filtro solo cambia las filas que se muestran. Todas se conservan en la tabla.

## Guardar la tabla editada como CSV o TSV

La descarga guarda todas las filas y respeta el orden actual de las filas y columnas. Para exportar solo las filas que coinciden con el filtro, usa las opciones de descarga. El editor conserva el delimitador y el tipo de salto de línea detectados, así como la marca de orden de bytes si existe. Los valores se mantienen como texto para conservar los ceros iniciales y los identificadores largos al editar y exportar.

## Archivos compatibles y privacidad

El editor admite la coma, la tabulación, el punto y coma y la barra vertical como delimitadores, además de campos entre comillas y celdas con varias líneas. Puedes abrir archivos UTF-8 o UTF-16 con marca de orden de bytes. Los archivos se abren y editan en tu dispositivo sin subirlos. Descarga una copia antes de salir de la página para guardar los cambios.
