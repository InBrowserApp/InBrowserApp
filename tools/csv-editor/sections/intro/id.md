## Cara mengedit file CSV secara online

Buka atau seret file CSV atau TSV ke editor, tempel teks berpemisah, atau coba contoh. Klik atau ketuk sel untuk mengubah nilainya. Tekan Enter untuk menyimpan, Escape untuk membatalkan, atau Shift+Enter untuk menyisipkan baris baru di dalam sel. Jika baris pertama berisi nama kolom, biarkan opsi Gunakan baris pertama sebagai header tetap dicentang agar baris tersebut tetap di bagian atas saat Anda mengurutkan atau memfilter data. Nama kolom dapat diedit melalui menu kolom.

## Urutkan baris, filter nilai, dan atur ulang kolom

Gunakan menu kolom untuk mengurutkan baris secara menaik atau menurun, atau kembalikan urutan awal. Filter mencari teks yang cocok di seluruh tabel atau pada satu kolom yang dipilih. Untuk mengubah urutan kolom, seret pegangan kolom atau pilih perintah pindah di menu kolom. Filter mengubah tampilan dan tetap menyimpan semua baris di tabel.

## Simpan tabel yang telah diedit sebagai CSV atau TSV

Unduhan menyertakan semua baris sesuai urutan baris dan kolom saat ini. Untuk mengekspor hanya baris yang cocok dengan filter, gunakan opsi unduhan. Editor mempertahankan pemisah dan format akhir baris yang terdeteksi, serta penanda urutan byte jika ada. Nilai sel tetap berupa teks, sehingga nol di awal dan ID panjang tetap utuh setelah diedit dan diekspor.

## File yang didukung dan privasi

Editor mendukung pemisah koma, tab, titik koma, dan garis vertikal, serta bidang yang diapit tanda kutip dan sel yang berisi beberapa baris. Buka file UTF-8 atau file UTF-16 dengan penanda urutan byte. File dibaca dan diedit langsung di perangkat Anda tanpa diunggah. Unduh salinannya sebelum meninggalkan halaman agar perubahan tersimpan.
