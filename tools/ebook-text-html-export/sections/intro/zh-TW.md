## 匯出本機電子書的內容

開啟未加密的 EPUB、MOBI/AZW3 或 FB2 書籍，然後選擇 HTML 或 TXT。轉換器也可辨識支援的 AZW 與 PRC 書籍容器，以及只含一本書籍的 FBZ 與 FB2.ZIP 壓縮檔。所有處理都在您的瀏覽器中完成，無須帳號、上傳或遠端轉換服務。

## 選擇 HTML 或純文字

HTML 是可攜式的閱讀副本，包含可選取的文字、章節標題、內部連結及支援的內含圖片。TXT 以 UTF-8 保留可讀取的文字、章節分隔及安全的外部連結網址。TXT 不含圖片與格式。可用的書名與作者資訊也會一併保留。

主要章節會維持閱讀順序，可用的註腳及補充章節也會保留。導覽文件與重複的章節項目不會匯出為重複章節。若必要章節遺失，匯出會停止；若選用資源無法使用，則會明確標示，不會將不完整的內容當作完整內容呈現。

## 相容性與閱讀副本

此工具擷取內容，不會重現原始分頁。出版者樣式、互動功能、指令碼、表單、音訊、影片及遠端資源都不會重現，也不會移除 DRM。遇到受保護、固定版面及不支援的變體時，會提供說明。實際可處理的範圍取決於瀏覽器資源，沒有固定的檔案大小或章節數量限制。

如需閱讀控制項及章節導覽，請使用 [EPUB 閱讀器](/tools/epub-reader/)、[MOBI 與 AZW3 閱讀器](/tools/mobi-reader/) 或 [FB2 閱讀器](/tools/fb2-reader/)。
