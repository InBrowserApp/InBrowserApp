## 导出本地电子书的内容

打开未加密的 EPUB、MOBI/AZW3 或 FB2 书籍，然后选择 HTML 或 TXT。转换器还可识别受支持的 AZW 和 PRC 电子书容器，以及包含单本书籍的 FBZ 和 FB2.ZIP 压缩包。所有处理均在浏览器中完成，无需账号、上传或远程转换服务。

## 选择 HTML 或纯文本

HTML 是便于携带和阅读的副本，包含可选中的文本、章节标题、内部链接和受支持的内嵌图片。TXT 以 UTF-8 编码保留可读文本、章节分隔和安全的外部链接地址，不含图片和格式。可用的书名和作者信息也会保留。

正文各章保留原有阅读顺序。可用的脚注和辅助章节也会保留。导航文档和重复的章节条目不会被导出为重复章节。缺少必需章节时会停止导出；不可用的可选资源会明确标记，避免将不完整内容呈现为完整副本。

## 兼容性与阅读副本

此工具用于提取内容，不会还原原始分页。出版方样式、交互功能、脚本、表单、音频、视频和远程资源均不会保留，也不会移除 DRM。对于受保护、固定版式和不受支持的书籍变体，工具会说明原因。实际处理能力取决于浏览器资源，没有固定的文件大小或章节数量限制。

如需阅读控制和章节导航，请使用 [EPUB 阅读器](/tools/epub-reader/)、[MOBI 和 AZW3 阅读器](/tools/mobi-reader/)或 [FB2 阅读器](/tools/fb2-reader/)。
