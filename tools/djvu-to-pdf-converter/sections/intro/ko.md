## DjVu를 PDF로 변환하는 방법

`.djvu` 또는 `.djv` 파일을 선택하거나 변환기에 끌어다 놓으세요. 미리보기에서 결과를 확인한 뒤 **PDF 다운로드**를 선택하세요. 예를 들어 `library-scan.djvu`는 `library-scan.pdf`로 변환됩니다. 변환은 기기에서 진행됩니다.

## PDF에서 텍스트 검색 및 복사

DjVu 스캔에는 문서를 스캔할 때 OCR로 만든 보이지 않는 텍스트 레이어가 포함되어 있을 수 있습니다. 변환기는 이 텍스트를 PDF에 옮기고 원본 파일에 위치 정보가 있으면 해당 위치에 배치합니다. 미리보기의 **문서에서 찾기**로 단어를 검색해 보세요. 다운로드한 뒤에도 PDF 뷰어에서 텍스트를 검색하거나 복사할 수 있습니다.

텍스트 레이어가 없는 페이지는 스캔 이미지로 저장됩니다. 이런 페이지의 텍스트도 검색하려면 다운로드한 PDF를 [PDF OCR](/ko/tools/pdf-ocr/)에서 열고 문서에 사용된 언어를 선택하세요. PDF OCR은 이미 검색 가능한 텍스트가 있는 페이지를 그대로 둡니다.

## 페이지 레이아웃과 여러 파일로 나뉜 DjVu 문서

DjVu의 각 페이지는 원본 순서, 크기, 방향을 유지한 채 PDF 페이지로 변환됩니다. 삽화, 여백, 페이지 번호를 비롯한 스캔 이미지의 모양도 유지됩니다. 모든 페이지가 들어 있는 DjVu 파일을 선택하세요. 일부 오래된 자료는 색인 파일과 각 페이지 이미지를 별도 파일로 저장합니다. 이러한 자료를 변환하려면 페이지가 한 파일에 모두 들어 있는 사본을 사용하세요.
