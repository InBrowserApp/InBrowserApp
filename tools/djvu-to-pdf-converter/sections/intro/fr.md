## Comment convertir un fichier DjVu en PDF

Choisissez un fichier `.djvu` ou `.djv`, ou faites-le glisser sur le convertisseur. Vérifiez le résultat dans l’aperçu, puis cliquez sur **Télécharger le PDF**. Par exemple, `library-scan.djvu` devient `library-scan.pdf`. La conversion se fait sur votre appareil.

## Rechercher et copier du texte dans le PDF

Un document numérisé au format DjVu peut contenir une couche de texte invisible, souvent créée par reconnaissance optique de caractères (OCR) lors de la numérisation. Le convertisseur conserve ce texte et le place dans le PDF aux emplacements indiqués dans le fichier source, lorsqu’ils sont disponibles. Dans l’aperçu, utilisez **Rechercher dans le document** pour vérifier qu’un mot est accessible. Vous pouvez ensuite rechercher, sélectionner ou copier du texte dans votre lecteur PDF.

Une page sans couche de texte reste une image. Pour pouvoir y rechercher du texte, ouvrez le fichier téléchargé dans [OCR PDF](/fr/tools/pdf-ocr/) et choisissez la langue du document. OCR PDF laisse intactes les pages où le texte est déjà sélectionnable.

## Mise en page et documents DjVu en plusieurs fichiers

Chaque page du DjVu devient une page du PDF, avec les mêmes dimensions et la même orientation. L’ordre des pages, les illustrations, les marges et les numéros de page sont conservés. Choisissez un fichier DjVu qui contient toutes ses pages. Dans certaines collections anciennes, un petit fichier d’index renvoie vers des images stockées séparément. Pour convertir un document de ce type, utilisez une copie qui regroupe toutes ses pages dans un seul fichier.
