## Come convertire DjVu in PDF

Seleziona un file `.djvu` o `.djv`, oppure trascinalo nel convertitore. Controlla l’anteprima e seleziona **Scarica PDF**. Ad esempio, `library-scan.djvu` diventa `library-scan.pdf`. La conversione avviene sul tuo dispositivo.

## Cercare e copiare il testo dal PDF

Una scansione in formato DjVu può contenere un livello di testo invisibile, spesso creato con l’OCR durante la scansione del libro. Il convertitore trasferisce il testo nel PDF e lo posiziona in base alle coordinate disponibili nel file originale. Usa **Trova nel documento** nell’anteprima per verificare la presenza di una parola. Puoi poi cercare o copiare il testo nel tuo lettore PDF.

Le pagine senza un livello di testo vengono trasferite come immagini. Per renderle ricercabili, apri il PDF scaricato con [OCR PDF](/it/tools/pdf-ocr/) e seleziona la lingua del documento. Lo strumento lascia intatte le pagine che contengono già testo ricercabile.

## Impaginazione e documenti DjVu composti da più file

Ogni pagina DjVu diventa una pagina del PDF, nello stesso ordine e con le stesse dimensioni e lo stesso orientamento. Le scansioni mantengono l’aspetto originale, comprese le illustrazioni, i margini e i numeri di pagina. Scegli un file DjVu completo che contenga tutte le pagine. Alcune raccolte meno recenti usano un piccolo file indice e conservano separatamente le immagini delle pagine. Per convertire una raccolta di questo tipo, usa una copia del documento con tutte le pagine in un unico file.
