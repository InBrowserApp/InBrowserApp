## Как конвертировать DjVu в PDF

Выберите файл `.djvu` или `.djv` либо перетащите его в окно конвертера. Проверьте результат в предпросмотре и нажмите **Скачать PDF**. Например, из `library-scan.djvu` получится `library-scan.pdf`. Преобразование выполняется на вашем устройстве.

## Как найти и скопировать текст в PDF

В скане DjVu может быть невидимый текстовый слой. Обычно его добавляют при распознавании текста отсканированной книги. Конвертер переносит этот слой в PDF и сохраняет расположение текста, если оно указано в исходном файле. Нажмите **Найти в документе** в предпросмотре, чтобы проверить, находится ли нужное слово. В готовом PDF можно искать и копировать этот текст в программе для просмотра PDF.

Страницы без текстового слоя переносятся в виде сканов. Чтобы добавить на них поиск по тексту, откройте скачанный файл в инструменте [OCR для PDF](/ru/tools/pdf-ocr/) и выберите язык документа. Страницы, на которых уже есть текст для поиска, OCR для PDF пропустит.

## Вид страниц и документы DjVu из нескольких файлов

Страницы PDF сохраняют порядок, размеры и ориентацию страниц DjVu. Скан сохраняет внешний вид оригинала, включая иллюстрации, поля и номера страниц. Выберите файл DjVu, в котором содержатся все страницы. В некоторых старых коллекциях небольшой индексный файл хранит ссылки на отдельные файлы страниц. Для преобразования такой коллекции возьмите копию документа, в которой все страницы собраны в одном файле DjVu.
