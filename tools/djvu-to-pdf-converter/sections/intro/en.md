## How to convert DjVu to PDF

Choose a `.djvu` or `.djv` file, or drop it onto the converter. Check the PDF preview and select **Download PDF**. For example, `library-scan.djvu` becomes `library-scan.pdf`. Conversion runs on your device.

## Search and copy text from the PDF

A DjVu scan can contain an invisible text layer, often made by OCR when the book was scanned. The converter carries that text into the PDF and uses the text positions stored in the source when available. Use **Find in document** in the preview to check a word, then search for or copy text in your PDF reader.

A page without a text layer carries over as a scan. If you need searchable text on those pages, open the downloaded PDF in [PDF OCR](/tools/pdf-ocr/) and choose the language used in the document. PDF OCR leaves pages that already contain searchable text alone.

## Page layout and multi-file DjVu documents

Each DjVu page becomes a PDF page in its original order and with the same size and orientation. The scan keeps the appearance of the original, including illustrations, margins, and page numbers. Choose a complete DjVu file that contains all its pages. Some older collections use a small index file with the page images stored separately. Use a bundled copy of the document to convert that kind of collection.
