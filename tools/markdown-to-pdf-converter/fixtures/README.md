# Markdown PDF fixtures

`field-manual.md` is an original repository-owned fixture covering headings,
Unicode, nested task lists, strikethrough, tables, code, a closed disclosure and
an embedded PNG. The four-color PNG is an original 160 × 80 test image. No network or companion files are needed.

Browser acceptance verifies checked/unchecked task labels and expanded details
in the generated PDF as well as pagination, A4 bounds and image rendering.
