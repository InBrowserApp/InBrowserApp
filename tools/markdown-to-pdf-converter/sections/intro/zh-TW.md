## 在本機轉換 Markdown 文件

開啟本機的 `.md`、`.markdown`、`.mdown` 或 `.txt` 文件，檢查產生的頁面，再下載預覽中顯示的 PDF。此工具會直接產生 PDF 檔案，無需開啟列印對話方塊。支援 UTF-8 與帶有 BOM 標記的 UTF-16 原始文件。如需閱讀或編輯原始內容，請使用 [Markdown 預覽器](../markdown-previewer/)。

## 列印結果與支援的原始內容

支援標準 Markdown，以及 GitHub 風格的表格、工作清單、刪除線與圍欄程式碼區塊。文件會使用固定的列印主題，繪製至邊界為 18 mm 的 A4 直向頁面，再以 150 DPI 擷取為圖片頁面。工作清單的勾選狀態會保留，收合的詳細內容會展開。較寬的表格與程式碼會依頁面寬度重新排版。無法選取 PDF 中的文字，也不會加入 OCR 或互動連結。字型、間距與分頁可能與其他 Markdown 工具不同。使用輸出結果前，請檢查每一頁。

缺少圖片資源或內嵌圖片無法讀取時，轉換會停止，且不會提供不完整的檔案供下載。請使用內嵌點陣圖片，讓文件本身包含所需內容。內嵌 HTML 會經過淨化；指令碼、樣式、表單、嵌入式應用程式、SVG 與 MathML 會省略。不會呈現語法醒目提示、數學公式、圖表、註腳與其他方言擴充語法；不支援的語法可能會保留為文字。

## 隱私與瀏覽器資源

您的文件會留在此瀏覽器中。工具不會從您的電腦或網路取得圖片及其他資源，也不會上傳檔案內容。內嵌點陣圖片資料會從選取的文件中讀取。由於每一頁都會繪製為圖片，大型檔案可能需要較多時間與記憶體。您可以取消轉換、關閉或更換文件。工具沒有固定的檔案大小或頁數限制；若能偵測到實際的瀏覽器資源不足，便會顯示錯誤。
