## Markdown 문서를 로컬에서 변환하기

로컬 `.md`, `.markdown`, `.mdown` 또는 `.txt` 문서를 열고 생성된 페이지를 확인한 다음 미리보기에 표시된 PDF를 다운로드하세요. 인쇄 대화상자 없이 PDF 파일을 직접 생성합니다. UTF-8과 바이트 순서 표시(BOM)가 있는 UTF-16 소스를 지원합니다. 소스를 읽거나 편집하려면 [Markdown 미리보기](../markdown-previewer/)를 사용하세요.

## 인쇄 결과와 지원하는 소스

표준 Markdown과 GitHub 스타일의 표, 작업 목록, 취소선, 펜스 코드 블록을 지원합니다. 문서는 고정된 인쇄 테마로 여백이 18 mm인 A4 세로 페이지에 렌더링된 후 150 DPI 이미지 페이지로 캡처됩니다. 작업의 체크 상태가 표시되며 접힌 상세 내용은 펼쳐집니다. 너비가 넓은 표와 코드는 페이지 너비에 맞게 재배치됩니다. PDF의 텍스트는 선택할 수 없으며 OCR과 대화형 링크는 추가되지 않습니다. 글꼴, 간격 및 페이지 나누기가 다른 Markdown 도구와 다를 수 있습니다. 결과를 사용하기 전에 모든 페이지를 확인하세요.

이미지 리소스가 없거나 문서에 포함된 이미지를 읽을 수 없으면 변환이 중단되며 불완전한 파일은 다운로드할 수 없습니다. 외부 파일에 의존하지 않는 문서에 래스터 이미지를 포함하세요. 인라인 HTML은 안전하게 정리되며 스크립트, 스타일, 양식, 삽입된 앱, SVG 및 MathML은 제외됩니다. 구문 강조, 수식, 다이어그램, 각주 및 기타 Markdown 확장 문법은 렌더링되지 않으며 지원하지 않는 표기법은 텍스트로 남을 수 있습니다.

## 개인정보 보호와 브라우저 리소스

문서는 이 브라우저 안에만 유지됩니다. 이미지와 기타 리소스를 컴퓨터나 네트워크에서 가져오지 않으며 파일 내용은 업로드되지 않습니다. 포함된 래스터 데이터는 선택한 문서에서 읽습니다. 각 페이지를 이미지로 렌더링하므로 큰 파일은 시간과 메모리가 많이 필요할 수 있습니다. 변환을 취소하거나 문서를 닫거나 바꿀 수 있습니다. 고정된 파일 크기 또는 페이지 수 제한은 없으며 실제 브라우저 리소스 부족을 감지할 수 있으면 오류를 표시합니다.
