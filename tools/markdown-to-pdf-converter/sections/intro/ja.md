## Markdown 文書をローカルで変換

ローカルの `.md`、`.markdown`、`.mdown` または `.txt` 文書を開き、生成されたページを確認して、プレビューに表示された PDF をダウンロードできます。PDF ファイルを直接生成するため、印刷ダイアログは不要です。UTF-8 と BOM 付き UTF-16 のソースに対応しています。ソースを読んだり編集したりする場合は、[Markdown プレビューアー](../markdown-previewer/)をご利用ください。

## 印刷結果と対応するソース

標準の Markdown と、GitHub 形式の表、タスクリスト、取り消し線、フェンス付きコードブロックに対応しています。文書は固定の印刷テーマで余白 18 mm の A4 縦向きページに描画され、150 DPI の画像ページとして取り込まれます。タスクの状態は表示され、折りたたまれた詳細は展開されます。幅の広い表やコードはページ幅に合わせて再配置されます。PDF 内のテキストは選択できず、OCR や操作可能なリンクは追加されません。フォント、間隔、改ページは他の Markdown ツールと異なる場合があります。出力を利用する前に、すべてのページを確認してください。

画像リソースが不足している場合や埋め込み画像を読み取れない場合は、変換が停止し、不完全なファイルはダウンロードできません。単一ファイルで完結する文書にラスター画像を埋め込んでください。インライン HTML はサニタイズされ、スクリプト、スタイル、フォーム、埋め込みアプリ、SVG、MathML は省かれます。構文ハイライト、数式、図、脚注、その他の方言拡張はレンダリングされず、未対応の記法がテキストとして残る場合があります。

## プライバシーとブラウザーのリソース

文書はこのブラウザー内に留まります。画像やその他のアセットをコンピューターやネットワークから取得することはなく、ファイルの内容がアップロードされることもありません。埋め込みのラスターデータは選択した文書から読み取ります。各ページを画像として描画するため、大きなファイルには時間とメモリが必要になることがあります。変換のキャンセル、文書を閉じる操作、別の文書への切り替えが可能です。ファイルサイズやページ数に固定の上限はありません。ブラウザーのリソース不足を検出できた場合は、エラーを表示します。
