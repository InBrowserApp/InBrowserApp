## Konversi dokumen Markdown secara lokal

Buka dokumen lokal `.md`, `.markdown`, `.mdown`, atau `.txt`, periksa halaman yang dihasilkan, lalu unduh PDF yang ditampilkan dalam pratinjau. Alat ini menghasilkan file PDF secara langsung; dialog cetak tidak diperlukan. Sumber UTF-8 dan UTF-16 dengan penanda BOM didukung. Untuk membaca atau menyunting sumber, gunakan [Pratinjau Markdown](../markdown-previewer/).

## Hasil cetak dan sumber yang didukung

Markdown standar serta tabel bergaya GitHub, daftar tugas, teks coret, dan blok kode berpagar didukung. Dokumen dirender dengan tema cetak tetap pada halaman A4 berorientasi potret dengan margin 18 mm, lalu diambil sebagai halaman gambar pada 150 DPI. Status tugas tetap terlihat, dan bagian detail yang dilipat dibuka. Tabel dan kode yang lebar ditata ulang sesuai lebar halaman. Teks dalam PDF tidak dapat dipilih, dan OCR serta tautan interaktif tidak ditambahkan. Font, spasi, dan pembagian halaman mungkin berbeda dari alat Markdown lainnya. Periksa setiap halaman sebelum mengandalkan hasilnya.

Sumber daya gambar yang hilang dan gambar tersemat yang tidak dapat dibaca menghentikan konversi tanpa unduhan parsial. Gunakan gambar raster tersemat dalam dokumen yang lengkap dalam satu file. HTML inline disanitasi; skrip, gaya, formulir, aplikasi tersemat, SVG, dan MathML dihilangkan. Penyorotan sintaks, rumus matematika, diagram, catatan kaki, dan ekstensi dialek lainnya tidak dirender; notasi yang tidak didukung dapat tetap ditampilkan sebagai teks.

## Privasi dan sumber daya browser

Dokumen Anda tetap di browser ini. Gambar dan aset lainnya tidak pernah diambil dari komputer Anda atau jaringan, dan konten file tidak pernah diunggah. Data raster tersemat dibaca dari dokumen yang dipilih. File besar dapat membutuhkan waktu dan memori karena setiap halaman dirender sebagai gambar. Anda dapat membatalkan, menutup, atau mengganti dokumen. Tidak ada batas tetap untuk ukuran file atau jumlah halaman; kegagalan sumber daya browser yang sebenarnya akan menghasilkan pesan kesalahan jika dapat dideteksi.
