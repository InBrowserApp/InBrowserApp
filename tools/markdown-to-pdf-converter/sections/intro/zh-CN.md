## 在本地转换 Markdown 文档

打开本地 `.md`、`.markdown`、`.mdown` 或 `.txt` 文档，检查生成的页面，然后下载预览中显示的 PDF。本工具直接生成 PDF 文件，无需打开打印对话框。支持 UTF-8 和带 BOM 标记的 UTF-16 源文件。如需阅读或编辑源文本，请使用 [Markdown 预览器](../markdown-previewer/)。

## 打印结果与支持的源内容

支持标准 Markdown 以及 GitHub 风格的表格、任务列表、删除线和围栏代码块。文档采用固定的打印主题，在页边距为 18 mm 的 A4 纵向页面上排版，再以 150 DPI 捕获为图像页面。任务勾选状态仍然可见，折叠的详情内容会展开。较宽的表格和代码会按页面宽度重新排版。PDF 中的文本不可选择，不进行 OCR，也不添加交互链接。字体、间距和分页可能与其他 Markdown 工具不同。使用输出文件前，请检查每一页。

缺失图片资源或无法读取的嵌入图片会使转换停止，且不会提供不完整的文件供下载。请使用嵌入位图图片的自包含文档。内联 HTML 会经过净化处理；脚本、样式、表单、嵌入式应用、SVG 和 MathML 会被省略。不渲染语法高亮、数学公式、图表、脚注及其他方言扩展；不受支持的标记可能以文本形式保留。

## 隐私与浏览器资源

文档仅在此浏览器中处理。不会从你的计算机或网络获取图片及其他资源，也绝不会上传文件内容。嵌入的位图数据直接从所选文档中读取。由于每一页都需要渲染为图像，大文件可能需要较多时间和内存。你可以取消转换、关闭或更换文档。不设固定的文件大小或页数上限；检测到实际的浏览器资源不足时，会显示错误。
