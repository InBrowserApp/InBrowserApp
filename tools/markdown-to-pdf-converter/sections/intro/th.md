## แปลงเอกสาร Markdown บนอุปกรณ์

เปิดเอกสาร `.md`, `.markdown`, `.mdown` หรือ `.txt` บนอุปกรณ์ ตรวจสอบหน้าที่สร้างขึ้น แล้วดาวน์โหลด PDF ที่แสดงในตัวอย่าง เครื่องมือนี้สร้างไฟล์ PDF โดยตรงโดยไม่ต้องเปิดกล่องโต้ตอบการพิมพ์ รองรับซอร์สแบบ UTF-8 และ UTF-16 ที่มีเครื่องหมาย BOM หากต้องการอ่านหรือแก้ไขซอร์ส ให้ใช้ [โปรแกรมดูตัวอย่าง Markdown](../markdown-previewer/)

## ผลลัพธ์การพิมพ์และซอร์สที่รองรับ

รองรับ Markdown มาตรฐาน รวมถึงตาราง รายการงาน ข้อความขีดฆ่า และบล็อกโค้ดแบบ fenced ตามรูปแบบ GitHub เอกสารจะแสดงด้วยธีมสำหรับพิมพ์แบบตายตัวบนหน้ากระดาษ A4 แนวตั้งที่มีระยะขอบ 18 มม. แล้วบันทึกเป็นหน้าภาพที่ความละเอียด 150 DPI สถานะงานยังคงมองเห็นได้ และส่วนรายละเอียดที่ยุบไว้จะถูกขยาย ตารางและโค้ดที่กว้างจะถูกจัดวางใหม่ให้พอดีกับความกว้างของหน้า เลือกข้อความใน PDF ไม่ได้ และไม่มีการเพิ่ม OCR หรือลิงก์แบบโต้ตอบ แบบอักษร ระยะห่าง และการแบ่งหน้าอาจต่างจากเครื่องมือ Markdown อื่น ตรวจสอบทุกหน้าก่อนนำผลลัพธ์ไปใช้งาน

หากขาดทรัพยากรรูปภาพหรืออ่านรูปภาพที่ฝังไว้ไม่ได้ การแปลงจะหยุดลงโดยไม่มีไฟล์บางส่วนให้ดาวน์โหลด ใช้รูปภาพแรสเตอร์ที่ฝังไว้ในเอกสารที่รวมทุกอย่างไว้ในไฟล์เดียว HTML แบบ inline จะถูกกรองให้ปลอดภัย สคริปต์ สไตล์ แบบฟอร์ม แอปที่ฝังไว้ SVG และ MathML จะถูกละไว้ ไม่มีการแสดงผลการเน้นสีไวยากรณ์ คณิตศาสตร์ แผนภาพ เชิงอรรถ และส่วนขยายรูปแบบอื่น ๆ สัญกรณ์ที่ไม่รองรับอาจยังปรากฏเป็นข้อความ

## ความเป็นส่วนตัวและทรัพยากรเบราว์เซอร์

เอกสารของคุณอยู่ในเบราว์เซอร์นี้ ไม่มีการดึงรูปภาพและทรัพยากรอื่นจากคอมพิวเตอร์หรือเครือข่าย และไม่มีการอัปโหลดเนื้อหาไฟล์ ข้อมูลภาพแรสเตอร์ที่ฝังไว้จะอ่านจากเอกสารที่เลือก ไฟล์ขนาดใหญ่อาจใช้เวลาและหน่วยความจำมากเพราะแต่ละหน้าถูกแสดงเป็นภาพ คุณสามารถยกเลิก ปิด หรือเปลี่ยนเอกสารได้ ไม่มีโควตาขนาดไฟล์หรือจำนวนหน้าแบบตายตัว หากตรวจพบว่าทรัพยากรเบราว์เซอร์ไม่เพียงพอจริง ระบบจะแสดงข้อผิดพลาด
