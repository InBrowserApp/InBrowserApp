## Comment recadrer une image

Choisissez ou déposez une image locale, puis faites glisser la sélection ou ses poignées. Utilisez Libre pour un rapport quelconque, Original pour conserver les proportions de l’image, ou un préréglage comme 1:1, 4:3 ou 16:9. Les champs en pixels permettent de saisir précisément la position et la taille de la sélection. Faites pivoter l’image par pas de 90°, retournez-la horizontalement ou verticalement, puis sélectionnez Recadrer l’image pour prévisualiser et télécharger le résultat.

## Qualité et confidentialité

Tout s’exécute dans votre navigateur ; le contenu des images n’est jamais envoyé. L’aperçu s’adapte à votre écran, tandis que les exports utilisent les pixels de l’image d’origine sans agrandissement. Le PNG préserve la transparence ; le JPEG utilise un fond blanc ; le WebP prend en charge la transparence et une qualité réglable. Si le navigateur ne peut pas encoder le format sélectionné, le téléchargement utilise le format réellement produit.

## Remarques sur les formats

La lecture des formats PNG, JPEG, WebP, AVIF, GIF et BMP dépend des capacités de décodage de votre navigateur. Les images animées produisent une seule image fixe. Les exports ne conservent ni les métadonnées d’origine, ni l’animation, ni toutes les informations du profil colorimétrique. Les très grandes images peuvent dépasser la mémoire disponible dans le navigateur. Utilisez le Redimensionneur d’images pour changer la taille de l’image entière plutôt que de sélectionner une zone.
