## How to compress an image to 200 KB

If an application form accepts images up to 200 KB each, enter **200** in **Maximum size per image** and choose the file format the form accepts. Add your photos and select **Compress images**. The tool adjusts image quality and checks the actual file size of each result. Download a single image or a ZIP of the files that meet the limit. In this tool, 200 KB means 200,000 bytes.

## Resize to exact dimensions and a file size limit

For a form that requires a **600 × 600 pixel JPG up to 200 KB**, choose **JPG**, set the maximum to **200 KB**, and select **Exact width and height**. Enter **600** for both measurements. The tool keeps the output at 600 × 600 pixels as it adjusts quality. If the form specifies pixel dimensions only, clear the size limit.

Select the chain icon between width and height to link the two values. The lock uses the entered ratio, or the first image’s ratio when a dimension is empty.

Choose **Fit whole image (pad edges)** to keep the entire photo. Extra space is white in JPG and transparent in WebP. Choose **Fill and crop edges** to fill the frame without stretching the image. Check the result thumbnail to see how the frame fits.

## What to do if an image is still over the limit

When the form specifies a file size only, choose **Shrink if needed** so the tool can reduce pixel dimensions proportionally. When dimensions are fixed, try WebP if the form accepts it. The results show the output size and pixel dimensions for each image so you can verify them before uploading. Images are processed in your browser.
