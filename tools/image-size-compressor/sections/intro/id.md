## Cara mengompres gambar ke 200 KB

Jika formulir pendaftaran menerima file gambar hingga 200 KB per gambar, masukkan **200** di kolom **Ukuran file maksimum per gambar** dan pilih format yang diterima formulir. Tambahkan foto, lalu pilih **Kompres gambar**. Alat ini menyesuaikan kualitas dan memeriksa ukuran file setiap hasil. Unduh gambar satu per satu atau unduh semua file yang memenuhi batas dalam satu ZIP. Di alat ini, 200 KB sama dengan 200.000 byte.

## Atur dimensi piksel dan batas ukuran file sekaligus

Jika formulir meminta **gambar JPG 600 × 600 piksel hingga 200 KB**, pilih **JPG**, atur batas ke **200 KB**, lalu pilih **Lebar dan tinggi yang ditentukan**. Masukkan **600** di kedua kolom. Alat ini menjaga dimensi keluaran tetap 600 × 600 piksel sembari menyesuaikan kualitas. Jika formulir hanya menentukan dimensi piksel, kosongkan kolom batas ukuran file.

Pilih **Tampilkan seluruh gambar (dengan ruang tepi)** agar foto tetap utuh. Ruang yang tersisa berwarna putih di JPG dan transparan di WebP. Pilih **Isi bingkai dan potong tepi** agar bingkai terisi penuh tanpa meregangkan gambar. Lihat gambar mini di hasil untuk memeriksa penempatannya dalam bingkai.

## Apa yang bisa dilakukan jika ukuran file masih melebihi batas?

Jika formulir hanya membatasi ukuran file, pilih **Perkecil dimensi bila perlu** agar alat ini bisa mengurangi dimensi piksel secara proporsional. Jika dimensi sudah ditentukan, coba WebP bila formulir menerimanya. Hasilnya menampilkan ukuran file dan dimensi piksel setiap gambar agar Anda dapat memeriksanya sebelum mengunggah. Gambar diproses di browser Anda.
