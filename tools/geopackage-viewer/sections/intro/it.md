## Come aprire un GeoPackage

Scegli o trascina un file .gpkg, poi usa **Layer o tabella** per selezionarne i contenuti. Seleziona **Prova un esempio** per aprire un pacchetto con un layer di punti e uno di poligoni. Il GeoPackage viene aperto sul tuo dispositivo. Dopo il caricamento della pagina, la mappa offline integrata funziona senza richiedere tasselli a un servizio online.

## Esplorare i layer vettoriali e gli attributi

La mappa inquadra il layer vettoriale selezionato. Fai clic su un punto, una linea o un poligono, oppure selezionalo nell’elenco **Elementi geografici** per consultarne gli attributi. Se il layer dichiara un sistema di riferimento delle coordinate supportato, il visualizzatore posiziona gli elementi in WGS 84. Puoi anche scegliere una tabella non spaziale e sfogliarne i record. L’anteprima mostra fino a 500 record per layer, così la mappa resta reattiva anche con file di grandi dimensioni.

## Cosa contiene un GeoPackage

GeoPackage è un formato OGC che memorizza i dati spaziali in un unico file SQLite. Un pacchetto può contenere più layer vettoriali, normali tabelle degli attributi e tabelle di tasselli. Le voci con tasselli compaiono nell’elenco dei layer. Scegli un layer vettoriale per vedere le geometrie sulla mappa. Se hai uno Shapefile Esri con file associati separati, usa il [Visualizzatore Shapefile](../shapefile-viewer/).
