## Lire un document Word dans votre navigateur

Ouvrez ou déposez un fichier Word 97–2003 `.doc` ou un fichier `.docx`, `.docm`, `.dotx` ou `.dotm`. Les fichiers DOC s’affichent en lecture continue avec zoom, sélection du texte et plan si les titres sont reconnus. Les formats récents permettent de naviguer entre les pages, de rechercher dans le document et de l’exporter en Markdown.

## Compatibilité et outils associés

Les documents restent dans votre navigateur. Les macros et les ressources externes sont désactivées. Les polices et les mises en forme complexes peuvent différer de l’original. Pour ouvrir un fichier chiffré, utilisez une copie non chiffrée.

Pour générer un PDF, utilisez le [convertisseur Microsoft Word en PDF](../microsoft-word-to-pdf-converter/). Pour les documents `.wps` et les modèles `.wpt`, utilisez la [visionneuse WPS](../wps-viewer/).
