## Leia um documento do Word no navegador

Abra ou arraste um arquivo `.doc` do Word 97–2003 ou um arquivo `.docx`, `.docm`, `.dotx` ou `.dotm`. Os arquivos DOC são exibidos em um layout de leitura contínua, com zoom, texto selecionável e uma estrutura do documento quando há títulos. Os formatos mais recentes permitem navegar entre páginas, pesquisar e exportar para Markdown.

## Compatibilidade e ferramentas relacionadas

Os documentos ficam no navegador. Macros e recursos externos são desativados. As fontes e a formatação complexa podem diferir do original. Para abrir um arquivo criptografado, use uma cópia sem criptografia.

Para gerar um PDF, use o [Conversor de Microsoft Word para PDF](../microsoft-word-to-pdf-converter/). Para documentos `.wps` e modelos `.wpt`, use o [Visualizador de WPS](../wps-viewer/).
