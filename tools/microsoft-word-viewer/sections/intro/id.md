## Baca dokumen Word di browser Anda

Buka atau letakkan file Word 97–2003 `.doc`, atau file `.docx`, `.docm`, `.dotx`, atau `.dotm` di sini. File DOC ditampilkan dalam tata letak berkelanjutan dengan opsi untuk mengubah skala dan memilih teks. Jika judul bagian terdeteksi, Anda dapat menavigasi lewat kerangka dokumen. Format yang lebih baru mendukung navigasi halaman, pencarian, dan ekspor Markdown.

## Kompatibilitas dan alat terkait

Dokumen tetap berada di browser Anda. Makro dan sumber daya eksternal dinonaktifkan. Font dan pemformatan yang rumit mungkin tampak berbeda dari aslinya. Untuk file terenkripsi, gunakan salinan yang tidak terenkripsi.

Untuk membuat PDF, gunakan [Konverter Microsoft Word ke PDF](../microsoft-word-to-pdf-converter/). Untuk dokumen `.wps` dan templat `.wpt`, gunakan [Penampil WPS](../wps-viewer/).
