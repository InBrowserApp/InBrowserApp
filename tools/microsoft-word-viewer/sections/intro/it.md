## Leggi un documento Word nel browser

Apri o trascina un file Word 97–2003 `.doc` oppure un file `.docx`, `.docm`, `.dotx` o `.dotm`. I file DOC si aprono in una vista continua con zoom, testo selezionabile e un indice quando sono presenti titoli. I formati più recenti supportano la navigazione tra le pagine, la ricerca e l’esportazione in Markdown.

## Compatibilità e strumenti correlati

I documenti restano nel browser. Le macro e le risorse esterne sono disattivate. I caratteri e la formattazione complessa possono differire dall’originale. Per aprire un file crittografato serve una copia non crittografata.

Per generare un PDF, usa il [Convertitore da Microsoft Word a PDF](../microsoft-word-to-pdf-converter/). Per i documenti `.wps` e i modelli `.wpt`, usa il [Visualizzatore WPS](../wps-viewer/).
