## Como transferir arquivos pela rede local

Abra Transferência de arquivos na rede local nos dois dispositivos conectados à mesma rede Wi-Fi ou cabeada. No primeiro, escolha **Enviar deste dispositivo**. No segundo, escaneie o código QR de convite com a câmera ou abra o link de convite. O segundo dispositivo vai exibir uma resposta. Escaneie a resposta na tela do convite do primeiro dispositivo ou cole o código de resposta nessa tela.

Depois de conectar os dispositivos, você pode enviar arquivos, links ou texto simples nos dois sentidos. Por exemplo, envie um PDF do notebook para o celular e mande um endereço do celular para o notebook na mesma sessão. Escolha ou solte um arquivo e selecione **Enviar arquivo**. No dispositivo que recebeu o conteúdo, selecione **Baixar** para salvar o arquivo ou **Copiar texto** para usar a mensagem em outro aplicativo.

## Por onde passam seus arquivos e textos

O WebRTC criptografa os dados e os transfere diretamente entre os navegadores. O link de convite e o código de resposta incluem os dados necessários para estabelecer a conexão. Compartilhe essas informações só com a pessoa com quem você quer se conectar. A ferramenta funciona sem serviço de sinalização, servidor de upload ou retransmissor. Mantenha as duas páginas abertas até o fim da transferência.

## Se os dispositivos não se conectarem

Redes Wi-Fi de convidados e algumas redes de escritório impedem que os dispositivos se comuniquem entre si mesmo quando estão no mesmo Wi-Fi. Tente usar uma rede privada que permita a comunicação entre eles. Se a câmera não estiver disponível, troque o link de convite e o código de resposta por um aplicativo de mensagens ou outro dispositivo.

## Arquivos grandes e transferências interrompidas

A integridade dos arquivos é verificada bloco a bloco com SHA-256. Os dados são gravados no armazenamento local do navegador que recebe o arquivo. O espaço disponível nesse navegador determina o tamanho dos arquivos que você pode receber. Baixe cada arquivo ao final da transferência para guardar uma cópia.

Se a conexão cair, mantenha as duas abas originais abertas e emparelhe os dispositivos de novo. Selecione **Retomar transferência do arquivo** para continuar a partir do último bloco verificado. Na aba receptora, escaneie ou cole o novo convite dentro da ferramenta para manter a página aberta.
