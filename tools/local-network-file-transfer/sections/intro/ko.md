## 로컬 네트워크에서 파일을 전송하는 방법

두 기기를 같은 Wi-Fi 또는 유선 네트워크에 연결하고 양쪽에서 로컬 네트워크 파일 전송을 여세요. 첫 번째 기기에서 **이 기기에서 보내기**를 선택합니다. 두 번째 기기의 카메라 앱으로 초대 QR 코드를 스캔하거나 초대 링크를 엽니다. 그러면 두 번째 기기에 응답이 표시됩니다. 첫 번째 기기의 초대 화면에서 QR 코드를 스캔하거나 응답 코드를 붙여넣으세요.

연결되면 어느 기기에서든 파일, 웹 링크 또는 일반 텍스트를 보낼 수 있습니다. 예를 들어 노트북에서 휴대폰으로 PDF를 보내고 같은 연결에서 주소를 노트북으로 다시 보내 복사할 수 있습니다. 파일을 선택하거나 끌어 놓은 다음 **파일 보내기**를 선택하세요. 받는 기기에서 **다운로드**를 선택해 파일을 저장하거나 **텍스트 복사**를 선택해 다른 앱에서 메시지를 사용할 수 있습니다.

## 파일과 텍스트의 전송 경로

WebRTC는 전송을 암호화하고 두 브라우저 사이에 데이터를 직접 보냅니다. 초대장과 응답은 연결을 설정하며 연결 정보가 포함되어 있으므로 연결하려는 사람에게만 공유하세요. 이 도구는 시그널링 서비스, 파일 업로드 서버 또는 중계 서버를 사용하지 않습니다. 전달이 끝날 때까지 두 페이지를 열어 두세요.

## 기기를 연결할 수 없는 경우

게스트 Wi-Fi와 일부 사무실 네트워크는 기기가 같은 Wi-Fi에 연결되어 있어도 기기 간 통신을 차단합니다. 기기 간 통신이 허용되는 개인 네트워크를 사용해 보세요. 카메라를 사용할 수 없다면 메시지 앱이나 다른 기기를 통해 초대 링크와 응답 코드를 주고받을 수 있습니다. 최대 128 MiB의 파일은 다운로드할 때까지 수신 탭의 메모리에 보관됩니다. 다른 파일을 받거나 페이지를 닫기 전에 파일을 저장하세요.
