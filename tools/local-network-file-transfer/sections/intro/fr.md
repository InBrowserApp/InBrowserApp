## Comment transférer des fichiers sur votre réseau local

Ouvrez Transfert de fichiers sur le réseau local sur les deux appareils connectés au même réseau Wi-Fi ou filaire. Sur le premier, choisissez **Envoyer depuis cet appareil**. Sur le second, scannez le QR code d’invitation avec l’appareil photo ou ouvrez le lien d’invitation. Le second appareil affiche alors une réponse. Sur le premier appareil, scannez la réponse depuis l’écran d’invitation ou collez-y le code de réponse.

Une fois la connexion établie, chacun des appareils peut envoyer un fichier, un lien web ou du texte brut. Vous pouvez, par exemple, envoyer un PDF de votre ordinateur portable vers votre téléphone, puis renvoyer une adresse vers votre ordinateur lors de la même session. Choisissez ou déposez un fichier, puis sélectionnez **Envoyer le fichier**. Sur l’appareil de réception, choisissez **Télécharger** pour enregistrer le fichier ou **Copier le texte** pour réutiliser un message dans une autre application.

## Où vont vos fichiers et votre texte

WebRTC chiffre les données et les transfère directement d’un navigateur à l’autre. Le lien d’invitation et le code de réponse contiennent les informations nécessaires à la connexion. Partagez-les uniquement avec la personne à qui vous souhaitez vous connecter. L’outil fonctionne sans service de signalisation, serveur de dépôt ou relais. Laissez les deux pages ouvertes jusqu’à la fin du transfert.

## Si les appareils ne se connectent pas

Les réseaux Wi-Fi invités et certains réseaux d’entreprise empêchent les appareils de communiquer entre eux, même s’ils sont sur le même Wi-Fi. Essayez un réseau privé où les appareils peuvent se joindre. Si la caméra est indisponible, échangez le lien d’invitation et le code de réponse via une messagerie ou un autre appareil.

## Fichiers volumineux et transferts interrompus

L’intégrité des fichiers est vérifiée bloc par bloc avec SHA-256. Les données sont enregistrées dans le stockage local du navigateur qui reçoit le fichier. L’espace disponible dans ce navigateur détermine la taille des fichiers que vous pouvez recevoir. Téléchargez chaque fichier une fois le transfert terminé pour en garder une copie.

Si la connexion est interrompue, laissez les deux onglets d’origine ouverts et associez à nouveau les appareils. Sélectionnez **Reprendre le transfert** pour continuer à partir du dernier bloc vérifié. Dans l’onglet de réception, scannez ou collez la nouvelle invitation directement dans l’outil pour garder la page ouverte.
