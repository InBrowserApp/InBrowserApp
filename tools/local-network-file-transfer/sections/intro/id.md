## Cara mengirim file lewat jaringan lokal

Buka Transfer File di Jaringan Lokal di kedua perangkat saat keduanya terhubung ke jaringan Wi-Fi atau kabel yang sama. Di perangkat pertama, pilih **Kirim dari perangkat ini**. Di perangkat kedua, pindai kode QR undangan dengan aplikasi kamera atau buka tautan undangan. Perangkat kedua akan menampilkan balasan. Gunakan pemindai di layar undangan pada perangkat pertama untuk memindai balasan tersebut, atau tempel kode balasannya di sana.

Setelah terhubung, kedua perangkat bisa mengirim file, tautan web, atau teks biasa. Misalnya, kirim PDF dari laptop ke ponsel, lalu kirim alamat dari ponsel dan salin di laptop dalam sesi yang sama. Pilih atau seret file ke area pengiriman, lalu pilih **Kirim file**. Di perangkat penerima, pilih **Unduh** untuk menyimpan file atau **Salin teks** untuk menggunakan pesan di aplikasi lain.

## Ke mana file dan teks dikirim

WebRTC mengenkripsi data yang dikirim langsung dari satu browser ke browser lain. Undangan dan balasan berisi detail untuk membuat koneksi. Bagikan hanya dengan orang yang ingin Anda hubungkan ke perangkat Anda. Alat ini tidak menggunakan layanan pensinyalan, server unggahan file, atau server perantara. Biarkan kedua halaman tetap terbuka sampai pengiriman selesai.

## Jika perangkat tidak bisa terhubung

Wi-Fi tamu dan beberapa jaringan kantor mencegah perangkat saling terhubung meski menggunakan Wi-Fi yang sama. Coba jaringan privat yang mengizinkan koneksi antarperangkat. Jika kamera tidak bisa digunakan, tukarkan tautan undangan dan kode balasan lewat aplikasi pesan atau perangkat lain.

## File besar dan transfer yang terputus

Setiap blok file diperiksa dengan SHA-256 lalu ditulis ke penyimpanan lokal browser penerima. Ukuran file yang bisa diterima bergantung pada ruang penyimpanan yang tersedia di browser. Unduh setiap file yang sudah selesai diterima untuk menyimpan salinannya.

Jika koneksi terputus, biarkan kedua tab yang tadi digunakan tetap terbuka dan pasangkan kembali perangkat. Pilih **Lanjutkan transfer file** untuk meneruskan transfer dari blok terakhir yang sudah diperiksa. Di tab penerima, pindai atau tempel undangan baru di dalam alat ini agar halaman tetap terbuka.
