## איך להעביר קבצים ברשת המקומית

פתחו את הכלי ״העברת קבצים ברשת המקומית״ בשני מכשירים שמחוברים לאותה רשת Wi-Fi או לאותה רשת קווית. במכשיר הראשון בחרו **שליחה מהמכשיר הזה**. במכשיר השני סרקו את קוד ה-QR של ההזמנה באפליקציית המצלמה או פתחו את הקישור להזמנה. המכשיר השני יציג תשובה. במסך ההזמנה של המכשיר הראשון, סרקו את הקוד שהתקבל או הדביקו את קוד התשובה.

אחרי החיבור אפשר לשלוח קובץ, קישור או טקסט רגיל מכל אחד מהמכשירים. לדוגמה, תוכלו להעביר PDF מהמחשב הנייד לטלפון ולשלוח כתובת מהטלפון בחזרה למחשב באותו חיבור. בחרו או גררו קובץ, ואז בחרו **שליחת קובץ**. במכשיר המקבל בחרו **הורדה** כדי לשמור את הקובץ או **העתקת הטקסט** כדי להשתמש בהודעה באפליקציה אחרת.

## לאן הקבצים והטקסט מגיעים?

WebRTC מצפינה את הנתונים ומעבירה אותם ישירות בין שני הדפדפנים. ההזמנה והתשובה משמשות ליצירת החיבור. הן מכילות פרטי חיבור, ולכן שתפו אותן רק עם מי שרוצים להתחבר אליו. הכלי פועל בלי שירות איתות, שרת להעלאת קבצים או שרת ממסר. השאירו את שני הדפים פתוחים עד לסיום ההעברה.

## מה לעשות אם המכשירים לא מתחברים?

רשתות Wi-Fi לאורחים וחלק מהרשתות במקומות עבודה מונעות תקשורת ישירה בין מכשירים, גם כשהם מחוברים לאותה רשת Wi-Fi. נסו רשת פרטית שמאפשרת תקשורת בין המכשירים. אם אין גישה למצלמה, העבירו את הקישור להזמנה ואת קוד התשובה באפליקציית הודעות או בעזרת מכשיר אחר.

## קבצים גדולים והעברות שנקטעו

הכלי מאמת כל מקטע של הקובץ באמצעות SHA-256 ושומר את המקטעים באחסון המקומי של הדפדפן המקבל. שטח האחסון הזמין לדפדפן קובע מה גודל הקובץ המרבי שאפשר לקבל. הורידו כל קובץ שהתקבל במלואו כדי לשמור עותק שלו.

אם החיבור מתנתק, השאירו את שתי הלשוניות המקוריות פתוחות והתחברו מחדש. בחרו **המשך העברת הקובץ** כדי להמשיך מהמקטע האחרון שאומת. בלשונית המקבלת, סרקו את קוד ההזמנה החדשה מתוך הכלי או הדביקו בו את הקישור, כדי להשאיר את הדף פתוח.
