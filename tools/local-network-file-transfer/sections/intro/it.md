## Come trasferire file sulla rete locale

Apri Trasferimento di file in rete locale su entrambi i dispositivi connessi alla stessa rete Wi-Fi o cablata. Sul primo dispositivo, scegli **Invia da questo dispositivo**. Sul secondo, scansiona il codice QR dell’invito con la fotocamera o apri il link di invito. Il secondo dispositivo mostrerà una risposta. Scansionala dalla schermata di invito del primo dispositivo o incolla il codice di risposta in quella schermata.

Una volta connessi, entrambi i dispositivi possono inviare file, link e testo semplice. Puoi ad esempio inviare un PDF dal portatile allo smartphone e poi rimandare un indirizzo al portatile nella stessa sessione. Scegli o trascina un file, poi seleziona **Invia file**. Sul dispositivo che riceve, seleziona **Scarica** per salvare il file o **Copia testo** per usare un messaggio in un’altra app.

## Dove finiscono i file e il testo

WebRTC cifra i dati e li trasferisce direttamente da un browser all’altro. Il link di invito e il codice di risposta contengono i dati necessari per stabilire la connessione. Condividili solo con chi vuoi collegarti. Lo strumento funziona senza servizi di segnalazione, server di caricamento o relay. Lascia aperte entrambe le pagine fino al termine del trasferimento.

## Se i dispositivi non si connettono

Le reti Wi-Fi per gli ospiti e alcune reti aziendali possono impedire ai dispositivi di comunicare tra loro anche quando sono sulla stessa rete. Prova una rete privata che consenta ai dispositivi di raggiungersi. Se non puoi usare la fotocamera, scambia il link di invito e il codice di risposta tramite un’app di messaggistica o un altro dispositivo. I file di massimo 128 MiB restano nella memoria della scheda che li riceve mentre li scarichi. Salva ogni file prima di riceverne un altro o chiudere la pagina.
