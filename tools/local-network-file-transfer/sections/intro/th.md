## วิธีส่งไฟล์ผ่านเครือข่ายภายใน

เปิดเครื่องมือส่งไฟล์ผ่านเครือข่ายภายในบนอุปกรณ์ทั้งสอง โดยเชื่อมต่อกับเครือข่าย Wi-Fi หรือเครือข่ายแบบใช้สายเดียวกัน บนเครื่องแรกให้เลือก **ส่งจากอุปกรณ์นี้** จากนั้นใช้แอปกล้องบนเครื่องที่สองสแกน QR Code คำเชิญ หรือเปิดลิงก์คำเชิญ เครื่องที่สองจะแสดงรหัสตอบกลับ ให้ใช้ตัวสแกนที่หน้าคำเชิญบนเครื่องแรกสแกนรหัสนั้น หรือวางรหัสตอบกลับในหน้านั้น

เมื่อเชื่อมต่อแล้ว ทั้งสองเครื่องจะส่งไฟล์ ลิงก์เว็บ หรือข้อความธรรมดาให้กันได้ เช่น ส่ง PDF จากแล็ปท็อปไปยังโทรศัพท์ แล้วส่งที่อยู่จากโทรศัพท์กลับมาคัดลอกบนแล็ปท็อปผ่านการเชื่อมต่อเดียวกัน เลือกหรือลากไฟล์มาวาง แล้วเลือก **ส่งไฟล์** บนเครื่องที่รับ ให้เลือก **ดาวน์โหลด** เพื่อบันทึกไฟล์ หรือ **คัดลอกข้อความ** เพื่อนำข้อความไปใช้ในแอปอื่น

## ไฟล์และข้อความถูกส่งไปที่ไหน

WebRTC เข้ารหัสข้อมูลที่ส่งตรงระหว่างเบราว์เซอร์ทั้งสอง คำเชิญและรหัสตอบกลับมีรายละเอียดที่ใช้ในการเชื่อมต่อ ควรแชร์กับคนที่คุณต้องการเชื่อมต่อด้วยเท่านั้น เครื่องมือนี้ไม่ใช้บริการส่งสัญญาณเพื่อจับคู่ เซิร์ฟเวอร์รับอัปโหลดไฟล์ หรือเซิร์ฟเวอร์ส่งต่อข้อมูล เปิดทั้งสองหน้าค้างไว้จนกว่าจะส่งเสร็จ

## หากอุปกรณ์เชื่อมต่อกันไม่ได้

Wi-Fi สำหรับแขกและเครือข่ายในสำนักงานบางแห่งอาจไม่อนุญาตให้อุปกรณ์เชื่อมต่อถึงกันแม้จะใช้ Wi-Fi เดียวกัน ลองใช้เครือข่ายส่วนตัวที่ให้อุปกรณ์เชื่อมต่อกันได้ หากใช้กล้องไม่ได้ ให้ส่งลิงก์คำเชิญและรหัสตอบกลับให้กันผ่านแอปส่งข้อความหรืออุปกรณ์อีกเครื่อง ไฟล์ขนาดไม่เกิน 128 MiB จะพักไว้ในหน่วยความจำของแท็บฝั่งผู้รับเพื่อให้ดาวน์โหลดได้ บันทึกแต่ละไฟล์ก่อนรับไฟล์ถัดไปหรือปิดหน้า
