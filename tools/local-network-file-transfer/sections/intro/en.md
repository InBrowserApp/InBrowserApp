## How to transfer files over your local network

Open Local Network File Transfer on both devices while they are connected to the same Wi-Fi or wired network. On the first device, choose **Send from this device**. On the second, scan the invitation QR code with your camera app or open the invitation link. The second device then displays a reply. Scan it from the first device’s invitation screen or paste the reply code there.

Once connected, either device can send a file, a web link, or plain text. For example, you can send a PDF from your laptop to your phone and copy an address back to your laptop in the same session. Choose or drop a file, then select **Send file**. On the receiving device, select **Download** to save the file or **Copy text** to use a message in another app.

## Where your files and text go

WebRTC encrypts the transfer and sends the data directly between the two browsers. The invitation and reply establish the connection. They contain connection details and should only be shared with the person you want to connect to. The tool uses no signaling service, file upload server, or relay. Keep both pages open until delivery finishes.

## If your devices cannot connect

Guest Wi-Fi and some office networks block devices from talking to each other even when they are on the same Wi-Fi. Try a private network that allows devices to reach one another. If camera access is unavailable, exchange the invitation link and reply code using a messaging app or another device. Files up to 128 MiB are held in the receiving tab’s memory so you can download them. Save each file before receiving another or closing the page.
