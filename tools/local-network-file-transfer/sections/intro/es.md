## Cómo transferir archivos por la red local

Abre Transferencia de archivos en red local en los dos dispositivos conectados a la misma red Wi-Fi o cableada. En el primero, selecciona **Enviar desde este dispositivo**. En el segundo, escanea el código QR de invitación con la cámara o abre el enlace de invitación. Aparecerá un código de respuesta en el segundo dispositivo. Escanéalo con el escáner de la pantalla de invitación del primero o pega allí el código de respuesta.

Una vez conectados, puedes enviar archivos, enlaces web o texto sin formato en ambas direcciones. Por ejemplo, envía un PDF de la computadora al teléfono y luego envía una dirección del teléfono a la computadora en la misma sesión. Elige o arrastra un archivo y selecciona **Enviar archivo**. En el dispositivo receptor, pulsa **Descargar** para guardar el archivo o **Copiar texto** para usar un mensaje en otra aplicación.

## Qué ocurre con tus archivos y tu texto

WebRTC cifra los datos y los envía directamente entre los navegadores. El enlace de invitación y el código de respuesta incluyen los datos necesarios para establecer la conexión. Compártelos solo con quien quieras conectarte. La herramienta funciona sin servicio de señalización, servidor de carga ni servidor intermediario. Mantén abiertas las dos páginas hasta que termine la transferencia.

## Si los dispositivos no se conectan

Las redes Wi-Fi para invitados y algunas redes de oficina impiden que los dispositivos se comuniquen entre sí aunque estén conectados a la misma red. Prueba con una red privada que permita el acceso entre dispositivos. Si no puedes usar la cámara, intercambia el enlace de invitación y el código de respuesta mediante una aplicación de mensajería u otro dispositivo.

## Archivos grandes y transferencias interrumpidas

La integridad de los archivos se verifica bloque a bloque con SHA-256. Los datos se guardan en el almacenamiento local del navegador receptor. El espacio disponible en el navegador determina el tamaño de los archivos que puedes recibir. Descarga cada archivo cuando termine la transferencia para conservar una copia.

Si se pierde la conexión, mantén abiertas las dos pestañas originales y vuelve a vincular los dispositivos. Selecciona **Reanudar la transferencia del archivo** para continuar desde el último bloque verificado. En la pestaña receptora, escanea o pega la nueva invitación dentro de la herramienta para mantener abierta la página.
