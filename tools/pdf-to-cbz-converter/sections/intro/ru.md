## Как конвертировать PDF в CBZ

Выберите комикс в формате `.pdf` или перетащите его в окно конвертера. Проверьте обложку и число страниц, затем нажмите **Скачать CBZ**. Например, из `volume-01.pdf` получится `volume-01.cbz`. Преобразование выполняется на вашем устройстве.

## Исходные сканы и оформление страниц

CBZ — это ZIP-архив, в котором страницы комикса хранятся как изображения. Каждая страница PDF становится одним изображением в архиве. Порядок страниц сохраняется. Если страница состоит только из одного неизменённого JPEG, который занимает её целиком, конвертер может скопировать исходное изображение. Для остальных страниц он создаёт изображение всей страницы, включая кадры, надписи и видимые отметки. Вертикальные страницы и широкие развороты сохраняют свои пропорции.

## Как открыть архив комикса

Откройте скачанный файл в [читалке комиксов CBZ](/ru/tools/cbz-reader/) или добавьте его в приложение для чтения или библиотеку комиксов. Если PDF запрашивает пароль, откройте файл с помощью пароля и выберите для преобразования копию без защиты.
