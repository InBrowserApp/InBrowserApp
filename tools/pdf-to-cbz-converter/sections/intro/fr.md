## Comment convertir un fichier PDF en CBZ

Choisissez une BD au format `.pdf` ou faites-la glisser sur le convertisseur. Vérifiez la couverture et le nombre de pages, puis cliquez sur **Télécharger le CBZ**. Par exemple, `volume-01.pdf` devient `volume-01.cbz`. La conversion se fait sur votre appareil.

## Images d’origine et rendu des pages complètes

Un CBZ est une archive ZIP qui contient les pages de la BD sous forme d’images. Chaque page du PDF devient une image dans l’archive, dans l’ordre d’origine. Si une page se résume à une image JPEG non modifiée qui occupe toute sa surface, le convertisseur peut réutiliser cette image telle quelle. Pour les autres pages, il produit une image de la page entière avec les cases, le texte et les annotations visibles. Les pages verticales et les doubles pages larges gardent leurs proportions.

## Ouvrir l’archive de la BD

Ouvrez le fichier téléchargé dans le [Lecteur de BD CBZ](/fr/tools/cbz-reader/) ou importez-le dans une application de lecture ou une bibliothèque de BD. Si le PDF demande un mot de passe, ouvrez-le avec ce mot de passe et choisissez une copie déverrouillée pour le convertir.
