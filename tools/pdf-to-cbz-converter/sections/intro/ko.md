## PDF를 CBZ로 변환하는 방법

`.pdf` 만화 파일을 선택하거나 변환기에 끌어다 놓으세요. 표지와 페이지 수를 확인한 뒤 **CBZ 다운로드**를 선택하세요. 예를 들어 `volume-01.pdf`는 `volume-01.cbz`로 변환됩니다. 변환은 기기에서 진행됩니다.

## 원본 스캔과 페이지 전체 이미지

CBZ는 만화 페이지를 이미지로 담은 ZIP 압축 파일입니다. PDF의 각 페이지가 이미지 한 장이 되어 원래 순서대로 저장됩니다. 페이지 전체가 수정되지 않은 JPEG 이미지 한 장으로만 구성된 경우 원본 JPEG를 그대로 옮길 수 있습니다. 다른 페이지는 전체를 이미지로 만들어 만화 칸과 글자, 화면에 보이는 표시를 유지합니다. 세로 페이지와 가로로 넓은 펼침면 모두 원래의 가로세로 비율을 유지합니다.

## 변환한 만화 파일 열기

다운로드한 파일을 [CBZ 만화 리더](/ko/tools/cbz-reader/)에서 열거나 만화 앱이나 라이브러리로 가져오세요. PDF를 열 때 비밀번호를 묻는다면 먼저 비밀번호로 보호를 해제한 뒤 해제된 사본을 선택해 변환하세요.
