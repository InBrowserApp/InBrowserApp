## วิธีเชื่อมต่อคีย์บอร์ด MIDI หรือคอนโทรลเลอร์

เชื่อมต่ออุปกรณ์ MIDI และตรวจสอบว่าระบบปฏิบัติการรู้จักอุปกรณ์ เลือก **เปิดใช้งาน MIDI** อนุญาตให้เบราว์เซอร์เข้าถึง MIDI เมื่อได้รับคำขอ แล้วเลือกอินพุต ใช้เบราว์เซอร์ที่รองรับผ่าน HTTPS มอนิเตอร์จะรับข้อความจากอินพุตที่เลือกและแสดงผลภายในเครื่อง

## วิธีทดสอบโน้ตและความเร็วในการกด

กดคีย์หรือแพดแล้วดูคีย์บอร์ดเปียโนและบันทึกข้อความ Note On แสดงโน้ตและความเร็วในการกด ซึ่งปกติเป็นค่าตั้งแต่ 1 ถึง 127 ส่วน Note Off หรือ Note On ที่มีความเร็วในการกดเป็น 0 จะปล่อยโน้ต คีย์บอร์ดแสดงโน้ต MIDI หมายเลข 60 เป็น C4 เปลี่ยนอ็อกเทฟเริ่มต้นเพื่อดูช่วงอื่น โน้ตที่กดค้างจะแสดงในรายการแม้อยู่นอกช่วงที่แสดง

## วิธีตรวจสอบ CC, Pitch Bend และ MIDI Clock

หมุนปุ่ม เลื่อนเฟดเดอร์ หรือกดแป้นเหยียบเพื่อดูหมายเลขและค่าของ Control Change (CC) ตัวอย่างเช่น แป้นเหยียบซัสเทนหลายรุ่นส่ง CC 64 ค่า Pitch Bend จะแสดงโดยมีค่ากลางเป็น 0 พัลส์ MIDI Clock จะนับแยกจากบันทึกข้อความ MIDI Clock มาตรฐานส่ง 24 พัลส์ต่อโน้ตตัวดำหนึ่งตัว บันทึกจะแสดงหมายเลขช่องสัญญาณและไบต์ดิบในรูปเลขฐานสิบหกเพื่อตรวจสอบข้อความแต่ละรายการ

## ทำไมอินพุต MIDI จึงไม่ตอบสนอง?

ตรวจสอบสายไฟ การจ่ายไฟ และโหมดของอุปกรณ์ รวมถึงตรวจสอบว่าพอร์ตที่เลือกตรงกับคอนโทรลเลอร์ ปิดแอปอื่นที่อาจใช้อินพุตอยู่ แล้วเชื่อมต่ออุปกรณ์อีกครั้ง การรองรับขึ้นอยู่กับเบราว์เซอร์และระบบปฏิบัติการ เครื่องมือนี้รับข้อความ MIDI มาตรฐานด้วยสิทธิ์เข้าถึง MIDI แบบปกติ ข้อความ System Exclusive (SysEx) ที่เฉพาะกับอุปกรณ์ต้องได้รับสิทธิ์เพิ่มเติม
