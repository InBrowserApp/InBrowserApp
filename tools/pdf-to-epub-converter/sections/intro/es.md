## Cómo convertir PDF a EPUB

Elige un archivo `.pdf` o arrástralo al convertidor. Selecciona **Convertir a EPUB** y, cuando termine, **Descargar EPUB**. Por ejemplo, `field-notes.pdf` se convierte en `field-notes.epub`. Abre el resultado en el [lector de EPUB](/es/tools/epub-reader/) o en otra aplicación de lectura para ajustar el tamaño del texto y comprobar el orden de lectura.

## Conserva el texto del PDF y reconoce el de las páginas escaneadas

El convertidor conserva el texto seleccionable del PDF. Si hay páginas que solo contienen una imagen escaneada, elige el idioma del texto antes de convertir. Activa **Reconocer también inglés** si las páginas escaneadas mezclan otro idioma con el inglés. El navegador descarga el motor OCR y los datos de idioma cuando los necesita. El PDF y el texto reconocido se quedan en tu dispositivo. Si el OCR no encuentra texto en una página, se guarda como imagen.

## Qué PDF funcionan mejor como libros electrónicos

Los libros y documentos de una sola columna con texto claro dan los mejores resultados. El EPUB adapta el texto a la pantalla, por lo que pueden cambiar los saltos de página, las tablas complejas y el diseño de varias columnas. Para mantener el diseño original del PDF y añadir texto que se pueda buscar en las páginas escaneadas, usa [OCR para PDF](/es/tools/pdf-ocr/).
