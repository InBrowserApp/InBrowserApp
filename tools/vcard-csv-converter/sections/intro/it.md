## Convertire contatti VCF in un foglio di calcolo CSV

Scegli **Da vCard a CSV**, apri un file `.vcf` o incollane il contenuto, poi seleziona **Converti**. Il CSV contiene una riga per contatto. Scaricalo per ordinare o modificare la rubrica in Excel, Fogli Google o un altro programma per fogli di calcolo. Seleziona **Prova un esempio** per vedere il formato previsto nelle due direzioni.

## Trasformare un elenco di contatti CSV in vCard

Scegli **Da CSV a vCard** e aggiungi un file CSV con codifica UTF-8 e le intestazioni delle colonne sulla prima riga. Lo strumento riconosce `Full Name`, `First Name`, `Last Name`, `Email`, `Phone`, `Company`, `Job Title`, `Website`, `Address` e `Notes`, oltre alle varianti più comuni nelle rubriche. Per esempio, una riga sotto `First Name,Last Name,Email` può creare un contatto con un nome visualizzato e campi distinti per nome e cognome.

Scarica il file VCF ottenuto per importare i contatti nella rubrica. Il file contiene una vCard 3.0 per ogni riga con un contatto.

## Quali dati conserva il CSV?

Il CSV è una tabella. Lo strumento conserva il primo indirizzo email, numero di telefono, sito web e indirizzo di ogni scheda. Le foto, le etichette dei campi e le proprietà vCard personalizzate rimangono nel VCF originale. Conservalo se ti serve un backup completo. La conversione avviene nel browser.
