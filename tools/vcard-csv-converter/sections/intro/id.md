## Konversi kontak VCF menjadi spreadsheet CSV

Pilih **vCard ke CSV**, buka file `.vcf` atau tempel isinya, lalu pilih **Konversi**. CSV berisi satu baris untuk setiap kontak. Unduh file untuk mengurutkan atau mengedit daftar kontak di Excel, Google Sheets, atau aplikasi spreadsheet lain. Pilih **Coba contoh** untuk melihat format masukan di kedua arah.

## Ubah daftar kontak CSV menjadi vCard

Pilih **CSV ke vCard** dan masukkan CSV berformat UTF-8 dengan judul kolom di baris pertama. Alat ini mengenali `Full Name`, `First Name`, `Last Name`, `Email`, `Phone`, `Company`, `Job Title`, `Website`, `Address`, dan `Notes`, serta variasi judul kolom yang lazim pada ekspor kontak. Sebagai contoh, satu baris di bawah judul `First Name,Last Name,Email` dapat menjadi kontak dengan nama tampilan, nama depan, dan nama belakang.

Unduh file VCF yang dihasilkan untuk mengimpor kontak ke buku alamat. Satu baris kontak menghasilkan satu entri vCard 3.0 di dalam VCF.

## Data apa saja yang masuk ke CSV?

CSV menyimpan data dalam tabel. Alat ini mengambil email, nomor telepon, situs web, dan alamat pertama dari setiap kartu. Foto, label kolom, dan properti khusus vCard tetap tersimpan di VCF asli. Simpan file asli jika Anda memerlukan cadangan lengkap. Konversi daftar kontak berlangsung di browser Anda.
