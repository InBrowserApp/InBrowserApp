## Как преобразовать файл STL в Wavefront OBJ

Нажмите **Открыть файл** или перетащите файл `.stl` в конвертер. Он читает как текстовые файлы STL в кодировке ASCII, так и двоичные, и готовит файл `.obj` для скачивания прямо в браузере. Чтобы попробовать конвертер на небольшом монтажном кронштейне, нажмите **Открыть пример**, а затем **Скачать OBJ**.

## Что содержится в файле OBJ

В файл Wavefront OBJ записываются треугольники исходной поверхности. Оси координат и масштаб сетки сохраняются. Формат STL не задаёт стандартную единицу измерения. Если длина ребра в исходном файле равна 40, в OBJ она останется равной 40 единицам координат. При импорте файла в другую программу выберите нужную единицу измерения.

Файл для скачивания содержит геометрию сетки. Библиотека материалов и текстуры в него не входят, поскольку стандартный формат STL описывает только поверхность.

## Как просмотреть результат или выполнить обратное преобразование

Проверьте скачанный файл с помощью инструмента [Просмотр OBJ](../obj-viewer/). Исходный файл можно открыть в инструменте [Просмотр STL](../stl-viewer/). Для обратного преобразования используйте [Конвертер OBJ в STL](../obj-to-stl-converter/).
