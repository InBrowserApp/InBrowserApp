## Lire un PDF dans votre navigateur

Ouvrez un PDF local ou déposez-le dans le lecteur. Parcourez les pages, réglez le zoom ou adaptez la page à la largeur disponible. Sélectionnez du texte pour le copier, ou recherchez dans le document et passez d’un résultat à l’autre.

## Confidentialité et compatibilité

Les fichiers et les mots de passe sont traités localement, sans être envoyés à un serveur ni enregistrés par cet outil. Les PDF protégés par un mot de passe peuvent être ouverts en saisissant ce mot de passe. Les polices intégrées et les ressources PDF fournies avec le lecteur sont utilisées lorsqu’elles sont disponibles ; des polices manquantes peuvent modifier l’apparence de certains documents.

Les numérisations contenant uniquement des images peuvent être lues, mais la sélection de texte et la recherche nécessitent une couche de texte existante. Ce lecteur n’effectue pas de reconnaissance optique de caractères (OCR), ne modifie pas les documents et n’exécute pas les scripts intégrés. Les liens du document ne s’ouvrent que lorsque vous les sélectionnez.
