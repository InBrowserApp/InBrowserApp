## 將 MP4 或 WebM 影片轉成 GIF 動圖

把一小段影片製作成循環播放的 GIF，方便在聊天中分享、回報問題，或用來示範操作。選好要分享的片段後，再調整影格率和寬度。讀取原始影片與產生 GIF 的過程都在瀏覽器內完成。

### 如何將影片片段轉成 GIF

1. 按一下**選擇影片**，或將影片拖曳到頁面。用原始影片播放器找到想保留的片段。
2. 拖曳裁剪滑桿的兩個把手，或輸入起訖時間，單位為秒。例如，輸入 **0.5** 和 **3.5**，即可從第 0.5 秒開始擷取 3 秒。
3. 設定影格率與寬度。將這段 3 秒的影片設為 **12 FPS**，就會產生 36 個影格。高度會依原始影片的長寬比自動調整。
4. 按一下**製作 GIF**，再播放預覽。確認預覽標題下方的尺寸和檔案大小後，按一下**下載 GIF**。

### 如何縮小 GIF 檔案

可先用短片段試做，將影格率設為 **10 FPS**、寬度設為 **480 像素**或更窄。先剪掉動作前後的停頓。縮小後若仍能看清細節，可再縮小寬度。如果對流暢度要求較低，也可以降低影格率。MP4 壓縮連續畫面的效率較高，因此輸出的 GIF 有時會比原始的 MP4 更大。

### 常見問題

#### 除了 MP4 和 WebM，也可以將 MOV 轉成 GIF 嗎？

能否轉換取決於瀏覽器能否解碼影片。相同副檔名的檔案可能採用不同的編解碼器，因此同一個 MP4 或 MOV 檔案在某部裝置上可以播放，在另一部裝置上可能無法開啟。遇到這種情況，可以改用目前瀏覽器可播放的 MP4 或 WebM 檔案。

#### 匯出的 GIF 有聲音嗎？

GIF 動圖會無聲循環播放。匯出的檔案只包含選取的影片影格，原始影片會保留在你的裝置上。
