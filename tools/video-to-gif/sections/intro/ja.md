## MP4 や WebM の動画をアニメーション GIF に変換する

動画の一部をループ再生する GIF にすると、チャットでの共有、不具合の報告、操作手順の紹介に使えます。共有したい範囲を選び、フレームレートと幅を指定します。元の動画の読み込みから GIF の生成まで、処理はブラウザー内で行われます。

### 動画の一部を GIF にする手順

1. **動画を選択**を押すか、動画をページにドロップします。元の動画を再生して、残したい場面を探します。
2. 2 つのつまみをドラッグするか、開始時刻と終了時刻を秒単位で入力します。たとえば **0.5** と **3.5** を入力すると、動画の 0.5 秒地点から 3 秒間を切り出せます。
3. フレームレートと幅を設定します。この 3 秒間を **12 FPS** で書き出すと、36 フレームになります。高さは元の動画の縦横比に合わせて自動で調整されます。
4. **GIF を作成**を押し、プレビューを再生します。プレビューの見出しの下で画像のサイズとファイル容量を確認し、**GIF をダウンロード**を押します。

### GIF のファイル容量を小さくするには

まず短い範囲を選び、**10 FPS**、幅 **480 px** 以下で試してみてください。動作の前後に待ち時間があれば、先に切り取ります。プレビューで細部が読み取れるなら幅を狭くし、動きの滑らかさがあまり重要でなければフレームレートを下げます。MP4 は連続する映像を効率よく圧縮できるため、作成した GIF の方が元の MP4 より大きくなることもあります。

### よくある質問

#### MP4 や WebM に加えて MOV も変換できますか？

ブラウザーで動画をデコードできれば変換できます。同じ拡張子でも使われているコーデックが異なることがあるため、同じ MP4 や MOV ファイルでも、ある端末で再生できて別の端末では開けない場合があります。開けないときは、使用中のブラウザーで再生できる MP4 や WebM をお試しください。

#### 作成した GIF に音声は入りますか？

アニメーション GIF は音声なしでループ再生されます。書き出されるのは選んだ範囲の映像フレームで、元の動画はお使いの端末に残ります。

### 画像から GIF を作る、動画から静止画を取り出す

複数の画像をつなげて動かしたいときは、[GIF 作成ツール](/ja/tools/gif-maker/)を使えます。動画の特定の時刻から静止画をダウンロードしたいときは、[動画フレーム抽出](/ja/tools/video-frame-extractor/)を使ってください。
