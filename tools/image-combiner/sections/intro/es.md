## Cómo combinar imágenes en un solo PNG

1. Selecciona **Añadir imágenes**, arrastra fotos al área de carga o pega una captura desde el portapapeles. Usa las flechas de **Imágenes** para ordenarlas.
2. Elige una disposición y ajusta la separación y el fondo. La vista previa se actualiza al instante y muestra el ancho y el alto finales en píxeles.
3. Selecciona **Descargar PNG** para guardar la imagen combinada. El navegador procesa tus imágenes en tu dispositivo.

## Elige una disposición para capturas o fotos

- **Horizontal** coloca las imágenes en una fila. Úsala para mostrar el antes y el después o para comparar dos versiones de una pantalla.
- **Vertical** coloca las imágenes una debajo de otra. Úsala para crear una captura larga a partir de varias capturas consecutivas. Si se solapan, [recorta las zonas repetidas](/es/tools/image-cropper/) primero.
- **Cuadrícula** organiza las imágenes en filas y columnas. Pon **Columnas** en 2 para crear un collage de 2 × 2 con cuatro fotos.

## Iguala el tamaño de las imágenes sin recortarlas

Por defecto, cada imagen conserva sus dimensiones originales. Activa **Igualar tamaños** para dar el mismo alto a las imágenes dispuestas en horizontal o el mismo ancho a las dispuestas en vertical. En la cuadrícula, cada imagen se ajusta a una celda del ancho y el alto elegidos. Las imágenes conservan sus proporciones y quedan visibles por completo.

Deja un campo vacío para usar el menor valor original de esa dimensión. Por ejemplo, para unir en vertical dos capturas de 1200 y 800 píxeles de ancho, activa **Igualar tamaños** y deja **Ancho (px)** vacío. Ambas capturas tendrán 800 píxeles de ancho en el resultado.

## Ajusta la separación y exporta con fondo transparente

Pon **Separación (px)** en 0 para unir las imágenes sin dejar huecos, o añade unos píxeles para separar las imágenes o las celdas de la cuadrícula. Elige **Transparente** para conservar los huecos y las zonas vacías transparentes en el PNG. Elige **Color sólido** para rellenarlos con un color, por ejemplo, blanco para un documento.
