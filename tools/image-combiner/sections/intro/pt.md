## Como juntar imagens em um único PNG

1. Selecione **Adicionar imagens**, solte fotos na área indicada ou cole uma captura de tela da área de transferência. Use as setas em **Imagens** para ajustar a ordem.
2. Escolha uma disposição e ajuste o espaçamento e o fundo. A prévia se atualiza na hora e mostra a largura e a altura finais em pixels.
3. Selecione **Baixar PNG** para salvar a montagem. O processamento das imagens ocorre diretamente no navegador.

## Escolher uma disposição para capturas de tela ou fotos

- **Lado a lado** coloca as imagens em uma única linha. Use para mostrar um antes e depois ou comparar duas versões de uma tela.
- **Empilhadas** coloca as imagens umas abaixo das outras. Use para juntar várias capturas de tela em uma única imagem vertical. Se as capturas se sobrepuserem, [recorte primeiro as áreas repetidas](/pt/tools/image-cropper/).
- **Grade** distribui as imagens em linhas e colunas. Defina **Colunas** como 2 para montar uma grade de 2 × 2 com quatro fotos.

## Uniformizar as dimensões sem cortar as imagens

Por padrão, cada imagem mantém suas dimensões originais. Ative **Uniformizar dimensões** para dar a mesma altura às imagens lado a lado ou a mesma largura às imagens empilhadas. Na grade, cada imagem é ajustada para caber em uma célula com a largura e a altura escolhidas. As imagens ficam totalmente visíveis e mantêm suas proporções.

Deixe um campo em branco para usar o menor valor original daquela dimensão. Por exemplo, para empilhar duas capturas com larguras de 1.200 e 800 pixels, ative **Uniformizar dimensões** e deixe **Largura (px)** em branco. No resultado, as duas capturas terão 800 pixels de largura.

## Ajustar o espaçamento e exportar com fundo transparente

Defina **Espaçamento (px)** como 0 para juntar as imagens sem intervalo ou adicione alguns pixels para separar as imagens ou as células da grade. Escolha **Transparente** para manter os espaços e as áreas vazias transparentes no PNG. Escolha **Cor sólida** para preencher essas áreas com uma cor, como branco para um documento.
