## Comment vérifier la fréquence de rafraîchissement de votre écran

Gardez cet onglet visible et attendez le résultat. Le test mesure le temps entre les images d’une animation sur une courte durée pour estimer la fréquence de rafraîchissement de l’écran en hertz (Hz). Si vous utilisez plusieurs écrans, déplacez toute la fenêtre du navigateur sur l’écran à tester, puis choisissez **Mesurer à nouveau**.

## À quoi correspondent la fréquence en Hz et l’intervalle entre les images ?

La fréquence en hertz indique combien de fois par seconde l’écran peut se rafraîchir dans la session de navigation en cours. À 60 Hz, l’intervalle entre les images est d’environ 16,7 millisecondes. À 120 Hz, il est d’environ 8,3 millisecondes. L’outil utilise l’intervalle typique pour limiter l’influence de quelques images affichées en retard.

## Pourquoi le résultat peut différer des caractéristiques du moniteur

Le test estime la fréquence que le navigateur utilise sur cet écran. Un écran annoncé à 144 Hz peut fonctionner à 60 Hz si le système est réglé sur 60 Hz, si la connexion limite le mode d’affichage ou si le navigateur fonctionne à une fréquence inférieure. Vérifiez la fréquence dans les réglages d’affichage, gardez le test au premier plan et recommencez la mesure. Le mode économie d’énergie et la fréquence de rafraîchissement variable peuvent également faire varier le résultat d’une mesure à l’autre.
