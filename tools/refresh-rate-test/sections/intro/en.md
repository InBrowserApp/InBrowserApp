## How to check your screen refresh rate

Keep this browser tab visible and wait for a reading. The test times animation frames over a short sample to estimate the display refresh rate in hertz (Hz). If you use more than one monitor, move the whole browser window onto the screen you want to test, then choose **Measure again**.

## What the Hz and frame interval numbers mean

Hertz indicates how many times per second the display can refresh in the current browser session. A reading of 60 Hz corresponds to about 16.7 milliseconds between frames. At 120 Hz the interval is about 8.3 milliseconds. The tool uses the typical interval so that a few delayed frames have less influence on the estimate.

## Why the result can differ from the monitor specification

The test estimates the rate the browser is using on this screen. A display rated for 144 Hz can still run at 60 Hz if the operating system is set to 60 Hz, the connection limits the mode, or the browser runs at a lower rate. Check the refresh rate in your display settings, keep the test in the foreground, and measure again. Power-saving modes and variable refresh rate can also change the reading between runs.
