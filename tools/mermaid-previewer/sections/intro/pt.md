## Pré-visualizar código Mermaid online

Cole uma definição no campo **Código Mermaid**. A prévia se atualiza enquanto você digita. Se o código veio de um documento Markdown, você também pode colar um único bloco de código delimitado e identificado como `mermaid`. Use a prévia para conferir diagramas de arquivos README, documentação técnica ou apresentações.

## Experimentar um fluxograma, diagrama de sequência ou ER

Selecione **Carregar um exemplo** para substituir o conteúdo do editor por um exemplo pronto. Um fluxograma mostra etapas e decisões. Um diagrama de sequência mostra as mensagens entre participantes e um diagrama ER mostra as relações entre entidades de um modelo de dados. Você também pode colar outras definições compatíveis com Mermaid, como diagramas de classes e de Gantt.

## Exportar como SVG ou PNG

Baixe o **SVG** para obter uma imagem vetorial que continua nítida ao mudar de tamanho. Escolha **PNG** para inserir uma imagem raster em slides ou documentos. O arquivo contém o diagrama atual com fundo transparente. Guarde o código Mermaid se quiser editar o diagrama mais tarde.

## Corrigir um diagrama que não aparece

Confira se a primeira linha indica o tipo de diagrama, como `flowchart LR` ou `sequenceDiagram`. Um rótulo sem fechamento ou uma seta fora de lugar pode impedir a visualização. O código fica no editor para você corrigir. Compare com um exemplo da ferramenta ou consulte a [referência de sintaxe do Mermaid](https://mermaid.js.org/intro/syntax-reference.html).
