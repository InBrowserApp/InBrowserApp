## Lee un archivo web guardado

Abre un archivo MHTML o MHT para leer su página principal guardada con las imágenes y los estilos incluidos. Los archivos permanecen en tu dispositivo. Usa el esquema del documento, el zoom, el control de ancho y el modo sin distracciones para leer y seleccionar texto cómodamente.

## Recursos incluidos y ubicación original

El visor resuelve las referencias content-location y content-ID dentro del archivo. Si hay una ubicación original disponible, se muestra como información de referencia, sin visitarla. Las imágenes, los estilos y las fuentes que faltan nunca se descargan del sitio web en línea. Los enlaces externos solo se abren al seleccionarlos.

## Compatibilidad

Este lector admite páginas HTML dentro de archivos web multipart/related, incluidos los recursos base64 y quoted-printable y las codificaciones de texto habituales. Las capturas incompletas muestran el contenido recuperado con un aviso. Las estructuras multiparte anidadas poco habituales y los mensajes de correo electrónico reciben una explicación clara.

Los scripts, formularios, redirecciones, aplicaciones incrustadas y páginas anidadas están desactivados. Los formatos de imagen no compatibles y los diseños complejos pueden verse diferentes del original. El visor no puede restaurar sesiones de sitios web ni contenido que no se haya guardado en el archivo. Si un archivo está dañado, guarda un nuevo archivo web en la aplicación original.
