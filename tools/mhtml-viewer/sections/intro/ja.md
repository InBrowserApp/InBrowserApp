## 保存した Web アーカイブを読む

MHTML または MHT ファイルを開くと、メインの保存ページを、含まれている画像やスタイルとともに読めます。ファイルは端末内に留まります。文書のアウトライン、ズーム、表示幅の調整、集中モードを使って、快適に閲覧したりテキストを選択したりできます。

## 含まれるリソースと元の場所

ビューアーはアーカイブ内の content-location と content-ID の参照を解決します。元の場所が記録されている場合は、アクセスせずに参考情報として表示します。不足している画像、スタイル、フォントを元の Web サイトから取得することはありません。外部リンクは選択した場合にのみ開きます。

## 互換性

このビューアーは multipart/related Web アーカイブ内の HTML ページに対応し、base64、quoted-printable のリソースや一般的な文字エンコーディングをサポートします。保存内容が不完全な場合は、復元できた内容と注意事項を表示します。特殊な入れ子のマルチパート構造やメールについては、明確な説明を表示します。

スクリプト、フォーム、リダイレクト、埋め込みアプリ、入れ子のページは無効です。未対応の画像形式や複雑なサイトレイアウトは、元の表示と異なる場合があります。Web サイトのセッションや、アーカイブに保存されていないコンテンツは復元できません。ファイルが破損している場合は、元のアプリケーションで Web アーカイブを保存し直してください。
