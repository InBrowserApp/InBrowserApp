## Cómo quitar el fondo de una imagen

1. Elige o arrastra una imagen JPG, PNG o WebP. La herramienta detecta automáticamente el sujeto principal y vuelve transparente el fondo.
2. Compara el recorte con la imagen original. La cuadrícula señala las zonas transparentes y solo aparece en la vista previa.
3. Selecciona **Descargar PNG** para guardar el recorte con las dimensiones originales. El formato PNG conserva la transparencia cuando colocas la imagen sobre otro fondo.

## Fotos de productos, avatares y recursos gráficos

Quita el fondo de una foto de producto para usar un fondo uniforme en tu catálogo. Recorta un retrato para crear un avatar o una imagen de perfil, o coloca un objeto aislado en una diapositiva, un folleto o una miniatura. El PNG conserva el tamaño del lienzo original para que coincida con la imagen de partida en tu editor gráfico.

## Cómo conseguir bordes más definidos

Parte de una imagen nítida con un solo sujeto bien definido. Una buena iluminación y un buen contraste ayudan a separar el sujeto de su entorno. Antes de descargar el resultado, revisa los detalles del pelo, el pelaje, el vidrio y las sombras, especialmente si el fondo es muy recargado o tiene colores parecidos a los del sujeto.

## ¿Se sube mi imagen a Internet?

El navegador descarga el modelo para quitar el fondo y su entorno de ejecución cuando los necesita. Tanto la imagen como el PNG resultante se procesan en tu dispositivo, sin subir archivos ni crear una cuenta.
