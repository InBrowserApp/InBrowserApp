## Como criar um CBZ a partir de imagens

Clique em **Escolher imagens** para selecionar arquivos individuais ou em **Escolher pasta** para adicionar uma pasta de páginas. Você também pode arrastar os arquivos para o conversor. Imagens em JPEG, PNG, WebP, GIF, BMP e AVIF podem fazer parte do mesmo quadrinho. Clique em **Criar CBZ** e depois em **Baixar CBZ** para salvar `comic.cbz`. Seus arquivos ficam no seu dispositivo.

## Como definir a ordem das páginas e a capa

As páginas novas são ordenadas pelos nomes das pastas e dos arquivos, levando a numeração em conta. Assim, `page2.jpg` vem antes de `page10.jpg`. Para mudar a ordem, arraste as páginas ou use os botões de seta para cima e para baixo. Clique em **Definir como capa** para mover uma imagem para a primeira página. As imagens que você adicionar depois ficam no fim da lista.

## Como ler o quadrinho pronto

O CBZ é um arquivo ZIP com as imagens das páginas. O conversor mantém os arquivos de imagem originais e atribui nomes numerados para que o leitor siga a ordem que você escolheu. Abra o resultado no [Leitor de quadrinhos CBZ](/pt/tools/cbz-reader/) ou importe-o para sua biblioteca de quadrinhos.
