## Cara membuat CBZ dari gambar

Gunakan **Pilih gambar** untuk menambahkan file gambar atau **Pilih folder** untuk menambahkan gambar dari satu folder. Anda juga bisa menyeret dan melepas file gambar ke konverter. Gambar JPEG, PNG, WebP, GIF, BMP, dan AVIF bisa dikemas dalam komik yang sama. Pilih **Buat CBZ**, lalu **Unduh CBZ** untuk menyimpan `comic.cbz`. File tetap di perangkat Anda.

## Mengatur urutan halaman dan memilih sampul

Halaman baru diurutkan berdasarkan folder dan nama file, sehingga `page2.jpg` muncul sebelum `page10.jpg`. Seret halaman atau gunakan tombol panah atas dan bawah untuk mengubah urutannya. Pilih **Jadikan sampul** untuk memindahkan gambar ke halaman pertama. Gambar yang Anda tambahkan setelahnya akan masuk ke akhir daftar.

## Membaca komik yang sudah dibuat

CBZ adalah arsip ZIP berisi gambar halaman komik. Konverter mempertahankan file gambar asli dan memberi nomor pada nama file di arsip agar aplikasi pembaca komik menampilkan halaman sesuai urutan pilihan Anda. Buka hasilnya di [Pembaca Komik CBZ](/id/tools/cbz-reader/) atau impor ke koleksi komik Anda.
