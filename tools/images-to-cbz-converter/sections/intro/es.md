## Cómo crear un cómic CBZ a partir de imágenes

Usa **Elegir imágenes** para seleccionar archivos individuales o **Elegir carpeta** si tienes las páginas en una carpeta. También puedes arrastrar las imágenes al convertidor. Puedes combinar imágenes JPEG, PNG, WebP, GIF, BMP y AVIF en el mismo cómic. Selecciona **Crear CBZ** y luego **Descargar CBZ** para guardar `comic.cbz`. Tus archivos se quedan en tu dispositivo.

## Ordena las páginas y elige la portada

Las páginas nuevas se ordenan por carpeta y nombre de archivo, de modo que `page2.jpg` va antes de `page10.jpg`. Arrastra las páginas o usa las flechas para cambiar el orden. Selecciona **Usar como portada** para mover una imagen a la primera página. Si añades más imágenes después, se colocarán al final de la lista.

## Lee el cómic terminado

Un CBZ es un archivo ZIP que contiene las imágenes de las páginas. El convertidor conserva los archivos de imagen originales y les asigna nombres numerados para que el lector respete el orden que elegiste. Abre el resultado en el [lector de cómics CBZ](/es/tools/cbz-reader/) o impórtalo a tu biblioteca de cómics.
