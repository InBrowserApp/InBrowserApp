## Ve la notación ABC como partitura

Pega o escribe notación ABC, selecciona **Abrir archivo ABC** o pulsa **Probar un ejemplo**. La partitura se actualiza mientras editas, así que puedes comprobar una melodía, una repetición o un cambio de tonalidad desde el navegador. El navegador procesa los archivos y el texto que pegues.

## Lee el encabezado y escribe una melodía

Una melodía en ABC suele empezar con `X:` para el número de referencia y `T:` para el título. Usa `M:` para indicar el compás, `L:` para la duración predeterminada de las notas y `K:` para la tonalidad. Por ejemplo, `M:4/4`, `L:1/8` y `K:D` indican una melodía en re mayor y compás de cuatro por cuatro, con la corchea como duración predeterminada.

Escribe las notas con letras, separa los compases con `|` y usa `z` para escribir un silencio. El número que sigue a una nota multiplica su duración. Así, `D2` es una negra cuando la duración predeterminada es `L:1/8`. Empieza cada melodía con su propio encabezado `X:` para previsualizar una colección.

## Revisa la notación incompleta o inesperada

Si una parte de la partitura no queda como esperabas, revisa primero el compás, la duración de las notas y las barras de compás. Abre **Mensajes de notación ABC** cuando aparezca para localizar la sintaxis que no se pudo interpretar. La vista previa puede seguir mostrando los pasajes que se pueden leer mientras corriges el texto.

## Descargar partituras

Usa **Descargar** para guardar la partitura en páginas de tamaño A4. Elige PDF para imprimir, PNG para compartir una imagen nítida o SVG para cambiar el tamaño de la imagen sin perder detalle. Si la partitura ocupa más de una página, la descarga en PNG o SVG incluye un archivo por página dentro de un ZIP. Elige **Texto fuente ABC** para guardar el texto del editor en un archivo .abc y editarlo más adelante.
