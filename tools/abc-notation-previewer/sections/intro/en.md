## Preview ABC notation as sheet music

Paste or type ABC notation, choose **Open ABC file**, or select **Try an example**. The score updates as you edit, so you can check a melody, a repeat, or a change of key without opening a desktop notation program. Files and pasted text are processed in your browser.

## Read the header and write a melody

An ABC tune usually starts with `X:` for its reference number and `T:` for the title. Use `M:` for the meter, `L:` for the default note length, and `K:` for the key. For example, `M:4/4`, `L:1/8`, and `K:D` describe a tune in four-four time with eighth notes as the default length and D major as the key.

Write notes with letters, separate measures with `|`, and use `z` for a rest. A number after a note multiplies its length, so `D2` is a quarter note when `L:1/8`. Start another tune with its own `X:` header to preview a tune book.

## Check incomplete or unexpected notation

If part of the score looks different from what you expected, review the meter, note lengths, and bar lines first. Open **ABC notation messages** when it appears to locate syntax the renderer could not interpret. The preview can keep showing readable parts while you fix the source.
