## Convert an FB2 book to EPUB locally

Open a local FB2 book, an FBZ archive or an FB2.ZIP archive containing one book to create an EPUB reading copy. Conversion happens in your browser, without uploading the book or using a remote conversion service. Archives containing several books need to be extracted first so you can choose one.

## Keep readable chapters, illustrations and notes

The EPUB keeps available title and author information, chapter order, contents, cover and supported included images. Poetry, footnotes and supporting sections remain readable in a simple layout. Resolvable internal links continue to point to the book's included content. Empty sanitized sections are omitted.

Check the book preview and conversion notes before downloading. A missing required chapter stops conversion. Missing or unsupported optional resources are disclosed, and unavailable images are marked with a text placeholder. External links open only when selected; remote resources are not fetched.

## Compatibility and layout

This is a reflowable reading copy, not a reproduction of the original source design. It does not preserve source styles, exact pagination, interactive features, scripts, forms, audio or video. Encrypted archives and unsupported variants receive an error. Practical limits depend on browser resources; there is no fixed file-size or chapter-count quota.

To read the source, use [FB2 Reader](/tools/fb2-reader/). To inspect the converted book, use [EPUB Reader](/tools/epub-reader/). For plain text or standalone HTML, use [Ebook to Text / HTML Converter](/tools/ebook-text-html-export/).
