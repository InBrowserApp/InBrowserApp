## Converta um livro FB2 para EPUB localmente

Abra um livro local em FB2, um arquivo compactado FBZ ou um arquivo FB2.ZIP contendo um único livro para criar uma cópia de leitura em EPUB. A conversão acontece no navegador, sem enviar o livro nem usar um serviço remoto de conversão. Arquivos compactados contendo vários livros precisam ser extraídos primeiro para que você possa escolher um deles.

## Preserve capítulos legíveis, ilustrações e notas

O EPUB preserva as informações disponíveis de título e autor, a ordem dos capítulos, o sumário, a capa e as imagens incluídas compatíveis. Poesia, notas de rodapé e seções complementares permanecem legíveis em um layout simples. Os links internos cujos destinos podem ser localizados continuam apontando para o conteúdo incluído no livro. As seções que ficam vazias após a sanitização são omitidas.

Confira a prévia do livro e as notas sobre a conversão antes de baixar. A ausência de um capítulo necessário interrompe a conversão. Recursos opcionais ausentes ou não compatíveis são informados, e as imagens indisponíveis são sinalizadas com um texto substituto. Links externos só abrem quando selecionados; recursos remotos não são buscados.

## Compatibilidade e layout

Esta é uma cópia de leitura com layout fluido, não uma reprodução do design original. Ela não preserva os estilos originais, a paginação exata, recursos interativos, scripts, formulários, áudio ou vídeo. Arquivos compactados criptografados e variantes não compatíveis resultam em erro. Os limites práticos dependem dos recursos do navegador; não há um limite fixo de tamanho de arquivo ou quantidade de capítulos.

Para ler o original, use o [Leitor de FB2](/tools/fb2-reader/). Para conferir o livro convertido, use o [Leitor de EPUB](/tools/epub-reader/). Para texto simples ou HTML independente, use o [Conversor de e-books para TXT / HTML](/tools/ebook-text-html-export/).
