## CB7을 PDF로 변환하는 방법

`.cb7` 만화 파일을 선택하거나 변환기에 끌어다 놓으세요. 만화 이미지가 담긴 `.7z` 압축 파일도 변환할 수 있습니다. 이미지 한 장이 PDF 한 페이지가 됩니다. 미리보기에서 확인한 뒤 **PDF 다운로드**를 선택하세요. 예를 들어 `volume-01.cb7`은 `volume-01.pdf`로 저장됩니다.

## 페이지 순서와 화질, 글자 검색

CB7은 만화 페이지를 묶은 7z 압축 파일입니다. 변환기는 폴더를 포함한 전체 파일 경로의 숫자를 고려해 페이지를 정렬합니다. 예를 들어 `chapter2/page2.jpg`가 `chapter2/page10.jpg`보다 앞에 옵니다. 세로 페이지와 가로로 넓은 펼침면 모두 원본의 픽셀 크기와 비율을 유지합니다. JPEG, PNG, GIF, WebP, BMP를 지원하며 브라우저에서 읽을 수 있는 경우 AVIF도 변환할 수 있습니다.

글자는 그림의 일부로 남습니다. 대사를 검색하려면 변환한 PDF를 [PDF OCR](../pdf-ocr/)에서 열고 만화에 쓰인 언어를 선택하세요.

## 크거나 암호로 보호된 압축 파일을 변환하는 방법

변환은 기기에서 진행되며 처리 중인 페이지가 표시됩니다. 대용량 솔리드 7z 압축 파일에서는 여러 이미지가 같은 압축 블록에 들어 있으므로 페이지를 읽는 데 시간이 더 걸릴 수 있습니다. 작업을 멈추고 다른 파일을 고르려면 **변환 취소**를 선택하세요. 암호로 보호되어 있거나 여러 파일로 나뉜 경우에는 압축을 먼저 푼 뒤 암호가 없는 단일 압축 파일로 다시 묶으세요. 원본 만화를 보려면 [CB7 만화 리더](../cb7-reader/)를, ZIP 방식으로 압축된 만화를 변환하려면 [CBZ PDF 변환기](../cbz-to-pdf-converter/)를 이용하세요.
