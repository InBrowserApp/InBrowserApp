## PDF 책갈피를 추가하거나 편집하는 방법

PDF를 열면 기존 책갈피를 볼 수 있습니다. 책갈피가 없는 문서에는 새로 만들 수 있습니다. 페이지 미리보기에서 원하는 장이나 절을 찾은 뒤 **책갈피 추가**를 선택하세요. 새 책갈피를 클릭하면 미리 보고 있던 페이지로 이동합니다. 읽는 사람이 원하는 부분을 쉽게 찾을 수 있도록 내용을 알 수 있는 제목을 붙여 주세요.

1. 책갈피를 선택하면 이름을 바꾸거나 대상 페이지를 변경할 수 있습니다. 미리 보고 있는 페이지에 연결하려면 **현재 미리보기 페이지로 설정**을 선택하세요.
2. 책갈피를 위아래로 이동해 순서를 바꿀 수 있습니다. 관련 내용을 묶으려면 이전 책갈피의 하위로 옮기세요. 한 단계 위로 이동할 수도 있습니다. 책갈피를 삭제하면 하위 책갈피는 남고 한 단계 위로 이동합니다.
3. **PDF 다운로드**를 선택한 뒤 다운로드한 파일을 열고 PDF 뷰어의 책갈피 또는 문서 개요 패널을 확인하세요.

## PDF 책갈피란?

PDF 책갈피는 PDF 뷰어의 탐색 패널에 표시되는 링크입니다. 책갈피를 클릭하면 특정 장이나 부록 등 원하는 위치로 바로 이동할 수 있습니다. 매뉴얼, 보고서, 강의 자료처럼 긴 PDF는 하위 책갈피를 사용하면 필요한 내용을 찾기 쉽습니다. 책갈피는 탐색 패널에 표시되며, PDF 안에 인쇄된 목차는 페이지 내용의 일부입니다.

## 다운로드한 PDF에서 무엇이 바뀌나요?

다운로드한 사본에는 편집한 책갈피 구조가 저장됩니다. 페이지 내용과 순서는 그대로 유지됩니다. 대상 페이지를 변경하기 전까지는 기존 링크와 정확한 이동 위치가 유지됩니다. PDF는 파일을 업로드하지 않고 브라우저에서 직접 읽고 저장합니다.
