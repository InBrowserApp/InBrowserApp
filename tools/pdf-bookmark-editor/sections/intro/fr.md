## Ajouter ou modifier des signets dans un PDF

Ouvrez un PDF pour consulter les signets existants ou créer une arborescence si le document n’en contient pas encore. Repérez un chapitre ou une section dans l’aperçu, puis sélectionnez **Ajouter un signet**. Le nouveau signet pointe vers la page affichée. Donnez-lui un titre explicite pour aider les lecteurs à retrouver la section.

1. Sélectionnez un signet pour le renommer ou changer sa page cible. Pour le faire pointer vers la page visible dans l’aperçu, choisissez **Utiliser la page affichée**.
2. Déplacez les signets vers le haut ou vers le bas pour en changer l’ordre. Imbriquez un signet sous le précédent pour regrouper des sections ou faites-le remonter d’un niveau. Si vous supprimez un signet, ses sous-signets sont conservés et remontent d’un niveau.
3. Sélectionnez **Télécharger le PDF**, puis ouvrez la copie téléchargée et affichez le panneau des signets ou du plan dans votre visionneuse PDF.

## À quoi servent les signets PDF ?

Les signets forment un plan cliquable dans une visionneuse PDF. Chaque signet peut mener directement à un chapitre, à une annexe ou à une autre destination. Les signets imbriqués facilitent la navigation dans les longs manuels, rapports et supports de cours. Ils figurent dans le panneau de navigation, tandis qu’une table des matières imprimée dans le PDF fait partie du contenu des pages.

## Qu’est-ce qui change dans le PDF téléchargé ?

La copie contient l’arborescence de signets modifiée. Le contenu et l’ordre des pages restent identiques. Les liens existants et les emplacements précis vers lesquels ils pointent sont conservés tant que vous ne changez pas leur destination. L’outil lit et enregistre le PDF dans votre navigateur, sans transmettre le fichier.
