## WARC 形式のウェブアーカイブを開く

`.warc` または `.warc.gz` ファイルを選択またはドラッグ＆ドロップします。サンプルでも試せます。ビューアーは収集レコードを一覧にまとめ、アーカイブ内で最初に見つかった HTML ページを表示します。URL またはレコードの種類で絞り込んで目的のレコードを探し、ページのプレビューとレコードの詳細を切り替えられます。大きなアーカイブはインデックスの作成に時間がかかる場合があります。ファイルの処理はブラウザー内で完結します。

## 取得日時とヘッダーを確認する

Web ARChive（WARC）ファイルには、クローラーやアーカイブツールがウェブサイトにアクセスした際に収集したレコードが保存されています。同じ URL に複数のレコードがある場合は、取得日時（UTC）と取得時の HTTP ステータスで見分けられます。レスポンスレコードにはサーバーからの応答が、リクエストレコードにはクローラーが送信した内容が記録されています。再訪問レコードはページを再度保存せず、別の取得結果を参照している場合があります。ページをプレビューできない場合でも、レコードの詳細は確認できます。

## プレビューには何が表示されますか？

静的プレビューには、同じアーカイブに保存されている HTML と、対応する形式の画像やスタイルシートが使われます。アーカイブに含まれないリソースがあると、レイアウトが崩れたり、空白ができたりすることがあります。スクリプトは無効で、元のサイトにはリクエストを送信しないため、ログインや動画再生などの操作はできません。WARC 1.0・1.1 および gzip で圧縮されたレコードに対応しています。
