## เปิดไฟล์เก็บถาวรเว็บ WARC

เลือกหรือลากไฟล์ `.warc` หรือ `.warc.gz` มาวาง หรือลองเปิดไฟล์เก็บถาวรตัวอย่าง โปรแกรมจะสร้างรายการบันทึกการเก็บข้อมูลและเปิดหน้า HTML หน้าแรกที่พบในไฟล์ กรองตาม URL หรือประเภทบันทึกเพื่อค้นหารายการที่ต้องการ แล้วสลับระหว่างตัวอย่างหน้าเว็บกับรายละเอียดบันทึก ไฟล์ขนาดใหญ่อาจใช้เวลาสร้างดัชนีสักครู่ ระบบจะประมวลผลไฟล์ในเบราว์เซอร์ของคุณ

## ดูเวลาที่บันทึกและส่วนหัว

ไฟล์ Web ARChive (WARC) เก็บบันทึกที่ได้จากโปรแกรมรวบรวมข้อมูลเว็บหรือเครื่องมือจัดเก็บเมื่อเข้าเว็บไซต์ URL เดียวกันอาจมีหลายบันทึก แยกแต่ละรายการได้จากเวลาที่บันทึกในเขตเวลา UTC และสถานะ HTTP ณ เวลานั้น บันทึกการตอบกลับมีคำตอบจากเซิร์ฟเวอร์ ส่วนบันทึกคำขอระบุข้อมูลที่โปรแกรมรวบรวมข้อมูลเว็บส่งออกไป บันทึกการเข้าชมซ้ำอาจอ้างอิงข้อมูลที่เก็บไว้ครั้งอื่นโดยไม่ต้องบันทึกหน้าเดิมซ้ำ คุณยังเปิดดูรายละเอียดของบันทึกเหล่านี้ได้แม้จะไม่มีตัวอย่างหน้าเว็บ

## ตัวอย่างหน้าเว็บแสดงอะไรบ้าง?

ตัวอย่างแบบคงที่ใช้ HTML รูปภาพ และสไตล์ชีตที่รองรับจากไฟล์เก็บถาวรเดียวกัน หากมีทรัพยากรขาดหายไป เค้าโครงอาจเปลี่ยนหรือบางส่วนอาจว่างเปล่า โปรแกรมจะปิดการทำงานของสคริปต์และไม่ส่งคำขอไปยังเว็บไซต์ต้นฉบับ จึงใช้งานฟังก์ชันโต้ตอบอย่างการเข้าสู่ระบบหรือเล่นวิดีโอไม่ได้ โปรแกรมรองรับ WARC 1.0 และ 1.1 รวมถึงบันทึกที่บีบอัดด้วย gzip
