## 開啟 WARC 網頁封存檔

選取或拖放 `.warc` 或 `.warc.gz` 檔案，也可以試用範例封存檔。檢視器會列出擷取記錄，並開啟封存檔中第一個找到的 HTML 網頁。依網址或記錄類型篩選，找到要查看的記錄後，即可在網頁預覽與記錄詳細資料之間切換。大型封存檔可能需要較長時間建立索引。檔案會留在瀏覽器中處理。

## 查看擷取時間與標頭

Web ARChive（WARC）檔案會儲存網路爬蟲或封存工具造訪網站時收集的記錄。同一個網址可能有多筆記錄，可以透過 UTC 擷取時間和原始 HTTP 狀態區分。回應記錄包含伺服器的回覆，要求記錄會描述爬蟲送出的內容，重新造訪記錄則可能參照另一次擷取，省下重複儲存網頁的空間。即使沒有可預覽的網頁，你仍可查看這些記錄。

## 預覽會顯示哪些內容？

靜態預覽會使用同一個封存檔中的 HTML，以及支援的圖片和樣式表。如果資源有缺漏，版面可能會改變，部分內容也可能留白。預覽會停用指令碼，且不會向原始網站傳送要求，因此無法登入或播放影片。檢視器支援 WARC 1.0 和 1.1，也支援使用 gzip 壓縮的記錄。
