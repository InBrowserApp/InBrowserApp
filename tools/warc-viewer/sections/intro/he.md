## פתיחת ארכיון אינטרנט מסוג WARC

בחרו קובץ `.warc` או `.warc.gz` או גררו אותו לחלון, או פתחו את הארכיון לדוגמה. המציג יוצר רשימה של רשומות הלכידה ופותח את דף ה־HTML הראשון שנשמר. סננו לפי כתובת URL או סוג רשומה כדי למצוא לכידה מסוימת, ואז עברו בין התצוגה המקדימה של הדף לפרטי הרשומה. הכנת האינדקס לארכיון גדול עשויה להימשך זמן מה. הקובץ נשאר בדפדפן.

## קריאת תאריכי לכידה וכותרות

קובץ Web ARChive ‏(WARC) מכיל רשומות שאוסף סורק אינטרנט או כלי ארכוב בעת ביקור באתר. לאותה כתובת URL יכולות להיות כמה רשומות. כדי להבדיל ביניהן, בדקו את מועד הלכידה לפי UTC ואת סטטוס ה־HTTP המקורי. רשומת תגובה (`response`) מכילה את התשובה מהשרת, ורשומת בקשה (`request`) מתארת את מה שהסורק שלח. רשומת ביקור חוזר (`revisit`) עשויה להפנות ללכידה אחרת בלי לשמור שוב את הדף. אפשר לבדוק את הרשומות האלה גם כשאין תצוגה מקדימה של הדף.

## מה כוללת התצוגה המקדימה?

התצוגה המקדימה הסטטית משתמשת ב־HTML, בתמונות ובגיליונות סגנון נתמכים שנשמרו באותו ארכיון. משאבים חסרים עלולים לשנות את הפריסה או להשאיר אזורים ריקים. סקריפטים מושבתים והתצוגה אינה שולחת בקשות לאתר המקורי, לכן פעולות אינטראקטיביות כמו התחברות והפעלת וידאו אינן זמינות. המציג תומך בגרסאות WARC 1.0 ו־WARC 1.1, כולל רשומות דחוסות ב־gzip.
