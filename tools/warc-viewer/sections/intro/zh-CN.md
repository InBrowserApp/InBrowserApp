## 打开 WARC 网页归档

选择或拖放 `.warc` 或 `.warc.gz` 文件，也可以试用示例归档。查看器会列出采集记录，并打开归档中第一个找到的 HTML 网页。按网址或记录类型筛选，找到目标记录后，即可在网页预览和记录详情之间切换。大型归档建立索引可能需要一些时间。文件留在浏览器中处理。

## 查看采集时间和标头

Web ARChive（WARC）文件保存爬虫或归档工具访问网站时收集的记录。同一个网址可能有多条记录，可以通过 UTC 采集时间和原始 HTTP 状态区分。响应记录包含服务器的回复，请求记录描述爬虫发送的内容，重访记录则可能引用另一次采集，省去再次保存网页的空间。即使没有网页可预览，你也可以查看这些记录。

## 预览会显示什么？

静态预览使用同一归档中保存的 HTML 以及受支持的图片和样式表。资源缺失时，页面布局可能发生变化，部分内容也可能留白。预览会停用脚本，且不会向原网站发送请求，因此无法登录或播放视频。查看器支持 WARC 1.0 和 1.1，也支持经过 gzip 压缩的记录。
