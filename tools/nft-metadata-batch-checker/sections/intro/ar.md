## فحص بيانات NFT الوصفية بصيغة JSON قبل السكّ

اختر **ملفات محلية** لفحص ملفات JSON منفردة أو مجلد مجموعة NFT على جهازك. تعرض الأداة أخطاء JSON ومشكلات البيانات الوصفية الشائعة في كل عنصر، مثل الأسماء الفارغة والصور الناقصة والأوصاف غير الصالحة والسمات ذات البنية غير الصحيحة. اختر **تحتاج إلى مراجعة** للعثور على العناصر المطلوب إصلاحها، أو نزّل التقرير الكامل بصيغة JSON.

## فحص عناوين URI للرموز دفعة واحدة

ضمن **عناوين URI للرموز**، ألصق عنوان بيانات وصفية واحدًا في كل سطر. للمجموعات المرقّمة، استخدم **قالب URI** مع عنصر نائب مثل `https://example.com/metadata/{id}.json`. حدّد أول معرّف وآخر معرّف لفحص النطاق بما فيه طرفاه. تستخدم الصيغة العشرية المعرّف كما كُتب. أما صيغة **سداسية عشرية وفق ERC-1155** فتكتب كل معرّف في 64 خانة سداسية عشرية بأحرف صغيرة، وتضيف أصفارًا على اليسار عند الحاجة، وفق قواعد استبدال `{id}` في ERC-1155.

## فحص روابط الصور والرسوم المتحركة في NFT

فعّل **تحقّق من توفّر الوسائط** لفحص روابط `image` و`animation_url`. اختر المجلد المحلي كاملًا ليشمل الفحص ملفات الوسائط المشار إليها بمسارات نسبية. يمكن للمتصفح أيضًا فحص موارد HTTP وIPFS وArweave. قد يتعذّر تأكيد توفّر رابط بسبب خطأ في البوابة، أو انتهاء مهلة الطلب، أو قيود الطلبات بين مصادر مختلفة. راجع هذه الروابط في البوابة أو السوق الذي تستخدمه. تُفحص الملفات المحلية داخل المتصفح، ويُرسل فحص عناوين URI طلبات إلى الخادم المضيف أو البوابة المعنية.

للاطّلاع على تعريفات الحقول وقواعد استبدال المعرّف في عنوان URI للرمز، راجع [دليل OpenSea للبيانات الوصفية](https://docs.opensea.io/docs/metadata-standards) و[مواصفة ERC-1155 للبيانات الوصفية](https://eips.ethereum.org/EIPS/eip-1155#metadata).
