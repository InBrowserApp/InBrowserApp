## ミント前に NFT メタデータの JSON をチェックする

**ローカルファイル** を選ぶと、端末上の個別の JSON ファイルやコレクションのフォルダーを確認できます。無効な JSON のほか、名前が空、画像がない、説明が無効、属性の形式が不正など、メタデータのよくある問題を項目ごとに表示します。**要確認** で修正が必要な項目を探したり、レポート全体を JSON でダウンロードしたりできます。

## トークン URI を一括でチェックする

**トークン URI** では、メタデータのアドレスを 1 行に 1 件ずつ貼り付けます。連番のコレクションには **URI パターン** を選び、`https://example.com/metadata/{id}.json` のようにプレースホルダーを含む URI を指定します。開始 ID と終了 ID を指定すると、両端を含む範囲を確認できます。10 進数の形式では、入力した ID をそのまま使います。**ERC-1155 の 16 進数** では、ERC-1155 の `{id}` 置換規則に従い、先頭をゼロで埋めて各 ID を小文字の 16 進数 64 桁で表します。

## NFT の画像リンクやアニメーションリンクを確認する

**メディアにアクセスできるか確認** を有効にすると、`image` と `animation_url` のリンクを確認します。相対パスで参照されるメディアを含めるには、端末上のフォルダー全体を選択してください。ブラウザは HTTP、IPFS、Arweave のリソースも確認できます。ゲートウェイのエラー、タイムアウト、クロスオリジン制限があると、リンクを確認できない場合があります。該当するリンクは、利用しているゲートウェイやマーケットプレイスで確認してください。ローカルファイルはブラウザ内で処理し、URI の確認では対象のホストやゲートウェイに接続します。

項目の定義やトークン URI の置換については、[OpenSea メタデータガイド](https://docs.opensea.io/docs/metadata-standards)と [ERC-1155 メタデータ仕様](https://eips.ethereum.org/EIPS/eip-1155#metadata)を参照してください。
