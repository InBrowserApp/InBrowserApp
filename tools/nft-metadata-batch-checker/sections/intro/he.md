## בדיקת מטא-נתוני NFT בפורמט JSON לפני ההטבעה

בחרו **קבצים מקומיים** כדי לבדוק קובצי JSON בודדים או תיקייה של אוסף במכשיר שלכם. הכלי מדווח על JSON לא תקין ועל בעיות נפוצות במטא-נתונים של כל פריט, כגון שמות ריקים, תמונות חסרות, תיאורים לא תקינים ומאפיינים במבנה שגוי. בחרו **דורשים בדיקה** כדי לאתר את הפריטים שצריך לתקן, או הורידו את הדוח המלא כ-JSON.

## בדיקה מרוכזת של כתובות URI של טוקנים

בכרטיסייה **כתובות URI של טוקנים**, הדביקו כתובת מטא-נתונים אחת בכל שורה. באוספים ממוספרים, השתמשו ב-**תבנית URI** עם מציין מקום, למשל `https://example.com/metadata/{id}.json`. הגדירו את המזהה הראשון והאחרון כדי לבדוק את כל הטווח, כולל שני הקצוות. בפורמט העשרוני משתמשים במזהה כפי שנכתב. בפורמט **הקסדצימלי לפי ERC-1155** כל מזהה נכתב ב-64 תווים הקסדצימליים, באותיות קטנות ועם אפסים מובילים לפי הצורך, בהתאם לכללי ההחלפה של `{id}` בתקן ERC-1155.

## בדיקת קישורי תמונות והנפשות ב-NFT

הפעילו את האפשרות **בדיקת זמינות מדיה** כדי לבדוק את הקישורים בשדות `image` ו-`animation_url`. בחרו את כל התיקייה המקומית כדי לכלול קובצי מדיה שמצוינים בנתיבים יחסיים. הדפדפן יכול לבדוק גם משאבי HTTP,‏ IPFS ו-Arweave. אם שער מחזיר שגיאה, זמן ההמתנה מסתיים או שהדפדפן מגביל בקשות בין מקורות, ייתכן שלא ניתן יהיה לאמת את הקישור. בדקו את הקישורים הללו בשער או בזירת המסחר שבהם אתם משתמשים. בדיקות של קבצים מקומיים מתבצעות בדפדפן, ובדיקות של כתובות URI פונות לשרת או לשער הרלוונטי.

להגדרות השדות ולכללי החלפת המזהה בכתובת URI של טוקן, עיינו ב[מדריך המטא-נתונים של OpenSea](https://docs.opensea.io/docs/metadata-standards) וב[מפרט המטא-נתונים של ERC-1155](https://eips.ethereum.org/EIPS/eip-1155#metadata).
