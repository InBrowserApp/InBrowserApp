## ตรวจสอบ JSON ข้อมูลเมตาของ NFT ก่อนมินต์

เลือก **ไฟล์ในเครื่อง** เพื่อตรวจสอบไฟล์ JSON ทีละไฟล์หรือทั้งโฟลเดอร์ของคอลเลกชันในอุปกรณ์ เครื่องมือจะรายงาน JSON ที่ไม่ถูกต้องและปัญหาข้อมูลเมตาที่พบบ่อยในแต่ละรายการ เช่น ชื่อว่าง ไม่มีรูปภาพ คำอธิบายไม่ถูกต้อง หรือรูปแบบแอตทริบิวต์ไม่ถูกต้อง ใช้ **ควรตรวจสอบ** เพื่อหารายการที่ต้องแก้ หรือเลือก **ดาวน์โหลด JSON** เพื่อบันทึกรายงานฉบับเต็ม

## ตรวจสอบ URI ของโทเคนหลายรายการ

ใน **URI ของโทเคน** ให้วางที่อยู่ข้อมูลเมตาหนึ่งรายการต่อบรรทัด สำหรับคอลเลกชันที่ใช้หมายเลข ให้ใช้ **รูปแบบ URI** ที่มีตัวแทนค่า เช่น `https://example.com/metadata/{id}.json` ระบุ ID แรกและ ID สุดท้ายเพื่อตรวจสอบทั้งช่วงโดยรวม ID ทั้งสองค่าด้วย รูปแบบเลขฐานสิบใช้ ID ตามที่ป้อน ส่วน **เลขฐานสิบหก ERC-1155** จะแปลงแต่ละ ID เป็นเลขฐานสิบหก 64 อักขระ ใช้ตัวอักษรพิมพ์เล็กและเติมศูนย์ด้านหน้าตามกฎการแทนค่า `{id}` ของ ERC-1155

## ตรวจสอบลิงก์รูปภาพและแอนิเมชันของ NFT

เปิด **ตรวจสอบว่าสื่อเข้าถึงได้หรือไม่** เพื่อตรวจสอบลิงก์ `image` และ `animation_url` เลือกทั้งโฟลเดอร์ในเครื่องเพื่อตรวจสอบสื่อที่อ้างอิงด้วยพาธสัมพัทธ์ เบราว์เซอร์ตรวจสอบทรัพยากร HTTP, IPFS และ Arweave ได้ด้วย ข้อผิดพลาดของเกตเวย์ การหมดเวลา หรือข้อจำกัดข้ามต้นทางอาจทำให้ยืนยันลิงก์ไม่ได้ ให้ตรวจสอบลิงก์เหล่านั้นบนเกตเวย์หรือตลาดซื้อขายที่คุณใช้ เบราว์เซอร์ตรวจสอบไฟล์ในเครื่องโดยตรง และติดต่อโฮสต์หรือเกตเวย์ที่เกี่ยวข้องเมื่อตรวจสอบ URI

ดูคำอธิบายฟิลด์และวิธีแทนค่าใน URI ของโทเคนเพิ่มเติมใน [คู่มือข้อมูลเมตาของ OpenSea](https://docs.opensea.io/docs/metadata-standards) และ [ข้อกำหนดข้อมูลเมตา ERC-1155](https://eips.ethereum.org/EIPS/eip-1155#metadata)
