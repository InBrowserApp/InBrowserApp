## 민팅 전에 NFT 메타데이터 JSON 검사하기

**로컬 파일**을 선택해 기기에 저장된 개별 JSON 파일이나 컬렉션 폴더를 검사하세요. `1`이나 `42`처럼 번호로 된 파일도 바로 선택할 수 있습니다. 도구는 유효하지 않은 JSON과 비어 있는 이름, 누락된 이미지, 잘못된 설명 또는 속성 형식처럼 흔한 메타데이터 문제를 항목별로 표시합니다. **검토 필요**를 선택해 수정할 항목을 찾거나, 전체 보고서를 JSON으로 다운로드할 수 있습니다.

## 토큰 URI 일괄 검사하기

**토큰 URI**에서 메타데이터 주소를 한 줄에 하나씩 붙여넣으세요. 번호가 매겨진 컬렉션에는 **URI 패턴**을 선택하고 `https://example.com/metadata/{id}.json`처럼 자리표시자가 있는 URI를 사용하세요. 시작 ID와 종료 ID를 설정하면 양쪽 끝을 포함한 범위를 검사합니다. 10진수 형식은 입력한 ID를 그대로 사용합니다. **ERC-1155 16진수**는 ERC-1155의 `{id}` 치환 규칙에 따라 앞에 0을 채워 각 ID를 소문자 16진수 64자리로 표시합니다. 이미지 링크 등 메타데이터 값에 있는 `{id}`도 치환합니다.

## NFT 이미지 및 애니메이션 링크 확인하기

**미디어에 접근할 수 있는지 확인**을 켜면 `image`와 `animation_url` 링크를 검사합니다. 상대 경로로 참조하는 미디어를 포함하려면 로컬 폴더 전체를 선택하세요. `/`로 시작하는 경로는 선택한 폴더의 최상위에서 찾습니다. 브라우저는 HTTP, IPFS, Arweave 리소스도 검사할 수 있습니다. 게이트웨이 오류, 시간 초과 또는 교차 출처 제한으로 링크를 확인하지 못할 수 있습니다. 해당 링크는 사용 중인 게이트웨이나 마켓플레이스에서 확인하세요. 로컬 파일은 브라우저에서 검사하며, URI를 검사할 때는 해당 호스트나 게이트웨이에 연결합니다.

필드 정의와 토큰 URI 치환 규칙은 [OpenSea 메타데이터 가이드](https://docs.opensea.io/docs/metadata-standards)와 [ERC-1155 메타데이터 사양](https://eips.ethereum.org/EIPS/eip-1155#metadata)을 참고하세요.
