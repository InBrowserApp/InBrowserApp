## Как открыть Shapefile

Перетащите ZIP-архив с набором Esri Shapefile в область просмотра. Можно также выбрать файл .shp вместе с сопутствующими файлами. Если в ZIP-архиве несколько наборов Shapefile, переключайтесь между ними в меню **Слой**. Нажмите **Загрузить пример**, чтобы изучить тестовый набор из двух слоёв с точками и полигонами. Браузер читает файлы локально на вашем устройстве.

## Какие файлы нужны для просмотра Shapefile?

В файле .shp хранится геометрия. Его достаточно, чтобы просмотреть слой с географическими координатами. Если есть сопутствующие файлы, добавьте .dbf с атрибутами, .prj с системой координат и .cpg с указанием кодировки текста атрибутов. Храните файлы одного слоя вместе и используйте для них одинаковое имя до расширения. Индекс .shx можно оставить в ZIP-архиве или выбрать вместе с остальными файлами.

## Как изучать карту и атрибуты

Офлайн-карта подбирает масштаб так, чтобы был виден весь текущий слой. Используйте кнопки карты, чтобы изменить масштаб или снова показать весь слой. Выберите геометрию на карте или элемент в списке **Объекты**, чтобы увидеть его атрибуты. По поддерживаемому файлу .prj инструмент преобразует координаты из проекции для отображения на карте. Без такого файла координаты в допустимых диапазонах долготы и широты считаются координатами WGS 84. Если исходный слой использует проекцию, повторно откройте его с файлом .prj, чтобы разместить слой корректно.
