## Como converter Mermaid em imagem

Cole código Mermaid ou abra um arquivo local `.mmd`, `.mermaid`, `.md` ou `.txt`. O conversor aceita código Mermaid puro e um único bloco de código Mermaid copiado do Markdown. Experimente o fluxograma, o diagrama de sequência ou o diagrama ER incluído para ver o código e o resultado.

Confira a prévia, escolha um formato e selecione **Baixar imagem**. Por exemplo, abra `release-flow.mmd` e escolha PNG em **2×** para salvar uma versão mais nítida do fluxograma para uma apresentação. A imagem contém o diagrama inteiro.

## Qual formato de imagem escolher?

- **PNG** é uma opção sem perdas para diagramas em apresentações e documentos. Ele pode manter o fundo transparente.
- **SVG** mantém o diagrama em formato vetorial para ampliá-lo sem pixelização. Os controles de escala rasterizada e fundo não se aplicam ao SVG.
- **JPG** usa fundo branco e funciona na maioria dos aplicativos que aceitam imagens.
- **WebP** é uma opção prática para publicar diagramas na web e pode manter a transparência.

Use **1×** para o tamanho natural do diagrama em pixels ou **2×** para dobrar a largura e a altura. A escala altera as dimensões da imagem baixada e mantém o mesmo layout.

## Como usar seu diagrama em outros lugares

A renderização e a exportação acontecem no navegador. Guarde o código Mermaid original se quiser editar o diagrama mais tarde. Abra o [Pré-visualizador de Mermaid](../mermaid-previewer/) para examinar um diagrama ou use o [Conversor de Mermaid para PDF](../mermaid-to-pdf-converter/) para obter um PDF vetorial com opções de tamanho de papel.
