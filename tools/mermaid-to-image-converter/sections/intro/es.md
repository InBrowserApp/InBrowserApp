## Cómo convertir Mermaid en una imagen

Pega código Mermaid o abre un archivo local `.mmd`, `.mermaid`, `.md` o `.txt`. El conversor admite código Mermaid sin procesar y un único bloque de código Mermaid copiado de Markdown. Prueba el diagrama de flujo, de secuencia o de entidad-relación incluido para ver tanto el código como el resultado.

Comprueba la vista previa, elige un formato y selecciona **Descargar imagen**. Por ejemplo, abre `release-flow.mmd` y elige PNG a **2×** para guardar una versión más nítida del diagrama de flujo para una presentación. La imagen contiene el diagrama completo.

## ¿Qué formato de imagen debo elegir?

- **PNG** es una opción sin pérdida para diagramas en presentaciones y documentos. Puede conservar el fondo transparente.
- **SVG** mantiene el diagrama como vector para ampliarlo sin pixelación. Los controles de escala de imagen y fondo no se aplican a SVG.
- **JPG** usa un fondo blanco y funciona en la mayoría de las aplicaciones que admiten imágenes.
- **WebP** es una opción práctica para publicar diagramas en la web y puede conservar la transparencia.

Usa **1×** para el tamaño natural en píxeles del diagrama o **2×** para duplicar el ancho y el alto. La escala cambia las dimensiones de la imagen descargada y mantiene el mismo diseño.

## Usar el diagrama en otros lugares

El procesamiento y la exportación se realizan en el navegador. Guarda el código Mermaid original si quieres editar el diagrama más adelante. Abre la [Vista previa de Mermaid](../mermaid-previewer/) para inspeccionar un diagrama o usa el [Conversor de Mermaid a PDF](../mermaid-to-pdf-converter/) para obtener un PDF vectorial con opciones de tamaño de papel.
