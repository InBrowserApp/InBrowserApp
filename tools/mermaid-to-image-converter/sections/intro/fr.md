## Comment convertir Mermaid en image

Collez du code Mermaid ou ouvrez un fichier local `.mmd`, `.mermaid`, `.md` ou `.txt`. Le convertisseur accepte le code Mermaid brut et un seul bloc de code Mermaid copié depuis Markdown. Essayez le diagramme de flux, de séquence ou entité-association intégré pour voir le code source et le résultat.

Vérifiez l’aperçu, choisissez un format, puis sélectionnez **Télécharger l’image**. Par exemple, ouvrez `release-flow.mmd` et choisissez PNG à **2×** pour enregistrer une version plus nette du diagramme de flux pour une présentation. L’image contient tout le diagramme.

## Quel format d’image choisir ?

- **PNG** est un format sans perte adapté aux diagrammes dans les présentations et les documents. Il peut conserver un fond transparent.
- **SVG** conserve le diagramme sous forme vectorielle pour l’agrandir sans pixellisation. Les réglages d’échelle matricielle et de fond ne s’appliquent pas au SVG.
- **JPG** utilise un fond blanc et fonctionne dans la plupart des applications qui acceptent les images.
- **WebP** est pratique pour publier des diagrammes sur le Web et peut conserver la transparence.

Utilisez **1×** pour les dimensions naturelles du diagramme en pixels ou **2×** pour doubler sa largeur et sa hauteur. L’échelle modifie les dimensions de l’image téléchargée tout en conservant la même mise en page.

## Utiliser votre diagramme ailleurs

Le rendu et l’exportation s’effectuent dans votre navigateur. Conservez le code Mermaid original si vous souhaitez modifier le diagramme plus tard. Ouvrez l’[Aperçu Mermaid](../mermaid-previewer/) pour examiner un diagramme ou utilisez le [Convertisseur Mermaid en PDF](../mermaid-to-pdf-converter/) pour obtenir un PDF vectoriel avec des options de format de papier.
