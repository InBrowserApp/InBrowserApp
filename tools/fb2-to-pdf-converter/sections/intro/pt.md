## Como converter FB2 para PDF

Abra um livro `.fb2` ou arraste-o para o conversor. Você também pode usar um arquivo compactado `.fb2.zip` ou `.fbz` que contenha um único livro. Confira a prévia dos capítulos e escolha **A4**, **A5** ou **Carta (EUA)**. Clique em **Salvar como PDF**. Na janela de impressão do navegador, escolha **Salvar como PDF** como destino e confirme. Para remover a data e o endereço da página, desative **Cabeçalhos e rodapés** nas opções de impressão.

## O que acontece com o texto do livro?

O texto original continua selecionável e pesquisável no PDF, inclusive em cirílico. O arquivo usa um layout simples para impressão e preserva a ordem dos capítulos, as quebras de linha dos versos, a capa quando disponível, as ilustrações incorporadas e os links para as notas que o conversor consegue ler. A paginação segue o tamanho de papel escolhido. Palavras desenhadas dentro de uma ilustração continuam fazendo parte da imagem.

## Quando usar outro formato

Use PDF para imprimir o livro ou compartilhar uma cópia com páginas de tamanho fixo. Para ajustar o tamanho do texto em um leitor digital, use o [Conversor de FB2 para EPUB](../fb2-to-epub-converter/). Se quiser apenas abrir o livro, use o [Leitor de FB2](../fb2-reader/). O livro fica no seu dispositivo.
