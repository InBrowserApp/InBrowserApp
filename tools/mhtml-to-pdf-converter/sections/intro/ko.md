## 저장된 웹 아카이브를 로컬에서 변환하기

로컬 `.mhtml` 또는 `.mht` 아카이브를 열고 생성된 페이지를 확인한 다음 미리보기에 표시된 PDF를 다운로드하세요. PDF 파일을 직접 생성하므로 인쇄 대화상자가 필요하지 않습니다. 기본 문서는 아카이브에 포함된 이미지와 스타일을 사용합니다. 변환 없이 읽으려면 [MHTML 뷰어](../mhtml-viewer/)를 사용하세요. 일반 HTML 문서는 [HTML PDF 변환기](../html-to-pdf-converter/)를, 저장된 이메일은 [이메일 뷰어](../email-viewer/)를 사용하세요.

## 인쇄 결과 및 지원되는 저장 파일

아카이브의 기본 문서를 여백이 18 mm인 A4 세로 페이지에 재배치한 다음 150 DPI 이미지 페이지로 캡처합니다. 지원되는 제목, 문단, 목록, 표, 코드, 명시적 페이지 나누기, 기본 스타일 및 포함된 래스터 이미지가 반영됩니다. 너비가 넓은 표와 코드는 페이지 너비에 맞게 재배치됩니다. PDF의 텍스트는 선택할 수 없으며 OCR과 대화형 링크는 추가되지 않습니다. 글꼴, 간격 및 페이지 나누기가 저장된 페이지와 다를 수 있습니다. 결과물을 사용하기 전에 모든 페이지를 확인하세요.

불완전한 아카이브, 지원하지 않는 텍스트 인코딩, 누락된 리소스, 읽을 수 없는 이미지 또는 지원하지 않는 인쇄 콘텐츠가 있으면 변환이 중단되며 일부만 변환된 파일은 다운로드할 수 없습니다. 삽입된 프레임이나 추가 페이지가 포함된 아카이브는 먼저 기본 문서만 따로 저장해야 합니다. 스크립트, 양식, 삽입된 앱, SVG 및 MathML은 제외됩니다. 복잡한 웹사이트 레이아웃과 포함된 글꼴은 지원하지 않습니다. 화면 전용 반응형 스타일은 인쇄 페이지에 적용되지 않으며 원본 용지 크기는 고정된 A4 레이아웃으로 대체됩니다.

## 개인정보 보호 및 브라우저 리소스

아카이브는 이 브라우저 안에만 유지됩니다. 포함된 리소스는 파일에서 읽으며, 누락된 콘텐츠나 원격 콘텐츠를 가져오거나 원본 웹사이트에 접속하지 않습니다. 파일 내용은 업로드되지 않습니다. 각 페이지를 이미지로 렌더링하므로 대용량 아카이브는 시간과 메모리를 많이 사용할 수 있습니다. 변환을 취소하거나 아카이브를 닫거나 바꿀 수 있습니다. 정해진 파일 크기나 페이지 수 제한은 없으며, 실제 브라우저 리소스 부족을 감지할 수 있는 경우 오류를 표시합니다.
