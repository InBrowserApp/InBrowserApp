## Come aprire un file PST di Outlook senza Outlook

Un file PST (Personal Storage Table, .pst) è un file di dati di Outlook. Può contenere cartelle di posta, messaggi e allegati. Apri un file PST qui sopra e scegli una cartella, oppure cerca in tutte le cartelle per oggetto, mittente o destinatario. Seleziona un messaggio per leggerlo e scaricare gli allegati salvati nell’archivio.

## Come trovare o esportare un file PST di Outlook

Nella versione classica di Outlook per Windows, vai a File, poi Apri & Esporta e Importa/Esporta. Scegli Esporta in un file, poi File di dati di Outlook (.pst). Seleziona la cassetta postale o la cartella da salvare e spunta Includi sottocartelle se vuoi conservare l’intera struttura delle cartelle. Se hai già un archivio PST, aprilo direttamente qui.

## Cosa puoi leggere nel Visualizzatore PST

Il visualizzatore legge la posta dai file PST sul tuo dispositivo e blocca i contenuti remoti nei messaggi HTML. Contatti, elementi del calendario e attività rimangono nel file originale. Un file OST è la cache offline di Outlook, mentre un MSG contiene un singolo elemento di Outlook. Per aprire una cassetta postale qui, esportala da Outlook in formato PST. Gli archivi di grandi dimensioni possono impiegare più tempo ad aprirsi, a seconda della memoria disponibile per il browser.
