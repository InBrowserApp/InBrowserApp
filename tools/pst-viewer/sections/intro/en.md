## Open an Outlook PST file without Outlook

A Personal Storage Table (.pst) is an Outlook Data File. It can contain email folders, messages, and the files attached to those messages. Open a PST file above, choose a mail folder, or search across all folders by subject, sender, or recipient. Select a message to read it and download the attached files saved inside the archive.

## Find or export your Outlook PST

In classic Outlook for Windows, choose File, Open & Export, then Import/Export. Select Export to a file and Outlook Data File (.pst). Choose the mailbox or folder to back up and include subfolders if you want to keep the full folder structure. If you already have a PST archive, open it directly here.

## What you can read in the PST Viewer

The viewer reads email from PST files on your device and blocks remote content in HTML messages. Contacts, calendar items, and tasks stay in the original file. An OST is an offline Outlook cache, and an MSG is an individual Outlook item. For a mailbox you can open here, export a PST from Outlook. Large archives can take longer to open and depend on your browser’s available memory.
