## Cara membuka file PST tanpa Outlook

PST (Personal Storage Table) adalah format File Data Outlook (.pst) yang dapat menyimpan folder email, pesan, dan lampiran. Buka file PST di atas, lalu pilih folder atau cari di semua folder berdasarkan subjek, pengirim, atau penerima. Pilih pesan untuk membacanya dan mengunduh lampiran yang tersimpan dalam arsip.

## Cara menemukan atau mengekspor file PST Outlook

Di Outlook klasik untuk Windows, pilih File, Buka dan Ekspor, lalu Impor/Ekspor. Setelah itu, pilih Ekspor ke file dan File Data Outlook (.pst). Pilih kotak surat atau folder yang ingin dicadangkan dan centang Sertakan subfolder jika ingin mempertahankan seluruh struktur folder. Jika sudah memiliki file PST, buka langsung di sini.

## Apa yang bisa dibaca di Penampil PST?

Penampil ini membaca email dari file PST di perangkat Anda dan memblokir konten eksternal dalam email HTML. Kontak, item kalender, dan tugas tetap ada di file asli. File OST adalah cache offline Outlook, sedangkan MSG berisi satu item Outlook. Untuk membuka kotak surat di sini, ekspor file PST dari Outlook. Arsip besar mungkin perlu waktu lebih lama untuk dibuka, bergantung pada memori yang tersedia di browser.
