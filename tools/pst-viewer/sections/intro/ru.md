## Как открыть PST-файл без Outlook

Personal Storage Table (.pst) — это файл данных Outlook. В нём могут храниться почтовые папки, письма и файлы, приложенные к письмам. Откройте PST-файл выше и выберите почтовую папку или выполните поиск по всем папкам по теме, отправителю или получателю. Выберите письмо, чтобы прочитать его и скачать вложения, сохранённые в архиве.

## Как найти или экспортировать PST-файл Outlook

В классическом Outlook для Windows выберите «Файл» → «Открыть и экспортировать» → «Импорт и экспорт». Выберите «Экспорт в файл», затем «Файл данных Outlook (.pst)». Укажите почтовый ящик или папку для резервного копирования. Чтобы сохранить всю структуру папок, включите вложенные папки. Если архив PST уже есть, откройте его здесь.

## Что можно открыть в просмотрщике PST

Просмотрщик читает почту из файлов PST на вашем устройстве и блокирует внешнее содержимое в письмах HTML. Контакты, события календаря и задачи остаются в исходном файле. OST — это локальный кэш Outlook, а MSG — отдельный элемент Outlook. Чтобы открыть здесь почтовый ящик, экспортируйте его из Outlook в формате PST. Большие архивы могут открываться дольше, и для их чтения требуется достаточно свободной памяти в браузере.
