## Ouvrir un fichier PST sans Outlook

Un PST (Personal Storage Table) est un fichier de données Outlook qui porte l’extension .pst. Il peut contenir des dossiers de messagerie, des e-mails et leurs pièces jointes. Ouvrez un fichier PST dans la zone ci-dessus pour parcourir un dossier ou effectuer une recherche dans tous les dossiers par objet, expéditeur ou destinataire. Sélectionnez un message pour le lire et télécharger les pièces jointes conservées dans l’archive.

## Retrouver ou exporter un fichier PST Outlook

Dans Outlook classique pour Windows, choisissez Fichier → Ouvrir et exporter → Importer/Exporter. Sélectionnez Exporter vers un fichier, puis Fichier de données Outlook (.pst). Choisissez la boîte aux lettres ou le dossier à sauvegarder et cochez Inclure les sous-dossiers pour conserver toute l’arborescence. Si vous avez déjà un fichier PST, ouvrez-le directement ici.

## Ce que vous pouvez lire avec la visionneuse PST

La visionneuse lit les e-mails du fichier PST sur votre appareil et bloque le contenu distant des messages HTML. Les contacts, les éléments du calendrier et les tâches restent dans le fichier d’origine. Un fichier OST est le cache hors connexion d’Outlook, tandis qu’un fichier MSG contient un seul élément Outlook. Pour ouvrir ici une boîte aux lettres, exportez-la depuis Outlook au format PST. L’ouverture d’une archive volumineuse peut prendre plus de temps selon la mémoire disponible dans votre navigateur.
