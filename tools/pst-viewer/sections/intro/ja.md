## Outlook を使わずに Outlook の PST ファイルを開く

Personal Storage Table (.pst) は Outlook データ ファイルの一種です。メールフォルダー、メッセージ、添付ファイルを含めることができます。上で PST ファイルを開き、メールフォルダーを選ぶか、件名、差出人、宛先で全フォルダーを検索します。メッセージを選択すると、内容を読み、アーカイブに保存された添付ファイルをダウンロードできます。

## Outlook の PST ファイルを探す、またはエクスポートする

従来の Windows 版 Outlook で、［ファイル］、［開く/エクスポート］、［インポート/エクスポート］の順に選びます。［ファイルにエクスポート］、［Outlook データ ファイル (.pst)］を選択します。バックアップするメールボックスまたはフォルダーを選び、フォルダー構造全体を保持する場合はサブフォルダーを含めます。既に PST アーカイブがある場合は、ここで直接開けます。

## PST ビューアーで読める内容

ビューアーはデバイス上で PST ファイルのメールを読み取り、HTML メッセージ内のリモートコンテンツをブロックします。連絡先、予定表アイテム、タスクは元のファイルに残ります。OST は Outlook のオフラインキャッシュ、MSG は個別の Outlook アイテムです。メールボックスをここで開くには、Outlook から PST ファイルをエクスポートしてください。大きなアーカイブは開くまでに時間がかかることがあり、ブラウザーの利用可能なメモリに左右されます。
