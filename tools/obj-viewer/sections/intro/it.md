## Aprire un file Wavefront OBJ online

Trascina un file `.obj` nel visualizzatore o selezionalo dal tuo dispositivo. Trascina per ruotare, usa la rotellina o il gesto di pizzicamento per lo zoom e trascina con il tasto destro o con due dita per spostare la vista. Scegli **Adatta alla vista** per inquadrare il modello intero o attiva **Wireframe** per esaminarne i triangoli. Seleziona **Prova un esempio** per vedere una piccola staffa di montaggio.

## Visualizzare materiali e texture di un OBJ

Un file Wavefront OBJ contiene la geometria e può fare riferimento a una o più librerie di materiali `.mtl`. Queste, a loro volta, possono fare riferimento a file di immagine. Seleziona o trascina insieme l’OBJ, i file MTL e le immagini delle texture. Ad esempio, apri `chair.obj`, `chair.mtl` e `wood.jpg` in un’unica selezione se sono i nomi usati dal modello. I file restano sul tuo dispositivo.

Puoi aprire l’OBJ anche se mancano alcuni file associati. Le superfici interessate appaiono con un materiale predefinito o senza la texture mancante. Se una texture non appare, verifica che il nome del file, estensione compresa, corrisponda al riferimento nel file MTL. Poi riapri insieme il modello e i file associati.

## Aprire altri formati 3D

Per una mesh triangolare esportata per la stampa 3D, usa il [Visualizzatore STL](../stl-viewer/). Se hai la parte o l’assieme CAD originale in un file `.step` o `.stp`, usa il [Visualizzatore STEP](../step-viewer/).
