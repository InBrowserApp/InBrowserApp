## Buka file Wavefront OBJ secara online

Seret file `.obj` ke penampil atau pilih file dari perangkat Anda. Seret untuk memutar, gulir atau cubit layar untuk memperbesar atau memperkecil, dan seret dengan tombol kanan mouse atau dua jari untuk menggeser tampilan. Pilih **Tampilkan seluruh model** agar seluruh model terlihat, atau aktifkan **Rangka kawat** untuk memeriksa segitiganya. Pilih **Coba contoh** untuk melihat model braket pemasangan kecil.

## Tinjau material dan tekstur OBJ

File Wavefront OBJ menyimpan geometri dan dapat merujuk ke satu atau beberapa pustaka material `.mtl`. File MTL juga dapat merujuk ke file gambar. Pilih atau seret OBJ, file MTL, dan gambar tekstur secara bersamaan. Misalnya, pilih `chair.obj`, `chair.mtl`, dan `wood.jpg` sekaligus jika model menggunakan nama-nama tersebut. File tetap di perangkat Anda.

OBJ tetap dapat dibuka ketika file pendampingnya kurang lengkap. Permukaan yang terdampak akan tampil dengan material bawaan atau tanpa tekstur yang hilang. Jika ada tekstur yang tidak tampil, pastikan nama file dan ekstensinya sama dengan yang tercantum di MTL, lalu buka kembali model bersama file pendampingnya.
