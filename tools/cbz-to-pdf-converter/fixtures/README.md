# CBZ conversion fixtures

All images are original geometric artwork generated by `generate.py` with Pillow. No third-party comic pages or personal documents are included.

- `complete.cbz`: 11 naturally ordered image pages, nested Unicode paths, portrait and landscape pages, PNG transparency, JPEG EXIF rotation, static PNG/JPEG/WebP/GIF/BMP/AVIF, animated GIF/WebP with distinct red and blue frames, and ignored metadata/hidden files. Transparent pixels should export as white; animated images use the red default frame. Page 7's EXIF orientation produces a portrait page with green in the upper-left corner.
- `later-damaged.cbz`: a valid PNG followed by corrupt image bytes. Conversion must identify page 2 and offer no partial download.

The existing CBZ Reader fixtures additionally cover 1,201 pages, unsupported and encrypted entries, corrupt directories, disguised SVG, and compatible AVIF brands. Browser validation uses an uncommitted copy with 51 MiB of unused ZIP padding to check that there is no 50 MB product quota.
