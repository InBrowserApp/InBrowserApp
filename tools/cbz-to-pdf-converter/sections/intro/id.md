## Konversikan komik ke PDF

Buka arsip CBZ lokal. Setiap gambar menjadi satu halaman PDF, lalu Anda dapat memeriksa hasilnya dan memilih Unduh PDF. Pratinjau menampilkan nama file gambar sumber untuk halaman saat ini. Menutup atau mengganti komik akan membatalkan konversi dan menghapus unduhan sebelumnya. Pembaca CBZ juga menyediakan ekspor PDF saat Anda membaca.

## Urutan dan tampilan halaman

Halaman mengikuti urutan alami berdasarkan jalur lengkap folder dan file: page2 mendahului page10. File tersembunyi, folder \_\_MACOSX, dan metadata yang tidak terkait diabaikan. Metadata ComicInfo dan arah baca tidak mengubah urutan hasil ekspor.

Setiap halaman PDF mengikuti proporsi dan orientasi gambarnya, tanpa pemotongan. Gambar didekode pada dimensi piksel aslinya; area transparan menjadi putih. Gambar animasi menggunakan bingkai statis bawaannya. Ukuran halaman PDF disesuaikan agar sisi panjangnya sama, sehingga hasilnya tidak mempertahankan ukuran cetak fisik dari metadata gambar. Penanganan warna oleh browser dapat memengaruhi tampilan. PDF ini berisi gambar tanpa OCR atau teks yang dapat dipilih.

## Kompatibilitas dan arsip yang tidak lengkap

Gambar JPEG, PNG, GIF, WebP, BMP, dan AVIF yang didukung browser dapat digunakan. Arsip CBR dan RAR, entri terenkripsi, SVG, serta format gambar lain yang tidak didukung tidak dapat dikonversi. Jika ada halaman gambar yang dikenali tetapi tidak dapat dibaca, alat ini menunjukkan posisi dan nama filenya serta tidak menyediakan PDF yang tidak lengkap untuk diunduh. Pembaca CBZ dapat membantu memeriksa halaman lain dari komik yang rusak.

## Komik tetap di perangkat Anda

Semua pemrosesan berlangsung di browser ini. Komik tidak diunggah, skrip tidak dijalankan, dan sumber daya dokumen jarak jauh tidak diambil. Tidak ada batas tetap untuk ukuran file atau jumlah halaman. Gambar atau arsip yang sangat besar tetap dapat melampaui memori atau sumber daya dekode browser; tutup tab lain atau coba perangkat dengan memori lebih besar jika diperlukan.
