## แปลงการ์ตูนเป็น PDF

เปิดไฟล์บีบอัด CBZ ในอุปกรณ์ แต่ละภาพจะกลายเป็นหนึ่งหน้าใน PDF จากนั้นคุณสามารถตรวจดูผลลัพธ์และเลือกดาวน์โหลด PDF ตัวอย่างจะแสดงชื่อไฟล์ภาพต้นฉบับของหน้าปัจจุบัน การปิดหรือเปลี่ยนการ์ตูนจะยกเลิกการแปลงและลบผลลัพธ์ก่อนหน้าที่พร้อมให้ดาวน์โหลด โปรแกรมอ่านการ์ตูน CBZ ยังมีการส่งออก PDF ขณะอ่านด้วย

## ลำดับหน้าและลักษณะที่แสดง

หน้าเรียงตามลำดับธรรมชาติของเส้นทางโฟลเดอร์และไฟล์แบบเต็ม โดย page2 มาก่อน page10 ระบบจะละเว้นไฟล์ที่ซ่อนอยู่ โฟลเดอร์ \_\_MACOSX และข้อมูลเมตาที่ไม่เกี่ยวข้อง ข้อมูลเมตา ComicInfo และทิศทางการอ่านไม่เปลี่ยนลำดับหน้าที่ส่งออก

แต่ละหน้าใน PDF จะคงสัดส่วนและแนววางของภาพไว้โดยไม่ครอบตัด ภาพจะถูกถอดรหัสตามขนาดพิกเซลเดิม และพื้นที่โปร่งใสจะกลายเป็นสีขาว สำหรับภาพเคลื่อนไหวจะใช้เฟรมภาพนิ่งที่เป็นค่าเริ่มต้น ขนาดหน้า PDF จะถูกปรับให้ด้านที่ยาวกว่ามีความยาวเท่ากัน จึงไม่คงขนาดจริงสำหรับพิมพ์ที่ระบุในข้อมูลเมตาของภาพ การจัดการสีของเบราว์เซอร์อาจส่งผลต่อลักษณะที่แสดง PDF นี้ประกอบด้วยภาพ ไม่มีการรู้จำข้อความด้วย OCR หรือข้อความที่เลือกได้

## ความเข้ากันได้และไฟล์บีบอัดที่ไม่ครบถ้วน

รองรับภาพ JPEG, PNG, GIF, WebP, BMP และ AVIF ที่เบราว์เซอร์รองรับ ไม่สามารถแปลงไฟล์บีบอัด CBR และ RAR รายการที่เข้ารหัส SVG และรูปแบบภาพอื่นที่ไม่รองรับได้ หากหน้าที่ระบบระบุว่าเป็นภาพหน้าใดอ่านไม่ได้ เครื่องมือจะแสดงตำแหน่งหน้าและชื่อไฟล์ โดยไม่มี PDF ที่ไม่ครบถ้วนให้ดาวน์โหลด โปรแกรมอ่านการ์ตูน CBZ ช่วยตรวจดูหน้าที่เหลือของการ์ตูนที่เสียหายได้

## เก็บการ์ตูนไว้ในอุปกรณ์ของคุณ

การประมวลผลทั้งหมดเกิดขึ้นในเบราว์เซอร์นี้ ไม่มีการอัปโหลดการ์ตูน เรียกใช้สคริปต์ หรือดึงทรัพยากรเอกสารจากภายนอก ไม่มีการกำหนดขีดจำกัดขนาดไฟล์หรือจำนวนหน้าตายตัว อย่างไรก็ตาม ภาพหรือไฟล์บีบอัดที่ใหญ่มากอาจใช้หน่วยความจำหรือทรัพยากรถอดรหัสเกินกว่าที่เบราว์เซอร์มี หากจำเป็น โปรดปิดแท็บอื่นหรือลองใช้อุปกรณ์ที่มีหน่วยความจำมากขึ้น
