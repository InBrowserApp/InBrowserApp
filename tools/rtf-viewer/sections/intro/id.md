## Baca dokumen teks berformat

Buka atau letakkan file `.rtf` lokal untuk membaca halaman berformatnya, memilih dan menyalin teks, atau mencari dalam dokumen. Gunakan kolom halaman untuk melompat, sesuaikan halaman dengan ruang yang tersedia, dan masuk ke mode baca fokus agar dokumen mendapat lebih banyak ruang. Tutup atau ganti file untuk membatalkan pembukaan dan membebaskan sumber dayanya.

## Fitur yang didukung pratinjau

Penampil mendukung pemformatan paragraf umum, penekanan teks, ukuran font, warna, daftar, tabel sederhana, serta gambar PNG atau JPEG tertanam. Escape Unicode dan banyak pengodean karakter Windows lama serta Asia Timur didukung. Halaman ditata di browser ini; pemisah halaman dan fontnya dapat berbeda dari editor asli. Pemilihan teks dan pencarian mencakup pratinjau saat ini, termasuk teks yang terpisah di beberapa halaman.

Dukungan untuk header, footer, catatan kaki, pewarisan lembar gaya, pengaturan bagian, tabel gabungan atau bersarang, bentuk, persamaan, dan kotak teks belum lengkap. Sebagian gambar metafile dapat menampilkan bitmap tertanam; gambar vektor mungkin menampilkan placeholder. Aksara kompleks dan dokumen dengan arah penulisan kanan ke kiri mungkin tidak ditampilkan dengan benar. Bagian yang diketahui tidak ditampilkan tercantum di Batasan pratinjau. Gunakan aplikasi pengolah kata khusus jika tata letak asli atau konten yang tidak ditampilkan diperlukan. File DOC, DOCX, dan teks biasa memerlukan penampil masing-masing.

## File lokal dan sumber daya browser

Isi dokumen tetap di browser ini. Aplikasi tertanam tidak dijalankan, tautan tidak diikuti, dan gambar tertaut atau sumber daya dokumen jarak jauh lainnya tidak diambil. Produk ini tidak membatasi ukuran file atau jumlah halaman. Dokumen dan gambar besar tetap dapat melampaui kapasitas memori atau kanvas browser; kurangi pembesaran untuk halaman yang terlalu besar, atau gunakan perangkat dengan memori lebih besar.
