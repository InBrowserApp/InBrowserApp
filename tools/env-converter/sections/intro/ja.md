## 環境設定を変換

`.env` ファイルを貼り付けて JSON または YAML を選択するか、フラットな JSON/YAML オブジェクトを `.env` に戻します。ローカルファイルの読み込み、入力と出力の入れ替え、結果のコピーやダウンロードができます。すべてブラウザー内で処理され、設定がアップロードされたり、ブラウザーの履歴やローカルストレージに保存されたりすることはありません。

### 値と引用符

環境変数は文字列です。`PORT=3000`、`DEBUG=false`、`CODE=0012` はそれぞれ `"3000"`、`"false"`、`"0012"` のまま保持されます。JSON/YAML の数値と真偽値は文字列に変換されます。Null、配列、入れ子のオブジェクトには、明示的な文字列値が必要です。YAML の `0012` など、表記を正確に保ちたい値は引用符で囲んでください。

パーサーは空行、`#` コメント、`export` 接頭辞、単一引用符・二重引用符・バッククォートで囲まれた複数行の値に対応しています。展開されるのは二重引用符内の `\n` と `\r` のみです。それ以外の引用符やバックスラッシュは、一般的な dotenv の動作に従ってそのまま保持されます。キーには英字、数字、アンダースコアを使用でき、数字で始めることはできません。出力では値を保持できる引用符の種類を選びます。

### 設定のチェック

重複する `.env` キーは行番号とともに表示され、最後の定義が使用されます。閉じ引用符の不足、閉じ引用符の後の余分なテキスト、無効な代入はエラーとして表示され、該当行へのリンクが付きます。曲線の引用符には警告が表示されます。JSON/YAML のキーの重複はエラーです。

コメント、元の引用符の種類、書式は保持されません。`${NAME}` などの参照やシェルコマンドはそのまま保持され、実行されることはありません。`.env` ローダーによって規則が異なるため、このツールはシェルスクリプトを解釈せず、ここで説明した構文の範囲に従います。

[Node.js の .env 仕様](https://nodejs.org/api/environment_variables.html#dotenv)と [dotenv の解析規則](https://github.com/motdotla/dotenv#what-rules-does-the-parsing-engine-follow)も参照してください。
