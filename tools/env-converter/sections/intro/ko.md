## 환경 설정 변환

`.env` 파일을 붙여넣고 JSON 또는 YAML을 선택하거나, 단일 계층 JSON/YAML 객체를 `.env`로 다시 변환하세요. 로컬 파일 가져오기, 입력과 출력 바꾸기, 결과 복사 및 다운로드를 지원합니다. 모든 처리는 브라우저에서 이루어지며, 설정은 업로드되거나 브라우저 기록 또는 로컬 저장소에 저장되지 않습니다.

### 값과 따옴표

환경 변수는 문자열입니다. `PORT=3000`, `DEBUG=false`, `CODE=0012`는 각각 `"3000"`, `"false"`, `"0012"`로 유지됩니다. JSON/YAML의 숫자와 불리언은 문자열로 변환됩니다. Null, 배열, 중첩 객체에는 명시적인 문자열 값이 필요합니다. `0012`와 같은 YAML 값의 정확한 표기를 유지하려면 따옴표로 감싸세요.

파서는 빈 줄, `#` 주석, `export` 접두사, 작은따옴표·큰따옴표·백틱으로 감싼 여러 줄 값을 지원합니다. 큰따옴표 안의 `\n` 및 `\r` 시퀀스만 실제 줄바꿈과 캐리지 리턴으로 변환됩니다. 그 밖의 따옴표와 백슬래시는 일반적인 dotenv 동작에 따라 원문 그대로 유지됩니다. 키에는 영문자, 숫자, 밑줄을 사용할 수 있으며 숫자로 시작할 수 없습니다. 출력 시 값을 보존하는 따옴표 종류를 선택합니다.

### 설정 검사

중복된 `.env` 키는 행 번호와 함께 표시되며 마지막 정의를 사용합니다. 닫는 따옴표 누락, 닫는 따옴표 뒤의 텍스트, 잘못된 할당은 해당 행으로 이동하는 링크와 함께 오류로 표시됩니다. 곡선 따옴표는 경고를 표시합니다. JSON/YAML의 중복 키는 오류로 처리됩니다.

주석, 원래의 따옴표 종류, 서식은 유지되지 않습니다. `${NAME}` 등의 참조와 셸 명령은 원문 그대로 유지되며 실행되지 않습니다. `.env` 로더마다 규칙이 다르므로, 이 도구는 셸 스크립트를 해석하는 대신 여기에 설명된 규칙 범위를 따릅니다.
