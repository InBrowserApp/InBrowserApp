## 轉換環境設定

貼上 `.env` 檔案並選擇 JSON 或 YAML，或將單層 JSON/YAML 物件轉回 `.env`。你可以匯入本機檔案、交換輸入與輸出，以及複製或下載結果。所有處理都在瀏覽器中進行；設定內容不會上傳，也不會儲存在瀏覽紀錄或本機儲存空間中。

### 值與引號

環境變數都是字串：`PORT=3000`、`DEBUG=false` 和 `CODE=0012` 會保留為 `"3000"`、`"false"` 和 `"0012"`。JSON/YAML 中的數字和布林值會轉為字串。Null、陣列和巢狀物件則需要明確的字串值。如果需要保留 `0012` 等 YAML 值的原始寫法，請加上引號。

解析器支援空白行、`#` 註解、`export` 前綴，以及以單引號、雙引號或反引號包住的多行值。只有雙引號中的 `\n` 和 `\r` 序列會展開。其他引號與反斜線會依照常見 dotenv 行為保留原文。鍵名可使用英文字母、數字和底線，但不能以數字開頭。輸出時會選擇可保留原值的引號樣式。

### 設定檢查

重複的 `.env` 鍵名會顯示行號，並採用最後一次定義。缺少結尾引號、結尾引號後出現文字，以及無效的賦值格式都會顯示錯誤，並提供前往問題行的連結。彎引號會產生警告。JSON/YAML 的重複鍵名則會視為錯誤。

註解、原始引號樣式和格式不會保留。`${NAME}` 等參照和 Shell 指令會保留原文，絕不執行。不同 `.env` 載入器的規則各異；這個工具遵循所述的規則子集，不會解譯 Shell 指令碼。

請參閱 [Node.js .env 規範](https://nodejs.org/api/environment_variables.html#dotenv)和 [dotenv 解析規則](https://github.com/motdotla/dotenv#what-rules-does-the-parsing-engine-follow)。
