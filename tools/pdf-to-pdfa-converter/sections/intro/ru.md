## Как преобразовать PDF в PDF/A

1. Выберите PDF-файл или перетащите его в инструмент.
2. Выберите стандарт PDF/A, который требует архив или портал подачи документов. Для обычного архивного хранения подойдёт **PDF/A-2b**.
3. Нажмите **Преобразовать в PDF/A**. Инструмент проверит созданный файл по выбранному профилю.
4. Сверьте профиль PDF/A рядом с кнопкой скачивания и сохраните архивную копию. Исходный PDF останется без изменений.

## Что такое PDF/A?

PDF/A — это семейство стандартов ISO 19005 для долговременного хранения документов PDF. Архивная копия содержит ресурсы, необходимые для того, чтобы страницы одинаково отображались с течением времени. Такой формат помогает сохранить внешний вид отсканированных писем, счетов, отчётов и подписанных бумажных документов.

## Какой стандарт PDF/A выбрать?

Выберите стандарт, который требует архив или портал подачи документов. **PDF/A-2b** подходит для большинства задач архивного хранения. Выберите **PDF/A-1b**, если требуется более ранний стандарт. В обоих профилях применяется уровень соответствия B, направленный на сохранение внешнего вида страниц. PDF/A-2b поддерживает прозрачность. Используйте этот профиль для документов с прозрачными элементами графики или эффектами, если архив его принимает.

## Что меняется в архивной копии?

Текст и векторная графика остаются в PDF, поэтому по тексту можно искать, его можно копировать, а иллюстрации можно увеличивать. Отсканированные страницы остаются сканами и сохраняют текстовый слой, если он уже есть. Если шрифт отсутствует, конвертер может встроить замену с той же шириной символов. Он также может скорректировать цвета или удалить функции и элементы, запрещённые выбранным стандартом, например JavaScript и некоторые вложения. Если в файле есть цифровая подпись, сохраните оригинал, поскольку преобразование делает подпись недействительной.

## Как проверяется файл PDF/A?

Конвертер выполняет проверки по выбранному профилю PDF/A во время преобразования. Затем браузер заново открывает архивную копию и проверяет обозначение PDF/A, геометрию страниц и текст, доступный для поиска. После успешной проверки файл можно скачать. Для независимого отчёта о соответствии используйте [veraPDF](https://verapdf.org/). Документ всё время остаётся на вашем устройстве.

### Как проверить архивную копию в Acrobat Pro

Откройте скачанный PDF в Adobe Acrobat Pro. На панели **Стандарты** выберите **Проверить соответствие**, чтобы увидеть профиль PDF/A и результат проверки. Чтобы проверить соответствие профилю, указанному рядом с кнопкой скачивания, откройте **Все инструменты → Применить допечатную подготовку → Предпечатная проверка**, выберите нужный профиль проверки PDF/A и нажмите **Анализировать**.
