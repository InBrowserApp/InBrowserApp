## 如何将 PDF 转换为 PDF/A？

1. 选择一个 PDF，或将文件拖放到工具中。
2. 按归档机构或提交平台的要求选择 PDF/A 标准。日常归档可选择 **PDF/A-2b**。
3. 点击 **转换为 PDF/A**。工具会按所选标准校验生成的文件。
4. 确认下载按钮旁显示的 PDF/A 标准，然后保存归档副本。原始 PDF 保持不变。

## 什么是 PDF/A？

PDF/A 是 ISO 19005 系列标准定义的长期文档保存格式。归档副本内嵌了呈现页面所需的资源，有助于文件在多年后仍能正确显示，适合留存信件、发票、报告和已签字文件的扫描件。

## 应该选择哪个 PDF/A 标准？

请按归档机构或提交平台的要求选择标准。一般归档可选 **PDF/A-2b**。如果档案部门、法院或文件提交平台明确要求使用较早的标准，请选择 **PDF/A-1b**。两者都采用 B 级符合性，侧重保留页面的视觉外观。PDF/A-2b 支持透明效果。如果归档机构接受此标准，含透明图形或效果的文档可选择 PDF/A-2b。

## 转换后，归档副本有什么变化？

归档副本会保留文本和矢量图形，您仍可搜索和复制文本，也能放大插图。扫描页仍以扫描图像保留，已有的可搜索文本层也会保留。如果缺少字体，转换时可以嵌入字宽相同的替代字体。工具可能会调整色彩，或移除所选标准不允许的功能，例如 JavaScript 和某些附件。转换会使数字签名失效。如果文件带有数字签名，请保留原始 PDF。

## 工具如何校验 PDF/A 文件？

工具会在转换过程中按所选 PDF/A 标准进行检查。随后，浏览器会重新打开归档副本，核对 PDF/A 标识、页面尺寸和布局，以及可搜索的文本。通过检查后即可下载。如果需要独立的符合性报告，可使用 [veraPDF](https://verapdf.org/)。整个过程都在您的设备上完成。

### 在 Acrobat Pro 中验证归档副本

在 Adobe Acrobat Pro 中打开下载的 PDF。在**标准**（Standards）面板中选择**验证符合性**（Verify Conformance），查看 PDF/A 配置文件和验证结果。要按下载按钮旁显示的配置文件进行检查，请打开**所有工具 → 使用印刷制作 → 印前检查**（All tools → Use print production → Preflight），选择对应的 PDF/A 验证配置文件，然后选择**分析**（Analyze）。
