## PDF を PDF/A に変換する方法

1. PDF を選択するか、このツールにドロップします。
2. 保存先や提出先で指定された PDF/A の規格を選びます。規格の指定がなければ、通常の長期保存には **PDF/A-2b** を選びます。
3. **PDF/A に変換**を押します。選択した規格に合わせて、変換したファイルをチェックします。
4. ダウンロードボタンの横に表示される PDF/A 規格を確認し、長期保存用のファイルを保存します。元の PDF は変更されません。

## PDF/A とは？

PDF/A は、文書の長期保存を目的とした ISO 19005 シリーズの PDF 規格です。ページの見た目を将来も再現できるように、表示に必要な情報をファイル内に収めます。スキャンした手紙や請求書、報告書、署名済みの紙文書の見た目を記録しておくのに適しています。

## どの PDF/A 規格を選べばよいですか？

保存先や提出先で指定された規格に合わせて選びます。通常の長期保存には **PDF/A-2b** が適しています。文書管理部門や裁判所、オンライン提出先から旧規格を明示的に指定された場合は、**PDF/A-1b** を選びます。どちらもページの見た目の再現を重視する適合レベル B に当たります。PDF/A-2b は透明効果に対応しています。保存先でこの規格が認められている場合は、透過した図や透明効果を含む文書に PDF/A-2b を選んでください。

## 長期保存用のファイルでは何が変わりますか？

テキストとベクター画像が残るため、変換後もテキストを検索・コピーしたり、図を拡大したりできます。スキャンページは画像のまま保持され、既存の検索可能なテキストレイヤーも残ります。フォントが不足している場合は、同じ文字幅の代替フォントを埋め込むことができます。選択した規格に合わせて色を調整したり、規格で認められていない JavaScript や一部の添付ファイルを削除したりすることがあります。変換すると電子署名は無効になるため、署名付きの PDF は元のファイルを保管してください。

## PDF/A ファイルはどのようにチェックされますか？

選んだ PDF/A 規格に照らしてチェックしながら変換します。その後、ブラウザーで変換したファイルを開き直し、PDF/A の識別情報、ページの寸法と配置、検索可能なテキストを確認します。チェックを通過するとダウンロードできます。独立した規格適合性レポートが必要な場合は、[veraPDF](https://verapdf.org/) を利用できます。すべての処理はお使いの端末内で行われます。

### Acrobat Pro で長期保存用のファイルを検証する

ダウンロードした PDF を Adobe Acrobat Pro で開きます。**規格**（Standards）パネルで**準拠を確認**（Verify Conformance）を選ぶと、PDF/A プロファイルと検証結果を確認できます。ダウンロードボタンの横に表示されたプロファイルで確認するには、**All tools → Use print production → Preflight** を開き、対応する PDF/A 検証プロファイルを選んで**解析**（Analyze）を実行します。
