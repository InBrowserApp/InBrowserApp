## איך ממירים PDF ל־PDF/A?

1. בחרו קובץ PDF או גררו אותו לכלי.
2. בחרו את תקן PDF/A שהארכיון או אתר ההגשה דורשים. לארכוב כללי מומלץ להתחיל עם **PDF/A-2b**.
3. בחרו **המרה ל־PDF/A**. הכלי יבדוק את הקובץ שנוצר לפי הפרופיל שבחרתם.
4. לאחר שהקובץ עובר את הבדיקות, הורידו את עותק הארכיון. קובץ ה־PDF המקורי נשאר כפי שהוא.

## מהו PDF/A?

PDF/A הוא שמה של משפחת תקני ISO 19005 שנועדו לשימור מסמכים בפורמט PDF לטווח ארוך. עותק הארכיון מכיל את המשאבים הדרושים כדי להציג את העמודים באופן עקבי לאורך זמן. הפורמט מתאים לשימור המראה של מכתבים סרוקים, חשבוניות, דוחות ומסמכי נייר חתומים.

## איזה תקן PDF/A כדאי לבחור?

**PDF/A-2b** הוא ברירת מחדל טובה לארכוב כללי. בחרו ב־**PDF/A-1b** כאשר ארכיון מוסדי, בית משפט או אתר הגשה דורשים במפורש את התקן הוותיק יותר. שני הפרופילים שייכים לרמת התאימות B, שמתמקדת בשימור מראה העמודים. PDF/A-2b תומך בשקיפות. בחרו בו למסמכים עם גרפיקה או אפקטים שקופים, אם הארכיון מקבל את התקן הזה.

## מה משתנה בעותק הארכיון?

הטקסט והגרפיקה הווקטורית נשמרים בקובץ ה־PDF, כך שאפשר להמשיך לחפש ולהעתיק טקסט ולהגדיל איורים. עמוד סרוק נשאר סריקה, כולל שכבת טקסט לחיפוש אם הייתה בו שכבה כזו. אם חסר גופן, הכלי יכול להטמיע גופן חלופי עם אותם רוחבי תווים. ההמרה עשויה לשנות צבעים או להסיר תכונות שהתקן שנבחר אוסר, כמו JavaScript וקבצים מצורפים מסוימים. אם הקובץ חתום בחתימה דיגיטלית, שמרו את המקור. ההמרה מבטלת את תוקף החתימה.

## איך נבדק קובץ ה־PDF/A?

כלי ההמרה בודק את פרופיל ה־PDF/A שנבחר תוך כדי העבודה. הדפדפן פותח מחדש את עותק הארכיון ובודק את פרטי הזיהוי של PDF/A, את מידות העמודים ואת הכיוון שלהם ואת הטקסט הניתן לחיפוש. אפשר להוריד את העותק לאחר שעבר את הבדיקות. לדוח תאימות עצמאי, השתמשו ב־[veraPDF](https://verapdf.org/). המסמך נשאר במכשיר שלכם לכל אורך התהליך.
