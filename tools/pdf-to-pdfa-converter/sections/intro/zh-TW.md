## 如何將 PDF 轉成 PDF/A

1. 選擇 PDF，或將檔案拖曳到工具中。
2. 選擇檔案管理單位或提交平台指定的 PDF/A 標準。一般長期保存可選擇 **PDF/A-2b**。
3. 按下**轉成 PDF/A**。工具會依照所選標準檢查產生的檔案。
4. 確認下載按鈕旁顯示的 PDF/A 標準，再儲存封存副本。原始 PDF 會保持原樣。

## 什麼是 PDF/A？

PDF/A 是 ISO 19005 系列標準，用於長期保存 PDF 文件。封存副本內含顯示頁面所需的資源，讓文件日後開啟時仍能維持一致的外觀。這種格式適合保存掃描的信件、發票、報告和紙本簽署文件。

## 該選擇哪個 PDF/A 標準？

請依檔案管理單位或提交平台的要求選擇標準。一般長期保存建議使用 **PDF/A-2b**。如果檔案管理單位、法院或提交平台明確要求較早的版本，請選擇 **PDF/A-1b**。兩者都採用 B 級，著重於保留頁面的視覺外觀。PDF/A-2b 支援透明效果。若檔案管理單位接受這個標準，含有透明圖形或效果的文件可以選擇 PDF/A-2b。

## 封存副本會有哪些變化？

封存副本會保留文字和向量圖形，仍可搜尋及複製文字，也可以放大插圖。掃描頁會維持原有的掃描影像，並保留已有的可搜尋文字層。如果缺少字型，工具可以嵌入字元寬度相同的替代字型。轉換時可能會調整色彩，或移除所選標準不允許的功能，例如 JavaScript 和部分附件。轉換會使數位簽章失效。如果檔案含有數位簽章，請保留原檔。

## 如何檢查 PDF/A 檔案？

工具會在轉換過程中依所選的 PDF/A 標準進行檢查。接著，瀏覽器會重新開啟封存副本，檢查 PDF/A 識別資訊、頁面尺寸與配置，以及可搜尋文字。通過檢查後即可下載。若需要獨立的符合性報告，可使用 [veraPDF](https://verapdf.org/)。整個過程都在你的裝置上完成。

### 在 Acrobat Pro 中驗證封存副本

在 Adobe Acrobat Pro 中開啟下載的 PDF。在**標準**（Standards）面板中選擇**驗證符合性**（Verify Conformance），查看 PDF/A 標準及驗證結果。若要依下載按鈕旁標示的標準檢查，請開啟**所有工具 → 使用列印製作 → 預檢**（All tools → Use print production → Preflight），選擇對應的 PDF/A 驗證設定檔，再選擇**分析**（Analyze）。
