## ייצוא מחברת Jupyter שמורה

יש לפתוח מחברת IPYNB ולבחור HTML, Markdown או קוד. HTML ו־Markdown שומרים על סדר התאים השמור, כולל פלטים שמורים נתמכים. הכול נשאר בדפדפן שלך. לא מופעלים ליבה, קוד או סביבת הרצה של וידג׳טים.

## בחירת פלט מתאים

HTML הוא עותק עצמאי לקריאה עם טקסט שניתן לבחור, תמונות כלולות נתמכות וטבלאות קריאות. Markdown מספק תוכן מסמך לשימוש חוזר; טבלאות עשויות להכיל HTML בטוח ותמונות משתמשות בכתובות URL מסוג data המוטמעות במסמך, שיישומי Markdown מסוימים אינם מציגים. הפריסה והעיצוב המקוריים עשויים להשתנות.

ייצוא קוד שומר על סדר תאי הקוד ומשמיט תאי Markdown, תאים גולמיים ופלט שמור. שפת מחברת מזוהה קובעת את סיומת הסקריפט; עבור שפות לא מזוהות נעשה שימוש ב־TXT. פקודות קסם ותחביר מעטפת של המחברת נשארים כפי שנכתבו, ולכן ייתכן שהקוד שיוצא יצריך התאמה ידנית או את הליבה המקורית של המחברת. מחברת ללא תאי קוד מפיקה קובץ קוד ריק.

## תוצאות שמורות ותאימות

הממיר קורא מחברות בפורמט 4. התוצאות מגיעות מהקובץ השמור וייתכן שאינן עדכניות. תוכן עשיר שאינו נתמך ותמונות שאינן זמינות מסומנים. משאבים מרוחקים אינם מאוחזרים; סקריפטים, וידג׳טים, אודיו ווידאו אינם מופעלים. LaTeX נשאר כטקסט מקור, ותאים גולמיים או לא מוכרים מופיעים כטקסט קריא בייצוא למסמכים.

משאבי הדפדפן קובעים את המגבלות המעשיות; אין מכסה קבועה לגודל הקובץ או למספר התאים. לעיון במחברת המקורית, אפשר להשתמש ב[מציג מחברות Jupyter](/tools/notebook-viewer/).
