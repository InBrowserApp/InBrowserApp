## 保存した Jupyter ノートブックを書き出す

IPYNB ノートブックを開き、HTML、Markdown、コードから形式を選択します。HTML と Markdown には、対応する保存済みの出力を含め、セルが保存された順序で保持されます。すべての処理はブラウザー内で行われます。カーネル、コード、ウィジェットの実行環境は起動しません。

## 用途に合った出力形式を選ぶ

HTML は単独で開ける閲覧用のコピーで、選択可能なテキスト、対応する埋め込み画像、読み取り可能な表が含まれます。Markdown は文書の内容を再利用するのに適しています。表に安全な HTML が含まれる場合があり、画像には埋め込みデータ URL が使われます。一部の Markdown アプリではこれらを表示できません。元のレイアウトや書式は変わる場合があります。

コードの書き出しではコードセルの順序を保持し、Markdown、生テキストのセル、保存済みの出力を省きます。ノートブックの言語が認識できる場合は、その言語に応じたスクリプトの拡張子を使用し、不明な場合は TXT を使用します。ノートブックのマジックコマンドやシェル構文は記述されたまま残るため、書き出したコードには手動での調整や元のノートブックのカーネルが必要になる場合があります。コードセルのないノートブックからは、空のコードファイルが作成されます。

## 保存済みの結果と互換性

この変換ツールはノートブック形式 4 を読み取ります。結果は保存されたファイルから取得するため、古くなっている場合があります。未対応のリッチコンテンツや利用できない画像にはその旨を表示します。外部リソースは取得せず、スクリプトやウィジェットの実行、音声や動画の再生も行いません。LaTeX はソーステキストのまま残り、生テキストや不明な種類のセルは文書の書き出し結果に読み取り可能なテキストとして表示されます。

実際に扱える範囲はブラウザーのリソースによって決まります。ファイルサイズやセル数に固定の上限はありません。元のノートブックを確認するには、[Jupyter Notebook ビューアー](/tools/notebook-viewer/)をご利用ください。
