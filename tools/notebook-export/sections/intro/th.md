## ส่งออกโน้ตบุ๊ก Jupyter ที่บันทึกไว้

เปิดโน้ตบุ๊ก IPYNB แล้วเลือก HTML, Markdown หรือโค้ด HTML และ Markdown คงเซลล์ตามลำดับที่บันทึกไว้ รวมถึงเอาต์พุตที่บันทึกไว้ซึ่งรองรับ ทุกอย่างอยู่ในเบราว์เซอร์ของคุณ ไม่มีการเริ่มเคอร์เนล รันโค้ด หรือเริ่มระบบรันวิดเจ็ต

## เลือกรูปแบบเอาต์พุตที่เหมาะสม

HTML เป็นสำเนาสำหรับอ่านแบบแยกเดี่ยวที่มีข้อความที่เลือกได้ รูปภาพที่รวมไว้ซึ่งรองรับ และตารางที่อ่านได้ Markdown ให้เนื้อหาเอกสารที่นำกลับไปใช้ต่อได้ ตารางอาจมี HTML ที่ปลอดภัย และรูปภาพใช้ URL ข้อมูลที่ฝังไว้ ซึ่งแอป Markdown บางแอปไม่แสดงผล เค้าโครงและการจัดรูปแบบเดิมอาจเปลี่ยนไป

การส่งออกโค้ดคงเซลล์โค้ดตามลำดับ และละ Markdown เซลล์ข้อความดิบ และเอาต์พุตที่บันทึกไว้ ภาษาของโน้ตบุ๊กที่ระบบรู้จักจะกำหนดนามสกุลของสคริปต์ ส่วนภาษาที่ไม่รู้จักจะใช้ TXT คำสั่งพิเศษของโน้ตบุ๊ก (magics) และไวยากรณ์เชลล์ยังคงตามที่เขียน โค้ดที่ส่งออกจึงอาจต้องปรับแก้ด้วยตนเองหรือใช้เคอร์เนลเดิมของโน้ตบุ๊ก โน้ตบุ๊กที่ไม่มีเซลล์โค้ดจะได้ไฟล์โค้ดว่าง

## ผลลัพธ์ที่บันทึกไว้และความเข้ากันได้

โปรแกรมแปลงอ่านรูปแบบโน้ตบุ๊กเวอร์ชัน 4 ผลลัพธ์มาจากไฟล์ที่บันทึกไว้และอาจล้าสมัย ระบบจะแจ้งเนื้อหาแบบสื่อสมบูรณ์ที่ไม่รองรับและรูปภาพที่ไม่พร้อมใช้งาน ไม่มีการดึงทรัพยากรระยะไกล รันสคริปต์หรือวิดเจ็ต หรือเล่นเสียงและวิดีโอ LaTeX ยังคงเป็นข้อความต้นฉบับ และเซลล์ข้อความดิบหรือเซลล์ที่ไม่รู้จักจะแสดงเป็นข้อความที่อ่านได้ในการส่งออกเอกสาร

ทรัพยากรของเบราว์เซอร์เป็นตัวกำหนดขีดจำกัดในการใช้งานจริง ไม่มีโควตาขนาดไฟล์หรือจำนวนเซลล์ที่ตายตัว หากต้องการตรวจดูโน้ตบุ๊กต้นฉบับ ให้ใช้ [โปรแกรมดูโน้ตบุ๊ก Jupyter](/tools/notebook-viewer/)
