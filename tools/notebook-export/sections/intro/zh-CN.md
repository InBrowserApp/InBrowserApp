## 导出已保存的 Jupyter 笔记本

打开 IPYNB 笔记本，选择 HTML、Markdown 或代码。HTML 和 Markdown 会保留单元格的保存顺序，并包含受支持的已保存输出。所有处理均在浏览器中完成，不会启动内核、执行代码或运行组件。

## 选择合适的输出格式

HTML 是可独立阅读的副本，包含可选择的文本、受支持的内含图片和可读取的表格。Markdown 提供可复用的文档内容；表格可能包含安全的 HTML，图片使用嵌入的 data URL，部分 Markdown 应用无法显示这些图片。原始布局和格式可能会发生变化。

代码导出按顺序保留代码单元格，省略 Markdown、原始文本单元格和已保存的输出。识别到的笔记本语言决定脚本扩展名，未知语言使用 TXT。笔记本魔法命令和 shell 语法按原样保留，因此导出的代码可能需要手动调整或使用原笔记本内核。没有代码单元格的笔记本会生成空代码文件。

## 已保存的结果与兼容性

转换器读取笔记本格式 4。结果来自已保存的文件，可能已过时。不支持的富内容和不可用的图片会有标注。不会获取远程资源，也不会运行脚本、组件或播放音频和视频。LaTeX 保留为源文本，原始文本或未知类型的单元格在文档导出中显示为可读取的文本。

实际可处理的大小取决于浏览器资源，没有固定的文件大小或单元格数量上限。如需查看原笔记本，请使用 [Jupyter 笔记本查看器](/tools/notebook-viewer/)。
