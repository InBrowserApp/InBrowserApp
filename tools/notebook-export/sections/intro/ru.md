## Экспорт сохранённого блокнота Jupyter

Откройте блокнот IPYNB и выберите HTML, Markdown или код. HTML и Markdown сохраняют порядок ячеек, включая поддерживаемый сохранённый вывод. Всё остаётся в вашем браузере. Ядро, код и среда выполнения виджетов не запускаются.

## Выбор подходящего формата

HTML — автономная копия для чтения с выделяемым текстом, поддерживаемыми встроенными изображениями и читаемыми таблицами. Markdown предоставляет содержимое документа для дальнейшего использования; таблицы могут содержать безопасный HTML, а изображения используют встроенные URL данных, которые некоторые приложения для Markdown не отображают. Исходный макет и форматирование могут измениться.

Экспорт кода сохраняет порядок ячеек с кодом и исключает Markdown, необработанные ячейки и сохранённый вывод. Если язык блокнота распознан, он определяет расширение скрипта; для неизвестных языков используется TXT. Магические команды блокнота и синтаксис оболочки сохраняются без изменений, поэтому экспортированный код может требовать ручной правки или исходного ядра блокнота. Блокнот без ячеек с кодом создаёт пустой файл кода.

## Сохранённые результаты и совместимость

Конвертер читает блокноты формата 4. Результаты берутся из сохранённого файла и могут быть устаревшими. Неподдерживаемое расширенное содержимое и недоступные изображения отмечаются. Внешние ресурсы не загружаются; скрипты, виджеты, аудио и видео не запускаются. LaTeX остаётся исходным текстом, а необработанные и неизвестные ячейки отображаются как читаемый текст при экспорте документа.

Практические ограничения зависят от ресурсов браузера; фиксированных ограничений на размер файла или число ячеек нет. Чтобы изучить исходный блокнот, используйте [Просмотр блокнотов Jupyter](/tools/notebook-viewer/).
