## 匯出已儲存的 Jupyter 筆記本

開啟 IPYNB 筆記本，並選擇 HTML、Markdown 或程式碼。HTML 與 Markdown 會依儲存時的順序保留儲存格，包括支援的已儲存輸出。所有內容都會留在您的瀏覽器中，不會啟動核心、執行程式碼或啟動互動元件執行環境。

## 選擇適合的輸出格式

HTML 是可獨立開啟的閱讀副本，包含可選取的文字、支援的內含圖片及可讀取的表格。Markdown 提供可重複使用的文件內容；表格可能包含安全的 HTML，圖片則使用內嵌的資料 URL，部分 Markdown 應用程式無法顯示這些圖片。原始版面與格式可能會改變。

程式碼匯出會依序保留程式碼儲存格，並省略 Markdown、原始文字儲存格及已儲存的輸出。可識別的筆記本程式語言會決定指令碼的副檔名；未知語言則使用 TXT。筆記本魔術指令與 Shell 語法會保持原樣，因此匯出的程式碼可能需要手動調整，或使用原筆記本核心。不含程式碼儲存格的筆記本會產生空白的程式碼檔案。

## 已儲存的結果與相容性

轉換器可讀取筆記本格式第 4 版。結果取自已儲存的檔案，可能已過時。不支援的豐富格式內容及無法使用的圖片會加以標示。不會擷取遠端資源，也不會執行或播放指令碼、互動元件、音訊與影片。LaTeX 會保留為原始文字；在文件匯出中，原始文字或未知類型的儲存格會顯示為可讀取的文字。

實際限制取決於瀏覽器資源，沒有固定的檔案大小或儲存格數量上限。若要檢視原始筆記本，請使用 [Jupyter 筆記本檢視器](/tools/notebook-viewer/)。
