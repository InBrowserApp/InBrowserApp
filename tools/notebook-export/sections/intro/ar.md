## تصدير دفتر Jupyter محفوظ

افتح دفترًا بصيغة IPYNB واختر HTML أو Markdown أو تعليمات برمجية. يحافظ HTML وMarkdown على ترتيب الخلايا المحفوظ، بما في ذلك المخرجات المحفوظة المدعومة. يبقى كل شيء في متصفحك. لا تُشغّل نواة أو تعليمات برمجية أو بيئة تشغيل لعناصر الواجهة التفاعلية.

## اختيار صيغة مناسبة

يوفر HTML نسخة مستقلة للقراءة بنص قابل للتحديد وصور مضمنة مدعومة وجداول قابلة للقراءة. يوفر Markdown محتوى مستند يمكن إعادة استخدامه؛ وقد تتضمن الجداول HTML آمنًا، وتستخدم الصور عناوين URL ببيانات مضمّنة لا تعرضها بعض تطبيقات Markdown. قد يتغير التخطيط والتنسيق الأصليان.

يحافظ تصدير التعليمات البرمجية على ترتيب خلايا التعليمات البرمجية، ويحذف خلايا Markdown والنص الخام والمخرجات المحفوظة. تحدد لغة الدفتر المعروفة امتداد ملف التعليمات البرمجية؛ وتستخدم اللغات غير المعروفة TXT. تبقى أوامر الدفتر الخاصة (magics) وصياغة أوامر الصدفة كما كُتبت، لذا قد تحتاج التعليمات البرمجية المصدّرة إلى تعديل يدوي أو نواة الدفتر الأصلية. ينتج الدفتر الذي لا يحتوي على خلايا تعليمات برمجية ملف تعليمات برمجية فارغًا.

## النتائج المحفوظة والتوافق

يقرأ المحوّل تنسيق الدفتر 4. تأتي النتائج من الملف المحفوظ وقد تكون قديمة. يُنبَّه إلى المحتوى الغني غير المدعوم والصور غير المتاحة. لا تُجلب الموارد الخارجية؛ ولا تُشغّل البرامج النصية أو عناصر الواجهة التفاعلية أو المقاطع الصوتية أو الفيديو. يبقى LaTeX كنص مصدر، وتظهر الخلايا الخام أو غير المعروفة كنص قابل للقراءة في المستندات المصدّرة.

تحدد موارد المتصفح الحدود العملية؛ ولا يوجد حد ثابت لحجم الملف أو عدد الخلايا. لفحص الدفتر الأصلي، استخدم [عارض دفاتر Jupyter](/tools/notebook-viewer/).
