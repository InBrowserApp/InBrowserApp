## Come convertire le diapositive PowerPoint in immagini

Apri o trascina un file PowerPoint e controlla l’anteprima delle diapositive. Scegli PNG, JPG o WebP, quindi seleziona la diapositiva corrente, un intervallo inclusivo o l’intera presentazione. Una singola diapositiva viene scaricata come immagine. Più diapositive vengono numerate nell’ordine della presentazione e scaricate insieme in un file ZIP.

Ad esempio, scegli le diapositive da 2 a 5 di `sales-deck.pptx` per salvare quattro immagini per una relazione. Usa **2×** per ottenere più pixel se devi ritagliare l’immagine o visualizzarla più grande. Le proporzioni della diapositiva restano invariate.

## Quando scegliere PNG, JPG o WebP

- **PNG** mantiene nitidi testo, diagrammi e colori uniformi grazie alla compressione senza perdita.
- **JPG** è utile per diapositive con foto quando conta avere un file più piccolo e ampiamente compatibile.
- **WebP** è utile per pubblicare sul web le immagini delle diapositive.

## Cosa include l’esportazione PowerPoint

Il convertitore usa il layout salvato delle diapositive, incluse quelle nascoste nell’ordine del file. Ogni immagine mostra una diapositiva statica con sfondo bianco nelle aree trasparenti. Animazioni, transizioni, note del relatore e contenuti interattivi vengono esclusi. Font ed effetti complessi possono differire dall’originale: controlla l’anteprima prima di scaricare.

Sono supportati i file PPTX, PPTM, POTX, POTM, PPSX e PPSM. Il file rimane nel browser e le macro non vengono eseguite. Usa il [Visualizzatore PPTX](../pptx-viewer/) per consultare tutta la presentazione oppure il [Convertitore da PPTX a PDF](../pptx-to-pdf-converter/) per riunire le diapositive in un documento stampabile.
