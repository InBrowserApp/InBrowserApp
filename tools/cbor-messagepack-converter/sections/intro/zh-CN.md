## 检查二进制接口数据

CBOR 和 MessagePack 是用于结构化数据的紧凑二进制序列化格式。使用此转换器，可将接口响应、WebSocket 消息或缓存值转换为 JSON 以便检查，也可从 JSON 创建二进制数据，辅助调试。所有处理均在浏览器中完成，不会上传或保存输入内容。

## 编码 JSON 或解码字节

选择二进制格式和转换方向。编码时，输入 JSON，并选择 Hex、Base64 或 Base64URL 作为输出编码。解码时，粘贴字节并选择其输入编码。更改输入编码会按新编码重新解释编辑器中的现有文本。

编码时可打开 JSON 文件，解码时可打开原始 `.cbor`、`.msgpack` 或 `.bin` 文件。Hex 或 Base64 等编码文本应直接粘贴到编辑器中。转换后，可复制显示的文本或下载结果。下载的二进制文件包含实际字节，可以再次导入。

## 保留数值并了解限制

在格式支持的 64 位范围内，整数字面量会保留每一位数字。JSON 无法表示的值（如二进制字段、CBOR 标签和 MessagePack 扩展）会显示为明确的类型包装对象。启用扩展 JSON，可将这些包装对象重新编码为二进制；如果普通 JSON 对象只是恰好使用了包装键，请保持关闭。

例如，启用扩展 JSON 后，`{"id":{"$integer":"9007199254740993"},"data":{"$binary":"AQI="}}` 会编码一个精确整数和两个二进制字节。

每次转换处理一个值，输入上限为 1 MiB。「格式化 JSON 字节数」统计显示的美化 JSON 的字节数，而非原始输入的字节数。重新编码会保留支持的值，但可能改变映射顺序或二进制编码方式。展开上方的「格式与类型保真」，可查看包装对象语法和不支持的类型。
