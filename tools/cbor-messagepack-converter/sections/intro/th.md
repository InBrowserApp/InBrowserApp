## ตรวจสอบข้อมูลไบนารีของ API

CBOR และ MessagePack เป็นรูปแบบการทำซีเรียลไลซ์ไบนารีขนาดกะทัดรัดสำหรับข้อมูลแบบมีโครงสร้าง ใช้ตัวแปลงนี้เพื่อตรวจสอบการตอบกลับของ API ข้อความ WebSocket หรือค่าที่แคชไว้ในรูปแบบ JSON หรือสร้างข้อมูลไบนารีจาก JSON เพื่อดีบัก ประมวลผลทั้งหมดในเบราว์เซอร์ของคุณ โดยไม่มีการอัปโหลดหรือบันทึกข้อมูลเข้า

## เข้ารหัส JSON หรือถอดรหัสไบต์

เลือกรูปแบบไบนารีและทิศทางการแปลง หากต้องการเข้ารหัส ให้ป้อน JSON และเลือก Hex, Base64 หรือ Base64URL สำหรับผลลัพธ์ หากต้องการถอดรหัส ให้วางไบต์และเลือกการเข้ารหัสของข้อมูลเข้า เมื่อเปลี่ยนการเข้ารหัสข้อมูลเข้า ระบบจะตีความข้อความที่มีอยู่ในตัวแก้ไขใหม่

เปิดไฟล์ JSON เมื่อเข้ารหัส หรือเปิดไฟล์ไบนารีดิบ `.cbor`, `.msgpack` หรือ `.bin` เมื่อถอดรหัส ข้อความที่เข้ารหัสแล้ว เช่น Hex หรือ Base64 ควรวางลงในตัวแก้ไข แปลงข้อมูล แล้วคัดลอกข้อความที่แสดงหรือดาวน์โหลดผลลัพธ์ ไฟล์ไบนารีที่ดาวน์โหลดมีไบต์จริงและสามารถนำเข้าอีกครั้งได้

## รักษาค่าและเข้าใจข้อจำกัด

ค่าจำนวนเต็มที่เขียนโดยตรงจะเก็บทุกหลักไว้ครบถ้วนภายในช่วง 64 บิตที่รูปแบบนั้นรองรับ ค่าที่ JSON ไม่สามารถแทนได้ เช่น ฟิลด์ไบนารี แท็ก CBOR และส่วนขยาย MessagePack จะแสดงเป็นแรปเปอร์ระบุชนิดอย่างชัดเจน เปิดใช้ JSON แบบขยายเพื่อเข้ารหัสแรปเปอร์เหล่านั้นกลับเป็นไบนารี และปิดไว้สำหรับออบเจ็กต์ JSON ปกติที่บังเอิญใช้คีย์แรปเปอร์

ตัวอย่างเช่น เมื่อเปิดใช้ JSON แบบขยาย `{"id":{"$integer":"9007199254740993"},"data":{"$binary":"AQI="}}` จะเข้ารหัสจำนวนเต็มที่แม่นยำและไบต์ไบนารีสองไบต์

การแปลงแต่ละครั้งจัดการหนึ่งค่า โดยจำกัดขนาดข้อมูลเข้าไว้ที่ 1 MiB ไบต์ JSON ที่จัดรูปแบบแล้วจะนับ JSON ที่แสดงและจัดย่อหน้าแล้ว แทนที่จะนับข้อมูลเข้าต้นฉบับ การเข้ารหัสซ้ำจะรักษาค่าที่รองรับไว้ แต่อาจเปลี่ยนลำดับของแมปหรือวิธีเข้ารหัสไบนารี เปิด “รูปแบบและการรักษาชนิดข้อมูล” ด้านบนเพื่อดูไวยากรณ์ของแรปเปอร์และชนิดข้อมูลที่ไม่รองรับ
