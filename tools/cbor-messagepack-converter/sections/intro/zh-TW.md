## 檢視二進位 API 資料

CBOR 和 MessagePack 是用於結構化資料的精簡二進位序列化格式。使用此轉換器，可將 API 回應、WebSocket 訊息或快取值轉為 JSON 以便檢視，也可從 JSON 建立二進位資料以協助除錯。所有處理都在瀏覽器中完成；輸入內容不會上傳或儲存。

## 編碼 JSON 或解碼位元組

選擇二進位格式與轉換方向。編碼時，輸入 JSON，並選擇 Hex、Base64 或 Base64URL 作為輸出表示法。解碼時，貼上位元組並選擇其輸入編碼。變更輸入編碼會以新編碼重新解讀編輯器中的文字。

編碼時可開啟 JSON 檔案；解碼時可開啟原始 `.cbor`、`.msgpack` 或 `.bin` 檔案。Hex 或 Base64 等編碼文字應貼入編輯器。完成轉換後，可複製顯示的文字或下載結果。下載的二進位檔案包含實際位元組，可再次匯入。

## 保留數值並了解限制

整數字面值會在格式支援的 64 位元範圍內保留每一位數字。JSON 無法表示的值，例如二進位欄位、CBOR 標籤與 MessagePack 擴充型別，會以明確的型別包裝物件顯示。啟用擴充 JSON，即可將這些包裝物件重新編碼為二進位；若一般 JSON 物件恰好使用包裝鍵，請勿啟用。

例如，啟用擴充 JSON 後，`{"id":{"$integer":"9007199254740993"},"data":{"$binary":"AQI="}}` 會編碼為一個精確的整數與兩個二進位位元組。

每次轉換處理一個值，輸入上限為 1 MiB。「格式化 JSON 位元組數」計算的是顯示的美化排版 JSON，而非原始輸入。重新編碼會保留支援的值，但可能變更對應表的排序或二進位編碼方式。展開上方的「格式與型別保真度」，即可查看包裝物件語法與不支援的型別。
