## बाइनरी API पेलोड की जाँच करें

CBOR और MessagePack संरचित डेटा के लिए छोटे बाइनरी सीरियलाइज़ेशन प्रारूप हैं। इस कन्वर्टर से API प्रतिक्रियाओं, WebSocket संदेशों या कैश किए गए मानों को JSON के रूप में जाँचें, या डीबगिंग के लिए JSON से बाइनरी पेलोड बनाएँ। सारी प्रोसेसिंग आपके ब्राउज़र में होती है; इनपुट अपलोड या सेव नहीं किए जाते।

## JSON एन्कोड करें या बाइट डिकोड करें

बाइनरी प्रारूप और रूपांतरण की दिशा चुनें। एन्कोड करने के लिए JSON दर्ज करें और आउटपुट के लिए Hex, Base64 या Base64URL चुनें। डिकोड करने के लिए बाइट पेस्ट करें और उनकी इनपुट एन्कोडिंग चुनें। इनपुट एन्कोडिंग बदलने से एडिटर में पहले से मौजूद टेक्स्ट को नई एन्कोडिंग के अनुसार पढ़ा जाता है।

एन्कोड करते समय JSON फ़ाइल खोलें, या डिकोड करते समय मूल `.cbor`, `.msgpack` या `.bin` फ़ाइल खोलें। Hex या Base64 जैसे एन्कोड किए गए टेक्स्ट को एडिटर में पेस्ट करें। रूपांतरण करें, फिर दिखाए गए टेक्स्ट को कॉपी करें या परिणाम डाउनलोड करें। बाइनरी डाउनलोड में वास्तविक बाइट होते हैं और उन्हें दोबारा इम्पोर्ट किया जा सकता है।

## मान सुरक्षित रखें और सीमाएँ समझें

प्रारूप की समर्थित 64-बिट सीमा के भीतर पूर्णांक लिटरल का हर अंक सुरक्षित रहता है। वे मान जिन्हें JSON निरूपित नहीं कर सकता, जैसे बाइनरी फ़ील्ड, CBOR टैग और MessagePack एक्सटेंशन, स्पष्ट टाइपयुक्त रैपर के रूप में दिखते हैं। इन रैपर को वापस बाइनरी में एन्कोड करने के लिए विस्तारित JSON चालू करें; सामान्य JSON ऑब्जेक्ट में संयोगवश रैपर कुंजियाँ होने पर इसे बंद रखें।

उदाहरण के लिए, विस्तारित JSON चालू होने पर `{"id":{"$integer":"9007199254740993"},"data":{"$binary":"AQI="}}` एक सटीक पूर्णांक और दो बाइनरी बाइट एन्कोड करता है।

प्रत्येक रूपांतरण एक मान संभालता है और इनपुट की सीमा 1 MiB है। फ़ॉर्मैट किए गए JSON बाइट की गिनती मूल इनपुट के बजाय दिखाए गए, व्यवस्थित JSON की होती है। दोबारा एन्कोड करने पर समर्थित मान सुरक्षित रहते हैं, लेकिन मैप का क्रम या बाइनरी एन्कोडिंग का चुनाव बदल सकता है। रैपर के सिंटैक्स और असमर्थित टाइप देखने के लिए ऊपर “प्रारूप और टाइप संरक्षण” खोलें।
