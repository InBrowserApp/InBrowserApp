## Просмотр двоичных данных API

CBOR и MessagePack — компактные форматы двоичной сериализации структурированных данных. Используйте этот конвертер, чтобы просматривать ответы API, сообщения WebSocket или кешированные значения в виде JSON либо создавать двоичные данные из JSON для отладки. Всё обрабатывается в браузере; входные данные никуда не отправляются и не сохраняются.

## Кодирование JSON и декодирование байтов

Выберите двоичный формат и направление преобразования. Для кодирования введите JSON и выберите Hex, Base64 или Base64URL для результата. Для декодирования вставьте байты и выберите их входную кодировку. При смене входной кодировки текст, уже находящийся в редакторе, интерпретируется заново.

При кодировании откройте файл JSON, а при декодировании — двоичный файл `.cbor`, `.msgpack` или `.bin`. Закодированный текст, например Hex или Base64, следует вставить в редактор. Выполните преобразование, затем скопируйте отображаемый текст или скачайте результат. Скачиваемые двоичные файлы содержат сами байты и могут быть импортированы повторно.

## Сохранение значений и ограничения

Целочисленные литералы сохраняют все цифры в пределах 64-битного диапазона, поддерживаемого форматом. Значения, которые нельзя представить в JSON, например двоичные поля, теги CBOR и расширения MessagePack, отображаются как явные типизированные обёртки. Включите расширенный JSON, чтобы закодировать эти обёртки обратно в двоичные данные; оставьте его выключенным для обычных объектов JSON, в которых случайно используются ключи обёрток.

Например, при включённом расширенном JSON `{"id":{"$integer":"9007199254740993"},"data":{"$binary":"AQI="}}` кодирует точное целое число и два байта двоичных данных.

Каждое преобразование обрабатывает одно значение с ограничением входных данных в 1 МиБ. Показатель «Байтов форматированного JSON» относится к отображаемому JSON с отступами, а не к исходным входным данным. Повторное кодирование сохраняет поддерживаемые значения, но может изменить порядок элементов карты или способ двоичного кодирования. Откройте раздел «Форматы и сохранение типов» выше, чтобы узнать синтаксис обёрток и неподдерживаемые типы.
