## فحص البيانات الثنائية لواجهات API

CBOR وMessagePack تنسيقان ثنائيان مضغوطان لتسلسل البيانات المنظّمة. استخدم هذا المحوّل لفحص استجابات API أو رسائل WebSocket أو القيم المخزنة مؤقتًا بصيغة JSON، أو لإنشاء بيانات ثنائية من JSON لتصحيح الأخطاء. تُعالج جميع البيانات في متصفحك؛ ولا تُرفع المدخلات أو تُحفظ.

## ترميز JSON أو فك ترميز البايتات

اختر التنسيق الثنائي واتجاه التحويل. للترميز، أدخل JSON واختر Hex أو Base64 أو Base64URL للإخراج. لفك الترميز، ألصق البايتات وحدد ترميز الإدخال. يؤدي تغيير ترميز الإدخال إلى إعادة تفسير النص الموجود في المحرر.

افتح ملف JSON عند الترميز، أو ملفًا خامًا بامتداد `.cbor` أو `.msgpack` أو `.bin` عند فك الترميز. يجب لصق النص المرمّز، مثل Hex أو Base64، في المحرر. نفّذ التحويل، ثم انسخ النص المعروض أو نزّل النتيجة. تحتوي التنزيلات الثنائية على البايتات الفعلية ويمكن استيرادها مجددًا.

## الحفاظ على القيم وفهم القيود

تحتفظ القيم الصحيحة المكتوبة مباشرة بجميع أرقامها ضمن نطاق 64 بت الذي يدعمه التنسيق. تظهر القيم التي لا يستطيع JSON تمثيلها، مثل الحقول الثنائية ووسوم CBOR وامتدادات MessagePack، كأغلفة صريحة ذات أنواع محددة. فعّل JSON الموسّع لإعادة ترميز هذه الأغلفة إلى بيانات ثنائية؛ واتركه معطّلًا لكائنات JSON العادية التي تصادف أنها تستخدم مفاتيح الأغلفة.

على سبيل المثال، عند تفعيل JSON الموسّع، يرمّز `{"id":{"$integer":"9007199254740993"},"data":{"$binary":"AQI="}}` عددًا صحيحًا دقيقًا وبايتين ثنائيين.

يعالج كل تحويل قيمة واحدة، بحد إدخال يبلغ 1 MiB. يحسب عدّاد بايتات JSON المنسّق حجم JSON المعروض بتنسيق مقروء بدلًا من الإدخال الأصلي. تحافظ إعادة الترميز على القيم المدعومة، لكنها قد تغيّر ترتيب الخرائط أو اختيار الترميز الثنائي. افتح «التنسيقات والحفاظ على الأنواع» أعلاه للاطلاع على صياغة الأغلفة والأنواع غير المدعومة.
