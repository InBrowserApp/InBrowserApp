## Calcular o checksum SHA-256 de um texto ou arquivo

Cole um texto UTF-8 ou selecione **Importar de arquivo** para calcular o hash dos bytes originais do arquivo. Copie o resultado em hexadecimal para compará-lo com um checksum publicado. O SHA-256 gera um hash de 256 bits, exibido com 64 caracteres hexadecimais.

Para verificar um download, calcule o hash do arquivo baixado e compare o valor hexadecimal completo com o divulgado pela fonte. No caso de texto, espaços, quebras de linha e alterações entre maiúsculas e minúsculas mudam o hash. Como teste rápido, o texto `abc` sem quebra de linha no fim produz este hash.

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
