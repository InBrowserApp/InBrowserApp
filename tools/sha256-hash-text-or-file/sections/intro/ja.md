## テキストやファイルの SHA-256 チェックサムを計算する

UTF-8 テキストを貼り付けるか、**ファイルから読み込み**を選んでファイルの元のバイト列をハッシュ化します。公開されているチェックサムと照合するには、十六進数の結果をコピーします。SHA-256 の出力は 256 ビットで、十六進数では 64 文字です。

ダウンロードしたファイルを確認するには、そのファイルのハッシュを計算し、配布元が公開した十六進数の値と全桁を比較します。テキストの場合は、空白、大文字・小文字、改行が変わるとハッシュも変わります。試しに末尾に改行を入れずに `abc` と入力すると、次の値が得られます。

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
