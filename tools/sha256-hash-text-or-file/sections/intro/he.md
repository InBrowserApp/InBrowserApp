## חישוב סכום בדיקה SHA-256 לטקסט או לקובץ

הדביקו טקסט ב-UTF-8 או בחרו **ייבוא מקובץ** כדי לחשב גיבוב של הבתים המקוריים של הקובץ. העתיקו את התוצאה ההקסדצימלית כדי להשוות אותה לסכום בדיקה שפורסם. SHA-256 מפיק ערך גיבוב בן 256 סיביות, שמוצג באמצעות 64 תווים הקסדצימליים.

כדי לבדוק הורדה, חשבו את הגיבוב של הקובץ שהורדתם והשוו את כל הערך ההקסדצימלי לערך שפרסם המקור. בטקסט, רווחים, הבדלים בין אותיות גדולות וקטנות ומעברי שורה משנים את הגיבוב. לדוגמה, הטקסט `abc` ללא מעבר שורה בסוף מפיק את הערך הבא.

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
