## 텍스트 또는 파일의 SHA-256 체크섬 계산하기

UTF-8 텍스트를 붙여넣거나 **파일에서 가져오기**를 선택해 파일의 원본 바이트를 해시하세요. 공개된 체크섬과 비교할 때는 16진수 결과를 복사하세요. SHA-256은 64자리 16진수로 표현할 수 있는 256비트 해시를 생성합니다.

다운로드한 파일을 확인하려면 파일의 해시를 계산한 뒤 배포처에서 공개한 16진수 값과 전체 자리를 비교하세요. 텍스트는 공백, 대소문자 또는 줄바꿈이 달라져도 해시가 바뀝니다. 예를 들어 끝에 줄바꿈이 없는 `abc`의 해시는 아래와 같습니다.

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
