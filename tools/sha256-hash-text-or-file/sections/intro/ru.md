## Как вычислить контрольную сумму SHA-256 для текста или файла

Вставьте текст в кодировке UTF-8 или выберите **Импорт из файла**, чтобы вычислить хеш исходных байтов файла. Скопируйте значение в шестнадцатеричном виде, чтобы сравнить его с опубликованной контрольной суммой. SHA-256 выдаёт 256-битный хеш, записанный 64 шестнадцатеричными символами.

Чтобы проверить скачанный файл, вычислите его хеш и целиком сравните шестнадцатеричное значение с тем, которое опубликовал источник. Для текста даже пробел, смена регистра или перенос строки меняет хеш. Для быстрой проверки введите `abc` без переноса строки в конце. Результат будет таким.

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
