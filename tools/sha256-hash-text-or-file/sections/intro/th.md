## คำนวณเช็กซัม SHA-256 ของข้อความหรือไฟล์

วางข้อความ UTF-8 หรือเลือก **นำเข้าจากไฟล์** เพื่อคำนวณแฮชจากไบต์เดิมของไฟล์ คัดลอกผลลัพธ์เลขฐานสิบหกเพื่อเทียบกับเช็กซัมที่เผยแพร่ไว้ SHA-256 ให้ค่าแฮชขนาด 256 บิต ซึ่งแสดงเป็นเลขฐานสิบหก 64 หลัก

หากต้องการตรวจสอบไฟล์ที่ดาวน์โหลด ให้คำนวณแฮชของไฟล์นั้น แล้วเทียบค่าเลขฐานสิบหกทั้งหมดกับค่าที่แหล่งดาวน์โหลดเผยแพร่ไว้ สำหรับข้อความ ช่องว่าง ตัวพิมพ์เล็กใหญ่ และการขึ้นบรรทัดใหม่ล้วนทำให้ค่าแฮชเปลี่ยน ลองป้อนข้อความ `abc` โดยไม่ขึ้นบรรทัดใหม่ท้ายข้อความ จะได้ผลลัพธ์ดังนี้

```text
ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
```
