## ブラウザーでゲームパッドをテストするには？

ゲームパッドを USB または Bluetooth で接続し、このタブを表示した状態でゲームパッドのいずれかのボタンを押してください。スティックを動かしたりボタンを押したりして、ブラウザーにどの入力が届くか確認します。複数台を接続している場合は、ゲームパッドのメニューからテストする機器を選んでください。

## スティックのドリフトを見分けるには？

各スティックをいくつかの方向に倒し、手を離して自然に戻るのを待ちます。触れていないスティックは通常、X と Y がどちらも 0 に近い中心付近に戻ります。**ドリフトを確認**を選び、3 秒間どちらのスティックにも触れないでください。平均のずれは測定中の中心からの距離の平均、最大のずれは記録された最も遠い距離です。

例えば X が 0.030、Y が 0.040 なら、中心からの距離は 0.050 です。何度試しても手を離した後に同程度のずれが出る場合、ドリフトしている可能性があります。最大のずれが平均を大きく上回る場合は、一瞬だけ入力値が跳ねた可能性があります。特定のゲームでだけ問題が出るなら、ゲーム内のデッドゾーン設定を確認してください。デッドゾーンとは、ゲームが中心付近の小さな入力を無視する範囲です。

## ボタンとトリガーのテストでは何を見ればよいですか？

各ボタンを順番に押して離します。デジタルボタンの値は通常 0% と 100% の間で切り替わり、アナログトリガーは途中の値も示します。左右のトリガーをゆっくり引いて離し、どちらも最大値に達してから 0% に戻るか比べてください。標準レイアウトが適用されない場合、操作部を一つずつ動かし、対応するボタンや軸の番号を特定します。

## ゲームパッドが検出されないのはなぜですか？

端末がゲームパッドを認識しているか確認し、このタブに戻ってボタンを押してください。Bluetooth 接続が不安定なら、データ転送対応の USB ケーブルを試してください。他のアプリでは使える場合、最新のブラウザーでテスターを直接開いてみてください。読み取れる入力は、ブラウザーと OS が提供するデータによって異なります。
