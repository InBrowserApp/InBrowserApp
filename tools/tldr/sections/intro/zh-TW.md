## 查找指令範例

搜尋 `git commit` 即可直接查看範例。搜尋 `git` 可瀏覽 `git add`、`git status` 等相關指令。每個頁面都有簡短說明、常見用法和文件連結。

## 選擇作業系統與語言

同一個指令在不同平台上的選項可能不同，此時可指定作業系統。例如，`cat` 在 Linux 和 macOS 各有專用頁面。自動模式會優先顯示通用頁面，無通用頁面且有多個平台版本時，會請你選擇。

範例語言預設跟隨網站語言。工具會優先查詢所選平台。若找不到翻譯，會先嘗試同一平台的英文頁面，再查詢通用頁面。結果會標示目前頁面實際使用的平台和語言。

## 閱讀、複製與分享範例

醒目標示的預留欄位需要自行填入內容，例如檔案路徑或提交訊息。看到 `[-m|--message]` 這類寫法時，請選擇其中一個選項。複製範例後，請先換成自己的值，再到終端機使用。

複製結果連結即可分享同一個指令、平台和範例語言。按一下 GitHub 圖示可開啟該版本的原始頁面。
