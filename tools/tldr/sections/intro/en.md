## Find examples for a command

Search for `git commit` to jump to its examples. Search for `git` to browse related commands such as `git add` and `git status`. Each page gives you a short description, common ways to use the command, and a link to its documentation.

## Choose a platform and language

Set the operating system when a command has different options on different platforms. For example, `cat` has separate Linux and macOS pages. Automatic selection prefers the common page and shows a choice when several platform-specific pages are available.

The example language follows the site language by default. Lookup tries your selected platform first, including its English page if a translation is unavailable, before trying the common page. The result shows the platform and language of the page you are actually reading.

## Read, copy, and share examples

Highlighted placeholders represent values you supply, such as a file path or commit message. When an example shows alternatives like `[-m|--message]`, choose one option. Copy an example, then replace those values before using it in your terminal.

Copy the result link to share the same command, platform, and example language. The GitHub icon opens the original page for that version.

## Where the examples come from

The tool searches a local command index and downloads the selected page from the [tldr pages project](https://github.com/tldr-pages/tldr). The community maintains the examples under the [MIT License](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
