## Look up a command

Search for a command such as `git commit`, then open a result to read or copy its examples. Choose an operating system when syntax differs. If an example is unavailable in your chosen language, the tool can show the English version for that platform.

The tool searches a local command index and downloads the selected page from the [tldr pages project](https://github.com/tldr-pages/tldr). The data is available under the [MIT License](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
