## ค้นหาตัวอย่างการใช้คำสั่ง

ค้นหา `git commit` เพื่อเปิดตัวอย่างการใช้งานโดยตรง ค้นหา `git` เพื่อดูคำสั่งที่เกี่ยวข้อง เช่น `git add` และ `git status` แต่ละหน้ามีคำอธิบายสั้น ๆ วิธีใช้คำสั่งที่พบบ่อย และลิงก์ไปยังเอกสารของคำสั่งนั้น

## เลือกแพลตฟอร์มและภาษา

เลือกระบบปฏิบัติการเมื่อคำสั่งมีตัวเลือกต่างกันในแต่ละแพลตฟอร์ม เช่น `cat` มีหน้าแยกสำหรับ Linux และ macOS โหมดอัตโนมัติจะเลือกหน้าทั่วไปก่อน และให้คุณเลือกเมื่อมีหน้าเฉพาะแพลตฟอร์มหลายหน้า

โดยค่าเริ่มต้น ตัวอย่างจะใช้ภาษาเดียวกับเว็บไซต์ เครื่องมือจะค้นหาหน้าของแพลตฟอร์มที่เลือกก่อน โดยใช้หน้าภาษาอังกฤษหากไม่มีฉบับแปล จากนั้นจึงค้นหาหน้าทั่วไป ผลการค้นหาจะแสดงแพลตฟอร์มและภาษาของหน้าที่กำลังอ่าน

## อ่าน คัดลอก และแชร์ตัวอย่าง

ส่วนที่ไฮไลต์เป็นค่าที่ต้องใส่เอง เช่น เส้นทางไฟล์หรือข้อความคอมมิต เมื่อตัวอย่างมีทางเลือกอย่าง `[-m|--message]` ให้เลือกใช้เพียงหนึ่งตัวเลือก คัดลอกตัวอย่างแล้วแทนที่ค่าเหล่านั้นก่อนนำไปใช้ในเทอร์มินัล

คัดลอกลิงก์ผลการค้นหาเพื่อแชร์คำสั่ง แพลตฟอร์ม และภาษาของตัวอย่างที่กำลังดู ไอคอน GitHub จะเปิดหน้าต้นฉบับของฉบับนั้น
