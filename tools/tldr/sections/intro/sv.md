## Slå upp ett kommando

Sök efter ett kommando som `git commit` och öppna ett sökresultat för att läsa eller kopiera exemplen. Välj ett operativsystem om syntaxen skiljer sig åt. Om ett exempel saknas på det språk du valt kan verktyget visa den engelska versionen för samma plattform.

Verktyget söker i ett lokalt kommandoindex och laddar ned den valda sidan från [projektet tldr pages](https://github.com/tldr-pages/tldr). Data görs tillgängliga under [MIT-licensen](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
