## 查找命令示例

搜索 `git commit` 可直接查看它的用法示例。搜索 `git` 可浏览 `git add` 和 `git status` 等相关命令。每个页面都包含简短说明、常见用法和命令文档链接。

## 选择平台和语言

如果命令选项因平台而异，请选择对应的操作系统。例如，`cat` 有各自的 Linux 和 macOS 页面。自动选择会优先显示通用页面。如果有多个平台专用页面可选，工具会提示你选择。

示例默认跟随网站语言。工具会先查找所选平台的页面。如果缺少所选语言的译文，会先查找该平台的英文页面，再尝试通用页面。结果会标明当前页面的平台和语言。

## 阅读、复制和分享示例

高亮的占位符标出需要自行填写的值，例如文件路径或提交说明。如果示例给出 `[-m|--message]` 这样的备选项，选择其中一个。复制示例后，先替换这些值，再在终端中使用。

复制结果链接即可分享同一命令、平台和示例语言。点击 GitHub 图标可打开该版本的原始页面。

## 示例来源

工具会在本地命令索引中搜索，并从 [tldr pages 项目](https://github.com/tldr-pages/tldr)下载选中的页面。这些示例由社区维护，按 [MIT 许可证](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md)发布。
