## Encuentra ejemplos de un comando

Busca `git commit` para ir directamente a sus ejemplos. Busca `git` para explorar comandos relacionados, como `git add` y `git status`. Cada página incluye una breve descripción, ejemplos de uso habitual y un enlace a la documentación del comando.

## Elige la plataforma y el idioma

Selecciona el sistema operativo cuando las opciones de un comando varíen según la plataforma. Por ejemplo, `cat` tiene páginas distintas para Linux y macOS. La selección automática da prioridad a la página común y te permite elegir si hay varias páginas para distintas plataformas.

De forma predeterminada, los ejemplos se muestran en el idioma del sitio. La búsqueda empieza por la plataforma elegida e incluye su página en inglés si falta la traducción. Después consulta la página común. El resultado indica la plataforma y el idioma de la página que estás leyendo.

## Lee, copia y comparte ejemplos

Los marcadores resaltados representan valores que debes proporcionar, como la ruta de un archivo o el mensaje de un commit. Cuando un ejemplo muestre alternativas como `[-m|--message]`, elige una opción. Copia el ejemplo y sustituye esos valores antes de usarlo en la terminal.

Copia el enlace del resultado para compartir el mismo comando, plataforma e idioma de los ejemplos. El icono de GitHub abre la página original de esa versión.

## De dónde vienen los ejemplos

La herramienta busca en un índice local de comandos y descarga la página seleccionada del [proyecto tldr pages](https://github.com/tldr-pages/tldr). La comunidad mantiene los ejemplos bajo la [licencia MIT](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
