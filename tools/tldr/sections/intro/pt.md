## Encontre exemplos de um comando

Busque `git commit` para abrir seus exemplos diretamente. Busque `git` para explorar comandos relacionados, como `git add` e `git status`. Cada página traz uma breve descrição, formas comuns de usar o comando e um link para a documentação.

## Escolha a plataforma e o idioma

Selecione o sistema operacional quando as opções de um comando variarem entre plataformas. Por exemplo, `cat` tem páginas separadas para Linux e macOS. A seleção automática dá preferência à página genérica e permite escolher quando há várias páginas específicas de plataforma.

Por padrão, os exemplos seguem o idioma do site. A consulta tenta primeiro a plataforma selecionada, recorrendo à página em inglês se não houver tradução, antes de tentar a página genérica. O resultado indica a plataforma e o idioma da página exibida.

## Leia, copie e compartilhe exemplos

Os campos destacados representam valores que você precisa preencher, como um caminho de arquivo ou uma mensagem de commit. Se um exemplo mostrar alternativas como `[-m|--message]`, escolha uma das opções. Copie o exemplo e substitua esses valores antes de usá-lo no terminal.

Copie o link do resultado para compartilhar o mesmo comando, plataforma e idioma dos exemplos. O ícone do GitHub abre a página original dessa versão.

## De onde vêm os exemplos

A ferramenta consulta um índice local de comandos e baixa a página selecionada do [projeto tldr pages](https://github.com/tldr-pages/tldr). A comunidade mantém os exemplos sob a [licença MIT](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
