## Consulte um comando

Busque um comando como `git commit` e abra um dos resultados para ler ou copiar os exemplos. Escolha um sistema operacional quando a sintaxe for diferente. Se um exemplo não estiver disponível no idioma escolhido, a ferramenta poderá mostrar a versão em inglês para esse sistema.

A ferramenta consulta um índice local de comandos e baixa a página selecionada do [projeto tldr pages](https://github.com/tldr-pages/tldr). Os dados estão disponíveis sob a [licença MIT](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
