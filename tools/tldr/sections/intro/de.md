## Einen Befehl nachschlagen

Suche nach einem Befehl wie `git commit` und öffne ein Ergebnis, um die Beispiele zu lesen oder zu kopieren. Wähle das passende Betriebssystem, wenn sich die Syntax unterscheidet. Ist ein Beispiel in der gewählten Sprache nicht verfügbar, kann das Tool die englische Version für dieses Betriebssystem anzeigen.

Das Tool durchsucht einen lokalen Befehlsindex und lädt die ausgewählte Seite aus dem [Projekt tldr pages](https://github.com/tldr-pages/tldr). Die Daten stehen unter der [MIT-Lizenz](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
