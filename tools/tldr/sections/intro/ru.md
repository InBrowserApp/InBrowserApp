## Как найти команду

Введите команду, например `git commit`, затем откройте результат, чтобы посмотреть или скопировать примеры. Если синтаксис различается, выберите операционную систему. Если примера нет на выбранном языке, инструмент может показать английскую версию для этой платформы.

Инструмент ищет по локальному индексу команд и загружает выбранную страницу из [проекта tldr pages](https://github.com/tldr-pages/tldr). Данные доступны по [лицензии MIT](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
