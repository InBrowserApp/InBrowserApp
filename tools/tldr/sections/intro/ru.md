## Как найти примеры для команды

Введите `git commit`, чтобы сразу перейти к примерам. Введите `git`, чтобы посмотреть связанные команды, например `git add` и `git status`. На каждой странице есть краткое описание, типичные примеры использования и ссылка на документацию команды.

## Как выбрать платформу и язык

Укажите операционную систему, если на разных платформах у команды разные параметры. Например, для `cat` есть отдельные страницы для Linux и macOS. В автоматическом режиме приоритет у общей страницы. Если доступны несколько страниц для разных платформ, можно выбрать нужную.

По умолчанию язык примеров совпадает с языком сайта. Сначала инструмент ищет страницу для выбранной платформы. Если перевода нет, он проверяет, есть ли для неё страница на английском, и только затем ищет общую страницу. В результате указаны платформа и язык открытой страницы.

## Как читать, копировать и делиться примерами

Выделенные заполнители обозначают значения, которые нужно указать самостоятельно, например путь к файлу или сообщение коммита. Если в примере указаны варианты вроде `[-m|--message]`, выберите один из них. Скопируйте пример и подставьте свои значения, прежде чем использовать его в терминале.

Скопируйте ссылку на результат, чтобы поделиться той же командой для той же платформы и на том же языке. Значок GitHub открывает исходную страницу этой версии.

## Откуда берутся примеры

Инструмент ищет по локальному индексу команд и загружает выбранную страницу из [проекта tldr pages](https://github.com/tldr-pages/tldr). Сообщество поддерживает примеры и публикует их по [лицензии MIT](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
