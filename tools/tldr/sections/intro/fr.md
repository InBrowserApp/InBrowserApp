## Rechercher une commande

Recherchez une commande comme `git commit`, puis ouvrez un résultat pour lire ou copier les exemples. Choisissez un système d’exploitation lorsque la syntaxe varie. Si un exemple n’existe pas dans la langue choisie, l’outil peut afficher la version anglaise pour ce système.

L’outil consulte un index local de commandes et télécharge la page choisie depuis le [projet tldr pages](https://github.com/tldr-pages/tldr). Les données sont disponibles sous [licence MIT](https://github.com/tldr-pages/tldr/blob/main/LICENSE.md).
