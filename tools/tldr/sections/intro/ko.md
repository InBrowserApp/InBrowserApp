## 명령어 예제 찾기

`git commit`을 검색하면 예제를 바로 볼 수 있습니다. `git`을 검색하면 `git add`, `git status` 등 관련 명령어를 둘러볼 수 있습니다. 각 페이지에는 간단한 설명과 자주 쓰는 사용법, 문서 링크가 있습니다.

## 운영체제와 언어 선택하기

명령어 옵션이 플랫폼에 따라 다르면 사용할 운영체제를 선택하세요. 예를 들어 `cat`에는 Linux용 페이지와 macOS용 페이지가 따로 있습니다. 자동 설정은 공통 페이지를 우선 표시하며, 공통 페이지 없이 플랫폼별 페이지가 여러 개 있으면 운영체제를 선택할 수 있습니다.

예제는 기본적으로 사이트와 같은 언어로 표시됩니다. 선택한 운영체제의 페이지를 먼저 찾고, 번역이 없으면 해당 운영체제의 영어 페이지를 확인한 뒤 공통 페이지를 찾습니다. 결과에는 현재 표시된 페이지의 운영체제와 언어가 표시됩니다.

## 예제 읽기, 복사하기, 공유하기

강조된 자리 표시자는 파일 경로나 커밋 메시지처럼 직접 입력할 값입니다. `[-m|--message]`처럼 선택지가 표시되면 옵션을 하나만 고르세요. 예제를 복사한 뒤 값을 바꾸고 터미널에서 사용하세요.

결과 링크를 복사하면 같은 명령어, 운영체제, 예제 언어를 공유할 수 있습니다. GitHub 아이콘을 누르면 해당 버전의 원본 페이지가 열립니다.
