## Leggi un file WPS Writer nel browser

Apri o trascina un documento WPS Writer compatibile (`.wps`) o un modello (`.wpt`). Puoi selezionare il testo in una vista continua, usare lo zoom o navigare tra i titoli riconosciuti. Il file resta sul tuo dispositivo.

## Compatibilità e strumenti correlati

I file supportati contengono dati binari Word o contenuto HTML in un contenitore OLE. I formati proprietari WPS meno recenti e i file Microsoft Works non sono supportati. La formattazione complessa può essere semplificata.

Per esportare un file compatibile, usa il [Convertitore da WPS a PDF](../wps-to-pdf-converter/). Per i file `.doc` e `.docx`, usa il [Visualizzatore Microsoft Word](../microsoft-word-viewer/).
