## Eine WPS-Writer-Datei im Browser lesen

Öffnen Sie ein kompatibles WPS-Writer-Dokument (`.wps`) oder eine kompatible Vorlage (`.wpt`). Sie können die Datei auch in den Betrachter ziehen. Markieren Sie Text in der fortlaufenden Leseansicht, passen Sie den Zoom an oder springen Sie zu erkannten Überschriften. Ihre Datei bleibt auf Ihrem Gerät.

## Kompatibilität und verwandte Werkzeuge

Unterstützte Dateien enthalten binäre Word- oder HTML-Dokumentinhalte in einem OLE-Container. Ältere proprietäre WPS-Formate und Microsoft-Works-Dateien werden nicht unterstützt. Komplexe Formatierungen können vereinfacht werden.

Um eine kompatible Datei zu exportieren, verwenden Sie den [WPS-zu-PDF-Konverter](../wps-to-pdf-converter/). Für `.doc`- und `.docx`-Dateien verwenden Sie den [Betrachter für Microsoft Word](../microsoft-word-viewer/).
