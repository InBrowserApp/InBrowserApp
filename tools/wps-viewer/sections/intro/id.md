## Baca file WPS Writer di browser Anda

Buka atau letakkan dokumen WPS Writer (`.wps`) atau templat (`.wpt`) yang kompatibel di sini. Baca dan pilih teks dalam tata letak berkelanjutan, ubah skala tampilan, atau buka bagian yang judulnya terdeteksi. File tetap berada di perangkat Anda.

## Kompatibilitas dan alat terkait

File yang didukung berisi dokumen Word biner atau HTML dalam kontainer OLE. Format WPS lama yang berpemilik dan file Microsoft Works tidak didukung. Pemformatan yang rumit dapat disederhanakan.

Untuk mengekspor file yang kompatibel, gunakan [Konverter WPS ke PDF](../wps-to-pdf-converter/). Untuk file `.doc` dan `.docx`, gunakan [Penampil Microsoft Word](../microsoft-word-viewer/).
