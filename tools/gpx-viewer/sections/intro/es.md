## Cómo abrir un archivo GPX

Abre un archivo .gpx de un reloj, un ciclocomputador o un planificador de rutas. El mapa muestra los trayectos registrados, las rutas planificadas y los puntos de paso guardados. Recorre el perfil de elevación con el puntero o con el control de teclado para localizar un punto registrado en el mapa.

## Cómo se calculan la distancia y el desnivel

La distancia se mide entre puntos consecutivos de cada tramo de un trayecto o de cada ruta. El desnivel positivo y negativo se calcula a partir de la elevación registrada en metros. Se conservan las separaciones entre tramos y los huecos sin datos de elevación. El mapa base y los cálculos funcionan sin conexión una vez cargada la página. El archivo se queda en tu navegador.
