## Afficher un fichier GPX

Ouvrez un fichier .gpx issu d’une montre, d’un compteur vélo ou d’un planificateur d’itinéraire. La carte affiche les traces GPS enregistrées, les itinéraires planifiés et les points de cheminement. Parcourez le profil altimétrique avec le pointeur ou le clavier pour repérer un point enregistré sur la carte.

## Calcul de la distance et du dénivelé

La distance est mesurée entre les points successifs de chaque segment de trace ou itinéraire. Le dénivelé positif et négatif est calculé à partir des altitudes enregistrées, en mètres. Le profil conserve les coupures entre les segments et les valeurs manquantes. Une fois la page chargée, le fond de carte et les calculs fonctionnent hors ligne. Le fichier reste dans votre navigateur.
