## Comment convertir un document Word DOCX en EPUB

Choisissez un fichier `.docx` ou faites-le glisser sur le convertisseur. Vérifiez l’aperçu du document, puis cliquez sur **Télécharger l’EPUB**. Par exemple, `manuscript.docx` devient `manuscript.epub`. La conversion se fait sur votre appareil. Si votre document Word utilise l’ancien format `.doc`, enregistrez d’abord une copie `.docx` dans Word.

## Conserver le texte, les titres et les illustrations

Le convertisseur conserve le texte sélectionnable, les titres, les listes, les tableaux, les liens et les illustrations intégrées prises en charge. Appliquez les styles de titre intégrés de Word pour générer une table des matières qui permet d’accéder directement à un chapitre ou à une section. L’EPUB reprend le titre et le nom de l’auteur lorsqu’ils sont renseignés dans le document Word.

## Lire le document Word comme un livre numérique

Avec un EPUB à mise en page adaptable, vous pouvez changer la taille de la police et le texte s’ajuste à votre écran. Les numéros de page, les en-têtes, les pieds de page et les sauts de page de Word sont omis. Ouvrez le fichier converti dans le [Lecteur EPUB](/fr/tools/epub-reader/) pour vérifier le texte et la navigation.
