## Konversikan dokumen Word ke PDF

Buka atau letakkan file `.doc`, `.docx`, `.docm`, `.dotx`, atau `.dotm` di sini. Pratinjau PDF yang dihasilkan sebelum mengunduhnya. File diproses di browser Anda.

## Tata letak halaman dan kompatibilitas

Isi utama dokumen DOC ditata ulang ke halaman A4. Format yang lebih baru menggunakan ukuran dan orientasi halaman dokumen. Halaman PDF berupa gambar dengan resolusi 150 DPI. Enkripsi dan beberapa fitur dokumen dapat menghambat konversi.

Untuk membaca dokumen, gunakan [Penampil Microsoft Word](../microsoft-word-viewer/). Untuk mengonversi file `.wps` atau `.wpt` yang kompatibel, gunakan [Konverter WPS ke PDF](../wps-to-pdf-converter/).
