## Convierte un documento de Word a PDF

Abre o arrastra al conversor un archivo `.doc`, `.docx`, `.docm`, `.dotx` o `.dotm`. Revisa el PDF generado antes de descargarlo. El archivo se procesa en tu navegador.

## Diseño de página y compatibilidad

El contenido principal de los archivos DOC se redistribuye en páginas A4. Para los formatos más recientes se usan el tamaño y la orientación de página del documento. Las páginas del PDF son imágenes a 150 DPI. El cifrado y algunas funciones del documento pueden impedir la conversión.

Para leer el documento, usa el [Visor de Microsoft Word](../microsoft-word-viewer/). Para convertir un archivo `.wps` o `.wpt` compatible, usa el [Conversor de WPS a PDF](../wps-to-pdf-converter/).
