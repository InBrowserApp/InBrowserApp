## Como extrair imagens de um PDF

1. Escolha um PDF ou arraste o arquivo para a caixa acima. A ferramenta analisa todas as páginas automaticamente.
2. Veja a prévia das fotos, digitalizações e outras imagens rasterizadas incorporadas. Cada resultado mostra o formato, as dimensões em pixels e a primeira página em que a imagem aparece.
3. Baixe as imagens que você precisa uma por vez ou reúna todos os resultados em um único arquivo ZIP.

O PDF e as imagens extraídas ficam no seu navegador. Você não precisa enviar o documento nem criar uma conta.

## Extrair imagens incorporadas ou converter páginas de PDF

Extrair imagens é salvar as figuras armazenadas dentro do PDF. Isso é útil para recuperar fotos de um catálogo, reutilizar um logotipo armazenado como bitmap ou reunir imagens digitalizadas para trabalhar com elas depois. Cada imagem é exportada com as dimensões em pixels gravadas no arquivo, que podem ser maiores do que as exibidas na página. Uma imagem incorporada usada mais de uma vez aparece apenas uma vez na lista, com a primeira página em que aparece.

Use o [Conversor de PDF para imagens](../pdf-to-image-converter/) para salvar páginas inteiras como imagens, incluindo texto, desenhos vetoriais e layout. Use o [Extrator de texto de PDF](../pdf-text-extractor/) para salvar o texto selecionável.

## Formatos e qualidade das imagens

Imagens JPEG incorporadas compatíveis são salvas como JPG sem nova compressão. As demais imagens compatíveis são salvas em PNG sem perdas, com transparência quando ela está presente no PDF. As imagens podem ter sido redimensionadas ou comprimidas antes de serem incorporadas, então o resultado reflete os dados que o PDF realmente guarda. Cortes, rotações e sobreposições aplicados na página não são incorporados à imagem extraída.

## Perguntas frequentes

### Posso extrair imagens de um PDF digitalizado?

Sim, quando a digitalização está armazenada como uma imagem rasterizada incorporada. Uma página digitalizada pode conter uma imagem de página inteira ou várias partes. Para obter uma única imagem da página completa, use o Conversor de PDF para imagens.

### Por que alguns elementos gráficos não aparecem?

Textos, logotipos vetoriais e desenhos compostos de formas do PDF não ficam armazenados como imagens rasterizadas separadas. Algumas imagens danificadas ou com codificações incompatíveis também podem ser ignoradas. Se você precisa do elemento gráfico exatamente como aparece na página, converta a página inteira em imagem.
