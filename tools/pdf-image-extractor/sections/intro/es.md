## Cómo extraer imágenes de un PDF

1. Elige un PDF o suéltalo en el recuadro de arriba. La herramienta analiza todas las páginas automáticamente.
2. Revisa la vista previa de las fotos, los escaneos y otras imágenes de mapa de bits incrustadas. Cada resultado indica el formato, las dimensiones en píxeles y la primera página en la que aparece la imagen.
3. Descarga las imágenes que necesites por separado o guarda todos los resultados en un solo archivo ZIP.

El PDF y las imágenes extraídas se quedan en tu navegador. No hace falta subir el documento ni crear una cuenta.

## Extraer imágenes incrustadas o convertir páginas de PDF

La extracción guarda las imágenes almacenadas en el PDF. Sirve para recuperar fotos de un catálogo, reutilizar un logotipo guardado como mapa de bits o recopilar escaneos para seguir trabajando con ellos. Las imágenes conservan las dimensiones en píxeles con las que se guardaron en el PDF, así que pueden tener más detalle del que se aprecia en la página. Si se reutiliza una imagen incrustada, aparece una sola vez en los resultados, junto con la primera página en la que se usa.

Usa el [Convertidor de PDF a imagen](../pdf-to-image-converter/) para guardar páginas enteras como imágenes, con el texto, los dibujos vectoriales y la maquetación. Usa el [Extractor de texto de PDF](../pdf-text-extractor/) para guardar el texto seleccionable.

## Formatos y calidad de las imágenes

Las imágenes JPEG incrustadas compatibles se guardan como JPG sin volver a comprimirlas. Las demás imágenes compatibles se guardan en PNG sin pérdida y conservan la transparencia que tengan en el PDF. Las imágenes pueden haberse redimensionado o comprimido antes de incorporarse al PDF, por lo que el resultado refleja lo que se guardó en el archivo. Los recortes, giros y elementos superpuestos que se aplican en la página no se incorporan a la imagen extraída.

## Preguntas frecuentes

### ¿Puedo extraer imágenes de un PDF escaneado?

Sí, si el escaneo se guardó como una imagen de mapa de bits incrustada. Una página escaneada puede contener una imagen de página completa o varias piezas. Para obtener una sola imagen de toda la página, usa el Convertidor de PDF a imagen.

### ¿Por qué no aparecen algunos gráficos?

El texto, los logotipos vectoriales y los dibujos hechos con formas de PDF no tienen archivos de imagen independientes que se puedan extraer. También pueden quedar fuera las imágenes dañadas o con una codificación no compatible. Si necesitas el gráfico tal como aparece en la página, convierte la página entera en una imagen.
