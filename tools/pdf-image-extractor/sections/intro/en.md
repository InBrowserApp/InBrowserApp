## How to extract images from a PDF

1. Choose a PDF or drop it into the box above. The tool scans each page automatically.
2. Preview the embedded photos, scans, and other raster images. Each result shows its format, pixel dimensions, and the first page where it appears.
3. Download the images you need one at a time, or download all results in a single ZIP file.

The PDF and extracted images stay in your browser. You do not need to upload a document or create an account.

## Extract embedded images or convert PDF pages

Image extraction saves the pictures stored inside the PDF. It is useful for recovering photos from a catalog, reusing a logo stored as a bitmap, or collecting scanned images for further work. Images are exported at their stored pixel dimensions, which can be higher than their visible size on the page. A reused embedded image is listed once, with the first page on which it appears.

Use the [PDF to Image Converter](../pdf-to-image-converter/) to save entire pages, including text, vector drawings, and layout, as images. Use the [PDF Text Extractor](../pdf-text-extractor/) to save selectable text.

## Image formats and quality

Compatible embedded JPEG streams are saved as JPG without recompression. Other supported images are saved as lossless PNG, including transparency where the PDF provides it. A PDF can resize or compress pictures before embedding them, so the extracted image reflects what the PDF actually stores. Page-level cropping, rotation, and overlays are not applied to the extracted image.

## Frequently asked questions

### Can I extract images from a scanned PDF?

Yes, when the scan is stored as an embedded raster image. A scanned page can contain one full-page image or several pieces. To get one image of the complete page, use the PDF to Image Converter.

### Why are some graphics missing?

Text, vector logos, and drawings made of PDF shapes do not have separate raster image files to extract. Some damaged or unsupported image encodings can also be skipped. If you need the graphic exactly as it appears on the page, convert the full page to an image.
