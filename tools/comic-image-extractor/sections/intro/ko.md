## CBZ, CBR, CB7에서 이미지를 추출하는 방법

만화 파일을 선택하거나 도구에 끌어다 놓으세요. 썸네일을 살펴보고 저장할 페이지를 고르세요. **원본 이미지** 또는 **JPG**를 선택한 뒤, 한 페이지는 **이미지 다운로드**, 여러 페이지는 **ZIP 다운로드**로 저장하세요. 만화 파일과 추출한 이미지는 기기에만 남습니다.

## 원본 페이지를 저장하거나 JPG로 변환하기

**원본 이미지**를 선택하면 압축 파일에 담긴 이미지가 재압축 없이 저장되어 원래 해상도와 투명 영역이 유지됩니다. 편집이나 공유에 널리 쓰이는 형식이 필요하면 **JPG**를 선택하세요. 변환한 JPG는 원래 페이지 크기를 유지하며 투명한 영역은 흰색으로 채웁니다. 움직이는 이미지에는 첫 프레임을 사용합니다.

## 만화에서 필요한 페이지만 선택하기

페이지는 폴더와 파일 이름에 들어 있는 숫자를 고려해 정렬합니다. 예를 들어 `page2.png`가 `page10.png`보다 앞에 옵니다. 처음부터 다시 고르려면 **선택 해제**를 누르고, 저장할 수 있는 페이지를 전부 고르려면 **모두 선택**을 누르세요. 다른 썸네일 묶음으로 이동해도 선택이 유지됩니다. ZIP으로 다운로드하면 읽는 순서에 맞춰 파일 이름에 번호가 붙습니다.
