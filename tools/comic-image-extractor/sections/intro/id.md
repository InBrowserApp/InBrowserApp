## Cara mengekstrak gambar dari CBZ, CBR, atau CB7

Pilih file komik atau seret dan lepas ke alat ekstraksi. Telusuri gambar mini dan pilih halaman yang ingin Anda simpan. Pilih **Gambar asli** atau **JPG**, lalu gunakan **Unduh gambar** untuk satu halaman atau **Unduh ZIP** untuk beberapa halaman. Komik dan gambar hasil ekstraksi tetap di perangkat Anda.

## Menyimpan halaman komik asli atau mengubahnya ke JPG

Gunakan **Gambar asli** untuk menyimpan file gambar dari arsip tanpa kompresi ulang sehingga resolusi dan transparansi aslinya tetap terjaga. Pilih **JPG** jika Anda membutuhkan format yang umum untuk menyunting atau berbagi gambar. JPG hasil konversi mempertahankan ukuran halaman, mengisi bagian transparan dengan warna putih, dan menggunakan bingkai pertama dari halaman animasi.

## Memilih halaman tertentu dari komik

Halaman mengikuti urutan alami berdasarkan folder dan nama file, sehingga `page2.png` muncul sebelum `page10.png`. Gunakan **Kosongkan pilihan** untuk membatalkan semua pilihan, atau **Pilih semua** untuk menyertakan semua halaman yang tersedia. Pilihan halaman tetap tersimpan saat Anda beralih ke kelompok gambar mini lain. Nama file di dalam unduhan ZIP diberi nomor sesuai urutan baca.
