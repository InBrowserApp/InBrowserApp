## Como extrair imagens de CBZ, CBR ou CB7

Escolha um arquivo de quadrinhos ou arraste-o para o extrator. Veja as miniaturas e selecione as páginas que deseja salvar. Escolha **Imagens originais** ou **JPG**. Use **Baixar imagem** para uma página ou **Baixar ZIP** para várias. O quadrinho e as imagens extraídas ficam no seu dispositivo.

## Como salvar as páginas originais ou convertê-las para JPG

Use **Imagens originais** para manter os arquivos de imagem sem recompressão, com a resolução e a transparência originais. Escolha **JPG** quando precisar de um formato comum para editar ou compartilhar. A conversão para JPG mantém as dimensões, preenche as áreas transparentes com branco e usa o primeiro quadro de páginas animadas.

## Como selecionar páginas específicas do quadrinho

A ordem segue os nomes das pastas e dos arquivos, levando a numeração em conta. Assim, `page2.png` vem antes de `page10.png`. Use **Limpar seleção** para começar sem páginas selecionadas ou **Selecionar tudo** para incluir todas as páginas disponíveis. A seleção é mantida ao navegar entre os grupos de miniaturas. No ZIP, os arquivos são numerados na ordem de leitura.
