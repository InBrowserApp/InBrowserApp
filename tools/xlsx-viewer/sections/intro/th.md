## เรียกดูสเปรดชีตและตารางในเบราว์เซอร์

เปิดไฟล์จากเครื่องหรือวางไฟล์ลงในโปรแกรมดูเอกสาร สลับเวิร์กชีต เลื่อนดูเซลล์ ปรับการซูม และตรวจดูเนื้อหาในเซลล์ เวิร์กบุ๊ก Excel ยังคงมีรูปแบบการอ่านเช่นเดิม ไฟล์ CSV และ TSV จะแสดงเป็นเวิร์กชีตเดียว ใช้ตัวคั่นและการเข้ารหัสข้อความเพื่อแก้ไขผลการตรวจหา คอลัมน์ข้อความจะเก็บเลขศูนย์นำหน้า รหัสระบุที่ยาว และข้อความที่มีลักษณะคล้ายวันที่ไว้ตามเดิม ใช้ส่งออกเวิร์กชีตเพื่อดาวน์โหลดชีตปัจจุบันเป็น CSV, TSV, JSON หรือ Markdown เลือกข้อความที่จัดรูปแบบหรือค่าที่จัดเก็บไว้ก่อนเตรียมการส่งออก

รูปแบบที่รองรับ ได้แก่ Excel XLSX, XLSM, XLTX, XLTM, XLS และ XLSB; CSV และ TSV; ODS และ FODS; Numbers 3.0 ขึ้นไป; สเปรดชีต WPS ET/ETT และ UOS ที่เข้ากันได้; DIF, SLK, PRN และ DBF; Lotus WK1/WK3/WK4/WKS/123; Quattro Pro WQ1/WQ2/WB1/WB2/WB3/QPW; Works XLR; และ EtherCalc ETH ความเข้ากันได้ขึ้นอยู่กับเวอร์ชันและฟีเจอร์ที่ใช้ในแต่ละไฟล์ รูปแบบรุ่นเก่าจะเน้นข้อมูลในเซลล์มากกว่าการแสดงรายละเอียดรูปลักษณ์ทั้งหมดให้เหมือนต้นฉบับ

## ความเป็นส่วนตัวและความเข้ากันได้

ไฟล์จะประมวลผลภายในเครื่อง โดยเครื่องมือนี้จะไม่อัปโหลดหรือบันทึกไฟล์ แบบอักษรจะมาจากอุปกรณ์ของคุณ โดยไม่มีการเรียกใช้แบบอักษรออนไลน์ เซลล์สูตรจะแสดงผลลัพธ์ที่บันทึกไว้หากมี โปรแกรมจะไม่คำนวณสูตรใหม่ ไม่เรียกใช้แมโคร ไม่รีเฟรชการเชื่อมต่อข้อมูลภายนอก และไม่โหลดลิงก์ในเอกสารโดยอัตโนมัติ

ตารางใน Numbers จะแสดงเป็นแท็บเวิร์กชีตแยกกัน พร้อมชื่อชีตและชื่อตารางเดิมหากมี ไม่รองรับเอกสาร Numbers รุ่นก่อน Numbers 3 โปรแกรมจะไม่โหลดไฟล์บันทึกข้อความที่ใช้คู่กับ DBF รูปแบบ PRN ใช้เค้าโครงความกว้างคงที่ของ Lotus/Excel โดยไม่รองรับไฟล์งานพิมพ์ทั่วไป แผนภูมิ ภาพวาด ฟีเจอร์พิวอต แบบอักษร และรูปแบบบางอย่างอาจไม่ปรากฏในไฟล์ที่นำเข้า หากมีข้อจำกัดเหล่านี้ โปรแกรมจะแสดงหมายเหตุเกี่ยวกับความเข้ากันได้ข้างเอกสาร

ไม่มีการกำหนดเพดานขนาดไฟล์หรือจำนวนชีตตายตัว แต่ไฟล์ที่ซับซ้อนยังคงอยู่ภายใต้ข้อจำกัดด้านหน่วยความจำจริงของเบราว์เซอร์และมาตรการป้องกันเมื่อแตกไฟล์ ไม่สามารถเปิดเวิร์กบุ๊กที่เข้ารหัสหรือเสียหายได้ โปรแกรมนี้ไม่แก้ไขหรือพิมพ์สเปรดชีต

การส่งออกเวิร์กชีตรวมแถวและคอลัมน์ที่ซ่อนอยู่ และใช้ผลลัพธ์ของสูตรที่บันทึกไว้ หากไม่มีผลลัพธ์ที่บันทึกไว้จะเป็นเซลล์ว่าง ข้อผิดพลาดของสเปรดชีตยังคงแสดงอยู่ และเซลล์ที่ผสานจะไม่ถูกขยาย JSON เก็บแถวแรกไว้เป็นข้อมูลและใช้อาร์เรย์สำหรับแต่ละแถว โดยใช้ null แทนเซลล์ว่าง Markdown สามารถใช้แถวแรกเป็นแถวหัวตารางได้ ข้อความที่จัดรูปแบบจะใช้รูปแบบตัวเลขที่รองรับ ส่วนวันที่ที่จัดเก็บไว้ยังคงเป็นเลขลำดับของ Excel ไม่ส่งออกแผนภูมิ รูปภาพ ความคิดเห็น และการจัดรูปแบบ สำหรับรูปแบบที่นำเข้า ผลลัพธ์การส่งออกจะเป็นไปตามข้อมูลเวิร์กชีตที่มีอยู่ในโปรแกรมดูนี้และหมายเหตุเกี่ยวกับความเข้ากันได้
