## Baca dokumen lama secara lokal

Buka dokumen Word 97–2003 `.doc`, dokumen WPS Writer `.wps` yang kompatibel, atau templat `.wpt`. File Anda tetap di perangkat Anda. Pilih dan salin teks, gunakan kerangka dokumen untuk menuju judul yang dikenali, sesuaikan pembesaran, atau masuk ke mode baca fokus. Posisi baca mengikuti alur dokumen berkelanjutan, bukan halaman cetak.

## Kompatibilitas dan tata letak baca

Pembaca ini mendukung dokumen biner Word dan file WPS Writer yang kompatibel, yang berisi konten dokumen biner Word atau HTML dalam kontainer OLE. Kompatibilitas ditentukan oleh isi file, bukan hanya ekstensinya. File Microsoft Works dan format WPS proprieter lama tidak didukung. Gunakan penampil DOCX untuk file Word modern.

Pratinjau mempertahankan teks yang dapat dibaca, tabel, pemformatan dasar, dan gambar tertanam yang didukung. Font, penomoran daftar, kolom, objek mengambang, dan batas halaman dapat berbeda dari aslinya. Header, footer, catatan kaki, catatan akhir, dan komentar tidak ditampilkan. Kotak teks yang dipulihkan mungkin muncul setelah teks utama. Gambar dan aplikasi tertanam yang tidak didukung dapat dihilangkan; catatan pembacaan menunjukkan pratinjau parsial bila terdeteksi.

Perubahan terlacak ditampilkan seolah telah diterima: teks yang disisipkan tetap ditampilkan dan teks yang dihapus disembunyikan. Templat menampilkan konten tersimpan tanpa membuat atau mengedit dokumen. File asli tidak berubah.

## Privasi dan file yang tidak dapat dibuka

Dokumen diproses di browser Anda. Tautan eksternal, gambar jarak jauh, makro, formulir, dan aplikasi tertanam tidak dijalankan. Rujukan internal mungkin tidak tersedia dalam pratinjau. Gunakan kerangka dokumen untuk menuju judul yang dikenali. Tidak ada konten dokumen yang diunggah atau disimpan secara otomatis.

Dokumen yang dilindungi kata sandi memerlukan salinan tanpa enkripsi. Dokumen yang kosong, rusak, tidak didukung, atau membutuhkan banyak sumber daya akan menampilkan penjelasan dan dapat diganti atau ditutup. Tidak ada batas tetap untuk ukuran file atau jumlah halaman; memori browser yang tersedia memengaruhi file yang dapat dibuka.
