## Läs ett äldre dokument lokalt

Öppna ett Word 97–2003-dokument i formatet `.doc`, ett kompatibelt WPS Writer-dokument i formatet `.wps` eller en `.wpt`-mall. Filen stannar på din enhet. Markera och kopiera text, använd översikten för att gå till identifierade rubriker, justera zoomnivån eller aktivera fokuserat läsläge. Läspositionen följer det löpande dokumentet i stället för utskrivna sidor.

## Kompatibilitet och läsvy

Visaren stöder binära Word-dokument och kompatibla WPS Writer-filer som innehåller binärt Word-innehåll eller HTML-dokumentinnehåll i en OLE-behållare. Filens innehåll avgör kompatibiliteten, inte bara filändelsen. Microsoft Works-filer och äldre proprietära WPS-format stöds inte. Använd DOCX-visaren för moderna Word-filer.

Förhandsvisningen bevarar läsbar text, tabeller, grundläggande formatering och inbäddade bilder som stöds. Teckensnitt, listnumrering, kolumner, flytande objekt och sidgränser kan skilja sig från originalet. Sidhuvuden, sidfötter, fotnoter, slutnoter och kommentarer visas inte. Återställda textrutor kan visas efter huvudtexten. Ritningar som inte stöds och inbäddade program kan utelämnas. Information om visningen anger när en ofullständig förhandsvisning har upptäckts.

Spårade ändringar visas som om de har accepterats: infogad text finns kvar och borttagen text döljs. Mallar visar sitt sparade innehåll utan att skapa eller redigera något dokument. Originalfilen ändras inte.

## Integritet och filer som inte kan öppnas

Dokument bearbetas i webbläsaren. Externa länkar, fjärrbilder, makron, formulär och inbäddade program aktiveras inte. Interna referenser kan saknas i förhandsvisningen. Använd översikten för att gå till identifierade rubriker. Inget dokumentinnehåll laddas upp eller sparas automatiskt.

För lösenordsskyddade dokument behövs en okrypterad kopia. Om ett dokument är tomt, skadat, för resurskrävande eller inte stöds visas en förklaring, och dokumentet kan bytas ut eller stängas. Det finns ingen fast gräns för filstorlek eller sidantal. Webbläsarens tillgängliga minne påverkar vilka filer som kan öppnas.
