## Genera una lista de nombres aleatorios

Elige el idioma o la región de los nombres, selecciona un tipo de nombre, introduce la cantidad y selecciona **Generar**. Copia los resultados o descarga un archivo de texto UTF-8 con un nombre por línea. Usa los nombres para rellenar cuentas de prueba, obtener una vista previa de una lista de contactos o buscar ideas para personajes de una historia o un juego.

## Elige un nombre completo, un nombre de pila o un apellido

Elige **Nombre completo** para obtener un nombre para mostrar. Elige **Nombre de pila** o **Apellido** cuando un formulario guarde los dos campos por separado. En el ejemplo `Alex Morgan`, `Alex` es el nombre de pila y `Morgan` es el apellido. El nombre de pila puede aparecer al principio o al final según la convención de nombres.

## Usa nombres de otro idioma o región

El idioma o la región de los nombres determina qué nombres y sistema de escritura usa Faker.js. El idioma del sitio determina el de la interfaz. Por ejemplo, puedes usar la interfaz en inglés para generar nombres japoneses como `山田 花子`. Un nombre completo puede incluir un título, varios apellidos u otro componente del nombre según la región seleccionada.
