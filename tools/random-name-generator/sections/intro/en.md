## Generate a batch of random names

Choose the name language or region, select a name type, enter the quantity, and select **Generate**. Copy the results or download a UTF-8 text file with one name per line. Use the names to fill test accounts, preview a contact list, or find ideas for characters in a story or game.

## Choose a full name, given name, or family name

Choose **Full name** for a display name. Choose **Given name** or **Family name** when a form stores the two fields separately. In the example `Alex Morgan`, `Alex` is the given name and `Morgan` is the family name. The given name can appear first or last depending on the naming convention.

## Use names from another language or region

The name language or region controls which names and writing system Faker.js uses. The site's language controls the interface. For example, you can use the English interface to generate Japanese names such as `山田 花子`. A full name can include a title, multiple surnames, or another name component according to the selected locale.
