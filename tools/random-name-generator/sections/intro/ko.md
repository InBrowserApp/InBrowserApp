## 무작위 이름 일괄 생성

이름의 언어 또는 지역과 이름 유형을 선택하고 수량을 입력한 다음 **생성**을 선택하세요. 결과를 복사하거나 이름이 한 줄에 하나씩 담긴 UTF-8 텍스트 파일을 다운로드할 수 있습니다. 테스트 계정에 입력하거나 연락처 목록을 미리 보고, 이야기나 게임 속 등장인물의 이름을 구상할 때 활용해 보세요.

## 전체 이름, 이름 또는 성 선택

표시할 이름이 필요하면 **전체 이름**을 선택하세요. 양식에서 이름과 성을 별도 항목에 저장한다면 **이름** 또는 **성**을 선택하세요. 예를 들어 `Alex Morgan`에서 `Alex`는 이름이고 `Morgan`은 성입니다. 이름을 쓰는 관습에 따라 이름은 성 앞이나 뒤에 올 수 있습니다.

## 다른 언어 또는 지역의 이름 사용

이름의 언어 또는 지역은 Faker.js가 사용할 이름과 문자 체계를 결정합니다. 사이트 언어는 인터페이스에 적용됩니다. 예를 들어 영어 인터페이스에서 `山田 花子` 같은 일본어 이름을 생성할 수 있습니다. 선택한 지역 설정에 따라 전체 이름에 호칭, 여러 성 또는 다른 이름 구성 요소가 포함될 수 있습니다.
