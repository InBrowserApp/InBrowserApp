# Presentation fixture

`field-notes.ppt` is original InBrowser.App test artwork: three saved slides with text, shapes, an original image, a table, and rotated text. It is generated by the repository's `tools/ppt-viewer/fixtures/generate.py` using python-pptx, Pillow, and LibreOffice. No third-party presentation content is redistributed.

`languages.ppt` is original test content generated by `languages.py`. It includes multiple writing systems, a hidden middle slide, and a final slide for checking saved order. The named fallback fonts are supplied by the converter; the generator needs python-pptx and LibreOffice.
