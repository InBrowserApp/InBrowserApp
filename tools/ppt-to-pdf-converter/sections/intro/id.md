## Konversi presentasi format lama secara lokal

Buka file PowerPoint 97–2003 `.ppt`, `.pps`, atau `.pot`, atau file biner WPS Presentation `.dps` atau `.dpt` yang kompatibel. Konversi slide tersimpan ke PDF, periksa halaman hasilnya, lalu unduh PDF yang sama dengan yang ditampilkan dalam pratinjau. Untuk file PowerPoint modern, gunakan [Konverter PPTX ke PDF](../pptx-to-pdf-converter/).

## Tampilan PDF dan kompatibilitas

Slide mempertahankan urutan, ukuran, dan orientasi yang tersimpan, termasuk slide tersembunyi. Teks yang didukung tetap dapat dipilih, dan bentuk, gambar, serta bagan yang didukung disertakan. OCR tidak ditambahkan pada teks hasil pemindaian. Font diganti jika font aslinya tidak tersedia, sehingga jarak dan pergantian baris dapat berubah. Efek lanjutan dapat berbeda dari aplikasi asalnya. Periksa semua halaman sebelum mengandalkan PDF.

Hasil ekspor bersifat statis: animasi, transisi, pemutaran audio/video, catatan pembicara, komentar, makro, dan tanda tangan digital tidak dipertahankan atau diverifikasi. Sumber daya dokumen eksternal tidak dimuat. File yang dilindungi kata sandi, presentasi yang rusak, serta format WPS atau PowerPoint lama yang tidak kompatibel akan menimbulkan kesalahan. Mengganti nama ekstensi tidak mengubah format aslinya. Untuk membaca tanpa konversi, gunakan [Penampil PPT dan DPS](../ppt-viewer/).

## Privasi dan sumber daya browser

Konversi berjalan di perangkat Anda. Konversi pertama mengunduh sekitar 90 MB file mesin dan font, yang dapat disimpan dalam cache oleh browser Anda; presentasinya sendiri tidak pernah diunggah. Mesin hanya dimuat setelah Anda memilih file. Diperlukan browser terbaru yang mendukung WebAssembly dan memori bersama. Presentasi besar atau kompleks dapat membutuhkan waktu dan memori. Anda dapat membatalkan, menutup, atau mengganti file; PDF yang belum selesai tidak ditawarkan untuk diunduh. Tidak ada batas tetap untuk ukuran file atau jumlah slide.
