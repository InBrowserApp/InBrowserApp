## 保存したメールを端末内で読む

EML、Apple Mail の EMLX、Outlook の MSG ファイルを開いて、件名、差出人、宛先、保存された日時、本文、添付ファイルを確認できます。HTML とプレーンテキストの両方が含まれる場合は、タブで切り替えられます。集中閲覧モードでは本文の表示領域が広がり、文字サイズの調整で長い返信のやり取りも読みやすくなります。

## プライバシーと安全な閲覧

処理はブラウザー内で行われます。メールの内容をアップロードしたり、自動保存したりすることはありません。コンテンツ ID で参照される添付のラスター画像は本文に表示できますが、外部画像、フォント、スタイルシート、動的コンテンツ、リンク先への移動は無効です。添付ファイルは名前、種類、取得できたサイズを一覧表示します。ファイルを開いたり実行したりすることはなく、添付メールの内容も展開しません。

## 形式の互換性

EML と EMLX では、MIME メッセージ、エンコードされた名前や件名、一般的な文字セット、テキストと HTML の本文、添付ファイルに対応しています。EMLX はバイト数で指定されたメール部分を読み取り、Apple Mail のメタデータは無視します。Apple Mail の部分的なダウンロードで別途保存された添付ファイルは利用できません。不完全なメールでも、復元可能な場合は互換性に関する注意とともに表示できます。

MSG では、Outlook のメールヘッダー、プレーンテキスト、HTML、添付ファイル情報、添付のラスター画像に対応しています。Outlook のリッチテキスト形式のみの本文は表示しません。予定表や連絡先のアイテム、暗号化されたメール、保護されたメールには対応していません。Outlook の複雑な書式は、元のアプリケーションと異なる表示になる場合があります。保存されたタイムスタンプに元のタイムゾーン表記があれば、そのまま保持します。メールの転送ヘッダーに日時がない MSG のタイムスタンプは、UTC と明示します。

メールを閲覧しても、送信者の本人確認や電子署名の検証は行われません。日時が欠けていたり形式が正しくなかったりする場合は、推測せずに表示します。開けるファイルは利用可能なメモリとブラウザーの機能によって決まり、ファイルサイズや添付ファイル数に固定の上限はありません。
