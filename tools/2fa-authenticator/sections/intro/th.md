## สร้างรหัส 2FA จากคีย์ตั้งค่าหรือ QR Code

เปิดการตั้งค่าการยืนยันตัวตนแบบสองปัจจัยบนเว็บไซต์ที่ต้องการปกป้องบัญชี แล้วเลือกตัวเลือกแอปยืนยันตัวตน อัปโหลดรูปหรือสแกน QR Code ของเว็บไซต์ หรือวางคีย์ตั้งค่าหรือลิงก์ `otpauth://` แล้วเลือก **เพิ่มบัญชี** คัดลอกรหัสที่แสดงไปใส่ในช่องยืนยันบนเว็บไซต์เพื่อให้การตั้งค่าเสร็จสมบูรณ์

## ย้ายบัญชีจากแอปยืนยันตัวตนอื่น

ใน Google Authenticator ให้เลือก **โอนบัญชี** แล้วส่งออกบัญชีที่ต้องการย้าย จากนั้นเลือก **ใช้กล้อง** ที่นี่เพื่อสแกน QR Code ที่ส่งออก หรืออัปโหลดรูป QR Code ที่บันทึกไว้พร้อมกัน ใน [แอปยืนยันตัวตน InBrowser.App เวอร์ชันเดิม](https://authenticator.inbrowser.app/) ให้เปิด **Export** เลือก **Google Authenticator** ดาวน์โหลดรูป QR Code แล้วอัปโหลดที่นี่

เมื่อนำเข้า QR Code สำหรับโอนบัญชีจาก Google รหัส TOTP จะอัปเดตทุก 30 วินาที หากต้องการเก็บรอบเวลาที่ตั้งเองในแอปเดิม ให้ย้ายบัญชีทีละบัญชี กดไอคอนรูปเฟืองของแต่ละบัญชี เปิด **Key URI** ในหน้าต่าง **Config** แล้ววางลิงก์ที่นี่

บัญชีจะถูกบันทึกไว้ในเบราว์เซอร์นี้ ดาวน์โหลดไฟล์สำรองจาก **ส่งออกบัญชี** ก่อนล้างข้อมูลเว็บไซต์หรือย้ายไปใช้เบราว์เซอร์อื่น เก็บไฟล์สำรองไว้ในที่ปลอดภัยเพราะมีคีย์ตั้งค่าของคุณ หากต้องการกู้คืนจากไฟล์ ให้เลือก **นำเข้าไฟล์สำรอง** ในส่วนเพิ่มบัญชี

## ทำไมเว็บไซต์จึงไม่รับรหัสยืนยัน

เว็บไซต์ส่วนใหญ่ใช้รหัสตามเวลา (TOTP) ตรวจสอบว่าอุปกรณ์ตั้งเวลาโดยอัตโนมัติ หากรหัสปัจจุบันใกล้หมดอายุ ให้รอใช้รหัสถัดไป ส่วนรหัสตามตัวนับ (HOTP) จะคงเดิมจนกว่าจะเลือก **รหัสถัดไป** สำหรับทั้งสองแบบ ให้ใช้รหัสของบัญชีที่ถูกต้องและตั้งค่าให้ตรงกับที่เว็บไซต์ระบุ
