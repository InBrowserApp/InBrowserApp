## 在瀏覽器中探索 SQLite 資料庫

開啟 SQLite 3 資料庫，即可瀏覽資料表與檢視表，檢視欄位、索引、外部索引鍵及 CREATE 陳述式，或執行唯讀 SQL 查詢。試用範例資料庫，即可探索工作區。檔案會在本機處理，絕不會被修改。

## 查詢與匯出結果

選取資料表或檢視表以載入資料列，再編輯 SQL 來篩選、排序或聯結資料。使用**執行查詢**或 **Ctrl/⌘ + Enter** 執行單一 SELECT、WITH 或 EXPLAIN 陳述式。按一下儲存格，即可檢視並複製完整的值。

可將結果上限設為 100、1,000 或 10,000 列，每頁瀏覽 50 列。查詢有 10 秒的時間上限，結果大小上限為 5 MiB。CSV 與 JSON 匯出內容包含所有分頁中已載入的資料列。

JSON 使用獨立的欄位名稱與資料列陣列，保留重複名稱及 NULL 值。整數為精確的十進位字串，BLOB 則包含 `$blob` 十六進位值。CSV 包含標題列、以空白欄位表示 NULL，並在類似公式的文字前加上單引號。

## 支援的 SQLite 檔案

可開啟未加密的 `.db`、`.sqlite` 或 `.sqlite3` 檔案，最大 50 MiB。若資料庫使用 WAL，請先建立已完成檢查點處理的副本再開啟；不會載入 WAL 與日誌附屬檔案。不支援自訂 SQLite 擴充功能。檔案與查詢不會自動儲存。
