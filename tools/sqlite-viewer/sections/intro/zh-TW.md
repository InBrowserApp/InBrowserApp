## 在本機檢視 SQLite 檔案

開啟 SQLite 3 資料庫，即可瀏覽資料表與檢視表，檢視欄位定義、索引、外部索引鍵及 CREATE 陳述式，或執行唯讀 SQL 查詢。您也可以試用範例資料庫，不必選擇檔案即可探索工作區。檔案與查詢始終留在您的瀏覽器中，不會自動儲存。

## 查詢與匯出結果

選取資料表即可預覽其資料列。編輯 SQL 後，使用**執行查詢**或 **Ctrl/⌘ + Enter** 執行單一 SELECT、WITH 或 EXPLAIN 陳述式。結果上限會限制載入的資料列數；每頁顯示 50 列。查詢也可能在達到 5 MiB 結果容量上限或執行 10 秒後停止。取消查詢可讓介面保持流暢，並在下次查詢時重新載入資料庫快照。

CSV 與 JSON 匯出內容包含已載入的結果，也涵蓋其他分頁的資料列。JSON 分別儲存欄位名稱與資料列陣列，保留重複名稱及 NULL 值。SQLite 整數會轉為精確的十進位字串，BLOB 則會轉為包含 `$blob` 十六進位值的物件。CSV 以空白欄位表示 NULL、為特殊字元加上引號，並在類似公式的文字前加上單引號，讓試算表使用更安全。

## 支援的資料庫與限制

可開啟未加密的 `.db`、`.sqlite` 或 `.sqlite3` 檔案，最大 50 MiB。原始檔案絕不會被修改。此工具會在記憶體中載入快照，因此記憶體使用量可能超過檔案大小。不會匯入 WAL 與日誌附屬檔案；請先使用您的資料庫應用程式建立已完成檢查點處理的乾淨副本，再於此開啟。不支援加密資料庫、自訂 SQLite 擴充功能及資料庫編輯。
