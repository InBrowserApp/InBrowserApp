## ตรวจสอบไฟล์ SQLite ในเครื่อง

เปิดฐานข้อมูล SQLite 3 เพื่อสำรวจตารางและวิว ตรวจสอบคำจำกัดความของคอลัมน์ ดัชนี คีย์นอก และคำสั่ง CREATE หรือรันคำสั่ง SQL แบบอ่านอย่างเดียว ลองใช้ฐานข้อมูลตัวอย่างเพื่อสำรวจพื้นที่ทำงานโดยไม่ต้องเลือกไฟล์ ไฟล์และคำสั่งจะอยู่ในเบราว์เซอร์ของคุณและไม่ถูกบันทึกโดยอัตโนมัติ

## รันคำสั่งและส่งออกผลลัพธ์

เลือกตารางเพื่อดูแถวข้อมูล แก้ไข SQL แล้วใช้ **รันคำสั่ง** หรือ **Ctrl/⌘ + Enter** เพื่อรันคำสั่ง SELECT, WITH หรือ EXPLAIN ครั้งละหนึ่งคำสั่ง ขีดจำกัดผลลัพธ์จะกำหนดจำนวนแถวสูงสุดที่โหลด โดยแบ่งแสดงหน้าละ 50 แถว คำสั่งอาจหยุดเมื่อผลลัพธ์ถึงขีดจำกัด 5 MiB หรือเมื่อใช้เวลาครบ 10 วินาที การยกเลิกช่วยให้อินเทอร์เฟซยังตอบสนองได้ และจะโหลดสแนปช็อตฐานข้อมูลใหม่เมื่อรันคำสั่งครั้งถัดไป

ไฟล์ส่งออก CSV และ JSON มีผลลัพธ์ที่โหลดแล้ว รวมถึงแถวในหน้าอื่นด้วย JSON เก็บชื่อคอลัมน์และอาร์เรย์ของแถวแยกกัน เพื่อคงชื่อที่ซ้ำกันและค่า NULL ไว้ จำนวนเต็มของ SQLite จะกลายเป็นสตริงเลขฐานสิบที่มีค่าตรงตามต้นฉบับ และ BLOB จะกลายเป็นออบเจ็กต์ที่มีค่าเลขฐานสิบหกใน `$blob` ส่วน CSV ใช้ช่องว่างสำหรับ NULL ครอบอักขระพิเศษด้วยเครื่องหมายคำพูด และเติมอะพอสทรอฟีหน้าข้อความที่อาจถูกตีความเป็นสูตร เพื่อให้ใช้ในสเปรดชีตได้ปลอดภัยขึ้น

## ฐานข้อมูลที่รองรับและข้อจำกัด

เปิดไฟล์ `.db`, `.sqlite` หรือ `.sqlite3` ที่ไม่ได้เข้ารหัสและมีขนาดไม่เกิน 50 MiB ไฟล์ต้นฉบับจะไม่ถูกแก้ไข เครื่องมือนี้โหลดสแนปช็อตไว้ในหน่วยความจำ จึงอาจใช้หน่วยความจำมากกว่าขนาดไฟล์ ไฟล์ประกอบ WAL และ journal จะไม่ถูกนำเข้า ก่อนเปิดที่นี่ ให้ใช้แอปพลิเคชันฐานข้อมูลของคุณสร้างสำเนาที่อยู่ในสภาพสมบูรณ์และทำเช็กพอยต์แล้ว ไม่รองรับฐานข้อมูลที่เข้ารหัส ส่วนขยาย SQLite แบบกำหนดเอง และการแก้ไขฐานข้อมูล
