## สำรวจฐานข้อมูล SQLite ในเบราว์เซอร์

เปิดฐานข้อมูล SQLite 3 เพื่อสำรวจตารางและวิว ตรวจสอบคอลัมน์ ดัชนี คีย์นอก และคำสั่ง CREATE หรือรันคำสั่ง SQL แบบอ่านอย่างเดียว ลองใช้ฐานข้อมูลตัวอย่างเพื่อสำรวจพื้นที่ทำงาน ไฟล์ของคุณจะถูกประมวลผลในเครื่องและไม่ถูกแก้ไข

## รันคำสั่งและส่งออกผลลัพธ์

เลือกตารางหรือวิวเพื่อโหลดแถวข้อมูล แล้วแก้ไข SQL เพื่อกรอง จัดเรียง หรือรวมข้อมูล รันคำสั่ง SELECT, WITH หรือ EXPLAIN ครั้งละหนึ่งคำสั่งด้วย **รันคำสั่ง** หรือ **Ctrl/⌘ + Enter** คลิกเซลล์เพื่อตรวจสอบและคัดลอกค่าแบบเต็ม

เลือกขีดจำกัดผลลัพธ์ 100, 1,000 หรือ 10,000 แถว และดูผลลัพธ์ครั้งละ 50 แถว คำสั่งมีขีดจำกัดเวลา 10 วินาทีและขนาดผลลัพธ์ 5 MiB ไฟล์ส่งออก CSV และ JSON มีแถวที่โหลดแล้วทั้งหมดจากทุกหน้า

JSON เก็บชื่อคอลัมน์และอาร์เรย์ของแถวแยกกัน เพื่อคงชื่อที่ซ้ำกันและค่า NULL ไว้ จำนวนเต็มเป็นสตริงเลขฐานสิบที่มีค่าตรงตามต้นฉบับ และ BLOB มีค่าเลขฐานสิบหกใน `$blob` ส่วน CSV มีแถวหัวตาราง ใช้ช่องว่างสำหรับ NULL และเติมอะพอสทรอฟีหน้าข้อความที่อาจถูกตีความเป็นสูตร

## ไฟล์ SQLite ที่รองรับ

เปิดไฟล์ `.db`, `.sqlite` หรือ `.sqlite3` ที่ไม่ได้เข้ารหัสและมีขนาดไม่เกิน 50 MiB สำหรับฐานข้อมูลที่ใช้ WAL ให้สร้างสำเนาที่ทำเช็กพอยต์แล้วก่อนเปิด ไฟล์ประกอบ WAL และ journal จะไม่ถูกโหลด ไม่รองรับส่วนขยาย SQLite แบบกำหนดเอง ไฟล์และคำสั่งจะไม่ถูกบันทึกโดยอัตโนมัติ
