## 로컬에서 SQLite 파일 살펴보기

SQLite 3 데이터베이스를 열어 테이블과 뷰를 탐색하고, 열 정의, 인덱스, 외래 키, CREATE 문을 살펴보거나 읽기 전용 SQL 쿼리를 실행하세요. 파일을 선택하지 않고 작업 공간을 둘러보려면 샘플 데이터베이스를 사용해 보세요. 파일과 쿼리는 브라우저에만 남으며 자동으로 저장되지 않습니다.

## 쿼리 및 결과 내보내기

테이블을 선택하면 행을 미리 볼 수 있습니다. SQL을 편집하고 **쿼리 실행** 또는 **Ctrl/⌘ + Enter**를 사용하여 SELECT, WITH 또는 EXPLAIN 문을 하나만 실행하세요. 결과 제한은 불러올 행 수를 제한하며, 페이지당 50개 행을 표시합니다. 결과 용량이 5 MiB에 도달하거나 실행 시간이 10초를 넘으면 쿼리가 중지될 수도 있습니다. 쿼리를 취소하면 인터페이스가 계속 응답하며 다음 쿼리 실행 시 데이터베이스 스냅샷을 다시 불러옵니다.

CSV 및 JSON 내보내기에는 다른 페이지의 행을 포함하여 불러온 결과 전체가 담깁니다. JSON은 열 이름과 행 배열을 따로 저장하여 중복 이름과 NULL 값을 보존합니다. SQLite 정수는 정확한 10진수 문자열로, BLOB은 `$blob` 16진수 값을 가진 객체로 변환됩니다. CSV는 NULL을 빈 필드로 표시하고, 특수 문자를 따옴표로 감싸며, 수식처럼 보이는 텍스트 앞에 작은따옴표를 붙여 스프레드시트에서 더 안전하게 사용할 수 있도록 합니다.

## 지원 데이터베이스 및 제한

최대 50 MiB의 암호화되지 않은 `.db`, `.sqlite` 또는 `.sqlite3` 파일을 열 수 있습니다. 원본 파일은 수정되지 않습니다. 이 도구는 메모리에 스냅샷을 불러오므로 메모리 사용량이 파일 크기를 초과할 수 있습니다. WAL 및 저널 보조 파일은 가져오지 않습니다. 데이터베이스 애플리케이션에서 체크포인트 처리를 마친 정리된 복사본을 만든 다음 여기에서 여세요. 암호화된 데이터베이스, 사용자 정의 SQLite 확장 기능, 데이터베이스 편집은 지원하지 않습니다.
