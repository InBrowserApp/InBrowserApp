## 브라우저에서 SQLite 데이터베이스 살펴보기

SQLite 3 데이터베이스를 열어 테이블과 뷰를 탐색하고, 열, 인덱스, 외래 키, CREATE 문을 살펴보거나 읽기 전용 SQL 쿼리를 실행하세요. 샘플 데이터베이스를 사용해 작업 공간을 둘러보세요. 파일은 로컬에서 처리되며 수정되지 않습니다.

## 쿼리 및 결과 내보내기

테이블이나 뷰를 선택하여 행을 불러온 다음 SQL을 편집해 데이터를 필터링, 정렬하거나 조인하세요. **쿼리 실행** 또는 **Ctrl/⌘ + Enter**로 SELECT, WITH 또는 EXPLAIN 문을 하나만 실행할 수 있습니다. 셀을 클릭하면 전체 값을 살펴보고 복사할 수 있습니다.

결과 제한을 100개, 1,000개 또는 10,000개 행으로 선택하고 페이지당 50개 행씩 살펴보세요. 쿼리 실행 시간은 10초, 결과 크기는 5 MiB로 제한됩니다. CSV 및 JSON 내보내기에는 모든 페이지에서 불러온 행이 포함됩니다.

JSON은 열 이름과 행 배열을 별도로 저장하여 중복 이름과 NULL 값을 보존합니다. 정수는 정확한 10진수 문자열이며 BLOB은 `$blob` 16진수 값을 포함합니다. CSV는 머리글 행을 포함하고 NULL을 빈 필드로 표시하며 수식처럼 보이는 텍스트 앞에 작은따옴표를 붙입니다.

## 지원되는 SQLite 파일

최대 50 MiB의 암호화되지 않은 `.db`, `.sqlite` 또는 `.sqlite3` 파일을 열 수 있습니다. WAL을 사용하는 데이터베이스는 체크포인트 처리를 마친 복사본을 만든 후 여세요. WAL 및 저널 보조 파일은 불러오지 않습니다. 사용자 정의 SQLite 확장 기능은 지원하지 않습니다. 파일과 쿼리는 자동으로 저장되지 않습니다.
