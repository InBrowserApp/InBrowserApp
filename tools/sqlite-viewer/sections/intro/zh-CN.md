## 在浏览器中浏览 SQLite 数据库

打开 SQLite 3 数据库，即可浏览表与视图，查看列、索引、外键和 CREATE 语句，或执行只读 SQL 查询。可以使用示例数据库体验工作区。文件在本地处理，原始文件不会被修改。

## 查询与导出结果

选择一个表或视图以加载数据行，然后编辑 SQL 进行筛选、排序或关联查询。点击**执行查询**或按 **Ctrl/⌘ + Enter**，即可执行一条 SELECT、WITH 或 EXPLAIN 语句。点击单元格可查看并复制完整值。

可将结果行数上限设为 100、1,000 或 10,000 行，每页浏览 50 行。每次查询最长运行 10 秒，结果大小上限为 5 MiB。CSV 和 JSON 导出包含所有分页中已加载的行。

JSON 分别保存列名和行数组，以保留重复列名和 NULL 值。整数表示为精确的十进制字符串，BLOB 包含 `$blob` 十六进制值。CSV 包含表头行，将 NULL 导出为空字段，并在类似公式的文本前添加单引号。

## 支持的 SQLite 文件

可打开最大 50 MiB 的未加密 `.db`、`.sqlite` 或 `.sqlite3` 文件。如果数据库使用 WAL，请先创建已完成检查点操作的副本再打开；不会加载 WAL 和日志附属文件。不支持自定义 SQLite 扩展。文件和查询不会自动保存。
