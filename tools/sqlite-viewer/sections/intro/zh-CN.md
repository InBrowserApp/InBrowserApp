## 在本地查看 SQLite 文件

打开 SQLite 3 数据库，即可浏览表与视图，查看列定义、索引、外键和 CREATE 语句，或执行只读 SQL 查询。无需选择文件，也可以使用示例数据库体验工作区。文件和查询始终保留在浏览器中，不会自动保存。

## 查询与导出结果

选择一个表以预览其数据行。编辑 SQL，然后点击**执行查询**或按 **Ctrl/⌘ + Enter**，即可执行一条 SELECT、WITH 或 EXPLAIN 语句。结果行数上限控制加载的行数，每页显示 50 行。查询结果达到 5 MiB 容量上限或运行超过 10 秒时也会停止。取消查询可保持界面响应，下次查询时会重新加载数据库快照。

CSV 和 JSON 导出包含已加载的结果，包括其他分页中的行。JSON 分别保存列名和行数组，以保留重复列名和 NULL 值。SQLite 整数会转换为精确的十进制字符串，BLOB 会转换为包含 `$blob` 十六进制值的对象。CSV 将 NULL 导出为空字段，为特殊字符添加引号，并在类似公式的文本前添加单引号，以便更安全地在电子表格中使用。

## 支持的数据库与限制

可打开最大 50 MiB 的未加密 `.db`、`.sqlite` 或 `.sqlite3` 文件。原始文件不会被修改。此工具将快照加载到内存中，因此内存用量可能超过文件大小。不会导入 WAL 和日志附属文件；请先使用数据库应用创建已完成检查点操作的干净副本，再在此处打开。不支持加密数据库、自定义 SQLite 扩展和数据库编辑。
