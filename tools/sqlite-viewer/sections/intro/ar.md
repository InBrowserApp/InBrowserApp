## فحص ملفات SQLite محليًا

افتح قاعدة بيانات SQLite 3 لتصفّح جداولها وعروضها، وفحص تعريفات الأعمدة والفهارس والمفاتيح الخارجية وعبارات CREATE، أو لتنفيذ استعلام SQL للقراءة فقط. جرّب قاعدة البيانات النموذجية لاستكشاف مساحة العمل دون اختيار ملف. تبقى الملفات والاستعلامات في متصفحك ولا تُحفظ تلقائيًا.

## الاستعلام وتصدير النتائج

اختر جدولًا لمعاينة صفوفه. عدّل SQL واستخدم **تنفيذ الاستعلام** أو **Ctrl/⌘ + Enter** لتنفيذ عبارة SELECT أو WITH أو EXPLAIN واحدة. يحدّ حد النتائج من عدد الصفوف المحمّلة؛ وتعرض كل صفحة 50 صفًا. قد يتوقف الاستعلام أيضًا عند بلوغ ميزانية النتائج البالغة 5 MiB أو بعد 10 ثوانٍ. يُبقي الإلغاء الواجهة مستجيبة ويعيد تحميل لقطة قاعدة البيانات عند تنفيذ الاستعلام التالي.

تتضمن صادرات CSV وJSON النتيجة المحمّلة، بما في ذلك الصفوف الموجودة في الصفحات الأخرى. يخزّن JSON أسماء الأعمدة ومصفوفات الصفوف بشكل منفصل، مع الحفاظ على الأسماء المكررة وقيم NULL. تتحول الأعداد الصحيحة في SQLite إلى سلاسل عشرية دقيقة، وتتحول BLOBs إلى كائنات تحتوي على قيمة `$blob` سداسية عشرية. يستخدم CSV حقولًا فارغة لقيم NULL، ويضع علامات اقتباس حول المحارف الخاصة، ويضيف فاصلة علوية قبل النصوص الشبيهة بالصيغ لاستخدام أكثر أمانًا في جداول البيانات.

## قواعد البيانات المدعومة والحدود

افتح ملفًا غير مشفّر بامتداد `.db` أو `.sqlite` أو `.sqlite3` بحجم يصل إلى 50 MiB. لا يُعدّل الملف الأصلي أبدًا. تحمّل هذه الأداة لقطة في الذاكرة، لذا قد يتجاوز استهلاك الذاكرة حجم الملف. لا تُستورد ملفات WAL وjournal المرافقة؛ أنشئ نسخة سليمة أُجريت لها نقطة تحقق باستخدام تطبيق قاعدة البيانات قبل فتحها هنا. قواعد البيانات المشفّرة وإضافات SQLite المخصّصة وتحرير قواعد البيانات غير مدعومة.
