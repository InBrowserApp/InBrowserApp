## استكشاف قواعد بيانات SQLite في متصفحك

افتح قاعدة بيانات SQLite 3 لتصفّح الجداول والعروض، وفحص الأعمدة والفهارس والمفاتيح الخارجية وعبارات CREATE، أو لتنفيذ استعلام SQL للقراءة فقط. جرّب قاعدة البيانات النموذجية لاستكشاف مساحة العمل. يُعالَج ملفك محليًا ولا يُعدّل أبدًا.

## الاستعلام وتصدير النتائج

اختر جدولًا أو عرضًا لتحميل صفوفه، ثم عدّل SQL لتصفية البيانات أو ترتيبها أو ربطها. نفّذ عبارة SELECT أو WITH أو EXPLAIN واحدة باستخدام **تنفيذ الاستعلام** أو **Ctrl/⌘ + Enter**. انقر على خلية لفحص قيمتها الكاملة ونسخها.

اختر حدًا للنتائج يبلغ 100 أو 1,000 أو 10,000 صف، وتصفّح النتيجة بمقدار 50 صفًا في كل صفحة. للاستعلامات حد زمني يبلغ 10 ثوانٍ وحد لحجم النتائج يبلغ 5 MiB. تشمل صادرات CSV وJSON جميع الصفوف المحمّلة عبر كل الصفحات.

يستخدم JSON أسماء أعمدة ومصفوفات صفوف منفصلة للحفاظ على الأسماء المكررة وقيم NULL. تُمثّل الأعداد الصحيحة كسلاسل عشرية دقيقة، وتحتوي BLOBs على قيمة `$blob` سداسية عشرية. يتضمن CSV صف عناوين، ويستخدم حقولًا فارغة لقيم NULL، ويضيف فاصلة علوية قبل النصوص الشبيهة بالصيغ.

## ملفات SQLite المدعومة

افتح ملفًا غير مشفّر بامتداد `.db` أو `.sqlite` أو `.sqlite3` بحجم يصل إلى 50 MiB. إذا كانت قاعدة البيانات تستخدم WAL، فأنشئ نسخة أُجريت لها نقطة تحقق قبل فتحها؛ لا تُحمّل ملفات WAL وjournal المرافقة. إضافات SQLite المخصّصة غير مدعومة. لا تُحفظ الملفات والاستعلامات تلقائيًا.
