## בדיקת קובצי SQLite באופן מקומי

ניתן לפתוח מסד נתונים של SQLite 3 כדי לעיין בטבלאות ובתצוגות שלו, לבדוק הגדרות עמודות, אינדקסים, מפתחות זרים ופקודות CREATE, או להריץ שאילתת SQL לקריאה בלבד. אפשר לנסות את מסד הנתונים לדוגמה כדי להכיר את סביבת העבודה בלי לבחור קובץ. הקבצים והשאילתות נשארים בדפדפן שלך ואינם נשמרים אוטומטית.

## שאילתות וייצוא תוצאות

יש לבחור טבלה כדי להציג את השורות שלה. ניתן לערוך את ה־SQL ולהשתמש ב־**הרצת שאילתה** או ב־**Ctrl/⌘ + Enter** כדי להריץ פקודת SELECT, WITH או EXPLAIN אחת. מגבלת התוצאות קובעת את מספר השורות שייטענו; בכל עמוד מוצגות 50 שורות. שאילתה עשויה להיעצר גם בהגעה לתקציב תוצאות של 5 MiB או לאחר 10 שניות. ביטול מאפשר לממשק להמשיך להגיב וטוען מחדש את תמונת המצב של מסד הנתונים בשאילתה הבאה.

ייצוא ל־CSV או ל־JSON כולל את התוצאות שנטענו, לרבות שורות בעמודים אחרים. JSON שומר את שמות העמודות ואת מערכי השורות בנפרד, וכך משמר שמות כפולים וערכי NULL. מספרים שלמים של SQLite הופכים למחרוזות עשרוניות מדויקות, וערכי BLOB הופכים לאובייקטים עם ערך הקסדצימלי בשדה `$blob`. CSV משתמש בשדות ריקים עבור NULL, מקיף תווים מיוחדים במירכאות ומוסיף גרש לפני טקסט שנראה כמו נוסחה, לשימוש בטוח יותר בגיליונות אלקטרוניים.

## מסדי נתונים נתמכים ומגבלות

ניתן לפתוח קובץ `.db`, `.sqlite` או `.sqlite3` לא מוצפן בגודל של עד 50 MiB. הקובץ המקורי לעולם אינו משתנה. הכלי טוען תמונת מצב בזיכרון, ולכן השימוש בזיכרון עשוי לחרוג מגודל הקובץ. קובצי WAL ו־journal נלווים אינם מיובאים; יש ליצור עותק נקי לאחר ביצוע checkpoint ביישום מסד הנתונים לפני פתיחתו כאן. אין תמיכה במסדי נתונים מוצפנים, בהרחבות SQLite מותאמות אישית או בעריכת מסד הנתונים.
