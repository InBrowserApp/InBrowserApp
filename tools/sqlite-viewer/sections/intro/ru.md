## Изучайте файлы SQLite локально

Откройте базу данных SQLite 3, чтобы просматривать её таблицы и представления, изучать определения столбцов, индексы, внешние ключи и инструкции CREATE или выполнять SQL-запросы только для чтения. Попробуйте пример базы данных, чтобы изучить рабочую область без выбора файла. Файлы и запросы остаются в браузере и не сохраняются автоматически.

## Выполняйте запросы и экспортируйте результаты

Выберите таблицу для предварительного просмотра строк. Измените SQL и нажмите **Выполнить запрос** или **Ctrl/⌘ + Enter**, чтобы выполнить одну инструкцию SELECT, WITH или EXPLAIN. Лимит результатов ограничивает число загружаемых строк; на странице отображается по 50 строк. Запрос также может остановиться при достижении лимита результатов в 5 МиБ или через 10 секунд. Отмена сохраняет отзывчивость интерфейса и перезагружает снимок базы данных при следующем запросе.

Экспорт CSV и JSON содержит загруженный результат, включая строки с других страниц. JSON хранит имена столбцов и массивы строк отдельно, сохраняя повторяющиеся имена и значения NULL. Целые числа SQLite становятся точными десятичными строками, а BLOB — объектами с шестнадцатеричным значением `$blob`. CSV использует пустые поля для NULL, заключает специальные символы в кавычки и добавляет апостроф перед текстом, похожим на формулу, для более безопасного использования в электронных таблицах.

## Поддерживаемые базы данных и ограничения

Откройте незашифрованный файл `.db`, `.sqlite` или `.sqlite3` размером до 50 МиБ. Исходный файл никогда не изменяется. Инструмент загружает снимок в память, поэтому расход памяти может превышать размер файла. Сопутствующие файлы WAL и journal не импортируются; перед открытием здесь создайте чистую копию после выполнения контрольной точки в своём приложении для работы с базами данных. Зашифрованные базы данных, пользовательские расширения SQLite и редактирование баз данных не поддерживаются.
