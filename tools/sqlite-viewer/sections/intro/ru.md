## Изучайте базы данных SQLite в браузере

Откройте базу данных SQLite 3, чтобы просматривать таблицы и представления, изучать столбцы, индексы, внешние ключи и инструкции CREATE или выполнять SQL-запросы только для чтения. Попробуйте пример базы данных, чтобы изучить рабочую область. Ваш файл обрабатывается локально и никогда не изменяется.

## Выполняйте запросы и экспортируйте результаты

Выберите таблицу или представление, чтобы загрузить строки, затем измените SQL для фильтрации, сортировки или объединения данных. Выполните одну инструкцию SELECT, WITH или EXPLAIN с помощью **Выполнить запрос** или **Ctrl/⌘ + Enter**. Нажмите ячейку, чтобы просмотреть и скопировать её полное значение.

Выберите лимит результатов в 100, 1 000 или 10 000 строк и просматривайте результат по 50 строк на странице. Для запросов действуют ограничения: 10 секунд и 5 МиБ на размер результата. Экспорт CSV и JSON включает все загруженные строки со всех страниц.

JSON хранит имена столбцов и массивы строк отдельно, сохраняя повторяющиеся имена и значения NULL. Целые числа представлены точными десятичными строками, а BLOB содержат шестнадцатеричное значение `$blob`. CSV включает строку заголовков, использует пустые поля для NULL и добавляет апостроф перед текстом, похожим на формулу.

## Поддерживаемые файлы SQLite

Откройте незашифрованный файл `.db`, `.sqlite` или `.sqlite3` размером до 50 МиБ. Если база данных использует WAL, перед открытием создайте копию после выполнения контрольной точки; сопутствующие файлы WAL и journal не загружаются. Пользовательские расширения SQLite не поддерживаются. Файлы и запросы не сохраняются автоматически.
