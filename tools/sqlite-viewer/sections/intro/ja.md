## SQLite ファイルをローカルで確認

SQLite 3 データベースを開いてテーブルやビューを閲覧し、列の定義、インデックス、外部キー、CREATE 文を確認したり、読み取り専用 SQL クエリを実行したりできます。ファイルを選択せずにサンプルデータベースでワークスペースを試すこともできます。ファイルとクエリはブラウザー内に留まり、自動保存されません。

## クエリと結果のエクスポート

テーブルを選択すると行をプレビューできます。SQL を編集し、**クエリを実行**または **Ctrl/⌘ + Enter** で SELECT、WITH、EXPLAIN 文を 1 つ実行します。結果の行数上限によって読み込む行数を制限し、1 ページに 50 行ずつ表示します。結果が 5 MiB の容量上限に達した場合や、10 秒を超えた場合もクエリは停止します。キャンセルしても画面の操作は継続でき、次のクエリ実行時にデータベースのスナップショットを再読み込みします。

CSV と JSON のエクスポートには、他のページの行を含む読み込み済みの結果が入ります。JSON は列名と行配列を別々に保存することで、重複する列名と NULL 値を保持します。SQLite の整数は正確な 10 進数の文字列に、BLOB は `$blob` に 16 進数の値を持つオブジェクトに変換されます。CSV では NULL を空欄にし、特殊文字を引用符で囲み、数式のようなテキストの先頭にアポストロフィを付けて、表計算ソフトでより安全に扱えるようにします。

## 対応するデータベースと制限

暗号化されていない、最大 50 MiB の `.db`、`.sqlite`、`.sqlite3` ファイルを開けます。元のファイルは変更しません。このツールはメモリー上にスナップショットを読み込むため、メモリー使用量がファイルサイズを上回る場合があります。WAL やジャーナルの付随ファイルは取り込まれません。データベースアプリでチェックポイント処理済みのクリーンなコピーを作成してから開いてください。暗号化されたデータベース、独自の SQLite 拡張機能、データベースの編集には対応していません。
