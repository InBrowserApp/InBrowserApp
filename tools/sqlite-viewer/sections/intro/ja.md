## ブラウザーで SQLite データベースを探索

SQLite 3 データベースを開いてテーブルやビューを閲覧し、列、インデックス、外部キー、CREATE 文を確認したり、読み取り専用 SQL クエリを実行したりできます。サンプルデータベースでワークスペースを試すこともできます。ファイルはローカルで処理され、元のファイルは変更されません。

## クエリと結果のエクスポート

テーブルやビューを選択して行を読み込んだら、SQL を編集してデータを絞り込み、並べ替え、結合できます。**クエリを実行**または **Ctrl/⌘ + Enter** で SELECT、WITH、EXPLAIN 文を 1 つ実行します。セルをクリックすると、値全体の確認とコピーができます。

結果の行数上限は 100、1,000、10,000 行から選択でき、1 ページに 50 行ずつ表示します。クエリの実行時間は最大 10 秒、結果のサイズは最大 5 MiB です。CSV と JSON のエクスポートには、全ページの読み込み済みの行が含まれます。

JSON は列名と行配列を別々に保存することで、重複する列名と NULL 値を保持します。整数は正確な 10 進数の文字列で表し、BLOB には `$blob` の 16 進数値が含まれます。CSV にはヘッダー行が含まれ、NULL は空欄になり、数式のようなテキストの先頭にはアポストロフィが付きます。

## 対応する SQLite ファイル

暗号化されていない、最大 50 MiB の `.db`、`.sqlite`、`.sqlite3` ファイルを開けます。WAL を使用するデータベースでは、チェックポイント処理済みのコピーを作成してから開いてください。WAL やジャーナルの付随ファイルは読み込まれません。独自の SQLite 拡張機能には対応していません。ファイルとクエリは自動保存されません。
