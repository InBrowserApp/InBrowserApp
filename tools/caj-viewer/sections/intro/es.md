## Lee artículos de forma local

Abre un documento CAJ, KDH o NH de tu dispositivo. Las páginas se preparan en tu navegador; tu artículo no se sube ni se guarda automáticamente. Puedes cambiar o cerrar un documento mientras se está abriendo.

## Navega por el documento

Usa el número de página, los controles de página anterior y siguiente o la vista de páginas para recorrer un artículo. Esta vista incluye miniaturas y un índice cuando están disponibles. Ajusta la página o su ancho, cambia el zoom, gira las páginas o activa el modo lectura para tener más espacio.

Busca y selecciona texto donde haya texto real en el documento. Las páginas escaneadas siguen siendo imágenes: este visor no realiza OCR. Puedes usar el teclado para acceder al área de lectura con el tabulador, usar los controles de página y pulsar Escape para cerrar la vista de páginas, la búsqueda o el modo lectura.

## Compatibilidad de formatos

La extensión del archivo no identifica todas las variantes internas. Se admiten los documentos CAJ que contienen objetos de página PDF y los documentos KDH que contienen contenido PDF. La compatibilidad con documentos HN-A basados en imágenes, incluidos los archivos NH con contenido HN-A, y con páginas de imágenes C8 es experimental. Compara las ecuaciones, tablas y diagramas importantes con el original. Puede que algunas entradas del índice no estén disponibles o se ajusten.

Las páginas de texto nativo HN-B y C8 que requieren fuentes externas no se pueden mostrar aquí. Se ofrece una explicación en el caso de documentos protegidos, variantes TEB, páginas dañadas y contenido no compatible. Los archivos de referencia CAA no contienen páginas legibles de artículos; nunca se descargan los documentos a los que apuntan. La extracción de texto y la fidelidad visual dependen del documento original y de su variante interna.

## Privacidad y documentos grandes

El contenido del documento se procesa de forma local. Descargar PDF guarda el documento preparado con el texto y los marcadores disponibles. El zoom y la rotación de la vista previa no modifican el PDF descargado. No se usan cuentas ni recursos remotos del documento, y no hay edición ni OCR. No hay un límite fijo de tamaño de archivo ni de número de páginas. Los archivos muy exigentes pueden superar los límites de memoria o de representación gráfica del navegador; al cerrar el documento se liberan los recursos usados para leerlo.
