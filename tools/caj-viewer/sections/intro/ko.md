## 로컬에서 논문 읽기

기기에서 CAJ, KDH 또는 NH 문서를 여세요. 페이지는 브라우저 안에서 준비되며, 논문은 업로드되거나 자동으로 저장되지 않습니다. 문서를 여는 중에도 다른 문서로 바꾸거나 닫을 수 있습니다.

## 문서 탐색

페이지 번호, 이전·다음 버튼 또는 페이지 개요로 논문을 탐색하세요. 개요에는 페이지 미리보기와, 제공되는 경우 목차가 표시됩니다. 페이지 전체나 너비에 맞추고, 배율을 조절하거나 페이지를 회전할 수 있으며, 집중 읽기로 더 넓은 공간을 활용할 수 있습니다.

실제 문서 텍스트가 있는 부분에서는 검색과 텍스트 선택이 가능합니다. 스캔한 페이지는 이미지로 유지되며, 이 뷰어는 OCR을 수행하지 않습니다. 키보드 사용자는 Tab 키로 읽기 영역에 진입하고 페이지 이동 버튼을 사용할 수 있습니다. Escape 키를 누르면 열린 개요, 검색 또는 집중 모드를 종료합니다.

## 형식 호환성

파일 확장자만으로 모든 내부 세부 형식을 구분할 수는 없습니다. PDF 페이지 객체가 포함된 CAJ 문서와 PDF 콘텐츠가 포함된 KDH 문서를 지원합니다. HN-A 콘텐츠가 포함된 NH 파일을 비롯한 이미지 기반 HN-A 문서와 C8 이미지 페이지는 실험적으로 지원합니다. 중요한 수식, 표, 도표는 원본과 대조하세요. 일부 목차 항목은 표시되지 않거나 조정될 수 있습니다.

별도 글꼴이 필요한 네이티브 HN-B 및 C8 텍스트 페이지는 여기서 표시할 수 없습니다. 보호된 문서, TEB 세부 형식, 손상된 페이지, 지원하지 않는 콘텐츠에는 안내 메시지가 표시됩니다. CAA 참조 파일에는 읽을 수 있는 논문 페이지가 없으며, 참조 대상은 가져오지 않습니다. 텍스트 추출 결과와 원본 재현도는 원본 문서와 내부 세부 형식에 따라 달라집니다.

## 개인정보 보호와 대용량 문서

문서 내용은 로컬에서 처리됩니다. 계정이나 원격 문서 리소스는 사용하지 않으며, 편집, PDF 다운로드, OCR 기능은 제공하지 않습니다. 파일 크기나 페이지 수에 정해진 제한은 없습니다. 리소스를 많이 요구하는 파일은 브라우저의 메모리 또는 그리기 한도를 초과할 수 있습니다. 문서를 닫으면 읽기에 사용한 리소스가 해제됩니다.
