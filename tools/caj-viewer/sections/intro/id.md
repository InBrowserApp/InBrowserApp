## Baca makalah secara lokal

Buka dokumen CAJ, KDH, atau NH dari perangkat Anda. Halaman disiapkan di dalam browser; makalah Anda tidak diunggah atau disimpan secara otomatis. Anda dapat mengganti atau menutup dokumen saat proses pembukaan berlangsung.

## Navigasi dokumen

Gunakan nomor halaman, kontrol sebelumnya dan berikutnya, atau ikhtisar halaman untuk menelusuri makalah. Ikhtisar berisi gambar mini dan daftar isi jika tersedia. Sesuaikan halaman atau lebarnya, atur zoom, putar halaman, atau gunakan fokus membaca untuk mendapat lebih banyak ruang.

Cari dan pilih teks jika dokumen memiliki teks asli. Halaman pindaian tetap berupa gambar: penampil ini tidak melakukan OCR. Pengguna keyboard dapat menekan Tab untuk masuk ke area baca, menggunakan kontrol halaman, dan menekan Escape untuk keluar dari ikhtisar, pencarian, atau mode fokus yang terbuka.

## Kompatibilitas format

Ekstensi file tidak mengidentifikasi semua varian internal. Dokumen CAJ yang berisi objek halaman PDF dan dokumen KDH yang berisi konten PDF didukung. Dukungan untuk dokumen HN-A berbasis gambar, termasuk file NH dengan konten HN-A, serta halaman gambar C8 masih eksperimental. Bandingkan persamaan, tabel, dan diagram penting dengan aslinya. Beberapa entri daftar isi mungkin tidak tersedia atau telah disesuaikan.

Halaman teks asli HN-B dan C8 yang membutuhkan font terpisah tidak dapat ditampilkan di sini. Dokumen yang dilindungi, varian TEB, halaman rusak, dan konten yang tidak didukung akan disertai penjelasan. File rujukan CAA tidak berisi halaman makalah yang dapat dibaca; dokumen yang dirujuk tidak pernah diambil. Ekstraksi teks dan kesesuaian tampilan bergantung pada dokumen asli dan varian internalnya.

## Privasi dan dokumen besar

Isi dokumen diproses secara lokal. Tidak diperlukan akun, dan tidak melibatkan sumber daya dokumen jarak jauh, penyuntingan, unduhan PDF, atau OCR. Tidak ada batas tetap untuk ukuran file atau jumlah halaman. File yang sangat berat tetap dapat melampaui batas memori atau penggambaran browser; menutup dokumen akan melepaskan sumber daya baca yang digunakannya.
