## 將工作表匯出為通用格式

開啟本機 .xlsx、.xlsm、.xltx 或 .xltm 檔案，或將檔案拖放到匯出工具中。依原始名稱選擇工作表，包括隱藏的工作表，再選擇 CSV、TSV、JSON 或 Markdown。預覽輸出、複製內容，或下載以活頁簿與工作表名稱命名的 UTF-8 檔案。更換或關閉檔案會取消尚未完成的處理，並清除先前可下載的結果。試算表檢視器也提供「匯出工作表」功能，可匯出目前的工作表。

預設儲存格範圍是包含已儲存的值或公式的最小矩形。該矩形內的空白儲存格與空白列會保留在輸出中。您可以輸入其他範圍，例如 A1:D20，然後選擇「套用範圍」。除非您明確指定範圍，否則空白工作表會產生空白文字檔或空的 JSON 陣列。

## 選擇值與標題列的呈現方式

格式化文字會遵循支援的數字格式，並在可用時保留日期的顯示方式與開頭含零的數字格式。依地區設定而異的格式可能與 Excel 不同。已儲存的值會保留數字與布林值；日期仍為 Excel 日期序號，不會附加時區。兩種模式都會保留文字儲存格的文字。公式使用已儲存的結果，不會重新計算。缺少已儲存結果的儲存格會變成空白，介面中會顯示提醒。試算表錯誤仍以可讀字串呈現，例如 #DIV/0!。

CSV 與 TSV 會以引號包住含分隔符號、引號或換行的欄位。JSON 是由各列陣列組成的陣列：第一列會保留為資料，重複或空白的標題不會成為物件鍵，空白儲存格使用 null。Markdown 可將第一列作為標題列，或在所有資料列上方加入空白標題列。Markdown 標點符號、HTML、直線符號與儲存格內的換行會進行跳脫處理或以安全方式呈現。下載檔案使用不含位元組順序標記的 UTF-8；匯入其他應用程式時，請選擇 UTF-8。

## 本機處理與相容性

您的活頁簿會留在此瀏覽器中，本工具不會上傳或儲存活頁簿。不會執行或重新整理巨集、指令碼與外部資料連線。選取範圍內的隱藏列與欄也會包含在內。不會將合併儲存格展開為重複的值。圖表、圖片、註解與活頁簿樣式不屬於這些文字格式的內容。

加密、損毀或不支援的活頁簿會顯示明確的錯誤訊息。檔案大小、工作表數量、列數與欄數沒有固定上限，但大量匯出可能超過瀏覽器的記憶體容量。此工具匯出的是已儲存的資料；不會編輯活頁簿，也不保證其他試算表應用程式會以相同方式解讀純文字欄位。
