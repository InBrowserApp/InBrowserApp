## ส่งออกเวิร์กชีตเป็นรูปแบบที่นำไปใช้ต่อได้

เปิดไฟล์ .xlsx, .xlsm, .xltx หรือ .xltm จากเครื่อง หรือวางไฟล์ลงในโปรแกรมส่งออก เลือกเวิร์กชีตตามชื่อเดิม รวมถึงเวิร์กชีตที่ซ่อนอยู่ แล้วเลือก CSV, TSV, JSON หรือ Markdown ดูตัวอย่างผลลัพธ์ คัดลอก หรือดาวน์โหลดไฟล์ UTF-8 ที่ตั้งชื่อตามเวิร์กบุ๊กและเวิร์กชีต การเปลี่ยนหรือปิดไฟล์จะยกเลิกงานที่ยังไม่เสร็จและลบผลลัพธ์ก่อนหน้าที่พร้อมให้ดาวน์โหลด โปรแกรมดูสเปรดชีตยังมีคำสั่งส่งออกเวิร์กชีตสำหรับชีตปัจจุบันด้วย

ช่วงเซลล์เริ่มต้นคือสี่เหลี่ยมผืนผ้าขนาดเล็กที่สุดที่ครอบคลุมค่าที่บันทึกไว้หรือสูตร เซลล์และแถวว่างภายในสี่เหลี่ยมนั้นจะยังอยู่ในผลลัพธ์ คุณสามารถป้อนช่วงอื่น เช่น A1:D20 แล้วเลือกใช้ช่วงที่ระบุ เวิร์กชีตที่ว่างจะให้ไฟล์ข้อความว่างหรืออาร์เรย์ JSON ว่าง เว้นแต่คุณจะเลือกช่วงเองอย่างชัดเจน

## เลือกวิธีแสดงค่าและหัวตาราง

ข้อความที่จัดรูปแบบจะใช้รูปแบบตัวเลขที่รองรับ โดยคงการแสดงวันที่และรูปแบบตัวเลขที่มีเลขศูนย์นำหน้าไว้เมื่อทำได้ รูปแบบที่ขึ้นอยู่กับการตั้งค่าภูมิภาคอาจต่างจาก Excel ค่าที่จัดเก็บไว้จะคงตัวเลขและค่าบูลีนไว้ โดยวันที่ยังเป็นเลขลำดับของ Excel แทนการกำหนดเขตเวลา เซลล์ข้อความจะเก็บข้อความเดิมไว้ในทั้งสองโหมด สูตรจะใช้ผลลัพธ์ที่บันทึกไว้โดยไม่คำนวณใหม่ หากไม่มีผลลัพธ์ที่บันทึกไว้ เซลล์จะว่างและมีข้อความแจ้งในหน้าจอ ข้อผิดพลาดของสเปรดชีตยังคงเป็นข้อความที่อ่านได้ เช่น #DIV/0!

CSV และ TSV จะครอบฟิลด์ที่มีตัวคั่น เครื่องหมายอัญประกาศ หรือการขึ้นบรรทัดใหม่ด้วยเครื่องหมายอัญประกาศ JSON เป็นอาร์เรย์ที่มีอาร์เรย์ย่อยสำหรับแต่ละแถว โดยแถวแรกยังเป็นข้อมูล หัวตารางที่ซ้ำหรือว่างจะไม่กลายเป็นคีย์ของออบเจ็กต์ และเซลล์ว่างจะใช้ null Markdown สามารถใช้แถวแรกเป็นแถวหัวตาราง หรือเพิ่มแถวหัวตารางว่างเหนือแถวข้อมูลทั้งหมดได้ เครื่องหมายวรรคตอนของ Markdown, HTML, ขีดตั้ง และการขึ้นบรรทัดใหม่ในเซลล์จะถูกเอสเคปหรือแสดงในรูปแบบที่ปลอดภัย ไฟล์ที่ดาวน์โหลดใช้ UTF-8 โดยไม่มีเครื่องหมายลำดับไบต์ โปรดเลือก UTF-8 เมื่อนำเข้าในแอปพลิเคชันอื่น

## การประมวลผลในเครื่องและความเข้ากันได้

เวิร์กบุ๊กของคุณอยู่ในเบราว์เซอร์นี้ โดยเครื่องมือจะไม่อัปโหลดหรือบันทึกไฟล์ ไม่มีการเรียกใช้แมโครหรือสคริปต์ และไม่รีเฟรชการเชื่อมต่อข้อมูลภายนอก แถวและคอลัมน์ที่ซ่อนอยู่จะรวมอยู่ในช่วงที่เลือกด้วย เซลล์ที่ผสานจะไม่ถูกขยายเพื่อใส่ค่าซ้ำ แผนภูมิ รูปภาพ ความคิดเห็น และการจัดรูปแบบของเวิร์กบุ๊กไม่รวมอยู่ในรูปแบบข้อความเหล่านี้

เวิร์กบุ๊กที่เข้ารหัส เสียหาย หรือไม่รองรับจะแสดงข้อความผิดพลาดที่ชัดเจน ไม่มีการกำหนดขีดจำกัดตายตัวสำหรับขนาดไฟล์ จำนวนเวิร์กชีต แถว หรือคอลัมน์ แต่การส่งออกข้อมูลจำนวนมากอาจใช้หน่วยความจำเกินกว่าที่เบราว์เซอร์มีให้ เครื่องมือนี้ส่งออกข้อมูลที่บันทึกไว้ โดยไม่แก้ไขเวิร์กบุ๊กหรือรับประกันว่าแอปพลิเคชันสเปรดชีตอื่นจะตีความฟิลด์ข้อความล้วนในลักษณะเดียวกัน
