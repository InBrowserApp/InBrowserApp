## 워크시트를 다른 곳에서 사용할 수 있는 형식으로 내보내기

기기에 있는 .xlsx, .xlsm, .xltx 또는 .xltm 파일을 열거나 내보내기 도구에 끌어다 놓으세요. 숨겨진 워크시트를 포함하여 원래 이름으로 워크시트를 선택한 다음 CSV, TSV, JSON 또는 Markdown을 선택하세요. 결과를 미리 보고 복사하거나 통합 문서와 워크시트 이름으로 된 UTF-8 파일을 다운로드할 수 있습니다. 파일을 바꾸거나 닫으면 진행 중인 작업이 취소되고 이전 다운로드 항목이 삭제됩니다. 스프레드시트 뷰어에서도 워크시트 내보내기를 사용하여 현재 시트를 내보낼 수 있습니다.

기본 셀 범위는 저장된 값이나 수식을 포함하는 가장 작은 직사각형입니다. 이 직사각형 안의 빈 셀과 행은 결과에 그대로 유지됩니다. A1:D20과 같은 다른 범위를 입력하고 범위 적용을 선택할 수 있습니다. 범위를 직접 지정하지 않은 경우 빈 시트는 빈 텍스트 파일이나 빈 JSON 배열로 내보내집니다.

## 값과 머리글의 표현 방식 선택하기

서식이 적용된 텍스트는 지원되는 숫자 서식을 따르며, 가능한 경우 표시된 날짜와 앞자리에 0이 있는 숫자 서식을 유지합니다. 지역에 따라 달라지는 서식은 Excel과 다를 수 있습니다. 저장된 값은 숫자와 불리언을 유지하며 날짜는 시간대가 적용되지 않고 Excel 일련번호로 유지됩니다. 텍스트 셀은 어느 모드에서도 텍스트가 유지됩니다. 수식은 다시 계산하지 않고 저장된 계산 결과를 사용합니다. 저장된 계산 결과가 없으면 빈 셀이 되며 화면에 안내가 표시됩니다. 스프레드시트 오류는 #DIV/0!와 같이 읽을 수 있는 문자열로 유지됩니다.

CSV와 TSV는 구분 기호, 따옴표 또는 줄바꿈이 포함된 필드를 따옴표로 감쌉니다. JSON은 각 행이 배열인 배열입니다. 첫 행도 데이터에 포함되며 중복되거나 비어 있는 머리글은 객체 키가 되지 않고 빈 셀은 null을 사용합니다. Markdown은 첫 행을 표 머리글로 사용하거나 모든 데이터 행 위에 빈 머리글을 추가할 수 있습니다. Markdown 문장 부호, HTML, 세로줄, 셀 안의 줄바꿈은 이스케이프 처리하거나 안전하게 표현합니다. 다운로드 파일은 바이트 순서 표시 없이 UTF-8을 사용합니다. 다른 애플리케이션으로 가져올 때 UTF-8을 선택하세요.

## 기기 내 처리 및 호환성

통합 문서는 이 브라우저 안에만 머무르며 이 도구가 업로드하거나 저장하지 않습니다. 매크로와 스크립트를 실행하거나 외부 데이터 연결을 새로 고치지 않습니다. 선택한 범위에 있는 숨겨진 행과 열도 포함됩니다. 병합된 셀은 값을 반복하여 확장하지 않습니다. 차트, 이미지, 메모, 통합 문서 스타일은 이러한 텍스트 형식에 포함되지 않습니다.

암호화되거나 손상되었거나 지원되지 않는 통합 문서에는 명확한 오류가 표시됩니다. 파일 크기, 워크시트 수, 행 수, 열 수에 고정된 제한은 없지만 큰 데이터를 내보내면 브라우저의 메모리 한계를 초과할 수 있습니다. 이 도구는 저장된 데이터를 내보내며 통합 문서를 편집하지 않습니다. 다른 스프레드시트 애플리케이션이 일반 텍스트 필드를 동일하게 해석한다고 보장하지 않습니다.
