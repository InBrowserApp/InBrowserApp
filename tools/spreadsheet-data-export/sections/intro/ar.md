## تصدير ورقة عمل إلى صيغة قابلة للنقل

افتح ملف .xlsx أو .xlsm أو .xltx أو .xltm محليًا أو أفلته في أداة التصدير. اختر ورقة عمل باسمها الأصلي، بما فيها أوراق العمل المخفية، وحدد CSV أو TSV أو JSON أو Markdown. عاين المخرجات أو انسخها أو نزّل ملفًا بترميز UTF-8 يحمل اسم المصنف وورقة العمل. يؤدي استبدال الملف أو إغلاقه إلى إلغاء العمل غير المكتمل وإزالة التنزيلات السابقة. يوفر عارض جداول البيانات أيضًا خيار تصدير ورقة العمل للورقة الحالية.

نطاق الخلايا الافتراضي هو أصغر مستطيل يحتوي على قيم محفوظة أو صيغ. تبقى الخلايا والصفوف الفارغة داخل هذا المستطيل في المخرجات. يمكنك إدخال نطاق آخر، مثل A1:D20، واختيار تطبيق النطاق. تنتج الورقة الفارغة ملفًا نصيًا فارغًا أو مصفوفة JSON فارغة ما لم تختر نطاقًا صراحةً.

## اختيار طريقة تمثيل القيم والرؤوس

يتبع النص المنسق تنسيقات الأرقام المدعومة، ويحافظ على التواريخ المعروضة وتنسيقات الأرقام ذات الأصفار البادئة عند توفرها. قد تختلف التنسيقات المعتمدة على الإعدادات المحلية عن Excel. تحتفظ القيم المخزنة بالأرقام والقيم المنطقية؛ وتبقى التواريخ أرقام Excel التسلسلية دون إسناد منطقة زمنية إليها. تحتفظ الخلايا النصية بنصها في كلا الوضعين. تستخدم الصيغ نتائجها المحفوظة دون إعادة حساب. تتحول النتيجة المحفوظة المفقودة إلى خلية فارغة، مع إشعار في الواجهة. تظل أخطاء جدول البيانات سلاسل نصية مقروءة مثل #DIV/0!.

تُحاط الحقول التي تحتوي على فواصل أو علامات اقتباس أو فواصل أسطر بعلامات اقتباس في CSV وTSV. يكون JSON مصفوفة من مصفوفات الصفوف: يبقى الصف الأول ضمن البيانات، ولا تتحول الرؤوس المكررة أو الفارغة إلى مفاتيح كائنات، وتستخدم الخلايا الفارغة القيمة null. يمكن أن يعامل Markdown الصف الأول كصف رؤوس أو يضيف صف رؤوس فارغًا فوق جميع صفوف البيانات. تُضاف محارف إفلات إلى رموز Markdown وHTML والخطوط العمودية وفواصل الأسطر داخل الخلايا أو تُمثَّل بطريقة آمنة. تستخدم التنزيلات ترميز UTF-8 دون علامة ترتيب البايتات؛ اختر UTF-8 عند الاستيراد إلى تطبيق آخر.

## المعالجة المحلية والتوافق

يبقى مصنفك في هذا المتصفح ولا ترفعه الأداة أو تحفظه. لا تُنفَّذ وحدات الماكرو أو البرامج النصية، ولا تُشغَّل اتصالات البيانات الخارجية أو تُحدَّث. تُدرج الصفوف والأعمدة المخفية ضمن النطاق المحدد. لا تُوسَّع الخلايا المدمجة إلى قيم مكررة. لا تتضمن هذه الصيغ النصية المخططات أو الصور أو التعليقات أو تنسيقات المصنف.

تظهر رسالة خطأ واضحة للمصنفات المشفرة أو التالفة أو غير المدعومة. لا توجد حدود ثابتة لحجم الملف أو عدد أوراق العمل أو الصفوف أو الأعمدة، لكن التصدير الكبير قد يتجاوز ذاكرة المتصفح. يصدّر هذا الخيار البيانات المحفوظة؛ ولا يعدّل المصنف أو يضمن أن يفسر تطبيق جداول بيانات آخر الحقول النصية بالطريقة نفسها.
