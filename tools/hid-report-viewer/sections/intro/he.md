## איך מחברים התקן HID בדפדפן

חברו התקן ממשק אנושי נתמך, כגון בקר משחק, ג׳ויסטיק, דוושה או מקלדת מאקרו. בחרו **חיבור התקן** ובחרו את ההתקן בחלון הבחירה של WebHID. המציג מראה את מזהי הספק (VID) והמוצר (PID), שמסייעים לזהות את החומרה. השתמשו בדפדפן שולחני תואם דרך HTTPS.

## איך קוראים אוספי HID ומזהי דוחות

פתחו אוסף כדי לראות את דף השימוש, השימוש ומזהי הדוחות שלו. דף השימוש מקבץ פונקציות קשורות, והשימוש מזהה פונקציה בתוך הקבוצה. דוחות קלט מכילים נתונים מההתקן, דוחות פלט מתארים נתונים שהמארח יכול לשלוח, ודוחות תכונות מתארים הגדרות או מצב ייחודיים להתקן. מזהה דוח 0 פירושו שהממשק אינו משתמש במזהה דוח מפורש.

## איך בודקים בתים משתנים בקלט

הפעילו בקר אחד בכל פעם בזמן שאתם צופים בדוחות ההקסדצימליים בזמן אמת. בתים מודגשים שונים מהנתונים הקודמים בעלי אותו מזהה דוח. מזהה הדוח מוצג בנפרד מהנתונים. השהו את האיסוף כדי לבדוק את הדוחות האחרונים, או נקו את הרשימה והתחילו מחדש. עיינו במבנה הדוחות של ההתקן כדי לפרש לחצנים, צירים ושדות אחרים.

## למה ההתקן או האוסף שלי לא מופיע ברשימה?

בדקו שמערכת ההפעלה מזהה את ההתקן ופתחו מחדש את חלון הבחירה. דפדפנים מגנים על אוספים נפוצים של מקלדות ועכברים, וחלק מההתקנים חושפים רק חלק מהדוחות שלהם לאינטרנט. המציג מקבל דוחות קלט מההתקן שנבחר ושומר את הנתונים בכרטיסייה זו. לבדיקת בקרים סטנדרטיים, נסו את [בודק בקר המשחק](../gamepad-tester/) או את [בודק המקלדת](../keyboard-tester/).
