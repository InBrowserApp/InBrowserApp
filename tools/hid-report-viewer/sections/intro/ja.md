## ブラウザーで HID デバイスに接続する方法

ゲームコントローラー、ジョイスティック、ペダル、マクロパッドなど、対応するヒューマンインターフェースデバイスを接続します。**デバイスに接続**を選び、WebHID の選択画面でデバイスを選択します。ビューアーにはハードウェアの識別に役立つベンダー ID（VID）と製品 ID（PID）が表示されます。HTTPS で対応するデスクトップブラウザーを使用してください。

## HID コレクションとレポート ID の読み方

コレクションを開くと、使用法ページ、使用法、レポート ID を確認できます。使用法ページは関連する機能をまとめ、使用法はそのグループ内の機能を識別します。入力レポートはデバイスからのデータを運び、出力レポートはホストが送信できるデータを記述し、Feature レポートはデバイス固有の設定や状態を記述します。レポート ID が 0 の場合、そのインターフェースは明示的なレポート ID を使用しません。

## 変化する入力バイトの調べ方

リアルタイムの16進数レポートを見ながら、操作部を一度に1つずつ動かします。強調表示されたバイトは、同じレポート ID の直前のペイロードから変化したものです。レポート ID はペイロードとは別に表示されます。取得を一時停止して最新のレポートを確認するか、一覧を消去して最初からやり直せます。ボタンや軸などのフィールドを解釈するには、デバイスのレポート形式を調べてください。

## デバイスやコレクションが一覧に表示されない場合は？

オペレーティングシステムがデバイスを認識していることを確認し、選択画面を開き直してください。ブラウザーは一般的なキーボードやマウスのコレクションを保護しており、デバイスによってはレポートの一部しかウェブに公開しません。このビューアーは選択したデバイスから入力レポートを受信し、データをこのタブ内に保持します。標準的な操作部には[ゲームパッドテスター](../gamepad-tester/)や[キーボードテスター](../keyboard-tester/)もお試しください。
