## 如何在浏览器中连接 HID 设备

连接受支持的人机接口设备，例如游戏手柄、操纵杆、踏板或宏键盘。选择**连接设备**，然后在 WebHID 设备选择器中选择设备。查看器会显示厂商 ID（VID）和产品 ID（PID），帮助识别硬件。请通过 HTTPS 使用兼容的桌面浏览器。

## 如何读取 HID 集合和报告 ID

展开集合可查看其用法页、用法和报告 ID。用法页将相关功能归为一组，用法则标识该组中的某个功能。输入报告携带来自设备的数据，输出报告描述主机可发送的数据，功能报告描述设备特定的设置或状态。报告 ID 为 0 表示该接口不使用显式报告 ID。

## 如何检查变化的输入字节

每次操作一个控件，同时观察实时十六进制报告。高亮字节表示它们与相同报告 ID 的上一次有效载荷相比发生了变化。报告 ID 与有效载荷分开显示。可以暂停采集以检查最近的报告，也可以清除列表后重新开始。查阅设备的报告格式，了解如何解读按键、轴和其他字段。

## 为什么设备或集合没有列出？

检查操作系统是否识别设备，然后重新打开设备选择器。浏览器会保护常见的键盘和鼠标集合，而某些设备只向网页提供部分报告。此查看器接收所选设备的输入报告，并将数据保留在当前标签页中。对于标准控件，可以尝试[游戏手柄测试器](../gamepad-tester/)或[键盘测试器](../keyboard-tester/)。
