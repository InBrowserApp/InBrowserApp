## Cara menyambungkan peranti HID dalam pelayar

Sambungkan peranti antara muka manusia yang disokong, seperti pengawal permainan, kayu bedik, pedal atau pad makro. Pilih **Sambungkan peranti** dan pilih peranti dalam pemilih WebHID. Pemapar menunjukkan ID vendor (VID) dan ID produk (PID), yang membantu mengenal pasti perkakasan. Gunakan pelayar desktop yang serasi melalui HTTPS.

## Cara membaca koleksi HID dan ID laporan

Buka koleksi untuk melihat halaman penggunaan, penggunaan dan ID laporannya. Halaman penggunaan mengumpulkan fungsi yang berkaitan, manakala penggunaan mengenal pasti fungsi dalam kumpulan itu. Laporan input membawa data daripada peranti, laporan output menerangkan data yang boleh dihantar oleh hos dan laporan ciri menerangkan tetapan atau keadaan khusus peranti. ID laporan 0 bermakna antara muka itu tidak menggunakan ID laporan yang dinyatakan secara khusus.

## Cara memeriksa perubahan bait input

Gerakkan satu kawalan pada satu masa sambil melihat laporan heks secara langsung. Bait yang diserlahkan berbeza daripada muatan data sebelumnya untuk ID laporan yang sama. ID laporan dipaparkan secara berasingan daripada muatan data. Jeda rakaman untuk memeriksa laporan terkini, atau kosongkan senarai dan mulakan semula. Rujuk format laporan peranti untuk mentafsir butang, paksi dan medan lain.

## Mengapa peranti atau koleksi saya tidak disenaraikan?

Pastikan sistem pengendalian mengenali peranti, kemudian buka semula pemilih. Pelayar melindungi koleksi papan kekunci dan tetikus yang lazim, dan sesetengah peranti hanya menyediakan sebahagian laporan kepada web. Pemapar ini menerima laporan input daripada peranti yang dipilih dan menyimpan data dalam tab ini. Untuk kawalan standard, cuba [Penguji pad permainan](../gamepad-tester/) atau [Penguji papan kekunci](../keyboard-tester/).
