## Что такое подмножество шрифта?

Подмножество шрифта содержит символы, нужные для конкретного текста, а также
вспомогательные глифы, необходимые для их отображения. Удаление неиспользуемых
глифов может значительно уменьшить объём загружаемых шрифтов, особенно крупных
китайских, японских и корейских шрифтов или шрифтов для неизменяемого заголовка,
логотипа либо страницы рекламной кампании.

## Как пользоваться инструментом

Выберите файл TTF, OTF, WOFF или WOFF2 и вставьте весь текст, который будет его
использовать. Выберите WOFF2 для размещения в интернете или TTF / OTF для
получения несжатого шрифта, затем создайте подмножество. Сравните размеры,
проверьте предпросмотр и скачайте шрифт с соответствующим CSS. Обработка шрифта
выполняется локально в Web Worker.

## Что сохраняется?

HarfBuzz сохраняет зависимости глифов и функции вёрстки OpenType, необходимые
для лигатур, кернинга, комбинируемых знаков и сложных систем письма. Хинтинг и
оси вариативного шрифта сохраняются. Канонически эквивалентные составные и
разложенные формы текста включаются, если исходный шрифт их поддерживает.
Предпросмотр использует созданный шрифт, а отсутствующие в исходном шрифте
символы перечисляются отдельно.

## Практические советы

- Укажите пробелы, знаки препинания, цифры и все нужные переведённые строки.
  Добавьте набор латинских символов, если текст также будет содержать базовую
  латиницу.
- Создавайте подмножество заново при каждом изменении текста. Фиксированное
  подмножество лучше подходит для известного содержимого; для пользовательских
  текстов используйте более широкий набор символов.
- Создание подмножества не добавляет символы, отсутствующие в исходном шрифте.
  Укажите запасной шрифт в CSS для символов за пределами подмножества.
- Используйте шрифт, лицензия которого разрешает изменение и встраивание на
  веб-страницы. Коллекции шрифтов (`.ttc` / `.otc`) сначала нужно экспортировать
  в виде отдельных шрифтов.
- Небольшие шрифты или уже созданные подмножества могут не стать меньше. WOFF2
  обычно обеспечивает наименьший объём загрузки для веба; количество глифов
  также включает вспомогательные глифы.
