## ชุดย่อยฟอนต์คืออะไร?

ชุดย่อยฟอนต์ประกอบด้วยอักขระที่ข้อความหนึ่งต้องใช้ รวมทั้งรูปอักษรเสริมที่จำเป็นต่อการแสดงผล การนำรูปอักษรที่ไม่ได้ใช้ออกช่วยลดขนาดไฟล์ฟอนต์ที่ต้องดาวน์โหลดได้มาก โดยเฉพาะฟอนต์ภาษาจีน ญี่ปุ่น และเกาหลีขนาดใหญ่ หรือหัวเรื่อง โลโก้ และหน้าแคมเปญที่มีข้อความตายตัว

## วิธีใช้เครื่องมือนี้

เลือกไฟล์ TTF, OTF, WOFF หรือ WOFF2 แล้ววางข้อความทั้งหมดที่จะใช้ฟอนต์นั้น เลือก WOFF2 สำหรับใช้บนเว็บ หรือ TTF / OTF สำหรับฟอนต์ที่ไม่บีบอัด จากนั้นสร้างชุดย่อย เปรียบเทียบขนาด ตรวจดูตัวอย่าง แล้วดาวน์โหลดฟอนต์และ CSS ที่ตรงกัน การประมวลผลฟอนต์ทำงานภายในอุปกรณ์ด้วย Web Worker

## เก็บอะไรไว้บ้าง?

HarfBuzz เก็บความเชื่อมโยงระหว่างรูปอักษรและคุณสมบัติการจัดวางของ OpenType ที่จำเป็นต่ออักษรควบ การปรับระยะห่างระหว่างคู่ตัวอักษร เครื่องหมายประกอบ และระบบการเขียนที่ซับซ้อน คำสั่งฮินติงและแกนของฟอนต์แปรผันยังคงอยู่ด้วย โดยจะรวมรูปข้อความแบบประกอบและแบบแยกที่สมมูลกันตามกฎการเทียบเท่ามาตรฐาน หากฟอนต์ต้นฉบับรองรับ ตัวอย่างใช้ฟอนต์ที่สร้างขึ้นจริง และแสดงรายการอักขระที่ฟอนต์ต้นฉบับไม่มีแยกต่างหาก

## เคล็ดลับการใช้งาน

- ใส่ช่องว่าง เครื่องหมายวรรคตอน ตัวเลข และข้อความแปลทุกภาษาที่ต้องใช้ หากข้อความมีอักขระละตินพื้นฐานด้วย ให้เพิ่มชุดอักขระละตินสำเร็จรูป
- สร้างชุดย่อยใหม่เมื่อข้อความเปลี่ยน ชุดย่อยแบบตายตัวเหมาะกับเนื้อหาที่ทราบล่วงหน้า สำหรับเนื้อหาจากผู้ใช้ ควรใช้ฟอนต์ที่ครอบคลุมอักขระมากกว่า
- การสร้างชุดย่อยเพิ่มอักขระที่ฟอนต์ต้นฉบับไม่มีไม่ได้ กำหนดฟอนต์สำรองใน CSS สำหรับอักขระนอกชุดย่อยไว้ด้วย
- ใช้ฟอนต์ที่มีสัญญาอนุญาตให้ดัดแปลงและฝังบนเว็บได้ ชุดรวมฟอนต์ (`.ttc` / `.otc`) ต้องส่งออกเป็นฟอนต์เดี่ยวก่อน
- ฟอนต์ขนาดเล็กหรือฟอนต์ที่สร้างเป็นชุดย่อยแล้วอาจไม่เล็กลงอีก โดยทั่วไป WOFF2 ให้ขนาดดาวน์โหลดบนเว็บเล็กที่สุด จำนวนรูปอักษรรวมรูปอักษรเสริมด้วย
