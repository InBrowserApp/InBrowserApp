## 글꼴 서브셋이란?

글꼴 서브셋은 특정 텍스트에 필요한 문자와 해당 문자를 표시하는 데 필요한 보조 글리프를 포함합니다.
사용하지 않는 글리프를 제거하면 글꼴 다운로드 크기를 크게 줄일 수 있습니다.
특히 중국어, 일본어, 한국어의 큰 글꼴이나 고정된 제목, 로고, 캠페인 페이지에 유용합니다.

## 도구 사용 방법

TTF, OTF, WOFF 또는 WOFF2 파일을 선택하고 해당 글꼴로 표시할 모든 텍스트를 붙여넣으세요.
웹 배포에는 WOFF2를, 비압축 글꼴에는 TTF / OTF를 선택한 후 서브셋을 생성하세요.
크기를 비교하고 미리보기를 확인한 다음 글꼴과 해당 CSS를 다운로드하세요.
글꼴 처리는 로컬 Web Worker에서 실행됩니다.

## 유지되는 항목

HarfBuzz는 합자, 커닝, 결합 부호, 복잡한 문자 체계에 필요한 글리프 의존성과
OpenType 레이아웃 기능을 유지합니다. 힌팅과 가변 글꼴 축도 유지됩니다.
원본 글꼴이 지원하는 경우 정규적으로 동등한 조합형과 분해형 텍스트를 모두 포함합니다.
미리보기에는 생성된 글꼴을 사용하며, 원본에 없는 문자는 별도로 표시합니다.

## 활용 팁

- 공백, 문장 부호, 숫자, 필요한 모든 번역 문자열을 포함하세요.
  기본 라틴 문자도 사용할 경우 라틴 문자 프리셋을 추가하세요.
- 텍스트가 변경될 때마다 서브셋을 다시 생성하세요. 고정된 서브셋은 내용이 정해진 경우에 적합합니다.
  사용자가 입력하는 텍스트에는 더 넓은 문자 범위를 사용하세요.
- 서브셋으로 원본 글꼴에 없는 문자를 추가할 수는 없습니다.
  서브셋 밖의 문자를 위해 CSS 대체 글꼴을 지정하세요.
- 수정과 웹 임베딩을 허용하는 라이선스의 글꼴을 사용하세요.
  글꼴 컬렉션(`.ttc` / `.otc`)은 먼저 개별 글꼴로 내보내야 합니다.
- 크기가 작거나 이미 서브셋으로 만든 글꼴은 더 작아지지 않을 수 있습니다.
  일반적으로 WOFF2가 웹 다운로드 크기가 가장 작으며, 글리프 수에는 보조 글리프도 포함됩니다.
