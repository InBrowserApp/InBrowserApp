## 什麼是字型子集？

字型子集包含特定文字所需的字元，以及正確顯示這些字元所需的輔助字形。
移除未使用的字形可大幅減少字型下載量，尤其適合大型中文、日文和韓文字型，
以及文字固定的標題、標誌或活動網頁。

## 如何使用此工具

選擇 TTF、OTF、WOFF 或 WOFF2 檔案，並貼上所有將使用此字型的文字。
網頁使用建議選擇 WOFF2；若需要未壓縮的字型，則選擇 TTF / OTF，再產生子集。
比較檔案大小、檢查預覽，然後下載字型及對應的 CSS。
字型處理會在本機的 Web Worker 中執行。

## 會保留哪些內容？

HarfBuzz 會保留連字、字距調整、組合附加符號和複雜文字系統所需的字形相依關係
與 OpenType 排版功能，也會保留字型微調資訊和可變字型軸。
若來源字型支援，也會納入標準等價的合成與分解文字形式。
預覽會使用產生的字型，來源字型缺少的字元則會另外列出。

## 實用提示

- 請包含空格、標點符號、數字及所有需要的翻譯文字。若文字也會包含基本拉丁字元，
  可加入拉丁字元預設集。
- 每次文字變更時，請重新產生子集。固定子集最適合已知內容；使用者產生的內容
  則應保留更廣泛的字元範圍。
- 子集無法新增原始字型缺少的字元。請在 CSS 中保留備援字型，以顯示子集以外的字元。
- 請使用授權允許修改及網頁嵌入的字型。字型集合（`.ttc` / `.otc`）必須先匯出為個別字型。
- 小型字型或已建立子集的字型不一定會縮小。WOFF2 通常可提供最小的網頁下載檔案；
  字形數也包含輔助字形。
