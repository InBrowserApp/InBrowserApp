## 什么是字体子集？

字体子集包含一段文本所需的字符，以及正确渲染它们所需的辅助字形。删除未使用的字形可以显著减少字体下载量，尤其适用于大型中日韩字体，或内容固定的标题、标志和活动页面。

## 如何使用此工具

选择 TTF、OTF、WOFF 或 WOFF2 文件，粘贴所有将使用该字体的文本。网页使用建议选择 WOFF2；如需未压缩字体，可选择 TTF / OTF，然后生成子集。比较文件大小、检查预览，再下载字体及配套 CSS。字体处理在本地 Web Worker 中运行。

## 会保留哪些内容？

HarfBuzz 会保留连字、字距调整、组合附加符号和复杂文字所需的字形依赖与 OpenType 排版特性，同时保留字体微调指令和可变字体轴。如果源字体支持，还会包含规范等价的预组合与分解文本形式。预览使用生成后的字体，源字体缺少的字符会单独列出。

## 实用建议

- 包含所需的空格、标点、数字和所有翻译文本。如果文本还会使用基本拉丁字符，可添加拉丁字符预设。
- 文本变化后，请重新生成子集。固定子集适合已知内容；用户生成的内容应使用覆盖范围更广的字符集。
- 子集无法添加原始字体缺少的字符。请在 CSS 中设置后备字体，以显示子集范围外的字符。
- 请使用许可允许修改和网页嵌入的字体。字体集合（`.ttc` / `.otc`）需要先导出为单个字体。
- 小型字体或已经生成过子集的字体可能不会进一步缩小。WOFF2 通常能提供最小的网页下载文件；字形数也包含辅助字形。
