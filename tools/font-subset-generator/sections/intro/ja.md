## フォントサブセットとは？

フォントサブセットは、特定のテキストに必要な文字と、その表示に必要な補助的な字形を含むフォントです。
不要な字形を取り除くと、フォントのダウンロードサイズを大幅に減らせます。
特に、中国語・日本語・韓国語の大きなフォントや、固定の見出し、ロゴ、キャンペーンページに役立ちます。

## 使い方

TTF、OTF、WOFF、WOFF2 ファイルを選び、そのフォントで表示するすべてのテキストを貼り付けます。
Web 配信には WOFF2、非圧縮フォントには TTF / OTF を選び、サブセットを生成してください。
サイズを比較してプレビューを確認したら、フォントと対応する CSS をダウンロードします。
フォントの処理は、デバイス内の Web Worker で行われます。

## 保持されるもの

HarfBuzz は、合字、カーニング、結合文字、複雑な文字体系に必要な字形の依存関係と
OpenType レイアウト機能を保持します。ヒンティングとバリアブルフォントの軸も保持されます。
元のフォントが対応している場合は、正準等価な合成済み表現と分解表現の両方を含めます。
プレビューには生成したフォントを使用し、元のフォントにない文字は別に表示します。

## 利用のヒント

- スペース、句読点、数字、必要なすべての翻訳文を含めてください。
  基本的なラテン文字も使う場合は、ラテン文字のプリセットを追加してください。
- テキストを変更したら、サブセットを再生成してください。固定のサブセットは内容が決まっている場合に適しています。
  ユーザーが入力するテキストには、より広い文字範囲を用意してください。
- 元のフォントにない文字をサブセットで追加することはできません。
  サブセットに含まれない文字のために、CSS で代替フォントを指定してください。
- 改変と Web への埋め込みがライセンスで許可されているフォントを使用してください。
  フォントコレクション（`.ttc` / `.otc`）は、先に個別のフォントとして書き出す必要があります。
- 小さなフォントや、すでにサブセット化されたフォントは、サイズが小さくならない場合があります。
  Web 配信では通常 WOFF2 が最も小さくなります。字形数には表示に必要な補助的な字形も含まれます。
