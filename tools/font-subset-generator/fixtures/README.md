# Font subset fixtures

These tiny fonts contain original geometric outlines generated by `build.py`
with FontTools. They include BMP and supplementary Unicode mappings, composed
and decomposed accents, a `liga` ligature and an `ss01` alternate. The variable
font has `wght` and `wdth` axes. The CFF fixture exercises OpenType output.

Regenerate with `python build.py` (requires FontTools and Brotli). They are test
data only and are not included in the production bundle.
