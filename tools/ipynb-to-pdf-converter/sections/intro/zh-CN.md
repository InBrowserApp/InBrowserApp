## 如何将 Jupyter 笔记本转换为 PDF

打开或拖入从 Jupyter、Google Colab 或 VS Code 保存的 `.ipynb` 文件。检查笔记本预览，选择 A4 或美国信纸（US Letter），然后点击 **保存为 PDF**。浏览器打开打印对话框后，在目标选项中选择 **保存为 PDF**。你也可以在同一个对话框里选择打印机直接打印。例如，你可以把 `analysis.ipynb` 转为 PDF，用作邮件附件或随报告一起提交。

## PDF 包含哪些内容

PDF 保留笔记本的单元格顺序，包含 Markdown 标题和表格、源代码，以及支持的已保存输出，例如控制台文本、表格和嵌入的图表图片。过长的代码行会按纸张宽度自动换行，内容较长的单元格可以接到下一页。PDF 里的文字仍可选中。

如果想保留最新的结果，请在转换前将输出和笔记本一起保存。转换器在本地读取文件，不会执行单元格。交互式组件只有在文件中保存了静态内容时才会显示。LaTeX 保留为源文本，在线图片和其他外部资源不会加载。

## 笔记本的其他用法

用 [Jupyter 笔记本查看器](../notebook-viewer/) 浏览各个单元格和已保存的输出。如果需要 HTML、Markdown 或代码脚本，可以使用 [Jupyter 笔记本转换器](../notebook-export/)。
