## Cara mengonversi notebook Jupyter ke PDF

Buka atau seret file `.ipynb` yang sudah disimpan dari Jupyter, Google Colab, atau VS Code ke halaman ini. Periksa pratinjau notebook, pilih A4 atau US Letter, lalu klik **Simpan sebagai PDF**. Pada dialog cetak browser, atur tujuan cetak ke **Simpan sebagai PDF**. Anda juga bisa memilih printer dari dialog tersebut. Misalnya, ubah `analysis.ipynb` menjadi PDF untuk dilampirkan ke email atau dikumpulkan bersama laporan.

## Isi file PDF

PDF mengikuti urutan sel di notebook. Isinya mencakup judul dan tabel Markdown, kode sumber, serta keluaran tersimpan yang didukung, seperti teks konsol, tabel, dan gambar grafik yang disematkan. Baris kode yang panjang diteruskan ke baris berikutnya agar muat di kertas. Isi sel yang panjang dapat berlanjut ke halaman berikutnya, dan teks di PDF tetap bisa diseleksi.

Simpan notebook beserta keluarannya sebelum mengonversi agar hasil terbaru ikut tercantum. Konverter membaca file yang tersimpan di perangkat Anda tanpa menjalankan sel. Widget hanya dapat ditampilkan jika notebook menyimpan versi statisnya. Sumber LaTeX tetap berupa teks, dan gambar serta sumber daya eksternal lain tidak dimuat.

## Cara lain menggunakan notebook

Gunakan [Penampil Notebook Jupyter](../notebook-viewer/) untuk berpindah antarsel dan membaca keluaran tersimpan. Gunakan [Konverter Notebook Jupyter](../notebook-export/) jika Anda membutuhkan HTML, Markdown, atau skrip kode.
