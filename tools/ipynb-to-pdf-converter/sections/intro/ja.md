## Jupyter Notebook を PDF に変換する方法

Jupyter、Google Colab、または VS Code で保存した `.ipynb` ファイルを開くか、ドラッグ＆ドロップします。プレビューを確認し、用紙サイズを A4 または US レターに設定して、**PDFとして保存**を選びます。ブラウザーの印刷ダイアログが開いたら、送信先に **PDFとして保存**を指定します。同じダイアログからプリンターを選ぶこともできます。たとえば、`analysis.ipynb` を PDF にすると、メールに添付したりレポートと一緒に提出したりできます。

## PDF に含まれる内容

セルの順序は元のノートブックと同じです。Markdown の見出しや表、ソースコードに加え、コンソールのテキスト、表、埋め込まれたグラフ画像など、対応する保存済みの出力が含まれます。長いコード行は用紙幅に合わせて折り返され、長いセルは次のページに続きます。PDF 内のテキストは選択できます。

最新の結果を含めるには、変換前に出力も含めてノートブックを保存してください。ファイルは端末内で読み込まれ、セルは実行されません。ウィジェットが表示されるのは静的な表示形式が保存されている場合です。LaTeX はソーステキストのまま表示され、外部の画像やリソースは取得されません。

## ノートブックのその他の使い方

[Jupyter Notebook ビューアー](../notebook-viewer/)では、セルと保存済みの出力を閲覧できます。HTML、Markdown、またはコードスクリプトが必要な場合は、[Jupyter Notebook 変換ツール](../notebook-export/)を使用してください。
