## 如何將 Jupyter 筆記本轉成 PDF

開啟或拖曳從 Jupyter、Google Colab 或 VS Code 儲存的 `.ipynb` 檔案。檢查筆記本預覽，選擇 A4 或美規信紙（US Letter），再按一下 **儲存為 PDF**。瀏覽器開啟列印對話方塊後，將目的地設為 **儲存為 PDF**。你也可以在同一個對話方塊選擇印表機直接列印。例如，你可以將 `analysis.ipynb` 轉成 PDF，當作電子郵件附件或隨報告一起繳交。

## PDF 包含哪些內容

PDF 會保留筆記本的儲存格順序，包含 Markdown 標題和表格、原始碼，以及支援的已儲存輸出，例如終端機文字、表格和內嵌的圖表圖片。過長的程式碼會依紙張寬度自動換行，內容較長的儲存格可以接續到下一頁。PDF 裡的文字仍可選取。

若要保留最新的結果，請在轉換前將輸出和筆記本一起儲存。轉換器會在裝置上讀取已儲存的檔案，不會執行任何儲存格。互動小工具只有在檔案中已有靜態內容時才會顯示。LaTeX 保留為原始文字，線上圖片和其他外部資源不會載入。

## 筆記本的其他用法

使用 [Jupyter 筆記本檢視器](../notebook-viewer/) 瀏覽各個儲存格和已儲存的輸出。如果需要 HTML、Markdown 或程式碼指令稿，可使用 [Jupyter 筆記本轉換器](../notebook-export/)。
