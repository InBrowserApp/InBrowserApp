## แปลงชื่อโดเมนระหว่าง Unicode กับ Punycode

วางชื่อโดเมน เช่น `bücher.com` ในช่อง **โดเมน Unicode** แล้วจะได้ `xn--bcher-kva.com` ในช่อง **โดเมน ASCII** หากต้องการอ่านโดเมนที่ขึ้นต้นด้วย `xn--` ให้ใส่ในช่อง **โดเมน ASCII** เพื่อดูชื่อในรูป Unicode ผลการแปลงจะแสดงทันทีที่พิมพ์ และคัดลอกได้ทั้งสองรูปแบบ

## ควรใช้โดเมนแต่ละรูปแบบเมื่อไร

Punycode ใช้ตัวอักษร ASCII ตัวเลข และขีดกลางแทนอักขระนอกชุด ASCII ในชื่อโดเมนสากล (IDN) ส่วนของชื่อโดเมนที่แปลงแล้วจะขึ้นต้นด้วย `xn--` ส่วนที่เป็น ASCII อยู่แล้ว เช่น `com` จะคงเดิม ใช้รูปแบบ ASCII เมื่อตั้งค่า DNS หรือโฮสติ้งที่ต้องการรูปแบบนี้ และใช้รูปแบบ Unicode เพื่ออ่านชื่อโดเมนจากบันทึกระบบหรือไฟล์การตั้งค่า

## ต้องใส่อะไรในช่องแปลง

ใส่เฉพาะชื่อโฮสต์ เช่น หาก URL คือ `https://bücher.com/catalog` ให้วางเพียง `bücher.com` เครื่องมือรองรับโดเมนย่อยด้วย เช่น `www.bücher.com` จะแปลงเป็น `www.xn--bcher-kva.com`
