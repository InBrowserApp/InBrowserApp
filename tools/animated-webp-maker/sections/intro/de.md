## Eine Animation aus Bildern erstellen

Füge mindestens zwei Bilder im Format PNG, JPEG, WebP oder AVIF hinzu.
Ziehe die Einzelbilder an die gewünschte Position oder nutze die Pfeile.
Lege die Anzeigedauer pro Einzelbild fest oder wähle für ein gleichmäßiges
Tempo **Auf alle anwenden**. Gib als Anzahl der Wiedergaben 0 für eine
Endlosschleife oder 1 für eine einmalige Wiedergabe ein.

## Vorschau und Download

Erstelle die animierte WebP-Datei, prüfe das Ergebnis mit **Abspielen**
und lade die Datei herunter. Die Einzelbilder werden auf einer gemeinsamen
Bildfläche mittig platziert. Freie Flächen bleiben transparent. Beim
Export bleiben auch halbtransparente Bildbereiche erhalten. Dein Browser
verarbeitet alle Bilder auf deinem Gerät.
