## Crie uma animação a partir de imagens

Adicione pelo menos duas imagens PNG, JPEG, WebP ou AVIF. Arraste os quadros
ou use as setas para mudar a ordem. Ajuste a duração de cada quadro ou
selecione **Aplicar a todos** para definir a mesma duração para todos. Use 0
para repetir sem parar ou 1 para reproduzir uma vez.

## Visualize e baixe

Crie o WebP animado, selecione **Reproduzir** para ver a prévia e baixe o
resultado. Os quadros ficam centralizados em uma área comum com margens
transparentes. O arquivo exportado preserva a transparência parcial. O
navegador faz todo o processamento no seu dispositivo.
