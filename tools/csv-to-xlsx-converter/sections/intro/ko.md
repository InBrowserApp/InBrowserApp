## 구분 기호로 나뉜 텍스트를 Excel로 변환하기

기기에 있는 CSV 또는 TSV 파일을 열거나 끌어다 놓고, 셀을 확인한 다음 Sheet1이라는 워크시트 하나가 포함된 XLSX 통합 문서를 다운로드하세요. 자동 감지 결과가 파일과 맞지 않으면 구분 기호와 텍스트 인코딩을 선택하세요. TSV 파일은 기본적으로 탭을 사용합니다. 미리 보기 창은 내보내는 데이터 범위를 제한하지 않습니다.

## 식별자와 원래 텍스트 유지하기

CSV와 TSV에는 스프레드시트 셀의 데이터 형식이 저장되지 않습니다. 이 변환기는 앞자리의 0, 긴 식별자, 소수처럼 보이는 숫자, 날짜, 등호로 시작하는 텍스트를 포함한 모든 필드를 텍스트로 유지합니다. 숫자나 날짜로 자동 변환하거나 수식을 실행하지 않습니다. 따옴표 안의 구분 기호, 이스케이프된 따옴표, 유니코드, 필드 안의 줄바꿈, 빈 필드와 빈 레코드도 유지됩니다. 필드 수가 적은 행은 나머지 셀을 비워 둡니다. 마지막 줄바꿈은 새 행을 추가하지 않고 마지막 레코드를 끝냅니다.

첫 행 설정에서는 일반 데이터 또는 Excel 필터가 있는 머리글을 선택할 수 있습니다. 두 옵션 모두 중복되거나 비어 있는 머리글을 포함하여 행을 작성된 그대로 유지합니다. 자동 인코딩은 UTF-8과 바이트 순서 표시가 있는 UTF-16을 지원합니다. 다른 인코딩은 직접 선택할 수 있습니다. 파일 맨 앞의 sep= 지시문은 구분 기호 자동 감지를 선택했거나 해당 지시문의 구분 기호가 선택한 구분 기호와 일치할 때만 생략됩니다.

따옴표로 묶인 필드의 형식이나 텍스트 인코딩이 잘못되었거나 데이터가 Excel의 행 수, 열 수 또는 셀 텍스트 길이 한도를 초과하면 일부가 잘린 통합 문서 대신 오류가 표시됩니다. 중요한 값은 다운로드한 후 스프레드시트 애플리케이션에서 확인하세요.

## 기기 내 처리

파일을 업로드하지 않고 이 브라우저에서 변환합니다. 가져오기 설정을 변경하거나 파일을 바꾸거나 닫으면 이전 결과가 삭제됩니다. 취소하면 백그라운드 작업이 중지됩니다. 파일 크기에 고정된 상한은 없으며, 처리할 수 있는 파일은 브라우저에서 사용할 수 있는 메모리에 따라 달라집니다.

스프레드시트 파일을 살펴보려면 [스프레드시트 뷰어](../xlsx-viewer/)를 여세요.
