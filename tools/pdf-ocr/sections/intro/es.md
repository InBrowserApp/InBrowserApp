## Cómo habilitar la búsqueda en un PDF escaneado

1. Elige un PDF o suéltalo en la herramienta.
2. Selecciona el idioma del documento. Activa **Reconocer también inglés** si el escaneo combina inglés con el idioma elegido.
3. Selecciona **Habilitar búsqueda en el PDF**. Mantén esta pestaña abierta mientras la herramienta revisa las páginas y reconoce el texto.
4. Descarga el PDF y ábrelo en un lector de PDF. Usa Ctrl+F o ⌘F para buscar una palabra, o selecciona parte de una línea para copiarla.

## ¿Qué hace el OCR en un PDF?

El reconocimiento óptico de caracteres (OCR) identifica letras y números en las imágenes de las páginas y añade una capa de texto invisible en la posición de los caracteres. Se conservan el aspecto, la distribución y el orden de las páginas. Así puedes buscar texto en contratos, facturas, formularios o páginas de libros escaneados y copiar fragmentos. El archivo que descargas es un PDF independiente.

## ¿Qué pasa si algunas páginas ya tienen texto seleccionable?

El OCR omite las páginas que ya tienen texto seleccionable. Así, un PDF con páginas escaneadas y páginas digitales conserva el texto original sin duplicarlo. Esto también se aplica a las páginas que combinan texto seleccionable con palabras dentro de una imagen. Si todas las páginas ya tienen texto o el OCR no reconoce texto nuevo, puedes descargar el PDF original.

Si el original lleva una firma digital, consérvalo. Al añadir una capa de texto, la firma deja de ser válida en la copia nueva.

## ¿Cómo puedo mejorar la precisión del OCR?

Elige el idioma de la página y usa un escaneo nítido, bien orientado y con buen contraste. Para textos en chino, japonés o coreano escritos en vertical, elige el modelo de escritura vertical correspondiente. La escritura a mano, las imágenes borrosas y la letra pequeña pueden reducir la precisión. Comprueba los nombres y números importantes en la página original.

El navegador descarga el motor OCR y los datos del idioma seleccionado cuando hacen falta. El PDF y el texto reconocido se quedan en tu dispositivo.
