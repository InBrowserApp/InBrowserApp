## How to make a scanned PDF searchable

1. Choose a PDF or drop it into the tool.
2. Select the language used in the document. Turn on **Also recognize English** for scans that mix English with the selected language.
3. Select **Make PDF searchable**. Keep this tab open while the tool checks and recognizes pages.
4. Download the searchable PDF and open it in a PDF reader. Use Ctrl+F or ⌘F to find a word, or select part of a line to copy it.

## What does PDF OCR do?

Optical character recognition (OCR) reads letters and numbers in page images and adds an invisible text layer at their positions. The page appearance, layout, and order stay the same. This is useful for searching scanned contracts, invoices, forms, or book pages and copying short passages. The downloaded file is a separate PDF.

## What if some pages already have selectable text?

OCR skips pages that already contain selectable text so mixed PDFs keep their existing text without doubling it. A page that mixes selectable text with words inside an image is also skipped. If every page already has text, or OCR finds no new text, the tool offers the original PDF to download.

## How can I improve OCR accuracy?

Choose the language on the page and use a sharp, upright scan with good contrast. For vertical Chinese, Japanese, or Korean, choose the corresponding vertical language model. Handwriting, blur, and small print can reduce accuracy. Check important names and numbers against the original page.

## Is PDF OCR private?

The browser downloads the OCR engine and selected language data as needed. Your PDF and recognized text stay on your device. For plain text from a searchable PDF, use [PDF Text Extractor](/tools/pdf-text-extractor/). For a screenshot or photo, use [Image to Text Converter](/tools/image-to-text-converter/).
