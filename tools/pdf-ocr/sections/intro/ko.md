## 스캔한 PDF를 검색 가능하게 만드는 방법

1. PDF를 선택하거나 도구에 끌어다 놓습니다.
2. 문서에 사용된 언어를 선택합니다. 선택한 언어와 영어가 함께 쓰인 스캔본이라면 **영어도 인식**을 켭니다.
3. **검색 가능한 PDF 만들기**를 선택합니다. 도구가 페이지를 확인하고 인식하는 동안 이 탭을 열어 두세요.
4. 검색 가능한 PDF를 다운로드하여 PDF 리더에서 엽니다. Ctrl+F 또는 ⌘F로 단어를 찾거나, 한 줄의 일부를 선택해 복사할 수 있습니다.

## PDF OCR은 어떤 기능인가요?

광학 문자 인식(OCR)은 페이지 이미지의 문자와 숫자를 읽고 해당 위치에 보이지 않는 텍스트 레이어를 추가합니다. 페이지의 모양과 레이아웃, 순서는 그대로 유지됩니다. 스캔한 계약서, 청구서, 양식이나 책 페이지를 검색하고 짧은 구절을 복사할 때 유용합니다. 다운로드한 파일은 별도의 PDF입니다.

## 일부 페이지에 이미 선택 가능한 텍스트가 있다면 어떻게 되나요?

OCR은 선택 가능한 텍스트가 이미 있는 페이지를 건너뛰므로, 여러 종류의 페이지가 섞인 PDF에서도 기존 텍스트를 중복 없이 유지합니다. 선택 가능한 텍스트와 이미지 속 글자가 함께 있는 페이지도 건너뜁니다. 모든 페이지에 이미 텍스트가 있거나 OCR이 새 텍스트를 찾지 못하면 원본 PDF를 다운로드할 수 있습니다.

## OCR 정확도를 높이려면 어떻게 해야 하나요?

페이지에 쓰인 언어를 선택하고 선명하고 똑바르며 명암 대비가 좋은 스캔본을 사용하세요. 세로로 쓴 중국어, 일본어 또는 한국어는 해당 세로쓰기 언어 모델을 선택하세요. 손글씨, 흐린 이미지, 작은 글씨는 정확도를 떨어뜨릴 수 있습니다. 중요한 이름과 숫자는 원본 페이지와 비교해 확인하세요.
