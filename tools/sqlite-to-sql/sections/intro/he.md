## איך מייצאים מסד SQLite לקובץ SQL

פותחים או גוררים קובץ מסד נתונים של SQLite 3, למשל בסיומת `.db`,‏ `.sqlite` או `.sqlite3`. הכלי יוצר סקריפט SQL באופן אוטומטי. כדי לייצא את המבנה בלי שורות הטבלאות, מפעילים את האפשרות **סכמה בלבד**. לאחר מכן בוחרים **הורדת קובץ .sql** כדי לשמור את הסקריפט המלא. אפשר לנסות את מסד הנתונים לדוגמה כדי לראות איך התוצאה נראית.

## מה כולל קובץ SQL שיוצא מ־SQLite

קובץ הייצוא מכיל סקריפט טקסט שאפשר להריץ כדי ליצור מחדש מסד נתונים. הוא כולל פקודות `CREATE` לטבלאות, לאינדקסים, לתצוגות ולטריגרים. הייצוא המלא כולל גם פקודות `INSERT` לשורות הטבלאות. אפשר להשתמש בו כדי לעיין בשינויי סכמה ב־Git, לשמור גיבוי קריא או להעביר את מסד הנתונים לסביבת SQLite אחרת.

קובץ המקור נשאר במכשיר שלך. אם מסד הנתונים משתמש ביומן כתיבה מקדים (WAL), מייצאים עותק עצמאי. אפשר להשתמש ביישום שיצר את מסד הנתונים או בפקודת הגיבוי של SQLite כדי שהעותק יכלול שינויים שנרשמו ביומן בעסקאות שהושלמו.

## איך משחזרים את מסד הנתונים מקובץ SQL

מריצים את הפקודה הבאה כדי לייבא את הסקריפט למסד נתונים חדש של SQLite.

```sh
sqlite3 restored.sqlite < database.sql
```

מחליפים את `database.sql` בשם הקובץ שהורד. הסקריפט משתמש בתחביר של SQLite. מסדי נתונים שמשתמשים בטבלאות וירטואליות או בהרחבות יש לשחזר בהתקנת SQLite שכוללת את המודולים הדרושים.

אפשר לעיין בטבלאות ולייצא תוצאות שאילתה ל־CSV או ל־JSON ב[מציג SQLite](../sqlite-viewer/). ליצירת מסד נתונים מגיליונות אלקטרוניים אפשר להשתמש ב[ממיר CSV ו־Excel ל־SQLite](../csv-excel-to-sqlite/).
