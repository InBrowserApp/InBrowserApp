## SQLite を SQL ファイルにエクスポートする方法

`.db`、`.sqlite`、`.sqlite3` などの SQLite 3 データベースファイルを選択するか、ドロップしてください。SQL ダンプが自動で生成されます。データベースの構造だけをエクスポートする場合は、**スキーマのみ**をオンにしてください。**.sql をダウンロード**を選ぶと、スクリプト全体を保存できます。出力を確認したいときは、サンプルデータベースをお試しください。

## SQLite の SQL ダンプに含まれる内容

SQL ダンプは、データベースを再作成するためのテキスト形式のスクリプトです。テーブル、インデックス、ビュー、トリガーの `CREATE` 文が含まれます。スキーマとデータをまとめてエクスポートすると、テーブルの行を復元する `INSERT` 文も含まれます。Git でのスキーマ変更の確認、内容を読める形式でのバックアップ、別の SQLite 環境への移行に使えます。

元のファイルはお使いの端末内で処理されます。書き込み先行ログ（WAL）を使用している場合は、作成元のアプリか SQLite のバックアップコマンドで、単独で開けるデータベースのコピーを作成してください。これにより、ログ内でコミット済みの変更もコピーに含まれます。

## SQL ダンプからデータベースを復元する方法

次のコマンドで、スクリプトを新しい SQLite データベースにインポートできます。

```sh
sqlite3 restored.sqlite < database.sql
```

`database.sql` はダウンロードしたファイルの名前に置き換えてください。スクリプトは SQLite の構文を使用します。仮想テーブルや拡張機能を使うデータベースは、必要なモジュールが用意されている SQLite 環境で復元してください。

テーブルの閲覧や、クエリ結果の CSV・JSON エクスポートには [SQLite ビューアー](../sqlite-viewer/) をお使いください。スプレッドシートからデータベースを作成するには [CSV・ExcelをSQLiteに変換](../csv-excel-to-sqlite/) をお使いください。
