## SQLite को SQL फ़ाइल में कैसे निर्यात करें

SQLite 3 डेटाबेस की `.db`, `.sqlite` या `.sqlite3` जैसी फ़ाइल खोलें या खींचकर यहाँ छोड़ें। टूल अपने आप SQL डंप बनाएगा। टेबल की डेटा पंक्तियाँ छोड़कर सिर्फ़ डेटाबेस की संरचना निर्यात करने के लिए **सिर्फ़ स्कीमा** चालू करें। पूरी स्क्रिप्ट सहेजने के लिए **.sql डाउनलोड करें** चुनें। नतीजा देखने के लिए नमूना डेटाबेस आज़माएँ।

## SQLite के SQL डंप में क्या होता है?

SQL डंप डेटाबेस को दोबारा बनाने के लिए एक टेक्स्ट स्क्रिप्ट है। इसमें टेबल, इंडेक्स, व्यू और ट्रिगर बनाने के लिए `CREATE` स्टेटमेंट होते हैं। पूरे निर्यात में टेबल की पंक्तियों के लिए `INSERT` स्टेटमेंट भी शामिल होते हैं। इससे आप Git में स्कीमा के बदलावों की समीक्षा कर सकते हैं, पढ़ने योग्य बैकअप रख सकते हैं या डेटाबेस को किसी दूसरे SQLite परिवेश में ले जा सकते हैं।

मूल फ़ाइल आपके डिवाइस पर रहती है। अगर डेटाबेस राइट-अहेड लॉग (WAL) इस्तेमाल करता है, तो ऐसी कॉपी निर्यात करें जिसे अलग से खोला जा सके। इसके लिए मूल ऐप या SQLite का बैकअप कमांड इस्तेमाल करें, ताकि लॉग में कमिट किए गए बदलाव भी कॉपी में आ जाएँ।

## SQL डंप से डेटाबेस कैसे बहाल करें

स्क्रिप्ट को नए SQLite डेटाबेस में इंपोर्ट करने के लिए यह कमांड चलाएँ।

```sh
sqlite3 restored.sqlite < database.sql
```

`database.sql` की जगह डाउनलोड की गई फ़ाइल का नाम लिखें। इस स्क्रिप्ट में SQLite का सिंटैक्स इस्तेमाल होता है। वर्चुअल टेबल या एक्सटेंशन वाले डेटाबेस को ऐसे SQLite इंस्टॉलेशन में बहाल करें जिसमें ज़रूरी मॉड्यूल मौजूद हों।

टेबल देखने या क्वेरी के नतीजे CSV या JSON में निर्यात करने के लिए [SQLite व्यूअर](../sqlite-viewer/) खोलें। स्प्रेडशीट से डेटाबेस बनाने के लिए [CSV और Excel को SQLite में बदलें](../csv-excel-to-sqlite/) टूल इस्तेमाल करें।
