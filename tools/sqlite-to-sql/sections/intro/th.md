## วิธีส่งออก SQLite เป็นไฟล์ SQL

เปิดไฟล์ฐานข้อมูล SQLite 3 เช่น `.db`, `.sqlite` หรือ `.sqlite3` หรือลากมาวางในเครื่องมือ ระบบจะสร้างไฟล์ดัมป์ SQL โดยอัตโนมัติ เปิดตัวเลือก **เฉพาะสคีมา** เพื่อส่งออกโครงสร้างฐานข้อมูลโดยไม่รวมแถวข้อมูล จากนั้นเลือก **ดาวน์โหลด .sql** เพื่อบันทึกสคริปต์ฉบับเต็ม ลองใช้ฐานข้อมูลตัวอย่างเพื่อดูผลลัพธ์

## ไฟล์ดัมป์ SQL ของ SQLite มีอะไรบ้าง

ดัมป์ SQL เป็นสคริปต์ข้อความสำหรับสร้างฐานข้อมูลขึ้นใหม่ โดยมีคำสั่ง `CREATE` สำหรับตาราง ดัชนี วิว และทริกเกอร์ หากเลือกส่งออกทั้งหมด จะมีคำสั่ง `INSERT` สำหรับแถวข้อมูลด้วย ใช้ไฟล์นี้เพื่อตรวจสอบการเปลี่ยนแปลงสคีมาใน Git เก็บข้อมูลสำรองที่อ่านได้ หรือย้ายฐานข้อมูลไปยังสภาพแวดล้อม SQLite อื่น

ไฟล์ต้นฉบับจะอยู่บนอุปกรณ์ของคุณ หากฐานข้อมูลใช้บันทึกแบบเขียนล่วงหน้า (WAL) ให้ส่งออกสำเนาที่เปิดได้โดยไม่ต้องใช้ไฟล์ประกอบ ใช้แอปต้นทางหรือคำสั่งสำรองข้อมูลของ SQLite เพื่อให้สำเนารวมการเปลี่ยนแปลงในบันทึกที่คอมมิตแล้วด้วย

## วิธีกู้คืนฐานข้อมูลจากไฟล์ดัมป์ SQL

รันคำสั่งนี้เพื่อนำเข้าสคริปต์ไปยังฐานข้อมูล SQLite ใหม่

```sh
sqlite3 restored.sqlite < database.sql
```

แทนที่ `database.sql` ด้วยชื่อไฟล์ที่ดาวน์โหลด สคริปต์ใช้ไวยากรณ์ของ SQLite หากฐานข้อมูลใช้ตารางเสมือนหรือส่วนขยาย ให้กู้คืนใน SQLite ที่มีโมดูลที่จำเป็น

หากต้องการดูตารางหรือส่งออกผลลัพธ์ของคำสั่งเป็น CSV หรือ JSON ให้เปิด [โปรแกรมดู SQLite](../sqlite-viewer/) หากต้องการสร้างฐานข้อมูลจากสเปรดชีต ให้ใช้ [แปลง CSV และ Excel เป็น SQLite](../csv-excel-to-sqlite/)
