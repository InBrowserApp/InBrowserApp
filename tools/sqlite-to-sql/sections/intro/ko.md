## SQLite를 SQL 파일로 내보내는 방법

`.db`, `.sqlite`, `.sqlite3` 등의 SQLite 3 데이터베이스 파일을 열거나 끌어다 놓으면 SQL 덤프가 자동으로 생성됩니다. 테이블 행을 제외하고 데이터베이스 구조만 내보내려면 **스키마만** 옵션을 켜세요. **.sql 다운로드**를 선택하면 전체 스크립트를 저장할 수 있습니다. 결과가 어떤 모습인지 확인하려면 샘플 데이터베이스를 사용해 보세요.

## SQLite SQL 덤프에 포함되는 내용

SQL 덤프는 데이터베이스를 다시 만드는 데 사용하는 텍스트 스크립트입니다. 테이블, 인덱스, 뷰, 트리거를 만드는 `CREATE` 문이 포함되며, 전체 내보내기에는 테이블 행을 추가하는 `INSERT` 문도 포함됩니다. Git에서 스키마 변경 사항을 검토하거나, 내용을 읽을 수 있는 백업을 보관하거나, 다른 SQLite 환경으로 데이터베이스를 옮길 때 사용할 수 있습니다.

원본 파일은 기기에 그대로 남습니다. 원본 데이터베이스가 미리 쓰기 로그(WAL)를 사용한다면, 데이터베이스를 만든 앱이나 SQLite의 백업 명령을 사용해 별도 로그 파일 없이 열 수 있는 복사본을 내보내세요. 이렇게 하면 로그에 커밋된 변경 사항도 복사본에 포함됩니다.

## SQL 덤프를 복원하는 방법

다음 명령을 실행하면 스크립트를 새 SQLite 데이터베이스로 가져올 수 있습니다.

```sh
sqlite3 restored.sqlite < database.sql
```

`database.sql`을 다운로드한 파일 이름으로 바꾸세요. 스크립트에는 SQLite 구문을 사용합니다. 가상 테이블이나 확장 기능이 있는 데이터베이스는 필요한 모듈이 설치된 SQLite 환경에서 복원하세요.

테이블을 살펴보거나 쿼리 결과를 CSV 또는 JSON으로 내보내려면 [SQLite 뷰어](../sqlite-viewer/)를 여세요. 스프레드시트에서 데이터베이스를 만들려면 [CSV·Excel을 SQLite로 변환](../csv-excel-to-sqlite/) 도구를 사용하세요.
