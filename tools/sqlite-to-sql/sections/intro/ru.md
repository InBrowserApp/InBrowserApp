## Как экспортировать SQLite в SQL-файл

Откройте или перетащите файл базы данных SQLite 3 с расширением `.db`, `.sqlite` или `.sqlite3`. Инструмент автоматически создаст SQL-дамп. Выберите **Только схема**, чтобы экспортировать структуру без строк таблиц, и нажмите **Скачать файл .sql**, чтобы сохранить скрипт целиком. Откройте пример базы данных, чтобы посмотреть на результат.

## Что входит в SQL-дамп SQLite

SQL-дамп — это текстовый скрипт для воссоздания базы данных. В него входят инструкции `CREATE` для таблиц, индексов, представлений и триггеров. При полном экспорте добавляются инструкции `INSERT` для строк таблиц. Такой скрипт можно использовать, чтобы отслеживать изменения схемы в Git, хранить резервную копию в читаемом формате или переносить базу в другую среду SQLite.

Исходный файл остаётся на вашем устройстве. Если база использует журнал предзаписи (WAL), экспортируйте отдельную копию базы. Воспользуйтесь исходным приложением или командой резервного копирования SQLite, чтобы в копию попали зафиксированные изменения из журнала.

## Как восстановить базу из SQL-дампа

Выполните эту команду, чтобы импортировать скрипт в новую базу данных SQLite.

```sh
sqlite3 restored.sqlite < database.sql
```

Вместо `database.sql` укажите имя скачанного файла. Скрипт использует синтаксис SQLite. Если база использует виртуальные таблицы или расширения, для восстановления понадобятся соответствующие модули в вашей установке SQLite.

В инструменте [Просмотр SQLite](../sqlite-viewer/) можно просматривать таблицы и экспортировать результаты запросов в CSV или JSON. Чтобы создать базу из электронных таблиц, воспользуйтесь инструментом [Конвертер CSV и Excel в SQLite](../csv-excel-to-sqlite/).
