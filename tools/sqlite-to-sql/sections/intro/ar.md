## كيفية تصدير قاعدة SQLite إلى ملف SQL

افتح ملف قاعدة بيانات SQLite 3 بامتداد مثل `.db` أو `.sqlite` أو `.sqlite3`، أو أفلته في الأداة. ينشئ المُصدّر ملف SQL تلقائيًا. فعّل **المخطط فقط** لتصدير البنية دون صفوف الجداول، ثم اختر **تنزيل ملف .sql** لحفظ النص الكامل. جرّب قاعدة البيانات النموذجية للتعرّف على شكل النتيجة.

## ماذا يتضمن ملف SQL المُصدَّر من SQLite؟

يتضمن ملف تصدير SQL نصًا برمجيًا يعيد إنشاء قاعدة البيانات. ويحتوي على عبارات `CREATE` للجداول والفهارس والعروض والمشغّلات، بالإضافة إلى عبارات `INSERT` لصفوف الجداول في التصدير الكامل. استخدم الملف لمراجعة تغييرات المخطط في Git أو الاحتفاظ بنسخة احتياطية قابلة للقراءة أو نقل قاعدة البيانات إلى بيئة SQLite أخرى.

يبقى الملف الأصلي على جهازك. إذا كانت قاعدة البيانات تستخدم سجل الكتابة المسبقة (WAL)، فصدّر نسخة مستقلة. استخدم التطبيق الذي أنشأ قاعدة البيانات أو أمر النسخ الاحتياطي في SQLite لتتضمن النسخة التغييرات المعتمدة في السجل.

## كيفية استعادة قاعدة SQLite من ملف SQL

نفّذ الأمر التالي لاستيراد النص البرمجي إلى قاعدة بيانات SQLite جديدة.

```sh
sqlite3 restored.sqlite < database.sql
```

استبدل `database.sql` باسم الملف الذي نزّلته. يستخدم النص البرمجي صياغة SQLite. إذا كانت قاعدة البيانات تستخدم جداول افتراضية أو ملحقات، فاستعدها في نسخة من SQLite تتوفر فيها الوحدات اللازمة.

لتصفّح الجداول أو تصدير نتائج الاستعلام بصيغة CSV أو JSON، افتح [عارض SQLite](../sqlite-viewer/). ولإنشاء قاعدة بيانات من جداول البيانات، استخدم أداة [تحويل CSV وExcel إلى SQLite](../csv-excel-to-sqlite/).
