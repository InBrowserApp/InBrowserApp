# DejaVu Sans

The unmodified DejaVu Sans regular and bold TTF files are from the [DejaVu Fonts 2.37 release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37). The accompanying license includes the copyright and redistribution terms. Diagram PDF export uses these fonts to outline text.

The unmodified [Noto Emoji variable font](https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/notoemoji) is distributed under the SIL Open Font License 1.1. It supplies monochrome outlines when labels use emoji.
